4.5 Tablas HTML

Las tablas permiten organizar información que presenta una relación entre filas y columnas. Son adecuadas para mostrar horarios, comparaciones, resultados, tarifas, estadísticas o cualquier otro conjunto de datos cuya estructura tabular ayude a comprender la información.

HTML proporciona elementos específicos para describir la estructura y el significado de una tabla. En este apartado aprenderemos a construirlas correctamente, diferenciando los datos de sus encabezados y organizando sus distintas partes de forma semántica.

📌 Importante

Las tablas HTML deben utilizarse para representar datos tabulares, no para colocar elementos en distintas zonas de una página. La maquetación de una interfaz se realizará mediante CSS y se estudiará en las unidades correspondientes.

Cuándo utilizar una tabla

Antes de crear una tabla debemos preguntarnos si existe una relación significativa entre los datos situados en sus filas y columnas. Si esa relación ayuda a interpretar o comparar la información, probablemente una tabla sea una estructura adecuada.

Contenido ¿Tabla? Motivo
Horario semanal de un grupo Sí Relaciona días, horas y módulos.
Comparación de características de varios planes Sí Permite comparar los mismos criterios entre distintas opciones.
Pasos para instalar una aplicación No Existe una secuencia, pero no una relación tabular entre filas y columnas.
Menú principal de un sitio web No Es un elemento de navegación, no un conjunto de datos tabulares.
⚠️ Atención

Durante años se utilizaron tablas para construir la distribución visual de páginas web. Esa práctica está obsoleta. Una tabla no debe utilizarse para crear columnas, cabeceras, barras laterales o cualquier otra parte del diseño de una interfaz.

Estructura básica de una tabla

Una tabla comienza con el elemento <table>. Dentro de él se crean las filas mediante <tr> y, dentro de cada fila, se incorporan las celdas.

HTML 
<table>
  <tr>
    <td>DWEC</td>
    <td>6 horas</td>
  </tr>
  <tr>
    <td>DIW</td>
    <td>6 horas</td>
  </tr>
</table>
Elemento Función
<table> Representa la tabla y contiene sus elementos.
<tr> Define una fila de la tabla.
<td> Define una celda de datos.

El número de celdas de cada fila dependerá de la estructura de los datos. En una tabla regular, las filas suelen mantener el mismo número de columnas, aunque posteriormente veremos cómo una celda puede abarcar varias filas o columnas.

Filas, celdas y encabezados

No todas las celdas tienen la misma función. Cuando una celda identifica o describe los datos de otras celdas debemos utilizar <th> en lugar de <td>. De este modo expresamos en el propio HTML que se trata de un encabezado de tabla.

HTML 
<table>
  <tr>
    <th>Módulo</th>
    <th>Horas semanales</th>
  </tr>
  <tr>
    <td>DWEC</td>
    <td>6</td>
  </tr>
  <tr>
    <td>DIW</td>
    <td>6</td>
  </tr>
</table>

En este ejemplo, Módulo y Horas semanales describen el significado de los datos situados debajo de ellos, por lo que se representan mediante <th>.

El atributo scope

El atributo scope permite indicar de forma explícita a qué conjunto de celdas se aplica un encabezado. Los valores más habituales en tablas sencillas son col para encabezados de columna y row para encabezados de fila.

HTML 
<tr>
  <th scope="col">Módulo</th>
  <th scope="col">Horas semanales</th>
</tr>

<tr>
  <th scope="row">DWEC</th>
  <td>6</td>
</tr>
📌 Importante

Utilizar <th> para los encabezados no consiste simplemente en conseguir que el navegador muestre el texto en negrita. Su función es describir la relación existente entre los datos. La apariencia visual se controlará posteriormente mediante CSS.

Organización de una tabla: <thead>, <tbody> y <tfoot>

Cuando una tabla contiene varias partes podemos agrupar sus filas mediante <thead>, <tbody> y <tfoot>. Estos elementos describen la función que desempeña cada grupo de filas.

Elemento Función
<thead> Agrupa las filas que forman la cabecera de la tabla.
<tbody> Agrupa las filas que contienen el cuerpo principal de datos.
<tfoot> Agrupa las filas finales, por ejemplo totales o resultados de resumen.
HTML 
<table>
  <thead>
    <tr>
      <th scope="col">Módulo</th>
      <th scope="col">Horas</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <th scope="row">DWEC</th>
      <td>6</td>
    </tr>
    <tr>
      <th scope="row">DIW</th>
      <td>6</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <th scope="row">Total</th>
      <td>12</td>
    </tr>
  </tfoot>
</table>

No todas las tablas necesitan obligatoriamente las tres secciones. Debemos utilizarlas cuando ayuden a representar con claridad la estructura real de los datos.

Título de una tabla con <caption>

El elemento <caption> proporciona un título o descripción breve que identifica el contenido de una tabla. Se coloca como primer hijo de <table>.

HTML 
<table>
  <caption>Horas semanales de varios módulos de 2.º DAW</caption>

  <thead>
    <tr>
      <th scope="col">Módulo</th>
      <th scope="col">Horas</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <th scope="row">DWEC</th>
      <td>6</td>
    </tr>
    <tr>
      <th scope="row">DIW</th>
      <td>6</td>
    </tr>
  </tbody>
</table>
⚠️ Atención

<caption> no es una celda ni debe colocarse dentro de <thead>. Pertenece directamente a la tabla y sirve para identificarla.

Combinación de celdas

En determinadas tablas una celda puede necesitar ocupar el espacio correspondiente a varias columnas o filas. Para ello se utilizan los atributos colspan y rowspan.

Atributo Función
colspan Indica cuántas columnas abarca una celda.
rowspan Indica cuántas filas abarca una celda.

Ejemplo con colspan

HTML 
<table>
  <tr>
    <th colspan="2">Horario del lunes</th>
  </tr>
  <tr>
    <th>Hora</th>
    <th>Módulo</th>
  </tr>
  <tr>
    <td>08:30 - 09:25</td>
    <td>DIW</td>
  </tr>
</table>

Ejemplo con rowspan

HTML 
<table>
  <tr>
    <th>Módulo</th>
    <th>Actividad</th>
  </tr>
  <tr>
    <th rowspan="2">DIW</th>
    <td>Diseño del prototipo</td>
  </tr>
  <tr>
    <td>Implementación de la interfaz</td>
  </tr>
</table>
⚠️ Atención

Al combinar celdas debemos comprobar cuidadosamente la estructura resultante. Un uso excesivo de colspan y rowspan puede hacer que una tabla sea más difícil de interpretar y mantener.

Buenas prácticas en el uso de tablas

Una tabla bien construida debe reflejar con claridad las relaciones existentes entre sus datos. Para conseguirlo conviene aplicar algunas prácticas básicas.

  • Utilizar tablas únicamente cuando el contenido sea realmente tabular.
  • Usar <th> para identificar correctamente los encabezados.
  • Utilizar scope="col" y scope="row" cuando ayuden a expresar la relación entre encabezados y datos.
  • Incluir <caption> cuando sea necesario identificar o contextualizar la tabla.
  • Organizar tablas con varias partes mediante <thead>, <tbody> y <tfoot> cuando corresponda.
  • Evitar combinaciones innecesariamente complejas mediante colspan y rowspan.
  • No utilizar atributos HTML obsoletos como border, cellpadding, cellspacing o align para controlar la presentación.
  • Aplicar la apariencia visual de la tabla mediante CSS.
💻 Ejemplo DAW

En StudyFlow podríamos utilizar una tabla para mostrar las entregas de una asignatura, relacionando cada actividad con su fecha límite y su estado. En cambio, no utilizaríamos una tabla para construir el menú, la cabecera o las columnas de la interfaz.

📌 Idea clave

La finalidad de una tabla HTML es representar relaciones entre datos. Los elementos de tabla describen esa estructura; CSS se encargará de su presentación visual.

💭 Piensa

Un alumno quiere colocar el menú a la izquierda y el contenido principal a la derecha. Para conseguirlo crea una tabla con una fila y dos celdas: en la primera introduce el menú y en la segunda todo el contenido de la página.

¿Es un uso adecuado de una tabla HTML? ¿Qué debería utilizar en su lugar?

Ver una posible solución

No. El menú y el contenido principal no forman un conjunto de datos tabulares. La tabla se estaría utilizando únicamente para controlar la distribución visual de la página.

La estructura del documento debe expresarse mediante los elementos HTML adecuados y la distribución visual debe realizarse mediante CSS, utilizando técnicas de maquetación como Flexbox o Grid, que estudiaremos más adelante.
