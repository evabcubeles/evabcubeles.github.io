📝 Actividades de la UT4

Para finalizar la UT4 vas a aplicar de forma conjunta los principales contenidos trabajados en los apartados 4.1 a 4.9.

Las actividades se dividen en dos partes: un reto final, en el que implementarás con HTML una página de StudyFlow, y una autoevaluación para comprobar los conceptos esenciales de la unidad.

🧩 Reto final — Construye la estructura HTML de StudyFlow

En la UT3 planificaste la arquitectura, la navegación y el prototipo de StudyFlow. Ahora ha llegado el momento de comenzar su implementación.

Tu trabajo consistirá en crear una página HTML completa que represente una de las vistas principales de la aplicación y utilice correctamente los elementos estudiados durante esta unidad.

El encargo

El equipo necesita una primera versión estructural de la página de una asignatura de StudyFlow. Todavía no se busca un diseño visual definitivo: el objetivo es construir un documento bien estructurado, semántico, legible y válido que posteriormente pueda recibir estilos CSS.

📌 Condición del proyecto

En este reto debes centrarte en HTML. No utilices tablas para maquetar ni dependas de estilos en línea para organizar la página. La presentación visual se desarrollará en las siguientes unidades de CSS.

Tu misión

Crea un archivo index.html para una asignatura de StudyFlow que cumpla los siguientes requisitos:

  1. Construye un documento HTML completo. Incluye <!DOCTYPE html>, el atributo lang, <head>, codificación UTF-8, viewport, un título adecuado y el <body>. Mantén una indentación coherente.
  2. Organiza correctamente el texto. Utiliza encabezados con una jerarquía lógica, párrafos, listas y los elementos de énfasis que resulten apropiados. Evita elegir etiquetas únicamente por su apariencia predeterminada.
  3. Crea la navegación. Añade enlaces a las principales zonas de StudyFlow y al menos un enlace interno mediante un fragmento e id. Utiliza rutas relativas cuando los recursos pertenezcan al proyecto.
  4. Incorpora una imagen. Añade al menos una imagen relacionada con la asignatura o el contenido. Decide qué valor debe tener alt según la función de la imagen y utiliza <figure> y <figcaption> cuando tenga sentido tratarla como una unidad con leyenda.
  5. Representa datos mediante una tabla. Incluye una tabla con las próximas actividades de la asignatura. Debe utilizar correctamente <table>, <caption>, <thead>, <tbody>, <tr>, <th>, <td> y los atributos scope necesarios.
  6. Añade un formulario. Crea un formulario sencillo para registrar una nueva tarea o enviar una consulta. Debe incluir etiquetas <label> correctamente asociadas, varios controles, al menos un campo obligatorio y un botón cuyo type esté indicado expresamente.
  7. Utiliza una estructura semántica. Organiza la página con los elementos que correspondan, como <header>, <nav>, <main>, <section>, <article>, <aside> o <footer>. No es necesario utilizarlos todos: selecciona únicamente los que describan realmente la función del contenido.
  8. Incorpora elementos semánticos específicos. Utiliza al menos dos de los elementos estudiados en el apartado 4.8, por ejemplo <details>/<summary>, <time>, <mark>, <abbr>, <blockquote> o <q>, siempre que tengan sentido en el contenido.
  9. Revisa el código. Comprueba el anidamiento, la unicidad de los id, las rutas, los atributos necesarios y la separación entre contenido y presentación. Corrige cualquier elemento o atributo utilizado de forma inadecuada.
  10. Valida el documento. Comprueba el archivo con Nu Html Checker. Corrige los errores detectados y vuelve a validar el documento. El objetivo es obtener un resultado sin errores de marcado y comprender las advertencias que pueda mostrar el validador.
📦 Entrega del reto

Entrega el archivo index.html junto con los recursos locales necesarios para visualizarlo correctamente. El código debe estar indentado, organizado y validado. Añade también una breve explicación de tres decisiones semánticas tomadas durante la implementación, indicando por qué has elegido esos elementos HTML para representar el contenido.

✅ Autoevaluación de la UT4

Responde las siguientes preguntas para comprobar qué contenidos de la UT4 has comprendido.

Cada pregunta tiene una única respuesta correcta.

1. ¿Cuál describe mejor la función principal de HTML en una interfaz web?

2. ¿Qué elemento es el más adecuado para representar un párrafo?

3. Si desde paginas/index.html queremos enlazar img/logo.png, situado en la carpeta superior del proyecto, ¿qué ruta relativa es adecuada?

4. ¿Qué opción es adecuada para una imagen puramente decorativa?

5. ¿Cuándo es apropiado utilizar una tabla HTML?

6. ¿Qué afirmación sobre <label> en un formulario es correcta?

7. ¿Qué elemento representa normalmente el contenido principal de una página?

8. ¿Qué combinación permite crear un bloque desplegable de forma nativa en HTML?

9. ¿Cuál de estas prácticas es la más adecuada?

10. ¿Qué significa que un documento HTML haya superado correctamente una validación de marcado?
