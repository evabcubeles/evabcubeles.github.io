4.4 Imágenes y contenido gráfico en HTML

Las imágenes forman parte habitual de las interfaces web: pueden mostrar productos, ilustrar contenidos, representar información o complementar visualmente una explicación. HTML permite incorporar estos recursos al documento y describir su función, mientras que otros aspectos, como su edición, formato, compresión u optimización, se estudiarán con más detalle en la UT8.

En este apartado nos centraremos en cómo integrar correctamente una imagen mediante HTML, cómo indicar su ubicación y qué información textual debemos proporcionar según la función que desempeñe dentro de la página.

📌 Importante

HTML no inserta normalmente los datos de la imagen dentro del documento: establece una referencia al recurso gráfico mediante su ruta. Por ello, una ruta incorrecta o un archivo inexistente impedirá que la imagen se muestre.

El elemento <img>

El elemento <img> permite incorporar una imagen a una página HTML. Es un elemento vacío: no contiene texto entre una etiqueta de apertura y otra de cierre, por lo que se escribe mediante una única etiqueta.

HTML 
<img src="img/estudiantes.jpg" alt="Estudiantes trabajando en un proyecto web">

En este ejemplo, src indica dónde se encuentra el archivo de imagen y alt proporciona una alternativa textual. Ambos atributos cumplen funciones diferentes y son fundamentales para integrar correctamente el recurso.

Elemento o atributo Función Ejemplo
<img> Incorpora una imagen al contenido del documento. <img ...>
src Indica la ruta del recurso gráfico. src="img/estudiantes.jpg"
alt Proporciona una alternativa textual adecuada a la función de la imagen. alt="Estudiantes trabajando en un proyecto web"
⚠️ Atención

No debemos utilizar una etiqueta de cierre como </img>. <img> es un elemento vacío y no admite contenido interno.

Rutas y recursos gráficos

El atributo src utiliza rutas de forma similar al atributo href que estudiamos en el apartado anterior. La ruta puede apuntar a un archivo situado dentro del propio proyecto o a un recurso disponible mediante una URL.

Imágenes del propio proyecto

Lo habitual es organizar los recursos gráficos en una carpeta específica, por ejemplo img o imagenes.

HTML 
<img src="img/logo.png" alt="StudyFlow">

<img src="../img/cabecera.jpg" alt="Alumnado utilizando ordenadores">
Ruta Interpretación
img/logo.png La carpeta img se encuentra dentro del directorio actual.
./img/logo.png Se parte explícitamente del directorio actual.
../img/cabecera.jpg Se sube un nivel antes de acceder a la carpeta img.

Imágenes mediante una URL

También es posible utilizar una dirección absoluta para referenciar una imagen alojada en otro lugar.

HTML 
<img
  src="https://example.com/imagenes/logo.png"
  alt="Logotipo de ejemplo"
>
⚠️ Atención

No debemos depender sin permiso de imágenes alojadas en sitios ajenos. El recurso podría cambiar, desaparecer o estar sujeto a condiciones de uso. La selección, licencias y tratamiento de recursos gráficos se estudiarán específicamente en la UT8.

Los atributos src y alt

Los atributos src y alt aparecen juntos con frecuencia, pero no significan lo mismo. src responde a la pregunta “¿dónde está la imagen?”, mientras que alt proporciona la alternativa textual que corresponde a la función de esa imagen en su contexto.

HTML 
<img
  src="img/grafico-entregas.png"
  alt="Las entregas aumentan progresivamente de septiembre a diciembre"
>

El texto alternativo no debe escribirse de forma automática describiendo únicamente el aspecto visual. Debe transmitir la información o finalidad relevante que aporta la imagen dentro de la página.

📌 Importante

No es necesario comenzar el texto alternativo con expresiones como “imagen de” o “foto de”. El propio elemento ya indica que se trata de una imagen. Lo importante es comunicar la información necesaria de forma breve y adecuada al contexto.

Anchura y altura

Los atributos width y height permiten indicar las dimensiones intrínsecas de la imagen en píxeles. Cuando conocemos sus dimensiones, incluir ambos valores ayuda al navegador a reservar el espacio necesario antes de que el recurso termine de cargarse.

HTML 
<img
  src="img/logo-studyflow.png"
  alt="StudyFlow"
  width="320"
  height="120"
>

Estos atributos no sustituyen al diseño mediante CSS. Más adelante podremos adaptar el tamaño visual de las imágenes a distintos diseños y dispositivos.

Imágenes con significado e imágenes decorativas

No todas las imágenes cumplen la misma función. Algunas aportan información necesaria para comprender el contenido; otras se utilizan únicamente como decoración. Esta diferencia determina cómo debemos tratar su alternativa textual.

Tipo de imagen Función Tratamiento de alt
Informativa Aporta información relevante al contenido. Debe disponer de un texto alternativo que comunique esa información.
Funcional Forma parte de un enlace o control y representa su finalidad. El texto alternativo debe comunicar la función del enlace o control.
Decorativa No añade información necesaria y solo cumple una función visual. Debe utilizar un atributo vacío: alt="".

Imagen informativa

HTML 
<img
  src="img/estado-proyecto.png"
  alt="El proyecto está completado al 75 %"
>

Imagen decorativa

HTML 
<img src="img/separador-decorativo.svg" alt="">

Aunque el valor esté vacío, el atributo alt se mantiene. De este modo indicamos que la imagen no aporta información textual necesaria.

Imagen utilizada como enlace

HTML 
<a href="index.html">
  <img src="img/inicio.svg" alt="Ir a la página de inicio">
</a>

En este caso, el texto alternativo comunica la finalidad del enlace, no una descripción puramente visual del icono.

💻 Ejemplo DAW

En StudyFlow, una captura que muestre el estado de una entrega puede ser informativa; una ilustración de fondo puede ser decorativa; y un icono utilizado como único contenido de un enlace debe comunicar la acción que permite realizar.

<figure> y <figcaption>

Cuando una imagen forma una unidad de contenido que necesita un pie o leyenda, podemos utilizar los elementos semánticos <figure> y <figcaption>.

HTML 
<figure>
  <img
    src="img/prototipo-studyflow.png"
    alt="Prototipo de la pantalla principal de StudyFlow"
  >
  <figcaption>
    Figura 1. Prototipo de la pantalla principal de StudyFlow.
  </figcaption>
</figure>

<figure> agrupa un contenido autocontenido relacionado con el flujo principal del documento, mientras que <figcaption> proporciona su leyenda o pie. Aunque es frecuente utilizarlos con imágenes, una figura también puede contener otros recursos, como diagramas, fragmentos de código o ilustraciones.

⚠️ Atención

<figcaption> no sustituye automáticamente al atributo alt. El pie visible y el texto alternativo cumplen funciones distintas y deben decidirse según la información que aporta la imagen en su contexto.

Buenas prácticas al incorporar imágenes

Al incorporar imágenes mediante HTML conviene mantener una serie de prácticas que facilitan la comprensión del documento y evitan errores frecuentes.

  • Utilizar rutas claras y mantener los recursos gráficos organizados dentro del proyecto.
  • Escribir un alt adecuado cuando la imagen aporte información o tenga una función.
  • Utilizar alt="" cuando una imagen sea realmente decorativa.
  • No repetir innecesariamente en alt información que ya aparece junto a la imagen.
  • Indicar width y height cuando se conozcan las dimensiones del recurso.
  • No utilizar atributos HTML obsoletos para controlar bordes, alineación o presentación visual.
  • Separar la estructura y el significado de la imagen de su presentación, que se controlará mediante CSS.
  • Comprobar que las rutas funcionan y que la página sigue siendo comprensible si una imagen no se carga.
📌 Idea clave

Al incorporar una imagen no basta con conseguir que aparezca en pantalla. Debemos indicar correctamente dónde se encuentra, qué función cumple y qué información aporta.

💭 Piensa

Un alumno incorpora el icono de una papelera como único contenido de un enlace que permite eliminar una actividad y escribe alt="papelera gris".

¿Es adecuado ese texto alternativo? ¿Qué información sería más útil?

Ver una posible solución

No. En este contexto la imagen tiene una función: permite activar un enlace para eliminar una actividad. Describir su aspecto visual no comunica qué ocurrirá al utilizarla.

Un texto como Eliminar actividad comunica mejor la finalidad del enlace. El texto alternativo debe responder a la función que desempeña la imagen en ese contexto.
