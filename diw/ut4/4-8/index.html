4.8 Otros elementos semánticos y de contenido

Además de los elementos estructurales estudiados en el apartado anterior, HTML dispone de otros elementos que permiten describir con mayor precisión determinados tipos de contenido. Utilizarlos cuando corresponde aporta significado al documento y evita recurrir siempre a contenedores genéricos.

En este apartado veremos algunos elementos especialmente útiles para incorporar figuras, crear bloques desplegables, representar fechas y horas, destacar fragmentos relevantes y expresar otros contenidos habituales de una interfaz web.

📌 Importante

Elegir un elemento HTML no depende de cómo queremos que se vea, sino de qué representa su contenido. La apariencia se definirá posteriormente mediante CSS.

<figure> y <figcaption>

En el apartado 4.4 vimos que <figure> y <figcaption> pueden utilizarse para asociar una imagen con su leyenda. Sin repetir lo ya estudiado, conviene ampliar una idea: <figure> no está limitado exclusivamente a las imágenes.

<figure> representa contenido autocontenido al que se hace referencia como una unidad dentro del documento y puede incluir una leyenda mediante <figcaption>. Puede contener, por ejemplo, una imagen, un diagrama, un fragmento de código o una ilustración.

HTML
<figure>
  <pre><code>const modulo = "DIW";
console.log(modulo);</code></pre>

  <figcaption>Ejemplo de un fragmento de código.</figcaption>
</figure>

<figcaption> proporciona la leyenda de la figura y puede aparecer como primer o último elemento dentro de <figure>.

⚠️ Atención

No debemos utilizar <figure> automáticamente para cualquier imagen. Si una imagen no constituye una unidad que necesite identificarse como figura, puede utilizarse simplemente <img>.

<details> y <summary>

Los elementos <details> y <summary> permiten crear un bloque cuyo contenido puede mostrarse u ocultarse de forma nativa, sin necesidad de programar ese comportamiento básico con JavaScript.

<details> contiene el bloque completo y <summary> proporciona el texto que actúa como encabezado o control visible del desplegable.

HTML
<details>
  <summary>Ver requisitos de la actividad</summary>
  <p>La entrega debe incluir el código HTML y la hoja de estilos.</p>
</details>

Al activar el <summary>, el navegador abre o cierra el contenido asociado. Además, el atributo booleano open permite indicar que el bloque aparezca inicialmente desplegado.

HTML
<details open>
  <summary>Información importante</summary>
  <p>La actividad se entrega el viernes.</p>
</details>
💻 Ejemplo DAW

Los propios apuntes que estás consultando utilizan este tipo de estructura para mostrar algunas soluciones de forma desplegable. HTML proporciona el comportamiento básico y CSS puede modificar posteriormente su presentación.

<time>

El elemento <time> permite representar fechas, horas y otros valores temporales de forma semántica. El texto visible puede estar escrito para las personas, mientras que el atributo datetime permite expresar el dato en un formato interpretable por software.

HTML
<p>
  Fecha de entrega:
  <time datetime="2026-10-25">25 de octubre de 2026</time>
</p>

También puede utilizarse para indicar una hora concreta:

HTML
<p>
  La presentación comienza a las
  <time datetime="18:30">18:30</time>.
</p>
📌 Importante

El contenido visible y el valor de datetime cumplen funciones diferentes: el primero se dirige a la persona usuaria y el segundo proporciona una representación procesable del dato temporal.

<mark>

El elemento <mark> representa una parte del texto que se encuentra marcada o resaltada por su relevancia en el contexto actual. Un caso habitual es destacar los términos que coinciden con una búsqueda.

HTML
<p>
  Resultado de búsqueda:
  Introducción al <mark>HTML semántico</mark>.
</p>
⚠️ Atención

<mark> no debe utilizarse simplemente porque queramos aplicar un fondo de color a una palabra. Si la finalidad es únicamente visual, corresponde utilizar CSS. Debe existir una razón semántica para considerar ese fragmento relevante en el contexto.

Otros elementos semánticos útiles

HTML incluye muchos otros elementos capaces de describir tipos concretos de contenido. No es necesario memorizar un catálogo completo, pero sí conocer algunos que aparecen con frecuencia.

ElementoUso principal
<address> Información de contacto de la persona u organización responsable del contenido o de la sección correspondiente.
<blockquote>Cita extensa procedente de otra fuente.
<q>Cita breve integrada dentro de un texto.
<cite>Título de una obra o creación citada.
<abbr>Abreviatura o acrónimo; puede ampliarse mediante el atributo title.

Ejemplo con una abreviatura

HTML
<p>
  El módulo de <abbr title="Diseño de Interfaces Web">DIW</abbr>
  pertenece al ciclo de DAW.
</p>

Ejemplo con una cita

HTML
<blockquote cite="https://ejemplo.com/fuente">
  <p>El diseño de una interfaz debe responder a las necesidades de sus usuarios.</p>
</blockquote>

El atributo cite puede indicar la fuente de una cita mediante una URL, pero esa dirección no se muestra automáticamente como un enlace visible. Si queremos que la persona usuaria pueda acceder a la fuente, debemos proporcionar también un enlace en el contenido.

Otros tipos de citas

Para una cita breve integrada dentro de un párrafo podemos utilizar <q>. Por su parte, <cite> permite identificar el título de una obra o creación.

HTML 
<p>
  Como indica la guía,
  <q>la interfaz debe mantener una estructura coherente</q>.
</p>

<p>
  Estamos consultando <cite>Diseño de interfaces web</cite>.
</p>
📌 Importante

<cite> identifica el título de una obra o creación; no se utiliza para marcar el nombre de la persona autora.

⚠️ Atención

HTML no dispone de un elemento <email>. Para solicitar una dirección de correo electrónico en un formulario se utiliza <input type="email">, como vimos en el apartado 4.6.

📌 Idea clave

Utilizar elementos semánticos no consiste en emplear el mayor número posible de etiquetas diferentes. Consiste en elegir el elemento que describa mejor el significado real del contenido y recurrir a elementos genéricos cuando no exista uno más apropiado.

En StudyFlow queremos mostrar la fecha límite de una actividad como «25 de octubre de 2026», permitir desplegar sus instrucciones y resaltar dentro de los resultados de búsqueda las palabras que coinciden con el término buscado.

¿Qué elementos HTML utilizarías para representar cada uno de esos contenidos?

Para la fecha utilizaríamos <time>, preferiblemente con un atributo datetime que represente el dato temporal de forma procesable.

Para las instrucciones desplegables utilizaríamos <details> junto con <summary>.
