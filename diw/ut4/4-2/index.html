4.2 Texto y organización del contenido

Una vez conocida la estructura básica de un documento HTML, el siguiente paso es aprender a organizar correctamente su contenido textual. HTML no se limita a mostrar texto: permite indicar qué función cumple cada fragmento dentro del documento.

Un título, un párrafo, una lista o una palabra especialmente importante no tienen el mismo significado. Utilizar el elemento adecuado permite construir documentos más claros, comprensibles y fáciles de mantener.

📌 Importante

En HTML debemos elegir los elementos por el significado del contenido, no por el aspecto que el navegador les aplica por defecto. La presentación visual se definirá posteriormente mediante CSS.

Encabezados

Los encabezados permiten identificar los títulos y subtítulos de un documento y establecer una jerarquía entre sus distintas partes. HTML dispone de seis niveles, desde <h1> hasta <h6>.

HTML 
<h1>StudyFlow</h1>
<h2>Asignaturas</h2>
<h3>Desarrollo de Aplicaciones Web</h3>

<h1> representa el encabezado de mayor nivel y <h6> el de menor nivel. Estos números expresan niveles jerárquicos, no tamaños de letra.

⚠️ Atención

No debemos utilizar <h1>, <h2> o <h3> para conseguir un texto más grande. Si necesitamos cambiar su tamaño o apariencia utilizaremos CSS. Los encabezados deben reflejar la organización lógica del contenido.

💻 Ejemplo DAW

En una página de una asignatura, <h1> podría identificar la página, <h2> separar bloques como “Próximas entregas” y “Materiales”, y <h3> identificar apartados incluidos dentro de uno de esos bloques.

Párrafos y saltos de línea

El elemento <p> representa un párrafo. Debemos utilizar un párrafo cuando un conjunto de frases forma una unidad de contenido independiente.

HTML 
<p>La actividad deberá entregarse antes del viernes.</p>
<p>Puedes consultar los materiales disponibles en el aula virtual.</p>

Los saltos de línea escritos directamente en el archivo HTML no crean necesariamente nuevos párrafos en la página. Para separar ideas distintas debemos utilizar elementos <p>.

Cuando el salto de línea forma parte del propio contenido, HTML proporciona el elemento <br>. Puede ser apropiado, por ejemplo, en una dirección postal o en determinados versos.

HTML 
<p>
  IES Ejemplo<br>
  Calle Principal, 10<br>
  Zaragoza
</p>
⚠️ Atención

No utilices varios <br> consecutivos para crear espacio entre elementos. El espaciado pertenece a la presentación y debe controlarse mediante CSS.

Énfasis e importancia del contenido

HTML permite expresar que una parte del texto tiene una importancia especial o debe enfatizarse. Para ello podemos utilizar, entre otros, los elementos <strong> y <em>.

Elemento Significado Ejemplo
<strong> Indica importancia, seriedad o urgencia especial. <strong>Entrega obligatoria</strong>
<em> Indica énfasis en una parte del texto. <em>antes del viernes</em>
<b> Llama visualmente la atención sin añadir importancia especial. <b>Palabra clave</b>
<i> Marca texto con una voz, término o convención diferenciada del texto normal. <i>responsive design</i>
HTML 
<p>
  <strong>Importante:</strong>
  la actividad debe entregarse <em>antes del viernes</em>.
</p>
📌 Importante

<strong> no significa simplemente “poner en negrita” y <em> no significa simplemente “poner en cursiva”. Su finalidad principal es aportar significado. El aspecto visual puede modificarse posteriormente con CSS.

Listas ordenadas y no ordenadas

Las listas permiten agrupar elementos relacionados. HTML distingue principalmente entre listas no ordenadas, cuando el orden de los elementos no es esencial, y listas ordenadas, cuando la secuencia sí tiene importancia.

Listas no ordenadas

Una lista no ordenada se crea con <ul> y cada elemento de la lista se representa mediante <li>.

HTML 
<ul>
  <li>Apuntes de la unidad</li>
  <li>Ejercicios prácticos</li>
  <li>Proyecto final</li>
</ul>

Listas ordenadas

Una lista ordenada se crea con <ol>. Cada elemento continúa representándose mediante <li>.

HTML 
<ol>
  <li>Analizar los requisitos</li>
  <li>Crear el prototipo</li>
  <li>Implementar la interfaz</li>
</ol>

Las listas también pueden anidarse cuando un elemento necesita contener una segunda lista. En ese caso, la lista interna debe situarse dentro del <li> correspondiente.

HTML 
<ul>
  <li>
    Desarrollo web
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
</ul>

Otros elementos de texto

Además de encabezados, párrafos y elementos de énfasis, HTML dispone de otros elementos que permiten describir con mayor precisión determinados tipos de contenido.

Elemento Uso habitual Ejemplo
<small> Comentarios secundarios, avisos legales o información complementaria. <small>Última actualización: septiembre</small>
<sub> Texto en subíndice. H<sub>2</sub>O
<sup> Texto en superíndice. m<sup>2</sup>
<code> Fragmentos de código informático. <code>display: grid;</code>
<pre> Texto preformateado que conserva espacios y saltos de línea. Útil para mostrar bloques de código junto con <code>.
HTML 
<p>La propiedad <code>display</code> controla el tipo de caja.</p>

<pre><code>
body {
  margin: 0;
}
</code></pre>
⚠️ Atención

Algunos elementos utilizados históricamente para dar formato visual al texto han quedado obsoletos o no deben utilizarse con ese propósito. La apariencia del contenido debe controlarse mediante CSS.

Estructura y jerarquía del contenido

Los elementos estudiados no deben utilizarse de forma aislada. Juntos permiten construir una estructura lógica que ayuda a comprender cómo se relacionan las distintas partes del contenido.

HTML 
<h1>Desarrollo de Aplicaciones Web</h1>

<h2>Diseño de Interfaces Web</h2>
<p>Materiales y actividades del módulo.</p>

<h3>Contenidos</h3>
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>Diseño responsive</li>
</ul>

<h3>Próxima entrega</h3>
<p>
  <strong>Proyecto de interfaz:</strong>
  entrega el viernes.
</p>

En este ejemplo, los encabezados establecen los niveles del contenido, los párrafos desarrollan la información y la lista agrupa elementos relacionados. El resultado es un documento cuya organización puede comprenderse incluso sin aplicar estilos CSS.

📌 Idea clave

La jerarquía visual podrá modificarse con CSS, pero la jerarquía del contenido debe quedar correctamente expresada en HTML.

💭 Piensa

Un alumno necesita mostrar el título de una actividad, una breve explicación, una lista de tres requisitos y un aviso indicando que la entrega es obligatoria. Decide escribir todo el contenido dentro de un único <p> y utilizar varios <br> para separarlo visualmente.

¿Es una buena estructura HTML? ¿Qué elementos utilizarías para representar mejor cada parte del contenido?

Ver una posible solución

No. Aunque el navegador podría mostrar el contenido, un único párrafo no expresa correctamente la función de cada parte.

Sería preferible utilizar un encabezado para el título, un párrafo para la explicación, una lista para los requisitos y <strong> para indicar la importancia del aviso cuando corresponda. De este modo, la estructura describe el significado del contenido y no depende de saltos de línea para organizarlo.
