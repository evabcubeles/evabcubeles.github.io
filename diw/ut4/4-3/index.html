4.3 Enlaces y navegación mediante HTML

Una de las características fundamentales de la Web es la posibilidad de relacionar documentos y recursos mediante hipervínculos. Gracias a ellos, el usuario puede desplazarse entre páginas, acceder a diferentes zonas de un mismo documento, descargar archivos o iniciar determinadas acciones.

En HTML, los enlaces se crean principalmente mediante el elemento <a>. Para utilizarlos correctamente debemos comprender tanto su sintaxis como la forma en que se construyen las rutas hacia los distintos recursos.

📌 Importante

Un enlace debe indicar claramente adónde conduce o qué acción realizará. El texto del enlace forma parte del contenido y debe resultar comprensible para el usuario.

El elemento <a>

El elemento <a>, conocido como ancla, permite crear un hipervínculo. Su atributo más importante es href, que indica el destino al que se accederá al activar el enlace.

HTML 
<a href="actividades.html">Ver actividades</a>

En este ejemplo, actividades.html es el destino y Ver actividades es el texto que verá el usuario. El contenido situado entre las etiquetas de apertura y cierre constituye la parte activable del enlace.

Parte Función Ejemplo
<a> Define el elemento de enlace. <a>...</a>
href Indica la dirección o recurso de destino. href="actividades.html"
Texto del enlace Comunica al usuario el destino o finalidad del enlace. Ver actividades
⚠️ Atención

Evita textos poco informativos como “haz clic aquí” o “más”. Es preferible utilizar expresiones que describan el destino, por ejemplo Consultar calendario de entregas.

Rutas absolutas y relativas

El valor de href puede contener distintos tipos de rutas. Elegir la adecuada depende de dónde se encuentre el recurso de destino respecto al documento actual.

Rutas absolutas

Una ruta absoluta contiene la dirección completa de un recurso. Se utiliza habitualmente para enlazar páginas o recursos situados en otros sitios web.

HTML 
<a href="https://developer.mozilla.org/">Consultar MDN Web Docs</a>

Rutas relativas

Una ruta relativa indica la ubicación del recurso tomando como referencia la posición del documento HTML actual. Son especialmente útiles para relacionar páginas y archivos pertenecientes al mismo proyecto.

HTML 
<a href="actividades.html">Actividades</a>
<a href="materiales/tema1.html">Tema 1</a>
<a href="../index.html">Volver al inicio</a>
Ruta Significado
actividades.html Archivo situado en la misma carpeta que la página actual.
./actividades.html . representa el directorio actual. En este caso, el archivo se encuentra en la misma carpeta que la página actual.
materiales/tema1.html Archivo situado dentro de la carpeta materiales.
../index.html .. permite subir un nivel en la estructura de carpetas.

En muchos casos, actividades.html y ./actividades.html hacen referencia al mismo recurso. El prefijo ./ indica de forma explícita que partimos del directorio actual.

💻 Ejemplo DAW

En un proyecto con varias páginas HTML, las rutas relativas permiten movernos entre los documentos sin escribir la dirección completa del sitio. Si la estructura de carpetas está bien organizada, los enlaces resultan más fáciles de mantener.

Enlaces internos dentro de una página

Un enlace también puede llevar a una zona concreta del mismo documento. Para ello, el elemento de destino debe disponer de un atributo id y el enlace utilizará ese identificador precedido por el símbolo #.

HTML 
<a href="#actividades">Ir a las actividades</a>

...

<h2 id="actividades">Actividades</h2>

Al activar el enlace, el navegador se desplazará hasta el elemento cuyo id sea actividades. Este mecanismo es especialmente útil en documentos largos, índices de contenidos o páginas con numerosos apartados.

También podemos combinar una ruta con un fragmento para acceder directamente a una zona concreta de otra página.

HTML 
<a href="tema1.html#ejercicios">Ejercicios del tema 1</a>
⚠️ Atención

El valor de id debe identificar de forma única a un elemento dentro del documento. Si repetimos el mismo identificador, los enlaces internos pueden producir resultados incorrectos y el HTML deja de estar correctamente estructurado.

Enlaces a otros recursos

El atributo href no se limita a páginas HTML. También puede apuntar a archivos u otros tipos de destinos. Por ejemplo, podemos enlazar un documento PDF o proporcionar un enlace de correo electrónico.

HTML 
<a href="documentos/guia.pdf">Consultar guía en PDF</a>

<a href="mailto:profesor@example.com">Enviar un correo al profesor</a>

<a href="tel:+34976000000">Llamar al centro</a>

Los esquemas mailto: y tel: permiten solicitar al dispositivo que abra una aplicación compatible para redactar un correo o realizar una llamada, respectivamente.

Enlaces de descarga

El atributo download permite indicar que un recurso enlazado está destinado a descargarse en lugar de utilizarse como una navegación convencional.

HTML 
<a href="documentos/guia.pdf" download>
  Descargar guía en PDF
</a>

También podemos proponer un nombre para el archivo descargado asignando un valor al atributo download.

HTML 
<a href="documentos/guia.pdf" download="guia-diw.pdf">
  Descargar guía de DIW
</a>
📌 Importante

El comportamiento de download puede depender del origen del recurso y de las políticas del navegador. No debemos asumir que cualquier recurso externo podrá descargarse de esta forma.

Abrir un enlace en otra pestaña

El atributo target="_blank" solicita al navegador que abra el destino en un nuevo contexto de navegación, normalmente una nueva pestaña.

HTML 
<a
  href="https://developer.mozilla.org/"
  target="_blank"
  rel="noopener"
>
  Abrir MDN Web Docs
</a>

Cuando utilizamos target="_blank", es habitual acompañarlo de rel="noopener" para impedir que la nueva página obtenga acceso a la página que abrió el enlace mediante window.opener. Los navegadores modernos ya aplican esta protección de forma implícita a _blank, pero escribir noopener hace explícita la intención.

📌 Importante

No es necesario abrir todos los enlaces externos en una pestaña nueva. Debemos utilizar target="_blank" únicamente cuando exista una razón clara para conservar la página actual abierta y teniendo en cuenta que cambia el comportamiento habitual de la navegación.

Enlaces y navegación de una interfaz

Los enlaces son uno de los mecanismos básicos con los que se construye la navegación de un sitio web. Menús, índices, migas de pan o enlaces contextuales pueden contener elementos <a> que permiten desplazarse entre los diferentes recursos.

En la UT3 estudiamos cómo diseñar un sistema de navegación coherente. Ahora podemos trasladar parte de ese diseño a HTML mediante enlaces correctamente estructurados.

HTML 
<nav aria-label="Navegación principal">
  <ul>
    <li><a href="index.html">Inicio</a></li>
    <li><a href="asignaturas.html">Asignaturas</a></li>
    <li><a href="actividades.html">Actividades</a></li>
  </ul>
</nav>

En el ejemplo, cada opción de navegación es un enlace. El elemento <nav> identifica un bloque importante de navegación; estudiaremos los elementos semánticos de estructura con más detalle en el apartado 4.7.

💻 Ejemplo DAW

En StudyFlow, el menú principal podría enlazar con el panel de inicio, las asignaturas y las actividades. Los enlaces contextuales podrían llevar desde una asignatura hasta sus materiales o entregas concretas. La estructura HTML implementa así parte del sistema de navegación que previamente habíamos planificado.

📌 Idea clave

Un buen enlace combina una ruta correcta con un texto de enlace comprensible. HTML define el destino y el significado; CSS se encargará posteriormente de su apariencia.

💭 Piensa

Un alumno crea un menú con tres enlaces cuyo texto es “Haz clic aquí”, “Haz clic aquí” y “Haz clic aquí”. Cada uno conduce a una página diferente del proyecto.

Aunque las rutas sean correctas, ¿qué problema presenta esta navegación? ¿Cómo la mejorarías?

Ver una posible solución

El texto de los enlaces no informa sobre su destino. El usuario tendría que deducir adónde conduce cada enlace a partir del contexto.

Sería preferible utilizar textos descriptivos como Asignaturas, Actividades o Calendario de entregas. De esta forma, cada enlace comunica su finalidad incluso cuando se interpreta de manera aislada.
