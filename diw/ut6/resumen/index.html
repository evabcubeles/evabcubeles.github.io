✏️ Resumen de la UT6

En esta unidad hemos estudiado cómo organizar, distribuir y alinear los elementos de una interfaz web mediante CSS, pasando de las técnicas básicas de visualización y posicionamiento a sistemas de maquetación más potentes como Flexbox y CSS Grid.

Este resumen reúne las ideas esenciales para utilizarlo como guía rápida de repaso. Nos ayudará a elegir la técnica de maquetación adecuada, interpretar sus propiedades y combinar diferentes sistemas de distribución en una misma página.

Visión global de la unidad

Maquetar una interfaz web consiste en decidir dónde se sitúan los elementos, cómo se relacionan entre sí y cómo se distribuye el espacio. CSS ofrece diferentes mecanismos para resolver estas necesidades.

📌 Idea fundamental

No existe una única técnica de maquetación válida para todas las situaciones. La elección depende de la estructura que queremos construir y de cómo deben comportarse sus elementos.

Flujo del documento y visualización

El flujo normal del documento determina cómo se colocan los elementos HTML cuando no utilizamos técnicas especiales de posicionamiento o maquetación.

▭ block

El elemento genera una caja de bloque que normalmente comienza en una nueva línea y ocupa el ancho disponible de su contenedor.

↔️ inline

El elemento participa en el flujo del texto. Sus dimensiones no se controlan de la misma forma que las de una caja de bloque.

▣ inline-block

Permite que una caja participe en línea y, al mismo tiempo, admita dimensiones propias de una caja de bloque.

🚫 none

display: none elimina la caja del elemento de la disposición visual y no reserva su espacio.

📐 flex

Convierte el elemento en un contenedor flexible que distribuye sus hijos directos mediante Flexbox.

🔲 grid

Convierte el elemento en un contenedor Grid para organizar sus hijos directos en filas y columnas.

⚠️ No confundas

display: none y visibility: hidden no tienen el mismo efecto. El primero elimina la caja de la disposición, mientras que el segundo oculta el elemento, pero normalmente conserva su espacio.

Posicionamiento de elementos

La propiedad position permite modificar la forma en que se posiciona un elemento. Su comportamiento depende del valor utilizado y del contexto en el que se encuentra.

📄 static

Es el valor predeterminado. El elemento sigue el flujo normal y las propiedades de desplazamiento top, right, bottom y left no lo desplazan.

↗️ relative

Permite desplazar visualmente el elemento respecto a su posición normal sin eliminar el espacio que ocupaba en el flujo.

🎯 absolute

El elemento sale del flujo normal y se posiciona respecto a su bloque contenedor de referencia.

📌 fixed

El elemento sale del flujo normal y normalmente permanece situado respecto a la ventana gráfica.

📍 sticky

Combina el comportamiento en flujo con la posibilidad de mantenerse en una posición durante el desplazamiento.

🗂️ z-index

Permite controlar el orden de superposición de los elementos. Su efecto depende del posicionamiento y de los contextos de apilamiento existentes.

top, right, bottom y left Permiten indicar desplazamientos o posiciones según el tipo de posicionamiento utilizado.
Contenedor de referencia En posicionamiento absoluto es importante identificar qué bloque establece la referencia para situar el elemento.
⚠️ Error frecuente

Utilizar position: absolute para construir toda la estructura de una página suele dificultar su mantenimiento y adaptación. Para organizar secciones y componentes normalmente es preferible utilizar Flexbox o Grid.

Flexbox: distribución flexible

Flexbox es un sistema de maquetación especialmente útil para distribuir y alinear elementos a lo largo de un eje principal. Resulta adecuado para barras de navegación, grupos de botones, cabeceras y componentes.

Ejemplo visual: distribución con Flexbox
Inicio
Cursos
Contacto
display: flex Activa Flexbox en el contenedor. Sus hijos directos pasan a ser elementos flexibles.
flex-direction Define la dirección del eje principal: row, row-reverse, column o column-reverse.
flex-wrap Permite controlar si los elementos permanecen en una sola línea o pueden distribuirse en varias.
gap Establece separaciones entre elementos sin tener que aplicar márgenes individuales.

Propiedades de los elementos flexibles

↔️ flex-grow

Determina cómo puede crecer un elemento para ocupar espacio libre del eje principal.

↘️ flex-shrink

Determina cómo puede reducirse un elemento cuando falta espacio disponible.

📏 flex-basis

Establece el tamaño base inicial utilizado en el cálculo de distribución flexible.

🔧 flex

Es una propiedad abreviada que combina flex-grow, flex-shrink y flex-basis.

🔢 order

Modifica el orden visual de los elementos, pero no altera su orden en el documento HTML.

🎯 align-self

Permite ajustar individualmente la alineación de un elemento en el eje transversal.

Alineación y distribución con Flexbox

Para comprender la alineación en Flexbox debemos distinguir el eje principal y el eje transversal. Su orientación depende de flex-direction.

justify-content Distribuye los elementos sobre el eje principal. Algunos valores son flex-start, center, space-between y space-around.
align-items Controla la alineación de los elementos sobre el eje transversal. Admite valores como stretch, center o flex-start.
align-content Distribuye las líneas flexibles en el eje transversal cuando existen varias líneas y espacio disponible.
align-self Permite modificar la alineación transversal de un elemento concreto.
📌 Regla para recordar

En Flexbox, justify-content actúa sobre el eje principal y align-items sobre el eje transversal. Si cambia flex-direction, también cambia la orientación de esos ejes.

CSS Grid: maquetación en filas y columnas

CSS Grid permite construir distribuciones bidimensionales mediante filas y columnas. Es especialmente adecuado para estructuras de página, paneles, galerías y cuadrículas de tarjetas.

display: grid Activa CSS Grid en el contenedor y convierte sus hijos directos en elementos de la cuadrícula.
grid-template-columns Define las columnas explícitas y sus tamaños.
grid-template-rows Define las filas explícitas y sus tamaños.
gap Establece la separación entre filas y columnas de la cuadrícula.
grid-column y grid-row Permiten indicar la posición o extensión de un elemento sobre las líneas de la cuadrícula.
grid-template-areas Permite describir una estructura mediante nombres de áreas.

Funciones y unidades importantes

📐 fr

Representa una fracción del espacio disponible en la cuadrícula. Ejemplo: 1fr 2fr.

🔁 repeat()

Permite repetir un patrón de pistas. Ejemplo: repeat(3, 1fr).

↔️ minmax()

Define un tamaño mínimo y máximo para una pista de Grid.

🧩 auto-fit

Ajusta el número de pistas repetidas al espacio disponible y contrae las pistas vacías, permitiendo que las ocupadas aprovechen mejor el espacio.

📦 auto-fill

Genera tantas pistas repetidas como puedan caber en el contenedor y conserva las pistas vacías, aunque no contengan elementos.

⚙️ auto

Su comportamiento depende de la propiedad y del contexto de dimensionamiento utilizado.

📌 Diferencia entre auto-fit y auto-fill

auto-fill conserva las pistas vacías que se hayan generado, mientras que auto-fit contrae las pistas repetidas vacías, permitiendo que las ocupadas aprovechen el espacio disponible.

💻 Ejemplo DAW

Una cuadrícula de cursos puede utilizar repeat(auto-fit, minmax(...)) para adaptar el número de columnas al espacio disponible, sin fijar siempre tres columnas de anchura rígida. 

.cursos {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(min(100%, 190px), 1fr));
  gap: 16px;
}

Distribución y alineación con CSS Grid

CSS Grid dispone de propiedades para alinear los elementos dentro de sus áreas y para distribuir la cuadrícula completa dentro del contenedor cuando existe espacio disponible.

justify-items Alinea los elementos de la cuadrícula dentro de sus áreas en el eje en línea.
align-items Alinea los elementos dentro de sus áreas en el eje de bloque.
justify-content Distribuye las pistas de la cuadrícula en el eje en línea cuando existe espacio libre para hacerlo.
align-content Distribuye las pistas en el eje de bloque cuando hay espacio libre disponible.
justify-self Permite alinear individualmente un elemento en el eje en línea.
align-self Permite alinear individualmente un elemento en el eje de bloque.
⚠️ Diferencia importante

justify-items y align-items alinean elementos dentro de sus áreas. En cambio, justify-content y align-content distribuyen las pistas de la cuadrícula. No producen necesariamente el mismo efecto.

Maquetación avanzada: combinación de técnicas

En una interfaz real es habitual combinar CSS Grid para organizar las regiones principales y Flexbox para distribuir elementos dentro de esas regiones.

Ejemplo visual: estructura general con Grid
Cabecera
Menú lateral
Contenido principal
Pie de página
Estructura general Grid permite organizar cabecera, menú lateral, contenido y pie mediante filas, columnas y áreas.
Navegación Flexbox facilita distribuir enlaces y controles dentro de una cabecera.
Tarjetas de contenido Grid permite construir cuadrículas de cursos, productos o recursos.
Elementos internos Flexbox permite organizar botones, etiquetas y otros componentes dentro de cada tarjeta.
📌 Contenedores anidados

Un contenedor Grid puede contener elementos que a su vez sean contenedores Flexbox o Grid. Cada contenedor organiza sus propios hijos directos, por lo que ambas técnicas pueden combinarse sin conflicto.

Flexbox frente a CSS Grid

Aunque ambas técnicas permiten distribuir elementos, cada una resulta especialmente útil en situaciones diferentes.

Característica Flexbox CSS Grid
Enfoque Principalmente unidimensional Bidimensional
Organización Distribución en un eje principal Filas y columnas relacionadas
Uso habitual Menús, botones y componentes Estructuras, paneles y cuadrículas
Espaciado gap gap
Alineación justify-content, align-items justify-items, align-items, justify-content, align-content
Combinación Puede utilizarse dentro de Grid Puede utilizarse dentro de Flexbox
📌 Criterio práctico

Flexbox es una buena elección para distribuir componentes en una dirección. Grid es una buena elección para organizar estructuras en filas y columnas. Son técnicas complementarias, no alternativas excluyentes.

Buenas prácticas de maquetación

Una maquetación adecuada debe ser comprensible, coherente y fácil de mantener. No se trata de utilizar muchas propiedades, sino de elegir las necesarias para resolver cada problema.

🧭 Elegir la técnica

Utilizar Flexbox o Grid según las necesidades de distribución y alineación.

🧩 Separar responsabilidades

Organizar la estructura general y los componentes internos mediante contenedores adecuados.

📏 Evitar tamaños rígidos

Utilizar medidas y funciones que permitan aprovechar mejor el espacio disponible.

🧹 Mantener CSS legible

Emplear clases descriptivas, reglas organizadas y evitar declaraciones innecesarias.

📱 Comprobar distintas anchuras

Revisar que los elementos no se solapen ni provoquen desbordamientos.

🔍 Probar el resultado

Utilizar las herramientas del navegador para comprobar la distribución real.

⚠️ Atención al orden visual

Propiedades como order o determinadas formas de posicionamiento pueden modificar la disposición visual sin cambiar el orden del HTML. Debemos evitar que esa diferencia dificulte la navegación por teclado o la comprensión del contenido.

Ideas clave de la UT6

📌 Si tuvieras que recordar solo estas ideas…
  • Maquetar una interfaz consiste en organizar y distribuir sus elementos de manera coherente.
  • El flujo normal del documento determina la disposición inicial de los elementos HTML.
  • La propiedad display controla el tipo de caja y puede activar Flexbox o Grid.
  • Posicionamiento y maquetación no son exactamente lo mismo. position permite situar elementos, mientras que Flexbox y Grid organizan distribuciones.
  • Flexbox es especialmente útil para distribuir elementos a lo largo de un eje principal.
  • En Flexbox, justify-content actúa sobre el eje principal y align-items sobre el transversal.
  • CSS Grid permite organizar elementos mediante filas y columnas.
  • fr, repeat() y minmax() facilitan la definición de cuadrículas flexibles.
  • En Grid debemos distinguir entre alinear elementos dentro de sus áreas y distribuir las pistas de la cuadrícula.
  • Grid y Flexbox pueden combinarse mediante contenedores anidados.
  • La elección de la técnica debe responder a las necesidades de la interfaz, no a la cantidad de propiedades CSS que podamos utilizar.
  • Una buena maquetación debe ser legible, mantenible y adaptable a diferentes espacios disponibles.
