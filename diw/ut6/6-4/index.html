6.4 Introducción a Flexbox

En los apartados anteriores hemos estudiado cómo se distribuyen los elementos HTML mediante el flujo normal, las propiedades de posicionamiento y la flotación.

Estas técnicas permiten controlar diferentes aspectos de una interfaz, pero presentan limitaciones cuando necesitamos organizar varios elementos en filas, columnas o grupos que se adapten al espacio disponible.

Para resolver estas necesidades, CSS dispone de Flexbox, un sistema de maquetación especialmente diseñado para distribuir y organizar elementos dentro de un contenedor.

📌 Importante

Flexbox permite organizar elementos en una dimensión principal: una fila o una columna. Facilita su distribución, alineación y adaptación al espacio disponible sin recurrir a flotaciones ni posicionamientos artificiales.

Qué es Flexbox

Flexbox, abreviatura de Flexible Box Layout, es un modelo de distribución de CSS que permite organizar los elementos hijos de un contenedor de forma flexible.

Su principal ventaja es que el navegador puede distribuir los elementos teniendo en cuenta el espacio disponible y las reglas que definimos mediante CSS.

Por ejemplo, podemos utilizar Flexbox para colocar tres botones uno junto a otro, organizar los enlaces de un menú o distribuir las tarjetas de una interfaz.

Comparación con el flujo normal

Cuando utilizamos elementos de bloque como <div>, estos se colocan normalmente uno debajo de otro.

HTML 
<div class="contenedor">
  <div>Elemento 1</div>
  <div>Elemento 2</div>
  <div>Elemento 3</div>
</div>
Resultado visual: flujo normal
Elemento 1
Elemento 2
Elemento 3

Los tres elementos de bloque se muestran uno debajo de otro.

Si aplicamos display: flex al contenedor, los elementos pasan a distribuirse horizontalmente de forma predeterminada.

CSS 
.contenedor {
  display: flex;
  gap: 10px;
}
Resultado visual: Flexbox
Elemento 1
Elemento 2
Elemento 3

Los elementos aparecen en una fila. La propiedad gap establece una separación de 10 píxeles entre ellos.

¿Para qué se utiliza Flexbox?

Necesidad Aplicación de Flexbox
Menús de navegación Colocar enlaces en una fila y distribuirlos dentro de la cabecera.
Grupos de botones Organizar acciones con separaciones uniformes.
Tarjetas Distribuir tarjetas en filas que puedan adaptarse al espacio.
Formularios Organizar campos, etiquetas y botones.
Cabeceras y barras de herramientas Colocar elementos y controlar su alineación.
💻 Ejemplo DAW

En StudyFlow utilizaremos Flexbox para organizar botones de navegación, acciones de usuario y grupos de elementos de la interfaz. Esto permitirá mantener una distribución más flexible y fácil de modificar.

Contenedor y elementos flexibles

Para trabajar con Flexbox debemos distinguir dos conceptos fundamentales: el contenedor flexible y los elementos flexibles.

El contenedor es el elemento al que aplicamos display: flex. Sus hijos directos pasan a participar en el modelo de distribución flexible.

Estructura básica

HTML + CSS 
<div class="contenedor-flex">

  <div class="elemento">1</div>
  <div class="elemento">2</div>
  <div class="elemento">3</div>

</div>

<style>

  .contenedor-flex {
    display: flex;
    gap: 12px;
  }

  .elemento {
    padding: 14px 18px;
    background-color: #e4f3e9;
    border: 1px solid #85c79b;
  }

</style>
Resultado visual Contenedor flexible
1
2
3

El borde discontinuo representa el contenedor. Los tres bloques verdes son sus elementos flexibles.

¿Qué elementos se convierten en flexibles?

Cuando aplicamos display: flex, los hijos directos del contenedor se convierten en elementos flexibles.

Los elementos que estén dentro de esos hijos no se convierten automáticamente en elementos flexibles del contenedor exterior.

HTML 
<div class="contenedor-flex">

  <div class="tarjeta">

    <h3>Diseño de Interfaces Web</h3>
    <p>Materiales de la asignatura</p>

  </div>

  <div class="tarjeta">

    <h3>Desarrollo Web en Entorno Cliente</h3>
    <p>Actividades de JavaScript</p>

  </div>

</div>

En este ejemplo, las dos tarjetas son elementos flexibles porque son hijas directas del contenedor. Los títulos y los párrafos siguen organizándose normalmente dentro de cada tarjeta.

⚠️ Atención

Flexbox no se aplica automáticamente a todos los descendientes. Si queremos utilizar otra distribución flexible dentro de una tarjeta, tendremos que aplicar display: flex al contenedor interior correspondiente.

Eje principal y eje transversal

Para comprender Flexbox es necesario conocer sus dos ejes de referencia: el eje principal (main axis) y el eje transversal (cross axis).

Estos ejes determinan cómo se organizan y alinean los elementos dentro del contenedor flexible.

El eje principal

Es el eje sobre el que se distribuyen los elementos flexibles. Su orientación depende de la propiedad flex-direction.

Por defecto, cuando utilizamos flex-direction: row, el eje principal sigue la dirección horizontal de escritura. En una página en español con dirección de izquierda a derecha, avanza hacia la derecha.

El eje transversal

Es perpendicular al eje principal. Si los elementos se distribuyen horizontalmente, el eje transversal es vertical.

CSS 
.contenedor {
  display: flex;
  flex-direction: row;
  gap: 12px;
}
Resultado visual: los ejes de Flexbox
1
2
3
━━ Eje principal → ┃ Eje transversal ↓

Con flex-direction: row, los elementos se distribuyen a lo largo del eje principal horizontal. El eje transversal es perpendicular.

Los ejes cambian con la dirección

Si utilizamos flex-direction: column, el eje principal pasa a seguir la dirección vertical de escritura y el transversal queda perpendicular.

Dirección Eje principal Eje transversal
row Horizontal Vertical
column Vertical Horizontal
📌 Idea clave

Los ejes de Flexbox no son necesariamente horizontal y vertical. Dependen de la dirección establecida para el contenedor y del modo de escritura del documento.

display: flex e inline-flex

Para activar Flexbox utilizamos la propiedad display. Los valores principales son flex e inline-flex.

display: flex

Convierte el elemento en un contenedor flexible que, hacia el exterior, se comporta como un elemento de bloque.

Esto significa que, normalmente, ocupa el ancho disponible de su contenedor, mientras que sus hijos se organizan mediante Flexbox.

HTML + CSS 
<div class="botones">
  <button>Guardar</button>
  <button>Editar</button>
  <button>Eliminar</button>
</div>

<style>

  .botones {
    display: flex;
    gap: 10px;
  }

</style>
Resultado visual

El contenedor ocupa el ancho disponible y los botones aparecen distribuidos en una fila.

display: inline-flex

También crea un contenedor flexible, pero su comportamiento exterior es similar al de un elemento en línea.

Esto permite integrar un grupo de elementos flexibles dentro de una línea de texto.

HTML + CSS 
<p>
  Estado:

  <span class="grupo-estados">
    <span>Activo</span>
    <span>Verificado</span>
  </span>

</p>

<style>

  .grupo-estados {
    display: inline-flex;
    gap: 10px;
  }

</style>
Resultado visual

Estado: Activo Verificado

El grupo de estados se integra dentro de la línea de texto. Sus elementos internos siguen utilizando Flexbox.

Diferencias principales

Propiedad Comportamiento exterior Comportamiento interior
display: flex Contenedor de bloque Distribución flexible
display: inline-flex Contenedor en línea Distribución flexible
⚠️ Atención

La diferencia entre flex e inline-flex afecta al comportamiento exterior del contenedor. En ambos casos, los hijos directos se distribuyen mediante Flexbox.

Dirección de los elementos

La propiedad flex-direction establece la dirección del eje principal y, por tanto, cómo se distribuyen los elementos dentro del contenedor.

Dispone de cuatro valores principales: row, row-reverse, column y column-reverse.

Valor Comportamiento
row Los elementos se distribuyen en una fila. Es el valor predeterminado.
row-reverse Los elementos se distribuyen en una fila, pero en sentido inverso.
column Los elementos se distribuyen en una columna.
column-reverse Los elementos se distribuyen en una columna, en sentido inverso.

flex-direction: row

Es el valor predeterminado. En una página con escritura de izquierda a derecha, los elementos aparecen de izquierda a derecha.

CSS 
.contenedor {
  display: flex;
  flex-direction: row;
  gap: 10px;
}
Resultado visual
1
2
3

Orden visual: 1 → 2 → 3.

flex-direction: row-reverse

Invierte el sentido del eje principal. En una página de izquierda a derecha, los elementos comienzan desde el extremo derecho del contenedor.

CSS 
.contenedor {
  display: flex;
  flex-direction: row-reverse;
  gap: 10px;
}
Resultado visual
1
2
3

Los elementos aparecen desde la derecha: 1, 2 y 3, avanzando hacia la izquierda. Visualmente, de izquierda a derecha, vemos 3, 2 y 1.

flex-direction: column

Coloca los elementos uno debajo de otro, siguiendo el eje principal vertical.

CSS 
.contenedor {
  display: flex;
  flex-direction: column;
  gap: 10px;
}
Resultado visual
1
2
3

Los elementos se muestran en una columna, de arriba hacia abajo.

flex-direction: column-reverse

Invierte el sentido del eje principal vertical. En una página con escritura horizontal habitual, el primer elemento aparece en la parte inferior.

CSS 
.contenedor {
  display: flex;
  flex-direction: column-reverse;
  gap: 10px;
}
Resultado visual
1
2
3

El orden visual, de arriba hacia abajo, es 3, 2 y 1.

📌 Importante

flex-direction modifica la distribución visual de los elementos, pero no cambia su orden en el código HTML. Debemos evitar utilizar los valores inversos para corregir un orden semántico incorrecto, especialmente cuando intervienen tecnologías de asistencia o navegación mediante teclado.

Distribución en varias líneas

Cuando un contenedor flexible tiene muchos elementos, puede ocurrir que no haya suficiente espacio para mostrarlos todos en una sola fila.

La propiedad flex-wrap permite decidir si los elementos deben mantenerse en una única línea o pueden distribuirse en varias.

Valores principales

Valor Comportamiento
nowrap Mantiene los elementos en una sola línea. Es el valor predeterminado.
wrap Permite que los elementos pasen a nuevas líneas cuando sea necesario.
wrap-reverse Permite varias líneas, pero invierte el sentido del eje transversal.

flex-wrap: nowrap

Es el valor predeterminado. Los elementos permanecen en una única línea.

Dependiendo de sus dimensiones y de otras propiedades flexibles, pueden reducir su tamaño o llegar a desbordar el contenedor.

CSS 
.contenedor {
  display: flex;
  flex-wrap: nowrap;
  gap: 10px;
  overflow-x: auto;
}

.contenedor .elemento {
  flex: 0 0 125px;
}
Resultado visual
1
2
3
4
5

Los elementos se mantienen en una sola línea. En esta demostración tienen una base fija de 125 píxeles y el contenedor permite desplazarse horizontalmente si no caben.

flex-wrap: wrap

Permite que los elementos pasen a la siguiente línea cuando el espacio disponible no sea suficiente.

CSS 
.contenedor {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.contenedor .elemento {
  flex: 0 0 125px;
}
Resultado visual
1
2
3
4
5

Cuando los elementos ya no caben en la primera fila, los siguientes pasan automáticamente a otra.

flex-wrap: wrap-reverse

También permite distribuir los elementos en varias líneas, pero invierte la dirección del eje transversal.

En una distribución habitual de izquierda a derecha, las nuevas líneas se colocan por encima de las anteriores.

CSS 
.contenedor {
  display: flex;
  flex-wrap: wrap-reverse;
  gap: 10px;
}

.contenedor .elemento {
  flex: 0 0 125px;
}
Resultado visual
1
2
3
4
5

Las líneas se distribuyen en sentido inverso al de wrap. La cantidad de elementos que cabe en cada línea depende del ancho disponible.

⚠️ Atención

flex-wrap: wrap no garantiza que aparezca un número concreto de elementos por fila. El resultado depende del ancho del contenedor, del tamaño de los elementos y del espacio que los separa.

Ejemplo DAW: botones de StudyFlow

Imaginemos que en StudyFlow queremos mostrar un conjunto de accesos rápidos a diferentes secciones de la aplicación.

Podemos utilizar Flexbox para distribuir estos enlaces en una fila y permitir que pasen a otra cuando el espacio disponible sea insuficiente.

HTML + CSS 
<nav class="accesos-studyflow" aria-label="Accesos rápidos">

  <a href="#asignaturas">Asignaturas</a>

  <a href="#actividades">Actividades</a>

  <a href="#calendario">Calendario</a>

  <a href="#mensajes">Mensajes</a>

  <a href="#perfil">Mi perfil</a>

</nav>

<style>

  .accesos-studyflow {
    display: flex;
    flex-wrap: wrap;
    gap: 12px;
  }

  .accesos-studyflow a {
    display: inline-block;
    padding: 12px 18px;
    border: 1px solid #85c79b;
    border-radius: 7px;
    background-color: #e4f3e9;
    color: #195c36;
    text-decoration: none;
  }

</style>
Resultado visual: accesos rápidos de StudyFlow
Asignaturas Actividades Calendario Mensajes Mi perfil

Los enlaces se organizan mediante display: flex. Con flex-wrap: wrap, pueden pasar a nuevas filas cuando el ancho disponible se reduce.

💻 Ejemplo DAW

En una aplicación como StudyFlow, Flexbox permite organizar grupos de enlaces y botones sin establecer posiciones fijas para cada elemento. Esto facilita la adaptación de la interfaz a diferentes tamaños de pantalla.

💭 Piensa

Estás diseñando una barra de navegación para StudyFlow con seis enlaces. En una pantalla grande caben todos en una fila, pero en una pantalla estrecha algunos dejan de tener espacio. ¿Qué propiedades de Flexbox utilizarías para organizar los enlaces y permitir que pasen a una segunda línea?

Ver respuesta orientativa

Aplicaría display: flex al contenedor de los enlaces para activar Flexbox.

Después utilizaría flex-wrap: wrap para permitir que los enlaces pasen a una nueva línea cuando no haya suficiente espacio disponible.

Finalmente, añadiría gap para mantener una separación uniforme entre los elementos.
