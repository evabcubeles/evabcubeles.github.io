6.3 Flotación de elementos y control del flujo

En los apartados anteriores hemos estudiado cómo se distribuyen los elementos HTML siguiendo el flujo normal del documento y cómo podemos modificar su posición mediante display y position.

Sin embargo, en determinadas situaciones necesitamos que un elemento se sitúe a un lado mientras el texto se distribuye a su alrededor. Por ejemplo, cuando una noticia incorpora una fotografía y queremos que los párrafos la rodeen.

Para conseguir este comportamiento, CSS dispone de la propiedad float. También estudiaremos clear, que permite controlar la relación entre los elementos flotantes y los que aparecen después, y overflow, que gestiona el desbordamiento del contenido.

📌 Importante

Aunque float se utilizó durante años para construir diseños completos, actualmente su uso principal es permitir que el texto rodee imágenes u otros elementos. Para organizar columnas, tarjetas y menús es preferible utilizar Flexbox o CSS Grid.

La propiedad float

La propiedad float permite desplazar un elemento hacia uno de los lados de su contenedor, de forma que el contenido que lo rodea pueda distribuirse junto a él.

Cuando aplicamos float, el elemento deja de ocupar su lugar habitual en el flujo de bloques. No obstante, sigue influyendo en la distribución de las líneas de texto que aparecen a su alrededor.

Valores principales

Valor Significado
none El elemento no flota. Es el valor predeterminado.
left El elemento flota hacia la izquierda y el contenido puede rodearlo por la derecha.
right El elemento flota hacia la derecha y el contenido puede rodearlo por la izquierda.

Primer ejemplo: una imagen flotante

Imaginemos una noticia en la que queremos colocar una imagen a la izquierda del texto.

HTML + CSS 
<article class="noticia">

  <img
    src="aula.jpg"
    alt="Alumnado trabajando en el aula"
  >

  <p>
    El alumnado de Desarrollo de Aplicaciones Web
    está preparando nuevos proyectos.
  </p>

  <p>
    Durante las próximas semanas se desarrollarán
    distintas actividades prácticas.
  </p>

</article>

<style>

  .noticia img {
    float: left;
    width: 150px;
    margin-right: 20px;
    margin-bottom: 10px;
  }

</style>
Resultado visual
Imagen

El alumnado de Desarrollo de Aplicaciones Web está preparando nuevos proyectos. El texto comienza a la derecha de la imagen porque esta utiliza la propiedad float: left.

Durante las próximas semanas se desarrollarán distintas actividades prácticas. Cuando el texto alcanza la parte inferior de la imagen, puede volver a ocupar todo el ancho disponible.

La imagen flota a la izquierda y el texto se distribuye a su alrededor.

¿Para qué sirve el margen?

Cuando una imagen flota junto al texto, es recomendable añadir márgenes para evitar que ambos contenidos queden demasiado juntos.

CSS 
.noticia img {
  float: left;
  width: 150px;
  margin: 0 20px 12px 0;
}

En este caso, el margen derecho de 20 píxeles separa la imagen del texto y el margen inferior de 12 píxeles añade espacio debajo de ella.

Flotación a izquierda y derecha

Los valores left y right permiten elegir hacia qué lado del contenedor se desplaza el elemento flotante.

Flotación a la izquierda

CSS 
.imagen {
  float: left;
  width: 120px;
  margin: 0 18px 12px 0;
}
Resultado visual
Izquierda

La imagen aparece en el lado izquierdo del contenedor. El texto se distribuye por el espacio que queda disponible a su derecha.

Si el texto continúa y supera la altura de la imagen, podrá utilizar también el espacio situado debajo de ella.

Flotación a la derecha

CSS 
.imagen {
  float: right;
  width: 120px;
  margin: 0 0 12px 18px;
}
Resultado visual
Derecha

Ahora la imagen aparece en el lado derecho del contenedor. El texto se distribuye a su izquierda.

Observa que el margen se aplica en el lado izquierdo de la imagen para separar correctamente ambos contenidos.

⚠️ Atención

float no equivale a text-align. La primera propiedad modifica la flotación del elemento; la segunda controla la alineación del contenido en línea dentro de un bloque.

Flotación y espacio disponible

Si el contenedor no tiene suficiente anchura para colocar varios elementos flotantes uno junto a otro, estos pueden pasar a una posición inferior.

Por este motivo, utilizar float para crear diseños de columnas puede provocar resultados difíciles de controlar.

📌 Idea clave

La finalidad principal de float es permitir que el contenido rodee un elemento, no crear una estructura completa de filas y columnas.

La propiedad clear

Cuando utilizamos elementos flotantes, el contenido posterior puede situarse junto a ellos si queda espacio disponible.

En algunas situaciones necesitamos impedir ese comportamiento. Para ello utilizamos la propiedad clear.

clear indica que un elemento no debe situarse junto a determinados elementos flotantes anteriores.

Valores principales

Valor Comportamiento
none No aplica ninguna separación especial respecto a los flotantes.
left Impide que el elemento quede junto a flotantes situados a la izquierda.
right Impide que el elemento quede junto a flotantes situados a la derecha.
both Impide que el elemento quede junto a flotantes de cualquiera de los dos lados.

Ejemplo con clear: both

Supongamos que tenemos una imagen flotante y queremos que la siguiente sección comience completamente debajo de ella.

HTML + CSS 
<div class="contenedor">

  <div class="imagen">Imagen</div>

  <p>
    Texto que puede rodear la imagen.
  </p>

  <div class="nueva-seccion">
    Nueva sección
  </div>

</div>

<style>

  .imagen {
    float: left;
    width: 120px;
    height: 90px;
    margin-right: 18px;
  }

  .nueva-seccion {
    clear: both;
  }

</style>
Resultado visual
Imagen

Este texto puede aparecer a la derecha de la imagen flotante.

Nueva sección con clear: both

La nueva sección comienza debajo del elemento flotante.

¿Qué ocurre con la altura del contenedor?

Un problema clásico aparece cuando un contenedor contiene únicamente elementos flotantes.

En esa situación, los flotantes no contribuyen de la manera habitual al cálculo de la altura automática del contenedor. Como consecuencia, el borde o el fondo del contenedor puede no rodearlos completamente.

Una solución moderna consiste en utilizar display: flow-root, que crea un nuevo contexto de formato de bloque.

CSS 
.galeria {
  display: flow-root;
  border: 2px solid #999;
  padding: 14px;
}

.galeria img {
  float: left;
  width: 120px;
  margin-right: 16px;
}
Resultado visual
Flotante

El borde del contenedor rodea correctamente la imagen flotante.

Esta demostración utiliza display: flow-root para contener la flotación.

La técnica clearfix

Antes de utilizarse habitualmente flow-root, era frecuente resolver este problema mediante un pseudoelemento con clear: both.

CSS 
.contenedor::after {
  content: "";
  display: block;
  clear: both;
}

Esta técnica se conoce como clearfix. Es útil conocerla porque todavía aparece en hojas de estilo de proyectos antiguos.

📌 Importante

clear controla la posición de un elemento respecto a los flotantes. display: flow-root crea un contexto de formato que, entre otros efectos, permite contener los flotantes interiores. Son soluciones relacionadas, pero no equivalentes.

Overflow y desbordamiento

El desbordamiento ocurre cuando el contenido de un elemento supera el espacio disponible dentro de su contenedor.

CSS permite controlar esta situación mediante la propiedad overflow.

Esta propiedad no es exclusiva de los elementos flotantes. También se utiliza en tablas anchas, fragmentos de código y paneles con desplazamiento.

Valores principales de overflow

Valor Comportamiento
visible El contenido puede sobresalir de los límites del contenedor.
hidden Recorta el contenido que excede los límites y no muestra barras de desplazamiento.
scroll Permite el desplazamiento y puede mostrar barras incluso cuando no son necesarias.
auto Permite el desplazamiento cuando el contenido lo necesita.

Ejemplo: tabla con desplazamiento horizontal

En una aplicación web puede haber tablas con muchas columnas. En lugar de permitir que desborden toda la página, podemos crear un contenedor con desplazamiento horizontal.

HTML + CSS 
<div class="tabla-contenedor">

  <table>
    <tr>
      <th>Asignatura</th>
      <th>Profesorado</th>
      <th>Horario</th>
      <th>Evaluación</th>
    </tr>
  </table>

</div>

<style>

  .tabla-contenedor {
    max-width: 100%;
    overflow-x: auto;
  }

  .tabla-contenedor table {
    min-width: 650px;
  }

</style>

Si el contenido supera la anchura disponible, se puede desplazar horizontalmente sin desbordar toda la página.

Overflow y flotación: relación y diferencias

Históricamente se utilizaba overflow: hidden para conseguir que un contenedor englobase sus elementos flotantes.

Aunque puede funcionar, tiene un inconveniente importante: recorta el contenido que sobresale, como sombras, etiquetas o elementos posicionados fuera de sus límites.

Para contener flotantes sin provocar ese recorte, actualmente suele ser más adecuado utilizar display: flow-root.

⚠️ Atención

No utilices overflow: hidden indiscriminadamente para solucionar problemas de maquetación. Puede ocultar contenido que debería permanecer visible.

Usos actuales de float

Durante los primeros años del diseño web con CSS, era frecuente utilizar float para construir cabeceras, columnas y menús completos.

Sin embargo, estas soluciones requerían correcciones adicionales con clear y podían resultar difíciles de mantener.

Actualmente disponemos de herramientas específicas para distribuir elementos: Flexbox y CSS Grid.

¿Qué técnica debemos utilizar?

Necesidad Técnica recomendada
Que el texto rodee una fotografía. float
Separar una sección de elementos flotantes anteriores. clear
Contener elementos flotantes dentro de un bloque. display: flow-root
Gestionar contenido demasiado ancho o alto. overflow
Distribuir botones o tarjetas en una fila. Flexbox
Crear la estructura principal de una página web. CSS Grid

Ejemplo DAW: noticias de StudyFlow

En nuestro proyecto StudyFlow podemos utilizar una imagen flotante dentro de una noticia, permitiendo que el texto se distribuya a su alrededor.

En cambio, para organizar las tarjetas de asignaturas, los botones y la estructura general de la aplicación, utilizaremos Flexbox o CSS Grid.

<article class="noticia-studyflow">

  >

  <h3>Nuevos recursos para el curso</h3>

    Ya están disponibles los materiales
    de apoyo para las asignaturas.
  </p>

  <p>
    Consulta las actividades y las fechas
    de entrega en StudyFlow.
  </p>

</article>

<style>

  .noticia-studyflow {
    display: flow-root;
  }

  .noticia-studyflow img {

💻 Ejemplo DAW

En una interfaz profesional, cada técnica debe utilizarse para el problema que resuelve mejor. float es adecuado para integrar imágenes dentro del texto; Flexbox y Grid permiten crear distribuciones más complejas, controlables y fáciles de mantener.

💭 Piensa

Estás diseñando StudyFlow y necesitas colocar cuatro tarjetas de asignaturas una junto a otra. Un compañero propone utilizar float: left en todas ellas. ¿Es la técnica más adecuada? ¿En qué situación sí utilizarías float?

Ver una posible solución

Para distribuir tarjetas es preferible utilizar Flexbox o CSS Grid, porque permiten controlar la alineación, el espaciado y la distribución de los elementos.

Utilizaría float cuando necesitase que el texto de una noticia rodease una imagen, por ejemplo.

Resumen del apartado

En este apartado hemos aprendido que float permite colocar un elemento a un lado para que el contenido pueda rodearlo.

También hemos estudiado clear, que controla la posición de los elementos posteriores respecto a los flotantes, y overflow, que gestiona el contenido que supera los límites de un contenedor.

Por último, hemos conocido display: flow-root como solución moderna para contener elementos flotantes y hemos comprobado por qué Flexbox y Grid son más adecuados para la maquetación general.

En el siguiente apartado comenzaremos a estudiar Flexbox, una herramienta creada específicamente para distribuir y alinear elementos dentro de una interfaz web.
