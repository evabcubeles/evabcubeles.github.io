6.2 Posicionamiento de elementos en CSS

En el apartado anterior hemos aprendido que los elementos HTML se distribuyen siguiendo el flujo normal del documento. También hemos visto cómo la propiedad display permite modificar su comportamiento visual.

Sin embargo, algunas interfaces necesitan situar determinados elementos en posiciones concretas: una insignia sobre una tarjeta, un botón que permanezca visible durante el desplazamiento o una cabecera que se mantenga en la parte superior de la página.

Para resolver estas situaciones, CSS dispone de la propiedad position, que permite controlar cómo se posiciona un elemento y respecto a qué referencia se calculan sus desplazamientos.

📌 Importante

El posicionamiento CSS no sustituye a las técnicas de maquetación como Flexbox o Grid. Su finalidad principal es controlar la posición de elementos concretos cuando el flujo normal no permite conseguir directamente el resultado deseado.

La propiedad position

La propiedad position determina el método de posicionamiento que utiliza un elemento dentro de la página web.

Dependiendo del valor seleccionado, el elemento puede permanecer en su posición habitual, desplazarse respecto a ella, colocarse respecto a un contenedor o permanecer visible mientras el usuario se desplaza por la página.

CSS 
.elemento {
  position: relative;
}

En este ejemplo, el elemento utiliza position: relative. Todavía no hemos indicado ningún desplazamiento, por lo que se mostrará en su posición habitual.

Valores principales

Valor Comportamiento Uso habitual
static Posicionamiento normal del elemento. Distribución habitual del contenido.
relative Permite desplazar el elemento respecto a su posición original. Pequeños ajustes y referencias para elementos absolutos.
absolute Extrae el elemento del flujo normal y permite posicionarlo respecto a su bloque de referencia. Insignias, iconos y elementos superpuestos.
fixed Fija normalmente el elemento respecto a la ventana del navegador. Botones flotantes y controles persistentes.
sticky Combina el comportamiento normal con la fijación durante el desplazamiento. Cabeceras y menús que permanecen visibles.

Propiedades de desplazamiento

Para indicar desplazamientos podemos utilizar top, right, bottom y left. Su efecto depende del valor de position.

CSS 
.elemento {
  position: relative;
  top: 20px;
  left: 15px;
}

En este caso, el elemento se desplaza 20 píxeles hacia abajo y 15 píxeles hacia la derecha respecto a su posición original.

⚠️ Atención

Las propiedades top, right, bottom y left no producen desplazamientos con position: static. Además, no todos los valores de position mantienen reservado el espacio original del elemento.

Posicionamiento static

El valor static es el posicionamiento predeterminado de los elementos HTML.

Cuando un elemento utiliza este valor, se coloca siguiendo las reglas normales de distribución del documento. No se desplaza mediante las propiedades top, right, bottom o left.

HTML + CSS 
<div class="caja">Elemento A</div>
<div class="caja">Elemento B</div>
<div class="caja">Elemento C</div>

<style>
  .caja {
    position: static;
    padding: 12px;
    margin-bottom: 8px;
  }
</style>
Resultado visual
Elemento A
Elemento B
Elemento C

Estos elementos se muestran en una fila porque el contenedor de la demostración utiliza Flexbox. Cada elemento mantiene position: static: su posición depende del sistema de distribución establecido por su contenedor.

📌 Idea clave

position: static no significa que el elemento tenga una posición fija en la pantalla. Significa que participa en la distribución normal de su contenedor.

Posicionamiento relative

El valor relative permite desplazar un elemento respecto a la posición que ocuparía normalmente.

La característica más importante es que el elemento conserva su espacio original dentro del flujo del documento, aunque visualmente aparezca desplazado.

HTML + CSS 
<div class="elemento">Elemento normal</div>

<div class="elemento destacado">
  Elemento desplazado
</div>

<div class="elemento">Siguiente elemento</div>

<style>
  .destacado {
    position: relative;
    top: 12px;
    left: 12px;
  }
</style>
Resultado visual aproximado
Elemento normal
Elemento desplazado
Siguiente elemento

El segundo elemento se desplaza visualmente, pero sigue conservando el espacio que tenía asignado en la distribución original.

¿Para qué se utiliza?

El posicionamiento relativo resulta útil para realizar pequeños desplazamientos, ajustar detalles visuales y, especialmente, establecer un bloque de referencia para elementos con posicionamiento absoluto.

⚠️ Atención

Si desplazamos mucho un elemento con position: relative, puede superponerse a otros elementos. El navegador sigue reservando su espacio original, por lo que los demás elementos no se reorganizan para ocupar su nueva posición.

Posicionamiento absolute

El valor absolute permite colocar un elemento en una posición concreta respecto a su bloque de referencia.

A diferencia de relative, un elemento con posicionamiento absoluto sale del flujo normal. Por tanto, los demás elementos se distribuyen como si no ocupara espacio en él.

El contenedor de referencia

Una técnica habitual consiste en asignar position: relative al contenedor y position: absolute al elemento que queremos situar dentro de él.

HTML + CSS 
<div class="contenedor">
  <p>Contenido principal</p>

  <span class="etiqueta">
    Nuevo
  </span>
</div>

<style>
  .contenedor {
    position: relative;
    min-height: 180px;
    padding: 20px;
    border: 1px solid #ccc;
  }

  .etiqueta {
    position: absolute;
    top: 15px;
    right: 15px;
  }
</style>
Resultado visual
Este es el contenido principal del contenedor.
Nuevo

La etiqueta aparece situada cerca de la esquina inferior derecha de esta demostración porque sus reglas visuales utilizan right y bottom. En el ejemplo de código anterior se utiliza top y right, lo que la situaría en la esquina superior derecha.

Ejemplo DAW: insignia en una tarjeta de StudyFlow

Imaginemos que StudyFlow muestra tarjetas con las asignaturas de un curso. Queremos destacar aquellas que contienen nuevas actividades mediante una pequeña insignia situada en la esquina superior.

HTML + CSS 
<article class="tarjeta-asignatura">

  <span class="insignia">Nuevo</span>

  <h3>Desarrollo web</h3>

  <p>
    Consulta las actividades disponibles.
  </p>

</article>

<style>
  .tarjeta-asignatura {
    position: relative;
    padding: 24px;
    border: 1px solid #ddd;
    border-radius: 10px;
  }

  .insignia {
    position: absolute;
    top: -12px;
    right: 12px;
    padding: 6px 12px;
    border-radius: 20px;
    background-color: #e4f3e9;
  }
</style>
Resultado visual aproximado
Nuevo

Desarrollo web

Consulta las actividades disponibles.

La insignia se posiciona respecto a la tarjeta, porque esta tiene position: relative.

📌 Importante

Un elemento absoluto busca su bloque de referencia según las reglas de posicionamiento CSS. En los ejemplos habituales, se utiliza el ancestro más cercano con position distinto de static. También existen otros mecanismos CSS capaces de establecer ese bloque de referencia.

Posicionamiento fixed

El valor fixed permite situar un elemento en una posición que normalmente permanece fija respecto a la ventana del navegador.

Cuando el usuario se desplaza verticalmente por la página, el elemento puede continuar visible en la misma posición.

Al igual que ocurre con position: absolute, los elementos fijos se extraen del flujo normal del documento.

Ejemplo: botón para volver arriba

HTML + CSS 
<a href="#inicio" class="volver-arriba">
  ↑ Volver arriba
</a>

<style>
  .volver-arriba {
    position: fixed;
    right: 24px;
    bottom: 24px;

    padding: 12px 18px;
    background-color: #177a43;
    color: white;
    border-radius: 8px;
    text-decoration: none;
  }
</style>

El enlace se mantiene normalmente a 24 píxeles del borde derecho y 24 píxeles del borde inferior de la ventana del navegador.

💻 Ejemplo DAW

En StudyFlow podríamos utilizar position: fixed para mostrar un botón de ayuda que permanezca disponible mientras el alumnado consulta una página extensa. Deberíamos comprobar que no tape contenido, controles o mensajes importantes.

⚠️ Atención

No conviene utilizar posicionamiento fijo para colocar todos los elementos de una página. En pantallas pequeñas podría provocar superposiciones y dificultades de navegación. Además, algunas propiedades CSS aplicadas a sus ancestros pueden modificar el bloque de referencia de un elemento fijo.

Posicionamiento sticky

El valor sticky combina características del posicionamiento relativo y del posicionamiento fijo.

Inicialmente, el elemento participa en el flujo normal. Sin embargo, cuando el desplazamiento alcanza un límite determinado, puede permanecer adherido a ese límite dentro de su contenedor de referencia.

Ejemplo: cabecera que permanece visible

HTML + CSS 
<div class="panel">

  <h3 class="cabecera">
    Mis actividades
  </h3>

  <div class="contenido">
    ...
  </div>

</div>

<style>
  .panel {
    height: 220px;
    overflow-y: auto;
  }

  .cabecera {
    position: sticky;
    top: 0;
    background-color: #e4f3e9;
  }
</style>

Diferencia entre fixed y sticky

Característica fixed sticky
Flujo normal Sale del flujo. Conserva su espacio en el flujo.
Desplazamiento Permanece normalmente fijo respecto a la ventana. Se adhiere al alcanzar un límite de desplazamiento.
Ámbito Habitualmente la ventana del navegador. Limitado por su contenedor y el área de desplazamiento correspondiente.
Uso habitual Botones y controles persistentes. Cabeceras y menús de navegación.
⚠️ Atención

Para que sticky produzca el efecto esperado, normalmente debemos indicar un límite como top: 0. También influyen la altura disponible, los contenedores y las propiedades de desbordamiento como overflow.

Superposición y z-index

Cuando varios elementos ocupan parcialmente la misma zona de la pantalla, necesitamos controlar cuál aparece visualmente delante de los demás.

Para ello podemos utilizar la propiedad z-index, que interviene en el orden de apilamiento de los elementos.

Ejemplo de superposición

HTML + CSS 
<div class="contenedor">
  <div class="capa-uno">Capa 1</div>
  <div class="capa-dos">Capa 2</div>
</div>

<style>
  .contenedor {
    position: relative;
    height: 200px;
  }

  .capa-uno {
    position: absolute;
    top: 20px;
    left: 20px;
    z-index: 1;
  }

  .capa-dos {
    position: absolute;
    top: 70px;
    left: 90px;
    z-index: 2;
  }
</style>
Resultado visual
Capa 1
Capa 2

La capa 2 aparece por delante de la capa 1 porque ambas participan en el mismo contexto de apilamiento y la segunda tiene un valor de z-index mayor.

¿Cómo funciona z-index?

En términos generales, dentro de un mismo contexto de apilamiento, un elemento con un valor de z-index mayor puede mostrarse por delante de otro con un valor menor.

Sin embargo, los elementos no siempre pertenecen al mismo contexto de apilamiento. Un contexto de apilamiento establece un grupo cuyo orden visual se organiza como una unidad respecto a otros grupos.

📌 Importante

z-index: 9999 no garantiza que un elemento aparezca por delante de toda la página. Su resultado depende del contexto de apilamiento en el que se encuentre. La propiedad se utiliza habitualmente con elementos posicionados y también puede aplicarse a determinados elementos Flexbox y Grid.

Ejemplo DAW: menú superpuesto

En StudyFlow podríamos utilizar z-index para controlar la superposición de un menú desplegable respecto a las tarjetas de actividades.

CSS 
.menu-desplegable {
  position: absolute;
  top: 100%;
  left: 0;
  z-index: 10;
}

.tarjeta-actividad {
  position: relative;
  z-index: 1;
}

Este planteamiento puede resultar adecuado cuando el menú y las tarjetas participan en contextos de apilamiento compatibles. Si el menú sigue quedando oculto, tendremos que revisar los contextos creados por sus elementos antecesores.

Resumen comparativo del posicionamiento

Valor ¿Conserva espacio en el flujo? Referencia principal
static Sí Distribución normal.
relative Sí Su posición original.
absolute No Su bloque de referencia.
fixed No Normalmente la ventana del navegador.
sticky Sí El área de desplazamiento y los límites del contenedor.

💭 Piensa

Estamos desarrollando StudyFlow y necesitamos incorporar tres elementos: una insignia «Nuevo» en la esquina de una tarjeta, una cabecera que permanezca visible al desplazarnos por una lista y un botón de ayuda que se mantenga en la esquina inferior de la ventana. ¿Qué valor de position utilizarías en cada caso y por qué?

Ver una posible solución

Insignia: utilizaríamos position: absolute dentro de una tarjeta con position: relative. Así podríamos situarla respecto a la tarjeta.

Cabecera de la lista: utilizaríamos position: sticky junto con top: 0, siempre que el contenedor permita el comportamiento de desplazamiento esperado.

Botón de ayuda: utilizaríamos position: fixed con valores de right y bottom para mantenerlo normalmente en la esquina inferior de la ventana.
