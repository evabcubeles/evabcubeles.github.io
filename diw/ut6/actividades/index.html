📝 Actividades de la UT6

En esta unidad hemos aprendido a distribuir y posicionar elementos HTML utilizando las principales técnicas de maquetación CSS: flujo normal, posicionamiento, flotación, Flexbox y CSS Grid.

Ahora aplicaremos estos conocimientos a una situación práctica relacionada con el desarrollo de interfaces web.

Las actividades incluyen un reto final y una autoevaluación interactiva para comprobar los conocimientos adquiridos.

📌 Objetivo de las actividades

Seleccionar y combinar las técnicas de maquetación CSS más adecuadas para construir una interfaz web ordenada, mantenible y visualmente coherente.

🧩 Reto final — Maqueta StudyFlow con CSS Grid y Flexbox

En la UT5 trabajamos los fundamentos del diseño visual mediante CSS. En esta unidad vamos a dar un paso más: organizar los componentes de una interfaz dentro de una estructura completa de página web.

El encargo

El equipo de desarrollo de StudyFlow, una plataforma web para organizar tareas y materiales de estudio, necesita transformar su propuesta visual en una interfaz correctamente maquetada.

La página debe permitir identificar claramente la cabecera, la navegación, las distintas áreas de contenido, el panel lateral y el pie de página.

Tu responsabilidad será desarrollar la distribución utilizando CSS Grid y Flexbox, justificando cuándo utilizas cada técnica.

Tu misión

Diseña y desarrolla una página principal de StudyFlow que incluya, como mínimo, los siguientes elementos:

  1. Una cabecera con el nombre o logotipo de StudyFlow y una zona de acceso al usuario.
  2. Una barra de navegación con enlaces a Inicio, Mis tareas, Calendario y Recursos.
  3. Un panel lateral con categorías o accesos rápidos.
  4. Una zona principal con un título, una breve descripción y tarjetas de tareas.
  5. Un panel informativo con próximos eventos, recordatorios o estadísticas.
  6. Un pie de página con información básica del proyecto.
⚠️ Importante

No se trata únicamente de conseguir que los elementos se vean correctamente. Debes demostrar que comprendes qué técnica de maquetación resulta más adecuada en cada parte de la interfaz.

📋 Requisitos técnicos del proyecto

Para completar el reto, tu solución deberá cumplir los siguientes requisitos:

  1. Estructura HTML semántica. Utiliza adecuadamente elementos como header, nav, main, aside, section y footer.
  2. Flujo normal y display. Utiliza correctamente los tipos de visualización y evita alterar innecesariamente el flujo normal.
  3. Maquetación principal con CSS Grid. Organiza las grandes áreas de la página mediante filas, columnas o áreas nombradas.
  4. Componentes con Flexbox. Utiliza Flexbox para distribuir los elementos de la navegación y al menos otro componente.
  5. Alineación y espaciado. Aplica correctamente propiedades como justify-content, align-items y gap.
  6. Distribución flexible. Utiliza unidades como fr y, cuando corresponda, funciones como repeat() o minmax().
  7. Posicionamiento. Incluye al menos un elemento que requiera position: relative y otro con position: absolute, justificando su utilización.
  8. Superposición. Controla correctamente la superposición cuando sea necesaria, teniendo en cuenta z-index y los contextos de apilamiento.
  9. Combinación de técnicas. Demuestra que sabes utilizar Grid para la estructura general y Flexbox para la distribución interna de componentes.
  10. Calidad del código. Organiza las reglas CSS, utiliza nombres descriptivos y evita estilos innecesarios o duplicados.

💡 Orientación para la maquetación

Una posible solución consiste en utilizar CSS Grid para distribuir las áreas principales de la página: 

.layout {
  display: grid;

  grid-template-columns: 220px minmax(0, 1fr) 240px;

  grid-template-areas:
    "header header header"
    "nav nav nav"
    "sidebar main info"
    "footer footer footer";

  gap: 20px;
}

.cabecera {
  grid-area: header;
}

.navegacion {
  grid-area: nav;
}

.lateral {
  grid-area: sidebar;
}

.principal {
  grid-area: main;
}

.informacion {
  grid-area: info;
}

.pie {
  grid-area: footer;
}

Posteriormente, podrías utilizar Flexbox dentro de la navegación: 

.navegacion {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 20px;
}
💻 Ejemplo DAW

En una aplicación real es habitual utilizar Grid para organizar las grandes regiones de la interfaz y Flexbox para alinear botones, enlaces, tarjetas o elementos internos. No son técnicas excluyentes: se complementan.

🔍 Comprobaciones antes de entregar

  • Las áreas de la página están correctamente distribuidas.
  • Los elementos no se superponen accidentalmente.
  • La navegación y las tarjetas mantienen una alineación coherente.
  • Los espacios entre elementos son consistentes.
  • El código HTML y CSS está ordenado.
  • Se han utilizado las técnicas de maquetación solicitadas.

📁 Documentación de la entrega

Además del código, adjunta un breve documento en PDF en el que expliques:

  • Qué partes de la interfaz has maquetado con CSS Grid.
  • Qué componentes has distribuido con Flexbox.
  • Qué propiedades de posicionamiento has utilizado y por qué.
  • Qué dificultades has encontrado y cómo las has solucionado.
  • Incluye una captura de pantalla del resultado final.
📌 Criterio de trabajo

Se valorará tanto el resultado visual como la corrección técnica de la maquetación y la capacidad para justificar las decisiones adoptadas.
