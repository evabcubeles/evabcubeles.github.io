UT6 - CSS: maquetación y diseño avanzado

En la unidad anterior aprendimos a utilizar CSS para definir la apariencia visual de las interfaces web mediante colores, tipografía, fondos, bordes, sombras y las propiedades del modelo de caja. Ahora avanzaremos un paso más y estudiaremos cómo distribuir y organizar los elementos dentro de una página web.

Comenzaremos analizando el flujo normal del documento y la propiedad display, para comprender cómo se colocan inicialmente los elementos HTML. Después estudiaremos las distintas técnicas de posicionamiento y flotación, así como sus posibilidades y limitaciones en la maquetación actual.

A continuación, aprenderemos a utilizar Flexbox y CSS Grid, dos sistemas fundamentales para construir distribuciones modernas. Con Flexbox organizaremos elementos en una dimensión, mientras que Grid nos permitirá crear estructuras de filas y columnas y controlar la distribución de los componentes de una interfaz.

Finalmente, combinaremos estas técnicas para desarrollar maquetaciones más completas y aplicar lo aprendido al proyecto StudyFlow, continuando la evolución de la interfaz HTML y CSS que hemos construido en las unidades anteriores.
