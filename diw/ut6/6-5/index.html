6.5 Distribución y alineación con Flexbox

En el apartado anterior hemos aprendido a crear contenedores flexibles mediante display: flex, a identificar el eje principal y el eje transversal y a controlar la dirección y el salto de línea de los elementos.

Sin embargo, organizar los elementos en una fila o una columna es solamente el primer paso. En una interfaz web también necesitamos decidir dónde se colocan, cómo se alinean, cuánto espacio ocupan y qué separación existe entre ellos.

Flexbox proporciona propiedades específicas para resolver estas necesidades. Algunas se aplican al contenedor y afectan a todos sus elementos; otras se aplican directamente a cada elemento flexible.

📌 Importante

En Flexbox debemos distinguir entre distribuir el espacio disponible, alinear los elementos y modificar su tamaño flexible. Aunque estos conceptos están relacionados, no significan lo mismo y utilizan propiedades diferentes.

Distribución sobre el eje principal: justify-content

La propiedad justify-content controla cómo se distribuyen los elementos flexibles a lo largo del eje principal del contenedor.

Cuando los elementos no ocupan todo el espacio disponible, podemos situarlos al principio, al final, en el centro o repartir el espacio libre entre ellos.

Esta propiedad se aplica al contenedor flexible, no a cada elemento individual.

Valores principales

Valor Comportamiento
flex-start Agrupa los elementos al inicio del eje principal.
flex-end Agrupa los elementos al final del eje principal.
center Centra el conjunto de elementos sobre el eje principal.
space-between Sitúa el primer elemento al inicio y el último al final, repartiendo el espacio libre entre ellos.
space-around Distribuye espacio alrededor de cada elemento. Entre dos elementos contiguos queda el doble de espacio que junto a los extremos.
space-evenly Establece separaciones iguales entre los elementos y los bordes del contenedor.

Ejemplo básico

HTML + CSS 
<div class="contenedor">
  <div class="elemento">1</div>
  <div class="elemento">2</div>
  <div class="elemento">3</div>
</div>

<style>
  .contenedor {
    display: flex;
    justify-content: center;
    gap: 10px;
  }

  .elemento {
    padding: 14px 18px;
    background-color: #e4f3e9;
    border: 1px solid #85c79b;
  }
</style>

¿Qué sucede si cambiamos flex-direction?

Es importante recordar que justify-content trabaja siempre sobre el eje principal. Por tanto, su efecto depende de flex-direction.

Con flex-direction: row, en una página escrita de izquierda a derecha, distribuye los elementos horizontalmente. Con flex-direction: column, los distribuye verticalmente.

CSS 
.contenedor {
  display: flex;
  flex-direction: column;
  justify-content: center;
  height: 300px;
}
⚠️ Atención

Si utilizamos flex-direction: column y queremos apreciar una distribución vertical, el contenedor debe disponer de espacio libre en esa dirección. Si su altura se ajusta exactamente al contenido, no habrá espacio adicional que repartir.

Alineación sobre el eje transversal: align-items

La propiedad align-items controla la alineación de los elementos flexibles sobre el eje transversal.

Cuando utilizamos flex-direction: row, el eje transversal es vertical. En este caso, align-items permite situar los elementos arriba, abajo o en el centro, entre otras posibilidades.

Valores principales

Valor Comportamiento
stretch Estira los elementos en el eje transversal cuando su tamaño en ese eje es automático y las restricciones lo permiten.
flex-start Alinea los elementos al inicio del eje transversal.
flex-end Alinea los elementos al final del eje transversal.
center Centra los elementos sobre el eje transversal.
baseline Alinea los elementos según la línea base de su contenido textual.

Ejemplo de alineación vertical

HTML + CSS 
<div class="contenedor">
  <div class="elemento">1</div>
  <div class="elemento">2</div>
  <div class="elemento">3</div>
</div>

<style>
  .contenedor {
    display: flex;
    align-items: center;
    gap: 10px;
    min-height: 180px;
  }

  .elemento {
    padding: 14px 18px;
    background-color: #e4f3e9;
  }
</style>

Centrado horizontal y vertical

Una de las aplicaciones más habituales de Flexbox es centrar un elemento en ambas direcciones dentro de un contenedor.

Para conseguirlo, podemos combinar justify-content: center con align-items: center.

CSS 
.contenedor {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 250px;
}
Resultado visual: centrado completo
Elemento centrado

El elemento se sitúa en el centro horizontal y vertical del espacio disponible.

📌 Importante

justify-content y align-items no significan «horizontal» y «vertical». La primera actúa sobre el eje principal y la segunda sobre el transversal. Si cambiamos flex-direction, cambia también la orientación de esos ejes.

Alineación de líneas y elementos individuales

Hasta ahora hemos utilizado propiedades que distribuyen o alinean el conjunto de elementos flexibles. Sin embargo, existen situaciones en las que necesitamos alinear varias líneas o modificar la alineación de un único elemento.

Para estos casos disponemos de align-content y align-self.

La propiedad align-content

align-content distribuye las líneas de elementos flexibles sobre el eje transversal cuando existe espacio libre.

Resulta especialmente útil cuando utilizamos flex-wrap: wrap y los elementos ocupan dos o más líneas.

No debemos confundir esta propiedad con align-items: mientras que align-items alinea los elementos dentro de cada línea, align-content distribuye las líneas dentro del contenedor.

CSS 
.contenedor {
  display: flex;
  flex-wrap: wrap;
  align-content: center;
  gap: 10px;
  width: 390px;
  height: 280px;
}

.elemento {
  flex: 0 0 105px;
}

⚠️ Atención

La propiedad align-self

La propiedad align-self permite modificar la alineación transversal de un elemento flexible concreto, independientemente de la alineación general establecida mediante align-items.

A diferencia de las propiedades anteriores, align-self se aplica directamente al elemento que queremos modificar.

HTML + CSS 
<div class="contenedor">
  <div class="elemento">1</div>
  <div class="elemento destacado">2</div>
  <div class="elemento">3</div>
</div>

<style>
  .contenedor {
    display: flex;
    align-items: flex-start;
    min-height: 180px;
    gap: 10px;
  }

  .destacado {
    align-self: center;
  }
</style>
Resultado visual: alineación individual

Espaciado entre elementos: gap

La propiedad gap establece la separación entre los elementos de un contenedor flexible.

Su principal ventaja es que permite definir un espaciado uniforme sin añadir márgenes individuales a cada elemento.

A diferencia de los márgenes, el espacio definido mediante gap aparece entre los elementos, pero no añade por sí mismo separación entre los elementos exteriores y los bordes del contenedor.

Separación uniforme

CSS 
.contenedor {
  display: flex;
  gap: 20px;
}

row-gap y column-gap

Cuando los elementos se distribuyen en varias líneas, podemos controlar por separado el espacio entre filas y entre columnas.

Para ello utilizamos row-gap y column-gap.

CSS 
.contenedor {
  display: flex;
  flex-wrap: wrap;

  row-gap: 12px;
  column-gap: 20px;
}

/* Forma abreviada equivalente */

.contenedor {
  display: flex;
  flex-wrap: wrap;
  gap: 12px 20px;
}

📌 Importante

gap establece una separación mínima entre los elementos. Si también utilizamos justify-content: space-between, el espacio libre adicional puede aumentar la distancia visible entre ellos.

Tamaño flexible de los elementos

Una de las características más importantes de Flexbox es su capacidad para adaptar el tamaño de los elementos al espacio disponible.

Hasta ahora hemos controlado principalmente la posición y la alineación. A continuación, estudiaremos tres propiedades que permiten controlar el crecimiento, la reducción y el tamaño base de los elementos flexibles.

Estas propiedades se aplican a los elementos flexibles, no al contenedor.

flex-grow: crecimiento

La propiedad flex-grow determina cómo participa un elemento en el reparto del espacio libre positivo del eje principal.

Su valor predeterminado es 0, lo que significa que el elemento no crece para ocupar el espacio libre solamente por efecto de esta propiedad.

Si varios elementos tienen valores positivos, el espacio libre se reparte proporcionalmente según sus factores de crecimiento.

HTML + CSS 
<div class="contenedor">
  <div class="elemento uno">1</div>
  <div class="elemento dos">2</div>
  <div class="elemento tres">3</div>
</div>

<style>
  .contenedor {
    display: flex;
    gap: 10px;
  }

  .elemento {
    flex-basis: 80px;
    min-width: 0;
  }

  .uno {
    flex-grow: 1;
  }

  .dos {
    flex-grow: 2;
  }

  .tres {
    flex-grow: 1;
  }
</style>
Resultado visual: crecimiento proporcional
grow: 1
grow: 2
grow: 1

Los tres elementos parten de una base de 80 píxeles. El segundo recibe el doble de espacio libre adicional que cada uno de los otros dos.

⚠️ Atención

flex-grow: 2 no significa necesariamente que un elemento termine midiendo el doble que otro con flex-grow: 1. Lo que se reparte proporcionalmente es el espacio libre disponible, teniendo en cuenta los tamaños base y las restricciones de los elementos.

flex-shrink: reducción

La propiedad flex-shrink determina cómo puede reducirse un elemento cuando los tamaños de los elementos superan el espacio disponible sobre el eje principal.

Su valor predeterminado es 1, por lo que los elementos flexibles normalmente pueden encogerse si es necesario.

Un valor 0 impide la reducción del tamaño base por el algoritmo de contracción flexible.

CSS 
.contenedor {
  display: flex;
  gap: 10px;
  width: 380px;
}

.elemento {
  flex-basis: 160px;
  flex-grow: 0;
  min-width: 0;
}

.primero {
  flex-shrink: 0;
}

.segundo {
  flex-shrink: 1;
}

.tercero {
  flex-shrink: 2;
}
Resultado visual: reducción de elementos
shrink: 0
shrink: 1
shrink: 2

Los tres elementos parten de 160 píxeles, pero no caben juntos. El primero conserva su tamaño base y los otros dos se reducen. El tercero tiene un factor de contracción mayor que el segundo.

El reparto de la reducción no depende únicamente del número indicado en flex-shrink. El navegador también tiene en cuenta los tamaños base de los elementos y sus límites.

⚠️ Atención

En ocasiones, un elemento no se reduce como esperamos porque conserva un tamaño mínimo automático relacionado con su contenido. En determinados diseños puede ser necesario utilizar min-width: 0 para permitir que se contraiga correctamente.

flex-basis: tamaño inicial

La propiedad flex-basis establece el tamaño base inicial de un elemento sobre el eje principal, antes de repartir el espacio libre o aplicar las reducciones necesarias.

Con flex-direction: row, se relaciona con la anchura inicial. Con flex-direction: column, se relaciona con la altura inicial.

Su valor predeterminado es auto, que permite tomar como referencia el tamaño principal especificado o, según el caso, el contenido.

CSS 
.contenedor {
  display: flex;
  gap: 10px;
}

.primero {
  flex-basis: 100px;
}

.segundo {
  flex-basis: 200px;
}

.tercero {
  flex-basis: 100px;
}
Resultado visual: diferentes tamaños base
100px
200px
100px

El segundo elemento parte de un tamaño base mayor. Si no hay suficiente espacio, los elementos podrán reducirse según sus factores de contracción.

La propiedad abreviada flex

CSS permite combinar flex-grow, flex-shrink y flex-basis mediante la propiedad abreviada flex.

CSS 
/* Propiedades individuales */

.elemento {
  flex-grow: 1;
  flex-shrink: 1;
  flex-basis: 200px;
}

/* Forma abreviada equivalente */

.elemento {
  flex: 1 1 200px;
}
Declaración Significado
flex: 1 Permite crecer y encogerse, utilizando una base flexible de 0%.
flex: 1 1 auto Permite crecer y encogerse, tomando como referencia el tamaño automático.
flex: 0 0 200px Establece una base de 200 píxeles sin crecimiento ni contracción flexible.
flex: 1 1 250px Parte de 250 píxeles, pero puede crecer o reducirse según el espacio disponible.
💻 Ejemplo DAW

En una página con tarjetas de cursos podemos utilizar flex: 1 1 250px para que cada tarjeta tenga una anchura base aproximada de 250 píxeles, pueda crecer para aprovechar el espacio libre y pueda reducirse cuando sea necesario.

Orden visual de los elementos: order

La propiedad order permite modificar el orden visual de los elementos dentro de un contenedor flexible.

De forma predeterminada, todos los elementos tienen order: 0 y aparecen siguiendo su orden de origen en el documento HTML.

Cuando asignamos valores diferentes, el navegador los ordena visualmente de menor a mayor. Los elementos que tienen el mismo valor mantienen su orden relativo de origen.

Ejemplo de modificación del orden

HTML + CSS 
<div class="contenedor">
  <div class="primero">1</div>
  <div class="segundo">2</div>
  <div class="tercero">3</div>
</div>

<style>
  .contenedor {
    display: flex;
    gap: 10px;
  }

  .primero {
    order: 3;
  }

  .segundo {
    order: 1;
  }

  .tercero {
    order: 2;
  }
</style>
Resultado visual: cambio de orden Orden original en HTML

Orden visual con CSS
1
2
3

El HTML mantiene la secuencia 1, 2, 3, pero visualmente los elementos aparecen como 2, 3, 1.

⚠️ Atención: accesibilidad

order modifica la presentación visual, pero no cambia el orden de los elementos en el HTML ni necesariamente su secuencia de navegación mediante teclado. Por ello, no debemos utilizarlo para reorganizar contenidos cuyo orden sea importante para la comprensión o la interacción.

Aplicaciones prácticas de Flexbox

Una vez conocidas las propiedades de distribución, alineación y tamaño flexible, podemos combinarlas para construir componentes habituales de una interfaz web.

Vamos a estudiar tres situaciones especialmente frecuentes en el desarrollo de aplicaciones web: una barra de navegación, un conjunto de tarjetas y una zona de acciones.

Ejemplo 1. Barra de navegación

En una cabecera podemos situar el nombre de una aplicación a la izquierda y los enlaces de navegación a la derecha.

Para ello utilizamos display: flex, align-items: center y margin-left: auto sobre el grupo de enlaces.

HTML + CSS 
<nav class="barra">

  <span class="marca">StudyFlow</span>

  <div class="enlaces">
    <a href="#inicio">Inicio</a>
    <a href="#cursos">Cursos</a>
    <a href="#perfil">Perfil</a>
  </div>

</nav>

<style>
  .barra {
    display: flex;
    align-items: center;
    flex-wrap: wrap;
    gap: 14px;
  }

  .enlaces {
    display: flex;
    flex-wrap: wrap;
    gap: 12px;
    margin-left: auto;
  }
</style>
Resultado visual: cabecera de StudyFlow

El margen automático absorbe el espacio libre disponible y desplaza el grupo de enlaces hacia el extremo derecho. Si el espacio es insuficiente, flex-wrap permite reorganizar los elementos.

Ejemplo 2. Tarjetas flexibles

Otro uso habitual consiste en distribuir tarjetas de contenido que se adapten al ancho disponible.

Podemos combinar flex-wrap, gap y la propiedad abreviada flex para conseguir una distribución flexible.

HTML + CSS 
<div class="tarjetas">

  <article class="tarjeta">
    <h3>HTML</h3>
    <p>Estructura de páginas web.</p>
    <a href="#html">Ver curso</a>
  </article>

  <article class="tarjeta">
    <h3>CSS</h3>
    <p>Diseño y presentación visual.</p>
    <a href="#css">Ver curso</a>
  </article>

  <article class="tarjeta">
    <h3>JavaScript</h3>
    <p>Interactividad en el navegador.</p>
    <a href="#javascript">Ver curso</a>
  </article>

</div>

<style>
  .tarjetas {
    display: flex;
    flex-wrap: wrap;
    gap: 14px;
  }

  .tarjeta {
    display: flex;
    flex-direction: column;
    flex: 1 1 190px;
    min-width: 0;
    padding: 18px;
    border: 1px solid #b8d8c3;
    border-radius: 9px;
  }

  .tarjeta a {
    margin-top: auto;
  }
</style>

Las tarjetas pueden crecer, reducirse y pasar a otra línea. Además, margin-top: auto permite situar sus enlaces en la parte inferior cuando existe espacio libre dentro de cada tarjeta.

Ejemplo 3. Botones de acción

En formularios y aplicaciones es frecuente encontrar varios botones que deben mantenerse agrupados y alineados.

Por ejemplo, podemos colocar las acciones «Cancelar» y «Guardar cambios» en el extremo derecho de un formulario.

HTML + CSS 
<div class="acciones">
  <button type="button">Cancelar</button>
  <button type="submit">Guardar cambios</button>
</div>

<style>
  .acciones {
    display: flex;
    justify-content: flex-end;
    align-items: center;
    flex-wrap: wrap;
    gap: 12px;
  }
</style>
Resultado visual: acciones de formulario

Los botones aparecen agrupados al final del eje principal y mantienen una separación uniforme. Esta demostración representa únicamente la distribución visual; no guarda datos.

💻 Ejemplo DAW: StudyFlow

En nuestro proyecto StudyFlow podemos combinar estas técnicas para organizar la cabecera, distribuir las tarjetas de cursos y alinear las acciones de cada formulario. Flexbox permite resolver estos componentes sin recurrir a flotaciones ni posiciones absolutas, manteniendo un diseño más adaptable y sencillo de mantener.

💭 Piensa

Imagina que estás diseñando una sección de StudyFlow con tres tarjetas de cursos. Quieres que las tarjetas aprovechen el espacio horizontal disponible, mantengan una separación uniforme y puedan pasar a una nueva línea cuando la pantalla sea más estrecha. ¿Qué propiedades de Flexbox utilizarías? ¿Aplicarías todas ellas al contenedor?

Ver respuesta razonada

Aplicaría display: flex al contenedor para activar Flexbox, flex-wrap: wrap para permitir que las tarjetas pasen a nuevas líneas y gap para establecer una separación uniforme.

A cada tarjeta le asignaría, por ejemplo, flex: 1 1 250px. Así partiría de un tamaño base de 250 píxeles y podría crecer o reducirse según el espacio disponible.

Por tanto, no todas las propiedades se aplicarían al contenedor: display, flex-wrap y gap pertenecen al contenedor, mientras que flex se aplica a cada tarjeta.
