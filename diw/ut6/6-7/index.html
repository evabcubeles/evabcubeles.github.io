6.7 Distribución y alineación con CSS Grid

En el apartado anterior hemos aprendido a crear cuadrículas con CSS Grid, definir filas y columnas y distribuir el espacio mediante unidades como fr.

Hasta ahora, los elementos se han colocado principalmente de forma automática, siguiendo el orden en el que aparecen en el documento HTML.

Sin embargo, en una interfaz web real podemos necesitar que determinados elementos ocupen varias columnas, se extiendan por diferentes filas o aparezcan en zonas concretas de la página.

CSS Grid proporciona propiedades que permiten controlar la posición, la distribución y la alineación de los elementos dentro de una cuadrícula.

📌 Importante

En CSS Grid podemos controlar tanto la estructura general de la cuadrícula como la posición que ocupa cada elemento.

Esta capacidad resulta especialmente útil para construir páginas con cabecera, menú lateral, contenido principal, pie de página y otros componentes.

grid-column y grid-row

Las propiedades grid-column y grid-row permiten indicar qué columnas y filas debe ocupar un elemento dentro de una cuadrícula.

Para comprender su funcionamiento debemos recordar que CSS Grid utiliza líneas de cuadrícula. Estas líneas delimitan las columnas y las filas.

Por ejemplo, una cuadrícula de tres columnas tiene cuatro líneas verticales.

Colocación mediante líneas

Podemos utilizar la siguiente sintaxis:

CSS 
.elemento {
  grid-column: 1 / 3;
  grid-row: 1 / 2;
}

En este ejemplo:

  • grid-column: 1 / 3 indica que el elemento comienza en la línea vertical 1 y termina en la línea vertical 3.
  • El elemento ocupa, por tanto, dos columnas.
  • grid-row: 1 / 2 indica que comienza en la línea horizontal 1 y termina en la línea horizontal 2.
  • El elemento ocupa una fila.
⚠️ Atención

Los números utilizados en grid-column y grid-row identifican líneas de cuadrícula, no números de columnas o filas.

Por ejemplo, 1 / 3 abarca dos columnas, no tres.

Ejemplo de posicionamiento

Vamos a crear una cuadrícula con tres columnas y dos filas. Uno de los elementos ocupará dos columnas y otro se extenderá por dos filas.

HTML + CSS 
<div class="contenedor">
  <div class="elemento destacado">A</div>
  <div class="elemento lateral">B</div>
  <div class="elemento c">C</div>
  <div class="elemento d">D</div>
</div>

<style>
  .contenedor {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(2, 75px);
    gap: 10px;
  }

  .destacado {
    grid-column: 1 / 3;
    grid-row: 1;
  }

  .lateral {
    grid-column: 3;
    grid-row: 1 / 3;
  }
  .c {
    grid-column: 1;
    grid-row: 2;
  }

  .d {
    grid-column: 2;
    grid-row: 2;
  }
</style>
Resultado visual: elementos que ocupan varias filas y columnas
A — Dos columnas
B — Dos filas
C
D

El elemento A ocupa las dos primeras columnas. El elemento B ocupa la tercera columna y se extiende por las dos filas. Los elementos C y D completan las posiciones disponibles.

Utilización de span

También podemos utilizar la palabra span para indicar cuántas columnas o filas debe abarcar un elemento, sin especificar necesariamente ambas líneas.

CSS 
.elemento {
  grid-column: span 2;
}

Esta regla indica que el elemento debe ocupar dos columnas a partir de su posición de inicio.

Otra posibilidad consiste en utilizar la línea -1, que representa la última línea de la cuadrícula explícita en ese eje.

CSS 
.elemento {
  grid-column: 1 / -1;
}
Resultado visual: elemento que ocupa todas las columnas
Elemento destacado
1
2
3

El primer elemento se extiende desde la primera hasta la última línea de la cuadrícula explícita. Los otros tres elementos ocupan una columna cada uno.

Áreas de la cuadrícula

Cuando una página contiene varias zonas claramente diferenciadas, podemos utilizar grid-template-areas para definir su distribución mediante nombres de áreas.

Esta técnica facilita la lectura del CSS, porque permite representar visualmente la estructura de la página.

Definición de áreas

Imaginemos una página formada por cuatro zonas:

  • Cabecera.
  • Menú lateral.
  • Contenido principal.
  • Pie de página.

Podemos definir su estructura mediante el siguiente código:

CSS 
.pagina {
  display: grid;

  grid-template-columns: 1fr 2fr;

  grid-template-areas:
    "cabecera cabecera"
    "lateral contenido"
    "pie pie";

  gap: 10px;
}

.cabecera {
  grid-area: cabecera;
}

.lateral {
  grid-area: lateral;
}

.contenido {
  grid-area: contenido;
}

.pie {
  grid-area: pie;
}

Cada cadena de texto representa una fila de la cuadrícula.

Los nombres repetidos indican que una misma área ocupa varias celdas. Por ejemplo, la cabecera ocupa las dos columnas de la primera fila.

Resultado visual: estructura de página mediante áreas
Cabecera
Menú lateral
Contenido principal
Pie de página

La cabecera y el pie ocupan todo el ancho. En la zona central aparecen el menú lateral y el contenido principal, distribuidos en dos columnas.

Asignación de áreas a elementos HTML

Para que cada elemento ocupe el área correspondiente, utilizamos grid-area.

HTML 
<div class="pagina">

  <header class="cabecera">
    Cabecera
  </header>

  <aside class="lateral">
    Menú lateral
  </aside>

  <main class="contenido">
    Contenido principal
  </main>

  <footer class="pie">
    Pie de página
  </footer>

</div>
📌 Importante

grid-template-areas se aplica al contenedor Grid.

grid-area se aplica a los elementos Grid para indicar qué área deben ocupar.

Celdas vacías en una distribución

Si queremos dejar una celda sin asignar a un área, podemos utilizar un punto (.) dentro de grid-template-areas.

CSS 
.pagina {
  display: grid;

  grid-template-columns: 1fr 2fr;

  grid-template-areas:
    "cabecera cabecera"
    "lateral contenido"
    ". pie";
}

En este ejemplo, la primera celda de la última fila queda sin asignar a un área con nombre.

⚠️ Atención

Las áreas definidas mediante grid-template-areas deben formar regiones rectangulares.

No podemos utilizar el mismo nombre para crear áreas separadas o con formas irregulares.

Colocación automática

CSS Grid no obliga a indicar manualmente la posición de todos los elementos.

Cuando no especificamos una posición, el navegador utiliza un sistema de colocación automática.

Por defecto, los elementos se distribuyen siguiendo las filas y ocupando las posiciones disponibles.

Distribución automática por filas

Observa el siguiente ejemplo:

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    repeat(3, 1fr);

  grid-auto-flow: row;

  gap: 10px;
}

Distribución automática por columnas

La propiedad grid-auto-flow permite modificar la dirección de la colocación automática.

Si utilizamos el valor column, los elementos se colocan siguiendo las columnas.

CSS 
.contenedor {
  display: grid;

  grid-template-rows: repeat(2, 70px);

  grid-auto-flow: column;

  grid-auto-columns: 120px;

  gap: 10px;
}

En este caso, los elementos se colocan primero en las dos filas de una columna y después pasan a la columna siguiente.

Filas y columnas implícitas

Cuando hay más elementos de los que caben en la cuadrícula definida, CSS Grid puede crear nuevas filas o columnas automáticamente.

Estas nuevas pistas forman parte de la cuadrícula implícita.

Podemos controlar sus dimensiones mediante las propiedades:

  • grid-auto-rows: establece el tamaño de las filas implícitas.
  • grid-auto-columns: establece el tamaño de las columnas implícitas.
CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    repeat(3, 1fr);

  grid-auto-rows:
    minmax(80px, auto);

  gap: 10px;
}

En este ejemplo, las filas creadas automáticamente tendrán una altura mínima de 80px, pero podrán aumentar si su contenido necesita más espacio.

📌 Importante

La colocación automática resulta muy útil cuando el número de elementos puede variar, por ejemplo, en un catálogo de productos, una galería de imágenes o una lista de cursos.

De esta forma, no necesitamos indicar manualmente la posición de cada tarjeta.

Alineación en Grid

CSS Grid permite controlar la alineación de los elementos dentro de sus celdas y la distribución de la cuadrícula dentro del espacio disponible.

Para ello, utiliza propiedades como justify-items, align-items, justify-content y align-content.

justify-items y align-items

Estas propiedades se aplican al contenedor Grid y controlan la alineación de los elementos dentro de sus respectivas áreas.

  • justify-items controla la alineación en el eje en línea (horizontal en una escritura habitual de izquierda a derecha).
  • align-items controla la alineación en el eje de bloque (vertical en ese mismo contexto).
CSS 
.contenedor {
  display: grid;

  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 95px);

  justify-items: center;
  align-items: center;

  gap: 10px;
}

Valores habituales de alineación

Valor Comportamiento
start Sitúa el elemento al inicio del eje.
end Sitúa el elemento al final del eje.
center Centra el elemento.
stretch Estira el elemento para ocupar el espacio disponible, siempre que su tamaño lo permita.

justify-self y align-self

Si queremos modificar la alineación de un elemento concreto, podemos utilizar justify-self y align-self.

Estas propiedades se aplican directamente al elemento Grid.

CSS 
.contenedor {
  display: grid;

  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 130px;

  align-items: center;
}

.primero {
  align-self: start;
}

.segundo {
  align-self: center;
}

.tercero {
  align-self: end;
}
Resultado visual: alineación individual de los elementos

Centro
Final

Cada elemento utiliza un valor diferente de align-self, por lo que aparece en una posición distinta dentro de su celda.

justify-content y align-content

A diferencia de las propiedades anteriores, justify-content y align-content distribuyen las pistas de la cuadrícula dentro del contenedor cuando existe espacio libre.

Estas propiedades no alinean individualmente cada elemento dentro de su celda.

📌 Importante

Para que los efectos de justify-content y align-content resulten visibles, debe existir espacio libre en el eje correspondiente.

Por ejemplo, si las columnas ocupan todo el ancho disponible, aplicar justify-content: space-between no producirá una separación adicional entre ellas.

CSS 
.contenedor {
  display: grid;

  grid-template-columns: repeat(2, 100px);
  grid-template-rows: repeat(2, 65px);

  justify-content: space-between;
  align-content: center;

  min-height: 230px;
  gap: 10px;
}
Resultado visual: distribución de la cuadrícula dentro del contenedor

Las columnas se distribuyen horizontalmente mediante space-between. Las filas se agrupan verticalmente en el centro del contenedor.

⚠️ Atención

No debemos confundir justify-items con justify-content.

La primera alinea los elementos dentro de sus áreas; la segunda distribuye las pistas de la cuadrícula cuando existe espacio disponible.

repeat() y minmax()

Cuando diseñamos cuadrículas con muchas columnas o con tamaños adaptables, resulta útil utilizar las funciones repeat() y minmax().

La función repeat()

La función repeat() permite repetir un patrón de tamaños sin escribirlo varias veces.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    repeat(3, 1fr);

  gap: 10px;
}

Esta declaración equivale a escribir:

CSS 
.contenedor {
  grid-template-columns: 1fr 1fr 1fr;
}
Resultado visual: tres columnas iguales
1
2
3
4
5
6

Los seis elementos se distribuyen en tres columnas de igual anchura.

La función minmax()

La función minmax() permite establecer un tamaño mínimo y un tamaño máximo para una pista de la cuadrícula.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    repeat(3, minmax(150px, 1fr));

  gap: 10px;
}

En este ejemplo, cada columna tiene un tamaño mínimo de 150px y puede crecer para repartir el espacio disponible.

⚠️ Atención

Definir tres columnas con un mínimo de 150px no garantiza que la cuadrícula quepa en una pantalla estrecha.

Si el espacio disponible es insuficiente, puede producirse desbordamiento horizontal. Para crear diseños adaptables podemos combinar minmax() con auto-fit.

Cuadrículas adaptables con auto-fit

El valor auto-fit permite ajustar automáticamente el número de columnas que caben en el contenedor.

Podemos combinarlo con repeat() y minmax() para crear distribuciones adaptables.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    repeat(
      auto-fit,
      minmax(min(100%, 180px), 1fr)
    );

  gap: 14px;
}

La cantidad de columnas se adapta al espacio disponible. Cuando el contenedor se estrecha, los elementos pasan a nuevas filas.

📌 Importante

La combinación de repeat(), auto-fit y minmax() permite crear cuadrículas flexibles sin definir manualmente todos los cambios de número de columnas.

Aplicaciones prácticas de Grid

CSS Grid resulta especialmente útil para construir galerías de imágenes, catálogos, paneles de control, estructuras de página y conjuntos de tarjetas.

En el desarrollo de aplicaciones web, podemos utilizarlo para distribuir componentes de forma ordenada, manteniendo una separación uniforme y aprovechando el espacio disponible.

💻 Ejemplo DAW: catálogo de cursos StudyFlow

💻 Ejemplo DAW

Imaginemos que estamos desarrollando StudyFlow, una plataforma que permite consultar diferentes cursos de formación.

Queremos mostrar las tarjetas de los cursos en una cuadrícula que se adapte automáticamente al ancho disponible.

Utilizaremos un contenedor Grid y varias tarjetas HTML.

HTML + CSS 
<section class="cursos">

  <article class="curso">
    <h3>HTML</h3>
    <p>Estructura de páginas web.</p>
    <span class="etiqueta-curso">
      Nivel inicial
    </span>
  </article>

  <article class="curso">
    <h3>CSS</h3>
    <p>Diseño de interfaces web.</p>
    <span class="etiqueta-curso">
      Nivel intermedio
    </span>
  </article>

  <article class="curso">
    <h3>JavaScript</h3>
    <p>Interactividad en el navegador.</p>
    <span class="etiqueta-curso">
      Nivel avanzado
    </span>
  </article>

</section>

<style>
  .cursos {
    display: grid;

    grid-template-columns:
      repeat(
        auto-fit,
        minmax(min(100%, 190px), 1fr)

    gap: 14px;

  .curso {

Nivel avanzado

Las tarjetas se distribuyen automáticamente según el espacio disponible. Cada tarjeta mantiene su contenido y el contenedor organiza la cuadrícula mediante CSS Grid.

¿Por qué utilizar CSS Grid en este ejemplo?

  • Permite organizar las tarjetas en filas y columnas.
  • Mantiene una separación uniforme mediante gap.
  • Facilita que las tarjetas se adapten al espacio disponible.
  • Evita tener que establecer manualmente la posición de cada tarjeta.
  • Permite ampliar el catálogo añadiendo nuevos elementos HTML.

💭 Actividad de reflexión

Imagina que estás diseñando una plataforma educativa con doce tarjetas de cursos. ¿Qué ventajas tendría utilizar repeat(auto-fit, minmax(...)) en lugar de definir siempre tres columnas de anchura fija?

Mostrar una posible respuesta

La combinación de repeat(), auto-fit y minmax() permite ajustar automáticamente el número y el tamaño de las columnas al espacio disponible.

De esta forma, en pantallas amplias pueden aparecer varias tarjetas por fila, mientras que en pantallas estrechas se distribuyen en menos columnas.

Además, podemos añadir nuevos cursos sin tener que modificar manualmente la posición de cada tarjeta.
