6.1 Flujo normal del documento y propiedad display

En la UT5 hemos aprendido a modificar la apariencia de los elementos HTML mediante CSS: colores, tipografía, fondos, bordes, espacios y el modelo de caja. Sin embargo, para construir una interfaz web completa no basta con definir el aspecto individual de sus elementos. También necesitamos decidir cómo se distribuyen dentro de la página.

Antes de estudiar técnicas de maquetación como Flexbox y CSS Grid, debemos comprender cómo coloca el navegador los elementos cuando no indicamos ninguna distribución especial. Este comportamiento se conoce como flujo normal del documento.

En este apartado estudiaremos las diferencias entre elementos de bloque y elementos en línea, el funcionamiento de la propiedad display y cómo podemos modificar la forma en la que los elementos ocupan espacio y se relacionan con los demás.

📌 Importante

La maquetación web consiste en organizar los elementos de una interfaz dentro del espacio disponible. Comprender el flujo normal del documento es fundamental para interpretar correctamente el comportamiento de CSS y utilizar después sistemas más avanzados de distribución.

El flujo normal del documento

Cuando el navegador interpreta un documento HTML, genera una representación visual de sus elementos siguiendo determinadas reglas de distribución. Si no aplicamos técnicas especiales de posicionamiento o maquetación, los elementos se organizan según el flujo normal.

En una página escrita de izquierda a derecha, los elementos de bloque se colocan normalmente uno debajo de otro, mientras que el contenido en línea se distribuye dentro de las líneas de texto disponibles.

Este comportamiento permite que el contenido se adapte de forma natural a diferentes anchuras de pantalla. Por ejemplo, cuando un párrafo no cabe en una sola línea, su texto continúa automáticamente en la siguiente.

Ejemplo de flujo normal

HTML 
<h2>Mis asignaturas</h2>

<p>Consulta las asignaturas del curso.</p>

<p>Selecciona una para ver sus actividades.</p>
Resultado visual aproximado
Mis asignaturas
Consulta las asignaturas del curso.
Selecciona una para ver sus actividades.

Los tres elementos se muestran uno debajo de otro porque los encabezados y los párrafos generan cajas de bloque de forma predeterminada.

⚠️ Atención

El flujo normal no significa que todos los elementos se coloquen verticalmente. Su distribución depende del tipo de caja que generan y del contexto en el que se encuentran.

Elementos de bloque y en línea

Para comprender cómo se distribuye el contenido, distinguiremos dos comportamientos visuales básicos: los elementos que generan cajas de bloque y los que generan cajas en línea.

Esta distinción está relacionada con la presentación de los elementos, no con su significado semántico. Un elemento HTML puede tener un comportamiento visual predeterminado que posteriormente modificaremos con CSS.

Elementos de bloque

Los elementos con comportamiento de bloque comienzan normalmente en una nueva línea y se colocan verticalmente respecto a los demás bloques. Cuando su anchura es automática, suelen ocupar todo el espacio horizontal disponible de su contenedor.

Algunos elementos que habitualmente se presentan como bloques son <div>, <p>, <h1> y <section>.

HTML + CSS 
<div class="bloque">Elemento 1</div>
<div class="bloque">Elemento 2</div>
<div class="bloque">Elemento 3</div>

<style>
  .bloque {
    display: block;
    padding: 12px;
    margin-bottom: 8px;
    background-color: #e4f3e9;
  }
</style>
Resultado: elementos de bloque
Elemento 1
Elemento 2
Elemento 3

Elementos en línea

Los elementos con comportamiento en línea se distribuyen dentro de una línea de texto. No comienzan necesariamente en una línea nueva y permiten que otros elementos en línea aparezcan a su lado mientras exista espacio disponible.

Entre los ejemplos habituales encontramos <span>, <a>, <strong> y <em>.

HTML + CSS 
<span class="etiqueta">HTML</span>
<span class="etiqueta">CSS</span>
<span class="etiqueta">JavaScript</span>

<style>
  .etiqueta {
    display: inline;
    background-color: #e4f3e9;
    color: #195c36;
  }
</style>
Resultado: elementos en línea HTML CSS JavaScript

Los elementos aparecen en la misma línea mientras exista espacio suficiente.

Característica Bloque En línea
Nueva línea Normalmente comienza en una nueva línea. Continúa dentro de la línea disponible.
Anchura Con anchura automática suele ocupar el espacio horizontal disponible. Se ajusta principalmente a su contenido.
width y height Generalmente pueden aplicarse. No modifican directamente el tamaño de las cajas en línea no reemplazadas.
Ejemplos habituales div, p, section, h1 span, a, strong, em
📌 Idea clave

No debemos confundir el tipo de elemento HTML con su comportamiento visual. Mediante CSS podemos modificar cómo se muestra un elemento sin cambiar necesariamente su significado en el documento.

La propiedad display

La propiedad display permite controlar cómo genera sus cajas un elemento HTML y cómo participa en la distribución del documento.

Sus valores determinan, entre otras cuestiones, si el elemento se comporta como un bloque, si aparece en línea con otros elementos o si establece un sistema de distribución para sus elementos hijos.

CSS 
.elemento {
  display: block;
}

En este ejemplo indicamos que los elementos con la clase elemento deben generar una caja de bloque.

Valor Comportamiento Uso habitual
block Genera una caja de bloque. Secciones y elementos que ocupan una línea propia.
inline Genera una caja en línea. Fragmentos de texto y enlaces.
inline-block Genera una caja que participa en línea, pero permite controlar sus dimensiones. Etiquetas, insignias y componentes pequeños.
none El elemento no genera cajas en la distribución. Ocultar elementos visualmente y retirarlos del diseño.
flex Establece un contenedor flexible. Distribución de elementos mediante Flexbox.
grid Establece un contenedor de cuadrícula. Distribución mediante CSS Grid.

En este primer apartado nos centraremos en block, inline, inline-block y none. Los valores flex y grid se estudiarán detalladamente más adelante.

Modificar el comportamiento predeterminado

Aunque un elemento se presente normalmente en línea, podemos hacer que genere una caja de bloque utilizando display: block.

HTML + CSS 
<a href="#" class="enlace-menu">Inicio</a>
<a href="#" class="enlace-menu">Asignaturas</a>
<a href="#" class="enlace-menu">Perfil</a>

<style>
  .enlace-menu {
    display: block;
    padding: 12px;
  }
</style>

En este caso, los enlaces, que normalmente se presentan en línea, pasan a ocupar una línea propia cada uno. Esta técnica puede resultar útil para construir un menú vertical.

💻 Ejemplo DAW

En StudyFlow podemos utilizar display: block para que los enlaces de un menú lateral ocupen una fila completa. De esta forma conseguimos una zona de interacción más amplia y una distribución vertical clara.

display: inline-block

El valor inline-block combina características de los elementos en línea y de los elementos de bloque.

Un elemento con display: inline-block puede situarse junto a otros elementos dentro de una línea, pero también permite establecer propiedades como width y height.

Esto resulta útil cuando queremos crear componentes de dimensiones controladas sin obligar a que cada uno comience en una nueva línea.

HTML + CSS 
<span class="categoria">Diseño web</span>
<span class="categoria">Programación</span>
<span class="categoria">Bases de datos</span>

<style>
  .categoria {
    display: inline-block;
    width: 140px;
    padding: 12px;
    margin: 4px;
    background-color: #e4f3e9;
    text-align: center;
    box-sizing: border-box;
  }
</style>
Resultado: inline-block Diseño web Programación Bases de datos

Los elementos pueden colocarse uno al lado del otro y mantienen una anchura definida. Si no existe espacio suficiente, pasan a la siguiente línea.

display: inline

Participa en el texto y no permite controlar directamente la anchura y la altura de una caja en línea no reemplazada.

display: inline-block

Participa en una línea, pero permite definir dimensiones, rellenos y márgenes como una caja de bloque.

⚠️ Atención

Los elementos inline-block participan en el formato en línea, por lo que los espacios y saltos de línea existentes en el HTML pueden producir separación visible entre ellos. Para distribuir grupos complejos de componentes suele ser preferible utilizar Flexbox o Grid.

display: none y visibilidad

En algunas interfaces necesitamos ocultar determinados elementos, por ejemplo, un panel de información que solo debe aparecer cuando se realiza una acción.

CSS ofrece distintas formas de ocultar elementos, pero no todas producen el mismo efecto sobre la distribución del documento.

Ocultar con display: none

Cuando aplicamos display: none, el elemento deja de generar cajas en el diseño y no reserva espacio dentro de la distribución.

HTML + CSS 
<p>Primera actividad</p>

<p class="oculto">Actividad temporalmente oculta</p>

<p>Segunda actividad</p>

<style>
  .oculto {
    display: none;
  }
</style>

En el resultado, el segundo párrafo no aparece y el tercero ocupa el espacio que correspondería al contenido visible.

Ocultar con visibility: hidden

La propiedad visibility permite controlar la visibilidad de un elemento sin eliminar necesariamente el espacio que ocupa.

Con visibility: hidden, el elemento no se muestra, pero su espacio continúa reservado dentro de la distribución.

CSS 
.oculto {
  visibility: hidden;
}
Propiedad ¿Se muestra? ¿Reserva espacio?
display: none No No
visibility: hidden No Sí
opacity: 0 No se ve Sí
⚠️ Atención

opacity: 0 hace transparente un elemento, pero no lo elimina del diseño ni impide por sí solo que pueda recibir interacciones. Por tanto, no debemos considerar opacity, visibility y display como soluciones equivalentes.

📌 Accesibilidad

Un elemento oculto mediante display: none o visibility: hidden normalmente también queda fuera del árbol de accesibilidad. Si necesitamos que una información siga disponible para tecnologías de asistencia, debemos utilizar una técnica adecuada a ese objetivo. Lo estudiaremos en la UT10.

Buenas prácticas de distribución

La propiedad display es una herramienta fundamental para controlar la presentación de los elementos. Sin embargo, conviene elegir sus valores según el comportamiento que necesitamos y no utilizarlos de forma indiscriminada.

Necesidad Solución posible
Colocar enlaces de un menú en filas independientes. display: block
Mostrar una etiqueta breve dentro de una línea de texto. display: inline
Mostrar etiquetas alineadas con dimensiones definidas. display: inline-block
Retirar un elemento de la distribución. display: none
Organizar componentes en una fila con control del espacio y alineación. Flexbox, que estudiaremos en los apartados 6.4 y 6.5.
Crear una estructura de filas y columnas. CSS Grid, que estudiaremos en los apartados 6.6 y 6.7.

Recomendaciones generales

  • Respetar la semántica HTML: elegir los elementos por su significado y utilizar CSS para definir su presentación.
  • Comprender el flujo normal: no modificar la distribución si el comportamiento predeterminado ya responde a nuestras necesidades.
  • Evitar dimensiones innecesarias: permitir que el contenido pueda adaptarse cuando cambie el tamaño de la pantalla.
  • Seleccionar la técnica adecuada: utilizar Flexbox y Grid cuando necesitemos controlar distribuciones más complejas.
  • Comprobar la accesibilidad: tener en cuenta cómo afectan las técnicas de ocultación a la navegación y a las tecnologías de asistencia.
