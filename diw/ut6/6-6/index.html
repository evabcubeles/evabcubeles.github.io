6.6 Introducción a CSS Grid

En los apartados anteriores hemos aprendido a utilizar Flexbox para organizar elementos en filas o columnas, distribuir el espacio disponible y controlar su alineación.

Flexbox resulta especialmente útil para construir barras de navegación, grupos de botones, tarjetas y otros componentes cuya distribución se organiza principalmente sobre un eje.

Sin embargo, algunas interfaces necesitan organizar simultáneamente filas y columnas. Por ejemplo, una página puede contener varias tarjetas distribuidas en una cuadrícula, un panel de control con diferentes bloques o una galería de imágenes.

Para resolver este tipo de diseños, CSS incorpora Grid Layout, conocido habitualmente como CSS Grid.

📌 Importante

CSS Grid es un sistema de maquetación bidimensional: permite organizar elementos mediante filas y columnas.

Esto no significa que sustituya a Flexbox. Ambos sistemas son complementarios y se utilizan según las necesidades de cada diseño.

Qué es CSS Grid

CSS Grid es un sistema de diseño que permite dividir un contenedor en una cuadrícula formada por filas y columnas.

Los elementos que contiene pueden distribuirse dentro de esa estructura sin necesidad de utilizar tablas HTML, flotaciones o posicionamiento absoluto para construir la maquetación.

A diferencia de Flexbox, que se centra en la distribución sobre un eje principal, Grid permite definir una estructura en dos dimensiones al mismo tiempo.

Flexbox frente a CSS Grid

Flexbox CSS Grid
Sistema principalmente unidimensional. Sistema bidimensional.
Organiza elementos sobre un eje principal. Organiza elementos mediante filas y columnas.
Resulta útil para distribuir componentes y controlar su alineación. Resulta útil para definir cuadrículas y estructuras de página.
Ejemplo: barra de navegación. Ejemplo: panel de tarjetas.

Por ejemplo, imaginemos que necesitamos mostrar seis cursos en una página web.

Con CSS Grid podemos establecer tres columnas y dejar que los elementos ocupen las filas correspondientes.

CSS 
.contenedor {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 10px;
}
Resultado visual: una cuadrícula de tres columnas

⚠️ Atención

Aunque CSS Grid permite construir diseños que se parecen visualmente a una tabla, no debemos utilizarlo para sustituir las tablas HTML cuando los datos tienen una estructura tabular.

Las tablas HTML siguen siendo la opción adecuada para presentar datos organizados mediante encabezados, filas y columnas.

Contenedor y elementos Grid

Al igual que sucede con Flexbox, en CSS Grid debemos distinguir entre el contenedor Grid y los elementos Grid.

El contenedor es el elemento HTML al que aplicamos display: grid. Sus hijos directos se convierten en elementos Grid.

Estructura HTML básica

HTML + CSS 
<div class="contenedor">
  <div class="elemento">1</div>
  <div class="elemento">2</div>
  <div class="elemento">3</div>
  <div class="elemento">4</div>
</div>

<style>
  .contenedor {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 10px;
  }

  .elemento {
    padding: 14px;
    background-color: #e4f3e9;
    border: 1px solid #85c79b;
  }
</style>
Resultado visual: contenedor y elementos Grid
1
2
3
4

El borde discontinuo representa el contenedor Grid. Los cuatro bloques verdes son sus elementos Grid, distribuidos en dos columnas.

¿Qué propiedades corresponden al contenedor?

El contenedor establece la estructura general de la cuadrícula: cuántas columnas existen, cómo se definen las filas y qué separación habrá entre ellas.

Propiedad Función
display: grid Activa el sistema de maquetación Grid.
grid-template-columns Define las columnas explícitas.
grid-template-rows Define las filas explícitas.
gap Establece la separación entre filas y columnas.
📌 Importante

Los hijos directos del contenedor son los elementos Grid.

Si uno de esos elementos contiene a su vez otros elementos HTML, estos no se convierten automáticamente en elementos de la cuadrícula exterior.

¿Qué sucede con los elementos anidados?

Observa este ejemplo:

HTML 
<div class="contenedor">

  <article class="tarjeta">
    <h3>HTML</h3>
    <p>Estructura web.</p>
  </article>

  <article class="tarjeta">
    <h3>CSS</h3>
    <p>Diseño visual.</p>
  </article>

</div>

Los elementos article son los elementos Grid porque son hijos directos del contenedor.

Los elementos h3 y p pertenecen al contenido interno de cada tarjeta. No participan directamente en la cuadrícula exterior.

Filas, columnas y líneas

Para trabajar correctamente con CSS Grid es necesario comprender los elementos que forman una cuadrícula.

Los conceptos fundamentales son las filas, las columnas, las líneas y las celdas.

Filas y columnas

Una columna es una división vertical de la cuadrícula, mientras que una fila es una división horizontal.

Por ejemplo, una cuadrícula de tres columnas y dos filas dispone de seis celdas.

CSS 
.contenedor {
  display: grid;

  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 80px 80px;

  gap: 10px;
}
Resultado visual: tres columnas y dos filas

La cuadrícula contiene tres columnas y dos filas de 80 píxeles de altura. Los elementos se colocan automáticamente siguiendo el orden del documento.

Las líneas de la cuadrícula

Las líneas Grid son las líneas que delimitan las filas y columnas.

No debemos confundir las líneas con los bordes visibles de los elementos. Las líneas Grid forman parte de la estructura de la cuadrícula, aunque no se dibujan automáticamente en la página.

Por ejemplo, una cuadrícula de tres columnas explícitas tiene cuatro líneas verticales que delimitan esas columnas.

Esquema: líneas verticales de una cuadrícula

Los números superiores representan las cuatro líneas verticales que delimitan las tres columnas. Las líneas son referencias para colocar elementos dentro de Grid.

Las celdas y las áreas

Una celda Grid es el espacio comprendido entre dos líneas de fila consecutivas y dos líneas de columna consecutivas.

Un área Grid es una región rectangular formada por una o varias celdas.

En este apartado utilizaremos principalmente las celdas. Más adelante, en el 6.7, aprenderemos a colocar elementos en posiciones concretas y a definir áreas de la cuadrícula.

📌 Importante

Si definimos tres columnas, tendremos cuatro líneas verticales que las delimitan. Si definimos dos filas, tendremos tres líneas horizontales.

Estas referencias serán especialmente útiles cuando estudiemos grid-column y grid-row en el siguiente apartado.

display: grid e inline-grid

Para activar CSS Grid utilizamos la propiedad display sobre el contenedor.

Los dos valores que estudiaremos son grid e inline-grid.

display: grid

El valor display: grid convierte un elemento en un contenedor Grid de tipo bloque.

Por tanto, el contenedor participa en el flujo exterior como un bloque, mientras que sus hijos directos se organizan mediante Grid.

HTML + CSS 
<div class="contenedor">
  <div class="elemento">1</div>
  <div class="elemento">2</div>
  <div class="elemento">3</div>
  <div class="elemento">4</div>
</div>

<style>
  .contenedor {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 10px;
  }
</style>
Resultado visual: display: grid
1

El contenedor ocupa el ancho disponible de su bloque contenedor y organiza sus elementos en dos columnas.

display: inline-grid

El valor display: inline-grid también crea un contenedor Grid, pero este participa en el flujo exterior como un elemento de nivel en línea.

Esto permite situarlo junto a texto u otros elementos en línea cuando existe espacio suficiente.

CSS 
.contenedor {
  display: inline-grid;
  grid-template-columns: 90px 90px;
  gap: 10px;
}
Resultado visual: display: inline-grid

1

Texto posterior

La cuadrícula participa en la misma línea que el texto cuando el ancho disponible lo permite. En su interior, los elementos siguen distribuyéndose mediante CSS Grid.

Valor Comportamiento exterior Distribución interior
grid Contenedor de tipo bloque. CSS Grid.
inline-grid Contenedor de nivel en línea. CSS Grid.
⚠️ Atención

La diferencia entre grid e inline-grid afecta principalmente a cómo participa el contenedor en el flujo exterior.

En ambos casos, los hijos directos se organizan utilizando CSS Grid.

grid-template-columns y grid-template-rows

Una vez creado el contenedor Grid, necesitamos definir la estructura de sus filas y columnas.

Para ello utilizamos dos propiedades: grid-template-columns y grid-template-rows.

grid-template-columns

La propiedad grid-template-columns define el número y el tamaño de las columnas explícitas de la cuadrícula.

Cada tamaño indicado representa una columna.

CSS 
/* Una columna */

.contenedor {
  display: grid;
  grid-template-columns: 1fr;
}

/* Dos columnas */

.contenedor {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

/* Tres columnas */

.contenedor {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}
Resultado visual: diferente número de columnas Una columna

Columnas con tamaños fijos

También podemos establecer columnas utilizando unidades absolutas, como los píxeles.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    100px 150px 100px;

  gap: 10px;
}
Resultado visual: columnas de anchura fija
100px
150px
100px

Las tres columnas tienen anchuras explícitas de 100, 150 y 100 píxeles. Si el espacio disponible es insuficiente, este diseño puede provocar desbordamiento horizontal.

Columnas con tamaños diferentes

No es obligatorio que todas las columnas tengan la misma anchura.

Por ejemplo, podemos combinar una columna fija con otra que aproveche el espacio restante.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    120px minmax(0, 1fr);

  gap: 10px;
}
Resultado visual: columna fija y columna flexible
120px
Espacio restante

La primera columna mantiene una anchura de 120 píxeles. La segunda utiliza el espacio disponible que queda.

📌 Importante

La función minmax() permite establecer límites mínimo y máximo para el tamaño de una pista Grid.

En minmax(0, 1fr), el valor mínimo es cero y el máximo flexible es una fracción del espacio disponible.

Estudiaremos esta función con mayor profundidad en el apartado 6.7.

grid-template-rows

La propiedad grid-template-rows define el tamaño de las filas explícitas de la cuadrícula.

Por ejemplo, podemos crear una cuadrícula de dos columnas y dos filas, donde la primera fila mida 60 píxeles y la segunda 100 píxeles.

CSS 
.contenedor {
  display: grid;

  grid-template-columns: 1fr 1fr;
  grid-template-rows: 60px 100px;

  gap: 10px;
}
Resultado visual: filas de diferente altura
1

Los elementos 1 y 2 ocupan la primera fila, de 60 píxeles. Los elementos 3 y 4 ocupan la segunda, de 100 píxeles.

Filas automáticas

No siempre es necesario indicar grid-template-rows.

Si definimos las columnas y añadimos más elementos de los que caben en una fila, Grid puede generar automáticamente nuevas filas.

CSS 
.contenedor {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 10px;
}

/* Si hay seis elementos,
   se crearán tres filas. */

⚠️ Atención

grid-template-columns y grid-template-rows definen las pistas explícitas.

Cuando el navegador necesita crear filas adicionales, estas forman parte de la cuadrícula implícita.

Más adelante veremos cómo controlar con mayor precisión la colocación automática de los elementos.

La unidad fr

Una de las características más útiles de CSS Grid es la unidad fr.

Esta unidad representa una fracción del espacio disponible para las pistas flexibles de la cuadrícula.

Nos permite distribuir el espacio sin tener que calcular manualmente porcentajes para cada columna.

Columnas con la misma proporción

Si utilizamos tres columnas con 1fr, cada una recibe la misma proporción del espacio que se reparte entre las columnas.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    1fr 1fr 1fr;

  gap: 10px;
}
Resultado visual: tres columnas equivalentes
1fr
1fr
1fr

Las tres columnas reciben la misma proporción del espacio disponible.

Columnas con diferentes proporciones

También podemos asignar factores diferentes a las columnas.

Por ejemplo, con 1fr 2fr 1fr, la segunda columna recibe el doble de espacio flexible que cada una de las otras dos, siempre que las restricciones de tamaño no impidan esa distribución.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    1fr 2fr 1fr;

  gap: 10px;
}
Resultado visual: proporción 1 : 2 : 1
1fr
2fr
1fr

La columna central es aproximadamente el doble de ancha que cada columna lateral. Las tres pistas reparten el espacio flexible en cuatro partes.

Combinar píxeles y fracciones

Podemos combinar unidades fijas y flexibles dentro de una misma cuadrícula.

Por ejemplo, una columna puede mantener una anchura fija de 100 píxeles y la otra aprovechar el espacio restante.

CSS 
.contenedor {
  display: grid;

  grid-template-columns:
    100px minmax(0, 1fr);

  gap: 10px;
}
Resultado visual: columna fija y espacio flexible
100px
1fr

La primera columna mide 100 píxeles. La segunda aprovecha el espacio restante del contenedor.

¿Cómo se calcula el espacio disponible?

Para comprender la unidad fr, imaginemos una cuadrícula con 800 píxeles de anchura interior y tres columnas.

En este ejemplo suponemos que el contenedor no tiene padding ni bordes que reduzcan el espacio interior disponible, y que el contenido no impone tamaños mínimos adicionales.

CSS 
.contenedor {
  display: grid;
  width: 800px;

  grid-template-columns:
    1fr 2fr 1fr;

  gap: 20px;
}

Como hay tres columnas, existen dos separaciones de 20 píxeles entre ellas.

Por tanto, el espacio que queda para repartir entre las columnas es:

💻 Cálculo del espacio

Anchura interior: 800 px.

Separaciones: 20 + 20 = 40 px.

Espacio flexible: 800 - 40 = 760 px.

Total de fracciones: 1 + 2 + 1 = 4.

Una fracción: 760 / 4 = 190 px.

Columnas: 190 px, 380 px y 190 px.

⚠️ Atención

Este cálculo representa un caso sencillo en el que el espacio interior disponible es conocido y el contenido no impone restricciones adicionales.

En diseños reales, los tamaños mínimos, el contenido y otras propiedades también pueden influir en el resultado.

Por eso, 1fr no significa necesariamente un porcentaje fijo del ancho total del contenedor.

Separación entre celdas

Una vez definidas las filas y columnas, necesitamos controlar la separación entre ellas.

CSS Grid utiliza la propiedad gap, que ya hemos estudiado en Flexbox.

row-gap y column-gap

Cuando necesitamos controlar las separaciones de forma independiente, podemos utilizar:

  • row-gap: separación entre las filas.
  • column-gap: separación entre las columnas.
CSS 
.contenedor {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;

  row-gap: 12px;
  column-gap: 20px;
}

/* Forma abreviada equivalente */

.contenedor {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;

  gap: 12px 20px;
}

Diferencia entre gap y padding

Aunque ambas propiedades generan espacio, no cumplen la misma función.

Propiedad Función
gap Separa las filas y columnas de la cuadrícula.
padding Establece espacio interior entre el borde del contenedor y su contenido.
margin Establece márgenes exteriores alrededor de los elementos.
📌 Importante

La propiedad gap no añade por sí misma espacio entre las pistas exteriores y el borde del contenedor.

Si necesitamos ese espacio, podemos utilizar padding sobre el contenedor.

💭 Piensa

Imagina que estás diseñando la sección de cursos de StudyFlow.

Necesitas mostrar seis tarjetas distribuidas en tres columnas, con el mismo espacio entre ellas.

¿Qué propiedades de CSS Grid utilizarías para crear esa estructura? ¿Cuántas filas se generarían? ¿Sería obligatorio definir grid-template-rows?
