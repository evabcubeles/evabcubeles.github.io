6.8 Maquetación avanzada: combinación de técnicas

A lo largo de esta unidad hemos estudiado diferentes técnicas de maquetación con CSS: el flujo normal del documento, el posicionamiento, la flotación de elementos, Flexbox y CSS Grid.

Cada técnica resuelve necesidades diferentes. En una interfaz web real no es necesario elegir una única técnica para toda la página. Lo habitual es combinar varias para organizar sus distintas partes.

Por ejemplo, podemos utilizar CSS Grid para distribuir la cabecera, el menú lateral y el contenido principal, mientras que Flexbox puede ayudarnos a alinear los enlaces de navegación, los botones o los elementos interiores de una tarjeta.

En este apartado aprenderemos a seleccionar la técnica más adecuada, combinar contenedores y construir estructuras de página claras, mantenibles y adaptables.

📌 Importante

Flexbox y CSS Grid no son tecnologías competidoras. Son herramientas complementarias.

Una misma página puede utilizar Grid para su estructura general y Flexbox para distribuir los componentes que contiene.

Cuándo utilizar Flexbox o Grid

Para decidir qué técnica utilizar debemos analizar cómo queremos organizar los elementos y qué tipo de distribución necesita la interfaz.

Flexbox: distribución en un eje principal

Flexbox resulta especialmente útil cuando queremos distribuir y alinear elementos a lo largo de un eje principal, que puede ser horizontal o vertical.

Aunque Flexbox permite que los elementos se repartan en varias líneas mediante flex-wrap, cada línea se distribuye de forma independiente. Por eso se considera un sistema de maquetación principalmente unidimensional.

Algunos usos habituales son:

  • Barras de navegación.
  • Grupos de botones.
  • Distribución de iconos y texto.
  • Alineación de elementos dentro de tarjetas.
  • Componentes organizados en filas o columnas.
CSS 
.barra-navegacion {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

CSS Grid: distribución en filas y columnas

CSS Grid resulta especialmente adecuado cuando necesitamos organizar elementos mediante filas y columnas, controlando ambas dimensiones de la distribución.

Podemos definir una cuadrícula y decidir qué espacio ocupa cada componente dentro de ella.

Algunos usos habituales son:

  • Estructura general de páginas web.
  • Paneles de administración.
  • Galerías de imágenes.
  • Cuadrículas de tarjetas.
  • Distribuciones con varias zonas diferenciadas.
CSS 
.cuadricula {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

⚠️ Atención

No debemos interpretar que Flexbox solo permite filas o que Grid solo sirve para páginas completas. Ambas técnicas pueden resolver diferentes distribuciones.

La elección depende de las necesidades de alineación, de la relación entre los elementos y del grado de control que necesitemos.

Combinación de técnicas

Una interfaz web suele estar formada por componentes que tienen necesidades de distribución diferentes.

Podemos utilizar CSS Grid para organizar las tarjetas y Flexbox para alinear los elementos interiores de cada tarjeta.

Grid para la estructura y Flexbox para el contenido

Imaginemos una página que muestra varios cursos. Queremos que las tarjetas se distribuyan en columnas, pero que el título y la etiqueta de cada curso aparezcan alineados en la misma fila.

Podemos resolverlo combinando ambas técnicas.

HTML + CSS 
<div class="cursos">

  <article class="curso">
    <div class="curso-cabecera">
      <h3>HTML</h3>
      <span>Básico</span>
    </div>
    <p>Estructura de páginas web.</p>
  </article>

  <article class="curso">
    <div class="curso-cabecera">
      <h3>CSS</h3>
      <span>Intermedio</span>
    </div>
    <p>Diseño visual y maquetación.</p>
  </article>

</div>

<style>
  .cursos {
    display: grid;
    grid-template-columns:
      repeat(2, minmax(0, 1fr));
    gap: 16px;
  }

  .curso {
    min-width: 0;
    padding: 18px;
    border: 1px solid #85c79b;
    border-radius: 8px;
    background-color: #e4f3e9;
    color: #195c36;
  }

  .curso-cabecera {
    display: flex;
    align-items: center;
    justify-content: space-between;
    flex-wrap: wrap;
    gap: 10px;
    margin-bottom: 14px;
  }

  .curso-cabecera h3 {
    margin: 0;
  }

  .curso-cabecera span {
    padding: 5px 9px;
    border-radius: 16px;
    background-color: #c9e8d4;
  }

  .curso p {
    margin: 0;
  }

  @media (max-width: 600px) {
    .cursos {
      grid-template-columns: 1fr;
    }
  }
</style>

📌 Importante

La propiedad display se aplica a cada contenedor de forma independiente.

Un elemento puede ser un elemento Grid respecto a su contenedor padre y, al mismo tiempo, convertirse en un contenedor Flexbox para sus propios hijos.

Estructura de una página web

Una página web puede organizarse en varias zonas: cabecera, navegación, contenido principal, barra lateral y pie de página.

CSS Grid permite definir estas zonas de forma clara mediante grid-template-areas.

Distribución mediante áreas

Vamos a construir una estructura sencilla con cabecera, menú lateral, contenido y pie.

HTML + CSS 
<div class="pagina">

  <header class="cabecera">
    Cabecera
  </header>

  <aside class="lateral">
    Menú lateral
  </aside>

  <main class="principal">
    Contenido principal
  </main>

  <footer class="pie">
    Pie de página
  </footer>

</div>

<style>
  .pagina {
    display: grid;
    grid-template-columns:
      minmax(0, 1fr) minmax(0, 2fr);
    grid-template-areas:
      "cabecera cabecera"
      "lateral principal"
      "pie pie";
    gap: 12px;
  }

  .cabecera {
    grid-area: cabecera;
  }

  .lateral {
    grid-area: lateral;
  }

  .principal {
    grid-area: principal;
  }

  .pie {
    grid-area: pie;
  }

  .pagina > * {
    padding: 20px;
    border: 1px solid #85c79b;
    border-radius: 7px;
    background-color: #e4f3e9;
    color: #195c36;
  }

  @media (max-width: 600px) {
    .pagina {
      grid-template-columns: 1fr;
      grid-template-areas:
        "cabecera"
        "lateral"
        "principal"
        "pie";
    }
  }
</style>

Relación entre HTML semántico y maquetación

Es importante distinguir entre la estructura semántica del HTML y la distribución visual del CSS.

Etiquetas como header, nav, main, aside y footer describen la función de las distintas partes del documento.

CSS decide cómo se presentan esas partes: en columnas, en filas, alineadas o distribuidas en distintas áreas.

⚠️ Atención

Cambiar visualmente la posición de un elemento mediante CSS no modifica necesariamente su posición en el documento HTML ni el orden de navegación por teclado.

Por ello, debemos mantener un orden HTML lógico y no depender exclusivamente del orden visual para transmitir información.

Contenedores anidados

En una página web es habitual que un contenedor incluya otros contenedores que también utilizan técnicas de maquetación.

A esta organización la denominamos anidamiento de contenedores.

Por ejemplo, una cuadrícula de tarjetas puede utilizar CSS Grid, mientras que cada tarjeta contiene un grupo de etiquetas organizado mediante Flexbox.

  <article class="tarjeta">

    <div class="etiquetas">
      <span>Color</span>

    </div>
  </article>

</div>

<style>
  .tarjetas {

    grid-template-columns:

Grid distribuye las tarjetas en columnas. Dentro de cada tarjeta, Flexbox organiza las etiquetas y permite que pasen a otra línea cuando sea necesario.

📌 Importante

Un contenedor Grid solo organiza directamente a sus elementos hijos.

Si uno de esos hijos contiene otros elementos, podemos aplicar una nueva distribución a ese contenedor interior.

Buenas prácticas de maquetación

Una buena maquetación no consiste únicamente en conseguir que los elementos aparezcan en la posición deseada.

También debe facilitar el mantenimiento del código, la adaptación a diferentes pantallas y la comprensión de la interfaz.

Elegir la técnica adecuada

Debemos utilizar la técnica que mejor resuelva cada necesidad.

  • Utilizar Flexbox para distribuir componentes en filas o columnas.
  • Utilizar Grid cuando necesitemos controlar filas y columnas.
  • Utilizar position cuando sea necesario controlar la posición de un elemento respecto a una referencia.
  • Evitar utilizar float como solución principal para maquetaciones modernas de varias columnas.

Evitar tamaños rígidos innecesarios

Los tamaños fijos pueden provocar desbordamientos cuando cambia el ancho de la pantalla o aumenta el contenido.

Siempre que sea apropiado, podemos utilizar unidades flexibles y funciones como minmax() y repeat().

CSS 
.tarjetas {
  display: grid;
  grid-template-columns: repeat(
    auto-fit,
    minmax(min(100%, 220px), 1fr)
  );
  gap: 16px;
}

Esta distribución crea tantas columnas como permita el espacio disponible, respetando el tamaño mínimo indicado cuando el ancho del contenedor lo permite.

Utilizar gap para separar elementos

La propiedad gap permite establecer una separación uniforme entre elementos Flexbox o Grid.

Esto suele resultar más sencillo que asignar márgenes diferentes a cada elemento.

Mantener una estructura HTML lógica

El orden de los elementos HTML debe tener sentido incluso cuando no se aplican estilos CSS.

También debemos utilizar etiquetas semánticas para describir correctamente la función de cada zona de la página.

Organizar y reutilizar los estilos

Es recomendable utilizar clases descriptivas y evitar repetir innecesariamente las mismas propiedades.

Por ejemplo, podemos definir una clase general para todas las tarjetas y añadir clases específicas únicamente cuando necesitemos diferencias visuales.

CSS 
.tarjeta {
  padding: 18px;
  border: 1px solid #ddd;
  border-radius: 8px;
}

.tarjeta-destacada {
  border-color: #2f9e5b;
  background-color: #eef8f1;
}

Comprobar el comportamiento responsive

La distribución debe revisarse en diferentes anchos de pantalla.

Una estructura que funciona correctamente en un ordenador puede necesitar cambios cuando se visualiza en un móvil.

⚠️ Atención

Una página no es responsive únicamente porque utilice porcentajes o unidades fr.

También debemos comprobar que el contenido no se desborda, que los textos siguen siendo legibles y que la navegación puede utilizarse correctamente.

Aplicación al proyecto StudyFlow

Vamos a aplicar los conceptos anteriores al diseño de una interfaz para StudyFlow, una plataforma ficticia de formación online.

Análisis de la solución

En este ejemplo, cada técnica cumple una función concreta:

  • Cabecera: Flexbox alinea el nombre de la plataforma con los enlaces de navegación.
  • Estructura principal: Grid crea una columna para el menú lateral y otra para el contenido.
  • Tarjetas: una segunda cuadrícula permite distribuir los cursos de forma flexible.
  • Adaptación: la media query coloca el menú lateral y el contenido en una sola columna cuando el ancho disponible disminuye.

En un proyecto de Desarrollo de Aplicaciones Web, esta combinación permite crear interfaces para plataformas educativas, paneles de administración, catálogos de productos o aplicaciones de gestión.

Separar la estructura general de los componentes interiores facilita mantener y ampliar el diseño.

¿Qué técnica utilizarías para la estructura general? ¿Y para organizar los botones dentro de cada tarjeta? Justifica tu respuesta.

Ver una posible solución

Para la estructura general utilizaría CSS Grid, porque permite organizar las distintas zonas de la página en filas y columnas.

También utilizaría Grid para distribuir las tarjetas de productos.

Para alinear los botones y otros elementos interiores de cada tarjeta, utilizaría Flexbox, ya que facilita la alineación y distribución en un eje principal.

Ambas técnicas pueden combinarse sin problemas porque cada contenedor controla a sus propios elementos hijos.

📌 Recuerda

Una maquetación avanzada no consiste en utilizar el mayor número posible de propiedades CSS, sino en elegir las herramientas adecuadas para cada parte de la interfaz.

Grid organiza estructuras, Flexbox distribuye componentes y ambas técnicas pueden combinarse mediante contenedores anidados.
