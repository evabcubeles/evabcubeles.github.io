✏️ Resumen de la UT2

En esta unidad hemos estudiado cómo construir una identidad visual coherente para una interfaz web a partir de decisiones sobre color, tipografía e iconografía.

Este resumen reúne las ideas esenciales de los apartados 2.1 a 2.6 para que puedas utilizarlo como guía rápida de repaso antes de aplicar estos criterios en un proyecto web.

2.1 El color en el diseño web

El color es un recurso de comunicación visual que puede organizar, destacar, diferenciar y reforzar el significado de los elementos de una interfaz.

ComunicarPuede transmitir información, estados y relaciones entre elementos.
OrganizarAyuda a diferenciar zonas, categorías, prioridades o acciones.
OrientarPuede dirigir la atención hacia elementos importantes de la interfaz.
Uso funcionalDebe aportar información o reforzar la estructura, no limitarse a decorar.
📌 Recuerda

El significado del color depende del contexto. No debemos asumir que un mismo color comunica siempre la misma idea.

2.2 Sistemas y propiedades del color

En una pantalla los colores se generan mediante luz. Para describirlos y representarlos digitalmente utilizamos distintos modelos y notaciones.

ConceptoIdea principal
RGBCombina intensidades de rojo, verde y azul para generar colores en dispositivos digitales.
MatizIdentifica la familia de color, como rojo, verde, azul o violeta.
SaturaciónIndica la intensidad o pureza del color.
LuminosidadIndica el grado de claridad u oscuridad del color dentro de este modelo.
Representación digitalLos colores pueden expresarse mediante nombres, hexadecimal, RGB/RGBA o HSL, entre otras sintaxis.
⚠️ Colores web seguros

La antigua paleta de colores web seguros tuvo sentido por las limitaciones de los primeros dispositivos, pero ya no constituye una restricción habitual en el diseño web actual.

2.3 Combinación y uso del color en interfaces web

Una paleta permite organizar los colores del proyecto y asignarles funciones concretas para mantener la coherencia visual.

PaletaConjunto de colores seleccionados para utilizarse de manera coordinada.
ArmoníaRelaciona colores siguiendo criterios que permiten crear combinaciones visualmente equilibradas.
ContrasteFacilita diferenciar elementos y resulta esencial para mantener una buena legibilidad.
AccesibilidadLa información importante no debe depender únicamente del color y debe existir contraste suficiente.
💻 Ejemplo DAW

En una aplicación podemos reservar un color principal para acciones destacadas, tonos neutros para fondos y textos secundarios, y colores funcionales para estados como éxito, advertencia o error.

2.4 Tipografía para interfaces web

La tipografía influye en la legibilidad, la jerarquía de la información y la personalidad visual de la interfaz.

🔤Familias

Las familias tipográficas presentan rasgos visuales diferentes y deben elegirse según el contexto y la función.

👁️Legibilidad

Tamaño, peso, longitud de línea, interlineado y contraste influyen en la facilidad de lectura.

↕️Jerarquía

Los niveles tipográficos ayudan a distinguir títulos, subtítulos, cuerpo de texto e información auxiliar.

🧩Combinación

Conviene limitar el número de tipografías y asignarles funciones claras y consistentes.

💻Fuentes del sistema

Aprovechan tipografías instaladas en el dispositivo y suelen ofrecer una carga rápida y fiable.

🌐Fuentes web

Permiten utilizar tipografías suministradas por el proyecto para mantener una apariencia más controlada.

2.5 Iconografía en interfaces web

La iconografía es el conjunto de iconos y símbolos visuales utilizados para representar funciones, contenidos, estados o categorías dentro de la interfaz.

ReconociblesLos símbolos conocidos aprovechan convenciones que el usuario ya ha aprendido en otras interfaces.
ComprensiblesUn icono debe relacionarse claramente con la acción o información que representa.
Icono + textoCuando existe ambigüedad, una etiqueta de texto ayuda a aclarar la función.
ConsistenciaLos iconos de una misma interfaz deben mantener criterios comunes de tamaño, trazo, proporción y estilo.
📌 Recuerda

Una biblioteca de iconos facilita la coherencia, pero seguimos teniendo que decidir qué símbolo utilizar, dónde colocarlo y si necesita texto de apoyo.

2.6 Identidad visual y guía de estilo

Color, tipografía, iconografía y otros recursos deben funcionar como partes de un mismo sistema para construir una identidad visual reconocible.

🎨Identidad visual

Conjunto de elementos y decisiones gráficas que permiten reconocer y diferenciar un proyecto.

🔁Coherencia visual

Aplica criterios comunes a elementos que cumplen funciones similares en las distintas pantallas.

📘Guía de estilo

Documenta colores, tipografías, iconos, componentes, espaciados y otras reglas de uso.

🧱Componentes

Botones, formularios, tarjetas, mensajes y otros elementos repetidos deben mantener criterios comunes.

📐Espaciado y composición

Las reglas de separación, alineación y distribución ayudan a mantener un ritmo visual consistente.

🧰Sistema de diseño

Amplía la guía con componentes, patrones y recursos reutilizables para diseñar y desarrollar el producto.

⚠️ Atención

Coherencia no significa uniformidad absoluta. Las diferencias visuales son útiles cuando representan diferencias funcionales claras y constantes.

Ideas clave de la UT2

📌 Si tuvieras que recordar solo estas ideas…
  • El color comunica: debe utilizarse con una función y no únicamente como decoración.
  • RGB describe la mezcla de luz en pantalla, mientras que matiz, saturación y luminosidad ayudan a describir las propiedades del color.
  • Una paleta eficaz establece roles claros para los colores y mantiene contraste y legibilidad.
  • La tipografía debe favorecer la lectura y la jerarquía de la información, además de contribuir a la identidad visual.
  • Los iconos deben ser reconocibles, comprensibles y consistentes; cuando exista ambigüedad, conviene apoyarlos con texto.
  • La identidad visual surge de coordinar colores, tipografías, iconos y otros recursos mediante criterios comunes.
  • La guía de estilo documenta esas decisiones para que puedan aplicarse de forma coherente durante todo el proyecto.
  • Un sistema de diseño amplía la guía con componentes y patrones reutilizables, aunque no todos los proyectos necesitan uno completo.
