📝 Actividades de la UT2

Para finalizar la UT2 vas a aplicar de forma conjunta los principales conceptos trabajados en los apartados 2.1 a 2.6.

Las actividades se dividen en dos partes: un reto final, basado en una situación profesional relacionada con la identidad visual de una aplicación web, y una autoevaluación para comprobar los contenidos esenciales de la unidad.

🧩 Reto final — Diseña la identidad visual de una aplicación web

Formas parte de un equipo de desarrollo que está creando StudyFlow, una aplicación web para organizar tareas, fechas de entrega y materiales de estudio.

La estructura y las funcionalidades principales ya están definidas, pero el proyecto todavía no tiene una identidad visual común. Cada miembro del equipo utiliza colores, tipografías e iconos diferentes, por lo que las pantallas parecen pertenecer a aplicaciones distintas.

El encargo

Tu misión consiste en definir una propuesta visual coherente que pueda utilizarse como referencia durante el desarrollo de StudyFlow.

📌 Condición del proyecto

No se busca simplemente que la aplicación resulte atractiva. Cada decisión debe tener una función clara y contribuir a la legibilidad, la coherencia y la comprensión de la interfaz.

Tu misión

Elabora una pequeña guía de estilo que incluya los siguientes apartados:

  1. Define una paleta de colores. Selecciona un color principal, uno secundario, tonos neutros y, si lo consideras necesario, colores funcionales para estados como éxito, advertencia o error. Indica el valor de cada color y explica qué función tendrá.
  2. Comprueba el uso del color. Explica cómo evitarías que una información importante dependa únicamente del color y comprueba que las combinaciones principales de texto y fondo mantienen un contraste suficiente para facilitar la lectura.
  3. Define la tipografía. Selecciona una o dos familias tipográficas y establece una jerarquía básica para título principal, subtítulos, cuerpo de texto e información auxiliar. Justifica tus decisiones desde el punto de vista de la legibilidad.
  4. Define el sistema de iconos. Elige un estilo coherente de iconografía y selecciona al menos cinco iconos para funciones habituales de la aplicación, por ejemplo inicio, tareas, calendario, búsqueda y configuración. Indica cuáles deberían ir acompañados de texto.
  5. Establece criterios para componentes visuales. Define unas reglas básicas para botones, campos de formulario, tarjetas, mensajes o avisos, así como criterios de espaciado. No necesitas programarlos: basta con especificar cómo deberían mantener una apariencia coherente.
  6. Construye una muestra visual. Diseña una pequeña pantalla o composición en la que se vean aplicados la paleta, la tipografía, los iconos y algunos de los componentes definidos.
  7. Justifica al menos cuatro decisiones. Explica por qué tus elecciones contribuyen a la identidad visual, la coherencia, la legibilidad o la comprensión de la interfaz.
📦 Entrega del reto

Presenta una guía de estilo breve con la paleta de colores, la propuesta tipográfica, el sistema de iconos, los criterios de los componentes y la muestra visual de StudyFlow. Puedes realizarla con una herramienta de diseño, una presentación o un documento bien organizado. No es necesario implementar todavía la interfaz con HTML y CSS.

✅ Autoevaluación de la UT2

Responde las siguientes preguntas para comprobar qué contenidos de la UT2 has comprendido.

Cada pregunta tiene una única respuesta correcta.

1. ¿Cuál de las siguientes afirmaciones describe mejor el uso funcional del color en una interfaz?

2. En el modelo RGB, ¿cómo se genera un color?

3. ¿Qué propiedad del color indica su intensidad o pureza?

4. ¿Cuál de estas decisiones mejora la accesibilidad relacionada con el color?

5. ¿Cuál de los siguientes factores influye directamente en la legibilidad tipográfica?

6. ¿Qué objetivo tiene principalmente una jerarquía tipográfica?

7. Si un icono puede resultar ambiguo para el usuario, ¿qué opción es normalmente más adecuada?

8. ¿Qué caracteriza a una iconografía consistente?

9. ¿Cuál es la función principal de una guía de estilo?

10. ¿Qué diferencia principal existe entre una guía de estilo y un sistema de diseño?
