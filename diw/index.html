Diseño de interfaces web

En este módulo aprenderemos a diseñar y desarrollar interfaces web que sean visualmente coherentes, fáciles de utilizar, adaptables a distintos dispositivos y accesibles para el mayor número posible de personas.

A lo largo del curso estudiaremos los principios del diseño visual, el uso del color y la tipografía, la planificación y el prototipado de interfaces, y la creación de páginas mediante HTML y CSS.

También trabajaremos con imágenes, audio, vídeo, animaciones y otros contenidos multimedia, y aprenderemos a evaluar una interfaz desde dos perspectivas fundamentales en el desarrollo web profesional: la accesibilidad y la usabilidad.

El enfoque será especialmente práctico: analizaremos interfaces, construiremos ejemplos, modificaremos código y comprobaremos de forma visual cómo cada decisión de diseño influye en la experiencia de las personas usuarias.
