📝 Actividades de la UT5

Para finalizar la UT5 vas a aplicar de forma conjunta los principales contenidos trabajados en los apartados 5.1 a 5.10.

Las actividades se dividen en dos partes: un reto final, en el que continuarás desarrollando StudyFlow aplicando CSS a la estructura HTML creada en la UT4, y una autoevaluación para comprobar los conceptos esenciales de la unidad.

🧩 Reto final — Diseña la apariencia visual de StudyFlow con CSS

En la UT4 construiste la estructura HTML de una de las vistas principales de StudyFlow. Ahora vas a mantener esa estructura y desarrollar su presentación visual mediante CSS.

El objetivo es transformar la página estructural en una interfaz visualmente coherente, legible y mantenible, aplicando los contenidos trabajados durante toda la UT5.

El encargo

El equipo de StudyFlow ha aprobado la estructura HTML de la página de una asignatura y necesita una primera propuesta de identidad visual. Debes crear una hoja de estilos que aplique de forma coherente las decisiones de color, tipografía, espaciado y apariencia de los componentes.

📌 Condición del proyecto

En este reto debes centrarte en los fundamentos y el diseño visual con CSS. No es necesario resolver todavía la maquetación avanzada con Flexbox o Grid ni desarrollar el comportamiento responsive: esos contenidos se trabajarán en las UT6 y UT7.

Tu misión

Parte del archivo index.html de StudyFlow realizado en la UT4 y crea una hoja estilos.css que cumpla los siguientes requisitos:

  1. Vincula correctamente una hoja de estilos externa. Crea el archivo estilos.css, enlázalo desde el documento HTML mediante <link rel="stylesheet"> y organiza las reglas de forma clara, utilizando comentarios cuando ayuden a identificar las distintas zonas del diseño.
  2. Utiliza selectores adecuados. Aplica selectores de tipo, clases y, cuando esté justificado, identificadores o selectores de atributo. Incluye también algún ejemplo de agrupación o combinación de selectores. Evita crear selectores innecesariamente específicos.
  3. Aplica pseudoclases y pseudoelementos. Define estados de interacción para enlaces, botones o controles mediante pseudoclases como :hover, :focus o :focus-visible. Utiliza al menos un pseudoelemento cuando tenga una función visual adecuada y no sustituya contenido significativo.
  4. Controla la cascada, la especificidad y la herencia. Organiza las reglas para evitar conflictos innecesarios. Si dos reglas afectan a la misma propiedad, debes poder explicar por qué prevalece una de ellas. No utilices !important como solución habitual.
  5. Elige unidades y valores adecuados. Combina de forma razonada unidades como px, rem, em o % según el tipo de propiedad y utiliza al menos una función CSS, por ejemplo calc(), min(), max() o clamp(), cuando resulte útil.
  6. Aplica la paleta de color de StudyFlow. Define colores coherentes para texto, fondos, elementos destacados y estados de interacción. Centraliza los colores principales mediante propiedades personalizadas de CSS y reutilízalos con var(). Mantén un contraste suficiente entre texto y fondo.
  7. Define la tipografía y el tratamiento del texto. Establece una familia tipográfica con alternativas, tamaños, grosor, interlineado y otras propiedades de texto necesarias para construir una jerarquía visual clara y mantener la legibilidad.
  8. Diseña fondos y cajas. Aplica fondos cuando sean necesarios y utiliza correctamente el modelo de caja: width o dimensiones cuando proceda, padding, border y margin. Incorpora box-sizing: border-box para facilitar el control de las dimensiones.
  9. Define la apariencia de los componentes. Utiliza bordes, border-radius, box-shadow o text-shadow únicamente cuando contribuyan a la jerarquía visual. Los elementos interactivos deben conservar un foco visible; no elimines el outline sin proporcionar una alternativa perceptible.
  10. Revisa y valida la hoja de estilos. Comprueba que el CSS está organizado, que no contiene reglas duplicadas o innecesarias y que las decisiones visuales son coherentes con la guía de estilo. Valida la hoja con el Servicio de Validación de CSS del W3C, corrige los errores detectados y vuelve a validarla. Analiza los avisos en lugar de eliminarlos de forma automática.
📦 Entrega del reto

Entrega el archivo index.html, la hoja estilos.css y los recursos locales necesarios para visualizar StudyFlow correctamente. El CSS debe estar organizado, legible y validado. Añade también una breve explicación de tres decisiones de diseño tomadas durante la implementación —por ejemplo, sobre color, tipografía, modelo de caja, selectores o estados de interacción— justificando cómo contribuyen a mantener una interfaz coherente.

✅ Autoevaluación de la UT5

Responde las siguientes preguntas para comprobar qué contenidos de la UT5 has comprendido.

Cada pregunta tiene una única respuesta correcta.

1. ¿Cuál es la forma más adecuada de aplicar estilos reutilizables a varias páginas de un mismo sitio web?

2. ¿Qué selector selecciona todos los elementos que tienen la clase tarjeta?

3. ¿Qué pseudoclase resulta especialmente útil para mostrar un estilo de foco cuando corresponde a la interacción mediante teclado?

4. Si dos reglas aplicables a la misma propiedad tienen la misma prioridad y especificidad, ¿qué puede decidir cuál prevalece?

5. ¿Qué unidad toma como referencia el tamaño de fuente del elemento raíz del documento?

6. ¿Qué ventaja ofrecen las propiedades personalizadas de CSS, como --color-principal?

7. En el modelo de caja, ¿qué zona se encuentra entre el contenido y el borde?

8. ¿Qué efecto tiene normalmente box-sizing: border-box sobre una anchura declarada con width?

9. ¿Cuál de estas afirmaciones sobre outline es correcta?

10. ¿Qué significa que una hoja CSS haya superado correctamente una validación?
