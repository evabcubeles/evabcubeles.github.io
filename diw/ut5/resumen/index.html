✏️ Resumen de la UT5

En esta unidad hemos estudiado cómo definir la presentación visual de una interfaz web mediante CSS, separando el contenido y la estructura HTML de las decisiones de diseño.

Este resumen reúne las ideas esenciales de los apartados 5.1 a 5.10 para utilizarlo como guía rápida de repaso de reglas, selectores, cascada, unidades, color, tipografía, fondos, modelo de caja y efectos visuales. Al final incorporamos también la validación de CSS como parte del proceso de revisión del código.

5.1 Introducción a CSS

CSS controla principalmente la presentación visual de los elementos HTML. Una regla CSS combina un selector con un bloque de declaraciones, y cada declaración relaciona una propiedad con un valor.

En líneaEl CSS se escribe en el atributo style del elemento. Es útil en casos puntuales, pero dificulta la reutilización y el mantenimiento.
Hoja internaLas reglas se incluyen en un elemento <style> del documento HTML.
Hoja externaLas reglas se guardan en un archivo .css enlazado mediante <link rel="stylesheet">. Es la opción habitual para proyectos con estilos reutilizables.
Hoja alternativarel="alternate stylesheet" permite declarar una presentación alternativa. En la web actual, los cambios de tema suelen implementarse mediante otros mecanismos cuando se necesita una selección controlada por la aplicación.
📌 Recuerda

Separar HTML y CSS permite mantener la estructura y el contenido independientes de su presentación y facilita aplicar cambios coherentes en todo el sitio.

5.2 Selectores CSS

Los selectores determinan qué elementos recibirán una regla. Elegirlos correctamente permite aplicar estilos con precisión sin llenar el HTML de reglas repetidas.

*️⃣Universal

* selecciona todos los elementos dentro de su ámbito.

🏷️Tipo

p, h1 o button seleccionan elementos por su nombre de etiqueta.

🔹Clase

.aviso selecciona los elementos que comparten una clase y favorece la reutilización.

#️⃣ID

#cabecera selecciona el elemento que posee ese identificador.

🔎Atributo

[required] o input[type="email"] seleccionan según la presencia o el valor de atributos.

🔗Combinadores

Permiten seleccionar elementos según relaciones de descendencia, hijos o hermanos.

5.3 Pseudoclases y pseudoelementos

Las pseudoclases permiten seleccionar elementos según un estado o condición; los pseudoelementos permiten aplicar estilos a una parte o abstracción del elemento.

Estados:hover, :active, :focus, :focus-visible, :checked o :disabled.
EstructuraPseudoclases estructurales permiten seleccionar elementos según su posición o relación dentro del documento.
::before y ::afterCrean pseudoelementos asociados al elemento seleccionado y pueden incorporar contenido generado con CSS.
Otros pseudoelementos::first-letter, ::first-line, ::selection, ::placeholder o ::marker permiten actuar sobre partes concretas.
⚠️ Atención

Los efectos de interacción no deben depender únicamente del ratón. Estados como :focus y :focus-visible son importantes para que el foco del teclado pueda percibirse.

5.4 Cascada, especificidad y herencia

Cuando varias declaraciones pueden afectar a un mismo elemento y propiedad, CSS debe determinar cuál se aplica. Para comprender el resultado hay que distinguir cascada, especificidad, orden e herencia.

CascadaEs el mecanismo general mediante el que CSS resuelve las declaraciones que compiten entre sí.
EspecificidadCompara el peso de los selectores. Un identificador tiene mayor especificidad que una clase, y una clase mayor que un selector de tipo.
OrdenCuando las declaraciones comparadas tienen la misma prioridad, el orden puede decidir cuál prevalece.
HerenciaAlgunas propiedades pueden transmitir su valor desde un elemento antecesor a sus descendientes.
⚠️ !important

No debe utilizarse como solución habitual para resolver conflictos. Un uso excesivo hace más difícil comprender y mantener la cascada.

5.5 Unidades y valores en CSS

Las propiedades CSS aceptan distintos tipos de valores. Elegir una unidad adecuada depende de qué estamos midiendo y de cómo queremos que ese valor se relacione con el resto de la interfaz.

Absolutaspx es una unidad muy utilizada para determinadas medidas en pantalla.
Relativasem, rem, vw y vh dependen de otras referencias y permiten expresar relaciones entre tamaños.
Porcentajes% expresa un valor relativo a una referencia que depende de la propiedad y del contexto.
Funcionescalc(), min(), max() y clamp() permiten calcular o limitar valores.
📌 Recuerda

No existe una única unidad correcta para todo el sitio. Debemos elegirla según el tipo de propiedad, la referencia que necesitamos y el comportamiento deseado.

5.6 Colores en CSS

CSS permite expresar colores mediante distintos formatos y reutilizarlos de forma coherente para aplicar la paleta definida en la guía de estilo.

🔤Nombres

Palabras clave como black, white o red.

#️⃣Hexadecimal

Valores como #1f6f43 representan componentes de color mediante notación hexadecimal.

🎨RGB

rgb() expresa los componentes rojo, verde y azul y puede incorporar transparencia.

🌈HSL

hsl() representa el color mediante matiz, saturación y luminosidad.

🔁currentColor

Permite reutilizar en otras propiedades el valor calculado de color.

🧩Variables CSS

Las propiedades personalizadas permiten centralizar valores de la identidad visual y reutilizarlos.

📌 Diseño coherente

La elección de colores no debe hacerse de forma aislada en cada regla. Conviene aplicar una paleta coherente y reutilizable y conservar suficiente contraste entre contenido y fondo.

5.7 Tipografía y texto

Las propiedades tipográficas permiten trasladar a CSS las decisiones de jerarquía y legibilidad definidas durante el diseño de la interfaz.

Familiafont-family establece una lista ordenada de familias tipográficas alternativas.
Tamañofont-size controla el tamaño del texto.
Estilo y grosorfont-style y font-weight modifican características de la fuente.
Interlineadoline-height controla la separación entre líneas de texto.
Alineacióntext-align controla la alineación; valores lógicos como start y end se adaptan a la dirección de escritura.
Otras propiedadestext-decoration, text-transform, espaciado, sangría, espacios en blanco y ajuste de palabras completan el tratamiento textual.

5.8 Fondos

El fondo forma parte de la presentación del elemento y puede combinar colores e imágenes sin introducir contenido estructural adicional en HTML.

background-colorDefine el color de fondo.
background-imagePermite utilizar una o varias imágenes de fondo mediante url() u otros valores admitidos.
Repetición y posiciónbackground-repeat y background-position controlan cómo se distribuye y sitúa la imagen.
Tamañobackground-size permite definir dimensiones y utilizar valores como cover o contain.
⚠️ Propiedad abreviada

background permite combinar varias propiedades de fondo, pero al utilizar una propiedad abreviada podemos reinicializar valores que no se hayan especificado expresamente.

5.9 El modelo de caja

CSS representa los elementos mediante cajas formadas por distintas áreas. Comprender este modelo es esencial para controlar correctamente dimensiones y espacios.

MARGEN → BORDE → PADDING → CONTENIDO
ContentÁrea en la que se encuentra el contenido del elemento.
PaddingEspacio interior situado entre el contenido y el borde.
BorderDelimita la caja alrededor del contenido y el relleno.
MarginEspacio exterior que separa la caja de otros elementos.
📌 box-sizing

Con content-box, width se refiere al área de contenido y el padding y el borde se añaden a esa anchura. Con border-box, la anchura declarada incluye contenido, padding y borde, lo que suele facilitar el control de las dimensiones.

5.10 Bordes, esquinas y sombras

Bordes, radios y sombras permiten reforzar la jerarquía visual y la identidad de los componentes, siempre que se utilicen de forma coherente y no dificulten la lectura.

▣Bordes

border-width, border-style y border-color controlan sus características; border permite abreviarlas.

◯Esquinas

border-radius redondea las esquinas y admite valores distintos para cada una.

🌫️Sombras de caja

box-shadow utiliza desplazamientos y puede añadir desenfoque, expansión, color e inset.

🔤Sombras de texto

text-shadow aplica sombras al texto; no dispone del valor de expansión de box-shadow.

⌖outline

Se dibuja alrededor del elemento sin modificar sus dimensiones y resulta especialmente útil para representar el foco.

🎯Coherencia

Radios, bordes y sombras deben seguir criterios comunes de la guía de estilo y responder a una función visual.

Validación y revisión del CSS

Además de comprobar visualmente una interfaz en el navegador, conviene revisar que la hoja de estilos está correctamente escrita. Un validador CSS analiza el código conforme a las reglas del lenguaje y puede ayudar a localizar errores de sintaxis o declaraciones incorrectas.

ValidarPodemos utilizar un servicio de validación CSS para analizar una hoja de estilos o el CSS asociado a un documento.
InterpretarHay que distinguir entre errores que deben corregirse y avisos que requieren analizar su contexto antes de decidir qué hacer.
CorregirTras localizar un problema, se modifica el código y se vuelve a ejecutar la validación para comprobar el resultado.
ComprobarLa validación no sustituye las pruebas visuales, de compatibilidad, accesibilidad o usabilidad.
📌 Flujo de trabajo recomendado

Escribir → probar en el navegador → validar → corregir → volver a probar. La validación forma parte de la revisión técnica del CSS, pero una hoja válida no garantiza por sí sola que el diseño sea adecuado.

Ideas clave de la UT5

📌 Si tuvieras que recordar solo estas ideas…
  • CSS define principalmente la presentación visual de los elementos HTML y permite separar estructura y diseño.
  • Una regla CSS combina un selector con declaraciones formadas por propiedades y valores.
  • Las clases son fundamentales para crear estilos reutilizables; los selectores también pueden basarse en etiquetas, identificadores, atributos y relaciones entre elementos.
  • Las pseudoclases seleccionan según estados o condiciones y los pseudoelementos permiten actuar sobre partes o abstracciones de un elemento.
  • Para entender por qué se aplica un estilo debemos distinguir cascada, especificidad, orden e herencia; !important no debe convertirse en una solución habitual.
  • Las unidades y funciones CSS permiten expresar tamaños y relaciones de forma adecuada al contexto.
  • Color y tipografía deben aplicar de forma coherente las decisiones de la guía de estilo.
  • Los fondos forman parte de la presentación; las imágenes que aportan contenido significativo deben incorporarse mediante HTML cuando corresponda.
  • El modelo de caja está formado por contenido, padding, borde y margen; box-sizing: border-box facilita habitualmente el control de dimensiones.
  • Bordes, radios y sombras deben reforzar la jerarquía y la identidad visual sin introducir ruido innecesario.
  • Una hoja CSS debe ser legible, coherente, mantenible y validada; validar ayuda a detectar problemas, pero no garantiza por sí solo un buen diseño, accesibilidad o usabilidad.
