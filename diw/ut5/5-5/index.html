5.5 Unidades y valores en CSS

Hasta ahora hemos utilizado propiedades CSS como color, border o font-size, pero cada propiedad necesita un valor que indique cómo debe aplicarse. En muchas propiedades ese valor incluye además una unidad de medida.

Elegir correctamente las unidades es importante para construir interfaces que sean legibles, flexibles y fáciles de adaptar a diferentes espacios. No existe una única unidad adecuada para todas las situaciones: su elección depende de qué queremos medir y de qué referencia debe utilizar el navegador.

📌 Importante

En CSS, el número y la unidad forman un único valor. Por ejemplo, en font-size: 18px, 18 es el número y px es la unidad. Cuando el valor es cero, normalmente puede escribirse simplemente 0, sin indicar unidad.

Valores en CSS

Una declaración CSS está formada por una propiedad y un valor. Dependiendo de la propiedad, ese valor puede ser una palabra clave, un número, una longitud, un porcentaje, un color, una función u otro tipo de dato admitido por CSS.

CSS
.tarjeta {
  width: 320px;
  max-width: 100%;
  margin: 0 auto;
  font-size: 1rem;
  opacity: 0.9;
}
EjemploTipo de valorSignificado
320pxLongitudUna medida expresada en píxeles CSS.
100%PorcentajeValor relativo a una referencia que depende de la propiedad.
autoPalabra claveEl navegador determina el valor según la propiedad y el contexto.
0.9NúmeroValor numérico sin unidad.
calc(100% - 2rem)FunciónResultado de un cálculo realizado por CSS.
⚠️ Atención

No podemos añadir cualquier unidad a cualquier propiedad. Cada propiedad CSS admite unos tipos de valores determinados. Por ejemplo, width puede utilizar longitudes o porcentajes, mientras que opacity utiliza un número y no se escribe como 0.8px.

Unidades absolutas

Las unidades absolutas no dependen del tamaño de fuente de otro elemento ni de las dimensiones de su contenedor. CSS define varias unidades de este tipo, como px, cm, mm, in, pt y pc.

UnidadNombreUso habitual
pxPíxel CSSMuy utilizada en interfaces de pantalla para bordes y determinadas dimensiones.
cmCentímetroMás relacionada con medios físicos e impresión.
mmMilímetroMás relacionada con medios físicos e impresión.
inPulgadaUnidad física definida en CSS.
ptPuntoFrecuente tradicionalmente en tipografía e impresión.
pcPicaUnidad tipográfica poco habitual en interfaces web.
CSS
.tarjeta {
  border: 1px solid #d8dde3;
  border-radius: 8px;
}
📌 Idea clave

En diseño web, px es la unidad absoluta que encontraremos con mayor frecuencia. Un píxel CSS es una unidad de referencia y no tiene por qué corresponder exactamente con un único píxel físico de la pantalla.

Unidades relativas

Las unidades relativas calculan su valor a partir de otra referencia. Esto permite que una medida pueda variar según el tamaño de fuente o, en otros casos, según las dimensiones del área visible del navegador.

UnidadReferencia principalEjemplo
emDepende del tamaño de fuente correspondiente al elemento; su referencia exacta depende de la propiedad.padding: 1em;
remTamaño de fuente del elemento raíz (html).font-size: 1.25rem;
vw1% del ancho del viewport.width: 50vw;
vh1% de la altura del viewport.min-height: 100vh;

em y rem

Las unidades em y rem son especialmente útiles para relacionar medidas con el tamaño del texto. rem utiliza como referencia el tamaño de fuente del elemento raíz, mientras que em depende del contexto en el que se utiliza.

CSS
html {
  font-size: 16px;
}

.titulo {
  font-size: 2rem;
}

.boton {
  font-size: 1rem;
  padding: 0.75em 1.25em;
}

Si el tamaño de fuente raíz es 16px, 2rem equivale en ese contexto a 32px. En el botón, el padding expresado en em se relaciona con el tamaño de fuente del propio botón, por lo que el espacio interior puede crecer junto con su texto.

⚠️ Atención

em no significa simplemente “el tamaño de fuente del padre”. En font-size, un valor en em se calcula respecto al tamaño de fuente heredado del elemento padre; en otras propiedades, como padding, normalmente se relaciona con el tamaño de fuente calculado del propio elemento.

vw y vh

Las unidades vw y vh se calculan a partir del viewport, es decir, del área de visualización utilizada por el navegador. Por ejemplo, 50vw representa la mitad del ancho del viewport.

Estas unidades permiten relacionar determinadas dimensiones con el espacio disponible. Las utilizaremos con más contexto cuando estudiemos el diseño web responsive en la UT7.

⚠️ Atención

Evita utilizar unidades del viewport de forma automática para todo. Una interfaz debe seguir respetando la legibilidad, el contenido y las necesidades de las personas usuarias. La elección de la unidad debe responder al comportamiento que queremos conseguir.

Porcentajes

Los porcentajes expresan un valor relativo, pero su referencia no es siempre la misma. Depende de la propiedad en la que se utilicen y del contexto de formato del elemento.

HTML
<section class="panel">
  <article class="tarjeta">Próxima entrega</article>
</section>
CSS
.panel {
  width: 800px;
}

.tarjeta {
  width: 50%;
}

En este ejemplo sencillo, la tarjeta ocupa el 50% del ancho disponible de su contenedor. Si ese ancho de referencia es 800px, el resultado será de 400px.

📌 Importante

Un porcentaje no significa siempre “porcentaje del ancho del padre”. La referencia utilizada depende de la propiedad. Por eso, cuando trabajemos con porcentajes, debemos saber primero respecto a qué magnitud se calcula esa propiedad.

Funciones y valores útiles

CSS dispone de palabras clave y funciones que permiten expresar valores de forma más flexible. No es necesario memorizar todas las posibilidades: lo importante es comprender qué problema resuelve cada una.

auto

auto es una palabra clave cuyo comportamiento depende de la propiedad. Indica que el navegador debe determinar el valor siguiendo las reglas aplicables a esa propiedad y al contexto del elemento.

CSS
.tarjeta {
  width: 320px;
  margin-left: auto;
  margin-right: auto;
}

En determinadas condiciones, utilizar márgenes horizontales automáticos permite repartir el espacio disponible a ambos lados de un elemento y centrarlo horizontalmente.

calc()

La función calc() permite realizar cálculos con valores CSS y resulta especialmente útil cuando necesitamos combinar unidades diferentes.

CSS
.contenido {
  width: calc(100% - 2rem);
}

En este caso el ancho se obtiene restando 2rem al 100% de la referencia utilizada por la propiedad width.

min(), max() y clamp()

Las funciones min() y max() permiten elegir un valor a partir de varias expresiones, mientras que clamp() permite limitar un valor entre un mínimo y un máximo.

CSS
.panel {
  width: min(90%, 1000px);
}

.titulo {
  font-size: clamp(1.75rem, 4vw, 3rem);
}

En el primer ejemplo, CSS utiliza el menor de los valores indicados. En el segundo, clamp() establece un tamaño mínimo de 1.75rem, un valor preferido de 4vw y un máximo de 3rem. Más adelante veremos cómo este tipo de valores puede resultar útil en interfaces adaptables.

💻 Ejemplo DAW

En StudyFlow podemos combinar rem para tamaños y espaciados relacionados con el texto, % para aprovechar el espacio de un contenedor y px para bordes finos. La elección no debe hacerse por costumbre, sino según la relación que queramos mantener entre cada medida y su contexto.

💭 Piensa

Queremos crear una tarjeta de StudyFlow que no ocupe más del 90% del espacio disponible, tenga un ancho máximo de 700px y quede centrada horizontalmente. ¿Qué valores y unidades podríamos utilizar?

Ver solución

Una posible solución sería:

CSS
.tarjeta {
  width: 90%;
  max-width: 700px;
  margin-left: auto;
  margin-right: auto;
}

90% permite relacionar el ancho con el espacio disponible, max-width: 700px impide que la tarjeta crezca indefinidamente y los márgenes horizontales automáticos permiten centrarla cuando queda espacio libre.
