5.8 Fondos

Los fondos forman parte de la presentación visual de una interfaz y permiten diferenciar zonas, reforzar la jerarquía y aportar identidad al diseño. CSS ofrece distintas propiedades para aplicar colores e imágenes de fondo y controlar cómo se muestran dentro de los elementos.

En el apartado 5.6 aprendimos a representar colores en CSS. Ahora utilizaremos esos valores para definir fondos y estudiaremos cómo incorporar imágenes, repetirlas, posicionarlas y adaptar su tamaño.

📌 Importante

El fondo de un elemento forma parte de su presentación. No debe utilizarse como sustituto del contenido HTML cuando la imagen transmite información necesaria para comprender la página.

Color de fondo

La propiedad background-color establece el color de fondo de un elemento. Puede utilizar cualquiera de las formas de representar colores estudiadas en el apartado 5.6.

CSS
.tarjeta {
  background-color: #ffffff;
}

.aviso {
  background-color: rgb(224 155 39 / 15%);
}

.cabecera {
  background-color: var(--color-principal);
}

Si no se especifica otro valor, el fondo de un elemento es transparente. Esto permite que pueda verse el fondo de los elementos situados detrás de él.

💻 Ejemplo DAW

En StudyFlow podemos utilizar un fondo neutro para las tarjetas y fondos suaves para avisos o estados. El color debe responder a la función definida en la guía de estilo y no elegirse de forma aislada para cada componente.

Imágenes de fondo

La propiedad background-image permite utilizar una o varias imágenes como fondo de un elemento. Para indicar un archivo se utiliza normalmente la función url().

CSS
.hero {
  background-image: url("../img/cabecera.jpg");
}

La ruta de una imagen indicada mediante url() se interpreta normalmente con respecto a la ubicación del archivo CSS que contiene la declaración, no con respecto al documento HTML.

⚠️ Atención

Una imagen de fondo definida con CSS es decorativa desde el punto de vista del contenido y no dispone de un atributo alt. Si la imagen aporta información esencial, debe incorporarse al HTML mediante un elemento adecuado, como <img>, y proporcionar la alternativa correspondiente.

Color de respaldo

Cuando utilizamos una imagen de fondo puede ser conveniente definir también un color de fondo. Así el elemento mantiene una presentación razonable mientras la imagen se carga o si esta no puede mostrarse.

CSS
.hero {
  background-color: #1f6f43;
  background-image: url("../img/cabecera.jpg");
}

Varias imágenes de fondo

CSS permite declarar varias imágenes de fondo separándolas mediante comas. La primera se dibuja por encima de las siguientes.

CSS
.cabecera {
  background-image:
    url("../img/patron.png"),
    url("../img/fondo.jpg");
}

Repetición de fondos

Por defecto, una imagen de fondo puede repetirse horizontal y verticalmente para cubrir el área disponible. La propiedad background-repeat permite controlar este comportamiento.

ValorComportamiento
repeatRepite la imagen horizontal y verticalmente.
repeat-xRepite la imagen únicamente en horizontal.
repeat-yRepite la imagen únicamente en vertical.
no-repeatMuestra una sola copia de la imagen.
CSS
.hero {
  background-image: url("../img/cabecera.jpg");
  background-repeat: no-repeat;
}
📌 Idea clave

La repetición resulta especialmente útil con patrones o texturas diseñados para encajar entre sí. En fotografías o imágenes grandes suele utilizarse no-repeat y controlar después su posición y tamaño.

Posición del fondo

La propiedad background-position determina la posición inicial de una imagen de fondo dentro del elemento.

Podemos utilizar palabras clave como left, center, right, top y bottom, o expresar la posición mediante longitudes y porcentajes.

CSS
.hero {
  background-image: url("../img/cabecera.jpg");
  background-repeat: no-repeat;
  background-position: center center;
}

También podemos combinar posiciones horizontales y verticales:

CSS
.icono-fondo {
  background-image: url("../img/icono.svg");
  background-repeat: no-repeat;
  background-position: right 1rem top 1rem;
}

Tamaño del fondo

La propiedad background-size controla el tamaño con el que se representa la imagen de fondo. Puede recibir longitudes, porcentajes y valores especiales como cover y contain.

ValorComportamiento
autoMantiene el tamaño automático de la imagen.
coverEscala la imagen para cubrir todo el área de fondo, aunque alguna parte pueda quedar recortada.
containEscala la imagen para que pueda verse completa dentro del área, aunque quede espacio sin cubrir.
Longitudes o porcentajesPermiten establecer de forma explícita el ancho y, opcionalmente, el alto.
CSS
.hero {
  background-image: url("../img/cabecera.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
⚠️ Atención

cover no significa que la imagen vaya a verse completa. Su objetivo es cubrir el área disponible conservando sus proporciones, por lo que puede recortar parte de la imagen. contain, en cambio, prioriza que la imagen completa quepa dentro del área.

💻 Ejemplo DAW

Para una cabecera visual de StudyFlow podríamos utilizar background-position: center y background-size: cover. Después deberíamos comprobar que las zonas importantes de la imagen siguen siendo adecuadas en distintos tamaños de pantalla; el tratamiento responsive se estudiará con más detalle en la UT7.

Propiedad abreviada background

CSS dispone de la propiedad abreviada background, que permite reunir varias propiedades de fondo en una sola declaración.

CSS
.hero {
  background: #1f6f43 url("../img/cabecera.jpg") center / cover no-repeat;
}

En este ejemplo se combinan el color, la imagen, la posición, el tamaño y la repetición del fondo. La barra / separa la posición del valor correspondiente a background-size.

⚠️ Atención

Al utilizar la propiedad abreviada background, las propiedades de fondo que no se indiquen pueden restablecerse a sus valores iniciales. Por ello, conviene utilizarla conociendo qué valores estamos definiendo.

💻 Ejemplo DAW

En StudyFlow podemos utilizar fondos para distinguir tarjetas, cabeceras y avisos, pero evitando convertirlos en el único recurso para comunicar información. La elección debe mantenerse coherente con la paleta y la guía de estilo del proyecto.

💭 Piensa

Una cabecera utiliza una fotografía como fondo. Con background-size: cover ocupa toda la zona, pero en algunas pantallas desaparece una parte importante de la fotografía. ¿Por qué ocurre y qué aspectos deberíamos revisar antes de decidir que esa imagen es adecuada como fondo?

Ver solución

cover escala la imagen manteniendo sus proporciones hasta cubrir completamente el área disponible. Cuando las proporciones de la imagen y del contenedor son diferentes, parte de la imagen puede quedar fuera del área visible.

Debemos comprobar el encuadre, la posición del fondo y el comportamiento en distintos tamaños. Además, si la parte que desaparece contiene información necesaria para comprender el contenido, esa información no debería depender de una imagen decorativa de fondo.
