5.2 Selectores CSS

En el apartado anterior vimos que toda regla CSS comienza con un selector. Su función es indicar al navegador qué elementos HTML deben recibir unas determinadas declaraciones de estilo.

Elegir correctamente los selectores es fundamental para aplicar los estilos de forma precisa y mantener una hoja CSS clara y reutilizable. En este apartado comenzaremos con los selectores básicos y terminaremos combinándolos para expresar relaciones entre elementos.

📌 Importante

Un selector no modifica por sí mismo la apariencia de la página. Su función es seleccionar elementos; las declaraciones incluidas entre llaves indican qué estilos se aplicarán a esos elementos.

Selector universal

El selector universal se representa mediante un asterisco (*) y selecciona todos los elementos que se encuentren dentro del ámbito en el que se utiliza.

CSS
* {
  box-sizing: border-box;
}

En este ejemplo la propiedad box-sizing se aplicará a todos los elementos. Más adelante estudiaremos qué hace esta propiedad cuando trabajemos el modelo de caja.

El selector universal también puede formar parte de selectores más concretos. Por ejemplo, .tarjeta * seleccionaría todos los elementos descendientes de un elemento cuya clase fuera tarjeta.

⚠️ Atención

Que * pueda seleccionar todos los elementos no significa que debamos utilizarlo para asignar indiscriminadamente todos los estilos. Conviene escoger el selector que exprese con mayor claridad qué elementos queremos modificar.

Selector de tipo o etiqueta

El selector de tipo, también denominado selector de etiqueta, utiliza el nombre de un elemento HTML y selecciona todos los elementos de ese tipo.

CSS
h2 {
  color: #1f6f43;
}

p {
  line-height: 1.6;
}

La primera regla selecciona todos los elementos <h2> del documento y la segunda todos los elementos <p>. Es una forma sencilla de establecer estilos generales para un determinado tipo de contenido.

💻 Ejemplo DAW

En StudyFlow podríamos utilizar h2 para dar una apariencia común a todos los títulos de sección y p para establecer el interlineado general de los párrafos.

Selector de clase

El selector de clase permite aplicar un mismo conjunto de estilos a diferentes elementos. En HTML la clase se asigna mediante el atributo class y en CSS se selecciona escribiendo un punto (.) seguido del nombre de la clase.

HTML
<article class="tarjeta">
  <h2>Desarrollo Web en Entorno Cliente</h2>
</article>

<article class="tarjeta">
  <h2>Diseño de Interfaces Web</h2>
</article>
CSS
.tarjeta {
  padding: 20px;
  border: 1px solid #d8dde3;
}

Ambos elementos <article> tienen la clase tarjeta, por lo que reciben las mismas declaraciones. Una misma clase puede reutilizarse en numerosos elementos y un mismo elemento puede tener varias clases separadas por espacios.

HTML
<p class="aviso importante">Entrega disponible hasta el viernes.</p>
📌 Idea clave

Las clases son especialmente útiles para identificar componentes, funciones o patrones reutilizables. Por ello serán uno de los selectores que utilizaremos con mayor frecuencia en nuestros proyectos.

Selector de identificador

El atributo HTML id identifica de forma única un elemento dentro del documento. En CSS se selecciona escribiendo una almohadilla (#) seguida del valor del identificador.

HTML
<section id="proximas-entregas">
  <h2>Próximas entregas</h2>
</section>
CSS
#proximas-entregas {
  background-color: #f5f7f8;
}

A diferencia de una clase, un mismo valor de id no debe repetirse en varios elementos del mismo documento. Esto permite identificar un elemento concreto, aunque para estilos reutilizables suele ser preferible trabajar con clases.

⚠️ Atención

No elijas entre class e id pensando únicamente en cuál “tiene más fuerza” en CSS. Utiliza id cuando necesites identificar un elemento único y class cuando quieras describir estilos o componentes reutilizables. La especificidad de los selectores se estudiará en el apartado 5.4.

Selectores de atributo

Los selectores de atributo permiten seleccionar elementos HTML según la presencia de un determinado atributo o según el valor que tenga dicho atributo.

Para seleccionar todos los elementos que poseen un atributo concreto, escribimos el nombre del atributo entre corchetes.

CSS 
[required] {
  border: 1px solid #1f6f43;
}

En este ejemplo se seleccionan todos los elementos HTML que tengan el atributo required, independientemente del tipo de elemento del que se trate.

También podemos seleccionar elementos cuyo atributo tenga un valor determinado.

CSS 
input[type="email"] {
  border: 1px solid #1f6f43;
}

a[target="_blank"] {
  font-weight: bold;
}

El primer selector selecciona los elementos <input> cuyo atributo type tenga exactamente el valor email. El segundo selecciona los enlaces cuyo atributo target tenga el valor _blank.

Selector Selecciona
[required] Elementos que tienen el atributo required.
input[type="email"] Elementos input cuyo atributo type vale email.
a[target="_blank"] Enlaces cuyo atributo target vale _blank.
💻 Ejemplo DAW

En un formulario de StudyFlow podríamos utilizar input[type="email"] para aplicar un estilo específico al campo donde el usuario introduce su correo electrónico, sin necesidad de añadirle una clase adicional.

📌 Idea clave

Los selectores de atributo permiten aprovechar la información que ya contiene el HTML para seleccionar elementos de forma precisa, sin tener que añadir siempre nuevas clases o identificadores.

Agrupación de selectores

Cuando varios selectores deben compartir exactamente las mismas declaraciones, podemos escribirlos en una lista de selectores separada por comas. De esta forma evitamos repetir código.

CSS
h1,
h2,
h3 {
  font-family: Arial, sans-serif;
  color: #1f6f43;
}

Esta regla aplica las mismas declaraciones a h1, h2 y h3. La coma es importante: indica que estamos escribiendo varios selectores independientes que comparten un bloque de declaraciones.

⚠️ Atención

h1, h2 y h1 h2 no significan lo mismo. La primera expresión selecciona los elementos h1 y h2; la segunda expresa una relación de descendencia. Veremos estas relaciones a continuación.

Combinadores y relaciones entre elementos

La estructura HTML establece relaciones entre los elementos: unos pueden estar dentro de otros, ser hijos directos o aparecer como hermanos. Los combinadores CSS permiten aprovechar esas relaciones para construir selectores más precisos.

CombinadorEjemploSelecciona
Descendiente (espacio) .tarjeta p Todos los p que estén dentro de un elemento con clase tarjeta, aunque no sean hijos directos.
Hijo directo (>) nav > a Los enlaces a que sean hijos directos de nav.
Hermano adyacente (+) h2 + p El primer p que aparezca inmediatamente después de cada h2 y comparta el mismo padre.
Hermanos posteriores (~) h2 ~ p Los p posteriores a un h2 que compartan el mismo padre.

Selector descendiente

CSS
.tarjeta p {
  color: #4b5563;
}

La regla selecciona los párrafos que se encuentren dentro de elementos con clase tarjeta. Otros párrafos situados fuera de esas tarjetas no quedan seleccionados.

Selector de hijo directo

CSS
nav > a {
  text-decoration: none;
}

En este caso solo se seleccionan los enlaces que sean hijos directos de <nav>. Si un enlace estuviera dentro de otro elemento intermedio, no coincidiría con este selector.

Selectores de hermanos

CSS
h2 + p {
  font-weight: bold;
}

h2 ~ p {
  color: #4b5563;
}

El combinador + selecciona el hermano que aparece inmediatamente después, mientras que ~ puede seleccionar varios hermanos posteriores que cumplan el selector indicado.

💻 Ejemplo DAW

En StudyFlow podemos utilizar .tarjeta-actividad p para modificar únicamente los párrafos incluidos en las tarjetas de actividades, sin afectar a los demás párrafos de la aplicación. Así conseguimos reglas más precisas sin añadir clases innecesarias a cada elemento.

💭 Piensa

Observa este fragmento HTML:

HTML
<section class="panel">
  <h2>Avisos</h2>
  <p>Entrega de la práctica el viernes.</p>

  <div>
    <p>Consulta las instrucciones antes de entregar.</p>
  </div>
</section>

<p>Información general del curso.</p>

¿Qué párrafos seleccionaría .panel p? ¿Y cuáles seleccionaría .panel > p?

Ver una posible solución

.panel p seleccionaría los dos párrafos situados dentro de <section class="panel">, tanto el hijo directo como el que está dentro del <div>.

.panel > p seleccionaría únicamente “Entrega de la práctica el viernes.”, porque es el único <p> que es hijo directo de .panel.

El párrafo “Información general del curso.” no sería seleccionado por ninguno de los dos selectores porque se encuentra fuera del panel.
