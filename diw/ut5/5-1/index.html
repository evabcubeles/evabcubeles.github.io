5.1 Introducción a CSS

En la UT4 hemos utilizado HTML para definir la estructura y el significado del contenido de una interfaz web. Sin embargo, una misma estructura puede presentarse de muchas formas diferentes. Para controlar su apariencia utilizamos CSS (Cascading Style Sheets), o Hojas de Estilo en Cascada.

CSS permite definir, entre otros aspectos, colores, tipografías, tamaños, espacios, fondos, bordes y muchas otras características visuales. De esta forma podemos mantener separado el contenido de su presentación y aplicar un diseño coherente a toda la interfaz.

📌 Importante

HTML describe qué es y cómo se organiza el contenido; CSS define principalmente cómo se presenta visualmente. Esta separación facilita el mantenimiento y la reutilización de los estilos.

El papel de CSS en una interfaz web

Los navegadores aplican unos estilos predeterminados a los elementos HTML. Por eso, incluso una página sin una hoja de estilos propia muestra encabezados con distintos tamaños, enlaces diferenciados o listas con viñetas. CSS permite sustituir o complementar esos estilos para construir la apariencia que hemos definido para nuestra interfaz.

Mediante CSS podemos establecer una presentación común para muchos elementos y modificarla desde un único lugar. Esto resulta especialmente útil en sitios formados por varias páginas, donde interesa conservar la misma identidad visual.

🧱 HTML

Define la estructura y el significado del contenido.

🎨 CSS

Define la presentación visual de los elementos de la interfaz.

⚙️ JavaScript

Permite programar comportamiento e interacción dinámica.

💻 Ejemplo DAW

En StudyFlow, HTML puede identificar el nombre de una asignatura como encabezado y sus actividades como una lista. CSS puede decidir la tipografía, los colores, los espacios y el aspecto visual de esos elementos sin modificar su significado en HTML.

Reglas CSS: selector y declaración

Los estilos se expresan mediante reglas CSS. Una regla indica qué elementos queremos seleccionar y qué características de su presentación deseamos modificar.

CSS 
p {
  color: #2f4858;
  font-size: 18px;
}
p { color: #2f4858; }

Selector + bloque de declaraciones → propiedad + valor

Parte Función Ejemplo
Selector Indica qué elemento o conjunto de elementos se desea seleccionar. p
Bloque de declaraciones Contiene las declaraciones que se aplicarán a los elementos seleccionados. { color: #2f4858; font-size: 18px; }
Declaración Asocia una propiedad CSS con un valor. color: #2f4858;
Propiedad Indica la característica que queremos definir. color
Valor Indica el valor asignado a la propiedad. #2f4858

El selector se escribe antes de las llaves. Dentro de ellas se incluyen una o varias declaraciones. Cada declaración utiliza dos puntos para separar la propiedad de su valor y normalmente termina con un punto y coma.

⚠️ Atención

No confundas selector con propiedad. El selector indica sobre qué elementos actuará la regla; la propiedad indica qué característica queremos modificar.

Propiedades y valores

CSS dispone de numerosas propiedades. Cada una admite determinados tipos de valores según la característica que controla. Algunas reciben colores, otras longitudes, palabras clave, números, imágenes o combinaciones de varios valores.

CSS 
h1 {
  color: #1f6f43;
  font-size: 36px;
  text-align: center;
}

.aviso {
  background-color: #fff7e8;
  padding: 16px;
}

En este ejemplo, color, font-size, text-align, background-color y padding son propiedades. Sus valores indican respectivamente un color, un tamaño, una alineación, un color de fondo y un espacio interior. Estudiaremos estas propiedades con mayor detalle a lo largo de la unidad.

📌 Idea clave

Una declaración CSS sigue la forma propiedad: valor;. Una regla puede contener varias declaraciones y todas ellas se aplican a los elementos que coincidan con su selector, salvo que intervengan otros mecanismos de CSS que estudiaremos más adelante, como la cascada y la especificidad.

Formas de incorporar CSS

Existen varias formas de asociar estilos CSS con un documento HTML. Las tres más habituales son los estilos en línea, las hojas de estilo internas y las hojas de estilo externas.

Estilos en línea

Se escriben directamente en el atributo style de un elemento HTML.

HTML 
<p style="color: #1f6f43;">Actividad disponible</p>

Esta técnica puede resultar útil en situaciones muy concretas, pero mezcla estructura y presentación y dificulta reutilizar los estilos. Por ello no suele ser la opción adecuada para organizar el diseño general de un sitio web.

Hoja de estilo interna

Las reglas CSS se escriben dentro de un elemento <style>, normalmente situado en el <head> del documento.

HTML + CSS 
<head>
  <style>
    p {
      color: #1f6f43;
    }
  </style>
</head>

Los estilos quedan separados del contenido visible, pero siguen perteneciendo a un único documento HTML. Puede ser útil para ejemplos pequeños o páginas aisladas.

Hoja de estilo externa

Las reglas se guardan en un archivo independiente con extensión .css y el documento HTML lo enlaza mediante el elemento <link>.

HTML 
<head>
  <link rel="stylesheet" href="css/estilos.css">
</head>
css/estilos.css 
p {
  color: #1f6f43;
}

Esta opción permite reutilizar la misma hoja de estilos en diferentes documentos HTML, centralizar los cambios de diseño y mantener mejor separadas la estructura y la presentación. Será la forma que utilizaremos habitualmente en los ejemplos y proyectos del módulo.

Hojas de estilo alternativas

Un mismo documento HTML puede disponer de varias hojas de estilo que permitan presentar su contenido con apariencias diferentes. Estas se conocen como hojas de estilo alternativas.

En HTML podemos indicar una hoja de estilo principal mediante rel="stylesheet" y declarar otras como alternativas utilizando rel="alternate stylesheet" y el atributo title.

HTML 
<link rel="stylesheet" href="css/estilos.css">

<link
  rel="alternate stylesheet"
  href="css/alto-contraste.css"
  title="Alto contraste"
>

En este ejemplo, estilos.css contiene la presentación principal del sitio, mientras que alto-contraste.css define una presentación alternativa.

📌 Importante

Las hojas de estilo alternativas permiten separar el contenido de sus distintas presentaciones. El documento HTML puede mantenerse igual mientras cambia la apariencia aplicada mediante CSS.

⚠️ En la web actual

Aunque HTML permite declarar hojas de estilo alternativas, los navegadores actuales no siempre ofrecen al usuario una interfaz para seleccionarlas. Por ello, en aplicaciones web modernas es habitual implementar cambios de tema mediante clases o atributos en el documento, propiedades personalizadas de CSS y, cuando es necesario, JavaScript.

💻 Ejemplo DAW

StudyFlow podría disponer de una presentación principal y otra de alto contraste. Ambas mantendrían la misma estructura HTML y el mismo contenido, pero aplicarían diferentes decisiones visuales mediante CSS.

Forma Dónde se escribe CSS Uso habitual
En línea En el atributo style del elemento. Casos puntuales; poco recomendable para organizar un sitio completo.
Interna En un elemento <style> del documento. Ejemplos o páginas aisladas.
Externa En un archivo .css enlazado con <link>. Proyectos y sitios con estilos reutilizables.

Organización básica de una hoja de estilos

A medida que una interfaz crece, también aumenta el número de reglas CSS. Por eso conviene mantener desde el principio una organización clara y un formato consistente.

CSS organizado 
/* Encabezados */

h1 {
  color: #1f6f43;
  font-size: 36px;
}


/* Avisos */

.aviso {
  padding: 16px;
  background-color: #fff7e8;
}

Es recomendable utilizar una indentación uniforme, separar visualmente los grupos de reglas, emplear nombres de clases comprensibles y añadir comentarios cuando realmente ayuden a entender la organización de la hoja de estilos.

Los comentarios CSS se escriben entre /* y */. El navegador los ignora al aplicar los estilos, pero pueden facilitar la lectura y el mantenimiento del código.

⚠️ Atención

Evita utilizar nombres de clase ligados únicamente a una apariencia concreta, como .texto-rojo, cuando la clase representa en realidad una función o componente. Nombres como .aviso o .mensaje-error suelen expresar mejor su propósito.

💻 Ejemplo DAW

En StudyFlow podemos guardar los estilos generales en css/estilos.css y enlazar esa misma hoja desde las distintas páginas del proyecto. Si modificamos allí el aspecto de las tarjetas de actividades, el cambio podrá aplicarse de forma coherente en todas las páginas que utilicen esos estilos.

💭 Piensa

Un proyecto contiene seis páginas HTML. En cada una se han repetido los mismos estilos dentro de atributos style. Ahora el equipo quiere cambiar el color y el tamaño de todos los títulos del sitio.

¿Qué problema plantea esta organización? ¿Cómo reorganizarías los estilos para facilitar el mantenimiento del proyecto?

Ver una posible solución

Los estilos están repetidos y cualquier cambio debe realizarse en numerosos lugares, lo que aumenta el trabajo y el riesgo de introducir inconsistencias.

Una solución adecuada sería trasladar las reglas comunes a una hoja de estilo externa y enlazarla desde las distintas páginas HTML. Así, una modificación realizada en el archivo CSS común puede afectar a todas las páginas que utilicen esa hoja de estilos.
