5.6 Colores en CSS

En la UT2 estudiamos el color desde el punto de vista del diseño: armonía, contraste, legibilidad e identidad visual. Ahora vamos a trasladar esas decisiones al código y aprender cómo representar y aplicar colores mediante CSS.

CSS permite expresar un mismo color de distintas formas. Elegir una sintaxis u otra no cambia por sí sola la calidad del diseño, pero conocerlas nos permite interpretar hojas de estilo, trabajar con transparencia y mantener una paleta de colores coherente.

📌 Importante

El color en CSS no se limita al texto. Muchas propiedades aceptan valores de color, por ejemplo color, background-color, border-color o text-decoration-color. En este apartado aprenderemos las formas de expresar esos valores.

La propiedad color

La propiedad color establece principalmente el color del texto de un elemento. Además, su valor puede servir como referencia para otras propiedades que utilizan currentColor.

HTML
<h2 class="titulo-panel">Próximas entregas</h2>
<p class="mensaje">Tienes dos actividades pendientes.</p>
CSS
.titulo-panel {
  color: #1f6f43;
}

.mensaje {
  color: #374151;
}

Como vimos al estudiar la herencia, color es una propiedad heredable. Si asignamos un color a un elemento contenedor, sus descendientes pueden heredarlo cuando no tengan otro valor aplicable para esa propiedad.

💻 Ejemplo DAW

En StudyFlow podemos definir un color general para el texto de una zona y reservar colores específicos para títulos, enlaces, avisos o estados. Así evitamos asignar un color diferente a cada elemento sin una razón de diseño.

Nombres de color

CSS dispone de nombres de color predefinidos que pueden escribirse directamente como valor. Algunos ejemplos habituales son black, white, red, blue, green o orange.

CSS
.error {
  color: red;
}

.aviso {
  color: orange;
}

Los nombres son cómodos para ejemplos sencillos, pruebas o colores muy concretos, pero una interfaz profesional suele necesitar una paleta más precisa. Para ello son más habituales otras notaciones como hexadecimal, RGB o HSL.

⚠️ Atención

El nombre de un color no describe necesariamente su función dentro de la interfaz. Es preferible pensar en colores con significado de diseño —principal, texto, fondo, aviso, error— y no construir la estructura de estilos alrededor de nombres como “rojo” o “verde”.

Notación hexadecimal

La notación hexadecimal representa los componentes rojo, verde y azul mediante números en base 16. Se escribe con el carácter # seguido normalmente de seis dígitos: #RRGGBB.

ParteComponenteRango
RRRojo00 a FF
GGVerde00 a FF
BBAzul00 a FF
CSS
.principal {
  color: #1f6f43;
}

.texto {
  color: #374151;
}

.fondo {
  background-color: #f3f4f6;
}

Cada pareja puede representar 256 niveles, desde 00 hasta FF. Por ejemplo, #000000 representa negro y #ffffff representa blanco.

Forma abreviada

Cuando cada pareja está formada por dos dígitos iguales, la notación puede abreviarse a tres caracteres. Por ejemplo, #ffffff puede escribirse como #fff y #336699 como #369.

📌 Idea clave

La forma abreviada no reduce la precisión de un color que ya puede representarse de ese modo: cada dígito se duplica al interpretarlo. Por ejemplo, #369 equivale exactamente a #336699.

RGB y transparencia

La función rgb() permite expresar un color mediante sus componentes rojo, verde y azul. Una forma muy extendida utiliza valores entre 0 y 255 para cada componente.

CSS
.principal {
  color: rgb(31, 111, 67);
}

.texto {
  color: rgb(55, 65, 81);
}

En la sintaxis moderna también podemos escribir los componentes separados por espacios y añadir un canal alfa después de una barra. El canal alfa controla la transparencia del color.

CSS
.aviso {
  background-color: rgb(224 155 39 / 20%);
}

.superposicion {
  background-color: rgb(0 0 0 / 0.5);
}

Un alfa de 0 significa transparencia total y un alfa de 1 opacidad total. También puede expresarse mediante porcentajes, como 20%.

⚠️ Atención

Aplicar transparencia al propio color no es lo mismo que utilizar la propiedad opacity. Un color con canal alfa afecta únicamente a ese color. opacity, en cambio, modifica la opacidad del elemento completo, incluido su contenido.

¿Y rgba()?

También encontraremos código escrito con rgba(), por ejemplo rgba(0, 0, 0, 0.5). Esta sintaxis sigue siendo válida. En CSS moderno, rgb() puede incluir directamente el canal alfa, por lo que no es obligatorio utilizar una función diferente para representar transparencia.

HSL

La función hsl() representa el color mediante matiz (Hue), saturación (Saturation) y luminosidad (Lightness). Estos conceptos ya los trabajamos desde el punto de vista visual en la UT2; aquí nos interesa su representación en CSS.

ComponenteQué representaEjemplo
H — MatizPosición en el círculo cromático.145
S — SaturaciónIntensidad o pureza relativa del color.56%
L — LuminosidadGrado de claridad u oscuridad.28%
CSS
.principal {
  color: hsl(145 56% 28%);
}

.principal-suave {
  background-color: hsl(145 56% 28% / 12%);
}

HSL puede resultar cómodo cuando queremos crear variaciones relacionadas de un mismo color, modificando de forma comprensible su saturación o luminosidad.

📌 Importante

Hexadecimal, RGB y HSL no son “niveles de calidad” distintos. Son diferentes formas de expresar colores en CSS. La elección depende de las necesidades del proyecto, de la legibilidad del código y de cómo queramos trabajar con la paleta.

Buenas prácticas en el uso del color

Saber escribir un color en CSS no garantiza que la interfaz esté bien diseñada. Las decisiones sobre color deben seguir los principios estudiados en la UT2 y mantenerse de forma coherente durante todo el proyecto.

  • Mantén una paleta coherente: reutiliza los mismos colores para las mismas funciones.
  • Garantiza un contraste suficiente: texto y fondo deben poder distinguirse con claridad.
  • No dependas únicamente del color: un error o un estado importante debe disponer también de otra señal comprensible.
  • Evita colores arbitrarios: cada color debería responder a una función dentro de la guía de estilo.
  • Comprueba estados interactivos: enlaces, botones y controles deben seguir siendo reconocibles en sus distintos estados.
⚠️ Atención

No debemos utilizar únicamente verde para indicar “correcto” y rojo para indicar “error”. Podemos acompañar el color con texto, iconos, símbolos o mensajes que permitan comprender el estado aunque la persona no perciba la diferencia cromática.

Colores y guía de estilo

En un proyecto real conviene centralizar la paleta para evitar repetir valores sin control. Una forma moderna de hacerlo es utilizar propiedades personalizadas de CSS (custom properties), que se definen con nombres precedidos por -- y se consultan mediante la función var().

CSS
:root {
  --color-principal: #1f6f43;
  --color-texto: #374151;
  --color-fondo: #f3f4f6;
  --color-error: #b42318;
}

body {
  color: var(--color-texto);
  background-color: var(--color-fondo);
}

.boton-principal {
  color: #fff;
  background-color: var(--color-principal);
}

Así, si cambia un color de la identidad visual, podemos modificar su valor en un único lugar y reutilizarlo en toda la interfaz. Además, nombres como --color-principal o --color-error expresan la función del color en lugar de describir simplemente su apariencia.

💻 Ejemplo DAW

En StudyFlow podemos trasladar la paleta definida en su guía de estilo a propiedades personalizadas. De este modo, tarjetas, botones, avisos y textos comparten los mismos valores y cualquier cambio posterior puede realizarse de forma centralizada.

💭 Piensa

Una aplicación utiliza #1f6f43 como color principal en veinte reglas CSS diferentes. El cliente decide sustituirlo por otro tono. ¿Qué ventaja tendría haber definido ese color como una propiedad personalizada?

Ver solución

Si el color estuviera definido, por ejemplo, como --color-principal, bastaría con modificar su valor en la definición central. Todas las reglas que utilicen var(--color-principal) recibirían el nuevo valor sin tener que localizar y cambiar manualmente las veinte apariciones.
