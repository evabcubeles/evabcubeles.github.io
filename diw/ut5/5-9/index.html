5.9 El modelo de caja

En CSS, los elementos que forman una página se representan mediante cajas rectangulares. Comprender cómo se calculan sus dimensiones y el espacio que ocupan es fundamental para controlar correctamente la presentación de una interfaz.

El modelo de caja o box model describe las distintas áreas que rodean al contenido de un elemento: contenido, relleno, borde y margen.

📌 Importante

Cuando vemos un elemento en una página web no debemos pensar únicamente en su contenido. CSS calcula una caja formada por varias áreas que influyen en el tamaño y en la separación respecto a otros elementos.

Concepto de modelo de caja

De dentro hacia fuera, el modelo de caja está formado por cuatro áreas principales:

ÁreaFunción
Contenido (content)Zona en la que se muestra el texto, una imagen u otro contenido del elemento.
Relleno (padding)Espacio entre el contenido y el borde.
Borde (border)Línea o contorno que rodea al contenido y al relleno.
Margen (margin)Espacio exterior que separa la caja de otros elementos.

De fuera hacia dentro:

margin → border → padding → content

El margen queda fuera del borde; el relleno queda entre el borde y el contenido.

CSS
.tarjeta {
  width: 300px;
  padding: 20px;
  border: 2px solid #d1d5db;
  margin: 24px;
}
💻 Ejemplo DAW

Una tarjeta de StudyFlow puede tener un área de contenido para el título y la descripción, un padding que evite que el texto quede pegado al borde, un borde que delimite visualmente el componente y un margin que lo separe de otras tarjetas.

Área de contenido

El área de contenido es la zona más interna de la caja. En ella se representa el contenido del elemento. Propiedades como width y height permiten controlar sus dimensiones, aunque su efecto exacto depende, entre otros factores, del valor de box-sizing, que estudiaremos al final del apartado.

CSS
.panel {
  width: 400px;
  height: 200px;
}

También podemos limitar las dimensiones mediante propiedades como min-width, max-width, min-height y max-height.

CSS
.panel {
  width: 90%;
  max-width: 700px;
  min-height: 200px;
}
⚠️ Atención

Asignar una altura fija puede provocar problemas si el contenido necesita más espacio del previsto. En interfaces web suele ser preferible permitir que la altura se adapte al contenido o utilizar límites cuando sean necesarios.

Relleno: padding

El padding es el espacio interior situado entre el contenido y el borde del elemento. Aumentarlo separa visualmente el contenido de los límites de la caja.

CSS
.tarjeta {
  padding: 20px;
}

Podemos controlar cada lado por separado mediante padding-top, padding-right, padding-bottom y padding-left.

CSS
.tarjeta {
  padding-top: 16px;
  padding-right: 24px;
  padding-bottom: 16px;
  padding-left: 24px;
}

Propiedad abreviada padding

La propiedad abreviada puede recibir entre uno y cuatro valores:

SintaxisAplicación
padding: 20px;Los cuatro lados.
padding: 10px 20px;Vertical (arriba/abajo) y horizontal (derecha/izquierda).
padding: 10px 20px 30px;Arriba, horizontal (derecha/izquierda) y abajo.
padding: 10px 20px 30px 40px;Arriba, derecha, abajo e izquierda, en sentido horario.
📌 Idea clave

En la forma abreviada de cuatro valores podemos recordar el orden siguiendo las agujas del reloj: arriba → derecha → abajo → izquierda.

Borde: border

El borde rodea el área de contenido y el padding. Sus características principales son el grosor, el estilo y el color.

CSS
.tarjeta {
  border-width: 2px;
  border-style: solid;
  border-color: #d1d5db;
}

La propiedad abreviada border permite reunir esos valores:

CSS
.tarjeta {
  border: 2px solid #d1d5db;
}

También existen propiedades específicas para cada lado, como border-top, border-right, border-bottom y border-left.

📌 Importante

Para que un borde sea visible debe existir un estilo de borde distinto de none. Definir únicamente un color no hace aparecer por sí solo un borde visible.

Margen: margin

El margin es el espacio exterior de la caja. Se utiliza para separar un elemento de los elementos que lo rodean.

CSS
.tarjeta {
  margin: 24px;
}

Al igual que padding, puede definirse por lados mediante margin-top, margin-right, margin-bottom y margin-left, y su forma abreviada utiliza el mismo orden de uno a cuatro valores.

El valor auto

En determinados contextos, auto permite que el navegador calcule automáticamente el margen disponible. Un uso clásico es centrar horizontalmente un elemento de bloque que tenga un ancho menor que el espacio disponible.

CSS
.panel {
  width: 80%;
  max-width: 900px;
  margin: 0 auto;
}

Colapso de márgenes

En determinadas situaciones del flujo normal, los márgenes verticales de elementos de bloque pueden colapsar: en lugar de sumarse, se combinan siguiendo las reglas de CSS.

Por ejemplo, si dos párrafos consecutivos tienen margin-bottom: 20px y margin-top: 30px, la separación vertical habitual entre ellos será de 30px, no de 50px.

⚠️ Atención

El colapso de márgenes no afecta a todos los márgenes ni ocurre en cualquier tipo de maquetación. Es un comportamiento propio de determinadas situaciones del flujo normal; por ejemplo, los márgenes de los elementos flex y grid no colapsan de esta forma.

box-sizing

La propiedad box-sizing determina cómo se calculan las dimensiones declaradas de una caja. Sus dos valores más importantes son content-box y border-box.

content-box

content-box es el comportamiento inicial. Con este modelo, width y height se aplican al área de contenido. El padding y el borde se añaden después.

CSS
.caja {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
}

En este caso, el ancho total ocupado por la caja, sin contar los márgenes, es:

300 + 20 + 20 + 2 + 2 = 344px

contenido + padding izquierdo y derecho + borde izquierdo y derecho

border-box

Con border-box, el valor declarado en width incluye el contenido, el padding y el borde. Esto hace que el tamaño final de los componentes resulte normalmente más fácil de controlar.

CSS
.caja {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
}

Ahora el ancho exterior de la caja, sin contar el margen, sigue siendo 300px. El espacio disponible para el contenido se reduce para alojar dentro de ese ancho el relleno y los bordes.

📌 Práctica habitual

Es frecuente utilizar box-sizing: border-box de forma general para que el cálculo de tamaños sea más predecible.

CSS
*,
*::before,
*::after {
  box-sizing: border-box;
}
💻 Ejemplo DAW

Si las tarjetas de StudyFlow tienen width: 300px, padding: 20px y un borde, utilizar border-box permite mantener esos 300px como ancho exterior de referencia sin tener que sumar manualmente el relleno y el borde.

💭 Piensa

Una caja tiene width: 400px, padding: 20px a ambos lados y un borde de 5px a ambos lados. ¿Qué ancho exterior tendrá con content-box? ¿Y con border-box?

Ver solución

Con content-box, los 400px corresponden únicamente al contenido. El ancho exterior será 400 + 20 + 20 + 5 + 5 = 450px.

Con border-box, los 400px incluyen contenido, relleno y borde, por lo que el ancho exterior será 400px, sin contar posibles márgenes.
