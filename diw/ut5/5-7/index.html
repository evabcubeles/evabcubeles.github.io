5.7 Tipografía y texto

En la UT2 estudiamos la tipografía como elemento visual de una interfaz: legibilidad, jerarquía, coherencia y elección de familias tipográficas. En este apartado vamos a trasladar esas decisiones al código mediante las propiedades CSS que controlan la apariencia y presentación del texto.

CSS permite elegir la familia tipográfica, modificar el tamaño, el estilo y el grosor de los caracteres, controlar el interlineado, alinear el texto y aplicar distintas formas de decoración. Estas propiedades deben utilizarse de manera coherente con la guía de estilo del proyecto.

📌 Importante

La tipografía no debe utilizarse únicamente para “hacer bonito” el contenido. Tamaño, grosor, interlineado y espaciado influyen directamente en la jerarquía visual y en la legibilidad de una interfaz.

Familias tipográficas

La propiedad font-family indica qué familia tipográfica debe utilizar el navegador para representar el texto. Es habitual proporcionar varias fuentes en orden de preferencia para disponer de alternativas si alguna no está disponible.

CSS
body {
  font-family: Arial, Helvetica, sans-serif;
}

El navegador intenta utilizar primero Arial. Si no está disponible, prueba Helvetica y, como última alternativa, utiliza una fuente perteneciente a la familia genérica sans-serif.

Familias genéricas

Familia genéricaDescripciónUso orientativo
serifTipografías con remates o serifas.Textos o diseños donde se busque ese estilo tipográfico.
sans-serifTipografías sin serifas.Muy habitual en interfaces digitales.
monospaceTodos los caracteres ocupan el mismo ancho.Código, terminales o datos técnicos.
cursiveTipografías de apariencia manuscrita.Usos decorativos puntuales.
fantasyTipografías principalmente decorativas.Títulos o usos muy específicos.
⚠️ Atención

Si el nombre de una fuente contiene espacios, debe escribirse entre comillas, por ejemplo "Trebuchet MS". Además, conviene terminar la lista con una familia genérica para disponer de una alternativa final.

CSS
.titulo {
  font-family: "Trebuchet MS", Arial, sans-serif;
}
.codigo {
  font-family: Consolas, "Courier New", monospace;
}
💻 Ejemplo DAW

En StudyFlow podemos utilizar una pila tipográfica coherente para toda la interfaz y reservar monospace para fragmentos de código o información técnica. De esta forma mantenemos una identidad visual uniforme sin depender de que una única fuente esté instalada.

Tamaño de fuente

La propiedad font-size establece el tamaño del texto. Puede utilizar diferentes tipos de valores, entre ellos unidades absolutas y relativas que ya estudiamos en el apartado 5.5.

CSS
body {
  font-size: 1rem;
}
h1 {
  font-size: 2.5rem;
}
.texto-secundario {
  font-size: 0.875rem;
}

Utilizar unidades relativas como rem facilita mantener una escala tipográfica relacionada con el tamaño base del documento. No significa que px sea incorrecto, sino que la unidad debe elegirse según la relación que queramos establecer.

📌 Idea clave

Una interfaz necesita una jerarquía tipográfica reconocible. Los tamaños deben ayudar a distinguir títulos, subtítulos, texto principal y contenido secundario, no elegirse de forma arbitraria para cada elemento.

Estilo y grosor

font-style

La propiedad font-style controla principalmente si el texto se muestra con estilo normal o inclinado. Sus valores más habituales son normal, italic y oblique.

CSS
.nota {
  font-style: italic;
}

italic solicita la variante cursiva de la fuente cuando existe, mientras que oblique representa una forma inclinada. El resultado concreto depende de la familia tipográfica utilizada y de las variantes disponibles.

font-weight

La propiedad font-weight controla el grosor de los caracteres. Puede utilizar palabras clave como normal y bold, además de valores numéricos.

CSS
.titulo {
  font-weight: 700;
}
.texto {
  font-weight: 400;
}

En muchas familias tipográficas, 400 corresponde al grosor normal y 700 al negrita. Sin embargo, no todas las fuentes disponen de todos los grosores posibles, por lo que el navegador puede utilizar el valor disponible más adecuado.

⚠️ Atención

No debemos utilizar únicamente cambios de tamaño o grosor para sustituir la estructura semántica del HTML. Un encabezado debe seguir siendo un elemento <h1>, <h2>, etc., aunque CSS permita dar a cualquier texto una apariencia similar.

Interlineado

La propiedad line-height controla la altura de la línea y, por tanto, el espacio vertical disponible entre líneas de texto. Un interlineado adecuado facilita la lectura, especialmente en párrafos largos.

CSS
p {
  font-size: 1rem;
  line-height: 1.6;
}

Cuando se utiliza un número sin unidad, como 1.6, la altura de línea se calcula multiplicando ese valor por el tamaño de fuente del propio elemento. Esta forma suele resultar cómoda porque mantiene una relación proporcional con el texto.

📌 Importante

line-height: 1.6 no significa 1.6px. Es un multiplicador sin unidad. Si el tamaño de fuente es 16px, la altura de línea calculada será 25.6px.

Alineación del texto

La propiedad text-align controla la alineación horizontal del contenido en línea dentro de un elemento de bloque. Entre sus valores más conocidos se encuentran left, right, center y justify.

CSS
.titulo {
  text-align: center;
}
.parrafo {
  text-align: left;
}

También existen valores lógicos como start y end, que se adaptan a la dirección de escritura del documento. Por ejemplo, start suele corresponder a la izquierda en textos escritos de izquierda a derecha y a la derecha en escrituras de derecha a izquierda.

⚠️ Atención

El texto justificado puede producir espacios irregulares entre palabras, especialmente en columnas estrechas. En interfaces web conviene comprobar siempre el resultado real y priorizar la legibilidad.

Decoración y otras propiedades de texto

text-decoration

La propiedad text-decoration permite añadir o controlar decoraciones como el subrayado. Es especialmente frecuente en enlaces.

CSS
a {
  text-decoration: underline;
}
a:hover {
  text-decoration: none;
}

CSS moderno permite controlar distintos aspectos de la decoración mediante propiedades como text-decoration-line, text-decoration-color, text-decoration-style y text-decoration-thickness.

⚠️ Atención

El subrayado es una convención visual muy asociada a los enlaces. Si se elimina, debemos asegurarnos de que el enlace siga siendo claramente identificable mediante otras señales visuales y sus estados de interacción.

Otras propiedades útiles

PropiedadFunciónEjemplo
text-transformControla transformaciones como mayúsculas o minúsculas.uppercase
text-indentEstablece la sangría de la primera línea.2rem
letter-spacingModifica el espacio entre caracteres.0.05em
word-spacingModifica el espacio entre palabras.0.2em
white-spaceControla cómo se tratan los espacios y saltos de línea.nowrap
CSS
.etiqueta {
  text-transform: uppercase;
  letter-spacing: 0.05em;
}
.descripcion {
  line-height: 1.6;
}
.codigo-corto {
  white-space: nowrap;
}
💻 Ejemplo DAW

En StudyFlow podemos definir una escala coherente para títulos, textos y etiquetas, mantener un interlineado legible y reservar transformaciones como las mayúsculas para componentes concretos. Estas decisiones deben corresponderse con la guía de estilo definida para la interfaz.

💭 Piensa

En StudyFlow se ha aplicado font-size: 14px, font-weight: 700 y text-transform: uppercase a todos los textos de la aplicación para que “destaquen más”. ¿Por qué esta decisión puede perjudicar la jerarquía visual y la legibilidad?

Ver solución

Si todos los textos tienen prácticamente la misma apariencia, desaparecen las diferencias visuales que permiten reconocer títulos, contenido principal, información secundaria o etiquetas. Además, el uso generalizado de negrita y mayúsculas puede dificultar la lectura. Lo adecuado es establecer una jerarquía tipográfica coherente y reservar esos recursos para los elementos que realmente los necesitan.
