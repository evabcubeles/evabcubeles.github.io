UT7 - Diseño web responsive

En la UT6 aprendimos a distribuir los elementos de una interfaz web utilizando el flujo normal del documento, técnicas de posicionamiento, Flexbox y CSS Grid. Ahora aplicaremos esos conocimientos para crear páginas que se adapten correctamente a diferentes tamaños de pantalla.

Comenzaremos comprendiendo qué es el diseño web responsive y cómo influye el viewport en la visualización de una página. Después utilizaremos unidades flexibles, media queries y puntos de ruptura para adaptar el diseño al espacio disponible.

También compararemos las estrategias mobile first y desktop first, aplicaremos Flexbox y Grid a diseños adaptables y aprenderemos a preparar imágenes y contenidos multimedia para distintas pantallas.

Finalmente, conoceremos el sistema de rejilla de Bootstrap 5 y comprobaremos el resultado con las herramientas de desarrollo del navegador. Continuaremos trabajando sobre StudyFlow, transformando la interfaz que hemos construido en las unidades anteriores en una experiencia cómoda para móviles, tabletas y ordenadores.
