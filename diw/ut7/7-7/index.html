7.7 Frameworks responsive: Bootstrap 5

En el apartado 7.6 aprendimos a adaptar imágenes y vídeos a diferentes pantallas. Hasta ahora hemos construido nuestros diseños responsive escribiendo directamente HTML y CSS, utilizando media queries, Flexbox y CSS Grid.

En este apartado conoceremos Bootstrap 5, un framework CSS que proporciona un sistema de cuadrícula, componentes y clases de utilidad para desarrollar interfaces responsive de forma más rápida. Seguiremos utilizando StudyFlow como ejemplo.

📌 Importante

Bootstrap no sustituye los conocimientos de CSS. Sus clases aplican estilos ya preparados, pero para utilizarlas correctamente debemos comprender los contenedores, las columnas y los puntos de ruptura.

Qué es Bootstrap y para qué sirve

Un framework CSS es un conjunto organizado de estilos, componentes y convenciones reutilizables. Bootstrap 5 incluye una cuadrícula basada en Flexbox, utilidades de espaciado y visualización, y componentes como tarjetas, barras de navegación y botones.

Su principal ventaja es que permite construir una base visual coherente sin escribir todas las reglas desde cero. Sin embargo, no todos los proyectos necesitan Bootstrap: en interfaces pequeñas puede resultar suficiente utilizar CSS propio.

💻 Ejemplo DAW

En StudyFlow podemos utilizar Bootstrap para distribuir los módulos DWEC, DIW y SASP en tarjetas: una columna en móviles, dos en pantallas medianas y tres en pantallas grandes.

Cómo incorporar Bootstrap 5

Una forma sencilla de comenzar es incluir la hoja de estilos de Bootstrap mediante un CDN. El siguiente ejemplo utiliza Bootstrap 5.3.3 para que los ejemplos mantengan una versión concreta.

HTML · Página mínima con Bootstrap 5
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>StudyFlow con Bootstrap</title>
  <link rel="stylesheet"
        href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
</head>
<body>
  <main class="container py-4">
    <h1>StudyFlow</h1>
    <p>Panel de módulos formativos.</p>
  </main>
</body>
</html>

La clase container aplica un contenedor adaptable y py-4 añade espacio vertical. La etiqueta meta name="viewport" sigue siendo necesaria para que el diseño se adapte correctamente en dispositivos móviles.

⚠️ Atención

Este ejemplo requiere conexión a Internet para descargar Bootstrap desde el CDN. En un proyecto real también podemos instalarlo o alojar sus archivos localmente. El JavaScript de Bootstrap solo es necesario para determinados componentes interactivos, no para utilizar su cuadrícula o sus clases CSS.

Contenedores y puntos de ruptura

Bootstrap dispone de contenedores que organizan y limitan la anchura del contenido. .container cambia su anchura máxima según el punto de ruptura; .container-fluid ocupa el 100 % del ancho disponible.

HTML · Dos tipos de contenedor
<div class="container">
  <p>Contenido con anchura máxima adaptable.</p>
</div>

<div class="container-fluid">
  <p>Contenido que ocupa todo el ancho disponible.</p>
</div>

Bootstrap 5 utiliza los siguientes puntos de ruptura mínimos. Las clases sin sufijo se aplican desde el tamaño más pequeño; los sufijos indican desde qué anchura del viewport comienza a aplicarse una regla.

NombrePrefijoAnchura mínima
Extra pequeñoSin sufijoMenos de 576 px (estilos base)
Pequeñosm576 px
Medianomd768 px
Grandelg992 px
Extra grandexl1200 px
Extra extra grandexxl1400 px

Por ejemplo, col-md-6 se aplica desde 768 px en adelante. Esto responde a una estrategia mobile first: primero definimos el comportamiento base y después incorporamos cambios para pantallas más amplias.

Sistema de cuadrícula responsive

La cuadrícula de Bootstrap se organiza mediante tres elementos principales: .container, que delimita el espacio disponible; .row, que agrupa las columnas; y .col, que representa cada columna de contenido.

Bootstrap utiliza un sistema de 12 columnas virtuales. Esto significa que podemos repartir la anchura de una fila en doce partes. Por ejemplo, col-12 ocupa las doce partes (100 %), col-6 ocupa seis (50 %) y col-4 ocupa cuatro (aproximadamente el 33,33 %).

Si añadimos un sufijo responsive, como col-md-6, indicamos que esa distribución se aplicará desde el punto de ruptura correspondiente. En este caso, la columna ocupará seis de las doce partes a partir de 768 px.

HTML · Una columna en móvil y dos desde md
<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-6">
      <div class="p-3 border rounded">DWEC</div>
    </div>
    <div class="col-12 col-md-6">
      <div class="p-3 border rounded">DIW</div>
    </div>
  </div>
</div>

La clase .row agrupa las columnas, mientras que g-3 establece una separación horizontal y vertical entre ellas mediante los gutters de Bootstrap. En la configuración predeterminada de Bootstrap 5, g-3 equivale a un espaciado de 1 rem (normalmente 16 px).

Cada columna ocupa toda la fila por debajo de 768 px y la mitad a partir de ese ancho. En este ejemplo, las clases de anchura se aplican a los elementos que son hijos de .row.

HTML · Una, dos o tres columnas según el viewport
<div class="container py-4">
  <div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4">DWEC</div>
    <div class="col-12 col-md-6 col-lg-4">DIW</div>
    <div class="col-12 col-md-6 col-lg-4">SASP</div>
  </div>
</div>

En este segundo ejemplo, col-12 muestra una columna en móvil; col-md-6 permite dos columnas desde 768 px; y col-lg-4 permite tres desde 992 px. En anchuras medianas, la tercera tarjeta pasa a una nueva fila.

Como la tercera tarjeta conserva la clase col-md-6, ocupará la mitad de la anchura de esa nueva fila, no toda la fila. Si quisiéramos que ocupase el ancho completo en ese rango, tendríamos que aplicar una configuración diferente.

Selecciona una distribución para visualizar cómo se organizan tres tarjetas. Esta simulación cambia el número de columnas sin modificar el viewport real.

⚠️ Atención

Los puntos de ruptura de Bootstrap se basan en la anchura del viewport, no en la anchura de una tarjeta o de un contenedor. La demostración anterior es una simulación didáctica, no un cambio real del breakpoint.

Utilidades y componentes responsive

Bootstrap incluye clases de utilidad para resolver ajustes frecuentes sin escribir una regla CSS nueva para cada caso. También proporciona componentes visuales reutilizables, como .card y .btn.

ClaseFunción
img-fluidImagen con max-width: 100% y height: auto.
d-none d-md-blockOculta un elemento por debajo de 768 px y lo muestra desde md.
text-center text-md-startCentra el texto en móvil y lo alinea al inicio desde md.
p-3 y mb-3Añaden espaciado interior y margen inferior.
w-100Establece una anchura del 100 %.
card y btn btn-primaryAplican estilos de tarjeta y botón.
HTML · Tarjeta y utilidades de Bootstrap
<article class="card h-100">
  <img src="img/curso-diw.jpg"
       class="card-img-top"
       alt="Vista previa de una interfaz web">
  <div class="card-body">
    <h2 class="card-title h5">Diseño de Interfaces Web</h2>
    <p class="card-text">Aprende a crear interfaces responsive.</p>
    <a href="curso-diw.html" class="btn btn-primary">Ver curso</a>
  </div>
</article>

La clase h-100 establece height: 100%, por lo que puede ayudar a que las tarjetas de una misma fila tengan una altura uniforme cuando sus columnas tienen una altura disponible definida por la distribución. No significa que la tarjeta ocupe el 100 % de la altura de la pantalla.

Por su parte, card-body organiza el contenido de la tarjeta y btn btn-primary aplica un estilo de botón al enlace. Las rutas de imágenes y páginas son ilustrativas.

Aplicación práctica a StudyFlow

Vamos a combinar el sistema de cuadrícula y el componente card para crear un panel de tres módulos. El siguiente fragmento debe insertarse en una página que ya haya cargado la hoja de estilos de Bootstrap 5.

HTML · Panel responsive de módulos StudyFlow
<main class="container py-4">
  <h1 class="mb-4">Mis módulos · StudyFlow</h1>
  <div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4">
      <article class="card h-100">
        <div class="card-body">
          <h2 class="card-title h5">DWEC</h2>
          <p class="card-text">Programación en el navegador.</p>
          <a class="btn btn-primary" href="dwec.html">Acceder</a>
        </div>
      </article>
    </div>
    <div class="col-12 col-md-6 col-lg-4">
      <article class="card h-100">
        <div class="card-body">
          <h2 class="card-title h5">DIW</h2>
          <p class="card-text">Diseño y adaptación de interfaces.</p>
          <a class="btn btn-primary" href="diw.html">Acceder</a>
        </div>
      </article>
    </div>
    <div class="col-12 col-md-6 col-lg-4">
      <article class="card h-100">
        <div class="card-body">
          <h2 class="card-title h5">SASP</h2>
          <p class="card-text">Sostenibilidad en el sector productivo.</p>
          <a class="btn btn-primary" href="sasp.html">Acceder</a>
        </div>
      </article>
    </div>
  </div>
</main>

La distribución se adapta sin que tengamos que escribir media queries propias: las clases col-12, col-md-6 y col-lg-4 establecen el comportamiento en cada rango de anchura. Las tarjetas conservan una estructura visual coherente.

💻 Ejemplo DAW

En un proyecto real podemos combinar Bootstrap con CSS propio para ajustar la identidad visual de StudyFlow. Conviene mantener las personalizaciones en una hoja de estilos cargada después de Bootstrap y comprobar cómo intervienen la cascada y la especificidad.

Buenas prácticas y errores frecuentes

  • Comprender las clases: no copies combinaciones de clases sin saber qué hacen.
  • Respetar la estructura: utiliza .container, .row y columnas de manera coherente.
  • Diseñar desde móvil: establece primero el comportamiento base y añade clases con sufijos cuando sean necesarias.
  • Evitar estilos contradictorios: revisa los conflictos entre Bootstrap y el CSS propio.
  • No confundir los breakpoints: md comienza en 768 px y lg en 992 px; no representan dispositivos concretos.
  • Revisar accesibilidad y rendimiento: utiliza textos descriptivos, estructura semántica y solo los recursos que realmente necesita la página.
  • Comprobar el resultado: prueba la interfaz en diferentes anchuras, también entre los puntos de ruptura.
📌 Idea clave

Bootstrap 5 facilita la construcción de interfaces responsive mediante contenedores, una cuadrícula de 12 columnas, puntos de ruptura y utilidades CSS. Saber utilizarlo implica entender el CSS que hay detrás de sus clases.

En el apartado 7.8 aprenderemos a realizar pruebas y verificaciones del diseño responsive para detectar errores de distribución, desbordamientos y problemas de visualización.

💭 Piensa

En StudyFlow quieres mostrar tres tarjetas de módulos: una por fila en móviles, dos por fila desde 768 px y tres por fila desde 992 px. ¿Qué clases de Bootstrap aplicarías a cada columna? ¿Por qué no sería suficiente utilizar únicamente col-4?

Ver una posible solución

Utilizaría col-12 col-md-6 col-lg-4 en cada columna, dentro de una fila row. Así, cada tarjeta ocupa las 12 columnas en móvil, 6 desde md y 4 desde lg.

Si utilizáramos solo col-4, las tarjetas ocuparían un tercio de la fila también en pantallas pequeñas, lo que podría dejar demasiado poco espacio para su contenido.
