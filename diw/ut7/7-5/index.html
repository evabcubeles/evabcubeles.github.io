7.5 Maquetación responsive con Flexbox y CSS Grid

En los apartados anteriores hemos aprendido a utilizar dimensiones flexibles, media queries y las estrategias mobile first y desktop first. Ahora vamos a aplicar esos conocimientos a la maquetación de interfaces completas mediante Flexbox y CSS Grid.

Ya conocemos estas herramientas de la UT6. En este apartado no se trata de aprenderlas desde cero, sino de decidir cómo conseguir que sus distribuciones se adapten al espacio disponible sin provocar desbordamientos ni dificultar la lectura.

📌 Importante

Flexbox resulta especialmente útil para distribuir elementos en una dirección principal, como enlaces de navegación o grupos de botones. CSS Grid permite organizar filas y columnas, por ejemplo, tarjetas o paneles. Ambos pueden crear diseños responsive y pueden combinarse en una misma página.

Flexbox en diseños responsive

Flexbox permite alinear, distribuir y reorganizar elementos dentro de un contenedor. Para que una fila se adapte a espacios estrechos podemos utilizar flex-wrap: wrap, que permite que los elementos pasen a otra línea cuando no caben.

HTML · Tarjetas de acceso a StudyFlow
<section class="accesos" aria-label="Accesos a módulos">
  <a class="acceso" href="#dwec">DWEC</a>
  <a class="acceso" href="#diw">DIW</a>
  <a class="acceso" href="#sasp">SASP</a>
</section>
CSS · Flexbox con ajuste de línea
.accesos {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.acceso {
  flex: 1 1 180px;
  min-width: 0;
  padding: 16px;
  text-align: center;
  border: 1px solid #b9dfc6;
  border-radius: 8px;
}

La declaración flex: 1 1 180px indica, en este ejemplo, que cada acceso puede crecer, encogerse y tomar 180px como tamaño base. Junto con flex-wrap: wrap, permite que los enlaces se distribuyan en varias filas cuando no hay espacio suficiente. No garantiza un número exacto de columnas: ese número depende del ancho del contenedor y de los espacios entre elementos.

Reorganizar un menú mediante una media query

Cuando queremos un cambio concreto, por ejemplo, pasar de un menú horizontal a uno vertical, podemos combinar Flexbox con una media query.

CSS · Menú horizontal que pasa a vertical
.menu-principal {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  gap: 12px;
}

@media (max-width: 600px) {
  .menu-principal {
    flex-direction: column;
  }
}

Por encima de 600 px, los enlaces se distribuyen horizontalmente y pueden saltar de línea si hace falta. A 600 px o menos, se apilan verticalmente. El cambio de dirección se aplica al contenedor, no a cada enlace por separado.

⚠️ Atención

flex-wrap: wrap no equivale a flex-direction: column. La primera propiedad permite crear nuevas líneas; la segunda cambia la dirección principal de distribución. Elegiremos una u otra según el comportamiento que necesitemos.

CSS Grid en diseños responsive

CSS Grid es adecuado cuando necesitamos organizar elementos en una cuadrícula. Podemos definir columnas diferentes según el viewport mediante media queries o utilizar una cuadrícula que ajuste automáticamente el número de columnas según el espacio del contenedor.

Columnas controladas mediante breakpoints

CSS · Grid mobile first con tres distribuciones
.panel-modulos {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

@media (min-width: 600px) {
  .panel-modulos {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (min-width: 900px) {
  .panel-modulos {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}

Con esta solución decidimos explícitamente cuándo aparecen una, dos o tres columnas. Es útil cuando el diseño necesita una estructura concreta en cada intervalo de anchura.

Columnas automáticas con auto-fit y minmax()

CSS · Grid adaptable sin breakpoints explícitos
.panel-modulos {
  display: grid;
  grid-template-columns: repeat(
    auto-fit,
    minmax(min(100%, 220px), 1fr)
  );
  gap: 16px;
}

auto-fit ajusta el número de columnas que caben; minmax() establece un tamaño mínimo y uno máximo para cada columna. Aquí se utiliza min(100%, 220px) para que el tamaño mínimo no supere el ancho disponible en contenedores muy estrechos. Las columnas pueden crecer hasta ocupar una fracción del espacio libre gracias a 1fr.

Esta técnica se adapta al ancho del contenedor, no a un modelo concreto de dispositivo. Por eso es especialmente útil para galerías, tarjetas y listados con cantidades variables de elementos.

💻 Ejemplo DAW

En StudyFlow, una cuadrícula automática permite añadir un cuarto módulo sin escribir otra media query para un número concreto de tarjetas. El navegador distribuye los módulos en las columnas que caben dentro del panel.

Cuándo utilizar Flexbox y cuándo CSS Grid

Las dos herramientas pueden resolver distribuciones parecidas, pero conviene elegir según la estructura que necesitamos controlar.

SituaciónHerramienta habitualMotivo
Menú de navegación o fila de botonesFlexboxOrganiza elementos principalmente en una dirección.
Tarjetas en filas y columnasCSS GridPermite definir una cuadrícula y controlar sus columnas.
Cabecera con logotipo y enlacesFlexboxFacilita alineación y separación de elementos.
Panel principal con barra lateral y contenidoCSS GridPermite organizar zonas de la página en columnas.
Tarjetas con botones en su interiorGrid + FlexboxGrid distribuye las tarjetas y Flexbox organiza sus controles internos.

No existe una regla que obligue a utilizar exclusivamente una herramienta. Lo importante es elegir la solución que haga el CSS más claro y que permita mantener la interfaz cuando cambie el contenido.

Adaptar una página con barra lateral y contenido

Una interfaz de StudyFlow puede incluir un menú lateral y una zona principal. En una pantalla amplia, ambas zonas pueden aparecer una junto a otra; en una estrecha, resulta más cómodo apilarlas.

HTML · Estructura de dos zonas
<div class="estructura">
  <aside class="menu-lateral">Módulos y unidades</aside>
  <main class="zona-principal">Contenido del módulo</main>
</div>
CSS · Estructura responsive con Grid
.estructura {
  display: grid;
  grid-template-columns: 1fr;
  gap: 20px;
}

.menu-lateral,
.zona-principal {
  min-width: 0;
}

@media (min-width: 900px) {
  .estructura {
    grid-template-columns: 240px minmax(0, 1fr);
  }
}

La regla base coloca las zonas una debajo de otra. Desde 900 px, la barra lateral ocupa 240px y el contenido principal utiliza el espacio restante. minmax(0, 1fr) y min-width: 0 ayudan a que el contenido pueda reducirse dentro de la cuadrícula, aunque los elementos internos también deben diseñarse para evitar desbordamientos.

⚠️ Atención

Un diseño de dos columnas puede desbordarse si contiene imágenes sin límites, cadenas de texto muy largas o bloques de código que no permiten desplazamiento horizontal. Revisa también los elementos internos, no solo la cuadrícula exterior.

Aplicación práctica a StudyFlow

Vamos a utilizar el mismo contenido para comparar una distribución con Flexbox y otra con CSS Grid. Ambas se adaptan al espacio disponible, aunque lo hacen mediante reglas diferentes.

HTML · Panel de módulos
<section class="panel" aria-label="Módulos de segundo de DAW">
  <article class="tarjeta"><h2>DWEC</h2><p>Entorno Cliente</p></article>
  <article class="tarjeta"><h2>DIW</h2><p>Diseño de Interfaces</p></article>
  <article class="tarjeta"><h2>SASP</h2><p>Sostenibilidad</p></article>
</section>
CSS · Opción A: panel con Flexbox
.panel {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.tarjeta {
  box-sizing: border-box;
  flex: 1 1 220px;
  min-width: 0;
  padding: 16px;
  border: 1px solid #b9dfc6;
  border-radius: 10px;
}
CSS · Opción B: panel con Grid
.panel {
  display: grid;
  grid-template-columns: repeat(
    auto-fit,
    minmax(min(100%, 220px), 1fr)
  );
  gap: 16px;
}

.tarjeta {
  min-width: 0;
  padding: 16px;
  border: 1px solid #b9dfc6;
  border-radius: 10px;
}

Estas son dos alternativas independientes. En Flexbox, las tarjetas se ajustan y pueden saltar de línea; en Grid, las columnas se crean automáticamente según el espacio disponible. No es necesario aplicar ambas reglas display al mismo contenedor.

Buenas prácticas y errores frecuentes

  • Elegir según la estructura: utiliza Flexbox para alineaciones en una dirección y Grid para cuadrículas cuando resulte más claro.
  • Permitir la adaptación: utiliza flex-wrap, columnas flexibles o media queries cuando el contenido lo necesite.
  • Evitar anchos rígidos innecesarios: un ancho fijo demasiado grande puede provocar desplazamiento horizontal.
  • Controlar el contenido interno: revisa imágenes, textos largos, tablas y bloques de código.
  • Probar tamaños intermedios: no compruebes únicamente una pantalla móvil y otra de escritorio.
  • Evitar reglas contradictorias: no combines soluciones distintas sin entender cómo actúa la cascada CSS.
📌 Idea clave

Flexbox y CSS Grid son herramientas complementarias. Un diseño responsive no consiste solo en cambiar el número de columnas: también debe mantener una lectura cómoda, evitar desbordamientos y reorganizar los componentes cuando el espacio disponible cambia.

En el apartado 7.6 veremos cómo adaptar las imágenes y el contenido multimedia para que acompañen correctamente a estas distribuciones flexibles.

💭 Piensa

En StudyFlow quieres mostrar un menú de enlaces que pueda pasar a varias líneas y, debajo, una cuadrícula de tarjetas de módulos que cambie automáticamente de columnas según el espacio disponible. ¿Qué herramienta utilizarías en cada zona y qué propiedades CSS serían esenciales? Explica cómo evitarías que las tarjetas se desbordaran en una pantalla estrecha.

Ver una posible solución

Para el menú utilizaría Flexbox con display: flex, flex-wrap: wrap y gap, porque los enlaces se organizan principalmente en una dirección y pueden pasar a otra línea.

Para las tarjetas utilizaría CSS Grid con repeat(auto-fit, minmax(min(100%, 220px), 1fr)) y gap. Así las columnas se ajustan al ancho del contenedor sin exigir breakpoints fijos. También revisaría min-width: 0 y los contenidos internos, especialmente imágenes y textos largos, para evitar desbordamientos.
