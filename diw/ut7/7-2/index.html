7.2 Viewport y dimensiones flexibles

En el apartado anterior hemos visto que una interfaz responsive debe adaptarse al espacio disponible sin perder legibilidad ni funcionalidad. Para conseguirlo necesitamos comprender qué espacio utiliza el navegador para mostrar la página y cómo podemos expresar las dimensiones de sus elementos de forma flexible.

En este apartado estudiaremos el viewport, la etiqueta <meta name="viewport">, las principales unidades de CSS y las propiedades que permiten construir contenedores capaces de crecer o reducirse sin provocar desbordamientos.

📌 Importante

Una página no se convierte en responsive por utilizar únicamente porcentajes o por incluir la etiqueta meta viewport. Es necesario combinar una configuración correcta del viewport con dimensiones flexibles y una distribución que se adapte al contenido.

Qué es el viewport

El viewport es el área de visualización de la página web que utiliza el navegador para representar su contenido. En el diseño responsive nos interesa especialmente su anchura, porque condiciona el espacio disponible para distribuir textos, imágenes y componentes.

El viewport no debe confundirse con la resolución física de la pantalla. Un dispositivo puede tener muchos píxeles físicos, pero el navegador utiliza un sistema de coordenadas expresado en píxeles CSS. Además, en un ordenador podemos reducir la anchura de la ventana sin cambiar de monitor.

ConceptoSignificado
Pantalla físicaSuperficie y resolución reales del dispositivo.
Píxel CSSUnidad de referencia utilizada por CSS; no tiene por qué equivaler a un píxel físico.
ViewportÁrea de referencia que utiliza el navegador para mostrar y distribuir la página.
Anchura del viewportMedida relevante para muchas reglas de diseño responsive y media queries.
💻 Ejemplo DAW

Si abres StudyFlow en un portátil y reduces la ventana del navegador, la página dispone de menos espacio horizontal aunque sigas utilizando el mismo ordenador. Por eso debemos comprobar el comportamiento del diseño con diferentes anchuras de ventana, no solo con diferentes dispositivos.

La etiqueta meta viewport

En los navegadores móviles, una página sin una configuración adecuada puede representarse inicialmente sobre un viewport de diseño más ancho que la pantalla y después reducirse visualmente. Esto puede hacer que los textos y los controles aparezcan demasiado pequeños.

Para indicar que queremos utilizar la anchura del dispositivo como referencia inicial, incluimos la siguiente etiqueta en el <head> del documento HTML:

HTML · Configuración del viewport
<meta name="viewport" content="width=device-width, initial-scale=1.0">
ParteFunción
name="viewport"Indica que la etiqueta configura el viewport.
width=device-widthSolicita que la anchura del viewport de diseño se ajuste a la anchura del dispositivo en píxeles CSS.
initial-scale=1.0Establece el nivel inicial de escala en 1.

Esta etiqueta es habitual en los documentos HTML actuales y debe aparecer dentro de <head>, junto a la codificación, el título y los enlaces a las hojas de estilo.

HTML · Estructura mínima
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>StudyFlow</title>
  <link rel="stylesheet" href="estilos.css">
</head>
<body>
  <h1>Bienvenido a StudyFlow</h1>
</body>
</html>
⚠️ Atención

Evita configurar user-scalable=no o limitar innecesariamente el zoom. Impedir que las personas amplíen la página puede perjudicar la accesibilidad. La etiqueta meta viewport tampoco corrige por sí sola una maquetación con anchuras rígidas.

Unidades absolutas y relativas

En CSS podemos definir tamaños con distintas unidades. Elegirlas correctamente permite crear diseños más flexibles y facilitar la lectura en diferentes contextos.

La unidad px

La unidad px representa un píxel CSS. Es útil para bordes, separaciones y otros valores concretos, pero utilizar anchuras fijas grandes puede generar problemas cuando el viewport se estrecha.

CSS · Anchura fija
.panel {
  width: 1000px;
}

Un panel de 1000 px puede ser demasiado ancho para una ventana de 390 px y provocar desplazamiento horizontal.

Porcentajes (%)

Los porcentajes permiten establecer dimensiones respecto a una referencia, que en el caso habitual de width es la anchura del bloque contenedor.

CSS · Anchura relativa
.panel {
  width: 80%;
}

Si el contenedor tiene una anchura de 1000 px, el panel ocupará aproximadamente 800 px; si mide 500 px, ocupará aproximadamente 400 px, suponiendo que no intervengan otras restricciones.

rem y em

Las unidades rem y em son relativas a tamaños de letra y resultan útiles para crear espacios y componentes que acompañen a la tipografía.

  • rem: toma como referencia el tamaño de letra del elemento raíz (html).
  • em: para font-size se calcula respecto al tamaño de letra del elemento padre; en muchas otras propiedades, respecto al tamaño de letra del propio elemento.
CSS · Medidas relativas a la tipografía
html {
  font-size: 16px;
}

.titulo {
  font-size: 2rem;   /* 32px si la raíz mide 16px */
}

.boton {
  font-size: 1rem;
  padding: 0.75em 1.25em;
}

En este ejemplo, los espacios interiores del botón se calculan a partir de su tamaño de letra. El resultado puede escalar de manera coherente si cambiamos dicho tamaño.

vw, vh y unidades modernas del viewport

vw representa el 1 % de la anchura del viewport; vh representa el 1 % de su altura. Son útiles en determinadas situaciones, aunque hay que emplearlas con criterio.

CSS · Unidades del viewport
.cabecera {
  min-height: 30vh;
}

.titulo-principal {
  font-size: clamp(1.5rem, 3vw, 2.5rem);
}

La función clamp() permite establecer un valor mínimo, uno preferido y uno máximo. Así evitamos que el título se reduzca o aumente sin límites.

En móviles, la altura visible puede cambiar cuando aparecen o desaparecen las barras del navegador. Para algunos diseños actuales existen unidades como dvh, que siguen la altura dinámica del viewport.

UnidadReferencia habitualUso frecuente
pxPíxel CSSBordes y tamaños concretos.
%Dimensión de referencia del contenedor, según la propiedadAnchuras flexibles.
remTipografía raízTipografía y espaciados consistentes.
emTipografía del elemento o de su padre, según la propiedadComponentes que escalan con el texto.
vwAnchura del viewportDimensiones relacionadas con la ventana.
vhAltura del viewportSecciones relacionadas con la altura de la ventana.
dvhAltura dinámica del viewportVistas móviles que se ajustan a barras del navegador.

Anchuras y dimensiones flexibles

Una técnica habitual consiste en combinar una anchura flexible con un límite máximo. De esta forma, un contenedor puede ocupar el espacio disponible en pantallas pequeñas sin extenderse demasiado en monitores grandes.

CSS · Contenedor flexible
.contenedor {
  width: 90%;
  max-width: 1100px;
  margin-inline: auto;
}

El contenedor ocupa el 90 % de la anchura disponible, pero no supera los 1100 px. margin-inline: auto permite centrarlo horizontalmente cuando queda espacio libre.

La función min()

La función min() permite utilizar el menor de varios valores. Podemos expresar el mismo límite de anchura de una manera compacta:

CSS · min()
.contenedor {
  width: min(90%, 1100px);
  margin-inline: auto;
}

La propiedad max-width

max-width también es importante para los elementos multimedia. Por ejemplo, una imagen puede conservar su tamaño natural cuando hay espacio suficiente y reducirse si el contenedor es más estrecho.

CSS · Imagen flexible
img {
  max-width: 100%;
  height: auto;
}

Esta regla es una primera aproximación a las imágenes responsive. Estudiaremos las opciones avanzadas para imágenes y multimedia en el apartado 7.6.

Evitar alturas rígidas innecesarias

En componentes con texto variable, establecer una altura fija puede hacer que el contenido se salga de la caja. En muchos casos es preferible utilizar min-height o dejar que la altura se ajuste automáticamente.

CSS · Altura adaptable
.tarjeta {
  min-height: 150px;
  padding: 1.25rem;
}

La tarjeta tendrá una altura mínima de 150 px, pero podrá crecer si necesita mostrar más contenido.

Desbordamiento horizontal

Existe desbordamiento horizontal cuando un elemento ocupa más anchura de la disponible y sobresale del área de visualización. Es uno de los problemas más habituales al adaptar una página a pantallas pequeñas.

Entre sus causas frecuentes encontramos los contenedores con anchuras fijas excesivas, las imágenes sin límites, las palabras o direcciones muy largas y algunos elementos de Grid o Flexbox que no pueden reducirse lo suficiente.

⚠️ Atención

Aplicar overflow-x: hidden a toda la página puede ocultar el problema sin solucionarlo. Antes de hacerlo, identifica qué elemento se desborda y corrige sus dimensiones o su comportamiento.

El modelo de caja y box-sizing

Con el valor predeterminado content-box, el padding y el borde se añaden a la anchura declarada. Esto puede provocar que un elemento con width: 100% termine ocupando más espacio del esperado.

CSS · Modelo de caja más predecible
*,
*::before,
*::after {
  box-sizing: border-box;
}

.panel {
  width: 100%;
  padding: 20px;
}

Con border-box, el relleno y el borde quedan incluidos en la anchura declarada. Esta configuración facilita la construcción de interfaces flexibles.

Contenido que necesita desplazamiento propio

En ocasiones, como sucede con tablas de muchas columnas o fragmentos de código, puede ser preferible permitir el desplazamiento horizontal solo dentro de ese componente.

CSS · Desplazamiento localizado
.tabla-contenedor {
  max-width: 100%;
  overflow-x: auto;
}

De esta manera evitamos que la tabla obligue a desplazar horizontalmente toda la página.

Aplicación a StudyFlow

Vamos a preparar una tarjeta informativa de StudyFlow que aproveche el espacio disponible, mantenga una anchura máxima razonable y permita que el contenido aumente su altura cuando sea necesario.

HTML · Tarjeta de StudyFlow
<main class="contenedor">
  <article class="tarjeta-curso">
    <h2>Diseño de Interfaces Web</h2>
    <p>Consulta los contenidos y actividades de la UT7.</p>
    <a href="ut7/index.html">Ver unidad</a>
  </article>
</main>
CSS · Dimensiones flexibles
*,
*::before,
*::after {
  box-sizing: border-box;
}

.contenedor {
  width: min(90%, 900px);
  margin-inline: auto;
}

.tarjeta-curso {
  width: 100%;
  min-height: 160px;
  padding: 1.5rem;
  border: 1px solid #b9dfc6;
  border-radius: 10px;
  background-color: #eef8f1;
  color: #195c36;
}

.tarjeta-curso h2 {
  margin-top: 0;
}

📌 Idea clave

Las dimensiones flexibles son la base del diseño responsive. Antes de añadir media queries, comprueba si la propia estructura puede adaptarse mediante porcentajes, límites máximos, unidades relativas y una altura determinada por el contenido.

En el siguiente apartado aprenderemos a utilizar las media queries para modificar estilos cuando las características del viewport lo requieran.

💭 Piensa

En StudyFlow tenemos una tarjeta con width: 900px y height: 180px. En una pantalla estrecha aparece una barra de desplazamiento horizontal y, cuando el texto ocupa varias líneas, parte del contenido sobresale. ¿Qué cambios harías para que la tarjeta se adapte mejor?

Ver una posible solución

Sustituiría la anchura rígida por width: 100% y añadiría max-width: 900px al contenedor correspondiente. Utilizaría box-sizing: border-box para incluir el relleno en la anchura y cambiaría height: 180px por min-height: 180px o una altura automática para permitir que el contenido crezca.
