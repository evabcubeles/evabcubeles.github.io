5.3 Parámetros y argumentos de las funciones

En el apartado anterior hemos aprendido a declarar e invocar funciones. También hemos comprobado que una misma función puede ejecutarse tantas veces como sea necesario.

Sin embargo, los ejemplos que hemos utilizado hasta ahora tienen una limitación: las funciones trabajan con información escrita directamente en su código. Esto significa que, aunque las llamemos varias veces, realizan siempre la misma operación con los mismos datos.

Imagina que estamos desarrollando una tienda online y necesitamos mostrar un saludo personalizado a cada cliente. No sería práctico crear una función diferente para cada persona. Lo adecuado sería utilizar una sola función capaz de recibir el nombre del cliente.

Para conseguirlo, JavaScript permite trabajar con parámetros y argumentos.

📌 Importante

Los parámetros y argumentos permiten proporcionar datos a una función. Gracias a ellos, una misma función puede realizar una tarea utilizando información diferente en cada llamada.

Qué son los parámetros y los argumentos

Aunque los términos parámetro y argumento están relacionados, no significan exactamente lo mismo.

Un parámetro es un identificador que aparece en la declaración de una función y representa un dato que esta podrá recibir.

Un argumento es el valor o expresión que proporcionamos al realizar una llamada a la función.

JavaScript 
function saludar(nombre) {
  console.log("Hola, " + nombre);
}

saludar("Lucía");

En este ejemplo, nombre es un parámetro, porque aparece en la declaración de la función.

En cambio, "Lucía" es un argumento, porque es el valor proporcionado al invocar la función.

La salida será:

Consola 
Hola, Lucía
Concepto Dónde aparece Ejemplo
Parámetro En la declaración de la función. nombre
Argumento En la llamada a la función. "Lucía"
saludar("Lucía") Llamada con el argumento "Lucía"
↓
function saludar(nombre) El parámetro nombre recibe el valor "Lucía"
↓
Hola, Lucía La función utiliza el dato recibido
⚠️ Atención

No debemos confundir el nombre del parámetro con el valor que recibe. En saludar("Lucía"), el parámetro sigue llamándose nombre, pero durante esa ejecución contiene el valor "Lucía".

Declarar funciones con parámetros

Para declarar una función con parámetros, escribimos sus nombres entre los paréntesis que aparecen después del nombre de la función.

La sintaxis básica de una función con un parámetro es la siguiente:

JavaScript 
function nombreFuncion(parametro) {
  // Instrucciones que utilizan el parámetro
}

Observa una función que muestra el precio de un producto:

JavaScript 
function mostrarPrecio(precio) {
  console.log("Precio: " + precio + " €");
}

El parámetro precio representa el dato que recibirá la función cuando sea invocada. Dentro del cuerpo podemos utilizarlo para construir el mensaje que aparecerá en la consola.

Observa que no hemos asignado ningún valor al parámetro en la declaración. El valor se proporcionará cuando realicemos la llamada.

📌 Importante

Los parámetros se declaran entre los paréntesis de la función y pueden utilizarse dentro de su cuerpo como identificadores que contienen los datos recibidos.

Funciones con parámetros y sin parámetros

No todas las funciones necesitan recibir información. Algunas pueden realizar su tarea sin parámetros, mientras que otras necesitan uno o varios datos.

JavaScript 
// Función sin parámetros
function mostrarTitulo() {
  console.log("CATÁLOGO DE PRODUCTOS");
}

// Función con un parámetro
function mostrarProducto(producto) {
  console.log("Producto: " + producto);
}

mostrarTitulo();
mostrarProducto("Teclado");

La consola mostrará:

Consola 
CATÁLOGO DE PRODUCTOS
Producto: Teclado

mostrarTitulo() no necesita recibir ningún dato porque siempre muestra el mismo encabezado. En cambio, mostrarProducto(producto) necesita conocer qué producto debe mostrar.

Invocar funciones con argumentos

Cuando llamamos a una función que tiene parámetros, podemos proporcionar los datos que necesita escribiendo los argumentos entre los paréntesis de la llamada.

El principal beneficio es que podemos ejecutar una misma función con valores diferentes, sin modificar su declaración.

JavaScript 
function saludar(nombre) {
  console.log("Bienvenido/a, " + nombre);
}

saludar("Ana");
saludar("Carlos");
saludar("Marta");

La salida será:

Consola 
Bienvenido/a, Ana
Bienvenido/a, Carlos
Bienvenido/a, Marta

En las tres llamadas se ejecuta el mismo cuerpo, pero el parámetro nombre recibe un valor diferente en cada ejecución.

Utilizar variables como argumentos

Los argumentos no tienen que ser necesariamente valores escritos directamente en la llamada. También podemos utilizar variables.

JavaScript 
function mostrarEdad(edad) {
  console.log("Edad del usuario: " + edad);
}

const edadCliente = 22;

mostrarEdad(edadCliente);

En este caso, el argumento es la variable edadCliente, cuyo valor es 22.

Por tanto, la consola mostrará:

Consola 
Edad del usuario: 22

Utilizar expresiones como argumentos

También podemos proporcionar una expresión cuyo resultado se utilizará como argumento.

JavaScript 
function mostrarCantidad(cantidad) {
  console.log("Cantidad: " + cantidad);
}

mostrarCantidad(4 + 3);
mostrarCantidad(5 * 2);

Antes de ejecutar el cuerpo de la función, JavaScript evalúa las expresiones utilizadas como argumentos.

Consola 
Cantidad: 7
Cantidad: 10
💻 Ejemplo DAW

En una aplicación de reservas, podríamos utilizar mostrarDisponibilidad(plazas) para informar de las plazas disponibles. El argumento podría proceder de una variable que almacene el número de plazas de cada actividad.

Funciones con varios parámetros

Una función puede necesitar más de un dato para realizar su tarea. En ese caso, podemos declarar varios parámetros separados por comas.

La sintaxis general es:

JavaScript 
function nombreFuncion(parametro1, parametro2) {
  // Instrucciones
}

Por ejemplo, podemos crear una función que muestre el nombre de un producto y su precio:

JavaScript 
function mostrarProducto(nombre, precio) {
  console.log("Producto: " + nombre);
  console.log("Precio: " + precio + " €");
}

mostrarProducto("Monitor", 180);

El resultado será:

Consola 
Producto: Monitor
Precio: 180 €

En la declaración hemos definido dos parámetros: nombre y precio. En la llamada proporcionamos dos argumentos: "Monitor" y 180.

El orden de los argumentos

Cuando una función tiene varios parámetros, el orden de los argumentos es fundamental. JavaScript los asigna según su posición.

Posición Parámetro Argumento recibido
Primera nombre "Monitor"
Segunda precio 180

Observa qué sucede si invertimos los argumentos:

JavaScript 
function mostrarProducto(nombre, precio) {
  console.log("Producto: " + nombre);
  console.log("Precio: " + precio + " €");
}

mostrarProducto(180, "Monitor");

La consola mostrará:

Consola 
Producto: 180
Precio: Monitor €

JavaScript no interpreta automáticamente qué argumento representa el nombre o el precio. Simplemente asigna cada valor al parámetro que ocupa la misma posición.

⚠️ Atención

Cambiar el orden de los argumentos puede provocar resultados incorrectos, aunque el programa no produzca un error de sintaxis.

Ejemplo con tres parámetros

Podemos utilizar tantos parámetros como requiera razonablemente la tarea que realiza la función.

JavaScript 
function mostrarReserva(cliente, habitacion, noches) {
  console.log("Cliente: " + cliente);
  console.log("Habitación: " + habitacion);
  console.log("Noches: " + noches);
}

mostrarReserva("Elena", 204, 3);

En este ejemplo, la función recibe tres datos relacionados con una reserva hotelera.

Consola 
Cliente: Elena
Habitación: 204
Noches: 3

Parámetros y variables locales

Los parámetros se comportan como identificadores disponibles dentro de la función. Esto significa que podemos utilizarlos en operaciones, condiciones y otras instrucciones.

Además, podemos declarar variables dentro del cuerpo de la función para almacenar resultados intermedios.

JavaScript 
function mostrarImporte(precio, cantidad) {
  const importe = precio * cantidad;

  console.log("Importe: " + importe + " €");
}

mostrarImporte(15, 4);

En este ejemplo, precio y cantidad son parámetros. La variable importe se declara dentro de la función y almacena el resultado de multiplicarlos.

La salida será:

Consola 
Importe: 60 €

Tanto los parámetros como la variable importe pertenecen al contexto de ejecución de la función. No podemos utilizar esos identificadores directamente fuera de ella como si fueran variables globales.

📌 Importante

Los parámetros permiten trabajar con los datos recibidos por una función. Las variables declaradas dentro de su cuerpo permiten almacenar información necesaria para realizar la tarea.

Estudiaremos con mayor profundidad el ámbito de las variables en el apartado 5.5.

Argumentos de distintos tipos de datos

En JavaScript no es necesario indicar un tipo de dato al declarar un parámetro.

Una función puede recibir números, cadenas de texto, valores booleanos y otros tipos de datos. Lo importante es que las instrucciones de la función sean adecuadas para los valores que reciben.

Argumentos numéricos

JavaScript 
function mostrarDoble(numero) {
  console.log(numero * 2);
}

mostrarDoble(8);
mostrarDoble(15);

La consola mostrará:

Consola 
16
30

Argumentos de tipo cadena

JavaScript 
function mostrarCategoria(categoria) {
  console.log("Categoría: " + categoria);
}

mostrarCategoria("Informática");
mostrarCategoria("Accesorios");

La salida será:

Consola 
Categoría: Informática
Categoría: Accesorios

Argumentos booleanos

Los valores booleanos son especialmente útiles para indicar estados o condiciones.

JavaScript 
function mostrarEstado(disponible) {
  if (disponible) {
    console.log("Producto disponible");
  } else {
    console.log("Producto agotado");
  }
}

mostrarEstado(true);
mostrarEstado(false);

El resultado será:

Consola 
Producto disponible
Producto agotado

La misma función muestra un mensaje diferente dependiendo del valor booleano recibido.

⚠️ Atención

JavaScript no comprueba automáticamente que los argumentos tengan el tipo de dato que esperamos. Si una función necesita un número y recibe una cadena, algunas operaciones pueden producir resultados inesperados.

Qué sucede cuando faltan o sobran argumentos

En JavaScript, el número de argumentos proporcionados en una llamada no tiene que coincidir necesariamente con el número de parámetros declarados.

Sin embargo, esa flexibilidad puede provocar comportamientos que debemos comprender.

Cuando faltan argumentos

Si una función espera un parámetro y no proporcionamos el argumento correspondiente, ese parámetro recibirá el valor undefined, siempre que no exista otro mecanismo que le asigne un valor.

JavaScript 
function saludar(nombre) {
  console.log("Hola, " + nombre);
}

saludar();

La consola mostrará:

Consola 
Hola, undefined

La función se ejecuta, pero el mensaje no es el que normalmente esperaríamos mostrar al usuario.

Cuando falta un argumento numérico

La ausencia de argumentos también puede afectar a los cálculos matemáticos.

JavaScript 
function mostrarTotal(precio, cantidad) {
  console.log(precio * cantidad);
}

mostrarTotal(20);

Como no hemos proporcionado el segundo argumento, cantidad contiene undefined.

La multiplicación produce NaN, que significa Not a Number («no es un número»). Se trata de un valor especial de JavaScript que indica que una operación numérica no ha producido un resultado numérico válido.

📌 Importante

Aunque su nombre pueda resultar confuso, NaN pertenece al tipo de dato number en JavaScript.

Consola 
NaN

Cuando sobran argumentos

Si proporcionamos más argumentos que parámetros declarados, los argumentos adicionales no se asignan automáticamente a los parámetros existentes.

JavaScript 
function mostrarNombre(nombre) {
  console.log("Nombre: " + nombre);
}

mostrarNombre("Sara", 25, "Zaragoza");

La consola mostrará:

Consola 
Nombre: Sara

La función únicamente utiliza el primer argumento porque solo hemos declarado un parámetro. Los demás argumentos no se utilizan en este ejemplo.

Esto no significa que JavaScript descarte necesariamente los argumentos adicionales. Existen mecanismos que permiten acceder a ellos, aunque no se hayan asignado a parámetros declarados individualmente.

En el apartado 5.7 estudiaremos los parámetros rest, que permiten recoger varios argumentos en un único parámetro.

Situación Comportamiento habitual
Coinciden parámetros y argumentos Cada parámetro recibe el argumento correspondiente.
Faltan argumentos Los parámetros sin argumento reciben undefined, salvo que se haya previsto otro valor.
Sobran argumentos Los argumentos adicionales no se asignan a parámetros declarados.
📌 Importante

Aunque JavaScript permita realizar llamadas con distintos números de argumentos, debemos proporcionar los datos necesarios para que la función pueda realizar correctamente su tarea.

En el apartado 5.7 aprenderemos a utilizar parámetros por defecto y parámetros rest.

Errores frecuentes al utilizar parámetros y argumentos

Al empezar a utilizar funciones con parámetros, es habitual cometer errores relacionados con el orden, la cantidad o el tipo de los argumentos.

1. Confundir parámetros y argumentos

Recuerda que los parámetros aparecen en la declaración y los argumentos en la llamada.

JavaScript 
function mostrarCiudad(ciudad) {
  console.log(ciudad);
}

mostrarCiudad("Teruel");

ciudad es el parámetro; "Teruel" es el argumento.

2. Proporcionar los argumentos en un orden incorrecto

Si los valores se proporcionan en un orden distinto al esperado, la función puede trabajar con datos equivocados.

JavaScript 
function mostrarCompra(producto, cantidad) {
  console.log(producto + ": " + cantidad);
}

// Incorrecto para la finalidad prevista
mostrarCompra(3, "Teclados");

// Correcto
mostrarCompra("Teclados", 3);

3. Olvidar un argumento necesario

Una llamada puede ejecutarse sin todos los argumentos, pero eso no significa que el resultado sea correcto.

JavaScript 
function mostrarPrecio(precio) {
  console.log("Precio: " + precio);
}

// Falta el argumento
mostrarPrecio();

En este caso aparecerá Precio: undefined.

4. Utilizar un tipo de dato inadecuado

Debemos prestar atención al tipo de dato que necesita cada operación.

JavaScript 
function mostrarDoble(numero) {
  console.log(numero * 2);
}

mostrarDoble("Hola");

La multiplicación de esa cadena por el número 2 produce NaN.

5. Pensar que el nombre del argumento debe coincidir con el parámetro

No es necesario que la variable utilizada como argumento tenga el mismo nombre que el parámetro.

JavaScript 
function mostrarPrecio(precio) {
  console.log(precio);
}

const costeProducto = 45;

mostrarPrecio(costeProducto);

La función recibe correctamente el valor 45, aunque el parámetro se llame precio y la variable utilizada como argumento se llame costeProducto.

⚠️ Atención

Cuando una función produce un resultado inesperado, comprueba qué argumentos recibe, en qué orden se proporcionan y qué operaciones realiza con esos valores.

Buenas prácticas al trabajar con parámetros

Para escribir funciones comprensibles y fáciles de mantener, conviene seguir algunas recomendaciones.

  • Utilizar nombres descriptivos: preferir precio o cantidad frente a nombres ambiguos como x.
  • Mantener un orden lógico: declarar los parámetros siguiendo una secuencia fácil de recordar y utilizar.
  • Proporcionar los datos necesarios: evitar llamadas incompletas cuando la función necesita varios valores.
  • Comprobar los tipos esperados: prestar especial atención a las operaciones matemáticas y las condiciones.
  • Evitar funciones con demasiados parámetros: si una función necesita numerosos datos, conviene revisar su responsabilidad y organización.
  • Probar diferentes llamadas: comprobar el comportamiento de la función con distintos argumentos.

Comprobar los datos recibidos

En determinadas situaciones, podemos utilizar condiciones para detectar argumentos inadecuados.

JavaScript 
function mostrarCantidad(cantidad) {
  if (typeof cantidad !== "number" ||
      !Number.isFinite(cantidad)) {
    console.log("La cantidad debe ser un número válido");
  } else {
    console.log("Cantidad: " + cantidad);
  }
}

mostrarCantidad(5);
mostrarCantidad("cinco");

La salida será:

Consola 
Cantidad: 5
La cantidad debe ser un número válido

La condición comprueba que el argumento sea un número finito. Si no cumple esa condición, la función muestra un aviso.

💻 Ejemplo DAW

En una aplicación web que gestione pedidos, una función encargada de procesar cantidades debería comprobar que los datos recibidos son adecuados antes de realizar cálculos. Esto ayuda a detectar errores y evita resultados inesperados.

Ejemplo práctico completo: gestionar productos de una tienda online

Vamos a aplicar los conceptos estudiados mediante un ejemplo relacionado con una tienda online.

Queremos mostrar información de varios productos sin tener que escribir una función distinta para cada uno.

El programa debe permitir:

  • mostrar la cabecera del catálogo;
  • mostrar el nombre y el precio de cada producto;
  • calcular y mostrar el importe de una compra;
  • indicar si un producto está disponible;
  • mostrar un mensaje final.

Para organizar estas operaciones, utilizaremos varias funciones. Algunas recibirán parámetros y otras no necesitarán argumentos.

JavaScript 
// Muestra la cabecera del catálogo
function mostrarCabecera() {
  console.log("CATÁLOGO DE PRODUCTOS");
  console.log("------------------------");
}

// Muestra los datos de un producto
function mostrarProducto(nombre, precio) {
  console.log("Producto: " + nombre);
  console.log("Precio: " + precio + " €");
}

// Calcula y muestra un importe
function mostrarImporte(precio, cantidad) {
  const importe = precio * cantidad;
  console.log("Importe: " + importe + " €");
}

// Muestra la disponibilidad
function mostrarDisponibilidad(disponible) {
  if (disponible) {
    console.log("Estado: Disponible");
  } else {
    console.log("Estado: Agotado");
  }
}

// Organiza la presentación de un producto
function mostrarFicha(nombre, precio, disponible) {
  mostrarProducto(nombre, precio);
  mostrarDisponibilidad(disponible);
  console.log("------------------------");
}

// Programa principal
mostrarCabecera();

mostrarFicha("Teclado", 35, true);
mostrarFicha("Monitor", 180, false);

console.log("RESUMEN DE COMPRA");

mostrarImporte(35, 2);

console.log("Fin del proceso");

La salida completa será:

Consola 
CATÁLOGO DE PRODUCTOS
------------------------
Producto: Teclado
Precio: 35 €
Estado: Disponible
------------------------
Producto: Monitor
Precio: 180 €
Estado: Agotado
------------------------
RESUMEN DE COMPRA
Importe: 70 €
Fin del proceso

Análisis del programa

Hemos declarado cinco funciones, cada una con una responsabilidad concreta.

Función Parámetros Responsabilidad
mostrarCabecera() Ninguno Mostrar el título del catálogo.
mostrarProducto() nombre, precio Mostrar los datos de un producto.
mostrarImporte() precio, cantidad Calcular y mostrar el importe de una compra.
mostrarDisponibilidad() disponible Mostrar el estado del producto.
mostrarFicha() nombre, precio, disponible Coordinar la presentación de una ficha.

Reutilización de las funciones

Observa las dos llamadas a mostrarFicha():

JavaScript 
mostrarFicha("Teclado", 35, true);

mostrarFicha("Monitor", 180, false);

Ambas llamadas utilizan la misma función, pero proporcionan argumentos diferentes. Por eso se generan fichas distintas sin repetir las instrucciones encargadas de mostrar cada producto.

Funciones que transmiten argumentos a otras funciones

También hemos comprobado que una función puede recibir datos y utilizarlos como argumentos al llamar a otras funciones.

JavaScript 
function mostrarFicha(nombre, precio, disponible) {
  mostrarProducto(nombre, precio);
  mostrarDisponibilidad(disponible);
  console.log("------------------------");
}

Los parámetros nombre y precio se utilizan como argumentos de mostrarProducto(). Del mismo modo, disponible se proporciona como argumento a mostrarDisponibilidad().

De esta manera, las funciones pueden colaborar entre sí utilizando los datos recibidos.

📌 Importante

Los parámetros permiten separar las instrucciones de una función de los datos concretos con los que trabaja. Esta separación favorece la reutilización, la organización y el mantenimiento del código.

En este apartado nuestras funciones han mostrado los resultados directamente en la consola. En el siguiente aprenderemos cómo una función puede devolver un valor mediante la sentencia return, para que otras partes del programa puedan utilizarlo.

💭 Piensa

Observa el siguiente programa sin ejecutarlo:

JavaScript 
function mostrarPedido(producto, cantidad, precio) {
  console.log("Producto: " + producto);
  console.log("Cantidad: " + cantidad);
  console.log("Total: " + cantidad * precio + " €");
}

mostrarPedido("Ratón", 3, 20);
mostrarPedido("Teclado", 2, 45);

Responde a las siguientes preguntas:

  1. ¿Cuántos parámetros tiene la función? ¿Cómo se llaman?
  2. ¿Qué argumentos recibe en la primera llamada?
  3. ¿Qué argumentos recibe en la segunda llamada?
  4. ¿Qué mensajes aparecerán en la consola?
  5. ¿Qué ocurriría si escribiéramos mostrarPedido("Ratón", 3)?
Ver una posible solución

La función tiene tres parámetros: producto, cantidad y precio.

En la primera llamada recibe los argumentos "Ratón", 3 y 20.

En la segunda llamada recibe "Teclado", 2 y 45.

La salida completa será:

Consola 
Producto: Ratón
Cantidad: 3
Total: 60 €
Producto: Teclado
Cantidad: 2
Total: 90 €

Si realizáramos la llamada mostrarPedido("Ratón", 3), faltaría el argumento correspondiente al parámetro precio. Este recibiría undefined y el cálculo produciría NaN.

En consecuencia, el último mensaje de esa llamada sería Total: NaN €.
