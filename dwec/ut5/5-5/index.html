5.5 Ámbito de las variables en las funciones

En los apartados anteriores hemos aprendido a declarar funciones, proporcionarles datos mediante parámetros y recuperar resultados utilizando la sentencia return.

Sin embargo, cuando trabajamos con funciones surge una pregunta importante: ¿podemos utilizar cualquier variable desde cualquier parte de un programa?

Imagina que estamos desarrollando una tienda online. Tenemos una función que calcula el importe de un producto y otra que muestra los datos de un pedido. Cada una puede necesitar sus propias variables para realizar los cálculos.

Si todas las variables estuvieran disponibles en cualquier lugar, podrían producirse conflictos entre sus nombres, modificaciones accidentales y errores difíciles de localizar.

Para evitar estos problemas, JavaScript establece reglas que determinan dónde puede utilizarse cada variable. Estas reglas están relacionadas con el concepto de ámbito.

📌 Importante

El ámbito de una variable, también denominado scope, determina las zonas del programa desde las que podemos acceder a ella.

Una variable puede existir dentro de una función o de un bloque y no estar disponible fuera de ellos.

Qué es el ámbito de una variable

Cuando declaramos una variable, JavaScript determina en qué parte del código puede utilizarse su nombre. Esa zona se conoce como ámbito de la variable.

Observa este ejemplo:

JavaScript 
function mostrarProducto() {
  const producto = "Teclado";

  console.log(producto);
}

mostrarProducto();

La consola mostrará:

Consola 
Teclado

La variable producto se declara dentro de mostrarProducto(). Por tanto, podemos utilizarla dentro de esa función.

Pero ¿qué ocurriría si intentáramos acceder a ella desde fuera?

JavaScript 
function mostrarProducto() {
  const producto = "Teclado";

  console.log(producto);
}

mostrarProducto();

console.log(producto);

La primera instrucción console.log() muestra Teclado, pero la última produce un error similar al siguiente:

Consola 
Teclado
ReferenceError: producto is not defined

El error se produce porque la variable producto pertenece al ámbito de la función y no está disponible fuera de ella.

⚠️ Atención

Que una función haya terminado de ejecutarse no significa que las variables declaradas dentro de ella pasen a estar disponibles en el resto del programa.

En este apartado distinguiremos principalmente tres situaciones: variables de ámbito global, variables locales de función y variables de ámbito de bloque.

Global Declarada fuera de las funciones y accesible desde los ámbitos internos cuando no está ocultada
Función Declarada dentro de una función y limitada a su ámbito
Bloque Declarada con let o const dentro de un bloque delimitado por llaves

Ámbito global

Una variable tiene ámbito global cuando se declara en el nivel superior de un script clásico, fuera de cualquier función o bloque.

En los ejemplos sencillos de esta unidad, estas variables pueden utilizarse tanto en el código principal como dentro de las funciones, siempre que otra declaración más cercana no oculte su nombre.

Acceder a una variable global desde una función

JavaScript 
const nombreTienda = "TecnoDAW";

function mostrarBienvenida() {
  console.log("Bienvenido a " + nombreTienda);
}

mostrarBienvenida();

console.log(nombreTienda);

La consola mostrará:

Consola 
Bienvenido a TecnoDAW
TecnoDAW

La variable nombreTienda se ha declarado fuera de la función. Por eso podemos acceder a ella desde mostrarBienvenida() y desde el código principal.

Modificar una variable global

Si una variable global se declara con let, una función también puede modificarla.

JavaScript 
let contador = 0;

function incrementarContador() {
  contador = contador + 1;
}

incrementarContador();
incrementarContador();

console.log(contador);

La salida será:

Consola 
2

Cada llamada modifica la misma variable contador. No se crea un contador independiente para cada ejecución.

⚠️ Atención

Aunque las variables globales pueden resultar útiles, utilizar demasiadas aumenta el riesgo de que distintas funciones modifiquen los mismos datos sin que resulte evidente.

Por ello, conviene limitar su uso y preferir parámetros y valores de retorno cuando una función necesita recibir o proporcionar información.

📌 Importante

En estos ejemplos trabajamos con scripts clásicos. En los módulos de JavaScript, las declaraciones del nivel superior pertenecen al ámbito del módulo, no al ámbito global compartido.

Más adelante estudiaremos cómo organizar y reutilizar código mediante módulos.

Ámbito local de una función

Una variable declarada dentro de una función pertenece a su ámbito local. Esto significa que su nombre puede utilizarse dentro de la función, pero no directamente desde el código exterior.

Observa el siguiente ejemplo:

JavaScript 
function calcularSubtotal(precio, cantidad) {
  const subtotal = precio * cantidad;

  console.log("Subtotal: " + subtotal + " €");
}

calcularSubtotal(25, 3);

La consola mostrará:

Consola 
Subtotal: 75 €

La variable subtotal se declara dentro de calcularSubtotal(). Podemos utilizarla durante la ejecución de la función, pero su nombre no es accesible directamente fuera de ella.

Utilizar return para recuperar un resultado

En el apartado 5.4 aprendimos que una función puede devolver un valor mediante return. Este mecanismo nos permite recuperar un resultado sin tener que acceder a sus variables locales.

JavaScript 
function calcularSubtotal(precio, cantidad) {
  const subtotal = precio * cantidad;

  return subtotal;
}

const importePedido = calcularSubtotal(25, 3);

console.log(importePedido);

La salida será:

Consola 
75

Aunque subtotal es una variable local, su valor se devuelve y se almacena en otra variable llamada importePedido.

Debemos distinguir entre acceder a una variable local y recibir el valor que una función devuelve. Son operaciones diferentes.

📌 Importante

La sentencia return no convierte una variable local en global. Simplemente devuelve un valor a la llamada de la función.

Variables locales en llamadas diferentes

Cada vez que invocamos una función, se realiza una nueva ejecución con sus propios parámetros y variables locales.

JavaScript 
function calcularDoble(numero) {
  const resultado = numero * 2;

  return resultado;
}

console.log(calcularDoble(4));
console.log(calcularDoble(7));
console.log(calcularDoble(10));

La consola mostrará:

Consola 
8
14
20

En cada llamada, el parámetro numero recibe un valor diferente y la variable local resultado se utiliza para calcular la respuesta correspondiente.

Estas ejecuciones no comparten automáticamente una misma variable local resultado.

Parámetros y variables locales

Los parámetros de una función también tienen un ámbito limitado. Sus nombres pertenecen al ámbito de la función y pueden utilizarse dentro de ella.

Por tanto, tanto los parámetros como las variables declaradas dentro de una función forman parte de la información con la que trabaja esa función.

JavaScript 
function mostrarPedido(producto, cantidad) {
  const mensaje = producto + ": " + cantidad + " unidades";

  console.log(mensaje);
}

mostrarPedido("Ratón", 3);

La consola mostrará:

Consola 
Ratón: 3 unidades

En este ejemplo tenemos tres nombres locales:

  • producto: parámetro que recibe el nombre del producto.
  • cantidad: parámetro que recibe el número de unidades.
  • mensaje: variable local que almacena el texto que se mostrará.

Los tres pueden utilizarse dentro de mostrarPedido(), pero no están disponibles directamente fuera de ella.

El nombre del argumento y el del parámetro

Recuerda que el argumento es el valor proporcionado durante la llamada y el parámetro es el nombre utilizado dentro de la función.

JavaScript 
const precioProducto = 30;

function calcularIVA(precio) {
  return precio * 0.21;
}

const iva = calcularIVA(precioProducto);

console.log(iva);
console.log(precioProducto);

La consola mostrará:

Consola 
6.3
30

La variable precioProducto se utiliza como argumento. Dentro de la función, el valor recibido se utiliza mediante el parámetro precio.

Ambos nombres pertenecen a ámbitos distintos. No es necesario que el argumento y el parámetro tengan el mismo nombre.

💻 Ejemplo DAW

Una aplicación web puede obtener el precio de un producto desde un formulario y enviarlo a una función mediante un argumento.

La función utiliza su propio parámetro para calcular el resultado, sin depender del nombre de la variable utilizada en el formulario.

Acceso a variables de ámbitos externos

Hasta ahora hemos visto que una función puede acceder a variables globales y que sus variables locales no están disponibles desde fuera.

Esta diferencia se debe a que JavaScript busca los nombres de las variables siguiendo las relaciones entre los ámbitos.

Cuando utilizamos un nombre, JavaScript comienza buscándolo en el ámbito actual. Si no lo encuentra, continúa por los ámbitos exteriores en los que se ha definido ese código.

Buscar una variable en un ámbito exterior

JavaScript 
const tienda = "TecnoDAW";

function mostrarProducto() {
  const producto = "Monitor";

  console.log(tienda);
  console.log(producto);
}

mostrarProducto();

La consola mostrará:

Consola 
TecnoDAW
Monitor

Al buscar producto, JavaScript encuentra la variable dentro de la función.

En cambio, al buscar tienda, no encuentra una declaración local con ese nombre y continúa buscando en el ámbito exterior.

Ámbito exterior const tienda = "TecnoDAW"
↓ Accesible desde el interior
Ámbito de mostrarProducto() const producto = "Monitor"
↑ No accesible directamente desde fuera
Regla fundamental Un ámbito interno puede consultar nombres de ámbitos exteriores; el acceso inverso no es automático

Funciones declaradas dentro de otras funciones

JavaScript también permite declarar una función dentro de otra. En ese caso, la función interna puede acceder a variables de la función exterior.

JavaScript 
function mostrarPedido() {
  const producto = "Teclado";

  function mostrarDetalle() {
    console.log("Producto: " + producto);
  }

  mostrarDetalle();
}

mostrarPedido();

La consola mostrará:

Consola 
Producto: Teclado

mostrarDetalle() puede utilizar producto porque se ha definido dentro de mostrarPedido().

Esta forma de buscar variables se conoce como ámbito léxico: el acceso depende del lugar donde está escrito y definido el código, no simplemente del lugar desde el que se llama a una función.

📌 Importante

Una función puede acceder a nombres declarados en sus ámbitos exteriores, pero no puede acceder automáticamente a las variables locales de cualquier otra función.

Ámbito de bloque

En JavaScript, las llaves { } pueden delimitar un bloque de instrucciones.

Ya hemos utilizado bloques al trabajar con estructuras como if, for y while.

Las variables declaradas con let y const dentro de un bloque tienen ámbito de bloque. Esto significa que no podemos acceder directamente a ellas desde fuera de ese bloque.

Variables declaradas dentro de un if

JavaScript 
const precio = 120;

if (precio >= 100) {
  const descuento = 10;

  console.log("Descuento: " + descuento + " €");
}

console.log("Precio: " + precio + " €");

La consola mostrará:

Consola 
Descuento: 10 €
Precio: 120 €

La variable descuento se declara dentro del bloque del if. Por tanto, solo puede utilizarse dentro de ese bloque.

Si después intentamos ejecutar console.log(descuento); fuera del bloque, se producirá un ReferenceError.

Variables declaradas dentro de un bucle

JavaScript 
for (let i = 1; i <= 3; i++) {
  console.log("Iteración " + i);
}

La consola mostrará:

Consola 
Iteración 1
Iteración 2
Iteración 3

La variable i se declara con let en el encabezado del bucle. Su ámbito está asociado al propio for.

Por eso, si intentamos acceder a i después del bucle, se producirá un error.

Bloques dentro de funciones

Una función puede contener varios bloques y cada uno puede tener sus propias variables.

JavaScript 
function comprobarStock(stock) {
  const producto = "Monitor";

  if (stock > 0) {
    const mensaje = "Disponible";

    console.log(producto + ": " + mensaje);
  }

  console.log("Comprobación terminada");
}

comprobarStock(5);

La consola mostrará:

Consola 
Monitor: Disponible
Comprobación terminada

producto pertenece al ámbito de la función y puede utilizarse dentro del bloque if.

En cambio, mensaje pertenece al ámbito del bloque if y no puede utilizarse directamente después de su llave de cierre.

⚠️ Atención

No debemos confundir el ámbito de función con el ámbito de bloque. Una función puede contener bloques más pequeños que limitan todavía más el acceso a determinadas variables.

Diferencias entre var, let y const

En la UT2 estudiamos las palabras clave var, let y const para declarar variables.

Ahora vamos a profundizar en una diferencia especialmente importante: no todas establecen el mismo ámbito.

Declaración Ámbito habitual ¿Permite reasignación?
var Función o global, según dónde se declare. Sí.
let Bloque. Sí.
const Bloque. No permite reasignar la variable.

Comportamiento de var dentro de un bloque

Las variables declaradas con var no quedan limitadas por un bloque if de la misma manera que las declaradas con let o const.

JavaScript 
function mostrarEjemplo() {
  if (true) {
    var mensaje = "Hola";
  }

  console.log(mensaje);
}

mostrarEjemplo();

La consola mostrará:

Consola 
Hola

Aunque mensaje se ha declarado dentro del if, su ámbito corresponde a la función mostrarEjemplo().

Comportamiento de let dentro de un bloque

Si utilizamos let, el resultado es diferente:

JavaScript 
function mostrarEjemplo() {
  if (true) {
    let mensaje = "Hola";

    console.log(mensaje);
  }
}

mostrarEjemplo();

La consola mostrará:

Consola 
Hola

En este caso, mensaje solo está disponible dentro del bloque if.

Si colocáramos console.log(mensaje); después de la llave de cierre del if, se produciría un ReferenceError.

Comportamiento de const

const tiene el mismo tipo de ámbito de bloque que let, pero además impide reasignar la variable.

JavaScript 
function mostrarProducto() {
  const producto = "Ratón";

  console.log(producto);
}

mostrarProducto();

La consola mostrará Ratón. La variable producto pertenece al ámbito de la función.

Si intentáramos asignarle otro valor mediante producto = "Teclado";, JavaScript produciría un error porque fue declarada con const.

📌 Importante

En el código JavaScript moderno se recomienda utilizar const cuando no sea necesario reasignar una variable y let cuando sí sea necesario.

Generalmente conviene evitar var en código nuevo, porque su comportamiento respecto al ámbito puede provocar confusiones y errores.

Variables con el mismo nombre en distintos ámbitos

En JavaScript es posible declarar variables con el mismo nombre en ámbitos diferentes. Esto no significa necesariamente que estemos trabajando con una única variable.

Cuando una declaración interna tiene el mismo nombre que otra exterior, la declaración interna oculta la exterior dentro de su propio ámbito.

Este comportamiento se conoce como sombreado de variables o variable shadowing.

Una variable local oculta una global

JavaScript 
const mensaje = "Mensaje global";

function mostrarMensaje() {
  const mensaje = "Mensaje local";

  console.log(mensaje);
}

mostrarMensaje();

console.log(mensaje);

La consola mostrará:

Consola 
Mensaje local
Mensaje global

Dentro de mostrarMensaje(), JavaScript encuentra primero la variable local mensaje. Por eso muestra Mensaje local.

Fuera de la función, la declaración local no está disponible y se utiliza la variable exterior.

El mismo nombre en dos funciones diferentes

JavaScript 
function mostrarCliente() {
  const nombre = "Ana";

  console.log(nombre);
}

function mostrarVendedor() {
  const nombre = "Carlos";

  console.log(nombre);
}

mostrarCliente();
mostrarVendedor();

La consola mostrará:

Consola 
Ana
Carlos

Las dos funciones declaran una variable llamada nombre, pero cada declaración pertenece a un ámbito diferente.

Por tanto, no existe un conflicto entre ellas.

⚠️ Atención

Aunque el sombreado es válido, utilizar repetidamente el mismo nombre en ámbitos anidados puede dificultar la lectura del programa.

Conviene utilizar nombres claros y evitar ocultar variables exteriores cuando pueda generar confusión.

Errores frecuentes relacionados con el ámbito

Comprender el ámbito de las variables es fundamental para evitar errores al desarrollar programas con funciones.

1. Intentar acceder a una variable local desde fuera

JavaScript 
function calcularTotal() {
  const total = 100;
}

calcularTotal();

console.log(total);

Este programa produce un ReferenceError porque total solo está declarada dentro de la función.

Si necesitamos recuperar ese valor, podemos utilizar return:

JavaScript 
function calcularTotal() {
  const total = 100;

  return total;
}

const resultado = calcularTotal();

console.log(resultado);

Ahora la consola muestra 100.

2. Pensar que dos variables con el mismo nombre son la misma

JavaScript 
let cantidad = 5;

function mostrarCantidad() {
  let cantidad = 10;

  console.log(cantidad);
}

mostrarCantidad();

console.log(cantidad);

La salida será:

Consola 
10
5

La variable local oculta a la exterior dentro de la función. No estamos modificando la variable exterior.

3. Utilizar una variable de bloque fuera de él

JavaScript 
if (true) {
  const estado = "Disponible";
}

console.log(estado);

Este código produce un ReferenceError. La variable estado se ha declarado dentro del bloque if.

4. Utilizar una variable antes de declararla

Con let y const, no podemos acceder a una variable antes de que se ejecute su declaración.

JavaScript 
function mostrarPrecio() {
  console.log(precio);

  const precio = 50;
}

mostrarPrecio();

El programa produce un ReferenceError porque intentamos acceder a precio antes de que su declaración haya sido inicializada.

El intervalo entre el comienzo del ámbito y la inicialización de una variable let o const se conoce como zona muerta temporal o Temporal Dead Zone (TDZ).

Para corregirlo, declaramos la variable antes de utilizarla.

JavaScript 
function mostrarPrecio() {
  const precio = 50;

  console.log(precio);
}

mostrarPrecio();

Ahora la consola mostrará 50.

5. Modificar una variable global sin necesidad

JavaScript 
let total = 0;

function calcularImporte(precio, cantidad) {
  total = precio * cantidad;
}

calcularImporte(20, 3);

console.log(total);

Este programa funciona y muestra 60, pero la función modifica directamente una variable exterior.

Una alternativa más reutilizable consiste en devolver el resultado:

JavaScript 
function calcularImporte(precio, cantidad) {
  return precio * cantidad;
}

const total = calcularImporte(20, 3);

console.log(total);

La salida sigue siendo 60, pero ahora la función no depende de una variable global para comunicar su resultado.

⚠️ Atención

No todos los errores de ámbito producen inmediatamente un mensaje de error en la consola.

En ocasiones, el programa funciona, pero utiliza o modifica una variable distinta de la que esperábamos.

Buenas prácticas al trabajar con variables

Para escribir funciones claras y fáciles de mantener, conviene organizar adecuadamente el ámbito de sus variables.

  • Preferir variables locales: declarar los datos dentro de la función o del bloque donde se necesitan.
  • Limitar las variables globales: evitar que distintas funciones dependan innecesariamente de datos compartidos.
  • Utilizar parámetros: proporcionar a las funciones los datos que necesitan para trabajar.
  • Utilizar return: devolver los resultados que otras partes del programa necesitan.
  • Preferir const y let: utilizar const cuando no se necesite reasignación y let cuando sí.
  • Evitar nombres ambiguos: escoger nombres descriptivos y reducir el sombreado innecesario.
  • Declarar cerca del uso: situar las variables en el ámbito más reducido que permita utilizarlas correctamente.

Comparación entre dos formas de organizar un cálculo

Observa esta primera versión:

JavaScript 
let precio = 25;
let cantidad = 4;
let total = 0;

function calcularTotal() {
  total = precio * cantidad;
}

calcularTotal();

console.log(total);

Esta función depende de tres variables exteriores. Si alguna cambia, el resultado de la función también puede cambiar.

Ahora observa una versión que utiliza parámetros y un valor de retorno:

JavaScript 
function calcularTotal(precio, cantidad) {
  const importe = precio * cantidad;

  return importe;
}

const total = calcularTotal(25, 4);

console.log(total);

Las dos versiones muestran 100, pero la segunda presenta varias ventajas:

  • La función recibe explícitamente los datos necesarios.
  • El cálculo se realiza mediante una variable local.
  • El resultado se devuelve mediante return.
  • La función puede reutilizarse con diferentes precios y cantidades.
💻 Ejemplo DAW

En una aplicación de comercio electrónico, las funciones de cálculo deberían poder trabajar con distintos productos sin depender de variables globales específicas de cada pedido.

Esta organización facilita las pruebas, la reutilización del código y el mantenimiento de la aplicación.

Ejemplo práctico completo: gestionar un pedido de una tienda online

Vamos a aplicar los conceptos estudiados mediante un programa que gestione un pedido sencillo de una tienda online.

En el apartado 5.4 utilizamos return para comunicar resultados entre funciones. Ahora prestaremos especial atención a dónde se declaran las variables y desde dónde pueden utilizarse.

Nuestro programa debe:

  • identificar la tienda;
  • calcular el subtotal de un producto;
  • aplicar un descuento cuando corresponda;
  • calcular el importe final;
  • mostrar un resumen del pedido.

Utilizaremos una constante exterior para el nombre de la tienda y varias funciones con parámetros y variables locales para realizar las operaciones.

JavaScript 
// Constante del ámbito exterior
const nombreTienda = "TecnoDAW";

// Calcula el subtotal
function calcularSubtotal(precio, cantidad) {
  const subtotal = precio * cantidad;

  return subtotal;
}

// Calcula el descuento
function calcularDescuento(subtotal) {
  if (subtotal >= 100) {
    const porcentaje = 0.10;

    return subtotal * porcentaje;
  }

  return 0;
}

// Calcula el importe final
function calcularTotal(subtotal, descuento) {
  const total = subtotal - descuento;

  return total;
}

// Muestra la información del pedido
function mostrarResumen(producto, subtotal, descuento, total) {
  const titulo = "RESUMEN DEL PEDIDO";

  console.log(titulo);
  console.log("Tienda: " + nombreTienda);
  console.log("Producto: " + producto);
  console.log("Subtotal: " + subtotal.toFixed(2) + " €");
  console.log("Descuento: " + descuento.toFixed(2) + " €");
  console.log("Total: " + total.toFixed(2) + " €");
}

// Programa principal
const producto = "Monitor";
const precio = 150;
const cantidad = 2;

const subtotal = calcularSubtotal(precio, cantidad);
const descuento = calcularDescuento(subtotal);
const total = calcularTotal(subtotal, descuento);

mostrarResumen(producto, subtotal, descuento, total);

La salida completa será:

Consola

Tienda: TecnoDAW

Análisis paso a paso

Vamos a comprobar cómo se organiza la información en los distintos ámbitos.

Variable Ámbito Finalidad
nombreTienda Exterior a las funciones. Identificar la tienda.
precio y cantidad (parámetros) Función calcularSubtotal(). Recibir los datos del cálculo.
subtotal (local) Función calcularSubtotal(). Guardar el producto del precio por la cantidad.
porcentaje Bloque if de calcularDescuento(). Representar el descuento del 10 %.
total (local) Función calcularTotal(). Calcular el importe final.

producto, precio, cantidad, subtotal, descuento y total del programa principal Ámbito exterior a las funciones. Organizar los datos y resultados del pedido.

¿Por qué no hay conflictos entre los nombres?

En este programa aparecen varias declaraciones que utilizan nombres como subtotal y total.

Por ejemplo, calcularTotal() declara una variable local llamada total, mientras que el programa principal también declara una variable con ese nombre.

No existe un conflicto porque pertenecen a ámbitos diferentes.

La función calcula su propio resultado y lo devuelve mediante return. Después, el programa principal almacena ese valor en su variable total.

¿Qué sucede con la variable porcentaje?

La variable porcentaje solo se declara cuando se ejecuta el bloque if y únicamente puede utilizarse dentro de él.

En nuestro ejemplo, el subtotal es 300, por lo que se cumple la condición subtotal >= 100.

Se calcula entonces el 10 % de descuento: 300 * 0.10 = 30.

La función devuelve 30 y no es necesario acceder directamente a la variable local porcentaje desde el resto del programa.

¿Qué ventajas ofrece esta organización?

Cada función utiliza sus propios parámetros y variables locales para realizar una tarea concreta.

Los resultados se comunican mediante valores de retorno, y las funciones no necesitan modificar variables exteriores para realizar los cálculos.

Esto facilita que podamos utilizar las mismas funciones para otros pedidos con diferentes productos, precios y cantidades.

📌 Importante

Una buena organización del ámbito permite que las funciones trabajen de forma más independiente.

Siempre que sea posible, conviene proporcionar los datos mediante parámetros, realizar los cálculos con variables locales y devolver los resultados mediante return.

En el siguiente apartado estudiaremos qué sucede cuando proporcionamos a una función distintos tipos de valores, especialmente al trabajar con arrays y objetos.

💭 Piensa

Observa el siguiente programa sin ejecutarlo:

JavaScript 
const tienda = "TecnoDAW";
let cantidad = 2;

function calcularPedido(precio) {
  const cantidad = 3;
  const subtotal = precio * cantidad;

  if (subtotal >= 100) {
    const descuento = 10;

    console.log("Descuento: " + descuento);
  }

  console.log("Tienda: " + tienda);

  return subtotal;
}

const total = calcularPedido(40);

console.log(total);
console.log(cantidad);

Responde a las siguientes preguntas:

  1. ¿Qué variables están declaradas fuera de la función?
  2. ¿Qué variables y parámetros pertenecen al ámbito de calcularPedido()?
  3. ¿Por qué podemos utilizar tienda dentro de la función?
  4. ¿Qué valor tiene cantidad dentro de la función y cuál tiene fuera de ella?
  5. ¿Qué mensajes aparecerán en la consola y en qué orden?
  6. ¿Qué ocurriría si añadiéramos console.log(descuento); después del bloque if, dentro de la función?
Ver una posible solución

1. Fuera de la función se declaran tienda, cantidad y, después de la llamada, total.

2. El parámetro precio y las variables cantidad y subtotal pertenecen al ámbito de la función. descuento pertenece específicamente al bloque if.

3. La función puede utilizar tienda porque está declarada en un ámbito exterior accesible desde ella.

4. Dentro de la función, cantidad vale 3. Fuera de ella, la variable exterior cantidad sigue valiendo 2.

5. La salida completa será:

Consola 
Descuento: 10
Tienda: TecnoDAW
120
2

El subtotal se calcula mediante 40 * 3 = 120. Como es mayor o igual que 100, se ejecuta el bloque del descuento.

Después se muestra el nombre de la tienda y la función devuelve 120. Finalmente, el programa principal muestra 120 y la cantidad exterior 2.

6. Si añadimos console.log(descuento); después del bloque if, se producirá un ReferenceError.

Esto sucede porque descuento fue declarada con const dentro del bloque y no puede utilizarse fuera de él.
