✏️ Resumen de la UT5

En esta unidad hemos aprendido a utilizar las funciones de JavaScript para organizar instrucciones, reutilizar código, recibir datos mediante parámetros y devolver resultados.

También hemos estudiado el ámbito de las variables, el comportamiento de los valores y las referencias, las funciones flecha, los callbacks, la recursividad y la organización modular de programas.

Este resumen reúne las ideas fundamentales de los apartados 5.1 a 5.12 y sirve como guía rápida de repaso de los conceptos y las diferencias que debes comprender antes de avanzar en el desarrollo de aplicaciones JavaScript.

📌 Idea principal

Una función permite agrupar instrucciones relacionadas bajo un nombre, ejecutarlas cuando sea necesario y, si corresponde, devolver un resultado.

5.1 Introducción a las funciones

Una función es un bloque de instrucciones diseñado para realizar una tarea concreta. Podemos ejecutarla tantas veces como necesitemos sin repetir su código.

♻️ Reutilización

Una misma función puede utilizarse en diferentes partes del programa.

🧩 Organización

Permite dividir problemas grandes en tareas más pequeñas.

🔧 Mantenimiento

Los cambios pueden realizarse en un único lugar.

JavaScript — Primera función 
function saludar() {
  console.log("Hola");
}

saludar();
saludar();

La función se declara una vez y se invoca dos veces. Por eso se muestra dos veces el mensaje Hola.

📌 Recuerda

Declarar una función no significa que su cuerpo se ejecute inmediatamente. Para ejecutarla normalmente debemos invocarla.

5.2 Declaración e invocación de funciones

Para utilizar una función debemos distinguir entre su declaración, donde definimos las instrucciones, y su invocación, donde solicitamos su ejecución.

Declaración Define el nombre, los parámetros y el cuerpo de la función.
Invocación Ejecuta la función escribiendo su nombre seguido de paréntesis.
Cuerpo Contiene las instrucciones que ejecutará la función.
Flujo de ejecución Al llamar a una función, el programa ejecuta su cuerpo y después continúa donde correspondía.
JavaScript — Declaración e invocación 
function mostrarMensaje() {
  console.log("Estoy dentro de la función");
}

console.log("Inicio");

mostrarMensaje();

console.log("Fin");

El orden de los mensajes será: Inicio, Estoy dentro de la función y Fin.

⚠️ Atención

Escribir mostrarMensaje y escribir mostrarMensaje() no significa lo mismo: la primera expresión hace referencia a la función y la segunda la invoca.

5.3 Parámetros y argumentos

Los parámetros permiten que una función reciba información y trabaje con distintos datos sin modificar su definición.

Concepto Significado Ejemplo
Parámetro Variable declarada en la definición de la función. nombre
Argumento Valor que proporcionamos al invocar la función. "Lucía"
JavaScript — Parámetros y argumentos 
function saludar(nombre) {
  console.log("Hola, " + nombre);
}

saludar("Lucía");
saludar("Carlos");

nombre es el parámetro. "Lucía" y "Carlos" son los argumentos utilizados en cada llamada.

📌 Recuerda

Los parámetros aparecen en la definición; los argumentos se proporcionan en la llamada.

5.4 Valores de retorno y sentencia return

Una función puede realizar instrucciones y también devolver un valor mediante la sentencia return.

return Finaliza la ejecución de la función y devuelve el valor indicado.
Valor devuelto Puede almacenarse en una variable o utilizarse en otra expresión.
Sin return explícito Una función normal devuelve undefined si termina sin devolver otro valor.
console.log() Muestra información, pero no sustituye a la devolución de un resultado.
JavaScript — Devolver un resultado 
function sumar(a, b) {
  return a + b;
}

const resultado = sumar(8, 5);

console.log(resultado); // 13
⚠️ Atención

console.log() muestra un dato en consola; return entrega un resultado al código que llamó a la función. Son operaciones diferentes.

5.5 Ámbito de las variables en las funciones

El ámbito determina desde qué partes del programa podemos acceder a una variable.

🌍 Ámbito global

Variables declaradas fuera de las funciones y disponibles según su entorno y reglas de acceso.

📦 Ámbito de función

Variables y parámetros accesibles dentro de la función correspondiente.

🧱 Ámbito de bloque

Las declaraciones con let y const respetan el bloque donde se definen.

JavaScript — Variable local 
function calcular() {
  const resultado = 10 + 5;

  console.log(resultado);
}

calcular(); // 15

// Fuera de la función, resultado
// no está disponible.
📌 Recuerda

Es recomendable limitar el ámbito de las variables y evitar dependencias innecesarias de variables globales.

5.6 Paso de valores y referencias a funciones

En JavaScript, los argumentos se pasan por valor. Sin embargo, cuando ese valor permite acceder a un objeto, la función puede modificar las propiedades del mismo objeto.

Tipo de dato Comportamiento habitual
Primitivos
Number, String, Boolean... 		Modificar el parámetro dentro de la función no modifica la variable original.
Objetos y arrays La función puede modificar sus propiedades o elementos si son modificables.
JavaScript — Modificar un objeto 
function cambiarNombre(persona) {
  persona.nombre = "Ana";
}

const usuario = {
  nombre: "Luis"
};

cambiarNombre(usuario);

console.log(usuario.nombre); // Ana
⚠️ Atención

Esto no significa que JavaScript utilice paso por referencia para los parámetros. Lo que se copia es el valor que permite acceder al mismo objeto.

5.7 Parámetros por defecto y parámetros rest

JavaScript permite asignar valores por defecto a los parámetros y recoger varios argumentos mediante la sintaxis ....

Parámetros por defecto Se utilizan cuando el argumento correspondiente es undefined o no se proporciona.
Parámetros rest Agrupan los argumentos restantes en un array.
JavaScript — Parámetro por defecto 
function saludar(nombre = "invitado") {
  return "Hola, " + nombre;
}

console.log(saludar());
// Hola, invitado

console.log(saludar("Marta"));
// Hola, Marta
JavaScript — Parámetro rest 
function sumarTodos(...numeros) {
  let total = 0;

  for (const numero of numeros) {
    total += numero;
  }

  return total;
}

console.log(sumarTodos(2, 3, 5)); // 10
📌 Recuerda

El parámetro rest debe ocupar la última posición en la lista de parámetros de una función.

5.8 Expresiones de función y funciones flecha

Además de declarar funciones con function, podemos crear expresiones de función y funciones flecha.

Forma Ejemplo
Declaración function sumar(a, b) { return a + b; }
Expresión de función const sumar = function(a, b) { return a + b; };
Función flecha const sumar = (a, b) => a + b;
JavaScript — Función flecha 
const cuadrado = numero => numero * numero;

console.log(cuadrado(4)); // 16
⚠️ Atención

Las funciones flecha no son completamente equivalentes a las funciones tradicionales: entre otras diferencias, no tienen su propio this y no pueden utilizarse como constructores con new.

5.9 Funciones como valores y funciones callback

En JavaScript, las funciones son valores: podemos almacenarlas en variables, pasarlas como argumentos y devolverlas desde otras funciones.

Una callback es una función que se proporciona a otra función para que esta pueda ejecutarla.

JavaScript — Función callback 
function procesar(numero, operacion) {
  return operacion(numero);
}

function duplicar(numero) {
  return numero * 2;
}

const resultado = procesar(5, duplicar);

console.log(resultado); // 10
Función como valor Podemos asignarla a una variable o pasarla como argumento.
Callback Es la función que otra función recibe para ejecutarla.
Funciones de orden superior Reciben funciones como argumentos o devuelven funciones.
Uso habitual Procesamiento de arrays, eventos y operaciones que requieren una función proporcionada por el programador.
📌 Recuerda

Pasar duplicar como argumento permite entregar la función. Escribir duplicar() supondría invocarla inmediatamente y pasar el valor que devolviese.

5.10 Funciones predefinidas y métodos de JavaScript

JavaScript proporciona numerosas funciones y métodos que permiten realizar operaciones habituales sin tener que programarlas desde cero.

Función o método Utilidad
Number() Intenta convertir un valor a número.
parseInt() Analiza una cadena para obtener un número entero.
parseFloat() Analiza una cadena para obtener un número decimal.
Number.isNaN() Comprueba si un valor numérico es NaN.
Math.round() Redondea al entero más próximo.
Math.max() Devuelve el mayor de los valores indicados.
Math.random() Genera un número pseudoaleatorio entre 0 incluido y 1 excluido.
toUpperCase() Convierte los caracteres de una cadena a mayúsculas.
includes() Comprueba si una cadena o array contiene un elemento o fragmento.
JavaScript — Funciones y métodos 
console.log(Number("25"));       // 25
console.log(Math.max(4, 9, 2));  // 9

const mensaje = "hola";

console.log(mensaje.toUpperCase());
// HOLA
⚠️ Atención

No debemos confundir una función global, como parseInt(), con un método de un objeto, como Math.round(), ni con un método de cadena, como toUpperCase().

5.11 Funciones recursivas

Una función recursiva es aquella que se llama a sí misma para resolver un problema mediante versiones más pequeñas de ese mismo problema.

Caso base Condición que permite detener las llamadas recursivas.
Caso recursivo Parte que realiza una nueva llamada con un problema más pequeño.
Pila de llamadas Mantiene las llamadas pendientes mientras se ejecuta la recursividad.
Condición de terminación Debe existir una progresión real hacia el caso base.
JavaScript — Factorial recursivo 
function factorial(n) {
  if (n === 0 || n === 1) {
    return 1;
  }

  return n * factorial(n - 1);
}

console.log(factorial(4)); // 24

Para calcular factorial(4), la función realiza llamadas para los valores 4, 3, 2 y 1, y después combina los resultados: 4 × 3 × 2 × 1 = 24.

⚠️ Atención

Si no existe un caso base alcanzable, las llamadas pueden continuar hasta desbordar la pila de ejecución. Además, este ejemplo presupone un entero no negativo y no valida la entrada.

5.12 Organización modular de un programa

La organización modular consiste en dividir un programa en partes relacionadas y con responsabilidades claras. En JavaScript moderno podemos distribuir estas partes en módulos ES.

📁 Separación de archivos

Cada archivo agrupa funciones y elementos relacionados.

📤 export

Permite compartir funciones, constantes y otros valores con otros módulos.

📥 import

Permite utilizar elementos exportados desde otros módulos.

Ejemplo de organización

Estructura de archivos 
proyecto/
├── index.html
└── js/
    ├── operaciones.js
    └── main.js

Exportar una función

JavaScript — operaciones.js 
export function sumar(a, b) {
  return a + b;
}

Importar y utilizar la función

JavaScript — main.js 
import { sumar } from "./operaciones.js";

console.log(sumar(3, 7)); // 10

Cargar el módulo desde HTML

HTML — index.html 
<script type="module" src="js/main.js"></script>
📌 Recuerda

export indica qué elementos comparte un módulo; import permite utilizarlos desde otro módulo. En el navegador debemos cargar el módulo principal con type="module".

⚠️ Atención

Utilizar varios archivos JavaScript no significa necesariamente utilizar módulos ES. Para probar importaciones en el navegador conviene utilizar un servidor local, como Live Server.

Ideas clave de la UT5

📌 Si tuvieras que recordar solo estas ideas…
  • Las funciones permiten agrupar instrucciones y reutilizar código.
  • Declarar una función no equivale a invocarla.
  • Los parámetros aparecen en la definición y los argumentos se proporcionan en la llamada.
  • return devuelve un resultado y termina la ejecución de la función. No es lo mismo que console.log().
  • El ámbito determina dónde pueden utilizarse las variables.
  • JavaScript pasa los argumentos por valor, aunque varios valores puedan permitir acceder al mismo objeto.
  • Los parámetros por defecto proporcionan valores alternativos y rest agrupa argumentos restantes en un array.
  • Las funciones flecha ofrecen una sintaxis más concisa, pero tienen diferencias respecto a las funciones tradicionales.
  • Una callback es una función que se entrega a otra para que pueda ejecutarla.
  • JavaScript proporciona funciones y métodos predefinidos que facilitan operaciones habituales.
  • Toda función recursiva debe disponer de un caso base y avanzar hacia él.
  • Los módulos ES permiten organizar archivos y compartir elementos mediante export e import.
💻 Aplicación al desarrollo web

En una aplicación de gestión de pedidos podemos utilizar funciones para validar datos, calcular subtotales, aplicar descuentos y mostrar resultados. Si el proyecto crece, esas funciones pueden distribuirse en módulos especializados para facilitar su mantenimiento.
