5.1 Introducción a las funciones

Hasta ahora hemos aprendido a utilizar variables, operadores, estructuras de control y arrays para desarrollar programas en JavaScript. Con estas herramientas podemos realizar cálculos, tomar decisiones, repetir instrucciones y trabajar con conjuntos de datos.

Sin embargo, a medida que desarrollamos aplicaciones más completas, aparecen nuevas necesidades. Por ejemplo, puede que tengamos que realizar el mismo cálculo en diferentes partes del programa, comprobar repetidamente determinados datos o ejecutar varias instrucciones cada vez que se produce una situación concreta.

Si escribimos todas esas instrucciones una y otra vez, el programa puede resultar difícil de comprender, modificar y mantener. Para resolver este problema utilizamos las funciones.

📌 Importante

Una función es un bloque de código que agrupa instrucciones destinadas a realizar una tarea determinada y que puede ejecutarse cuando el programa lo necesita.

Qué es una función

Una función permite reunir varias instrucciones bajo un mismo nombre para utilizarlas como una unidad dentro de un programa.

En lugar de escribir repetidamente todas las instrucciones necesarias para realizar una tarea, podemos definir una función y solicitar su ejecución cuando sea necesario.

Imagina que estamos desarrollando una aplicación para gestionar los pedidos de una tienda online. La aplicación necesita realizar operaciones como:

  • calcular el importe total de un pedido;
  • comprobar si un producto está disponible;
  • aplicar un descuento;
  • mostrar un mensaje de confirmación;
  • calcular los gastos de envío.

Cada una de estas operaciones puede organizarse mediante una función diferente. De esta manera, el programa queda dividido en partes más pequeñas y resulta más sencillo comprender qué hace cada una.

Una función como tarea independiente

Podemos imaginar una función como una pequeña herramienta dentro de nuestra aplicación. Cada herramienta tiene una responsabilidad concreta y podemos utilizarla cuando la necesitemos.

Calcular Realizar operaciones con datos
Comprobar Verificar condiciones
Mostrar Presentar información

Esta separación no significa que las funciones trabajen siempre de forma aislada. Una función puede utilizar información, devolver resultados e incluso llamar a otras funciones.

Lo importante es comprender que cada función permite identificar y organizar una operación concreta dentro de un programa más amplio.

Para qué necesitamos funciones

Las funciones son fundamentales porque permiten resolver problemas habituales que aparecen cuando los programas empiezan a crecer.

Para comprenderlo, imaginemos que queremos mostrar un mensaje de bienvenida en diferentes momentos de una aplicación.

Un programa sin funciones

Podríamos escribir las mismas instrucciones cada vez que necesitáramos mostrar el mensaje:

JavaScript 
console.log("Bienvenido a la aplicación");
console.log("Esperamos que disfrutes de la experiencia");

// Otras instrucciones del programa

console.log("Bienvenido a la aplicación");
console.log("Esperamos que disfrutes de la experiencia");

// Más instrucciones del programa

console.log("Bienvenido a la aplicación");
console.log("Esperamos que disfrutes de la experiencia");

Este código funciona, pero presenta varios inconvenientes:

  • Repetición: escribimos las mismas instrucciones varias veces.
  • Mantenimiento: si queremos modificar el mensaje, debemos localizar y cambiar todas sus apariciones.
  • Legibilidad: el programa contiene más instrucciones de las necesarias y puede resultar más difícil de seguir.
  • Riesgo de errores: podemos modificar unas copias y olvidar otras.

El mismo programa utilizando una función

Podemos agrupar las instrucciones repetidas dentro de una función llamada mostrarBienvenida().

JavaScript 
function mostrarBienvenida() {
  console.log("Bienvenido a la aplicación");
  console.log("Esperamos que disfrutes de la experiencia");
}

// Primera llamada
mostrarBienvenida();

// Otras instrucciones del programa

// Segunda llamada
mostrarBienvenida();

// Más instrucciones del programa

// Tercera llamada
mostrarBienvenida();

Ahora las instrucciones que muestran el mensaje están escritas una sola vez. Cada vez que necesitamos ejecutarlas, utilizamos el nombre de la función seguido de paréntesis.

Si queremos cambiar el mensaje, únicamente tendremos que modificar las instrucciones que aparecen dentro de la función.

⚠️ Atención

Definir una función no significa ejecutarla inmediatamente. En este ejemplo, las instrucciones de mostrarBienvenida() se ejecutan cuando realizamos una llamada a la función. Estudiaremos esta diferencia con detalle en el apartado 5.2.

Reutilización del código

Una de las principales ventajas de las funciones es la reutilización del código. Consiste en escribir una solución una sola vez y poder utilizarla en diferentes partes del programa.

Esto resulta especialmente útil cuando una operación debe realizarse repetidamente o cuando diferentes partes de una aplicación necesitan aplicar la misma lógica.

Ejemplo: calcular un descuento

Supongamos que una tienda online aplica un descuento del 10 % sobre determinados productos.

Si realizamos el cálculo directamente cada vez que lo necesitamos, podríamos escribir:

JavaScript 
const precio1 = 100;
const precioFinal1 = precio1 - precio1 * 0.10;

const precio2 = 250;
const precioFinal2 = precio2 - precio2 * 0.10;

const precio3 = 80;
const precioFinal3 = precio3 - precio3 * 0.10;

console.log(precioFinal1); // 90
console.log(precioFinal2); // 225
console.log(precioFinal3); // 72

Aunque el programa es correcto, estamos repitiendo la misma operación matemática para cada producto.

Podemos evitarlo creando una función que reciba el precio y calcule el descuento.

JavaScript 
function calcularDescuento(precio) {
  return precio - precio * 0.10;
}

console.log(calcularDescuento(100)); // 90
console.log(calcularDescuento(250)); // 225
console.log(calcularDescuento(80));  // 72

En este segundo ejemplo, la operación matemática está definida una sola vez. Podemos utilizar la función con diferentes precios sin repetir el cálculo.

Observa que hemos introducido dos elementos nuevos:

  • precio es un parámetro, que permite proporcionar un dato a la función.
  • return permite devolver un resultado al código que ha llamado a la función.

Por ahora basta con comprender su finalidad general. Los parámetros y los valores de retorno se estudiarán detalladamente en los apartados 5.3 y 5.4.

📌 Importante

Reutilizar código no consiste únicamente en escribir menos instrucciones. También permite centralizar la lógica de una operación, facilitar los cambios y reducir las posibilidades de introducir errores.

Organización del programa

Además de reutilizar instrucciones, las funciones permiten dividir un programa complejo en tareas más pequeñas.

Esta forma de trabajar facilita la comprensión del código, porque podemos analizar cada operación por separado antes de estudiar cómo se relaciona con las demás.

Dividir un problema en tareas

Imagina que tenemos que desarrollar una aplicación que gestione las calificaciones de un grupo de estudiantes.

La aplicación podría necesitar:

  • calcular la nota media de un estudiante;
  • determinar si ha aprobado;
  • obtener la calificación más alta;
  • contar el número de aprobados;
  • mostrar un resumen de resultados.

En lugar de desarrollar todas estas operaciones en un único bloque de instrucciones, podemos plantear una función para cada tarea.

Tarea Posible función Responsabilidad
Calcular la media calcularMedia() Obtener la media aritmética de un conjunto de calificaciones.
Comprobar el aprobado estaAprobado() Determinar si una nota alcanza el mínimo establecido.
Buscar la nota máxima obtenerNotaMaxima() Identificar la calificación más alta.
Contar aprobados contarAprobados() Contabilizar las calificaciones que cumplen la condición.
Mostrar resultados mostrarResumen() Presentar la información obtenida.

Esta tabla representa una posible organización del programa. Todavía no estamos implementando todas esas funciones, sino identificando las tareas que sería conveniente separar.

Ventajas de organizar el código en funciones

Dividir un programa en funciones proporciona varias ventajas importantes:

  • Legibilidad: los nombres de las funciones ayudan a comprender qué operaciones realiza el programa.
  • Mantenimiento: resulta más sencillo localizar y modificar una operación concreta.
  • Reutilización: una misma función puede utilizarse desde diferentes partes de la aplicación.
  • Pruebas: podemos comprobar el comportamiento de una función de forma individual.
  • Depuración: cuando aparece un error, es más fácil identificar en qué operación se produce.
  • Trabajo en equipo: diferentes personas pueden encargarse de desarrollar distintas funcionalidades, siempre que exista una organización adecuada.
💻 Ejemplo DAW

En una aplicación web de gestión de pedidos, podemos utilizar una función para calcular el subtotal, otra para aplicar descuentos y otra para calcular los gastos de envío. Así, cada operación tiene una responsabilidad concreta y puede modificarse sin tener que reescribir todo el programa.

Este planteamiento se relaciona con la programación modular, que consiste en organizar un programa en componentes con responsabilidades definidas. Las funciones son una herramienta fundamental para conseguirlo, aunque la modularidad también puede implicar otros mecanismos de organización.

Las funciones en JavaScript

JavaScript permite crear nuestras propias funciones para realizar operaciones adaptadas a las necesidades de una aplicación.

También dispone de numerosas funciones y métodos ya existentes que podemos utilizar sin tener que implementarlos desde cero.

Funciones creadas por el programador

Son aquellas que definimos para resolver tareas específicas de nuestro programa.

Por ejemplo, podemos crear una función que muestre un mensaje:

JavaScript 
function mostrarMensaje() {
  console.log("Estamos aprendiendo funciones");
}

mostrarMensaje();

La función mostrarMensaje() ha sido creada expresamente para este programa. Su finalidad es mostrar un texto en la consola.

Funciones y métodos disponibles en JavaScript

Durante las unidades anteriores ya hemos utilizado operaciones que se invocan mediante paréntesis, aunque todavía no hayamos estudiado las funciones en profundidad.

JavaScript 
const numero = Number("25");

console.log(numero);

const mayor = Math.max(10, 30, 20);

console.log(mayor);

const frutas = ["manzana", "pera"];

frutas.push("naranja");

console.log(frutas);

En este ejemplo encontramos diferentes operaciones:

  • Number("25") realiza una conversión a un valor numérico.
  • Math.max(10, 30, 20) devuelve el mayor de los números proporcionados.
  • frutas.push("naranja") añade un elemento al final del array.
  • console.log() permite mostrar información en la consola.

Algunas de estas operaciones son funciones globales, mientras que otras son métodos asociados a objetos. Estudiaremos con mayor detalle esta distinción en el apartado 5.10.

⚠️ Atención

No todas las operaciones que utilizamos mediante paréntesis son funciones globales. Por ejemplo, console.log(), Math.max() y push() son métodos. Un método es una función asociada a un objeto o a su prototipo.

Características generales de las funciones

Aunque existen distintas formas de crear funciones en JavaScript, muchas comparten estas características:

  • Pueden tener un nombre que permita identificarlas.
  • Pueden recibir datos de entrada mediante parámetros.
  • Contienen instrucciones que realizan una determinada operación.
  • Pueden devolver un resultado al código que las utiliza.
  • Pueden ejecutarse tantas veces como sea necesario.
  • Pueden llamar a otras funciones.

No todas las funciones necesitan recibir parámetros ni devolver un resultado explícito. Su estructura dependerá de la tarea que deban realizar.

Primer ejemplo de función

Vamos a estudiar un ejemplo sencillo para identificar los elementos básicos de una función en JavaScript.

Queremos desarrollar un programa que muestre un saludo de bienvenida a los estudiantes del módulo DWEC.

JavaScript 
function saludar() {
  console.log("Bienvenidos a DWEC");
}

saludar();

Al ejecutar este programa, la consola mostrará el siguiente mensaje:

Consola 
Bienvenidos a DWEC

Elementos de la función

Vamos a analizar las partes que aparecen en el ejemplo anterior.

Elemento Significado
function Palabra reservada utilizada para declarar una función.
saludar Nombre de la función.
() Paréntesis en los que pueden declararse los parámetros. En este ejemplo están vacíos.
{ } Llaves que delimitan el cuerpo de la función.
console.log(...) Instrucción que se ejecutará cuando llamemos a la función.
saludar(); Llamada o invocación que ejecuta la función.

Qué ocurre durante la ejecución

Podemos describir el funcionamiento del programa en tres pasos:

  1. JavaScript procesa la declaración de la función saludar().
  2. Cuando encuentra la instrucción saludar();, se realiza una llamada a la función.
  3. Se ejecutan las instrucciones de su cuerpo y aparece el mensaje en la consola.

Una vez finalizada la ejecución de la función, el programa continúa con las instrucciones que correspondan.

Ejecutar una función varias veces

Podemos llamar a una misma función tantas veces como necesitemos.

JavaScript 
function saludar() {
  console.log("Bienvenidos a DWEC");
}

console.log("Inicio del programa");

saludar();
saludar();
saludar();

console.log("Fin del programa");

La salida será:

Consola 
Inicio del programa
Bienvenidos a DWEC
Bienvenidos a DWEC
Bienvenidos a DWEC
Fin del programa

Observa que la función se ha definido una sola vez, pero sus instrucciones se han ejecutado tres veces.

📌 Importante

Debemos distinguir entre declarar una función, que consiste en definir las instrucciones que realizará, e invocar una función, que consiste en solicitar su ejecución. Esta diferencia será el punto de partida del siguiente apartado.

💭 Piensa

Imagina que estás desarrollando una aplicación web para gestionar las reservas de habitaciones de un hotel.

La aplicación debe comprobar la disponibilidad, calcular el precio de una estancia, aplicar descuentos y mostrar un resumen de la reserva.

¿Qué funciones crearías para organizar estas operaciones? ¿Qué ventajas tendría utilizar funciones en lugar de escribir todas las instrucciones seguidas?

Ver una posible solución

Podríamos organizar el programa mediante funciones como comprobarDisponibilidad(), calcularPrecio(), aplicarDescuento() y mostrarResumen().

Cada función tendría una responsabilidad concreta. Por ejemplo, calcularPrecio() se encargaría de calcular el importe de una estancia a partir de los datos necesarios.

Esta organización permitiría reutilizar operaciones, localizar errores con mayor facilidad y modificar determinadas funcionalidades sin tener que revisar todo el programa.

Además, el código sería más comprensible, porque los nombres de las funciones ayudarían a identificar las tareas que realiza la aplicación.
