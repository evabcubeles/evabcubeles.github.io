5.6 Paso de valores y referencias a funciones

En los apartados anteriores hemos aprendido a crear funciones, proporcionarles información mediante parámetros y argumentos, devolver resultados con return y comprender el ámbito de las variables.

Sin embargo, todavía debemos resolver una cuestión importante: ¿qué sucede con los datos originales cuando una función recibe un argumento y lo modifica?

Imagina que estamos desarrollando una tienda online. Tenemos una variable que almacena el precio de un producto y una función encargada de aplicar descuentos. También tenemos un objeto que contiene los datos del producto y un array con los productos del carrito.

¿Modificar una variable dentro de la función cambiará el precio original? ¿Qué ocurrirá si la función modifica una propiedad del objeto? ¿Y si añade un producto al array?

Aunque en todos estos casos utilizamos argumentos y parámetros, los resultados pueden ser diferentes dependiendo del tipo de dato recibido y de la operación realizada.

📌 Importante

En JavaScript, los argumentos se pasan por valor.

Cuando el argumento es un dato primitivo, la función recibe su valor. Cuando es un objeto o un array, recibe una copia del valor de referencia que permite acceder al mismo objeto o array.

Por eso, una función puede modificar las propiedades de un objeto o los elementos de un array original, aunque no puede sustituir la variable original simplemente reasignando su parámetro.

Cómo se pasan los argumentos a una función

Cuando invocamos una función, los argumentos que escribimos entre paréntesis proporcionan los valores que recibirán sus parámetros.

Recuerda el siguiente ejemplo:

JavaScript 
function mostrarPrecio(precio) {
  console.log("Precio: " + precio + " €");
}

const precioProducto = 50;

mostrarPrecio(precioProducto);

La consola mostrará:

Consola 
Precio: 50 €

La variable precioProducto contiene el número 50. Al llamar a mostrarPrecio(), ese valor se proporciona como argumento y el parámetro precio lo recibe.

Es importante distinguir entre la variable utilizada en la llamada y el parámetro declarado en la función.

  • precioProducto es la variable que utilizamos como argumento.
  • precio es el parámetro local de la función.
  • Ambos contienen inicialmente el mismo valor numérico.
  • No son la misma variable.
Programa principal precioProducto = 50
↓ Se proporciona el valor 50
Función mostrarPrecio() El parámetro precio recibe 50
↓ La función utiliza el parámetro
Resultado Se muestra el precio en consola

Para comprender qué sucede si modificamos un parámetro, debemos diferenciar los valores primitivos de los objetos.

Paso de valores primitivos a funciones

Los tipos primitivos de JavaScript incluyen, entre otros, los números, las cadenas de texto, los booleanos, undefined, null, bigint y symbol.

Cuando proporcionamos un valor primitivo como argumento, la función recibe una copia de ese valor en su parámetro.

Si después reasignamos el parámetro, la variable utilizada como argumento no cambia.

Ejemplo con un número

JavaScript 
function aumentarPrecio(precio) {
  precio = precio + 10;

  console.log("Dentro: " + precio);
}

let precioProducto = 50;

aumentarPrecio(precioProducto);

console.log("Fuera: " + precioProducto);

La consola mostrará:

Consola 
Dentro: 60
Fuera: 50

Analicemos el programa paso a paso:

  1. Declaramos precioProducto con el valor 50.
  2. Invocamos aumentarPrecio() y proporcionamos ese valor.
  3. El parámetro local precio recibe 50.
  4. Dentro de la función, reasignamos precio con el valor 60.
  5. La variable exterior precioProducto continúa valiendo 50.
⚠️ Atención

Modificar un parámetro numérico no significa modificar automáticamente la variable que utilizamos como argumento.

El parámetro y la variable exterior son variables diferentes.

Ejemplo con una cadena de texto

El mismo comportamiento aparece cuando trabajamos con cadenas de texto.

JavaScript 
function cambiarNombre(nombre) {
  nombre = "Monitor";

  console.log("Dentro: " + nombre);
}

let producto = "Teclado";

cambiarNombre(producto);

console.log("Fuera: " + producto);

La salida será:

Consola 
Dentro: Monitor
Fuera: Teclado

La función modifica su parámetro local nombre, pero no cambia la variable exterior producto.

Utilizar return para comunicar el nuevo valor

Si queremos que el programa principal utilice un valor calculado dentro de la función, podemos devolverlo mediante return.

JavaScript 
function aumentarPrecio(precio) {
  return precio + 10;
}

let precioProducto = 50;

precioProducto = aumentarPrecio(precioProducto);

console.log(precioProducto);

Ahora la consola mostrará:

Consola 
60

La diferencia es que ahora el programa principal recibe el valor devuelto y lo asigna expresamente a precioProducto.

No es la función la que modifica directamente la variable exterior. Es la instrucción de asignación del programa principal la que actualiza su valor.

📌 Importante

Cuando una función recibe valores primitivos, normalmente es recomendable utilizar return para comunicar los resultados de sus cálculos.

Objetos y referencias en JavaScript

Hasta ahora hemos utilizado números y cadenas de texto. Sin embargo, JavaScript también permite trabajar con estructuras que contienen varios datos relacionados.

En la UT4 estudiamos los arrays y sus elementos. También podemos representar información mediante objetos con propiedades.

Observa el siguiente objeto:

JavaScript 
const producto = {
  nombre: "Teclado",
  precio: 50,
  stock: 10
};

console.log(producto.nombre);
console.log(producto.precio);

La consola mostrará:

Consola 
Teclado
50

El objeto contiene tres propiedades: nombre, precio y stock.

Cuando asignamos un objeto a una variable, esta almacena un valor de referencia que permite acceder a dicho objeto. Por eso, dos variables diferentes pueden hacer referencia al mismo objeto y compartir sus propiedades.

Dos variables pueden acceder al mismo objeto

JavaScript 
const producto1 = {
  nombre: "Teclado",
  precio: 50
};

const producto2 = producto1;

producto2.precio = 60;

console.log(producto1.precio);
console.log(producto2.precio);

La salida será:

Consola 
60
60

Aunque tenemos dos variables, producto1 y producto2, ambas permiten acceder al mismo objeto.

Al ejecutar producto2.precio = 60;, modificamos una propiedad de ese objeto. Por tanto, el cambio también es visible cuando accedemos a través de producto1.

producto1 Referencia al objeto
producto2 Copia de la referencia
Objeto compartido nombre: Teclado
precio: 60

Este comportamiento resulta fundamental para comprender qué sucede cuando proporcionamos objetos a las funciones.

Modificar objetos desde una función

Cuando pasamos un objeto como argumento, el parámetro de la función recibe una copia de su valor de referencia.

Esto significa que el parámetro permite acceder al mismo objeto que la variable original.

Por tanto, si la función modifica una propiedad del objeto, ese cambio puede observarse fuera de la función.

Ejemplo: modificar el precio de un producto

JavaScript 
function aplicarDescuento(producto) {
  producto.precio = producto.precio * 0.90;
}

const articulo = {
  nombre: "Monitor",
  precio: 200
};

aplicarDescuento(articulo);

console.log(articulo.precio);

La consola mostrará:

Consola 
180

Veamos qué sucede:

  1. Creamos un objeto llamado articulo cuyo precio inicial es 200.
  2. Invocamos aplicarDescuento() proporcionando el objeto como argumento.
  3. El parámetro producto recibe una copia de la referencia al mismo objeto.
  4. La función modifica la propiedad precio de ese objeto.
  5. Cuando volvemos a consultar articulo.precio, obtenemos 180.
⚠️ Atención

Este comportamiento suele describirse informalmente como «pasar un objeto por referencia».

Sin embargo, en JavaScript el paso de argumentos sigue siendo por valor. Lo que se copia es el valor de referencia que permite acceder al objeto compartido.

Modificar varias propiedades

Una función puede modificar varias propiedades del mismo objeto.

JavaScript 
function actualizarProducto(producto) {
  producto.precio = 75;
  producto.stock = 5;
}

const articulo = {
  nombre: "Teclado",
  precio: 60,
  stock: 12
};

actualizarProducto(articulo);

console.log(articulo.precio);
console.log(articulo.stock);

La consola mostrará:

Consola 
75
5

El objeto original ha cambiado. No se ha creado automáticamente un objeto nuevo para realizar estas modificaciones.

💻 Ejemplo DAW

En una aplicación web de gestión de inventario, una función podría recibir un objeto que representa un producto y actualizar su stock después de registrar una venta.

En ese caso, modificar directamente el objeto puede ser una decisión intencionada, siempre que el programa esté diseñado para trabajar así.

Reasignar un parámetro que recibe un objeto

Hemos comprobado que una función puede modificar las propiedades de un objeto recibido como argumento.

Pero debemos distinguir entre modificar el contenido de un objeto y reasignar el parámetro para que apunte a otro objeto.

Son operaciones diferentes.

Ejemplo: sustituir el objeto dentro de la función

JavaScript 
function cambiarProducto(producto) {
  producto = {
    nombre: "Monitor",
    precio: 200
  };

  console.log("Dentro: " + producto.nombre);
}

const articulo = {
  nombre: "Teclado",
  precio: 50
};

cambiarProducto(articulo);

console.log("Fuera: " + articulo.nombre);

La consola mostrará:

Consola 
Dentro: Monitor
Fuera: Teclado

¿Por qué ahora no se modifica el objeto original?

Inicialmente, el parámetro producto permite acceder al mismo objeto que articulo.

Sin embargo, cuando ejecutamos producto = { ... };, asignamos al parámetro local una referencia a otro objeto.

La variable exterior articulo continúa haciendo referencia al objeto original, cuyo nombre sigue siendo Teclado.

Operación ¿Modifica el objeto original?
producto.precio = 100; Sí, si el parámetro sigue apuntando al objeto original.
producto.nombre = "Monitor"; Sí, modifica una propiedad del objeto compartido.
producto = { nombre: "Monitor" }; No. Reasigna únicamente el parámetro local.
📌 Importante

Modificar una propiedad cambia el contenido del objeto.

Reasignar el parámetro cambia el valor almacenado en ese parámetro, pero no sustituye automáticamente el objeto al que apunta la variable exterior.

Devolver un objeto nuevo con return

Si queremos sustituir un objeto por otro, podemos devolver el nuevo objeto y asignarlo expresamente desde el programa principal.

JavaScript 
function crearProductoActualizado(producto) {
  return {
    nombre: producto.nombre,
    precio: producto.precio + 10
  };
}

let articulo = {
  nombre: "Teclado",
  precio: 50
};

articulo = crearProductoActualizado(articulo);

console.log(articulo.nombre);
console.log(articulo.precio);

La salida será:

Consola 
Teclado
60

La función crea y devuelve un nuevo objeto. Después, el programa principal reasigna articulo con la referencia al objeto devuelto.

Arrays como argumentos de funciones

Los arrays también son objetos en JavaScript. Por tanto, cuando proporcionamos un array como argumento, el parámetro recibe una copia de la referencia al mismo array.

Esto significa que una función puede modificar sus elementos, añadir otros nuevos o eliminar los existentes.

Añadir un elemento mediante push()

JavaScript 
function agregarProducto(carrito) {
  carrito.push("Monitor");
}

const productos = ["Teclado", "Ratón"];

agregarProducto(productos);

console.log(productos);

La consola mostrará:

Consola 
["Teclado", "Ratón", "Monitor"]

La función recibe el array mediante el parámetro carrito. Al ejecutar push(), añade un elemento al array compartido.

Por eso, después de la llamada, productos contiene tres elementos.

Modificar un elemento del array

JavaScript 
function cambiarPrimerProducto(lista) {
  lista[0] = "Monitor";
}

const productos = ["Teclado", "Ratón"];

cambiarPrimerProducto(productos);

console.log(productos);

La salida será:

Consola 
["Monitor", "Ratón"]

La instrucción lista[0] = "Monitor"; modifica el primer elemento del array original.

Reasignar el parámetro de un array

En cambio, si asignamos un array nuevo al parámetro, no sustituimos automáticamente el array exterior.

JavaScript 
function sustituirCarrito(carrito) {
  carrito = ["Monitor", "Impresora"];

  console.log("Dentro: " + carrito.join(", "));
}

const productos = ["Teclado", "Ratón"];

sustituirCarrito(productos);

console.log("Fuera: " + productos.join(", "));

La consola mostrará:

Consola 
Dentro: Monitor, Impresora
Fuera: Teclado, Ratón

Dentro de la función, carrito pasa a referirse a un array nuevo. Fuera de ella, productos continúa apuntando al array original.

⚠️ Atención

No debemos confundir carrito.push("Monitor") con carrito = ["Monitor"].

La primera instrucción modifica el array existente. La segunda reasigna el parámetro a otro array.

Evitar modificaciones no deseadas

Modificar directamente un objeto o un array recibido como argumento puede ser útil, pero también puede provocar errores.

Imagina que una función debe calcular un descuento para mostrarlo en pantalla, pero no queremos alterar el precio almacenado en el catálogo de productos.

Si la función modifica directamente el objeto original, otras partes de la aplicación podrían utilizar accidentalmente el precio modificado.

Crear una copia de un objeto

Podemos utilizar el operador de propagación ... para crear un objeto nuevo a partir de las propiedades de otro.

JavaScript 
function aplicarDescuento(producto) {
  const copia = { ...producto };

  copia.precio = copia.precio * 0.90;

  return copia;
}

const articulo = {
  nombre: "Monitor",
  precio: 200
};

const rebajado = aplicarDescuento(articulo);

console.log(articulo.precio);
console.log(rebajado.precio);

La consola mostrará:

Consola 
200
180

Ahora tenemos dos objetos distintos:

  • articulo conserva el precio original de 200.
  • rebajado contiene un objeto nuevo cuyo precio es 180.

De esta forma, la función devuelve un resultado sin modificar directamente el objeto recibido.

Crear una copia de un array

También podemos utilizar el operador de propagación para crear un array nuevo.

JavaScript 
function agregarProducto(carrito, nuevoProducto) {
  const copia = [...carrito];

  copia.push(nuevoProducto);

  return copia;
}

const carritoOriginal = ["Teclado", "Ratón"];

const carritoNuevo = agregarProducto(
  carritoOriginal,
  "Monitor"
);

console.log(carritoOriginal);
console.log(carritoNuevo);

La consola mostrará:

Consola 
["Teclado", "Ratón"]
["Teclado", "Ratón", "Monitor"]

La función crea un nuevo array, añade el producto a la copia y devuelve el resultado.

El array original permanece sin cambios.

Las copias superficiales tienen límites

Debemos tener presente que { ...objeto } y [...array] realizan copias superficiales.

Esto significa que copian las propiedades o elementos del primer nivel, pero no duplican automáticamente todos los objetos anidados.

JavaScript 
const producto = {
  nombre: "Monitor",
  detalles: {
    color: "Negro"
  }
};

const copia = { ...producto };

copia.detalles.color = "Blanco";

console.log(producto.detalles.color);

La consola mostrará:

Consola 
Blanco

Aunque producto y copia son objetos distintos, sus propiedades detalles siguen haciendo referencia al mismo objeto anidado.

📌 Importante

Crear una copia superficial evita compartir el objeto o array exterior, pero no garantiza que los objetos anidados sean independientes.

Cuando trabajemos con estructuras de datos más complejas, tendremos que valorar cómo realizar las copias necesarias.

Comparación entre valores primitivos, objetos y arrays

Ya podemos comparar los comportamientos estudiados.

Tipo de argumento Operación dentro de la función Efecto fuera de la función
Número Reasignar el parámetro. La variable original no cambia.
Cadena de texto Reasignar el parámetro. La variable original no cambia.
Booleano Reasignar el parámetro. La variable original no cambia.
Objeto Modificar una propiedad. El objeto original puede cambiar.
Objeto Reasignar el parámetro a otro objeto. La variable original sigue apuntando al objeto anterior.
Array Modificar un elemento o utilizar push(). El array original puede cambiar.
Array Reasignar el parámetro a otro array. La variable original no se sustituye.

Por tanto, la diferencia fundamental no consiste en que JavaScript utilice dos mecanismos diferentes para pasar argumentos.

Todos los argumentos se pasan por valor. La diferencia aparece porque los valores de referencia permiten acceder a objetos compartidos.

💻 Ejemplo DAW

En una aplicación de comercio electrónico, una función que recibe el precio numérico de un producto puede calcular un descuento sin modificar el precio original.

En cambio, una función que recibe el objeto completo del producto puede modificar directamente su propiedad precio, si así está programada.

Elegir entre modificar los datos recibidos o devolver una copia es una decisión importante al diseñar aplicaciones web.

Errores frecuentes al pasar argumentos a funciones

Existen varias confusiones habituales relacionadas con los valores primitivos, los objetos y los arrays.

1. Pensar que modificar un número cambia la variable original

JavaScript 
function duplicar(numero) {
  numero = numero * 2;
}

let cantidad = 5;

duplicar(cantidad);

console.log(cantidad);

La consola mostrará 5, no 10.

La función ha modificado su parámetro local, pero no ha cambiado cantidad.

Si queremos actualizarla, podemos devolver el resultado:

JavaScript 
function duplicar(numero) {
  return numero * 2;
}

let cantidad = 5;

cantidad = duplicar(cantidad);

console.log(cantidad);

Ahora la consola muestra 10.

2. Modificar un objeto sin darse cuenta

JavaScript 
function calcularOferta(producto) {
  producto.precio = producto.precio * 0.80;

  return producto.precio;
}

const articulo = {
  nombre: "Monitor",
  precio: 100
};

const oferta = calcularOferta(articulo);

console.log(oferta);
console.log(articulo.precio);

La consola mostrará:

Consola 
80
80

La función no solo ha calculado una oferta: también ha modificado el precio del objeto original.

Si únicamente queremos calcular el precio rebajado, podemos utilizar:

JavaScript 
function calcularOferta(producto) {
  return producto.precio * 0.80;
}

Esta versión devuelve el resultado sin modificar el objeto recibido.

3. Pensar que const impide modificar un objeto

Recuerda que const impide reasignar una variable, pero no convierte automáticamente su contenido en inmutable.

JavaScript 
const producto = {
  nombre: "Ratón",
  precio: 20
};

producto.precio = 25;

console.log(producto.precio);

La consola mostrará 25.

La variable producto sigue haciendo referencia al mismo objeto. Lo que ha cambiado es una propiedad de ese objeto.

4. Pensar que asignar un array crea una copia independiente

JavaScript 
const original = ["Teclado", "Ratón"];

const copia = original;

copia.push("Monitor");

console.log(original);

La consola mostrará:

Consola 
["Teclado", "Ratón", "Monitor"]

La instrucción const copia = original; no crea un array independiente. Copia la referencia al mismo array.

Si queremos una copia superficial, podemos escribir:

JavaScript 
const copia = [...original];

5. Pensar que reasignar un parámetro sustituye el objeto exterior

Como hemos visto, ejecutar producto = { ... }; dentro de una función no sustituye automáticamente la referencia almacenada en la variable original.

Si queremos utilizar el nuevo objeto, debemos devolverlo y asignarlo expresamente donde corresponda.

⚠️ Atención

Algunos errores relacionados con los objetos y arrays no producen mensajes de error en la consola.

El programa puede ejecutarse correctamente, pero modificar datos que deberían haberse conservado.

Buenas prácticas al pasar datos a funciones

Cuando diseñamos funciones que reciben información, conviene decidir si deben modificar los datos originales o simplemente calcular y devolver un resultado.

  • Utilizar return para comunicar resultados: especialmente cuando trabajamos con valores primitivos.
  • Evitar modificaciones inesperadas: no cambiar objetos o arrays recibidos si la finalidad de la función es únicamente consultar o calcular.
  • Documentar las modificaciones: cuando una función cambia deliberadamente un objeto o array, su comportamiento debe resultar claro.
  • Crear copias cuando sea necesario: utilizar objetos o arrays nuevos si necesitamos conservar los originales.
  • Recordar los límites de las copias superficiales: los objetos anidados pueden seguir compartiéndose.
  • Utilizar nombres descriptivos: elegir nombres que permitan comprender qué información recibe cada función.
  • Diseñar funciones con responsabilidades claras: evitar que una función modifique datos ajenos a su tarea.

Comparación entre dos formas de aplicar un descuento

Observa esta primera versión:

JavaScript 
function aplicarDescuento(producto) {
  producto.precio = producto.precio * 0.90;
}

const articulo = {
  nombre: "Monitor",
  precio: 200
};

aplicarDescuento(articulo);

console.log(articulo.precio);

Esta función modifica directamente el precio del objeto original. La consola muestra 180.

Ahora observa una versión alternativa:

JavaScript 
function calcularPrecioRebajado(producto) {
  return producto.precio * 0.90;
}

const articulo = {
  nombre: "Monitor",
  precio: 200
};

const precioFinal = calcularPrecioRebajado(articulo);

console.log(precioFinal);
console.log(articulo.precio);

La salida será:

Consola 
180
200

En esta segunda versión, la función calcula y devuelve el precio rebajado, pero mantiene intacto el objeto original.

Ninguna de las dos formas es incorrecta por sí misma. La elección depende del comportamiento que necesitemos.

📌 Importante

Una función debería modificar los objetos o arrays que recibe solo cuando esa modificación sea intencionada y forme parte de su responsabilidad.

Ejemplo práctico completo: gestionar el carrito de una tienda online

Vamos a aplicar los conceptos estudiados mediante un programa que gestione el carrito de una tienda online.

En el apartado 5.5 aprendimos a organizar las variables según su ámbito. Ahora nos centraremos en comprender qué datos cambian y cuáles se conservan cuando utilizamos funciones.

Nuestro programa debe:

  • almacenar los productos del carrito;
  • calcular el subtotal de cada producto;
  • calcular el total del pedido;
  • crear una copia de un producto con descuento;
  • añadir un producto nuevo al carrito;
  • mostrar el estado del carrito antes y después de las operaciones.

Utilizaremos un array de objetos para representar los productos.

JavaScript 
// Carrito inicial
const carrito = [
  {
    nombre: "Teclado",
    precio: 50,
    cantidad: 2
  },
  {
    nombre: "Ratón",
    precio: 20,
    cantidad: 1
  }
];

// Calcula el subtotal de un producto
function calcularSubtotal(producto) {
  return producto.precio * producto.cantidad;
}

// Calcula el total del carrito
function calcularTotal(productos) {
  let total = 0;

  for (const producto of productos) {
    total = total + calcularSubtotal(producto);
  }

  return total;
}

// Crea un producto nuevo con descuento
function crearProductoRebajado(producto, porcentaje) {
  const copia = { ...producto };

  copia.precio = copia.precio * (1 - porcentaje / 100);

  return copia;
}

// Añade un producto al carrito recibido
function agregarProducto(productos, nuevoProducto) {
  productos.push(nuevoProducto);
}

// Muestra los productos del carrito
function mostrarCarrito(productos) {
  for (const producto of productos) {
    const subtotal = calcularSubtotal(producto);

    let unidad = "unidades";

    if (producto.cantidad === 1) {
      unidad = "unidad";
    }

    console.log(
      producto.nombre +
      " - " +
      producto.cantidad +
      " " +
      unidad +
      " - " +
      subtotal.toFixed(2) +
      " €"
    );
  }
}

// PROGRAMA PRINCIPAL

console.log("CARRITO INICIAL");
mostrarCarrito(carrito);

console.log("Total inicial: " + calcularTotal(carrito).toFixed(2) + " €");

// Crear una copia rebajada del teclado
const tecladoRebajado = crearProductoRebajado(
  carrito[0],
  10
);

console.log("Precio original: " + carrito[0].precio + " €");
console.log("Precio rebajado: " + tecladoRebajado.precio + " €");

// Añadir un monitor al carrito
const monitor = {
  nombre: "Monitor",
  precio: 150,
  cantidad: 1
};

agregarProducto(carrito, monitor);

console.log("CARRITO ACTUALIZADO");
mostrarCarrito(carrito);

console.log("Total final: " + calcularTotal(carrito).toFixed(2) + " €");

La salida completa será:

Consola 
CARRITO INICIAL
Teclado - 2 unidades - 100.00 €
Ratón - 1 unidad - 20.00 €
Total inicial: 120.00 €
Precio original: 50 €
Precio rebajado: 45 €
CARRITO ACTUALIZADO
Teclado - 2 unidades - 100.00 €
Ratón - 1 unidad - 20.00 €
Monitor - 1 unidad - 150.00 €
Total final: 270.00 €

Análisis paso a paso

Vamos a estudiar cómo se comportan los argumentos en cada función.

1. La función calcularSubtotal()

Esta función recibe un objeto que representa un producto.

JavaScript 
function calcularSubtotal(producto) {
  return producto.precio * producto.cantidad;
}

La función consulta las propiedades precio y cantidad del objeto recibido.

Después calcula el subtotal y devuelve el resultado mediante return.

No modifica el objeto original.

2. La función calcularTotal()

Esta función recibe un array de productos.

Recorre sus elementos y utiliza calcularSubtotal() para obtener el importe correspondiente a cada producto.

La variable local total acumula los resultados y finalmente se devuelve.

El array recibido no se modifica. Únicamente se consultan sus elementos.

3. La función crearProductoRebajado()

Esta función recibe un objeto y un porcentaje numérico.

Primero crea una copia superficial del producto mediante { ...producto }.

Después modifica el precio de la copia y la devuelve.

En nuestro ejemplo, el teclado tiene un precio original de 50 euros.

Al aplicar un descuento del 10 %, la copia tendrá un precio de 45 euros.

El objeto original conserva su precio de 50 euros.

4. La función agregarProducto()

Esta función recibe el array del carrito y un objeto que representa un nuevo producto.

Mediante push(), añade el objeto al array compartido.

En este caso, la modificación del array original es intencionada.

Después de la llamada, el carrito contiene tres productos: teclado, ratón y monitor.

5. La función mostrarCarrito()

Esta función recibe el array y recorre sus elementos para mostrar información en la consola.

Consulta los objetos, calcula sus subtotales y muestra los resultados.

No añade, elimina ni modifica elementos del carrito.

Resumen del comportamiento de las funciones

Función Datos recibidos ¿Modifica los originales?
calcularSubtotal() Un objeto producto. No. Consulta propiedades y devuelve un número.
calcularTotal() Un array de productos. No. Recorre el array y devuelve un número.
crearProductoRebajado() Un objeto y un porcentaje. No. Devuelve una copia con el precio modificado.
agregarProducto() Un array y un objeto. Sí. Añade un elemento al array original.
mostrarCarrito() Un array de productos. No. Solo consulta y muestra información.
📌 Importante

Que una función reciba un objeto o un array no significa que necesariamente vaya a modificarlo.

El resultado depende de las instrucciones que ejecutemos dentro de ella.

Debemos distinguir entre consultar datos, modificar estructuras compartidas y crear nuevos valores o copias.

En el siguiente apartado estudiaremos cómo proporcionar valores predeterminados a los parámetros y cómo utilizar parámetros rest para recibir un número variable de argumentos.

💭 Piensa

Observa el siguiente programa sin ejecutarlo:

JavaScript 
let precio = 100;

const producto = {
  nombre: "Teclado",
  stock: 5
};

const carrito = ["Ratón"];

function cambiarPrecio(valor) {
  valor = valor - 20;

  console.log("Precio dentro: " + valor);
}

function actualizarStock(articulo) {
  articulo.stock = articulo.stock - 2;
}

function agregarAlCarrito(lista) {
  lista.push("Monitor");
}

function sustituirProducto(articulo) {
  articulo = {
    nombre: "Monitor",
    stock: 10
  };

  console.log("Dentro: " + articulo.nombre);
}

cambiarPrecio(precio);
actualizarStock(producto);
agregarAlCarrito(carrito);
sustituirProducto(producto);

console.log("Precio fuera: " + precio);
console.log("Stock: " + producto.stock);
console.log("Producto: " + producto.nombre);
console.log("Carrito: " + carrito.join(", "));

Responde a las siguientes preguntas:

  1. ¿Qué valor recibe el parámetro valor cuando se invoca cambiarPrecio()?
  2. ¿Se modifica la variable exterior precio? Explica por qué.
  3. ¿Qué valor tendrá producto.stock después de ejecutar actualizarStock()?
  4. ¿Qué elementos contendrá el array carrito después de llamar a agregarAlCarrito()?
  5. ¿La función sustituirProducto() sustituye el objeto original? Justifica tu respuesta.
  6. ¿Qué mensajes aparecerán en la consola y en qué orden?
  7. ¿Cómo podríamos modificar cambiarPrecio() para que devolviera el nuevo precio sin modificar directamente la variable exterior?
Ver una posible solución

1. El parámetro valor recibe el número 100, que es el valor almacenado en la variable exterior precio.

2. No se modifica la variable exterior. La instrucción valor = valor - 20; reasigna únicamente el parámetro local, que pasa a valer 80.

La variable precio sigue valiendo 100.

3. producto.stock pasa de 5 a 3.

La función modifica directamente una propiedad del objeto compartido.

4. El array carrito contendrá ["Ratón", "Monitor"].

El método push() modifica el array original.

5. La función sustituirProducto() no sustituye el objeto original.

La asignación articulo = { ... }; hace que el parámetro local se refiera a otro objeto. La variable exterior producto sigue haciendo referencia al objeto inicial.

6. La salida completa será:

Consola 
Precio dentro: 80
Dentro: Monitor
Precio fuera: 100
Stock: 3
Producto: Teclado
Carrito: Ratón, Monitor

Las dos primeras líneas se muestran dentro de las funciones. Las cuatro restantes aparecen al ejecutar las instrucciones finales del programa principal.

7. Podemos modificar la función para que devuelva el resultado mediante return:

JavaScript 
function cambiarPrecio(valor) {
  return valor - 20;
}

let precio = 100;

const nuevoPrecio = cambiarPrecio(precio);

console.log(nuevoPrecio);
console.log(precio);

La consola mostrará:

Consola 
80
100

La función devuelve el nuevo precio, pero la variable original precio permanece sin cambios.
