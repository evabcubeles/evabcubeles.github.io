5.2 Declaración e invocación de funciones

En el apartado anterior hemos aprendido que las funciones permiten agrupar instrucciones para realizar una tarea y reutilizarlas en diferentes partes de un programa.

Ahora vamos a estudiar cómo se crean y cómo se ejecutan las funciones en JavaScript. Para ello, debemos comprender dos operaciones fundamentales: declarar una función e invocarla.

Aunque ambas operaciones están relacionadas, no significan lo mismo. Podemos definir una función sin ejecutarla y también podemos llamar varias veces a una función que ya hemos definido.

📌 Importante

Declarar una función consiste en definir las instrucciones que realizará. Invocar una función consiste en solicitar que se ejecuten esas instrucciones.

Declarar una función

La declaración de una función permite indicar a JavaScript que existe una función con un determinado nombre y un conjunto de instrucciones que forman su cuerpo.

Una de las formas de crear funciones es utilizar la palabra reservada function, seguida del nombre que queremos asignar a la función.

Observa el siguiente ejemplo:

JavaScript 
function mostrarSaludo() {
  console.log("Hola, bienvenido a DWEC");
}

Hemos declarado una función llamada mostrarSaludo(). Su tarea será mostrar un mensaje en la consola cuando se ejecute.

Sin embargo, si ejecutamos únicamente este código, el mensaje todavía no aparecerá en la consola.

Esto sucede porque hemos indicado qué debe hacer la función, pero aún no hemos solicitado que realice esa tarea.

⚠️ Atención

Una declaración de función no ejecuta automáticamente las instrucciones de su cuerpo. Para que se ejecuten, debe producirse una llamada a la función.

Sintaxis de una declaración de función

La estructura básica de una declaración de función en JavaScript es la siguiente:

JavaScript 
function nombreFuncion() {
  // Instrucciones de la función
}

Vamos a identificar sus elementos:

Elemento Función que desempeña
function Palabra reservada que permite realizar una declaración de función.
nombreFuncion Identificador que utilizaremos para referirnos a la función.
() Paréntesis en los que pueden declararse los parámetros. Por ahora los dejaremos vacíos.
{ } Llaves que delimitan el cuerpo de la función.
Instrucciones Código que se ejecutará cuando se invoque la función.

El nombre de la función

El nombre de una función debe cumplir las reglas generales de los identificadores de JavaScript.

Por ejemplo, puede contener letras, números, _ y $, pero no puede comenzar por un número ni coincidir con una palabra reservada.

Además, JavaScript distingue entre mayúsculas y minúsculas. Por tanto, mostrarSaludo y mostrarsaludo son identificadores diferentes.

Es recomendable utilizar nombres descriptivos que permitan comprender la tarea realizada por la función.

Nombre Valoración
calcularTotal() Adecuado: expresa claramente la operación.
comprobarDisponibilidad() Adecuado: identifica una tarea concreta.
f1() Poco descriptivo: no permite conocer su finalidad.
2calcular() Incorrecto: comienza por un número.

El cuerpo de la función

El cuerpo está formado por las instrucciones situadas entre las llaves. Estas instrucciones se ejecutan cuando llamamos a la función.

Una función puede contener una o varias instrucciones, incluyendo variables, operaciones matemáticas, condiciones, bucles y llamadas a otras funciones.

JavaScript 
function mostrarInformacion() {
  console.log("Módulo: DWEC");
  console.log("Unidad: Funciones");
  console.log("Lenguaje: JavaScript");
}

En este caso, el cuerpo contiene tres instrucciones. Cuando se invoque la función, se ejecutarán en ese orden.

📌 Importante

En una declaración de función, los paréntesis son obligatorios aunque no haya parámetros. Las llaves delimitan el conjunto de instrucciones que forman su cuerpo.

Invocar una función

Una vez declarada una función, podemos solicitar su ejecución mediante una llamada o invocación.

Para invocar una función, escribimos su nombre seguido de paréntesis. Si no necesita argumentos, los paréntesis permanecen vacíos.

Veamos un ejemplo completo:

JavaScript 
// Declaración de la función
function mostrarSaludo() {
  console.log("Hola, bienvenido a DWEC");
}

// Llamada a la función
mostrarSaludo();

Al ejecutar el programa, la consola mostrará:

Consola 
Hola, bienvenido a DWEC

La primera parte del programa define la función. La instrucción mostrarSaludo(); provoca que se ejecuten las instrucciones de su cuerpo.

La importancia de los paréntesis

Existe una diferencia fundamental entre escribir el nombre de una función y escribirlo seguido de paréntesis.

JavaScript 
function saludar() {
  console.log("Hola");
}

saludar;   // Referencia a la función, sin ejecutarla

saludar(); // Llamada: ejecuta la función

La expresión saludar hace referencia a la función como valor, pero no ejecuta su cuerpo.

En cambio, saludar() realiza una llamada. Por eso, en este ejemplo el mensaje "Hola" aparece una sola vez.

Más adelante estudiaremos cómo JavaScript permite utilizar las funciones como valores y almacenarlas en variables.

⚠️ Atención

No debemos confundir saludar con saludar(). La primera expresión hace referencia a la función; la segunda solicita su ejecución.

Orden de ejecución de un programa con funciones

Cuando un programa contiene funciones, debemos distinguir entre las instrucciones que aparecen en el código principal y las que se encuentran dentro de cada función.

El programa ejecuta las instrucciones correspondientes y, cuando encuentra una llamada a una función, comienza a ejecutar el cuerpo de esa función.

Observa el siguiente ejemplo:

JavaScript 
function mostrarMensaje() {
  console.log("Dentro de la función");
}

console.log("Inicio del programa");

mostrarMensaje();

console.log("Fin del programa");

La salida será:

Consola 
Inicio del programa
Dentro de la función
Fin del programa

Explicación paso a paso

  1. JavaScript dispone de la declaración de la función mostrarMensaje().
  2. Se ejecuta el primer console.log() del programa principal y aparece Inicio del programa.
  3. El programa encuentra la llamada mostrarMensaje();.
  4. Se ejecuta el cuerpo de la función y aparece Dentro de la función.
  5. Cuando termina la función, la ejecución continúa después de la llamada.
  6. Se ejecuta el último console.log() y aparece Fin del programa.
1. Programa Ejecuta las instrucciones hasta encontrar una llamada.
2. Función Ejecuta las instrucciones de su cuerpo.
3. Continuación Regresa al programa después de la llamada.

En estos ejemplos estamos trabajando con funciones síncronas. Esto significa que la llamada se completa antes de que el programa continúe con la siguiente instrucción del código principal.

Más adelante estudiaremos situaciones en las que intervienen operaciones asíncronas y el orden de ejecución requiere un análisis diferente.

📌 Importante

En una llamada síncrona, el programa ejecuta la función y, cuando esta termina, continúa en la instrucción situada después de la llamada.

Llamar varias veces a una función

Una función no está limitada a una única ejecución. Podemos invocarla tantas veces como sea necesario durante el funcionamiento del programa.

Esta característica es una de las principales razones por las que las funciones permiten reutilizar código.

JavaScript 
function mostrarSeparador() {
  console.log("--------------------");
}

console.log("Listado de productos");

mostrarSeparador();

console.log("Portátil");
console.log("Monitor");

mostrarSeparador();

console.log("Fin del listado");

mostrarSeparador();

El resultado será:

Consola 
Listado de productos
--------------------
Portátil
Monitor
--------------------
Fin del listado
--------------------

Hemos escrito las instrucciones de mostrarSeparador() una sola vez, pero hemos ejecutado la función en tres momentos distintos.

Invocar una función dentro de un bucle

También podemos combinar las funciones con las estructuras de repetición que estudiamos en la UT3.

JavaScript 
function mostrarAviso() {
  console.log("Recuerda guardar los cambios");
}

for (let i = 0; i < 3; i++) {
  mostrarAviso();
}

En cada iteración del bucle se realiza una nueva llamada a la función. Por tanto, el mensaje se mostrará tres veces:

Consola 
Recuerda guardar los cambios
Recuerda guardar los cambios
Recuerda guardar los cambios
💻 Ejemplo DAW

En una aplicación de gestión de productos, podemos crear una función que muestre la cabecera de un informe. Cada vez que generemos un nuevo informe, llamaremos a esa función en lugar de repetir todas las instrucciones necesarias para construir la cabecera.

Declaraciones de funciones y hoisting

Hasta ahora hemos escrito las declaraciones de funciones antes de sus llamadas. Esta es una forma clara de organizar los ejemplos, pero JavaScript permite una característica que conviene conocer.

Las declaraciones de funciones se procesan durante la preparación del entorno de ejecución. Por eso, dentro del ámbito correspondiente, normalmente podemos llamar a una función antes de que aparezca su declaración en el código.

Este comportamiento forma parte de lo que habitualmente se denomina hoisting o elevación.

JavaScript 
mostrarBienvenida();

function mostrarBienvenida() {
  console.log("Bienvenidos al curso");
}

Aunque la llamada aparece antes que la declaración, este programa funciona y muestra:

Consola 
Bienvenidos al curso

¿Significa que JavaScript mueve el código?

No debemos interpretar el hoisting como si JavaScript desplazara físicamente las instrucciones hasta el principio del archivo.

Lo que ocurre es que, al preparar el entorno de ejecución, el motor registra las declaraciones de funciones y permite utilizarlas antes de alcanzar su posición textual.

Para entenderlo, podemos comparar estas dos formas de escribir un mismo programa.

Declaración antes de la llamada Llamada antes de la declaración
Primero definimos la función y después la invocamos. Primero aparece la llamada y después la declaración.
Es una organización fácil de seguir. También funciona con las declaraciones de funciones habituales, dentro de su ámbito.
No necesitamos conocer el hoisting para comprender el orden del código. Debemos conocer el comportamiento de las declaraciones durante la preparación de la ejecución.
⚠️ Atención

No todas las formas de crear funciones se comportan igual respecto al hoisting. Por ejemplo, las funciones asignadas a variables declaradas con const o let no pueden utilizarse antes de que se ejecute su inicialización. Estudiaremos esas expresiones de función en el apartado 5.8.

Aunque JavaScript permita llamar a determinadas funciones antes de su declaración, en los primeros programas resulta recomendable mantener una organización que facilite la lectura y comprensión del código.

Funciones que llaman a otras funciones

Las funciones no solo pueden ser llamadas desde el código principal. También pueden invocarse desde el cuerpo de otras funciones.

Esta posibilidad permite dividir una operación compleja en tareas más pequeñas y coordinar su ejecución.

Imaginemos que queremos mostrar un pequeño informe de una tienda online.

JavaScript 
function mostrarCabecera() {
  console.log("TIENDA ONLINE");
  console.log("----------------");
}

function mostrarProductos() {
  console.log("1. Portátil");
  console.log("2. Monitor");
}

function mostrarInforme() {
  mostrarCabecera();
  mostrarProductos();
  console.log("Fin del informe");
}

mostrarInforme();

Al ejecutar mostrarInforme(), esta función llama a otras dos funciones.

La salida será:

Consola 
TIENDA ONLINE
----------------
1. Portátil
2. Monitor
Fin del informe

Cómo se desarrolla la ejecución

  1. El programa llama a mostrarInforme().
  2. Dentro de esta función se llama a mostrarCabecera().
  3. Se muestran el título y el separador.
  4. La ejecución regresa a mostrarInforme().
  5. Se llama a mostrarProductos() y se muestran los dos productos.
  6. La ejecución vuelve a mostrarInforme() y se muestra el mensaje final.
mostrarInforme() Coordina la generación del informe.
mostrarCabecera() Presenta el título y el separador.
mostrarProductos() Presenta los productos disponibles.

Observa que cada función tiene una responsabilidad concreta. La función principal se encarga de organizar las llamadas, mientras que las otras realizan tareas específicas.

📌 Importante

Una función puede llamar a otras funciones. Cuando una llamada termina, la ejecución continúa en el punto desde el que se realizó. Este comportamiento permite construir programas organizados mediante funciones que colaboran entre sí.

Errores frecuentes al declarar e invocar funciones

Al comenzar a trabajar con funciones es habitual cometer algunos errores de sintaxis o confundir la declaración con la llamada.

Vamos a estudiar los más frecuentes.

1. Olvidar los paréntesis en la llamada

Observa este programa:

JavaScript 
function mostrarMensaje() {
  console.log("Mensaje de prueba");
}

mostrarMensaje; // No ejecuta la función

El programa no muestra el mensaje porque mostrarMensaje es una referencia a la función, no una llamada.

Para ejecutarla debemos escribir:

JavaScript 
mostrarMensaje();

2. Escribir incorrectamente el nombre

JavaScript distingue entre mayúsculas y minúsculas, por lo que el nombre utilizado en la llamada debe coincidir con el de la declaración.

JavaScript 
function mostrarSaludo() {
  console.log("Hola");
}

// Error: el nombre no coincide
mostrarsaludo();

Si no existe otra función con ese nombre, JavaScript producirá un ReferenceError.

3. Olvidar las llaves de la declaración

El cuerpo de una declaración de función debe estar delimitado por llaves.

JavaScript 
// Incorrecto: faltan las llaves
function mostrarSaludo()
  console.log("Hola");

La forma correcta es:

JavaScript 
function mostrarSaludo() {
  console.log("Hola");
}

4. Llamar a una función inexistente

Si intentamos invocar una función que no está definida ni disponible en el ámbito correspondiente, el programa producirá un error.

JavaScript 
// No hemos definido esta función
generarInforme();

En este caso, si generarInforme no existe, JavaScript mostrará un error similar a:

Consola 
ReferenceError: generarInforme is not defined

5. Confundir la declaración con la ejecución

Declarar una función no garantiza que su código llegue a ejecutarse.

JavaScript 
function mostrarAviso() {
  console.log("Operación completada");
}

console.log("Programa terminado");

En este ejemplo únicamente aparecerá Programa terminado, porque nunca se ha llamado a mostrarAviso().

⚠️ Atención

Cuando una función parece no funcionar, comprueba primero que la has invocado, que el nombre está correctamente escrito y que los paréntesis y las llaves se encuentran en su posición adecuada.

Buenas prácticas al declarar funciones

Además de escribir código que funcione, debemos procurar que sea fácil de leer, comprender y mantener.

Desde el principio conviene adoptar algunas buenas prácticas:

  • Utilizar nombres descriptivos: preferir mostrarResumen() frente a funcion1().
  • Emplear camelCase: escribir nombres como calcularPrecioFinal(), siguiendo la convención habitual de JavaScript.
  • Definir tareas concretas: evitar que una misma función acumule operaciones que no guardan relación entre sí.
  • Mantener una indentación coherente: facilitar la identificación de las instrucciones que pertenecen al cuerpo de la función.
  • Evitar repetir instrucciones: aprovechar las funciones cuando una misma operación se utiliza en diferentes lugares.
  • Comprobar las funciones: ejecutarlas con ejemplos sencillos y verificar que producen el comportamiento esperado.

Por ejemplo, comparemos dos nombres:

JavaScript 
// Nombre poco descriptivo
function f1() {
  console.log("Pedido confirmado");
}

// Nombre descriptivo
function mostrarConfirmacionPedido() {
  console.log("Pedido confirmado");
}

Ambas funciones realizan la misma operación, pero mostrarConfirmacionPedido() permite comprender su finalidad sin tener que examinar las instrucciones de su cuerpo.

💻 Ejemplo DAW

En una aplicación de comercio electrónico, nombres como comprobarStock(), calcularGastosEnvio() o mostrarConfirmacion() ayudan a identificar las operaciones del programa y facilitan el trabajo en equipo.

Ejemplo práctico completo: organizar un pedido

Vamos a aplicar lo aprendido mediante un ejemplo relacionado con el desarrollo de aplicaciones web.

Imagina que estamos desarrollando una tienda online y queremos mostrar un resumen sencillo de un pedido en la consola.

El programa debe realizar las siguientes tareas:

  • mostrar el título del pedido;
  • mostrar los productos incluidos;
  • mostrar un mensaje de confirmación;
  • indicar que ha terminado el proceso.

Podemos organizar estas tareas mediante varias funciones.

JavaScript 
// Función que muestra la cabecera
function mostrarCabeceraPedido() {
  console.log("RESUMEN DEL PEDIDO");
  console.log("------------------------");
}

// Función que muestra los productos
function mostrarProductosPedido() {
  console.log("Producto: Teclado");
  console.log("Producto: Ratón");
}

// Función que muestra la confirmación
function mostrarConfirmacion() {
  console.log("Pedido registrado correctamente");
}

// Función que organiza todo el proceso
function mostrarResumenPedido() {
  mostrarCabeceraPedido();
  mostrarProductosPedido();
  mostrarConfirmacion();
}

// Programa principal
console.log("Iniciando aplicación");

mostrarResumenPedido();

console.log("Proceso finalizado");

La salida del programa será:

Consola 
Iniciando aplicación
RESUMEN DEL PEDIDO
------------------------
Producto: Teclado
Producto: Ratón
Pedido registrado correctamente
Proceso finalizado

Análisis del programa

Primero hemos declarado cuatro funciones. Cada una tiene una responsabilidad definida:

Función Responsabilidad
mostrarCabeceraPedido() Mostrar el título y el separador del pedido.
mostrarProductosPedido() Mostrar los productos incluidos en el pedido.
mostrarConfirmacion() Mostrar el mensaje de confirmación.
mostrarResumenPedido() Coordinar la ejecución de las tres funciones anteriores.

Después comienza la ejecución del programa principal. Primero se muestra Iniciando aplicación.

A continuación, la llamada mostrarResumenPedido(); inicia la ejecución de la función encargada de coordinar el resumen.

Esta función llama sucesivamente a las otras tres, de manera que se muestran la cabecera, los productos y el mensaje de confirmación.

Finalmente, cuando termina mostrarResumenPedido(), el programa continúa y muestra Proceso finalizado.

¿Qué hemos conseguido?

Hemos dividido el programa en operaciones más pequeñas y hemos separado la organización del proceso de las instrucciones encargadas de mostrar cada parte.

Además, podríamos volver a llamar a mostrarResumenPedido() en otro momento sin repetir todas las instrucciones.

📌 Importante

Las funciones permiten organizar un programa mediante tareas con responsabilidades concretas. Una función puede coordinar otras funciones, y todas ellas pueden reutilizarse cuando sea necesario.

En este ejemplo hemos utilizado mensajes y productos escritos directamente en el código para centrarnos en la declaración y la invocación.

En el siguiente apartado aprenderemos a utilizar parámetros y argumentos, lo que permitirá proporcionar información diferente a una misma función y hacer nuestros programas más flexibles.

💭 Piensa

Observa el siguiente programa sin ejecutarlo:

JavaScript 
function mostrarInicio() {
  console.log("Inicio de la operación");
}

function mostrarFin() {
  console.log("Fin de la operación");
}

console.log("Programa preparado");

mostrarInicio();
mostrarInicio();

console.log("Procesando datos");

mostrarFin();

¿En qué orden aparecerán los mensajes en la consola? ¿Cuántas veces se ejecuta mostrarInicio()? ¿Qué ocurriría si elimináramos la llamada a mostrarFin()?

Ver una posible solución

Primero aparece Programa preparado. Después se ejecuta dos veces mostrarInicio(), por lo que Inicio de la operación aparece dos veces.

A continuación, se muestra Procesando datos y finalmente se ejecuta mostrarFin().

La salida completa es:

Consola 
Programa preparado
Inicio de la operación
Inicio de la operación
Procesando datos
Fin de la operación

Si elimináramos la llamada a mostrarFin(), su cuerpo no se ejecutaría y el último mensaje dejaría de aparecer. La declaración seguiría existiendo.
