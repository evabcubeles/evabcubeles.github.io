5.7 Parámetros por defecto y parámetros rest

En el apartado anterior hemos estudiado qué ocurre cuando una función recibe números, cadenas, objetos o arrays. Ahora vamos a aprender a diseñar funciones más flexibles: algunas podrán funcionar aunque no proporcionemos todos sus argumentos y otras podrán recibir tantos argumentos como necesitemos.

Imagina una tienda online. Al calcular los gastos de envío queremos utilizar una tarifa habitual si no se indica otra. Por otra parte, para calcular el total de varios precios no sabemos de antemano si recibiremos dos, tres o diez productos.

JavaScript ofrece dos herramientas muy útiles para resolver estas situaciones: los parámetros por defecto y los parámetros rest.

📌 Importante

Un parámetro por defecto proporciona un valor alternativo cuando el argumento recibido es undefined. Un parámetro rest, escrito con ..., reúne los argumentos restantes en un array. Aunque ambos se escriben en la declaración de una función, resuelven problemas diferentes.

Qué ocurre cuando faltan argumentos

En JavaScript podemos invocar una función con menos argumentos de los parámetros que declara. Los parámetros para los que no se proporciona un argumento reciben el valor undefined.

JavaScript 
function saludar(nombre, ciudad) {
  console.log("Hola, " + nombre);
  console.log("Ciudad: " + ciudad);
}

saludar("Lucía");

Salida por consola:

Consola 
Hola, Lucía
Ciudad: undefined

El primer argumento, "Lucía", se asigna a nombre. Como no hemos proporcionado un segundo argumento, ciudad vale undefined.

El programa no genera un error automáticamente, pero puede producir mensajes poco útiles o resultados inesperados.

Un problema frecuente: operar con un argumento que falta

JavaScript 
function calcularPrecio(precio, unidades) {
  return precio * unidades;
}

console.log(calcularPrecio(25));

Salida por consola:

Consola 
NaN

La operación es 25 * undefined. Como no puede obtenerse un resultado numérico válido, JavaScript devuelve NaN (Not a Number).

Aunque NaN significa Not a Number, en JavaScript es un valor especial del tipo number que indica que una operación numérica no ha producido un resultado válido.

⚠️ Atención

Que JavaScript permita omitir argumentos no significa que la función pueda trabajar correctamente sin ellos. Debemos decidir cuáles son obligatorios y cuáles pueden tener un valor predeterminado.

Declarar parámetros por defecto

Un parámetro por defecto se declara escribiendo = y un valor en la lista de parámetros. Ese valor se utilizará si, al invocar la función, el argumento correspondiente es undefined.

JavaScript 
function saludar(nombre = "visitante") {
  console.log("Hola, " + nombre);
}

saludar("Marcos");
saludar();

Salida por consola:

Consola 
Hola, Marcos
Hola, visitante

En la primera llamada se proporciona un nombre y se utiliza ese argumento. En la segunda no se proporciona ninguno, por lo que se aplica "visitante".

Varios parámetros con valores predeterminados

JavaScript 
function calcularImporte(precio, unidades = 1, descuento = 0) {
  const subtotal = precio * unidades;
  return subtotal - subtotal * descuento / 100;
}

console.log(calcularImporte(40));
console.log(calcularImporte(40, 3));
console.log(calcularImporte(40, 3, 10));

Salida por consola:

Consola 
40
120
108

Vamos a analizar cada llamada:

  • calcularImporte(40): se utiliza una unidad y un descuento del 0 %.
  • calcularImporte(40, 3): se utilizan tres unidades y un descuento del 0 %.
  • calcularImporte(40, 3, 10): los tres argumentos proporcionados sustituyen los valores predeterminados.

De este modo, una sola función permite realizar varias operaciones sin obligarnos a escribir siempre todos los argumentos.

Valores por defecto y return

Los parámetros por defecto no modifican el funcionamiento de return. La función calcula un resultado y lo devuelve al programa que la invoca.

JavaScript 
function calcularEnvio(importe, costeEnvio = 4.95) {
  return importe + costeEnvio;
}

const totalNormal = calcularEnvio(30);
const totalUrgente = calcularEnvio(30, 9.95);

console.log(totalNormal.toFixed(2) + " €");
console.log(totalUrgente.toFixed(2) + " €");

Salida por consola:

Consola 
34.95 €
39.95 €
💻 Ejemplo DAW

En una aplicación de comercio electrónico, los valores por defecto resultan útiles para establecer cantidades iniciales, gastos de envío habituales, descuentos del 0 % o mensajes alternativos. Así evitamos repetir argumentos que casi siempre tienen el mismo valor.

Diferencia entre undefined, null y otros valores

Una cuestión especialmente importante es cuándo se aplica exactamente el valor por defecto.

Se utiliza si no se pasa ningún argumento o si se pasa explícitamente undefined. No se aplica automáticamente con null, 0, false ni con una cadena vacía.

JavaScript 
function mostrarValor(valor = "predeterminado") {
  console.log(valor);
}

mostrarValor();
mostrarValor(undefined);
mostrarValor(null);
mostrarValor(0);
mostrarValor(false);
mostrarValor("");

Salida por consola:

Consola 
predeterminado
predeterminado
null
0
false

La última llamada muestra una línea vacía, porque el argumento es la cadena "". Esta cadena es un valor válido, aunque no contenga caracteres.

⚠️ Atención

No confundas un argumento ausente con un argumento que contiene un valor considerado falso (0, false o ""). Los parámetros por defecto conservan estos últimos valores.

Por qué no siempre conviene utilizar el operador ||

Antes de los parámetros por defecto era habitual utilizar el operador || para proporcionar valores alternativos. Sin embargo, este operador puede producir resultados no deseados.

JavaScript 
function mostrarCantidad(cantidad) {
  const resultado = cantidad || 10;
  console.log(resultado);
}

mostrarCantidad(0);

Salida por consola:

Consola 
10

Aunque hemos proporcionado 0, el operador || elige 10 porque 0 es un valor falsy. Si cero es un dato válido, ese comportamiento no es adecuado.

Podemos resolverlo utilizando un parámetro por defecto:

JavaScript 
function mostrarCantidad(cantidad = 10) {
  console.log(cantidad);
}

mostrarCantidad(0);
mostrarCantidad();

Salida por consola:

Consola 
0
10

El parámetro por defecto permite distinguir correctamente entre el valor 0 y un argumento omitido.

Orden y dependencia de los parámetros

Normalmente colocamos primero los parámetros que deben recibir un argumento y después los que tienen valores predeterminados. Es una recomendación de claridad, no una obligación sintáctica de JavaScript.

JavaScript 
function crearFicha(nombre, categoria = "General", activo = true) {
  console.log(nombre + " | " + categoria + " | " + activo);
}

crearFicha("Teclado");
crearFicha("Ratón", "Periféricos");
crearFicha("Monitor", "Pantallas", false);

Salida por consola:

Consola 
Teclado | General | true
Ratón | Periféricos | true
Monitor | Pantallas | false

Saltar un parámetro para utilizar el siguiente

Los argumentos se asignan por posición. Si queremos conservar el valor por defecto de un parámetro intermedio y proporcionar uno posterior, podemos pasar undefined en esa posición.

JavaScript 
function registrarUsuario(nombre, idioma = "es", avisos = true) {
  console.log(nombre + " - " + idioma + " - " + avisos);
}

registrarUsuario("Ana", undefined, false);

Salida por consola:

Consola 
Ana - es - false

El segundo parámetro utiliza su valor por defecto, mientras que el tercero recibe false.

Cuando hay muchos parámetros opcionales, suele ser más legible utilizar un objeto de opciones. Estudiaremos este patrón más adelante.

Un valor por defecto puede depender de un parámetro anterior

JavaScript 
function calcularPrecioFinal(precio, impuesto = precio * 0.21) {
  return precio + impuesto;
}

console.log(calcularPrecioFinal(100));
console.log(calcularPrecioFinal(100, 10));

Salida por consola:

Consola 
121
110

El valor por defecto de impuesto se calcula a partir del parámetro precio, que ya está disponible. La expresión predeterminada se evalúa cuando hace falta, durante la llamada.

📌 Importante

Los valores por defecto pueden ser expresiones, no solamente números o cadenas fijas. Para evitar errores y mejorar la comprensión, utiliza expresiones sencillas y evita depender de parámetros declarados después.

Funciones con un número variable de argumentos

Hasta ahora hemos declarado funciones con una cantidad fija de parámetros. Pero hay situaciones en las que no sabemos cuántos valores recibiremos: sumar importes, calcular promedios, registrar mensajes o procesar una lista variable de productos.

Podríamos escribir una función con tres parámetros, pero dejaría de servir si necesitáramos sumar cuatro o cinco cantidades.

JavaScript 
function sumarTres(a, b, c) {
  return a + b + c;
}

console.log(sumarTres(10, 20, 30));

Salida por consola:

Consola 
60

Para resolver este problema utilizamos los parámetros rest.

Sintaxis del parámetro rest (...)

Un parámetro rest se escribe anteponiendo tres puntos ... al nombre del parámetro. Recoge todos los argumentos que le correspondan y los almacena en un array.

JavaScript 
function mostrarProductos(...productos) {
  console.log(productos);
}

mostrarProductos("Teclado", "Ratón", "Monitor");
mostrarProductos("Webcam");
mostrarProductos();

Salida por consola:

Consola 
["Teclado", "Ratón", "Monitor"]
["Webcam"]
[]

En la primera llamada, productos es un array con tres elementos. En la segunda contiene uno. En la tercera es un array vacío.

Para comprenderlo mejor, observa este ejemplo:

JavaScript 
function mostrarDatos(...datos) {
  console.log(datos);
}

mostrarDatos(10, 20, 30);

En este caso, los tres argumentos 10, 20 y 30 se agrupan automáticamente en un único array.

Por tanto, dentro de la función, el parámetro datos contiene:

Consola 
[10, 20, 30]

Como se trata de un array, podemos utilizar propiedades y métodos conocidos, como length, for...of, push() o reduce().

Recorrer los argumentos recibidos

JavaScript 
function listarProductos(...productos) {
  console.log("Total de productos: " + productos.length);

  for (const producto of productos) {
    console.log("- " + producto);
  }
}

listarProductos("Teclado", "Ratón", "Monitor");

Salida por consola:

Consola 
Total de productos: 3
- Teclado
- Ratón
- Monitor
📌 Importante

Los tres puntos ... del parámetro rest no significan que la función reciba un array directamente como argumento. Significan que JavaScript agrupa varios argumentos en un array dentro de la función.

Utilizar rest para realizar cálculos

Vamos a desarrollar una función que sume cualquier cantidad de importes. Para ello recorreremos el array recibido y acumularemos sus valores.

JavaScript 
function sumarImportes(...importes) {
  let total = 0;

  for (const importe of importes) {
    total += importe;
  }

  return total;
}

console.log(sumarImportes(10, 20));
console.log(sumarImportes(10, 20, 5, 15));
console.log(sumarImportes());

Salida por consola:

Consola 
30
50
0

Análisis paso a paso

  1. El parámetro importes contiene un array con los argumentos recibidos.
  2. La variable total comienza en 0.
  3. El bucle for...of recorre cada importe y lo añade al acumulador.
  4. La sentencia return devuelve la suma final.
  5. Si no recibimos argumentos, el bucle no se ejecuta y la función devuelve 0.

Calcular una media con rest

Para calcular una media, además de sumar los valores, necesitamos saber cuántos se han recibido. Debemos controlar el caso del array vacío para evitar una división entre cero.

JavaScript 
function calcularMedia(...notas) {
  if (notas.length === 0) {
    return null;
  }

  let suma = 0;

  for (const nota of notas) {
    suma += nota;
  }

  return suma / notas.length;
}

console.log(calcularMedia(6, 8, 10));
console.log(calcularMedia(5, 7));
console.log(calcularMedia());

Salida por consola:

Consola 
8
6
null

Hemos decidido devolver null cuando no existen notas, porque no tiene sentido calcular una media sin datos. Es una decisión de diseño de nuestra función; también podríamos optar por mostrar un mensaje o lanzar un error, según los requisitos.

💻 Ejemplo DAW

Una plataforma educativa puede utilizar una función con rest para calcular la media de un conjunto variable de calificaciones, sin tener que declarar una función diferente para cada número de actividades.

Combinar parámetros normales, por defecto y rest

Una función puede tener parámetros normales, parámetros con valores por defecto y un parámetro rest. El parámetro rest debe colocarse siempre en último lugar.

JavaScript 
function registrarPedido(cliente, envio = "estándar", ...productos) {
  console.log("Cliente: " + cliente);
  console.log("Envío: " + envio);
  console.log("Productos: " + productos.join(", "));
}

registrarPedido("Laura", "urgente", "Teclado", "Ratón");
registrarPedido("Pablo", undefined, "Monitor");

Salida por consola:

Consola 
Cliente: Laura
Envío: urgente
Productos: Teclado, Ratón
Cliente: Pablo
Envío: estándar
Productos: Monitor

En la primera llamada, cliente recibe "Laura", envio recibe "urgente" y productos reúne los dos argumentos restantes.

En la segunda llamada, undefined activa el envío predeterminado.

Restricciones importantes

  • Una función solo puede declarar un parámetro rest.
  • El parámetro rest debe ser el último de la lista.
  • No puede tener un valor por defecto propio, porque ya recibe un array vacío cuando no quedan argumentos.
JavaScript 
// Incorrecto: rest no puede ir antes de otro parámetro.
// function ejemplo(...numeros, nombre) { }

// Incorrecto: rest no puede tener un valor por defecto.
// function ejemplo(...numeros = []) { }

// Correcto:
function ejemplo(nombre, ...numeros) {
  console.log(nombre, numeros);
}
⚠️ Atención

El código incorrecto de los comentarios es ilustrativo: si intentaras declararlo sin comentar, JavaScript produciría un SyntaxError. Recuerda que el parámetro rest debe ocupar la última posición.

Diferencia entre rest y spread

Los tres puntos ... también aparecen en otra característica de JavaScript: la sintaxis spread (expansión).

Aunque comparten el mismo símbolo, su función depende del lugar donde se escriben.

  • Rest: en la declaración de parámetros, agrupa argumentos en un array.
  • Spread: en una llamada a función o en determinadas expresiones, expande los elementos de un iterable, como un array.
JavaScript 
function sumar(...numeros) { // Rest: agrupa
  let total = 0;

  for (const numero of numeros) {
    total += numero;
  }

  return total;
}

const importes = [10, 20, 30];

console.log(sumar(...importes)); // Spread: expande

Salida por consola:

Consola 
60

En function sumar(...numeros), rest crea el array de parámetros.

En sumar(...importes), spread toma los elementos del array importes y los proporciona como argumentos individuales.

Qué ocurre si no utilizamos spread

JavaScript 
function contarArgumentos(...valores) {
  console.log(valores.length);
}

const numeros = [10, 20, 30];

contarArgumentos(numeros);
contarArgumentos(...numeros);

Salida por consola:

Consola 
1
3

La primera llamada pasa un único argumento: el array completo.

La segunda pasa tres argumentos: sus elementos individuales.

📌 Importante

Aunque rest y spread utilizan los mismos tres puntos (...), realizan operaciones diferentes:

  • Rest agrupa: varios argumentos se convierten en un array.
  • Spread expande: los elementos de un array se proporcionan como argumentos individuales.

Recuerda: rest agrupa y spread expande.

Errores frecuentes y buenas prácticas

1. Confundir un argumento omitido con null

El valor por defecto no se aplica cuando se pasa null. Si una aplicación permite ese valor, hay que decidir expresamente cómo tratarlo.

2. Pensar que rest es un número o una cadena

Rest siempre construye un array con los argumentos restantes. Para obtener su suma, media o concatenación, debemos recorrerlo o utilizar los métodos correspondientes.

3. Olvidar el orden de los argumentos

Los argumentos se asignan por posición. Un parámetro opcional intermedio puede requerir pasar undefined para conservar su valor predeterminado.

4. No comprobar si se han recibido datos

Antes de calcular una media, un máximo o un mínimo con rest, comprueba si el array contiene elementos. De lo contrario, podrías obtener NaN, Infinity u otro resultado no deseado.

5. No validar los tipos de datos

Rest permite recibir una cantidad variable de argumentos, pero no garantiza que todos sean números. En aplicaciones reales debemos validar los datos cuando proceden de formularios, peticiones o entradas del usuario.

JavaScript 
function sumarNumeros(...valores) {
  for (const valor of valores) {
    if (typeof valor !== "number" || !Number.isFinite(valor)) {
      return null;
    }
  }

  let suma = 0;

  for (const valor of valores) {
    suma += valor;
  }

  return suma;
}

console.log(sumarNumeros(10, 20, 5));
console.log(sumarNumeros(10, "20"));

Salida por consola:

Consola 
35
null

Esta versión devuelve null si encuentra un valor que no sea un número finito. Así evitamos que una cadena convierta la suma en una concatenación inesperada.

⚠️ Atención

Los parámetros por defecto y rest mejoran la flexibilidad de las funciones, pero no sustituyen la validación de datos. Una función puede recibir argumentos válidos en cantidad y, aun así, recibir valores incorrectos en tipo o contenido.

Comparación entre parámetros habituales, por defecto y rest

Tipo de parámetro Ejemplo Comportamiento
Habitual precio Recibe el argumento de su posición; si falta, vale undefined.
Por defecto unidades = 1 Utiliza 1 cuando recibe undefined.
Rest ...precios Reúne los argumentos restantes en un array y debe ir al final.

Ejemplo práctico completo: calcular presupuestos de una tienda online

Vamos a reunir los conceptos en un pequeño programa de una tienda tecnológica.

Queremos calcular presupuestos a partir de una cantidad variable de precios y aplicar, si no se indica lo contrario, un descuento del 0 % y unos gastos de envío de 4,95 €.

Para facilitar las llamadas, diseñaremos dos funciones: una suma importes mediante rest y otra calcula el presupuesto con parámetros por defecto.

JavaScript 
// Suma cualquier cantidad de importes.
function sumarImportes(...importes) {
  let total = 0;

  for (const importe of importes) {
    total += importe;
  }

  return total;
}

// Aplica descuento y añade gastos de envío.
function calcularPresupuesto(subtotal, descuento = 0, envio = 4.95) {
  const importeDescuento = subtotal * descuento / 100;
  return subtotal - importeDescuento + envio;
}

// Productos seleccionados.
const preciosCarrito = [50, 20, 150];

// Spread envía cada precio como argumento individual.
const subtotal = sumarImportes(...preciosCarrito);

const presupuestoNormal = calcularPresupuesto(subtotal);
const presupuestoPromocion = calcularPresupuesto(subtotal, 10);
const presupuestoRecogida = calcularPresupuesto(subtotal, 10, 0);

console.log("Subtotal: " + subtotal.toFixed(2) + " €");
console.log("Normal: " + presupuestoNormal.toFixed(2) + " €");
console.log("Promoción: " + presupuestoPromocion.toFixed(2) + " €");
console.log("Recogida: " + presupuestoRecogida.toFixed(2) + " €");

Salida por consola:

Consola 
Subtotal: 220.00 €
Normal: 224.95 €
Promoción: 202.95 €
Recogida: 198.00 €

Análisis paso a paso

  1. El array preciosCarrito contiene tres precios: 50, 20 y 150 euros.
  2. sumarImportes(...preciosCarrito) utiliza spread para enviar los tres precios como argumentos separados.
  3. El parámetro rest ...importes los reúne en un array y devuelve un subtotal de 220 €.
  4. calcularPresupuesto(subtotal) utiliza los valores predeterminados: descuento 0 % y envío 4,95 €. Resultado: 224,95 €.
  5. calcularPresupuesto(subtotal, 10) aplica un descuento del 10 % (22 €) y mantiene el envío de 4,95 €. Resultado: 202,95 €.
  6. calcularPresupuesto(subtotal, 10, 0) aplica el mismo descuento, pero establece el envío en 0 €. Resultado: 198 €.
💻 Ejemplo DAW

Este patrón puede utilizarse en el desarrollo de un carrito de compra, una calculadora de presupuestos o una herramienta de facturación.

La función que suma importes acepta una cantidad variable de productos; la función que calcula el presupuesto permite configurar únicamente las opciones necesarias.

function crearMensaje(usuario = "Invitado", ...acciones) {

  4. ¿Cuántas acciones se mostrarán en cada llamada?
  5. ¿Qué mostrará join(" | ") cuando el array esté vacío?
  6. ¿Cuál será la salida completa de la consola?
