📝 Actividades de la UT5

Para finalizar la UT5 vas a aplicar de forma conjunta los principales conceptos relacionados con las funciones de JavaScript, trabajados en los apartados 5.1 a 5.12.

Las actividades se organizan en tres bloques: actividades prácticas, un reto final y una autoevaluación para comprobar los conocimientos fundamentales de la unidad.

📌 Importante

En las actividades de programación no basta con conseguir que el resultado sea correcto. Debes utilizar adecuadamente las funciones, los parámetros, los valores de retorno y una organización clara del código.

💻 Actividades prácticas

Actividad 1 — Analiza la declaración y la invocación de funciones

Observa el siguiente programa sin ejecutarlo:

JavaScript 
function mostrarSaludo() {
  console.log("Hola desde la función");
}

console.log("Inicio");

mostrarSaludo();

console.log("Fin");

mostrarSaludo();
  1. Identifica dónde se declara la función.
  2. Indica cuántas veces se invoca.
  3. Escribe el orden exacto de los mensajes que aparecerán en consola.
  4. Explica qué ocurriría si eliminásemos las dos llamadas a mostrarSaludo().
  5. Ejecuta el código y comprueba tus respuestas.
📌 Recuerda

Declarar una función no significa ejecutarla. La función se ejecuta cuando se invoca mediante su nombre seguido de paréntesis.

Actividad 2 — Parámetros, argumentos y return

Crea un programa para calcular el precio final de un producto después de aplicar un descuento.

  1. Crea una función llamada calcularDescuento.
  2. La función debe recibir dos parámetros: precio y porcentaje.
  3. Calcula el importe descontado y devuelve el precio final utilizando return.
  4. Invoca la función con un precio de 80 euros y un descuento del 15 %.
  5. Guarda el resultado en una variable y muéstralo en consola.
  6. Realiza una segunda llamada con otros valores.

Puedes partir de esta estructura:

JavaScript · Estructura inicial 
function calcularDescuento(precio, porcentaje) {
  // Calcula el precio final.
  // Devuelve el resultado.
}

const precioFinal = calcularDescuento(80, 15);

console.log(precioFinal);
⚠️ Atención

La función debe devolver el resultado, no limitarse a mostrarlo mediante console.log().

Actividad 3 — Ámbito de las variables

Analiza el siguiente código antes de ejecutarlo:

JavaScript 
const nombre = "Ana";

function mostrarDatos() {
  const edad = 20;

  console.log(nombre);
  console.log(edad);
}

mostrarDatos();

console.log(nombre);
console.log(edad);
  1. Identifica la variable global y la variable local.
  2. Explica por qué la función puede acceder a nombre.
  3. Indica qué sucede al ejecutar el último console.log().
  4. Explica qué tipo de error se produce y por qué.
  5. Modifica el programa para que funcione correctamente sin convertir edad en una variable global.
📌 Recuerda

Las variables declaradas dentro de una función no pueden utilizarse directamente fuera de su ámbito. Una posible solución consiste en devolver el valor necesario.

Actividad 4 — Valores primitivos y objetos

Observa este programa:

JavaScript 
function modificarNumero(numero) {
  numero = 100;
}

function modificarUsuario(usuario) {
  usuario.nombre = "Marta";
}

let cantidad = 10;

const persona = {
  nombre: "Carlos"
};

modificarNumero(cantidad);
modificarUsuario(persona);

console.log(cantidad);
console.log(persona.nombre);
  1. Predice los dos resultados antes de ejecutar el código.
  2. Explica por qué cantidad conserva su valor.
  3. Explica por qué cambia la propiedad nombre del objeto.
  4. Indica si JavaScript utiliza realmente paso por referencia para los parámetros.
  5. Modifica modificarUsuario para que devuelva un nuevo objeto sin modificar el original.
⚠️ Atención

En JavaScript los argumentos se pasan por valor. Cuando ese valor permite acceder a un objeto, distintas variables pueden acceder al mismo objeto y modificar sus propiedades.

Actividad 5 — Parámetros por defecto, rest y funciones flecha

Vas a crear dos funciones relacionadas con el cálculo de importes.

  1. Crea una función calcularPrecio que reciba precio y iva, utilizando un IVA por defecto del 21 %.
  2. La función debe devolver el precio con IVA.
  3. Comprueba que funciona tanto indicando el IVA como omitiéndolo.
  4. Crea una función sumarImportes que utilice un parámetro rest para recibir cualquier cantidad de importes.
  5. La función debe devolver la suma de todos los importes.
  6. Reescribe calcularPrecio utilizando una función flecha.

Utiliza estas llamadas para comprobar tu programa:

JavaScript · Pruebas 
console.log(calcularPrecio(100));

console.log(calcularPrecio(100, 10));

console.log(sumarImportes(10, 20, 30));

console.log(sumarImportes(5, 15, 25, 35));
📌 Recuerda

Los parámetros por defecto proporcionan un valor alternativo cuando no se recibe un argumento o este es undefined. El parámetro rest recoge los argumentos restantes en un array.

Actividad 6 — Callbacks y funciones de orden superior

Analiza el siguiente código:

JavaScript 
function procesar(numero, operacion) {
  return operacion(numero);
}

function duplicar(numero) {
  return numero * 2;
}

function triplicar(numero) {
  return numero * 3;
}

console.log(procesar(5, duplicar));
console.log(procesar(5, triplicar));
  1. Identifica qué función actúa como función de orden superior.
  2. Indica qué funciones se utilizan como callbacks.
  3. Predice los resultados.
  4. Explica por qué escribimos duplicar y no duplicar() al pasarla como argumento.
  5. Crea una función elevarCuadrado y utilízala como callback.
  6. Reescribe una de las llamadas utilizando una función flecha directamente como argumento.

Actividad 7 — Funciones predefinidas y métodos

Una aplicación recibe datos de productos en forma de cadenas. Debes convertirlos y procesarlos correctamente.

JavaScript 
const precioTexto = "19.95";
const unidadesTexto = "4";
const producto = "teclado mecanico";
  1. Convierte precioTexto en un número decimal.
  2. Convierte unidadesTexto en un número entero.
  3. Calcula el importe total.
  4. Redondea el importe total utilizando Math.round().
  5. Muestra el nombre del producto en mayúsculas.
  6. Comprueba si el nombre contiene la palabra "teclado".
  7. Explica qué diferencia existe entre Number(), Math.round() y toUpperCase().

Actividad 8 — Funciones recursivas

Completa la siguiente función recursiva para calcular la suma de los números naturales desde 1 hasta n.

JavaScript · Código incompleto 
function sumarHasta(n) {

  // Escribe aquí el caso base.

  // Escribe aquí el caso recursivo.

}

console.log(sumarHasta(4));
  1. Define el caso base para n === 0.
  2. Escribe la llamada recursiva necesaria.
  3. Comprueba que sumarHasta(4) devuelve 10.
  4. Describe el orden de las llamadas recursivas.
  5. Explica qué sucedería si eliminases el caso base.
  6. Indica qué validación añadirías para evitar entradas negativas o no enteras.
⚠️ Atención

Toda función recursiva debe tener un caso base alcanzable y avanzar hacia él. De lo contrario, puede producirse un desbordamiento de la pila de llamadas.

Actividad 9 — Organización modular con import y export

Crea un pequeño proyecto con esta estructura:

Estructura de archivos 
calculadora/
├── index.html
└── js/
    ├── operaciones.js
    └── main.js
  1. En operaciones.js, crea y exporta las funciones sumar, restar y multiplicar.
  2. En main.js, importa las tres funciones.
  3. Realiza varias operaciones y muestra los resultados en consola.
  4. Desde index.html, carga main.js mediante type="module".
  5. Ejecuta el proyecto utilizando Live Server.
  6. Explica la función de export e import.
📌 Recuerda

Dividir el código en varios archivos no significa necesariamente utilizar módulos ES. Debemos exportar e importar los elementos correspondientes y cargar el módulo principal correctamente.

🧩 Reto final — Sistema de gestión de pedidos

Te incorporas a un equipo de desarrollo que está creando una pequeña aplicación para gestionar pedidos de una tienda de productos informáticos.

Tu responsable te pide desarrollar la lógica de cálculo de los pedidos utilizando funciones reutilizables y una organización modular.

Situación inicial

La tienda trabaja con productos que tienen un nombre, un precio unitario y una cantidad.

El programa debe calcular importes, aplicar descuentos, añadir el IVA y generar un resumen del pedido.

Los productos de prueba serán los siguientes:

JavaScript · Datos iniciales 
const productos = [
  {
    nombre: "Teclado",
    precio: 35,
    cantidad: 2
  },
  {
    nombre: "Ratón",
    precio: 20,
    cantidad: 3
  },
  {
    nombre: "Monitor",
    precio: 180,
    cantidad: 1
  }
];

El proyecto deberá tener esta estructura:

Estructura del proyecto 
gestion-pedidos/
├── index.html
└── js/
    ├── calculos.js
    ├── utilidades.js
    └── main.js

Tu misión

  1. Calcula el subtotal de cada producto. Crea una función calcularSubtotal(precio, cantidad) que devuelva el importe correspondiente.
  2. Calcula el importe total del pedido. Crea una función que reciba el array de productos y devuelva la suma de todos los subtotales.
  3. Aplica descuentos. Crea una función aplicarDescuento que reciba el importe y un porcentaje de descuento. El descuento por defecto será del 0 %.
  4. Calcula el IVA. Crea una función que reciba el importe y el porcentaje de IVA, utilizando el 21 % como valor por defecto.
  5. Utiliza una función callback. Crea una función que reciba un importe y una operación como argumento. Utilízala para aplicar una transformación al importe.
  6. Utiliza una función flecha. Implementa al menos una de las operaciones anteriores mediante una función flecha.
  7. Organiza el código en módulos. Sitúa las funciones de cálculo en calculos.js, las funciones auxiliares en utilidades.js y la ejecución principal en main.js. Utiliza export e import.
  8. Muestra el resumen del pedido. El programa debe mostrar en consola los productos, sus subtotales, el importe total antes del descuento, el descuento aplicado y el importe final con IVA.
  9. Comprueba los resultados. Ejecuta el proyecto con Live Server y verifica que los cálculos sean correctos.
  10. Explica tus decisiones. Redacta una breve explicación indicando qué funciones has creado, qué parámetros reciben, qué valores devuelven y por qué has distribuido el programa en varios módulos.
⚠️ Atención

Evita repetir operaciones de cálculo directamente en main.js. La lógica debe estar organizada en funciones reutilizables. Las funciones de cálculo deben devolver resultados que puedan utilizarse posteriormente.

📦 Entrega del reto

Entrega la carpeta gestion-pedidos con todos los archivos del proyecto y un documento breve en el que expliques las funciones implementadas, la organización modular y las pruebas realizadas.

El programa debe ejecutarse correctamente mediante Live Server y mostrar los resultados en la consola del navegador.
