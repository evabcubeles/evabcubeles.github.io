5.10 Funciones predefinidas y métodos de JavaScript

Hasta ahora hemos aprendido a crear nuestras propias funciones, definir parámetros, devolver resultados y utilizar funciones como argumentos de otras funciones.

Sin embargo, cuando desarrollamos aplicaciones con JavaScript, no necesitamos programar desde cero todas las operaciones. El lenguaje proporciona numerosas funciones predefinidas y métodos que permiten realizar tareas habituales.

Por ejemplo, podemos convertir una cadena de texto en un número, comprobar si un valor es válido, transformar textos, buscar información en arrays o redondear cantidades.

En este apartado aprenderemos a utilizar algunas de estas herramientas, prestando especial atención a sus argumentos, sus valores de retorno y las diferencias entre una función y un método.

📌 Importante

Las funciones predefinidas y los métodos nos permiten reutilizar funcionalidades que JavaScript ya proporciona.

Aunque no hayamos escrito su código interno, debemos conocer cómo se invocan, qué argumentos aceptan y qué resultado devuelven.

Qué son las funciones predefinidas

Una función predefinida es una función que ya está disponible en el entorno de programación y que podemos utilizar sin tener que implementarla nosotros.

JavaScript incorpora funciones globales como Number(), String(), parseInt() o parseFloat().

Estas funciones realizan operaciones concretas y devuelven un resultado que podemos almacenar, mostrar o utilizar en otros cálculos.

Comparación con una función creada por nosotros

JavaScript 
// Función creada por nosotros.
function convertirANumero(valor) {
  return Number(valor);
}

// Función predefinida.
const precio = Number("25");

// Nuestra función utiliza la predefinida.
const cantidad = convertirANumero("4");

console.log(precio);
console.log(cantidad);
console.log(precio * cantidad);

Salida por consola:

Consola 
25
4
100

La función Number() ya existe en JavaScript. Nosotros simplemente la invocamos para convertir una cadena de texto en un valor numérico.

Por su parte, convertirANumero() es una función creada por nosotros que utiliza internamente esa función predefinida.

💻 Ejemplo DAW

En una tienda online, los datos introducidos en un formulario pueden llegar como cadenas de texto. Antes de calcular el importe de una compra, necesitamos convertir los valores correspondientes a cantidades y precios en números.

Diferencia entre funciones y métodos

Aunque los términos función y método están relacionados, conviene distinguirlos.

Una función puede invocarse mediante su nombre, mientras que un método es una función asociada a un objeto y normalmente se invoca mediante la notación de punto.

JavaScript 
const numero = Number("25");

const mensaje = "hola";

const mayusculas = mensaje.toUpperCase();

console.log(numero);
console.log(mayusculas);

Salida por consola:

Consola 
25
HOLA

En el primer caso, Number("25") es una llamada a una función global.

En el segundo caso, toUpperCase() es un método que utilizamos sobre el valor de texto almacenado en mensaje.

Característica Función global Método
Forma habitual de llamada nombre(argumentos) objeto.metodo(argumentos)
Ejemplo Number("15") "hola".toUpperCase()
Relación con un objeto No necesita indicarse un objeto receptor Se accede a través de un objeto o valor
Valor de retorno Depende de la función Depende del método

También existen métodos de objetos predefinidos

Algunas funcionalidades se invocan a través de objetos que JavaScript ya proporciona, como Math o console.

JavaScript 
console.log(Math.max(10, 25, 7));
console.log(Math.round(8.6));

Salida por consola:

Consola 
25
9

max() y round() son métodos del objeto Math. No se invocan directamente como funciones globales.

📌 Importante

No todas las funcionalidades incorporadas en JavaScript son funciones globales. Algunas son métodos de objetos predefinidos, y otras son métodos disponibles en determinados tipos de valores.

Por eso debemos respetar la forma de llamada: Number("5"), Math.round(5.7) o "hola".toUpperCase().

El método console.log()

Durante las unidades anteriores hemos utilizado constantemente console.log() para observar el resultado de nuestros programas.

Ahora podemos identificarlo correctamente: es un método del objeto console, que normalmente está disponible en el navegador.

JavaScript 
const producto = "Monitor";
const precio = 180;

console.log("Producto:", producto);
console.log("Precio:", precio);
console.log("Disponible:", true);

Salida por consola:

Consola 
Producto: Monitor
Precio: 180
Disponible: true

Podemos enviar varios argumentos a console.log(). La consola los muestra como parte del mismo mensaje.

Mostrar un valor no significa devolverlo

Es importante recuperar una diferencia que ya estudiamos al trabajar con la sentencia return.

JavaScript 
function mostrarDoble(numero) {
  console.log(numero * 2);
}

function calcularDoble(numero) {
  return numero * 2;
}

const resultado1 = mostrarDoble(5);
const resultado2 = calcularDoble(5);

console.log(resultado1);
console.log(resultado2);

Salida por consola:

Consola 
10
undefined
10

La primera función muestra el número 10, pero no lo devuelve. Por eso resultado1 contiene undefined.

La segunda función sí devuelve 10 mediante return, de modo que podemos almacenar y reutilizar ese valor.

⚠️ Atención

console.log() resulta muy útil para comprobar el funcionamiento de un programa, pero no sustituye a return.

Conversión de valores mediante Number()

JavaScript permite trabajar con diferentes tipos de datos. En muchas ocasiones necesitamos transformar un valor de un tipo a otro.

La función global Number() intenta convertir el valor recibido en un número.

JavaScript 
console.log(Number("25"));
console.log(Number("12.5"));
console.log(Number(" 30 "));
console.log(Number(""));
console.log(Number(true));
console.log(Number(false));

Salida por consola:

Consola 
25
12.5
30
0
1
0

Análisis de las conversiones

  • Number("25") convierte una cadena numérica en el número 25.
  • Number("12.5") convierte una cadena decimal en un número.
  • Number(" 30 ") admite espacios al principio y al final.
  • Number("") devuelve 0.
  • Number(true) devuelve 1 y Number(false) devuelve 0.

Qué ocurre si el texto no representa un número

JavaScript 
const precio1 = Number("50");
const precio2 = Number("50 euros");

console.log(precio1);
console.log(precio2);

Salida por consola:

Consola 
50
NaN

La primera cadena puede convertirse correctamente en un número.

La segunda contiene caracteres que impiden interpretarla como un número completo. Por eso obtenemos NaN, un valor especial que estudiaremos más adelante.

💻 Ejemplo DAW

Si un formulario solicita la cantidad de productos, el valor introducido puede llegar como texto. Antes de multiplicarlo por el precio unitario, conviene convertirlo y comprobar que representa una cantidad válida.

Las funciones parseInt() y parseFloat()

JavaScript también proporciona las funciones globales parseInt() y parseFloat().

Ambas permiten interpretar el comienzo de una cadena de texto como un número, aunque su comportamiento no es exactamente igual al de Number().

parseInt(): interpretar un número entero

parseInt() intenta obtener un número entero a partir del comienzo del texto recibido.

JavaScript 
console.log(parseInt("25", 10));
console.log(parseInt("25.8", 10));
console.log(parseInt("30px", 10));
console.log(parseInt("abc", 10));

Salida por consola:

Consola 
25
25
30
NaN

El segundo argumento, 10, indica que queremos interpretar el número utilizando el sistema decimal.

En "25.8", la lectura se detiene al llegar al punto decimal y obtenemos 25. En "30px", se interpreta el comienzo numérico y se obtiene 30.

Si el texto no comienza por una representación numérica válida, el resultado es NaN.

⚠️ Atención

parseInt() no redondea los números decimales. Interpreta la parte inicial que corresponde a un entero y deja de leer cuando encuentra un carácter que no puede continuar esa representación.

Para redondear utilizaremos métodos como Math.round().

parseFloat(): interpretar un número decimal

parseFloat() permite interpretar números que contienen una parte decimal.

JavaScript 
console.log(parseFloat("12.75"));
console.log(parseFloat("19.99 euros"));
console.log(parseFloat("8.5px"));
console.log(parseFloat("precio 20"));

Salida por consola:

Consola 
12.75
19.99
8.5
NaN

Observa que parseFloat() puede detenerse cuando encuentra caracteres que ya no forman parte de la representación numérica.

Sin embargo, si la cadena comienza con texto no numérico, no puede obtener un número válido.

Comparación entre Number(), parseInt() y parseFloat()

Expresión Resultado Explicación
Number("25.8") 25.8 Convierte toda la cadena
parseInt("25.8", 10) 25 Interpreta la parte entera inicial
parseFloat("25.8") 25.8 Interpreta un número decimal
Number("30px") NaN La cadena completa no representa un número
parseInt("30px", 10) 30 Obtiene el entero inicial
parseFloat("30.5px") 30.5 Obtiene el decimal inicial
Number("") 0 Convierte la cadena vacía en cero
parseInt("", 10) NaN No encuentra un entero inicial
📌 Importante

Number() y las funciones de análisis de texto no son intercambiables en todos los casos.

Si necesitamos validar que un campo contiene un número completo, no debemos aceptar automáticamente el resultado de parseInt() o parseFloat(), porque pueden ignorar caracteres finales.

El valor NaN y la validación numérica

Cuando una conversión numérica no puede producir un número válido, JavaScript puede devolver el valor especial NaN.

Sus siglas proceden de la expresión inglesa Not a Number.

Aunque su nombre pueda resultar confuso, NaN pertenece al tipo number de JavaScript.

JavaScript 
const valor = Number("hola");

console.log(valor);
console.log(typeof valor);
console.log(valor === NaN);

Salida por consola:

Consola 
NaN
number
false

La última línea es especialmente importante: NaN no es igual a sí mismo mediante el operador ===.

Por tanto, no debemos comprobar si una conversión ha fallado escribiendo valor === NaN.

Comprobar NaN con Number.isNaN()

Podemos utilizar Number.isNaN(), un método del objeto Number, para comprobar si un valor es exactamente el valor numérico especial NaN.

JavaScript 
const edad1 = Number("20");
const edad2 = Number("veinte");

console.log(Number.isNaN(edad1));
console.log(Number.isNaN(edad2));
console.log(Number.isNaN("veinte"));

Salida por consola:

Consola 
false
true
false

La tercera llamada devuelve false porque la cadena "veinte" no es el valor numérico NaN. Number.isNaN() no convierte automáticamente esa cadena.

Validar números finitos

Otra comprobación útil es Number.isFinite(), que permite saber si un valor es un número finito.

JavaScript 
console.log(Number.isFinite(25));
console.log(Number.isFinite(NaN));
console.log(Number.isFinite(Infinity));
console.log(Number.isFinite("25"));

Salida por consola:

Consola 
true
false
false
false

Para validar un dato numérico introducido como texto, podemos convertirlo y comprobar después que el resultado sea finito.

JavaScript 
function convertirPrecio(texto) {
  if (texto.trim() === "") {
    return null;
  }

  const precio = Number(texto);

  if (!Number.isFinite(precio)) {
    return null;
  }

  return precio;
}

console.log(convertirPrecio("49.95"));
console.log(convertirPrecio("abc"));
console.log(convertirPrecio("   "));

Salida por consola:

Consola 
49.95
null
null

En esta función utilizamos null para indicar que no hemos obtenido un precio válido.

Primero descartamos cadenas vacías o formadas únicamente por espacios. Después convertimos el texto y comprobamos que el resultado sea un número finito.

⚠️ Atención

Que un valor sea un número finito no significa que sea adecuado para cualquier situación.

Por ejemplo, una cantidad de productos puede necesitar ser un entero positivo. En ese caso también deberíamos comprobar condiciones como Number.isInteger(cantidad) y cantidad > 0.

Conversión a texto mediante String()

La función global String() permite obtener una representación textual de diferentes valores.

JavaScript 
console.log(String(25));
console.log(String(true));
console.log(String(false));
console.log(String(null));
console.log(String(undefined));

Salida por consola:

Consola 
25
true
false
null
undefined

Aunque la consola muestre estos resultados sin comillas, todos los valores devueltos por String() son cadenas de texto.

Comprobar el tipo obtenido

JavaScript 
const numero = 150;
const texto = String(numero);

console.log(texto);
console.log(typeof numero);
console.log(typeof texto);

Salida por consola:

Consola 
150
number
string

La conversión no modifica la variable original. numero sigue conteniendo un número, mientras que texto contiene su representación como cadena.

💻 Ejemplo DAW

En una interfaz web puede ser necesario convertir cantidades numéricas a texto para construir mensajes, etiquetas o resúmenes de pedidos.

También podemos utilizar plantillas literales para incorporar valores dentro de cadenas, sin llamar expresamente a String() en muchos casos.

Métodos habituales de las cadenas de texto

Las cadenas de texto disponen de métodos que permiten transformarlas, buscar fragmentos o eliminar espacios innecesarios.

Estos métodos resultan especialmente útiles cuando trabajamos con datos introducidos por usuarios o recibidos desde otras partes de una aplicación.

toUpperCase() y toLowerCase()

toUpperCase() devuelve una versión del texto en mayúsculas, mientras que toLowerCase() devuelve una versión en minúsculas.

JavaScript 
const nombre = "JavaScript";

console.log(nombre.toUpperCase());
console.log(nombre.toLowerCase());
console.log(nombre);

Salida por consola:

Consola 
JAVASCRIPT
javascript
JavaScript

Observa que la cadena original no se modifica. Los métodos devuelven nuevas cadenas.

trim(): eliminar espacios exteriores

trim() elimina los espacios y otros caracteres de espacio en blanco situados al principio y al final del texto.

JavaScript 
const usuario = "   Laura   ";

console.log("[" + usuario + "]");
console.log("[" + usuario.trim() + "]");

Salida por consola:

Consola 
[   Laura   ]
[Laura]

Los corchetes se han añadido únicamente para que podamos identificar visualmente los espacios.

includes(): comprobar si existe un fragmento

includes() devuelve un valor booleano que indica si una cadena contiene determinado texto.

JavaScript 
const correo = "alumna@centro.es";

console.log(correo.includes("@"));
console.log(correo.includes(".es"));
console.log(correo.includes("gmail"));

Salida por consola:

Consola 
true
true
false
⚠️ Atención

Comprobar que un correo contiene @ no significa que la dirección sea válida.

includes() únicamente busca un fragmento de texto. La validación completa de formularios requiere otras comprobaciones.

slice(): obtener una parte de una cadena

slice() permite extraer una parte del texto indicando posiciones de inicio y fin.

La posición inicial se incluye, mientras que la posición final no se incluye.

JavaScript 
const codigo = "DAW2026";

console.log(codigo.slice(0, 3));
console.log(codigo.slice(3));
console.log(codigo.slice(-4));

Salida por consola:

Consola 
DAW
2026
2026

La expresión slice(-4) comienza cuatro posiciones antes del final de la cadena.

replace(): sustituir texto

replace() permite obtener una nueva cadena en la que se sustituye una coincidencia por otro texto.

JavaScript 
const mensaje = "Hola, alumno";

const nuevoMensaje = mensaje.replace(
  "alumno",
  "alumna"
);

console.log(nuevoMensaje);
console.log(mensaje);

Salida por consola:

Consola 
Hola, alumna
Hola, alumno

Cuando utilizamos dos cadenas como argumentos, replace() sustituye la primera coincidencia encontrada.

La cadena original sigue siendo la misma.

Tabla resumen de métodos de cadenas

Método Finalidad Ejemplo
toUpperCase() Convertir a mayúsculas "hola".toUpperCase() → "HOLA"
toLowerCase() Convertir a minúsculas "HOLA".toLowerCase() → "hola"
trim() Eliminar espacios exteriores " Ana ".trim() → "Ana"
includes() Buscar un fragmento "JavaScript".includes("Script") → true
slice() Extraer parte del texto "DAW2026".slice(0, 3) → "DAW"
replace() Sustituir una coincidencia "Hola Ana".replace("Ana", "Eva") → "Hola Eva"

Métodos habituales de los arrays

En la UT4 estudiamos los arrays como estructuras para almacenar varios valores.

Además, en el apartado 5.9 vimos cómo algunos métodos de arrays reciben funciones callback.

Ahora vamos a repasar algunos métodos habituales, centrándonos en cómo se invocan, qué hacen y qué resultado devuelven.

includes(): comprobar si existe un elemento

Los arrays también disponen de un método llamado includes().

En este caso permite comprobar si un array contiene un valor determinado.

JavaScript 
const productos = ["Teclado", "Ratón", "Monitor"];

console.log(productos.includes("Ratón"));
console.log(productos.includes("Impresora"));
console.log(productos.includes("ratón"));

Salida por consola:

Consola 
true
false
false

La tercera comparación devuelve false porque las cadenas "Ratón" y "ratón" no son iguales.

join(): convertir los elementos en una cadena

join() combina los elementos de un array en una cadena de texto.

Podemos indicar el separador que queremos utilizar.

JavaScript 
const categorias = [
  "Informática",
  "Periféricos",
  "Accesorios"
];

console.log(categorias.join(", "));
console.log(categorias.join(" | "));

Salida por consola:

Consola 
Informática, Periféricos, Accesorios
Informática | Periféricos | Accesorios

map(): transformar elementos

Como vimos en el apartado anterior, map() recibe una callback y devuelve un nuevo array con los resultados de aplicarla.

JavaScript 
const precios = [10, 20, 30];

const preciosDobles = precios.map(precio => {
  return precio * 2;
});

console.log(preciosDobles);
console.log(precios);

Salida por consola:

Consola 
[20, 40, 60]
[10, 20, 30]

filter(): seleccionar elementos

filter() recibe una callback que indica si cada elemento debe incluirse en el nuevo array.

JavaScript 
const precios = [15, 80, 25, 120];

const caros = precios.filter(precio => {
  return precio > 50;
});

console.log(caros);

Salida por consola:

Consola 
[80, 120]

find(): obtener el primer elemento que cumple una condición

find() también recibe una callback, pero su resultado es diferente al de filter().

Devuelve el primer elemento que cumple la condición o undefined si no encuentra ninguno.

JavaScript 
const precios = [15, 80, 25, 120];

const primerCaro = precios.find(precio => {
  return precio > 50;
});

const inexistente = precios.find(precio => {
  return precio > 200;
});

console.log(primerCaro);
console.log(inexistente);

Salida por consola:

Consola 
80
undefined

Comparación entre métodos de arrays

Método Finalidad Resultado
includes() Comprobar si existe un valor true o false
join() Unir elementos en un texto Una cadena
forEach() Ejecutar una callback por elemento undefined
map() Transformar elementos Un nuevo array
filter() Seleccionar elementos Un nuevo array
find() Buscar el primer elemento que cumple una condición El elemento o undefined
📌 Importante

Dos métodos pueden recibir callbacks y, sin embargo, devolver resultados diferentes.

Por ejemplo, filter() devuelve un array, mientras que find() devuelve un único elemento o undefined.

Métodos numéricos y el objeto Math

JavaScript proporciona herramientas para trabajar con valores numéricos, redondear cantidades y obtener resultados matemáticos.

Vamos a estudiar algunos métodos especialmente útiles en aplicaciones web.

toFixed(): representar un número con decimales

toFixed() es un método que permite obtener una representación de un número con una cantidad determinada de cifras decimales.

JavaScript 
const precio = 12.5;

console.log(precio.toFixed(2));
console.log(precio.toFixed(3));
console.log(typeof precio.toFixed(2));

Salida por consola:

Consola 
12.50
12.500
string

La última línea es muy importante: toFixed() devuelve una cadena de texto, no un número.

Este método es útil para mostrar importes, pero debemos tener cuidado si después queremos realizar operaciones matemáticas con el resultado.

⚠️ Atención

toFixed() produce una representación decimal, pero no elimina los problemas generales de precisión de los números de coma flotante de JavaScript.

Para cálculos monetarios que exijan exactitud, una aplicación real necesita una estrategia de cálculo adecuada.

Math.round(): redondear al entero más próximo

JavaScript 
console.log(Math.round(4.2));
console.log(Math.round(4.8));
console.log(Math.round(4.5));

Salida por consola:

Consola 
4
5
5

Math.floor() y Math.ceil()

Math.floor() devuelve el mayor entero que no supera el número recibido.

Math.ceil() devuelve el menor entero que no es inferior al número recibido.

JavaScript 
console.log(Math.floor(4.8));
console.log(Math.ceil(4.2));

console.log(Math.floor(-4.2));
console.log(Math.ceil(-4.8));

Salida por consola:

Consola 
4
5
-5
-4

Los ejemplos negativos permiten comprobar que floor() no significa simplemente «quitar decimales».

Math.max() y Math.min()

Estos métodos permiten obtener el mayor y el menor valor entre varios números.

JavaScript 
console.log(Math.max(10, 50, 25));
console.log(Math.min(10, 50, 25));

Salida por consola:

Consola 
50
10

Math.random(): generar valores aleatorios

Math.random() devuelve un número pseudoaleatorio mayor o igual que 0 y menor que 1.

Como el resultado cambia entre ejecuciones, no podemos indicar una salida numérica fija.

JavaScript 
const aleatorio = Math.random();

console.log(aleatorio);

const dado = Math.floor(Math.random() * 6) + 1;

console.log(dado);

La variable aleatorio contiene un número entre 0 incluido y 1 excluido.

La variable dado contendrá un número entero entre 1 y 6, ambos incluidos.

⚠️ Atención

Math.random() no debe utilizarse para generar contraseñas, tokens de seguridad ni otros valores que necesiten aleatoriedad criptográficamente segura.

Método Finalidad Ejemplo

Encadenamiento de métodos

Cuando un método devuelve un valor sobre el que podemos aplicar otro método, es posible escribir varias llamadas consecutivas.

Esta técnica se denomina encadenamiento de métodos.

Un ejemplo con cadenas de texto

JavaScript 
const nombre = "   LAURA   ";

const nombreNormalizado = nombre
  .trim()
  .toLowerCase();

console.log(nombreNormalizado);

Salida por consola:

Consola 
laura

Análisis paso a paso

  1. La variable nombre contiene una cadena con espacios exteriores y letras mayúsculas.
  2. trim() devuelve una nueva cadena sin esos espacios.
  3. Sobre esa nueva cadena se ejecuta toLowerCase().
  4. El resultado final se almacena en nombreNormalizado.

Encadenar métodos de arrays

También podemos encadenar métodos de arrays cuando el resultado de uno permite ejecutar el siguiente.

JavaScript 
const precios = [10, 80, 25, 120];

const resultado = precios
  .filter(precio => precio > 20)
  .map(precio => precio * 2);

console.log(resultado);

Salida por consola:

Consola 
[160, 50, 240]

Primero, filter() selecciona los precios superiores a 20: [80, 25, 120].

Después, map() multiplica por dos cada uno de los valores seleccionados.

📌 Importante

Para encadenar métodos debemos conocer qué devuelve cada llamada.

Si un método devuelve undefined, no podemos seguir invocando directamente métodos sobre ese resultado.

Errores frecuentes y buenas prácticas

1. Confundir una función global con un método

Debemos utilizar la sintaxis correspondiente a cada funcionalidad.

JavaScript 
// Correcto:
console.log(Number("25"));
console.log(Math.round(4.8));

// Incorrecto: no existe una función
// global llamada round().
// console.log(round(4.8));

Si no hemos definido una función llamada round, intentar invocarla directamente provocará un ReferenceError.

2. Suponer que Number() siempre devuelve un número válido

Una conversión puede producir NaN. Antes de realizar cálculos importantes, conviene comprobar el resultado.

3. Utilizar parseInt() para redondear decimales

parseInt() interpreta texto numérico; no es una función de redondeo.

JavaScript 
console.log(parseInt("8.9", 10));
console.log(Math.round(8.9));

Salida por consola:

Consola 
8
9

4. Olvidar que toFixed() devuelve una cadena

JavaScript 
const precio = 12.5;

const texto = precio.toFixed(2);

console.log(texto + 5);
console.log(Number(texto) + 5);

Salida por consola:

Consola 
12.505
17.5

La primera expresión concatena texto, mientras que la segunda realiza una suma numérica.

5. Suponer que todos los métodos modifican el valor original

Métodos como trim(), toUpperCase(), map() y filter() devuelven nuevos valores.

En cambio, otros métodos, como push() en los arrays, sí modifican la estructura original.

Debemos conocer el comportamiento de cada método antes de utilizarlo.

6. Invocar un método sobre un valor inadecuado

No todos los métodos están disponibles en todos los tipos de datos.

JavaScript 
const edad = 20;

// Incorrecto:
// edad.toUpperCase();

// Correcto:
const edadTexto = String(edad);

console.log(edadTexto);

Salida por consola:

Consola 
20

Si descomentáramos edad.toUpperCase(), se produciría un TypeError porque ese método no está disponible en un valor numérico.

7. Encadenar métodos sin comprobar su retorno

No podemos asumir que todos los métodos devuelven un objeto o un array sobre el que seguir trabajando.

JavaScript 
const numeros = [1, 2, 3];

// Incorrecto:
// numeros.forEach(n => console.log(n)).map(n => n * 2);

// Correcto:
const dobles = numeros.map(n => n * 2);

console.log(dobles);

Salida por consola:

Consola 
[2, 4, 6]

forEach() devuelve undefined. Por tanto, no podemos ejecutar directamente map() sobre ese resultado.

💻 Ejemplo DAW

Cuando procesamos datos de una aplicación web, es recomendable separar la conversión, la validación y la presentación.

Por ejemplo, podemos convertir el precio con Number(), comprobarlo con Number.isFinite() y utilizar toFixed(2) únicamente al mostrarlo.

Ejemplo práctico completo: procesamiento de un pedido online

Vamos a reunir los conceptos aprendidos mediante un ejemplo de una tienda de productos informáticos.

La aplicación recibe datos de un pedido en forma de cadenas de texto. Nuestro objetivo es comprobarlos, realizar los cálculos y mostrar un resumen del pedido.

Utilizaremos funciones predefinidas, métodos de cadenas, métodos numéricos y funciones creadas por nosotros.

El programa realizará las siguientes operaciones:

  1. Eliminar espacios innecesarios del nombre del producto.
  2. Convertir el precio y la cantidad en números.
  3. Comprobar que los valores son válidos.
  4. Calcular el subtotal y aplicar un descuento.
  5. Calcular el importe con IVA.
  6. Mostrar un resumen con dos decimales.
JavaScript 
// Datos recibidos como texto.
const nombreIntroducido = "   Teclado mecánico   ";
const precioIntroducido = "50";
const cantidadIntroducida = "2";

// Función para normalizar el nombre.
function normalizarNombre(nombre) {
  return nombre.trim();
}

// Función para convertir y validar el precio.
function obtenerPrecio(texto) {
  if (texto.trim() === "") {
    return null;
  }

  const precio = Number(texto);

  if (!Number.isFinite(precio) || precio < 0) {
    return null;
  }

  return precio;
}

// Función para convertir y validar la cantidad.
function obtenerCantidad(texto) {
  if (texto.trim() === "") {
    return null;
  }

  const cantidad = Number(texto);

  if (
    !Number.isInteger(cantidad) ||
    cantidad <= 0
  ) {
    return null;
  }

  return cantidad;
}

// Función para aplicar un descuento.
function aplicarDescuento(importe, porcentaje) {
  return importe * (1 - porcentaje / 100);
}

// Función para aplicar el IVA.
function aplicarIVA(importe, porcentaje) {
  return importe * (1 + porcentaje / 100);
}

// Función para mostrar importes.
function mostrarImporte(etiqueta, importe) {
  console.log(
    etiqueta + ": " + importe.toFixed(2) + " €"
  );
}

// Normalizamos y convertimos los datos.
const nombre = normalizarNombre(nombreIntroducido);
const precio = obtenerPrecio(precioIntroducido);
const cantidad = obtenerCantidad(cantidadIntroducida);

// Comprobamos los datos antes de calcular.
if (
  nombre === "" ||
  precio === null ||
  cantidad === null
) {
  console.log("Error: datos del pedido no válidos");
} else {
  // Calculamos el subtotal.
  const subtotal = precio * cantidad;

  // Aplicamos un descuento del 10 %.
  const conDescuento = aplicarDescuento(subtotal, 10);

  // Aplicamos el 21 % de IVA.
  const total = aplicarIVA(conDescuento, 21);

  // Mostramos el resumen.
  console.log("RESUMEN DEL PEDIDO");
  console.log("Producto: " + nombre);
  console.log("Cantidad: " + cantidad);

  mostrarImporte("Precio unitario", precio);
  mostrarImporte("Subtotal", subtotal);
  mostrarImporte("Con descuento", conDescuento);
  mostrarImporte("Total con IVA", total);
}

Salida por consola:

Consola 
RESUMEN DEL PEDIDO
Producto: Teclado mecánico
Cantidad: 2
Precio unitario: 50.00 €
Subtotal: 100.00 €
Con descuento: 90.00 €
Total con IVA: 108.90 €

Análisis paso a paso

  1. normalizarNombre() utiliza trim() para eliminar los espacios exteriores del nombre del producto.
  2. obtenerPrecio() comprueba que el texto no está vacío, lo convierte mediante Number() y verifica que sea un número finito no negativo.
  3. obtenerCantidad() utiliza Number() y Number.isInteger() para comprobar que la cantidad sea un entero positivo.
  4. El programa comprueba los resultados de las conversiones antes de realizar los cálculos.
  5. El subtotal se obtiene multiplicando el precio unitario por la cantidad: 50 × 2 = 100 €.
  6. aplicarDescuento() reduce el subtotal un 10 %, obteniendo 90 €.
  7. aplicarIVA() añade el 21 % al importe descontado, obteniendo 108,90 €.
  8. mostrarImporte() utiliza toFixed(2) para presentar los importes con dos decimales.
📌 Importante

En este ejemplo hemos combinado funciones creadas por nosotros con funciones y métodos que JavaScript ya proporciona.

La finalidad es que cada función tenga una responsabilidad concreta: normalizar datos, convertirlos, validarlos, calcular resultados o mostrarlos.

💻 Ejemplo DAW

En una aplicación de comercio electrónico real, este tipo de procesamiento formaría parte de la lógica de validación y cálculo de los pedidos.

Más adelante podremos conectar estas funciones con formularios HTML, eventos del navegador y actualizaciones de la interfaz.

Para importes monetarios reales también deberíamos definir una estrategia de precisión y redondeo adecuada a los requisitos de la aplicación.
