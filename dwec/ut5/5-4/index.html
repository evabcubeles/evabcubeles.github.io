5.4 Valores de retorno y sentencia return

En el apartado anterior hemos aprendido a utilizar parámetros y argumentos para proporcionar información a las funciones. Gracias a ellos, una misma función puede trabajar con datos diferentes en cada llamada.

Hasta ahora, muchos de nuestros ejemplos han utilizado console.log() para mostrar resultados. Sin embargo, en una aplicación web no siempre queremos mostrar inmediatamente el resultado de un cálculo.

Imagina que estamos desarrollando una tienda online. Una función calcula el importe de una compra, pero ese resultado puede ser necesario para aplicar un descuento, calcular los impuestos o mostrar el total del pedido.

Para conseguirlo, necesitamos que la función devuelva el resultado a la parte del programa que la ha llamado.

📌 Importante

La sentencia return permite que una función devuelva un valor a la expresión que la ha invocado. De esta manera, otras instrucciones pueden utilizar el resultado obtenido.

Qué significa devolver un valor

Una función puede realizar operaciones y producir un resultado. Cuando queremos utilizar ese resultado fuera de la función, podemos devolverlo mediante return.

Observa el siguiente ejemplo:

JavaScript 
function sumar(a, b) {
  return a + b;
}

const resultado = sumar(5, 3);

console.log(resultado);

La consola mostrará:

Consola 
8

Vamos a analizar qué sucede:

  1. Se realiza la llamada sumar(5, 3).
  2. Los parámetros a y b reciben los valores 5 y 3.
  3. La expresión a + b produce el valor 8.
  4. La sentencia return devuelve ese valor a la llamada.
  5. El valor devuelto se almacena en la variable resultado.
  6. Finalmente, console.log() muestra el contenido de esa variable.
sumar(5, 3) El programa llama a la función
↓
return a + b La función calcula y devuelve 8
↓
const resultado = 8 El programa utiliza el valor devuelto

Podemos interpretar que, una vez ejecutada la función, la expresión sumar(5, 3) proporciona el valor 8.

⚠️ Atención

return no muestra automáticamente el resultado en la consola. Su función es devolver un valor. Para visualizarlo, podemos utilizar console.log() desde la parte del programa que recibe ese valor.

Sintaxis de la sentencia return

La sintaxis básica de una función que devuelve un valor es la siguiente:

JavaScript 
function nombreFuncion(parametro1, parametro2) {
  // Instrucciones de la función

  return valor;
}

La palabra reservada return va seguida de una expresión cuyo resultado queremos devolver.

Esa expresión puede ser un valor literal, una variable, una operación matemática o cualquier otra expresión válida.

Devolver el resultado de una operación

JavaScript 
function calcularDoble(numero) {
  return numero * 2;
}

console.log(calcularDoble(7));

La salida será:

Consola 
14

Devolver el contenido de una variable

También podemos almacenar previamente el resultado en una variable y devolverlo después.

JavaScript 
function calcularImporte(precio, cantidad) {
  const importe = precio * cantidad;

  return importe;
}

const total = calcularImporte(20, 3);

console.log(total);

La consola mostrará:

Consola 
60

En este caso, importe es una variable declarada dentro de la función. Aunque no podamos utilizar directamente esa variable fuera de ella, sí podemos recuperar el valor devuelto y almacenarlo en total.

📌 Importante

Devolver un valor no significa hacer accesibles desde fuera todas las variables de una función. La sentencia return proporciona el resultado de una expresión.

Estudiaremos con más detalle el ámbito de las variables en el apartado 5.5.

Diferencias entre console.log() y return

Una de las confusiones más frecuentes al comenzar a trabajar con funciones es pensar que console.log() y return realizan la misma tarea.

Aunque ambos pueden aparecer en funciones, su finalidad es diferente.

Función que muestra un resultado

JavaScript 
function sumar(a, b) {
  console.log(a + b);
}

sumar(4, 6);

La consola mostrará:

Consola 
10

Esta función calcula una suma y muestra el resultado directamente.

Sin embargo, no devuelve explícitamente el valor de la suma.

Función que devuelve un resultado

JavaScript 
function sumar(a, b) {
  return a + b;
}

const resultado = sumar(4, 6);

console.log(resultado);

La consola también mostrará:

Consola 
10

La diferencia es que ahora la función devuelve el resultado, por lo que podemos guardarlo en una variable y utilizarlo posteriormente.

Característica console.log() return
Finalidad Mostrar información en la consola. Devolver un valor a la llamada.
Permite reutilizar el resultado del cálculo No por el hecho de mostrarlo. Sí, si se utiliza el valor devuelto.
Finaliza la función No. Sí, cuando se ejecuta.
Uso habitual Depuración y visualización de mensajes. Cálculos y comunicación de resultados.

¿Qué ocurre si intentamos guardar el resultado de console.log()?

Observa este ejemplo:

JavaScript 
function multiplicar(a, b) {
  console.log(a * b);
}

const resultado = multiplicar(3, 5);

console.log(resultado);

La salida será:

Consola 
15
undefined

El primer mensaje aparece porque la función ejecuta console.log(a * b).

El segundo aparece porque la función no tiene ninguna sentencia return que devuelva explícitamente el producto. Por tanto, la llamada devuelve undefined.

⚠️ Atención

Que una función muestre un resultado correcto en la consola no significa que esté devolviendo ese resultado.

Esta diferencia es fundamental para construir programas formados por funciones que colaboran entre sí.

Cómo utilizar el valor devuelto por una función

Una vez que una función devuelve un valor, podemos utilizarlo de distintas maneras.

Guardar el resultado en una variable

JavaScript 
function calcularCuadrado(numero) {
  return numero * numero;
}

const cuadrado = calcularCuadrado(6);

console.log(cuadrado);

La consola mostrará 36.

Utilizar el resultado en otra operación

JavaScript 
function calcularDoble(numero) {
  return numero * 2;
}

const total = calcularDoble(10) + 5;

console.log(total);

La salida será:

Consola 
25

Primero se ejecuta calcularDoble(10), que devuelve 20. Después se suma 5.

Utilizar el resultado como argumento de otra función

También podemos proporcionar el valor devuelto por una función como argumento de otra.

JavaScript 
function calcularSubtotal(precio, cantidad) {
  return precio * cantidad;
}

function mostrarTotal(total) {
  console.log("Total: " + total + " €");
}

mostrarTotal(calcularSubtotal(25, 4));

La consola mostrará:

Consola 
Total: 100 €

La función calcularSubtotal() devuelve 100. Ese resultado se utiliza como argumento de mostrarTotal().

Devolver un resultado desde otra función

Una función también puede llamar a otra y devolver el resultado obtenido.

JavaScript 
function calcularSubtotal(precio, cantidad) {
  return precio * cantidad;
}

function calcularTotalConEnvio(precio, cantidad) {
  const subtotal = calcularSubtotal(precio, cantidad);

  return subtotal + 5;
}

const total = calcularTotalConEnvio(20, 3);

console.log(total);

La salida será:

Consola 
65

La primera función calcula 60. La segunda recibe ese resultado, añade 5 de gastos de envío y devuelve 65.

💻 Ejemplo DAW

En una tienda online, una función puede calcular el subtotal de un pedido, otra puede aplicar descuentos y otra puede calcular los impuestos.

Gracias a return, los resultados de unas funciones pueden utilizarse en otras, evitando repetir cálculos.

La sentencia return y el final de la ejecución

Además de devolver un valor, return tiene otra característica fundamental: finaliza inmediatamente la ejecución de la función cuando se alcanza.

Esto significa que las instrucciones posteriores a un return ejecutado no se realizan en esa llamada.

JavaScript 
function mostrarEjemplo() {
  console.log("Inicio de la función");

  return 10;

  console.log("Fin de la función");
}

const resultado = mostrarEjemplo();

console.log(resultado);

La consola mostrará:

Consola 
Inicio de la función
10

El mensaje Fin de la función no aparece porque la ejecución termina al alcanzar return 10;.

Utilizar return dentro de una condición

Podemos utilizar return en estructuras condicionales para devolver resultados diferentes.

JavaScript 
function comprobarEdad(edad) {
  if (edad >= 18) {
    return "Mayor de edad";
  }

  return "Menor de edad";
}

console.log(comprobarEdad(20));
console.log(comprobarEdad(16));

La salida será:

Consola 
Mayor de edad
Menor de edad

Cuando edad vale 20, la condición es verdadera y se ejecuta el primer return.

Cuando vale 16, la condición es falsa y se alcanza el segundo return.

Salir anticipadamente de una función

La sentencia return también permite finalizar una función cuando detectamos una situación que impide continuar con el proceso.

JavaScript 
function calcularImporte(precio, cantidad) {
  if (precio < 0 || cantidad <= 0) {
    return "Datos incorrectos";
  }

  return precio * cantidad;
}

console.log(calcularImporte(20, 3));
console.log(calcularImporte(20, -2));

La consola mostrará:

Consola 
60
Datos incorrectos

En la segunda llamada, la función detecta una cantidad no válida y devuelve un mensaje sin realizar la multiplicación.

⚠️ Atención

En este ejemplo, la función puede devolver un número o una cadena de texto. Aunque JavaScript lo permite, en aplicaciones reales conviene establecer una forma coherente de comunicar los resultados y los errores.

Funciones que no devuelven un valor explícito

No todas las funciones necesitan devolver un resultado. Algunas se encargan de mostrar información o realizar una acción.

Cuando una función termina sin ejecutar una sentencia return con valor, su llamada produce undefined.

JavaScript 
function saludar(nombre) {
  console.log("Hola, " + nombre);
}

const resultado = saludar("Ana");

console.log(resultado);

La salida será:

Consola 
Hola, Ana
undefined

La sentencia return sin expresión

También podemos escribir return; sin indicar ningún valor.

En ese caso, la función termina inmediatamente y devuelve undefined.

JavaScript 
function mostrarMensaje(activo) {
  if (!activo) {
    return;
  }

  console.log("El servicio está activo");
}

mostrarMensaje(false);
mostrarMensaje(true);

La consola mostrará únicamente:

Consola 
El servicio está activo

En la primera llamada, return; finaliza la función antes de llegar a console.log().

📌 Importante

Debemos distinguir tres situaciones:

  • return expresion;: devuelve el resultado de la expresión y finaliza la función.
  • return;: finaliza la función y devuelve undefined.
  • Función sin return ejecutado: termina normalmente y devuelve undefined.

Tipos de valores que puede devolver una función

En JavaScript, las funciones no están limitadas a devolver números. Pueden devolver valores de diferentes tipos.

Devolver un número

JavaScript 
function calcularTriple(numero) {
  return numero * 3;
}

console.log(calcularTriple(4));

El resultado es 12.

Devolver una cadena de texto

JavaScript 
function obtenerSaludo(nombre) {
  return "Hola, " + nombre;
}

console.log(obtenerSaludo("Lucía"));

La salida será Hola, Lucía.

Devolver un valor booleano

Una función puede devolver true o false para indicar si se cumple una condición.

JavaScript 
function esMayorDeEdad(edad) {
  return edad >= 18;
}

console.log(esMayorDeEdad(21));
console.log(esMayorDeEdad(15));

La consola mostrará:

Consola 
true
false

En este caso, la expresión edad >= 18 ya produce un valor booleano, por lo que podemos devolver directamente su resultado.

Devolver un array

También podemos devolver una estructura que contenga varios valores.

JavaScript 
function obtenerCategorias() {
  return ["Informática", "Accesorios", "Monitores"];
}

const categorias = obtenerCategorias();

console.log(categorias[0]);
console.log(categorias.length);

La salida será:

Consola 
Informática
3

La función devuelve un array con tres elementos. Podemos almacenar ese resultado en una variable y acceder posteriormente a sus elementos mediante sus índices.

📌 Importante

Una sentencia return devuelve el resultado de una expresión. Ese resultado puede ser un número, una cadena, un booleano, un array, un objeto u otro tipo de valor.

Errores frecuentes al utilizar return

Al comenzar a utilizar valores de retorno, es habitual cometer errores relacionados con la devolución de resultados y el orden de ejecución.

1. Confundir mostrar con devolver

Una función que muestra un resultado no necesariamente lo devuelve.

JavaScript 
// Incorrecto si queremos reutilizar la suma
function sumar(a, b) {
  console.log(a + b);
}

const resultado = sumar(2, 3);

La variable resultado contendrá undefined.

La versión adecuada para devolver el resultado sería:

JavaScript 
function sumar(a, b) {
  return a + b;
}

const resultado = sumar(2, 3);

2. Escribir instrucciones después de un return incondicional

JavaScript 
function calcularDoble(numero) {
  return numero * 2;

  console.log("Cálculo terminado");
}

El mensaje no se mostrará porque return finaliza la función.

3. Olvidar devolver el resultado calculado

JavaScript 
// No devuelve el importe
function calcularImporte(precio, cantidad) {
  const importe = precio * cantidad;
}

console.log(calcularImporte(10, 4));

La consola mostrará undefined.

Para corregirlo, añadimos:

JavaScript 
function calcularImporte(precio, cantidad) {
  const importe = precio * cantidad;

  return importe;
}

4. No devolver un valor en todos los caminos necesarios

Cuando utilizamos condiciones, debemos comprobar qué ocurre en cada caso.

JavaScript 
function comprobarAcceso(edad) {
  if (edad >= 18) {
    return "Acceso permitido";
  }
}

console.log(comprobarAcceso(16));

La consola mostrará undefined, porque la condición es falsa y la función termina sin ejecutar un return.

Podemos corregirlo así:

JavaScript 
function comprobarAcceso(edad) {
  if (edad >= 18) {
    return "Acceso permitido";
  }

  return "Acceso denegado";
}

5. Pensar que return modifica automáticamente una variable externa

Devolver un valor no significa que JavaScript lo guarde automáticamente en una variable determinada.

JavaScript 
function sumar(a, b) {
  return a + b;
}

let total = 0;

sumar(4, 6);

console.log(total);

La consola mostrará 0. Hemos llamado a la función, pero no hemos utilizado el valor devuelto.

Para actualizar la variable:

JavaScript 
let total = 0;

total = sumar(4, 6);

console.log(total);

Ahora se mostrará 10. Este último fragmento supone que sumar() ya está declarada.

⚠️ Atención

Una función puede devolver correctamente un valor y, aun así, el programa puede ignorarlo si no lo guarda, muestra o utiliza en otra expresión.

Buenas prácticas al devolver valores

Para escribir funciones comprensibles, reutilizables y fáciles de mantener, conviene seguir algunas recomendaciones.

  • Devolver los resultados de los cálculos: si una función calcula un importe o una cantidad, suele ser conveniente devolver ese resultado.
  • Separar cálculo y presentación: una función puede calcular un valor y otra encargarse de mostrarlo.
  • Utilizar nombres descriptivos: nombres como calcularTotal() u obtenerPrecio() ayudan a comprender la finalidad de la función.
  • Comprobar todos los caminos de ejecución: asegurarse de que la función devuelve un resultado adecuado en las situaciones previstas.
  • Evitar instrucciones inalcanzables: no escribir operaciones necesarias después de un return incondicional.
  • Utilizar los valores devueltos: almacenar, combinar o proporcionar los resultados a otras funciones cuando sea necesario.

Separar el cálculo de la presentación

Observa cómo podemos organizar dos tareas diferentes mediante funciones independientes.

JavaScript 
function calcularImporte(precio, cantidad) {
  return precio * cantidad;
}

function mostrarImporte(importe) {
  console.log("Importe: " + importe + " €");
}

const importe = calcularImporte(30, 2);

mostrarImporte(importe);

La salida será:

Consola 
Importe: 60 €

La función calcularImporte() se encarga exclusivamente del cálculo. En cambio, mostrarImporte() se encarga de presentar el resultado.

Esta separación permite reutilizar el cálculo en otros lugares del programa.

💻 Ejemplo DAW

En una aplicación web, podríamos utilizar calcularImporte() para obtener un total y después mostrarlo en una tabla, incluirlo en un resumen de compra o utilizarlo para calcular un descuento.

La función de cálculo no necesita saber cómo se presentará finalmente el resultado.

Ejemplo práctico completo: calcular el total de una tienda online

Vamos a aplicar los conceptos estudiados mediante un programa que calcule el importe final de una compra.

En el apartado 5.3 utilizamos funciones que mostraban directamente los datos y los resultados en la consola.

Ahora vamos a separar las operaciones de cálculo de la presentación de resultados, utilizando return.

Nuestro programa debe:

  • calcular el subtotal de la compra;
  • aplicar un descuento del 10 % si el subtotal es de al menos 100 €;
  • calcular el IVA del 21 % sobre el importe después del descuento;
  • calcular el total final;
  • mostrar un resumen del pedido.

Para organizar el programa, utilizaremos varias funciones. Las encargadas de los cálculos devolverán sus resultados.

JavaScript 
// Calcula el subtotal de la compra
function calcularSubtotal(precio, cantidad) {
  return precio * cantidad;
}

// Calcula el descuento
function calcularDescuento(subtotal) {
  if (subtotal >= 100) {
    return subtotal * 0.10;
  }

  return 0;
}

// Calcula el IVA
function calcularIVA(base) {
  return base * 0.21;
}

// Calcula el total final
function calcularTotal(subtotal, descuento, iva) {
  return subtotal - descuento + iva;
}

// Muestra el resumen del pedido
function mostrarResumen(producto, subtotal, descuento, iva, total) {
  console.log("PEDIDO: " + producto);
  console.log("Subtotal: " + subtotal.toFixed(2) + " €");
  console.log("Descuento: " + descuento.toFixed(2) + " €");
  console.log("IVA: " + iva.toFixed(2) + " €");
  console.log("TOTAL: " + total.toFixed(2) + " €");
}

// Programa principal
const producto = "Teclado";
const precio = 35;
const cantidad = 4;

const subtotal = calcularSubtotal(precio, cantidad);

const descuento = calcularDescuento(subtotal);

const baseConDescuento = subtotal - descuento;

const iva = calcularIVA(baseConDescuento);

const total = calcularTotal(subtotal, descuento, iva);

mostrarResumen(producto, subtotal, descuento, iva, total);

La salida completa será:

Consola 
PEDIDO: Teclado
Subtotal: 140.00 €
Descuento: 14.00 €
IVA: 26.46 €
TOTAL: 152.46 €

Análisis paso a paso

Vamos a comprobar cómo se obtiene el resultado final.

Paso Operación Resultado
1. Subtotal 35 × 4 140 €
2. Descuento 10 % de 140 14 €
3. Base con descuento 140 − 14 126 €
4. IVA 21 % de 126 26,46 €
5. Total 140 − 14 + 26,46 152,46 €

Funciones que devuelven valores

En nuestro programa, cuatro funciones utilizan return para devolver resultados:

Función Valor devuelto
calcularSubtotal() Subtotal de la compra.
calcularDescuento() Importe del descuento.
calcularIVA() Importe del IVA.
calcularTotal() Importe final del pedido.

La función mostrarResumen(), en cambio, se encarga de mostrar la información en la consola. No necesita devolver un valor.

¿Por qué resulta útil esta organización?

Si en el futuro necesitamos mostrar el total en una página web, almacenarlo en un pedido o enviarlo a otro proceso, podremos reutilizar el valor de total sin modificar las funciones de cálculo.

📌 Importante

El método toFixed(2) se utiliza aquí para mostrar dos decimales en los importes.

Por ejemplo, observa la diferencia entre mostrar directamente un número y utilizar toFixed(2):

JavaScript 
const precio = 140;

console.log(precio);
console.log(precio.toFixed(2));

La consola mostrará:

Consola 
140
140.00

Lo estudiaremos con más detalle en el apartado 5.10. Este método devuelve una cadena de texto con el número formateado y no modifica el valor numérico original.

En aplicaciones comerciales reales, los cálculos monetarios requieren especial atención al redondeo y a la precisión de los números decimales en JavaScript. Este ejemplo tiene una finalidad didáctica.

💭 Piensa

Observa el siguiente programa sin ejecutarlo:

JavaScript 
function calcularPrecioFinal(precio, descuento) {
  if (descuento > 0) {
    return precio - descuento;
  }

  return precio;
}

const primero = calcularPrecioFinal(80, 10);
const segundo = calcularPrecioFinal(50, 0);

console.log(primero);
console.log(segundo);
console.log(primero + segundo);

Responde a las siguientes preguntas:

  1. ¿Qué valor devuelve la primera llamada?
  2. ¿Qué valor devuelve la segunda llamada?
  3. ¿Qué tres mensajes aparecerán en la consola?
  4. ¿Por qué no se ejecuta el último return en la primera llamada?
  5. ¿Qué ocurriría si sustituyéramos return precio - descuento; por console.log(precio - descuento);?
Ver una posible solución

La primera llamada devuelve 70, porque 80 - 10 = 70.

La segunda llamada devuelve 50, porque la condición es falsa y se alcanza return precio;.

La salida completa será:

Consola 
70
50
120

En la primera llamada, return precio - descuento; finaliza inmediatamente la función. Por eso no se alcanza el último return.

Si sustituyéramos ese return por console.log(precio - descuento);, la primera llamada mostraría 70 desde dentro de la función, pero después continuaría hasta return precio;.

En consecuencia, la variable primero almacenaría 80, no 70.

Con esa modificación, la salida completa del programa sería:

Consola 
70
80
50
130
