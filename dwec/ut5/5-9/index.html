5.9 Funciones como valores y funciones callback

En los apartados anteriores hemos aprendido a declarar funciones, utilizar parámetros, devolver resultados y definir funciones mediante expresiones y funciones flecha.

Ahora vamos a estudiar una característica especialmente importante de JavaScript: las funciones también pueden utilizarse como valores. Esto significa que podemos guardarlas en variables, pasarlas como argumentos a otras funciones y devolverlas como resultado.

Esta posibilidad es fundamental para comprender las funciones callback, que aparecen constantemente en el desarrollo web: al procesar arrays, responder a eventos, gestionar formularios o realizar operaciones asíncronas.

📌 Importante

Una función callback es una función que se proporciona a otra función para que esta pueda ejecutarla cuando corresponda.

La idea fundamental es distinguir entre pasar una función y ejecutar una función.

Las funciones como valores en JavaScript

Habitualmente utilizamos variables para guardar números, cadenas de texto, valores booleanos, arrays u objetos. Sin embargo, en JavaScript también podemos guardar funciones.

Esto es posible porque JavaScript trata las funciones como valores que pueden almacenarse, transmitirse y utilizarse en diferentes partes del programa. Se dice que las funciones son ciudadanos de primera clase (first-class functions).

Observa el siguiente ejemplo:

JavaScript 
function saludar(nombre) {
  return "Hola, " + nombre;
}

const mensaje = saludar;

console.log(mensaje("Ana"));
console.log(typeof mensaje);

Salida por consola:

Consola 
Hola, Ana
function

La instrucción const mensaje = saludar; no ejecuta la función. Guarda en la variable mensaje una referencia a la misma función.

Por tanto, podemos invocarla utilizando mensaje("Ana") o saludar("Ana"). Ambas llamadas ejecutan la misma función.

📌 Importante

Las funciones son valores en JavaScript. Por eso pueden asignarse a variables, guardarse en estructuras de datos, pasarse como argumentos y devolverse desde otras funciones.

Asignar funciones a variables

Vamos a profundizar en la diferencia entre guardar una función y guardar el resultado de ejecutarla.

Guardar una función sin ejecutarla

JavaScript 
function calcularDoble(numero) {
  return numero * 2;
}

const operacion = calcularDoble;

console.log(operacion(5));
console.log(operacion(12));

Salida por consola:

Consola 
10
24

La variable operacion contiene una función. Podemos ejecutarla tantas veces como necesitemos y utilizar diferentes argumentos.

Guardar el resultado de una función

JavaScript 
function calcularDoble(numero) {
  return numero * 2;
}

const resultado = calcularDoble(5);

console.log(resultado);
console.log(typeof resultado);

Salida por consola:

Consola 
10
number

Ahora sí hemos ejecutado calcularDoble(5). La función devuelve 10 y ese número queda almacenado en resultado.

Expresión Qué sucede Qué obtenemos
calcularDoble Accedemos a la función sin ejecutarla Una función
calcularDoble(5) Invocamos la función con el argumento 5 El número 10
const f = calcularDoble; Guardamos la función en otra variable Una referencia a la función
const r = calcularDoble(5); Guardamos el resultado de la llamada El número 10
⚠️ Atención

Los paréntesis cambian el significado:

const funcion = calcularDoble; guarda la función.

const resultado = calcularDoble(5); ejecuta la función y guarda el resultado.

Pasar funciones como argumentos

Hasta ahora hemos enviado números, cadenas y objetos como argumentos. Pero también podemos enviar una función como argumento de otra función.

Esto permite que una función reciba instrucciones sobre qué operación debe realizar.

JavaScript 
function sumar(a, b) {
  return a + b;
}

function multiplicar(a, b) {
  return a * b;
}

function calcular(a, b, operacion) {
  return operacion(a, b);
}

console.log(calcular(10, 5, sumar));
console.log(calcular(10, 5, multiplicar));

Salida por consola:

Consola 
15
50

Análisis paso a paso

  1. Declaramos la función sumar, que devuelve la suma de dos números.
  2. Declaramos la función multiplicar, que devuelve el producto de dos números.
  3. La función calcular recibe tres parámetros: dos números y una función llamada operacion.
  4. Cuando escribimos calcular(10, 5, sumar), estamos pasando la función sumar como tercer argumento, sin ejecutarla todavía.
  5. Dentro de calcular, la instrucción operacion(a, b) ejecuta la función recibida.
  6. En la segunda llamada pasamos multiplicar y se realiza una operación diferente.

La función calcular no necesita saber de antemano si realizará una suma o una multiplicación. Simplemente ejecuta la función que recibe.

Función externa calcular(10, 5, sumar)
Función recibida operacion = sumar
Resultado operacion(10, 5) → 15
💻 Ejemplo DAW

En una aplicación de comercio electrónico podríamos utilizar una función general para calcular precios y pasarle diferentes operaciones: aplicar un descuento, añadir IVA o calcular un recargo.

Así evitamos repetir el código que organiza la operación y cambiamos únicamente la función encargada del cálculo.

Funciones de orden superior

Una función que recibe otra función como argumento o que devuelve una función como resultado se denomina función de orden superior (higher-order function).

En el ejemplo anterior, calcular() es una función de orden superior porque recibe otra función mediante el parámetro operacion.

Las funciones sumar() y multiplicar() se utilizan como argumentos de calcular().

📌 Importante

Una función de orden superior es una función que recibe otras funciones como argumentos o devuelve funciones.

Una callback es la función que se proporciona a otra función para que esta pueda ejecutarla.

Por tanto, ambos conceptos están relacionados, pero no significan lo mismo.

Qué es una función callback

Una función callback es una función que pasamos a otra función para que esta pueda invocarla en un momento determinado.

El término inglés callback suele traducirse como «función de retorno de llamada», aunque en programación es habitual utilizar directamente la palabra callback.

Observa este ejemplo:

JavaScript 
function mostrarMensaje() {
  console.log("Operación completada");
}

function ejecutarTarea(callback) {
  console.log("Iniciando tarea");

  callback();

  console.log("Tarea finalizada");
}

ejecutarTarea(mostrarMensaje);

Salida por consola:

Consola 
Iniciando tarea
Operación completada
Tarea finalizada

La función mostrarMensaje es la callback. Se pasa como argumento a ejecutarTarea.

Dentro de ejecutarTarea, la instrucción callback() ejecuta la función recibida.

📌 Importante

Una callback no es un tipo especial de función ni necesita una sintaxis diferente.

Puede ser una declaración tradicional, una expresión de función o una función flecha. Lo que la convierte en callback es el papel que desempeña al ser proporcionada a otra función.

Cómo y cuándo se ejecuta una callback

Es importante comprender que pasar una función como argumento no implica ejecutarla inmediatamente.

La función que recibe la callback decide cuándo invocarla y, dependiendo de su diseño, incluso puede decidir no ejecutarla.

Ejecutar la callback dentro de otra función

JavaScript 
function avisar() {
  console.log("Aviso ejecutado");
}

function procesar(callback) {
  console.log("Antes de la callback");

  callback();

  console.log("Después de la callback");
}

console.log("Inicio del programa");

procesar(avisar);

console.log("Fin del programa");

Salida por consola:

Consola 
Inicio del programa
Antes de la callback
Aviso ejecutado
Después de la callback
Fin del programa

En este ejemplo, todas las instrucciones se ejecutan de forma secuencial. La callback se ejecuta exactamente cuando aparece la instrucción callback().

Ejecutar una callback solo si se cumple una condición

JavaScript 
function mostrarConfirmacion() {
  console.log("Compra confirmada");
}

function procesarCompra(importe, callback) {
  if (importe > 0) {
    callback();
  } else {
    console.log("Importe no válido");
  }
}

procesarCompra(50, mostrarConfirmacion);
procesarCompra(0, mostrarConfirmacion);

Salida por consola:

Consola 
Compra confirmada
Importe no válido

En la primera llamada se ejecuta mostrarConfirmacion. En la segunda, la condición no se cumple y la callback no llega a invocarse.

⚠️ Atención

Una callback no es necesariamente asíncrona. También puede ejecutarse inmediatamente, durante la ejecución de la función que la recibe.

Más adelante distinguiremos entre callbacks síncronas y asíncronas.

Callbacks que reciben parámetros

Una callback también puede recibir argumentos. La función que la invoca es la encargada de proporcionárselos.

Por ejemplo, podemos crear una función que procese el nombre de un usuario y permita elegir cómo mostrarlo.

JavaScript 
function mostrarMayusculas(nombre) {
  console.log(nombre.toUpperCase());
}

function mostrarSaludo(nombre) {
  console.log("Hola, " + nombre);
}

function procesarUsuario(nombre, callback) {
  callback(nombre);
}

procesarUsuario("Laura", mostrarMayusculas);
procesarUsuario("Carlos", mostrarSaludo);

Salida por consola:

Consola 
LAURA
Hola, Carlos

La función procesarUsuario recibe el nombre y la callback. Después ejecuta callback(nombre).

En la primera llamada se ejecuta mostrarMayusculas("Laura"). En la segunda se ejecuta mostrarSaludo("Carlos").

Callbacks con varios argumentos

JavaScript 
function mostrarPrecio(nombre, precio) {
  console.log(nombre + ": " + precio + " €");
}

function procesarProducto(nombre, precio, callback) {
  callback(nombre, precio);
}

procesarProducto("Teclado", 40, mostrarPrecio);

Salida por consola:

Consola 
Teclado: 40 €
📌 Importante

Cuando una función ejecuta una callback, puede pasarle tantos argumentos como necesite su diseño.

Debemos consultar cómo se invoca la callback para saber qué datos recibirá. No todas las callbacks tienen los mismos parámetros.

Callbacks y valores de retorno

Las callbacks también pueden devolver valores mediante return. La función que las ejecuta puede recoger esos resultados y utilizarlos.

Vamos a crear una función general para aplicar diferentes operaciones a un precio.

JavaScript 
function aplicarDescuento(precio) {
  return precio * 0.90;
}

function aplicarIVA(precio) {
  return precio * 1.21;
}

function transformarPrecio(precio, callback) {
  return callback(precio);
}

console.log(transformarPrecio(100, aplicarDescuento));
console.log(transformarPrecio(100, aplicarIVA));

Salida por consola:

Consola 
90
121

La función transformarPrecio no realiza directamente el descuento ni el cálculo del IVA.

Ejecuta la callback recibida y devuelve su resultado mediante return callback(precio).

El resultado de la callback no se devuelve automáticamente

Observa esta diferencia:

JavaScript 
const duplicar = numero => numero * 2;

function procesar1(numero, callback) {
  callback(numero);
}

function procesar2(numero, callback) {
  return callback(numero);
}

console.log(procesar1(5, duplicar));
console.log(procesar2(5, duplicar));

Salida por consola:

Consola 
undefined
10

En ambos casos la callback calcula 10. Sin embargo, procesar1 no devuelve ese resultado.

En cambio, procesar2 utiliza return para devolver el valor producido por la callback.

⚠️ Atención

Que una callback devuelva un valor no significa que la función que la ejecuta también lo devuelva automáticamente.

Si queremos propagar el resultado, la función externa debe devolverlo explícitamente.

Callbacks anónimas y funciones flecha

Hasta ahora hemos definido las callbacks por separado y después las hemos pasado como argumentos.

Sin embargo, también podemos escribir la función directamente en el lugar donde la necesitamos.

Callback mediante una función anónima

JavaScript 
function ejecutar(callback) {
  callback();
}

ejecutar(function() {
  console.log("Callback ejecutada");
});

Salida por consola:

Consola 
Callback ejecutada

La función anónima se crea directamente como argumento de ejecutar. No necesitamos asignarla previamente a una variable.

Callback mediante una función flecha

JavaScript 
function ejecutar(callback) {
  callback();
}

ejecutar(() => {
  console.log("Callback ejecutada");
});

Salida por consola:

Consola 
Callback ejecutada

Las dos versiones realizan la misma tarea. La segunda utiliza la sintaxis de funciones flecha estudiada en el apartado 5.8.

Funciones flecha con retorno implícito

Cuando la callback simplemente calcula y devuelve un resultado, podemos escribirla de forma muy breve.

JavaScript 
function calcular(numero, callback) {
  return callback(numero);
}

const doble = calcular(8, numero => numero * 2);

const cuadrado = calcular(8, numero => numero * numero);

console.log(doble);
console.log(cuadrado);

Salida por consola:

Consola 
16
64
💻 Ejemplo DAW

En desarrollo web es muy frecuente escribir funciones flecha directamente como callbacks, especialmente cuando la operación es breve y está relacionada con un único lugar del programa.

Si una callback contiene muchas instrucciones o se utiliza en varias partes de la aplicación, puede ser preferible definirla por separado y asignarle un nombre descriptivo.

Callbacks para trabajar con arrays

Una aplicación muy habitual de las callbacks es el procesamiento de arrays.

JavaScript proporciona métodos que reciben funciones para recorrer, transformar o seleccionar elementos de un array.

Vamos a introducir tres métodos muy utilizados: forEach(), map() y filter().

El objetivo de estos ejemplos es comprender cómo los métodos de los arrays reciben y ejecutan funciones callback. No pretendemos estudiar aquí todas las características de estos métodos, sino observar cómo se utilizan las funciones como argumentos en situaciones habituales del desarrollo web.

forEach(): ejecutar una función por cada elemento

JavaScript 
const productos = ["Teclado", "Ratón", "Monitor"];

productos.forEach(function(producto) {
  console.log(producto);
});

Salida por consola:

Consola 
Teclado
Ratón
Monitor

El método forEach() ejecuta la callback una vez por cada elemento del array.

En cada ejecución, el parámetro producto recibe el elemento correspondiente.

También podemos escribirlo mediante una función flecha:

JavaScript 
const productos = ["Teclado", "Ratón", "Monitor"];

productos.forEach(producto => {
  console.log(producto);
});

map(): transformar los elementos de un array

El método map() utiliza una callback para obtener un nuevo valor por cada elemento.

Devuelve un nuevo array con los resultados.

JavaScript 
const precios = [10, 20, 30];

const preciosConIVA = precios.map(precio => {
  return precio * 1.21;
});

console.log(preciosConIVA);
console.log(precios);

Salida por consola:

Consola 
[12.1, 24.2, 36.3]
[10, 20, 30]

El array original no se modifica por esta operación. map() construye otro array utilizando los valores que devuelve la callback.

filter(): seleccionar elementos mediante una condición

El método filter() utiliza una callback para decidir qué elementos deben incluirse en un nuevo array.

JavaScript 
const precios = [15, 80, 25, 120, 40];

const preciosAltos = precios.filter(precio => {
  return precio > 50;
});

console.log(preciosAltos);

Salida por consola:

Consola 
[80, 120]

La callback devuelve true cuando el precio supera 50. Solo esos elementos se incluyen en el array resultante.

Comparación de los tres métodos

Método Qué hace la callback Resultado del método
forEach() Ejecuta una operación por cada elemento Devuelve undefined
map() Devuelve un valor transformado por cada elemento Un nuevo array de resultados
filter() Indica si cada elemento cumple una condición Un nuevo array con los elementos seleccionados
⚠️ Atención

No confundas el valor que devuelve una callback con el valor que devuelve el método que la utiliza.

Por ejemplo, map() recoge los valores devueltos por la callback para construir un nuevo array, mientras que forEach() no devuelve un array de resultados.

Callbacks y eventos en una página web

Las callbacks también son fundamentales para crear páginas web interactivas.

Cuando una persona hace clic en un botón, escribe en un campo o envía un formulario, el navegador puede ejecutar una función que hayamos registrado previamente.

Esa función actúa como callback o manejador del evento.

Un ejemplo con un botón

Imagina que tenemos este elemento HTML:

HTML 
<button id="botonSaludar">Saludar</button>

Podemos registrar una función para que se ejecute cuando el usuario haga clic.

JavaScript 
const boton = document.getElementById("botonSaludar");

function mostrarSaludo() {
  console.log("Has pulsado el botón");
}

boton.addEventListener("click", mostrarSaludo);

Si el elemento existe y se pulsa una vez, aparecerá el siguiente mensaje:

Consola 
Has pulsado el botón

La instrucción addEventListener() registra la función mostrarSaludo para el evento click.

La función no se ejecuta al registrarla. El navegador la ejecutará cuando se produzca el evento.

Utilizar una función flecha como callback

JavaScript 
const boton = document.getElementById("botonSaludar");

boton.addEventListener("click", () => {
  console.log("Has pulsado el botón");
});

Esta versión realiza la misma tarea, pero utiliza una función flecha anónima.

💻 Ejemplo DAW

En una aplicación web utilizaremos callbacks para responder a acciones del usuario: añadir productos al carrito, validar formularios, abrir menús o actualizar información en pantalla.

En la unidad dedicada al DOM y los eventos estudiaremos addEventListener() y los manejadores de eventos con mayor profundidad.

Callbacks síncronas y asíncronas

Hasta ahora, la mayoría de nuestras callbacks se han ejecutado durante la propia llamada a la función que las recibe.

Sin embargo, una callback también puede registrarse para ejecutarse posteriormente, cuando ocurra un evento o se complete una operación.

Callback síncrona

Una callback síncrona se ejecuta durante la ejecución de la función que la invoca, siguiendo el flujo normal del programa.

JavaScript 
function ejecutar(callback) {
  console.log("Paso 1");

  callback();

  console.log("Paso 3");
}

ejecutar(() => {
  console.log("Paso 2");
});

Salida por consola:

Consola 
Paso 1
Paso 2
Paso 3

Callback asíncrona

Una callback asíncrona, en el sentido de una función programada para ejecutarse posteriormente, permite indicar qué código debe ejecutarse cuando llegue el momento correspondiente.

Por ejemplo, setTimeout() permite programar la ejecución de una función después de que transcurra al menos un tiempo determinado.

JavaScript 
console.log("Inicio");

setTimeout(() => {
  console.log("Callback del temporizador");
}, 1000);

console.log("Fin");

Salida por consola:

Consola 
Inicio
Fin
Callback del temporizador

Primero aparece Inicio. Después se registra la callback del temporizador y continúa la ejecución del programa.

Por eso aparece Fin antes del mensaje de la callback. Cuando el temporizador ha cumplido el tiempo establecido y el entorno puede atenderla, se ejecuta la función registrada.

⚠️ Atención

setTimeout(callback, 1000) no garantiza que la callback se ejecute exactamente a los 1000 milisegundos.

Ese tiempo representa un retraso mínimo aproximado. La ejecución real también depende de la disponibilidad del entorno de JavaScript.

📌 Importante

Las callbacks pueden utilizarse tanto en operaciones síncronas como asíncronas.

Además, una callback programada para ejecutarse posteriormente no necesita estar declarada con la palabra async. Son conceptos relacionados, pero diferentes.

En la unidad de comunicación asíncrona estudiaremos con más detalle los temporizadores, las promesas y las peticiones a servidores.

Errores frecuentes y buenas prácticas

1. Ejecutar una función en lugar de pasarla

Este es uno de los errores más frecuentes cuando comenzamos a trabajar con callbacks.

JavaScript 
function avisar() {
  console.log("Aviso");
}

function ejecutar(callback) {
  callback();
}

// Correcto: pasamos la función.
ejecutar(avisar);

// Incorrecto: avisar() se ejecuta primero.
// Después, ejecutar recibe undefined.
// ejecutar(avisar());

En ejecutar(avisar) pasamos la función. En ejecutar(avisar()) ejecutamos primero avisar y pasamos el valor que devuelve.

Como avisar no contiene return, devuelve undefined. Si después intentamos ejecutar ese valor mediante callback(), se producirá un TypeError.

2. Confundir los parámetros de la función externa y la callback

Cada función tiene sus propios parámetros. La callback recibe los argumentos que le proporciona la función encargada de ejecutarla.

3. Olvidar devolver el resultado

Si necesitamos utilizar el valor calculado por una callback, debemos comprobar que la función externa también devuelve ese resultado.

4. Suponer que todas las callbacks se ejecutan inmediatamente

Algunas callbacks se ejecutan durante la llamada a la función externa. Otras se registran para ejecutarse posteriormente.

El momento de ejecución depende de la función o del método que recibe la callback.

5. No comprobar que el argumento es una función

Cuando una función propia recibe una callback que podría no proporcionarse, podemos validar su tipo antes de ejecutarla.

JavaScript 
function procesar(callback) {
  if (typeof callback === "function") {
    callback();
  } else {
    console.log("No se ha recibido una función");
  }
}

procesar(() => console.log("Procesando"));
procesar(25);

Salida por consola:

Consola 
Procesando
No se ha recibido una función

6. Escribir callbacks demasiado extensas

Una callback pequeña suele resultar fácil de comprender. Sin embargo, una función anónima con muchas instrucciones puede dificultar la lectura y el mantenimiento.

Cuando la operación es compleja o debe reutilizarse, conviene definir una función con un nombre que explique su responsabilidad.

💻 Ejemplo DAW

Si una aplicación necesita validar un pedido, calcular impuestos y actualizar varios elementos, puede resultar más claro separar esas tareas en funciones con nombres descriptivos que incluir todo el código en una única callback.

La finalidad de las callbacks es facilitar la organización y reutilización del código, no complicar su estructura.

Ejemplo práctico completo: procesamiento de pedidos de una tienda online

Vamos a reunir los conceptos aprendidos mediante un ejemplo relacionado con una tienda tecnológica.

Queremos crear una función que procese el importe de un pedido y permita aplicar diferentes operaciones sin modificar su estructura principal.

Para ello utilizaremos callbacks que calcularán descuentos, añadirán IVA y mostrarán resultados.

El programa realizará las siguientes operaciones:

  1. Crear un producto con su nombre y precio.
  2. Aplicar una operación al precio mediante una callback.
  3. Calcular el precio con descuento.
  4. Calcular el precio con IVA.
  5. Mostrar un resumen por consola.
JavaScript 
// Creamos un producto.
const crearProducto = (nombre, precio) => ({
  nombre,
  precio
});

// Función que utilizaremos como callback
// para aplicar un descuento del 10 %.
const aplicarDescuento = precio => precio * 0.90;

// Función que utilizaremos como callback
// para aplicar un IVA del 21 %.
const aplicarIVA = precio => precio * 1.21;

// Función que recibe y ejecuta una callback.
function procesarPrecio(precio, operacion) {
  return operacion(precio);
}

// Función para mostrar un importe.
const mostrarImporte = function(etiqueta, importe) {
  console.log(
    etiqueta + ": " + importe.toFixed(2) + " €"
  );
};

// Creamos el producto.
const producto = crearProducto("Teclado", 100);

// Aplicamos el descuento.
const precioDescuento = procesarPrecio(
  producto.precio,
  aplicarDescuento
);

// Aplicamos el IVA al precio descontado.
const precioFinal = procesarPrecio(
  precioDescuento,
  aplicarIVA
);

// Mostramos los resultados.
console.log("RESUMEN DEL PEDIDO");
console.log("Producto: " + producto.nombre);

mostrarImporte("Precio original", producto.precio);
mostrarImporte("Con descuento", precioDescuento);
mostrarImporte("Precio final con IVA", precioFinal);

Salida por consola:

Consola 
RESUMEN DEL PEDIDO
Producto: Teclado
Precio original: 100.00 €
Con descuento: 90.00 €
Precio final con IVA: 108.90 €

Análisis paso a paso

  1. crearProducto() es una función flecha que devuelve un objeto con el nombre y el precio del producto.
  2. aplicarDescuento() es una función flecha que calcula el precio tras aplicar un descuento del 10 %.
  3. aplicarIVA() es otra función flecha que añade el 21 % de IVA.
  4. procesarPrecio() recibe un número y una callback llamada operacion.
  5. En la primera llamada a procesarPrecio(), pasamos aplicarDescuento. El precio de 100 € se transforma en 90 €.
  6. En la segunda llamada pasamos aplicarIVA. El IVA del 21 % sobre 90 € produce 108,90 €.
  7. mostrarImporte() es una expresión de función tradicional que muestra los importes con dos decimales.
  8. El objeto producto conserva su precio original de 100 €, porque los cálculos se realizan con valores numéricos y no modifican su propiedad precio.

Observa que aplicarDescuento y aplicarIVA son funciones normales definidas mediante la sintaxis de funciones flecha.

Actúan como callbacks cuando las pasamos como argumentos a procesarPrecio(), que es una función de orden superior.

📌 Importante

La función procesarPrecio() puede utilizar diferentes operaciones sin modificar su código.

Esa es una de las principales ventajas de las callbacks: permiten separar el funcionamiento general de una tarea de la operación concreta que queremos realizar.

💻 Ejemplo DAW

En una tienda online real, podríamos ampliar este sistema con nuevas callbacks para aplicar descuentos especiales, recargos o diferentes reglas de cálculo.

También podríamos utilizar callbacks para recorrer productos del carrito, filtrar artículos disponibles o responder al clic del botón «Finalizar compra».

💭 Piensa

Observa el siguiente programa sin ejecutarlo. Intenta responder a las preguntas antes de consultar la solución.

JavaScript 
function calcular(precio, callback) {
  console.log("Calculando...");
  return callback(precio);
}

const descuento = precio => precio * 0.80;

const iva = function(precio) {
  return precio * 1.21;
};

const mostrarResultado = (nombre, precio) => {
  console.log(nombre + ": " + precio.toFixed(2) + " €");
};

const precioOriginal = 100;

const precioDescuento = calcular(
  precioOriginal,
  descuento
);

const precioFinal = calcular(
  precioDescuento,
  iva
);

mostrarResultado("Precio original", precioOriginal);
mostrarResultado("Con descuento", precioDescuento);
mostrarResultado("Con IVA", precioFinal);
  1. ¿Qué función está definida mediante una declaración tradicional?
  2. ¿Qué funciones utilizan la sintaxis de funciones flecha?
  3. ¿Qué función es una expresión de función tradicional?
  4. ¿Qué parámetro de calcular() representa la callback?
  5. ¿Por qué escribimos calcular(precioOriginal, descuento) y no calcular(precioOriginal, descuento())?
  6. ¿Cuántas veces se ejecuta calcular() y qué callback recibe en cada ocasión?
  7. ¿Qué valores tendrán precioDescuento y precioFinal?
  8. ¿Qué mensajes aparecerán en la consola y en qué orden?
Ver una posible solución

1. calcular es una declaración tradicional porque utiliza function calcular(...).

2. descuento y mostrarResultado son funciones flecha porque utilizan el operador =>.

3. iva es una expresión de función tradicional. Se crea con function y se asigna a una variable declarada mediante const.

4. El parámetro callback de calcular() recibe la función que se utilizará para transformar el precio.

5. Escribimos descuento sin paréntesis porque queremos pasar la propia función. Si escribiéramos descuento(), intentaríamos ejecutarla antes de pasar el argumento. Además, en este caso recibiría undefined como precio y produciría NaN.

6. calcular() se ejecuta dos veces. Primero recibe descuento y después recibe iva.

7. El precio original es 100 €. El descuento del 20 % produce precioDescuento = 80. Después se añade el 21 % de IVA: precioFinal = 96.8.

8. La salida completa será:

Consola 
Calculando...
Calculando...
Precio original: 100.00 €
Con descuento: 80.00 €
Con IVA: 96.80 €

Los dos primeros mensajes aparecen porque calcular() se ejecuta dos veces. En cada llamada muestra "Calculando..." antes de invocar la callback.

Finalmente, las tres llamadas a mostrarResultado() muestran los importes con dos decimales.
