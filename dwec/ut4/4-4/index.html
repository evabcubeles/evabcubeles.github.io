4.4 Modificar arrays con splice()

En el apartado anterior hemos aprendido a añadir y eliminar elementos utilizando push(), pop(), unshift() y shift().

Estos métodos son muy útiles cuando queremos trabajar con el principio o el final del array. Sin embargo, en muchas ocasiones necesitaremos modificar una posición concreta.

Para ello JavaScript dispone del método splice(), que permite eliminar, insertar o sustituir elementos en cualquier posición de un array.

📌 Importante

splice() modifica directamente el array original. No crea un nuevo array con el resultado de la modificación.

Qué permite hacer splice()

Hasta ahora hemos trabajado principalmente con los extremos de un array. Con splice() podemos indicar exactamente en qué posición queremos realizar una modificación.

Este método permite realizar tres operaciones fundamentales:

  • Eliminar uno o varios elementos.
  • Insertar nuevos elementos.
  • Sustituir elementos existentes por otros.
Operación ¿Qué hace?
Eliminar Borra elementos a partir de una posición concreta.
Insertar Añade elementos en una posición determinada.
Sustituir Elimina elementos y coloca otros nuevos en su lugar.

Sintaxis de splice()

La forma general del método es:

JavaScript 
array.splice(posicionInicial, cantidadEliminar, elementosNuevos);

Sus parámetros tienen el siguiente significado:

Parámetro Significado
posicionInicial Índice en el que comenzará la modificación.
cantidadEliminar Número de elementos que queremos eliminar.
elementosNuevos Elementos que queremos insertar. Este parámetro es opcional.
⚠️ Atención

El primer parámetro de splice() es un índice. Recuerda que los índices de los arrays comienzan en 0.

Eliminar elementos con splice()

Para eliminar elementos indicamos:

  • La posición desde la que queremos comenzar.
  • Cuántos elementos queremos eliminar.

Observa el siguiente array:

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript", "PHP"];

lenguajes.splice(1, 1);

console.log(lenguajes);

La instrucción:

JavaScript 
lenguajes.splice(1, 1);

significa:

  • Comienza en el índice 1.
  • Elimina 1 elemento.

Como "CSS" ocupa el índice 1, será el elemento eliminado.

El resultado será:

Console 
["HTML", "JavaScript", "PHP"]

Eliminar varios elementos

También podemos eliminar varios elementos consecutivos.

JavaScript 
const tecnologias = ["HTML", "CSS", "JavaScript", "PHP", "SQL"];

tecnologias.splice(1, 2);

console.log(tecnologias);

En este caso comenzamos en el índice 1 y eliminamos 2 elementos: "CSS" y "JavaScript".

El resultado será:

Console 
["HTML", "PHP", "SQL"]

Insertar elementos con splice()

splice() también permite insertar elementos sin eliminar ninguno.

Para conseguirlo, utilizamos 0 como segundo parámetro:

JavaScript 
const lenguajes = ["HTML", "JavaScript"];

lenguajes.splice(1, 0, "CSS");

console.log(lenguajes);

La instrucción:

JavaScript 
lenguajes.splice(1, 0, "CSS");

significa:

  • Comienza en el índice 1.
  • Elimina 0 elementos.
  • Inserta "CSS".

El resultado será:

Console 
["HTML", "CSS", "JavaScript"]
📌 Importante

Cuando el segundo parámetro de splice() es 0, no se elimina ningún elemento. Los nuevos elementos simplemente se insertan a partir de la posición indicada.

Insertar varios elementos

Podemos añadir varios elementos en la misma operación:

JavaScript 
const tecnologias = ["HTML", "PHP"];

tecnologias.splice(1, 0, "CSS", "JavaScript");

console.log(tecnologias);

El resultado será:

Console 
["HTML", "CSS", "JavaScript", "PHP"]

Sustituir elementos con splice()

Una de las posibilidades más útiles de splice() consiste en eliminar un elemento e insertar otro en su lugar.

De esta forma podemos sustituir elementos.

JavaScript 
const lenguajes = ["HTML", "CSS", "PHP"];

lenguajes.splice(2, 1, "JavaScript");

console.log(lenguajes);

La instrucción:

JavaScript 
lenguajes.splice(2, 1, "JavaScript");

indica que:

  • La modificación comienza en el índice 2.
  • Se elimina 1 elemento: "PHP".
  • En esa posición se inserta "JavaScript".

El resultado será:

Console 
["HTML", "CSS", "JavaScript"]

Sustituir varios elementos

También podemos sustituir varios elementos en una sola operación:

JavaScript 
const tecnologias = ["HTML", "CSS", "PHP", "MySQL"];

tecnologias.splice(2, 2, "JavaScript", "Node.js");

console.log(tecnologias);

Se eliminan "PHP" y "MySQL", y en su lugar se insertan "JavaScript" y "Node.js".

Console 
["HTML", "CSS", "JavaScript", "Node.js"]

Valor devuelto por splice()

Además de modificar el array original, splice() devuelve un nuevo array que contiene los elementos eliminados.

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript", "PHP"];

const eliminados = lenguajes.splice(1, 2);

console.log(eliminados);
console.log(lenguajes);

Console mostrará:

Console 
["CSS", "JavaScript"]
["HTML", "PHP"]

Por tanto, debemos distinguir entre:

  • lenguajes: el array original, que ha sido modificado.
  • eliminados: un nuevo array que contiene los elementos que splice() ha eliminado.
⚠️ Atención

El valor devuelto por splice() no es el array modificado. Es un array que contiene los elementos que han sido eliminados.

¿Qué ocurre si no eliminamos ningún elemento?

Si utilizamos splice() únicamente para insertar, el método devuelve un array vacío porque no se ha eliminado ningún elemento.

JavaScript 
const lenguajes = ["HTML", "JavaScript"];

const eliminados = lenguajes.splice(1, 0, "CSS");

console.log(eliminados);
console.log(lenguajes);

Console mostrará:

Console 
[]
["HTML", "CSS", "JavaScript"]

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación mantiene un array con las opciones de un menú. Queremos insertar una nueva opción, sustituir otra y eliminar una que ya no necesitamos.

JavaScript 
const menu = [
  "Inicio",
  "Productos",
  "Contacto"
];

menu.splice(2, 0, "Servicios");

console.log(menu);

Hemos insertado "Servicios" en el índice 2 sin eliminar ningún elemento.

Console 
["Inicio", "Productos", "Servicios", "Contacto"]

Ahora podemos sustituir "Productos" por "Catálogo":

JavaScript 
menu.splice(1, 1, "Catálogo");

console.log(menu);

El resultado será:

Console 
["Inicio", "Catálogo", "Servicios", "Contacto"]

Finalmente podemos eliminar "Servicios":

JavaScript 
menu.splice(2, 1);

console.log(menu);

El array final será:

Console 
["Inicio", "Catálogo", "Contacto"]

Errores frecuentes al utilizar splice()

1. Confundir el índice con el número de elementos

En:

JavaScript 
lenguajes.splice(2, 1);

el 2 indica la posición inicial y el 1 indica cuántos elementos deben eliminarse.

2. Olvidar que splice() modifica el array original

Después de utilizar splice(), el array sobre el que hemos ejecutado el método puede tener un contenido y una longitud diferentes.

3. Pensar que splice() devuelve el array modificado

splice() devuelve un array con los elementos eliminados, no el array después de la modificación.

4. Olvidar utilizar 0 cuando solo queremos insertar

Si queremos añadir elementos sin borrar ninguno, la cantidad de elementos que se deben eliminar tiene que ser 0.

📌 Recuerda

Puedes interpretar splice() pensando en tres preguntas: ¿desde dónde?, ¿cuántos elimino? y ¿qué elementos añado?.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const modulos = [
  "DWEC",
  "DIW",
  "SASP",
  "DAW"
];

const eliminados = modulos.splice(
  1,
  2,
  "Programación"
);

console.log(eliminados);
console.log(modulos);

Antes de ejecutarlo, responde:

  • ¿En qué índice comienza la modificación?
  • ¿Cuántos elementos se eliminan?
  • ¿Qué elementos se eliminan?
  • ¿Qué elemento se añade?
  • ¿Qué contendrá eliminados?
  • ¿Cómo quedará finalmente modulos?
Ver solución

La modificación comienza en el índice 1.

Se eliminan 2 elementos: "DIW" y "SASP".

En esa posición se añade "Programación".

Por tanto:

Console 
["DIW", "SASP"]
["DWEC", "Programación", "DAW"]

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y prueba las siguientes instrucciones una a una:

JavaScript 
const tecnologias = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

tecnologias.splice(1, 1);
tecnologias;

tecnologias.splice(1, 0, "CSS");
tecnologias;

tecnologias.splice(3, 1, "Node.js");
tecnologias;

Antes de ejecutar cada splice(), intenta predecir cómo quedará el array.

Después comprueba el resultado en Console y observa cómo cambian los índices y la propiedad length.
