UT4 - Arrays y estructuras de datos en JavaScript

En esta unidad aprenderemos a trabajar con arrays, estructuras que permiten almacenar varios valores dentro de una misma variable y acceder a ellos mediante su posición. Los arrays son una de las herramientas fundamentales de JavaScript para organizar y procesar conjuntos de datos.

Comenzaremos aprendiendo a crear e inicializar arrays, acceder a sus elementos mediante índices y utilizar la propiedad length. Después veremos cómo modificar su contenido, añadir y eliminar elementos y buscar información utilizando distintos métodos proporcionados por JavaScript.

También aprenderemos a recorrer arrays utilizando las estructuras repetitivas estudiadas en la UT3, especialmente el bucle for, y conoceremos otras herramientas específicas como for...of y forEach(). A partir de estos recorridos podremos procesar, transformar y filtrar conjuntos de datos.

Finalmente, estudiaremos cómo ordenar arrays, trabajar con estructuras multidimensionales y combinar las distintas operaciones aprendidas para resolver problemas completos. Durante toda la unidad prestaremos especial atención a la elección de la operación adecuada, las pruebas y la depuración del código.
