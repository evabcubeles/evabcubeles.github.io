4.8 El método forEach()

En los apartados anteriores hemos aprendido a recorrer arrays utilizando un bucle for y la estructura for...of.

JavaScript proporciona además métodos propios de los arrays que permiten realizar operaciones sobre sus elementos. Uno de los más utilizados para recorrerlos es forEach().

El método forEach() ejecuta una acción una vez por cada elemento del array.

📌 Importante

forEach() recorre todos los elementos del array y ejecuta para cada uno de ellos el código que indiquemos.

Sintaxis de forEach()

Una forma habitual de utilizar forEach() es:

JavaScript 
array.forEach((elemento) => {
  // instrucciones
});

En esta estructura:

  • array es el array que queremos recorrer.
  • forEach() ejecutará el código una vez por cada elemento.
  • elemento irá tomando el valor de cada elemento del array.
  • El código situado entre las llaves se ejecutará en cada iteración.
⚠️ Atención

La expresión (elemento) => { ... } es una función flecha. En este apartado utilizaremos esta sintaxis únicamente para poder trabajar con forEach(). Las funciones se estudiarán con detalle en la UT5.

Recorrer un array con forEach()

Observa el siguiente ejemplo:

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

lenguajes.forEach((lenguaje) => {
  console.log(lenguaje);
});

Console mostrará:

Console 
HTML
CSS
JavaScript
PHP

El método forEach() va recorriendo el array desde el primer elemento hasta el último.

En cada recorrido, la variable lenguaje contiene directamente el elemento actual.

Iteración Valor de lenguaje
1 HTML
2 CSS
3 JavaScript
4 PHP

El elemento actual

Al igual que ocurría con for...of, forEach() permite trabajar directamente con el elemento actual.

Por ejemplo:

JavaScript 
const navegadores = [
  "Chrome",
  "Firefox",
  "Edge"
];

navegadores.forEach((navegador) => {
  console.log(navegador);
});

La variable navegador irá tomando sucesivamente los valores "Chrome", "Firefox" y "Edge".

📌 Recuerda

El nombre de la variable lo elegimos nosotros. Conviene utilizar un nombre en singular relacionado con el contenido del array: alumno, nota, producto, lenguaje, etc.

Acceder también al índice

Una diferencia interesante respecto a for...of es que forEach() puede proporcionarnos también el índice del elemento actual.

Para ello añadimos un segundo parámetro:

JavaScript 
array.forEach((elemento, indice) => {
  // instrucciones
});

El primer parámetro representa el elemento y el segundo representa su posición dentro del array.

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

lenguajes.forEach((lenguaje, indice) => {
  console.log(indice, lenguaje);
});

Console mostrará:

Console 
0 HTML
1 CSS
2 JavaScript
3 PHP
⚠️ Atención

En forEach(), el primer parámetro es el elemento y el segundo es el índice. No debemos intercambiar su significado.

Realizar operaciones con forEach()

Durante el recorrido podemos realizar operaciones con los elementos del array, igual que hacíamos con for y for...of.

Por ejemplo, podemos sumar todas las notas:

JavaScript 
const notas = [
  7,
  5,
  9,
  6,
  8
];

let suma = 0;

notas.forEach((nota) => {
  suma += nota;
});

console.log(suma);

Console mostrará:

Console 
35

Combinar forEach() con una condición

También podemos incluir estructuras condicionales dentro de forEach().

Por ejemplo, podemos contar cuántas notas están aprobadas:

JavaScript 
const notas = [
  7,
  4,
  9,
  3,
  6
];

let aprobadas = 0;

notas.forEach((nota) => {

  if (nota >= 5) {
    aprobadas++;
  }

});

console.log(aprobadas);

Console mostrará:

Console 
3

Comparación entre for, for...of y forEach()

Ahora conocemos tres formas diferentes de recorrer un array. Todas permiten acceder a sus elementos, pero cada una tiene características diferentes.

Característica for for...of forEach()
Acceso al elemento Mediante array[i]. Directo. Directo.
Acceso al índice Sí. No directamente. Sí, como segundo parámetro.
Control del inicio y final Sí. No directamente. No directamente.
Recorrido inverso sencillo Sí. No directamente. No directamente.
Recorrido de todos los elementos Sí. Sí. Sí.
Sintaxis Más detallada. Sencilla. Basada en un método del array.
📌 Recuerda

No existe una única forma correcta de recorrer todos los arrays. La elección depende de lo que necesitemos hacer durante el recorrido.

¿Cuándo utilizar forEach()?

forEach() resulta especialmente útil cuando queremos ejecutar una acción para cada elemento del array.

Por ejemplo:

  • Mostrar todos los elementos.
  • Realizar un cálculo con cada valor.
  • Comprobar una condición para cada elemento.
  • Utilizar también el índice durante el recorrido.
💡 Elección del recorrido

Si necesitamos controlar exactamente las posiciones que se recorren, un for tradicional suele ser más adecuado. Si queremos trabajar directamente con todos los elementos, podemos utilizar for...of o forEach().

Limitaciones de forEach()

Aunque forEach() es muy cómodo para recorrer arrays, no ofrece el mismo control que un bucle for.

Una diferencia importante es que no podemos utilizar break para detener el recorrido antes de llegar al final.

⚠️ Atención

forEach() está pensado para ejecutar una acción sobre cada elemento. Si necesitamos detener el recorrido con break, debemos elegir otra estructura.

Tampoco utilizamos continue dentro de forEach() de la misma forma que en un bucle tradicional.

Por ello, antes de elegir una forma de recorrido debemos pensar qué control necesitamos sobre las iteraciones.

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación registra los tiempos de carga de varios recursos de una página web. Queremos mostrar cada tiempo, calcular el total y contar cuántos recursos han tardado más de 1000 milisegundos.

JavaScript 
const tiempos = [
  320,
  450,
  1200,
  580,
  1500
];

let total = 0;
let lentos = 0;

tiempos.forEach((tiempo, indice) => {

  console.log(
    "Recurso " + indice + ": " + tiempo + " ms"
  );

  total += tiempo;

  if (tiempo > 1000) {
    lentos++;
  }

});

console.log("Tiempo total: " + total + " ms");
console.log("Recursos lentos: " + lentos);

Console mostrará:

Console 
Recurso 0: 320 ms
Recurso 1: 450 ms
Recurso 2: 1200 ms
Recurso 3: 580 ms
Recurso 4: 1500 ms
Tiempo total: 4050 ms
Recursos lentos: 2

En este ejemplo, forEach() nos permite obtener tanto el valor de cada tiempo como su índice.

  • tiempo representa el valor actual.
  • indice representa su posición en el array.
  • Acumulamos los tiempos en total.
  • Contamos los valores superiores a 1000 milisegundos.

Errores frecuentes al utilizar forEach()

1. Olvidar que forEach() es un método

forEach() se aplica sobre el array que queremos recorrer:

JavaScript 
lenguajes.forEach((lenguaje) => {
  console.log(lenguaje);
});

2. Confundir el elemento con el índice

Si utilizamos dos parámetros, el primero representa el elemento y el segundo su índice:

JavaScript 
lenguajes.forEach((lenguaje, indice) => {
  console.log(indice, lenguaje);
});

3. Olvidar los paréntesis de forEach()

Al tratarse de un método, debemos escribir forEach(...) con sus paréntesis.

4. Intentar utilizar break

No podemos utilizar break dentro de forEach() para detener el recorrido.

Si necesitamos interrumpir las iteraciones antes de llegar al final del array, debemos utilizar otra estructura más apropiada.

5. Pensar que forEach() crea un nuevo array

forEach() sirve para ejecutar una acción por cada elemento. No crea automáticamente un nuevo array con los resultados.

📌 Recuerda

forEach() es especialmente útil cuando queremos recorrer todos los elementos y realizar una acción con cada uno. En el siguiente apartado veremos otros métodos diseñados para obtener nuevos arrays a partir de uno existente.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const numeros = [
  4,
  7,
  2,
  9,
  6
];

let suma = 0;
let mayores = 0;

numeros.forEach((numero, indice) => {

  console.log(indice, numero);

  suma += numero;

  if (numero > 5) {
    mayores++;
  }

});

console.log(suma);
console.log(mayores);

Antes de ejecutarlo, responde:

  • ¿Qué valores irá tomando numero?
  • ¿Qué valores irá tomando indice?
  • ¿Qué representa cada uno de los dos parámetros?
  • ¿Qué valor tendrá finalmente suma?
  • ¿Qué valor tendrá finalmente mayores?
Ver solución

numero irá tomando los valores 4, 7, 2, 9 y 6.

indice irá tomando los valores 0, 1, 2, 3 y 4.

El primer parámetro representa el elemento actual y el segundo representa su índice.

La suma será 4 + 7 + 2 + 9 + 6 = 28.

Los valores mayores que 5 son 7, 9 y 6, por lo que mayores tendrá el valor 3.

Console mostrará:

Console 
0 4
1 7
2 2
3 9
4 6
28
3

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y prueba las siguientes instrucciones:

JavaScript 
const tecnologias = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

tecnologias.forEach((tecnologia) => {
  console.log(tecnologia);
});

tecnologias.forEach((tecnologia, indice) => {
  console.log(indice, tecnologia);
});

Antes de ejecutarlo, intenta predecir qué mostrará cada recorrido.

Después observa la diferencia entre utilizar únicamente tecnologia y utilizar los parámetros tecnologia e indice.
