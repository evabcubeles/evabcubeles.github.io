4.10 Ordenar e invertir arrays

En los apartados anteriores hemos aprendido a recorrer arrays, buscar elementos, transformar sus valores y seleccionar aquellos que cumplen determinadas condiciones.

En muchas aplicaciones también necesitamos ordenar los datos. Por ejemplo, podemos querer mostrar productos por precio, puntuaciones de menor a mayor o nombres alfabéticamente.

JavaScript proporciona métodos específicos para realizar estas operaciones. En este apartado estudiaremos principalmente sort() y reverse().

📌 Importante

sort() permite ordenar los elementos de un array y reverse() permite invertir el orden en el que se encuentran. A diferencia de map() y filter(), estos métodos modifican el array original.

Ordenar un array con sort()

El método sort() permite ordenar los elementos de un array.

Su forma básica es:

JavaScript 
array.sort();

Por ejemplo:

JavaScript 
const lenguajes = [
  "JavaScript",
  "CSS",
  "HTML",
  "PHP"
];

lenguajes.sort();

console.log(lenguajes);

Console mostrará:

Console 
["CSS", "HTML", "JavaScript", "PHP"]

En este caso, sort() ordena las cadenas de texto siguiendo su orden lexicográfico.

📌 Recuerda

Cuando trabajamos con cadenas de texto, sort() puede utilizarse para realizar una ordenación básica de sus elementos.

sort() modifica el array original

Una característica muy importante de sort() es que modifica directamente el array sobre el que se utiliza.

Observa:

JavaScript 
const lenguajes = [
  "JavaScript",
  "CSS",
  "HTML"
];

console.log(lenguajes);

lenguajes.sort();

console.log(lenguajes);

Console mostrará:

Console 
["JavaScript", "CSS", "HTML"]
["CSS", "HTML", "JavaScript"]

El contenido del array lenguajes ha cambiado después de utilizar sort().

Esto supone una diferencia importante respecto a métodos como map() y filter(), que generan un nuevo array sin modificar directamente el original.

Método ¿Modifica el array original? ¿Genera un nuevo array?
map() No. Sí.
filter() No. Sí.
sort() Sí. No.
⚠️ Atención

Si necesitamos conservar el orden original de los datos, no debemos aplicar sort() directamente sobre ese array sin tener en cuenta que será modificado.

El problema de sort() con los números

Cuando utilizamos sort() sin indicar cómo queremos ordenar los datos, JavaScript no realiza una ordenación numérica como podríamos esperar.

Observa:

JavaScript 
const numeros = [
  2,
  10,
  5,
  30
];

numeros.sort();

console.log(numeros);

Podríamos esperar:

Resultado esperado 
[2, 5, 10, 30]

Sin embargo, Console mostrará:

Console 
[10, 2, 30, 5]

Esto ocurre porque, de forma predeterminada, sort() compara los elementos como cadenas de texto.

Por este motivo, para ordenar correctamente números debemos indicar el criterio de ordenación.

📌 Importante

No debemos utilizar simplemente sort() cuando queremos ordenar números de menor a mayor o de mayor a menor.

Ordenar números de menor a mayor

Para ordenar números correctamente podemos proporcionar a sort() una función que indique cómo deben compararse los valores.

Para ordenar de menor a mayor utilizaremos:

JavaScript 
numeros.sort((a, b) => {
  return a - b;
});

Por ejemplo:

JavaScript 
const numeros = [
  20,
  5,
  100,
  12
];

numeros.sort((a, b) => {
  return a - b;
});

console.log(numeros);

Console mostrará:

Console 
[5, 12, 20, 100]

La expresión:

JavaScript 
a - b

indica a sort() que queremos realizar una ordenación numérica ascendente, es decir, de menor a mayor.

⚠️ Atención

De nuevo estamos utilizando una función flecha para trabajar con un método de los arrays. Las funciones se estudiarán en profundidad en la UT5.

En este apartado es suficiente recordar:

JavaScript 
return a - b;

→ ordena los números de menor a mayor.

Ordenar números de mayor a menor

Si queremos realizar la ordenación contraria, utilizamos:

JavaScript 
numeros.sort((a, b) => {
  return b - a;
});

Por ejemplo:

JavaScript 
const numeros = [
  20,
  5,
  100,
  12
];

numeros.sort((a, b) => {
  return b - a;
});

console.log(numeros);

Console mostrará:

Console 
[100, 20, 12, 5]

Podemos resumirlo de esta forma:

Ordenación Criterio
Menor → mayor a - b
Mayor → menor b - a
📌 Recuerda

Para números, return a - b; ordena de menor a mayor y return b - a; ordena de mayor a menor.

Invertir un array con reverse()

El método reverse() invierte el orden actual de los elementos de un array.

Su sintaxis es:

JavaScript 
array.reverse();

Por ejemplo:

JavaScript 
const tecnologias = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

tecnologias.reverse();

console.log(tecnologias);

Console mostrará:

Console 
["PHP", "JavaScript", "CSS", "HTML"]

El primer elemento pasa a ocupar la última posición, el segundo pasa a la penúltima, y así sucesivamente.

⚠️ Atención

reverse() no ordena los elementos según su valor. Únicamente invierte el orden que tienen actualmente. Además, igual que sort(), reverse() modifica el array original.

Diferencia entre sort() y reverse()

Aunque ambos métodos modifican el orden de los elementos, realizan operaciones diferentes.

Método Operación
sort() Ordena los elementos siguiendo un criterio.
reverse() Invierte el orden actual de los elementos.

Por ejemplo:

JavaScript 
const numeros = [
  8,
  2,
  5,
  1
];

Si utilizamos:

JavaScript 
numeros.reverse();

obtendremos:

Console 
[1, 5, 2, 8]

No hemos ordenado los números. Simplemente hemos invertido sus posiciones.

En cambio:

JavaScript 
numeros.sort((a, b) => {
  return a - b;
});

produce:

Console 
[1, 2, 5, 8]

porque en este caso sí estamos realizando una ordenación numérica.

Combinar sort() y reverse()

Los métodos también pueden utilizarse de forma sucesiva.

Por ejemplo, podemos ordenar alfabéticamente un array y después invertir ese orden:

JavaScript 
const lenguajes = [
  "PHP",
  "CSS",
  "JavaScript",
  "HTML"
];

lenguajes.sort();
lenguajes.reverse();

console.log(lenguajes);

Console mostrará:

Console 
["PHP", "JavaScript", "HTML", "CSS"]

Primero sort() establece el orden y después reverse() lo invierte.

💡 Consejo

Cuando trabajamos con números es más claro indicar directamente el criterio de ordenación con b - a para ordenar de mayor a menor, en lugar de ordenarlos primero de menor a mayor y aplicar después reverse().

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación web registra los tiempos de respuesta de varias peticiones al servidor. Queremos mostrar esos tiempos desde la petición más rápida hasta la más lenta.

JavaScript 
const tiempos = [
  1200,
  320,
  1500,
  450,
  580
];

tiempos.sort((a, b) => {
  return a - b;
});

console.log(tiempos);

Console mostrará:

Console 
[320, 450, 580, 1200, 1500]

Si queremos mostrar primero las peticiones más lentas:

JavaScript 
tiempos.sort((a, b) => {
  return b - a;
});

console.log(tiempos);

Console mostrará:

Console 
[1500, 1200, 580, 450, 320]

En este ejemplo:

  • a - b permite ordenar los tiempos de menor a mayor.
  • b - a permite ordenarlos de mayor a menor.
  • sort() modifica directamente el array tiempos.

Errores frecuentes al ordenar e invertir arrays

1. Utilizar sort() directamente para ordenar números

Este es uno de los errores más habituales.

JavaScript 
const numeros = [
  2,
  10,
  5,
  30
];

numeros.sort();

El resultado no será una ordenación numérica correcta.

Para ordenar de menor a mayor utilizaremos:

JavaScript 
numeros.sort((a, b) => {
  return a - b;
});

2. Pensar que sort() genera un nuevo array

sort() modifica el array original.

Si ordenamos numeros, el contenido de numeros cambia.

3. Pensar que reverse() ordena los elementos

reverse() únicamente invierte el orden actual.

No comprueba si los elementos son mayores, menores o si están ordenados alfabéticamente.

4. Confundir a - b con b - a

Debemos recordar:

Recuerda 
a - b → menor a mayor
b - a → mayor a menor

5. Olvidar que reverse() modifica el array original

Después de ejecutar:

JavaScript 
array.reverse();

el orden de los elementos almacenados en array habrá cambiado.

📌 Recuerda

sort() ordena y reverse() invierte. Cuando trabajamos con números, debemos indicar el criterio de ordenación. Además, ambos métodos modifican el array original.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const numeros = [
  15,
  3,
  20,
  8
];

numeros.sort((a, b) => {
  return a - b;
});

console.log(numeros);

numeros.reverse();

console.log(numeros);

Antes de ejecutarlo, responde:

  • ¿Qué array obtendremos después de utilizar sort()?
  • ¿Qué tipo de ordenación realiza a - b?
  • ¿Qué ocurrirá después de ejecutar reverse()?
  • ¿Se modifica el array original?
  • ¿Qué diferencia existe entre sort() y reverse()?
Ver solución

Después de sort() tendremos [3, 8, 15, 20], porque a - b realiza una ordenación numérica de menor a mayor.

Después de reverse() tendremos [20, 15, 8, 3].

El mismo array numeros se modifica en ambas operaciones.

sort() ordena los elementos siguiendo un criterio, mientras que reverse() únicamente invierte el orden actual.

Console mostrará:

Console 
[3, 8, 15, 20]
[20, 15, 8, 3]
