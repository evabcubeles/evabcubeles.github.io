4.1 Introducción a los arrays

Hasta ahora hemos utilizado variables para almacenar valores individuales. Por ejemplo, podemos guardar el nombre de un alumno, su edad o una calificación utilizando una variable para cada dato.

JavaScript 
const alumno1 = "Ana";
const alumno2 = "Luis";
const alumno3 = "Marta";
const alumno4 = "Pablo";

Esta solución puede funcionar cuando tenemos pocos datos, pero se vuelve poco práctica cuando necesitamos almacenar decenas o cientos de valores relacionados entre sí.

Para resolver este problema JavaScript dispone de los arrays, que permiten almacenar varios valores dentro de una misma estructura.

📌 Importante

Un array permite agrupar varios valores relacionados dentro de una única variable. Cada valor ocupa una posición concreta dentro del array y puede recuperarse utilizando su índice.

Qué es un array

Un array es una estructura de datos que permite almacenar varios valores dentro de una misma variable.

En JavaScript los arrays se representan normalmente mediante corchetes [ ]. Los distintos elementos se escriben separados mediante comas.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta", "Pablo"];

En este ejemplo la variable alumnos contiene cuatro valores. Cada uno de ellos recibe el nombre de elemento del array.

Ana Elemento
Luis Elemento
Marta Elemento
Pablo Elemento

De esta forma podemos manejar un conjunto de datos relacionados sin tener que crear una variable diferente para cada uno.

💻 Ejemplo DAW

En una aplicación web podríamos utilizar arrays para almacenar nombres de usuarios, productos de una tienda, calificaciones, categorías, mensajes o cualquier otro conjunto de datos que necesitemos procesar.

Para qué necesitamos arrays

Imagina que necesitamos almacenar las calificaciones de cinco alumnos. Sin utilizar arrays podríamos escribir:

JavaScript 
const nota1 = 7;
const nota2 = 5;
const nota3 = 9;
const nota4 = 6;
const nota5 = 8;

Aunque el código es válido, estamos creando cinco variables diferentes para representar datos que pertenecen al mismo conjunto.

Con un array podemos agrupar todas las calificaciones:

JavaScript 
const notas = [7, 5, 9, 6, 8];

Ahora las cinco notas forman parte de una única estructura llamada notas.

Sin array Con array
Necesitamos varias variables: nota1, nota2, nota3... Utilizamos una única variable: notas.
Los datos se encuentran separados. Los datos relacionados quedan agrupados.
Resulta más difícil trabajar con grandes cantidades de datos. Podemos trabajar con todos los elementos como un conjunto.
📌 Importante

Los arrays son especialmente útiles cuando necesitamos trabajar con colecciones de datos relacionados. Más adelante aprenderemos a recorrer todos sus elementos mediante bucles y a realizar operaciones sobre ellos.

Crear un array

La forma más habitual de crear un array en JavaScript es utilizar corchetes [ ].

Podemos crear inicialmente un array vacío:

JavaScript 
const alumnos = [];

En este momento alumnos es un array, pero todavía no contiene ningún elemento.

También podemos crear directamente un array que ya contenga datos:

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

Los elementos se escriben dentro de los corchetes y se separan mediante comas.

⚠️ Atención

No confundas los corchetes [ ] utilizados para crear arrays con las llaves { } que hemos utilizado para delimitar bloques de código. Son símbolos diferentes y cumplen funciones distintas.

Inicializar un array

Inicializar un array significa crear el array asignándole desde el principio los valores que va a contener.

Por ejemplo:

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript"];

El array lenguajes queda inicializado con tres elementos.

También podemos crear arrays de números:

JavaScript 
const edades = [18, 21, 25, 30];

O arrays de valores booleanos:

JavaScript 
const disponibles = [true, false, true, true];
💻 Ejemplo DAW

Una tienda online podría almacenar inicialmente las categorías disponibles mediante const categorias = ["Portátiles", "Monitores", "Teclados"];. Todas las categorías quedan agrupadas dentro del mismo array.

Elementos e índices

Cada elemento de un array ocupa una posición concreta. Para identificar esas posiciones JavaScript utiliza números denominados índices.

Existe una regla fundamental que debemos recordar: los índices de los arrays comienzan en 0.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta", "Pablo"];
Índice Elemento Posición habitual
0 Ana Primer elemento
1 Luis Segundo elemento
2 Marta Tercer elemento
3 Pablo Cuarto elemento
0 Ana
1 Luis
2 Marta
3 Pablo
📌 Importante

El primer elemento de un array tiene índice 0, no índice 1. Por tanto, si un array contiene cuatro elementos, sus índices serán 0, 1, 2 y 3.

⚠️ Atención

No debemos confundir el número de elementos con el índice del último elemento. En un array de cuatro elementos, el número de elementos es 4, pero el último índice es 3.

Acceder a los elementos

Para acceder a un elemento concreto escribimos el nombre del array seguido de su índice entre corchetes.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta", "Pablo"];

console.log(alumnos[0]);
console.log(alumnos[2]);

Console mostrará:

Console 
Ana
Marta

La expresión alumnos[0] obtiene el primer elemento, mientras que alumnos[2] obtiene el tercer elemento.

Podemos utilizar los elementos de un array igual que utilizaríamos otros valores almacenados en variables:

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript"];

console.log("Estamos estudiando " + lenguajes[2]);

El resultado será:

Console 
Estamos estudiando JavaScript

La propiedad length

Los arrays disponen de la propiedad length, que indica cuántos elementos contiene el array.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta", "Pablo"];

console.log(alumnos.length);

El resultado será:

Console 
4

El array contiene cuatro elementos y, por tanto, alumnos.length devuelve 4.

Como los índices comienzan en 0, el índice del último elemento puede obtenerse restando 1 a length.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta", "Pablo"];

console.log(alumnos.length);
console.log(alumnos.length - 1);

Console mostrará:

Console 
4
3
📌 Importante

length indica el número de elementos del array. Como los índices empiezan en 0, en un array no vacío el índice del último elemento es array.length - 1.

💻 Ejemplo DAW

Si una aplicación almacena productos en un array, productos.length permite conocer cuántos productos contiene actualmente esa colección. Esta información será muy útil cuando posteriormente recorramos arrays mediante bucles.

Arrays con distintos tipos de datos

JavaScript permite almacenar en un mismo array valores de distintos tipos.

JavaScript 
const datos = ["Ana", 20, true, 8.5];

Este array contiene:

  • Una cadena: "Ana".
  • Un número entero: 20.
  • Un valor booleano: true.
  • Un número decimal: 8.5.

Técnicamente esta combinación es válida en JavaScript. Sin embargo, que sea posible no significa que siempre sea la mejor forma de organizar nuestros datos.

⚠️ Atención

Aunque JavaScript permite mezclar tipos de datos dentro de un array, normalmente resulta más claro utilizar arrays cuyos elementos representen información del mismo tipo o tengan una finalidad común. Por ejemplo, un array de nombres o un array de calificaciones.

JavaScript 
const nombres = ["Ana", "Luis", "Marta"];
const notas = [7, 5, 9, 8];
const disponibles = [true, false, true];

En estos ejemplos cada array tiene una finalidad claramente definida, lo que facilita la lectura y el mantenimiento del programa.

Visualización en Console

Durante el aprendizaje de los arrays utilizaremos frecuentemente las herramientas de desarrollo del navegador y, especialmente, Console.

Podemos mostrar un array completo utilizando console.log():

JavaScript 
const tecnologias = ["HTML", "CSS", "JavaScript"];

console.log(tecnologias);

El navegador mostrará el contenido del array en Console. La forma exacta de representación puede variar ligeramente entre navegadores, pero podremos inspeccionar sus elementos y sus índices.

También podemos consultar elementos concretos y el número total de elementos:

JavaScript 
const tecnologias = ["HTML", "CSS", "JavaScript"];

console.log(tecnologias);
console.log(tecnologias[0]);
console.log(tecnologias[2]);
console.log(tecnologias.length);

De esta forma podemos comprobar rápidamente el contenido de un array mientras desarrollamos y depuramos nuestros programas.

📌 Importante

Console será una herramienta especialmente útil durante esta unidad. Nos permitirá observar el contenido de los arrays, comprobar sus elementos, revisar los índices y detectar errores mientras desarrollamos nuestros programas.

🧠 Comprueba lo aprendido

Observa el siguiente array sin ejecutar el código:

JavaScript 
const modulos = ["DWEC", "DIW", "SASP", "DAW"];

Responde a las siguientes preguntas:

  • ¿Cuántos elementos contiene el array?
  • ¿Cuál es el índice de "DWEC"?
  • ¿Cuál es el índice de "SASP"?
  • ¿Qué valor obtendríamos con modulos[1]?
  • ¿Qué valor devuelve modulos.length?
  • ¿Cuál es el índice del último elemento?
Ver solución

El array contiene 4 elementos.

El índice de "DWEC" es 0.

El índice de "SASP" es 2.

modulos[1] devuelve "DIW".

modulos.length devuelve 4.

El índice del último elemento es 3, es decir, modulos.length - 1.

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y entra en Console. Crea el siguiente array:

Console 
const navegadores = ["Chrome", "Firefox", "Edge", "Safari"];

Después prueba una a una las siguientes expresiones:

Console 
navegadores
navegadores[0]
navegadores[1]
navegadores[3]
navegadores.length
navegadores[navegadores.length - 1]

Antes de ejecutar cada expresión, intenta predecir qué resultado obtendrás. Después comprueba el resultado en Console.

El objetivo es acostumbrarnos a relacionar el índice con la posición del elemento y a distinguir entre el número de elementos del array y el índice de su último elemento.
