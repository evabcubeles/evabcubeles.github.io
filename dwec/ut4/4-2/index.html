4.2 Acceso y modificación de elementos

En el apartado anterior hemos aprendido que cada elemento de un array ocupa una posición concreta identificada mediante un índice y que estos índices comienzan en 0.

Conocer la posición de los elementos nos permite realizar dos operaciones fundamentales: consultar el valor almacenado en una posición y modificarlo.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta", "Pablo"];

console.log(alumnos[1]);

alumnos[1] = "Carlos";

console.log(alumnos[1]);

En este ejemplo accedemos primero al elemento situado en el índice 1, cuyo valor es "Luis". Después sustituimos ese valor por "Carlos".

Console mostrará:

Console 
Luis
Carlos
📌 Importante

Para acceder o modificar un elemento utilizamos el nombre del array seguido del índice entre corchetes: array[indice].

Acceder mediante el índice

Para consultar un elemento concreto de un array debemos indicar la posición que ocupa mediante su índice.

La sintaxis general es:

JavaScript 
nombreArray[indice]

Por ejemplo:

JavaScript 
const tecnologias = ["HTML", "CSS", "JavaScript", "PHP"];

console.log(tecnologias[0]);
console.log(tecnologias[1]);
console.log(tecnologias[3]);

Console mostrará:

Console 
HTML
CSS
PHP
Expresión Índice Valor obtenido
tecnologias[0] 0 HTML
tecnologias[1] 1 CSS
tecnologias[2] 2 JavaScript
tecnologias[3] 3 PHP
⚠️ Atención

El primer elemento se encuentra en el índice 0. Por tanto, tecnologias[1] no obtiene el primer elemento, sino el segundo.

Modificar un elemento

Además de consultar los elementos de un array, podemos cambiar el valor almacenado en una posición concreta.

Para hacerlo utilizamos el índice del elemento y el operador de asignación =.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

alumnos[1] = "Pablo";

console.log(alumnos);

El elemento situado en el índice 1, que inicialmente contenía "Luis", pasa a contener "Pablo".

El array queda así:

Console 
["Ana", "Pablo", "Marta"]

Podemos modificar cualquier posición existente del array:

JavaScript 
const notas = [5, 7, 6, 8];

notas[0] = 7;
notas[2] = 9;

console.log(notas);

El resultado será:

Console 
[7, 7, 9, 8]
💻 Ejemplo DAW

Imagina que una aplicación almacena en un array el stock disponible de varios productos. Si cambia la cantidad de uno de ellos, podemos actualizar directamente la posición correspondiente. Por ejemplo, stock[2] = 15; cambia el valor almacenado en el índice 2.

Arrays declarados con const

En los ejemplos anteriores hemos declarado los arrays utilizando const y, sin embargo, hemos podido modificar sus elementos. Esto puede generar una duda: si una constante no puede cambiar, ¿por qué podemos modificar un array declarado con const?

Cuando declaramos un array con const, no podemos asignar un array diferente a esa misma variable, pero sí podemos modificar los elementos que contiene.

Por ejemplo, esto es válido:

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

alumnos[0] = "Lucía";

console.log(alumnos);

Console mostrará:

Console 
["Lucía", "Luis", "Marta"]

Sin embargo, no podemos sustituir el array completo por otro:

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

alumnos = ["Pablo", "Lucía"];

Esta segunda operación produce un error porque intenta asignar un nuevo valor a la variable alumnos.

📌 Importante

Declarar un array con const no impide modificar sus elementos. Lo que impide es volver a asignar a esa variable un array diferente. Por esta razón utilizaremos habitualmente const para declarar arrays.

Añadir elementos mediante índices

Los índices también pueden utilizarse para añadir un nuevo elemento al final de un array.

Observa el siguiente ejemplo:

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

alumnos[3] = "Pablo";

console.log(alumnos);

Inicialmente el array tiene tres elementos, cuyos índices son 0, 1 y 2. El índice 3 corresponde a la siguiente posición disponible.

El resultado será:

Console 
["Ana", "Luis", "Marta", "Pablo"]

Sin embargo, escribir directamente el número del índice no es una solución cómoda si desconocemos cuántos elementos contiene el array.

Podemos utilizar length para obtener automáticamente la siguiente posición disponible:

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

alumnos[alumnos.length] = "Pablo";

console.log(alumnos);

Antes de añadir el nuevo elemento, alumnos.length vale 3. Por tanto, la expresión anterior equivale en ese momento a:

JavaScript 
alumnos[3] = "Pablo";
⚠️ Atención

Aunque podemos añadir elementos utilizando directamente los índices, JavaScript proporciona métodos específicos para realizar estas operaciones de una forma más clara. En el apartado 4.3 estudiaremos, entre otros, el método push().

Índices inexistentes

También debemos saber qué ocurre cuando intentamos consultar una posición que no existe dentro de un array.

Observa este ejemplo:

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

console.log(alumnos[5]);

El array tiene tres elementos, por lo que sus índices utilizados son 0, 1 y 2. No existe ningún elemento almacenado en el índice 5.

Console mostrará:

Console 
undefined
📌 Importante

Acceder a un índice que no contiene ningún elemento devuelve undefined. Esto indica que no existe un valor definido en esa posición.

Asignar un valor a un índice alejado

Una situación diferente se produce si asignamos directamente un valor a un índice situado más allá de la siguiente posición disponible.

JavaScript 
const alumnos = ["Ana", "Luis", "Marta"];

alumnos[5] = "Pablo";

console.log(alumnos);
console.log(alumnos.length);

El array tenía elementos en los índices 0, 1 y 2. Al asignar directamente un valor al índice 5, quedan posiciones vacías en los índices 3 y 4.

Además, length pasa a valer 6, porque el índice más alto utilizado es 5.

⚠️ Atención

Debemos evitar crear accidentalmente posiciones vacías utilizando índices alejados del final del array. Normalmente trabajaremos con posiciones consecutivas o utilizaremos los métodos específicos que estudiaremos en los siguientes apartados.

Relación entre índices y length

La propiedad length y los índices están relacionados, pero representan conceptos diferentes.

Observa este array:

JavaScript 
const navegadores = ["Chrome", "Firefox", "Edge", "Safari"];
Concepto Valor
Número de elementos 4
navegadores.length 4
Primer índice 0
Último índice 3
navegadores.length - 1 3

En un array con elementos almacenados de forma consecutiva, si contiene n elementos, sus índices van desde 0 hasta n - 1.

📌 Importante

length indica el número de elementos del array, no el índice del último elemento. En un array no vacío cuyo contenido ocupa posiciones consecutivas, el último índice es array.length - 1.

Acceder al último elemento

No siempre conoceremos de antemano cuántos elementos contiene un array. Por ello, no es recomendable escribir directamente un índice concreto cuando queremos acceder al último elemento.

Por ejemplo:

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript", "PHP"];

console.log(lenguajes[3]);

Este código funciona porque sabemos que el último elemento está en el índice 3. Pero si posteriormente cambia el número de elementos, ese índice podría dejar de corresponder al último elemento.

Podemos obtener la última posición de forma dinámica utilizando length - 1:

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript", "PHP"];

console.log(lenguajes[lenguajes.length - 1]);

El resultado será:

Console 
PHP

La expresión se interpreta paso a paso de la siguiente forma:

Expresión Resultado
lenguajes.length 4
lenguajes.length - 1 3
lenguajes[3] "PHP"
💻 Ejemplo DAW

Si una aplicación va almacenando mensajes dentro de un array, mensajes[mensajes.length - 1] permite consultar el último mensaje sin necesidad de conocer previamente cuántos elementos contiene el array.

Errores frecuentes al trabajar con índices

Cuando comenzamos a trabajar con arrays es habitual cometer algunos errores relacionados con las posiciones y los índices. Veamos los más frecuentes.

Confundir la posición con el índice

El primer elemento tiene índice 0, no índice 1.

JavaScript 
const colores = ["Rojo", "Verde", "Azul"];

console.log(colores[0]);

El resultado es "Rojo", porque el índice 0 corresponde al primer elemento.

Utilizar length como índice del último elemento

Si un array contiene tres elementos, length vale 3, pero el último índice es 2.

JavaScript 
const colores = ["Rojo", "Verde", "Azul"];

console.log(colores.length);
console.log(colores[colores.length]);
console.log(colores[colores.length - 1]);

Console mostrará:

Console 
3
undefined
Azul

Acceder a una posición que no contiene un elemento

JavaScript 
const colores = ["Rojo", "Verde", "Azul"];

console.log(colores[10]);

El resultado será undefined, ya que no existe ningún elemento definido en el índice 10.

Crear posiciones vacías accidentalmente

También debemos evitar asignar valores a índices demasiado alejados de la siguiente posición disponible:

JavaScript 
const colores = ["Rojo", "Verde", "Azul"];

colores[6] = "Negro";

console.log(colores.length);

El índice 6 pasa a contener "Negro", pero quedan posiciones vacías entre el último elemento original y el nuevo. Además, length pasa a valer 7.

⚠️ Atención

Muchos errores al trabajar con arrays se producen por utilizar un índice incorrecto. Antes de acceder o modificar una posición, comprueba qué índice necesitas y recuerda siempre que los índices comienzan en 0.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const modulos = ["DWEC", "DIW", "SASP"];

modulos[1] = "DAW";
modulos[modulos.length] = "IPE";

Responde a las siguientes preguntas:

  • ¿Qué valor tenía inicialmente modulos[1]?
  • ¿Qué valor contiene después de la asignación?
  • ¿Cuánto vale inicialmente modulos.length?
  • ¿En qué índice se almacenará "IPE"?
  • ¿Cuántos elementos tendrá finalmente el array?
  • ¿Cuál será el contenido final de modulos?
Ver solución

Inicialmente modulos[1] contiene "DIW".

Después de ejecutar modulos[1] = "DAW";, el índice 1 contiene "DAW".

Inicialmente modulos.length vale 3.

Por tanto, modulos[modulos.length] = "IPE"; equivale en ese momento a modulos[3] = "IPE";.

"IPE" se almacena en el índice 3.

El array tendrá finalmente 4 elementos.

Su contenido final será ["DWEC", "DAW", "SASP", "IPE"].

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y crea el siguiente array:

Console 
const tecnologias = ["HTML", "CSS", "JavaScript"];

Después ejecuta estas expresiones una a una:

Console 
tecnologias[0]
tecnologias[2]
tecnologias[1] = "Bootstrap"
tecnologias
tecnologias.length
tecnologias[tecnologias.length - 1]
tecnologias[tecnologias.length] = "PHP"
tecnologias
tecnologias.length
tecnologias[10]

Antes de ejecutar cada expresión, intenta predecir el resultado. Después compruébalo en Console.

Presta especial atención a cómo cambia el contenido del array cuando modificamos una posición existente, cuando añadimos un elemento en la posición indicada por length y cuando intentamos consultar una posición que no contiene ningún elemento.
