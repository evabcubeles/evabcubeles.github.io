📝 Actividades de la UT4

Para finalizar la UT4 vas a aplicar de forma conjunta los principales conceptos trabajados sobre arrays y estructuras de datos en JavaScript.

Las actividades se organizan en tres bloques: actividades prácticas, un reto final y una autoevaluación.

📌 Importante

Antes de escribir código, analiza qué datos tienes, qué resultado necesitas obtener y qué operación resulta más adecuada. No se trata de utilizar el mayor número posible de métodos, sino de elegir una solución clara, correcta y adecuada.

💻 Actividades prácticas

Actividad 1 — Crear, consultar y modificar arrays

Observa el siguiente array:

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript", "PHP"];
  1. Muestra el array completo en Console.
  2. Muestra el primer elemento.
  3. Muestra el último elemento utilizando length.
  4. Muestra cuántos elementos contiene el array.
  5. Cambia "PHP" por "Python".
  6. Intenta consultar una posición que no exista y explica por qué aparece undefined.
  7. Explica por qué podemos modificar los elementos aunque el array esté declarado con const.

Actividad 2 — Añadir y eliminar elementos

Partimos del siguiente array:

JavaScript 
const modulos = ["DWEC", "DIW", "SASP"];
  1. Añade "DAW" al final.
  2. Añade "EIE" al principio.
  3. Elimina el último elemento y guárdalo en una variable.
  4. Elimina el primer elemento y guárdalo en otra variable.
  5. Muestra el array después de cada operación.
  6. Indica qué devuelve cada uno de los métodos push(), pop(), unshift() y shift().
📌 Recuerda

push(), pop(), unshift() y shift() modifican el array original.

Actividad 3 — Modificar un array con splice()

Observa el siguiente array:

JavaScript 
const tecnologias = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP",
  "MySQL"
];
  1. Elimina "PHP".
  2. Inserta "React" entre "JavaScript" y "MySQL".
  3. Sustituye "CSS" por "Sass".
  4. Guarda en una variable los elementos eliminados en una de las operaciones.
  5. Muestra el array después de cada modificación.
  6. Explica qué posibilidades ofrece splice() frente a métodos como push() o pop().

Actividad 4 — Buscar información en un array

Partimos de los siguientes tiempos de respuesta:

JavaScript 
const tiempos = [
  320,
  450,
  1200,
  580,
  1500,
  700
];

Utiliza el método más adecuado para:

  1. Comprobar si existe exactamente el valor 1200.
  2. Obtener la posición de 580.
  3. Encontrar el primer tiempo superior a 1000.
  4. Obtener la posición del primer tiempo superior a 1000.
  5. Buscar un valor que no exista y observar qué devuelve cada método utilizado.
  6. Explica cuándo utilizarías includes(), indexOf(), find() y findIndex().

Actividad 5 — Recorrer arrays con for

Utiliza el siguiente array de calificaciones:

JavaScript 
const notas = [
  7,
  4,
  9,
  5,
  3,
  8
];

Utilizando exclusivamente un bucle for tradicional:

  1. Muestra todas las notas.
  2. Muestra cada índice junto a su nota.
  3. Calcula la suma de las notas.
  4. Calcula la media.
  5. Cuenta cuántas notas están aprobadas.
  6. Cuenta cuántas están suspensas.
  7. Recorre finalmente el array en orden inverso.

Actividad 6 — for...of y forEach()

Utiliza de nuevo el array de notas de la actividad anterior.

  1. Recórrelo mediante for...of.
  2. Calcula la suma mediante for...of.
  3. Recórrelo mediante forEach().
  4. Muestra con forEach() cada elemento y su índice.
  5. Explica cuál de las alternativas for, for...of o forEach() elegirías si necesitas trabajar con el índice.
  6. Indica cuál elegirías si solo necesitas el valor.
  7. Indica cuál permite interrumpir el recorrido mediante break.
⚠️ Atención

No elijas una forma de recorrer arrays solo porque sea más corta. Piensa primero qué información necesitas durante el recorrido.

Actividad 7 — Transformar y filtrar datos

Partimos del siguiente array:

JavaScript 
const precios = [
  25,
  80,
  120,
  40,
  200
];
  1. Obtén mediante filter() únicamente los precios iguales o superiores a 100.
  2. Crea mediante map() un nuevo array aplicando un IVA del 21 % a todos los precios.
  3. Filtra primero los precios de al menos 100 y después aplícales el IVA.
  4. Resuelve el apartado anterior encadenando filter() y map().
  5. Muestra el array original al final.
  6. Explica si map() y filter() han modificado ese array.

Actividad 8 — Ordenar e invertir arrays

Utiliza los siguientes tiempos:

JavaScript 
const tiempos = [
  450,
  1200,
  320,
  1500,
  580,
  2100
];
  1. Ordena los tiempos de menor a mayor.
  2. Ordénalos de mayor a menor.
  3. Invierte el orden actual mediante reverse().
  4. Explica la diferencia entre ordenar e invertir.
  5. Comprueba qué ocurre con el array sobre el que aplicas sort() y reverse().
  6. Explica por qué para ordenar números utilizamos una función de comparación como (a, b) => a - b.

Actividad 9 — Arrays multidimensionales

Observa la siguiente estructura:

JavaScript 
const notas = [
  [7, 8, 6],
  [5, 9, 7],
  [8, 6, 10]
];
  1. Muestra el elemento de la primera fila y segunda columna.
  2. Modifica la última nota de la segunda fila.
  3. Muestra cuántas filas existen.
  4. Muestra cuántos elementos contiene la primera fila.
  5. Recorre toda la estructura utilizando dos bucles for.
  6. Repite el recorrido mediante dos bucles for...of.
  7. Calcula la suma de todas las notas.
  8. Calcula la media de todas las notas.

Actividad 10 — Resolver un problema completo con arrays

Una aplicación web ha registrado los siguientes tiempos de respuesta:

JavaScript 
const tiempos = [
  320,
  1500,
  450,
  1200,
  580,
  2100,
  700
];
  1. Muestra el número total de peticiones.
  2. Obtén únicamente las que superan 1000 ms.
  3. Ordena esas peticiones de mayor a menor.
  4. Convierte esos tiempos a segundos.
  5. Muestra todos los resultados.
  6. Comprueba que el array original conserva sus valores.
  7. Explica qué operación has utilizado en cada paso y por qué.
📌 Antes de programar

Divide el problema en pasos. Comprueba cada resultado intermedio antes de continuar con la siguiente operación.

🧩 Reto final

En este reto vas a combinar los principales contenidos de la UT4 para resolver un problema relacionado con el desarrollo de aplicaciones web.

Analizador de rendimiento de una aplicación web

Formas parte del equipo de desarrollo de una aplicación web. Durante una prueba de rendimiento se han registrado los tiempos de respuesta, en milisegundos, de distintas peticiones.

JavaScript · Datos iniciales 
const tiempos = [
  320,
  850,
  1200,
  450,
  2100,
  680,
  1500,
  390,
  1100,
  270
];

Tu misión

  1. Muestra el número total de peticiones.
  2. Calcula el tiempo total acumulado.
  3. Calcula el tiempo medio de respuesta.
  4. Cuenta las peticiones rápidas, considerando rápidas las que tardan 500 ms o menos.
  5. Cuenta las peticiones normales, con tiempos superiores a 500 ms y de hasta 1000 ms.
  6. Cuenta las peticiones lentas, con tiempos superiores a 1000 ms.
  7. Crea un nuevo array que contenga únicamente las peticiones lentas.
  8. Ordena las peticiones lentas de mayor a menor.
  9. Crea un nuevo array con esos tiempos lentos convertidos a segundos.
  10. Obtén el mayor tiempo registrado y su posición dentro del array original.
  11. Comprueba si existe alguna petición exactamente de 1500 ms.
  12. Muestra finalmente el array original y comprueba qué operaciones lo han modificado y cuáles no.
⚠️ Requisito

Utiliza de forma razonada varias de las herramientas estudiadas: length, acceso mediante índices, for o for...of, includes(), find() o findIndex(), filter(), map() y sort(). No es obligatorio utilizar todas si no son necesarias.

📦 Entrega del reto

Entrega el código JavaScript y una explicación breve en la que indiques qué operaciones has utilizado, por qué has elegido cada una, qué arrays nuevos se crean, qué operaciones modifican un array y cómo has comprobado que los resultados obtenidos son correctos.
