4.11 Arrays multidimensionales

Hasta ahora hemos trabajado principalmente con arrays que almacenan una única secuencia de elementos. Cada valor se encuentra en una posición concreta y podemos acceder a él mediante su índice.

Sin embargo, en algunas aplicaciones necesitamos representar datos que tienen una estructura más compleja. Por ejemplo, podemos querer almacenar las notas de varios alumnos, los tiempos de respuesta registrados durante varios días o los valores de una tabla.

Para representar este tipo de información podemos utilizar arrays multidimensionales.

📌 Importante

En JavaScript, un array multidimensional es, en realidad, un array que contiene otros arrays. El caso más habitual es el array bidimensional, que podemos imaginar como una estructura formada por filas y columnas.

Crear un array bidimensional

Un array bidimensional puede crearse incluyendo varios arrays dentro de un array principal.

Por ejemplo:

JavaScript 
const notas = [
  [7, 8, 6],
  [5, 9, 7],
  [8, 6, 10]
];

En este ejemplo, el array notas contiene tres elementos. Cada uno de esos elementos es, a su vez, otro array.

Podemos imaginar su contenido de la siguiente forma:

Columna 0 Columna 1 Columna 2
Fila 0 7 8 6
Fila 1 5 9 7
Fila 2 8 6 10

Esta representación se parece a una tabla, aunque debemos recordar que internamente seguimos trabajando con arrays.

📌 Recuerda

Un array bidimensional puede entenderse como un array principal cuyas posiciones contienen otros arrays.

Filas, columnas e índices

Igual que ocurre con cualquier array, los índices comienzan en 0.

En un array bidimensional utilizaremos normalmente dos índices:

  • El primer índice indica qué array interior queremos seleccionar. Podemos interpretarlo como la fila.
  • El segundo índice indica qué elemento queremos seleccionar dentro de esa fila. Podemos interpretarlo como la columna.
JavaScript 
notas[fila][columna]

Por ejemplo:

JavaScript 
notas[1][2]

Primero seleccionamos la fila situada en el índice 1:

JavaScript 
[5, 9, 7]

Después seleccionamos el elemento situado en el índice 2 de ese array, cuyo valor es 7.

⚠️ Atención

No debemos olvidar que los índices comienzan en 0. Por tanto, la fila 1 es realmente la segunda fila y la columna 2 es la tercera columna.

Acceder a los elementos

Para acceder a un elemento concreto indicamos primero el índice del array interior y después el índice del elemento que queremos obtener.

JavaScript 
const notas = [
  [7, 8, 6],
  [5, 9, 7],
  [8, 6, 10]
];

console.log(notas[0][0]);
console.log(notas[1][2]);
console.log(notas[2][1]);

Console mostrará:

Console 
7
7
6

También podemos acceder a una fila completa utilizando únicamente el primer índice:

JavaScript 
console.log(notas[1]);

Console mostrará:

Console 
[5, 9, 7]
📌 Recuerda

notas[1] obtiene un array completo, mientras que notas[1][2] obtiene un elemento concreto de ese array.

Modificar elementos

Los elementos de un array bidimensional pueden modificarse de la misma forma que los elementos de cualquier otro array.

Solo tenemos que indicar la posición que queremos modificar.

JavaScript 
const notas = [
  [7, 8, 6],
  [5, 9, 7],
  [8, 6, 10]
];

notas[1][2] = 10;

console.log(notas[1]);

Console mostrará:

Console 
[5, 9, 10]

Hemos modificado el elemento situado en la fila 1 y la columna 2.

⚠️ Atención

Aunque el array se haya declarado utilizando const, podemos modificar sus elementos. Lo que no podemos hacer es asignar directamente otro array diferente a la constante.

Recorrer un array bidimensional

En muchos problemas no conocemos de antemano qué posición concreta necesitamos consultar, sino que queremos procesar todos los elementos del array.

Como un array bidimensional contiene arrays dentro de otro array, necesitamos realizar dos recorridos:

  • Un recorrido para avanzar por las filas.
  • Otro recorrido para avanzar por los elementos de cada fila.

Para ello podemos utilizar bucles anidados, un concepto que ya hemos estudiado en la UT3.

📌 Importante

El bucle exterior recorre las filas y, para cada fila, el bucle interior recorre sus elementos.

Recorrer un array bidimensional con for

Podemos utilizar dos bucles for anidados para recorrer todas las posiciones de un array bidimensional.

JavaScript 
const notas = [
  [7, 8, 6],
  [5, 9, 7],
  [8, 6, 10]
];

for (let fila = 0; fila < notas.length; fila++) {

  for (
    let columna = 0;
    columna < notas[fila].length;
    columna++
  ) {

    console.log(notas[fila][columna]);

  }

}

Console mostrará:

Console 
7
8
6
5
9
7
8
6
10

El funcionamiento es el siguiente:

  • El primer for controla el índice fila.
  • notas[fila] representa el array correspondiente a la fila actual.
  • El segundo for recorre los elementos de esa fila.
  • notas[fila][columna] permite acceder a cada valor.

Comprender el recorrido paso a paso

Cuando fila vale 0, el segundo bucle recorre:

JavaScript 
[7, 8, 6]

Cuando fila vale 1, recorre:

JavaScript 
[5, 9, 7]

Y cuando fila vale 2, recorre:

JavaScript 
[8, 6, 10]

De esta forma terminamos visitando todos los elementos del array.

Recorrer un array bidimensional con for...of

Si no necesitamos conocer los índices, también podemos realizar el recorrido utilizando dos bucles for...of.

JavaScript 
const notas = [
  [7, 8, 6],
  [5, 9, 7],
  [8, 6, 10]
];

for (const fila of notas) {

  for (const nota of fila) {

    console.log(nota);

  }

}

En este caso:

  • fila representa directamente cada array interior.
  • nota representa directamente cada elemento de la fila.

El resultado será exactamente el mismo:

Console 
7
8
6
5
9
7
8
6
10
Recorrido Característica
for anidado Permite trabajar directamente con los índices de filas y columnas.
for...of anidado Permite trabajar directamente con las filas y sus valores.
📌 Recuerda

Utilizaremos for cuando necesitemos controlar los índices y for...of cuando únicamente necesitemos trabajar con los valores.

La propiedad length en arrays multidimensionales

La propiedad length continúa funcionando exactamente igual que en cualquier otro array.

Si la aplicamos al array principal, obtenemos el número de arrays interiores:

JavaScript 
const notas = [
  [7, 8, 6],
  [5, 9, 7],
  [8, 6, 10]
];

console.log(notas.length);

Console mostrará:

Console 
3

Si aplicamos length a una fila concreta, obtenemos el número de elementos que contiene esa fila:

JavaScript 
console.log(notas[0].length);
console.log(notas[1].length);

Console mostrará:

Console 
3
3

Esta es precisamente la razón por la que, al utilizar bucles for anidados, escribimos:

JavaScript 
fila < notas.length

para controlar el número de filas, y:

JavaScript 
columna < notas[fila].length

para controlar el número de elementos de la fila actual.

⚠️ Atención

No debemos suponer que todas las filas tienen necesariamente el mismo número de elementos. Utilizar notas[fila].length permite adaptar el recorrido al tamaño real de cada fila.

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación web registra los tiempos de respuesta de tres peticiones al servidor durante tres días diferentes. Queremos recorrer todos los datos y detectar las peticiones que han tardado más de 1000 milisegundos.

JavaScript 
const tiempos = [
  [320, 450, 580],
  [410, 1200, 530],
  [290, 380, 1500]
];

let peticionesLentas = 0;

for (const fila of tiempos) {

  for (const tiempo of fila) {

    if (tiempo > 1000) {
      peticionesLentas++;
    }

  }

}

console.log(peticionesLentas);

Console mostrará:

Console 
2

En este ejemplo:

  • Cada array interior contiene los tiempos registrados durante un día.
  • El primer for...of recorre cada fila.
  • El segundo for...of recorre los tiempos de esa fila.
  • La condición comprueba si cada tiempo supera los 1000 milisegundos.
  • Existen dos peticiones lentas: 1200 y 1500 milisegundos.

Errores frecuentes al trabajar con arrays multidimensionales

1. Olvidar que los índices comienzan en 0

Igual que ocurre con los arrays simples, la primera fila y la primera columna utilizan el índice 0.

2. Utilizar un único índice cuando queremos un valor concreto

Si escribimos:

JavaScript 
notas[1]

obtenemos una fila completa.

Si queremos acceder a un valor concreto necesitamos dos índices:

JavaScript 
notas[1][2]

3. Confundir fila y columna

En una expresión como:

JavaScript 
notas[fila][columna]

el primer índice selecciona el array interior y el segundo selecciona un elemento de ese array.

4. Utilizar notas.length para controlar también las columnas

El número de elementos de cada fila debe consultarse utilizando:

JavaScript 
notas[fila].length

y no utilizando siempre notas.length.

5. Olvidar el segundo recorrido

Si recorremos únicamente el array principal, obtendremos cada fila completa, pero no cada uno de sus valores.

JavaScript 
for (const fila of notas) {
  console.log(fila);
}

Para acceder a todos los valores necesitaremos otro recorrido dentro del primero.

📌 Recuerda

En un array bidimensional trabajamos normalmente con dos niveles: primero seleccionamos una fila y después un elemento de esa fila. Para recorrer todos sus valores necesitaremos normalmente dos bucles anidados.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const numeros = [
  [3, 8, 5],
  [10, 4, 7],
  [6, 12, 2]
];

console.log(numeros[0][1]);
console.log(numeros[2][0]);

numeros[1][2] = 9;

console.log(numeros[1]);

Antes de ejecutarlo, responde:

  • ¿Qué valor mostrará numeros[0][1]?
  • ¿Qué valor mostrará numeros[2][0]?
  • ¿Qué elemento se modifica con numeros[1][2] = 9?
  • ¿Qué contendrá finalmente numeros[1]?
  • ¿Cuánto vale numeros.length?
Ver solución

numeros[0][1] vale 8, porque seleccionamos la fila 0 y después el elemento situado en la posición 1.

numeros[2][0] vale 6.

La instrucción numeros[1][2] = 9 modifica el tercer elemento de la segunda fila. El valor 7 se sustituye por 9.

Por tanto, numeros[1] contendrá [10, 4, 9].

numeros.length vale 3, porque el array principal contiene tres arrays interiores.

Console mostrará:

Console 
8
6
[10, 4, 9]

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y prueba las siguientes instrucciones:

JavaScript 
const ventas = [
  [120, 80, 150],
  [200, 90, 110],
  [75, 180, 130]
];

let total = 0;

for (const fila of ventas) {

  for (const venta of fila) {

    total += venta;

  }

}

console.log(total);

Antes de ejecutarlo, intenta predecir:

  • Cuántas filas contiene el array ventas.
  • Cuántos elementos contiene cada fila.
  • Qué valores irá recorriendo la variable venta.
  • Qué valor tendrá finalmente la variable total.

Después ejecuta el código y comprueba el resultado. Prueba también a modificar algún valor del array y observa cómo cambia el total.
