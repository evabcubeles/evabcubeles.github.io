✏️ Resumen de la UT4

En esta unidad hemos aprendido a utilizar arrays para almacenar, organizar y procesar conjuntos de datos en JavaScript.

Hemos estudiado cómo crear arrays, acceder y modificar sus elementos, añadirlos y eliminarlos, buscar información, recorrer sus valores, transformar y filtrar datos, ordenar elementos y trabajar con arrays multidimensionales.

Este resumen reúne las ideas esenciales de los apartados 4.1 a 4.12 para utilizarlo como guía rápida de repaso.

4.1 Introducción a los arrays

Un array es una estructura que permite almacenar varios valores dentro de una misma variable.

Array Colección ordenada de elementos almacenados bajo un mismo nombre.
Índice Posición que ocupa cada elemento. El primer índice es 0.
Acceso Utilizamos corchetes y el índice: array[indice].
length Indica el número de elementos almacenados en el array.
💻 Ejemplo

const lenguajes = ["HTML", "CSS", "JavaScript"];

📌 Recuerda

Los índices comienzan en 0. Por tanto, en un array de tres elementos los índices válidos son 0, 1 y 2.

4.2 Acceso y modificación de elementos

Podemos consultar o modificar un elemento indicando la posición que ocupa dentro del array.

Consultar lenguajes[0] devuelve el primer elemento.
Modificar Podemos asignar un nuevo valor: lenguajes[1] = "Sass";
Último elemento Su posición puede obtenerse mediante array.length - 1.
const Un array declarado con const puede modificar sus elementos aunque no pueda reasignarse la variable completa.
⚠️ Atención

Acceder a una posición que no existe devuelve undefined. Debemos comprobar siempre que el índice utilizado corresponde a una posición válida.

4.3 Añadir y eliminar elementos

JavaScript proporciona métodos específicos para añadir o eliminar elementos en los extremos de un array.

Método Operación Valor devuelto
push() Añade uno o varios elementos al final. Nueva longitud del array.
pop() Elimina el último elemento. Elemento eliminado.
unshift() Añade uno o varios elementos al principio. Nueva longitud del array.
shift() Elimina el primer elemento. Elemento eliminado.
📌 Importante

push(), pop(), unshift() y shift() modifican el array original.

4.4 Modificar arrays con splice()

El método splice() permite realizar modificaciones en cualquier posición del array.

➖ Eliminar

Puede eliminar uno o varios elementos desde una posición.

➕ Insertar

Puede introducir nuevos elementos sin eliminar los existentes.

🔄 Reemplazar

Puede eliminar elementos e insertar otros en su lugar.

💻 Sintaxis básica

array.splice(posicionInicial, cantidadEliminar, elemento1, ...)

📌 Recuerda

splice() modifica el array original y devuelve un nuevo array con los elementos que hayan sido eliminados.

4.5 Buscar elementos en un array

Dependiendo de lo que necesitemos conocer podemos utilizar diferentes métodos de búsqueda.

Método Qué busca Resultado
indexOf() Un valor concreto. Índice o -1.
includes() Si existe un valor concreto. true o false.
find() Primer elemento que cumple una condición. Elemento o undefined.
findIndex() Posición del primer elemento que cumple una condición. Índice o -1.
⚠️ Atención

Cuando utilizamos indexOf() o findIndex(), debemos recordar que -1 significa que no se ha encontrado ningún elemento.

4.6 Recorrer arrays con for

El bucle for permite recorrer un array utilizando sus índices.

Inicio Normalmente comenzamos en el índice 0.
Límite Utilizamos i < array.length.
Índice La variable de control representa la posición del elemento.
Elemento Accedemos mediante array[i].
💻 Estructura habitual

for (let i = 0; i < array.length; i++) { ... }

⚠️ Error frecuente

Utilizar i <= array.length intenta acceder a una posición que no existe. La condición habitual es i < array.length.

4.7 Recorrer arrays con for...of

for...of permite recorrer directamente los valores almacenados en un array.

💻 Estructura básica

for (const elemento of array) { ... }

Acceso directo La variable representa directamente el elemento actual.
Sintaxis sencilla No necesitamos controlar manualmente un índice.
Cuándo utilizarlo Resulta apropiado cuando necesitamos los valores pero no sus índices.
for tradicional Sigue siendo preferible cuando necesitamos controlar posiciones, límites o recorridos inversos.
⚠️ for...of no es for...in

Para recorrer habitualmente los valores de un array utilizamos for...of. No debemos confundirlo con for...in.

4.8 El método forEach()

forEach() ejecuta una acción una vez por cada elemento del array.

Elemento El primer parámetro representa el elemento actual.
Índice Podemos utilizar un segundo parámetro para conocer su posición.
Uso Es útil cuando queremos realizar una acción con todos los elementos.
Resultado No crea automáticamente un nuevo array transformado.
📌 Recuerda

forEach() resulta muy cómodo para recorrer todos los elementos, pero no permite utilizar break o continue como en un bucle tradicional.

4.9 Transformar y filtrar arrays

map() y filter() permiten obtener nuevos arrays a partir de un array existente.

🔄 map()

Transforma cada elemento y genera un nuevo array con el mismo número de elementos.

🔎 filter()

Selecciona únicamente los elementos que cumplen una condición.

🔗 Combinación

Podemos encadenar operaciones para filtrar y después transformar los resultados.

Método Objetivo Nuevo array
forEach() Realizar una acción por elemento. No.
map() Transformar todos los elementos. Sí.
filter() Seleccionar algunos elementos. Sí.
📌 Idea esencial

map() y filter() no modifican por sí mismos el array original. Devuelven un nuevo array que debemos guardar si queremos utilizarlo.

4.10 Ordenar e invertir arrays

Los métodos sort() y reverse() permiten modificar el orden de los elementos.

sort() Ordena los elementos del array.
Orden numérico ascendente Utilizamos sort((a, b) => a - b).
Orden numérico descendente Utilizamos sort((a, b) => b - a).
reverse() Invierte el orden actual de los elementos.
⚠️ Atención

Tanto sort() como reverse() modifican el array original.

📌 Ordenar no es invertir

reverse() no ordena los valores de menor a mayor ni de mayor a menor: únicamente invierte el orden que ya tiene el array.

4.11 Arrays multidimensionales

Un array multidimensional es un array que contiene otros arrays como elementos.

Filas Cada array interior puede representar una fila de datos.
Columnas Cada elemento de una fila puede interpretarse como una columna.
Acceso Utilizamos dos índices: array[fila][columna].
Recorrido Normalmente necesitamos un recorrido exterior para las filas y otro interior para sus elementos.
💻 Ejemplo

const notas = [[7, 8, 6], [5, 9, 7], [8, 6, 10]];

📌 length en arrays multidimensionales

array.length indica el número de filas, mientras que array[fila].length indica el número de elementos de esa fila.

4.12 Resolución de problemas con arrays

Resolver problemas con arrays no consiste en utilizar cuantos más métodos mejor, sino en analizar qué resultado necesitamos y elegir la herramienta adecuada.

💻 Método de trabajo

📌 Idea fundamental

Conocer muchos métodos no sustituye al razonamiento. Lo importante es comprender el problema y seleccionar la herramienta que mejor se adapte al resultado que necesitamos.

Ideas clave de la UT4

📌 Si tuvieras que recordar solo estas ideas…
  • Un array permite almacenar varios valores dentro de una misma estructura.
  • Los índices de un array comienzan en 0.
  • La propiedad length indica cuántos elementos contiene un array.
  • Podemos acceder o modificar un elemento mediante array[indice].
  • Un array declarado con const puede modificar sus elementos, aunque no podemos reasignar la variable a otro array.
  • push() y unshift() añaden elementos; pop() y shift() los eliminan de los extremos del array.
  • splice() permite eliminar, insertar o reemplazar elementos en cualquier posición.
  • indexOf() devuelve un índice, mientras que includes() responde con true o false.
  • find() devuelve el primer elemento que cumple una condición y findIndex() devuelve su posición.
  • for resulta especialmente útil cuando necesitamos trabajar con los índices o controlar el recorrido.
  • for...of permite recorrer directamente los valores de un array.
  • forEach() ejecuta una acción una vez por cada elemento del array.
  • map() transforma los elementos y devuelve un nuevo array.
  • filter() selecciona los elementos que cumplen una condición y devuelve un nuevo array.
  • sort() ordena los elementos y reverse() invierte el orden actual.
  • sort(), reverse() y splice() modifican el array original.
  • Para ordenar números correctamente con sort() necesitamos una función de comparación: (a, b) => a - b para orden ascendente y (a, b) => b - a para descendente.
  • Un array multidimensional contiene otros arrays y permite representar estructuras como filas y columnas.
  • Para recorrer un array multidimensional normalmente necesitamos recorridos anidados.
  • Antes de elegir un método debemos preguntarnos qué resultado necesitamos obtener: un valor, un índice, una comprobación o un nuevo array.
  • Resolver problemas con arrays implica analizar, elegir la herramienta adecuada, programar, comprobar, depurar y corregir.
