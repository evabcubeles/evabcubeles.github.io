4.7 Recorrer arrays con for...of

En el apartado anterior hemos aprendido a recorrer un array utilizando un bucle for. Para ello utilizábamos una variable como i que representaba el índice de cada elemento.

Sin embargo, en muchas ocasiones no necesitamos conocer la posición que ocupa cada elemento. Simplemente queremos trabajar directamente con los valores almacenados en el array.

JavaScript proporciona la estructura for...of, que permite recorrer los elementos de un array de una forma especialmente sencilla y legible.

📌 Importante

Con for...of obtenemos directamente cada elemento del array. No necesitamos utilizar un índice ni escribir array[i].

Sintaxis de for...of

La estructura básica de un bucle for...of es:

JavaScript 
for (const elemento of array) {
  // instrucciones
}

En esta estructura:

  • array es el array que queremos recorrer.
  • elemento es una variable que irá tomando el valor de cada elemento del array.
  • El bloque de instrucciones se ejecutará una vez por cada elemento.
📌 Importante

El nombre elemento es solo un ejemplo. Lo habitual es utilizar un nombre que describa el contenido del array: lenguaje, nota, alumno, producto, etc.

Recorrer un array con for...of

Observa el siguiente array:

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

for (const lenguaje of lenguajes) {
  console.log(lenguaje);
}

Console mostrará:

Console 
HTML
CSS
JavaScript
PHP

En cada iteración, la variable lenguaje recibe directamente uno de los valores del array.

Iteración Valor de lenguaje
1 HTML
2 CSS
3 JavaScript
4 PHP

El elemento actual

La principal diferencia respecto al for tradicional es que ahora la variable del bucle representa directamente el elemento actual.

Con un for tradicional escribíamos:

JavaScript 
for (let i = 0; i < lenguajes.length; i++) {
  console.log(lenguajes[i]);
}

En cambio, con for...of podemos escribir:

JavaScript 
for (const lenguaje of lenguajes) {
  console.log(lenguaje);
}

En el primer caso, i representa una posición y necesitamos escribir lenguajes[i] para obtener el elemento.

En el segundo caso, lenguaje ya contiene directamente el elemento.

⚠️ Atención

En un for...of, la variable del bucle no contiene el índice. Contiene directamente el valor almacenado en el array.

Comparación entre for y for...of

Ambas estructuras permiten recorrer un array, pero no proporcionan exactamente la misma información.

Característica for for...of
Acceso directo al elemento No, normalmente usamos array[i]. Sí.
Acceso directo al índice Sí. No.
Control del inicio y final Sí. Recorre los elementos del array.
Recorrido inverso sencillo Sí. No directamente.
Sintaxis Más detallada. Más sencilla.

Si solo necesitamos trabajar con todos los valores del array, for...of suele resultar más sencillo.

Si necesitamos conocer o controlar las posiciones, comenzar en un índice determinado o recorrer el array en sentido inverso, el for tradicional suele ser más apropiado.

📌 Recuerda

for nos facilita trabajar con índices, mientras que for...of nos permite trabajar directamente con los elementos.

Realizar operaciones con for...of

Al igual que ocurría con el for tradicional, podemos realizar operaciones con cada elemento durante el recorrido.

Por ejemplo, podemos sumar todas las notas almacenadas en un array:

JavaScript 
const notas = [
  7,
  5,
  9,
  6,
  8
];

let suma = 0;

for (const nota of notas) {
  suma += nota;
}

console.log(suma);

Console mostrará:

Console 
35

En cada iteración, nota contiene directamente uno de los valores del array. Por tanto, no necesitamos escribir notas[i].

Combinar for...of con una condición

También podemos utilizar estructuras condicionales dentro del recorrido.

Por ejemplo, podemos contar cuántas notas están aprobadas:

JavaScript 
const notas = [
  7,
  4,
  9,
  3,
  6
];

let aprobadas = 0;

for (const nota of notas) {

  if (nota >= 5) {
    aprobadas++;
  }

}

console.log(aprobadas);

Console mostrará:

Console 
3

¿Qué ocurre si necesitamos el índice?

Una característica importante de for...of es que proporciona directamente los valores del array, pero no sus índices.

Por ejemplo:

JavaScript 
const navegadores = [
  "Chrome",
  "Firefox",
  "Edge"
];

for (const navegador of navegadores) {
  console.log(navegador);
}

Podemos obtener fácilmente los valores "Chrome", "Firefox" y "Edge", pero la variable navegador no contiene los índices 0, 1 y 2.

Si necesitamos utilizar específicamente la posición de cada elemento, el for tradicional estudiado en el apartado 4.6 es más apropiado.

💡 Elección del recorrido

Si queremos mostrar simplemente todos los nombres de un array, for...of es una opción muy cómoda. Si queremos mostrar algo como «Elemento 0», «Elemento 1», «Elemento 2», necesitaremos trabajar también con las posiciones.

for...of no es for...in

JavaScript también dispone de una estructura llamada for...in. Aunque su nombre es parecido, no debemos confundirla con for...of.

Cuando trabajamos con arrays y queremos recorrer directamente sus elementos, utilizaremos for...of.

⚠️ Atención

No utilices for...in como forma habitual de recorrer los valores de un array. En esta unidad utilizaremos for, for...of y, en el siguiente apartado, forEach().

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación registra los tiempos de respuesta de varias peticiones al servidor. Queremos recorrer todos los tiempos, calcular el total y contar cuántas peticiones han tardado más de 1000 milisegundos.

JavaScript 
const tiempos = [
  320,
  450,
  1200,
  580,
  1500
];

let total = 0;
let lentas = 0;

for (const tiempo of tiempos) {

  console.log(
    "Tiempo registrado: " + tiempo + " ms"
  );

  total += tiempo;

  if (tiempo > 1000) {
    lentas++;
  }

}

console.log("Tiempo total: " + total + " ms");
console.log("Peticiones lentas: " + lentas);

Console mostrará:

Console 
Tiempo registrado: 320 ms
Tiempo registrado: 450 ms
Tiempo registrado: 1200 ms
Tiempo registrado: 580 ms
Tiempo registrado: 1500 ms
Tiempo total: 4050 ms
Peticiones lentas: 2

En este ejemplo no necesitamos conocer la posición de cada tiempo. Solo necesitamos trabajar con sus valores.

Por ese motivo, for...of permite expresar el recorrido de una forma muy clara:

  • tiempo representa directamente cada valor.
  • Sumamos cada tiempo en total.
  • Comprobamos si el valor supera los 1000 milisegundos.
  • Contamos las peticiones lentas mediante lentas.

Errores frecuentes al utilizar for...of

1. Pensar que la variable contiene el índice

En el siguiente código:

JavaScript 
for (const lenguaje of lenguajes) {
  console.log(lenguaje);
}

lenguaje contiene directamente valores como "HTML" o "CSS". No contiene los índices 0, 1, etc.

2. Intentar utilizar el elemento como si fuera un índice

Si la variable del bucle ya contiene el elemento, no debemos utilizarla como posición:

JavaScript 
for (const lenguaje of lenguajes) {
  console.log(lenguajes[lenguaje]);
}

Lo correcto, si queremos mostrar el valor, es:

JavaScript 
for (const lenguaje of lenguajes) {
  console.log(lenguaje);
}

3. Confundir for...of con for...in

Aunque sus nombres son parecidos, no realizan exactamente el mismo tipo de recorrido. Para obtener directamente los valores de un array utilizaremos for...of.

4. Utilizar for...of cuando necesitamos controlar las posiciones

Si el problema requiere conocer el índice, comenzar en una posición determinada o recorrer determinadas posiciones, el for tradicional suele ser más adecuado.

5. Pensar que el recorrido modifica automáticamente el array

Recorrer un array con for...of no cambia por sí mismo sus elementos. El bucle simplemente nos permite acceder a ellos uno a uno.

📌 Recuerda

Si necesitas la posición, piensa primero en for. Si necesitas trabajar directamente con cada valor, for...of suele ofrecer un código más sencillo y legible.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const numeros = [
  4,
  7,
  2,
  9,
  6
];

let suma = 0;
let mayores = 0;

for (const numero of numeros) {

  suma += numero;

  if (numero > 5) {
    mayores++;
  }

}

console.log(suma);
console.log(mayores);

Antes de ejecutarlo, responde:

  • ¿Qué valores irá tomando numero?
  • ¿Representa numero un índice o un elemento?
  • ¿Qué valor tendrá finalmente suma?
  • ¿Cuántos elementos son mayores que 5?
  • ¿Qué valor tendrá finalmente mayores?
Ver solución

La variable numero irá tomando directamente los valores 4, 7, 2, 9 y 6.

numero representa cada elemento del array, no su índice.

La suma será 4 + 7 + 2 + 9 + 6 = 28.

Los valores mayores que 5 son 7, 9 y 6, por lo que mayores tendrá el valor 3.

Console mostrará:

Console 
28
3

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y prueba las siguientes instrucciones:

JavaScript 
const numeros = [
  3,
  8,
  12,
  5,
  20
];

for (const numero of numeros) {
  console.log(numero);
}

let total = 0;

for (const numero of numeros) {
  total += numero;
}

console.log(total);

Antes de ejecutarlo, intenta predecir qué valores mostrará el primer bucle y cuál será el valor final de total.

Después compara este recorrido con el realizado mediante for en el apartado 4.6 y observa que ahora trabajamos directamente con cada elemento.
