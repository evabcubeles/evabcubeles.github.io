4.6 Recorrer arrays con for

En los apartados anteriores hemos aprendido a crear arrays, acceder a sus elementos, modificarlos y buscar información dentro de ellos.

Sin embargo, cuando queremos trabajar con todos los elementos de un array, acceder a ellos uno a uno de forma manual no resulta práctico.

Para procesar todos sus elementos podemos combinar los arrays con las estructuras repetitivas estudiadas en la UT3. Una de las formas más habituales consiste en utilizar un bucle for.

📌 Importante

Un bucle for permite recorrer las posiciones de un array utilizando un índice. En cada iteración podemos acceder al elemento correspondiente mediante array[indice].

Por qué necesitamos recorrer un array

Imagina que tenemos un array con los nombres de varios lenguajes:

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

Podríamos mostrar cada elemento accediendo manualmente a cada posición:

JavaScript 
console.log(lenguajes[0]);
console.log(lenguajes[1]);
console.log(lenguajes[2]);
console.log(lenguajes[3]);

Este código funciona, pero tiene un problema: necesitamos escribir una instrucción diferente para cada elemento.

Si el array tuviera cien elementos, tendríamos que escribir cien instrucciones. Además, si el número de elementos cambiara, también tendríamos que modificar el código.

Los bucles permiten resolver este problema recorriendo automáticamente las posiciones del array.

Recorrer un array con for

El bucle for que estudiamos en la UT3 puede utilizarse para recorrer los índices de un array.

Observa el siguiente ejemplo:

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

for (let i = 0; i < lenguajes.length; i++) {
  console.log(lenguajes[i]);
}

Console mostrará:

Console 
HTML
CSS
JavaScript
PHP

En cada iteración, la variable i contiene un índice diferente del array:

Iteración Valor de i Expresión Elemento
1 0 lenguajes[0] HTML
2 1 lenguajes[1] CSS
3 2 lenguajes[2] JavaScript
4 3 lenguajes[3] PHP

Diferencia entre índice y elemento

Al recorrer un array con for es importante distinguir entre el índice y el elemento almacenado en esa posición.

En el siguiente código:

JavaScript 
const navegadores = [
  "Chrome",
  "Firefox",
  "Edge"
];

for (let i = 0; i < navegadores.length; i++) {
  console.log(i);
  console.log(navegadores[i]);
}

i representa la posición, mientras que navegadores[i] representa el valor almacenado en esa posición.

Expresión Representa Ejemplo
i El índice o posición. 0, 1, 2
navegadores[i] El elemento almacenado en esa posición. Chrome, Firefox, Edge
⚠️ Atención

No confundas i con array[i]. La variable i contiene un número que representa una posición; array[i] permite acceder al elemento almacenado en esa posición.

Utilizar length como límite del bucle

Para recorrer un array completo necesitamos saber cuántos elementos contiene.

Como vimos anteriormente, la propiedad length devuelve el número de elementos del array.

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

console.log(lenguajes.length);

Console mostrará:

Console 
4

Sin embargo, los índices de este array van desde 0 hasta 3.

Por este motivo, la condición habitual del bucle es:

JavaScript 
i < lenguajes.length
📌 Importante

La forma habitual de recorrer completamente un array es for (let i = 0; i < array.length; i++). Empezamos en el índice 0 y continuamos mientras i sea menor que length.

Recorrer el array completo

Podemos utilizar el mismo patrón para recorrer cualquier array, independientemente del número de elementos que contenga.

JavaScript 
const modulos = [
  "DWEC",
  "DIW",
  "SASP",
  "DAW"
];

for (let i = 0; i < modulos.length; i++) {
  console.log(modulos[i]);
}

Si posteriormente añadimos otro elemento:

JavaScript 
modulos.push("Proyecto");

no necesitamos modificar el límite del bucle. Como utilizamos modulos.length, el recorrido se adapta automáticamente al nuevo número de elementos.

Recorrer solo una parte del array

No siempre necesitamos recorrer todos los elementos. Podemos modificar el valor inicial o la condición del for para trabajar únicamente con determinadas posiciones.

Por ejemplo, para comenzar en el índice 1:

JavaScript 
const tecnologias = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

for (let i = 1; i < tecnologias.length; i++) {
  console.log(tecnologias[i]);
}

Console mostrará:

Console 
CSS
JavaScript
PHP

También podemos detener el recorrido antes del final. Por ejemplo, para procesar únicamente las tres primeras posiciones:

JavaScript 
for (let i = 0; i < 3; i++) {
  console.log(tecnologias[i]);
}
⚠️ Atención

Cuando utilices un límite fijo, asegúrate de que esas posiciones existen en el array. Utilizar length suele ser más seguro cuando queremos recorrer todos sus elementos.

Recorrer un array en orden inverso

También podemos recorrer un array desde el último elemento hasta el primero.

Para ello debemos comenzar en el último índice: array.length - 1.

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

for (let i = lenguajes.length - 1; i >= 0; i--) {
  console.log(lenguajes[i]);
}

Console mostrará:

Console 
PHP
JavaScript
CSS
HTML

En este caso:

  • Comenzamos en lenguajes.length - 1, que es el último índice válido.
  • Continuamos mientras i >= 0.
  • Utilizamos i-- para retroceder una posición en cada iteración.

Realizar operaciones durante el recorrido

Recorrer un array no sirve únicamente para mostrar sus elementos. Durante cada iteración podemos realizar operaciones con el elemento actual.

Por ejemplo, podemos sumar todos los valores de un array:

JavaScript 
const notas = [7, 5, 9, 6, 8];

let suma = 0;

for (let i = 0; i < notas.length; i++) {
  suma += notas[i];
}

console.log(suma);

Console mostrará:

Console 
35

La variable suma funciona como un acumulador. En cada iteración añadimos el valor del elemento actual: notas[i].

Combinar el recorrido con una condición

También podemos utilizar estructuras condicionales dentro del bucle. Por ejemplo, para contar cuántas notas están aprobadas:

JavaScript 
const notas = [7, 4, 9, 3, 6];

let aprobadas = 0;

for (let i = 0; i < notas.length; i++) {

  if (notas[i] >= 5) {
    aprobadas++;
  }

}

console.log(aprobadas);

Console mostrará:

Console 
3
📌 Importante

Al combinar arrays, bucles y estructuras condicionales podemos procesar colecciones completas de datos: sumar valores, contar elementos que cumplen una condición, localizar máximos o mínimos y realizar muchos otros cálculos.

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación registra los tiempos de respuesta de varias peticiones al servidor. Queremos recorrerlos para mostrar cada valor, calcular el tiempo total y contar cuántas peticiones han tardado más de 1000 milisegundos.

JavaScript 
const tiempos = [
  320,
  450,
  1200,
  580,
  1500
];

let total = 0;
let lentas = 0;

for (let i = 0; i < tiempos.length; i++) {

  console.log(
    "Petición " + i + ": " + tiempos[i] + " ms"
  );

  total += tiempos[i];

  if (tiempos[i] > 1000) {
    lentas++;
  }

}

console.log("Tiempo total: " + total + " ms");
console.log("Peticiones lentas: " + lentas);

Console mostrará:

Console 
Petición 0: 320 ms
Petición 1: 450 ms
Petición 2: 1200 ms
Petición 3: 580 ms
Petición 4: 1500 ms
Tiempo total: 4050 ms
Peticiones lentas: 2

En este ejemplo utilizamos el índice i para acceder a cada tiempo mediante tiempos[i].

Además, durante el mismo recorrido:

  • Mostramos cada elemento.
  • Acumulamos todos los tiempos en total.
  • Comprobamos cuáles superan los 1000 milisegundos.
  • Contamos esas peticiones mediante lentas.

Errores frecuentes al recorrer arrays con for

1. Utilizar <= en lugar de <

Uno de los errores más frecuentes consiste en escribir:

JavaScript 
for (let i = 0; i <= lenguajes.length; i++) {
  console.log(lenguajes[i]);
}

Si el array tiene cuatro elementos, length vale 4, pero el último índice válido es 3. Cuando i llegue a 4, estaremos intentando acceder a una posición que no existe.

⚠️ Atención

Para recorrer un array completo desde el primer elemento, utiliza normalmente i < array.length, no i <= array.length.

2. Comenzar en 1 y olvidar el primer elemento

Los índices comienzan en 0. Si escribimos let i = 1, el elemento situado en el índice 0 no será procesado.

3. Confundir el índice con el elemento

Dentro del bucle, i representa el índice. Para obtener el elemento debemos utilizar array[i].

4. Escribir manualmente el tamaño del array

Podemos escribir un límite fijo:

JavaScript 
for (let i = 0; i < 4; i++) {
  console.log(lenguajes[i]);
}

pero si posteriormente cambia el número de elementos, ese límite puede dejar de ser correcto. Para recorrer el array completo es preferible utilizar lenguajes.length.

5. Utilizar mal el índice en un recorrido inverso

En un recorrido inverso debemos comenzar en array.length - 1, porque array.length no es un índice válido del array.

📌 Recuerda

Para recorrer un array con for piensa en tres cuestiones: ¿en qué índice comienzo?, ¿hasta qué índice debo llegar? y ¿cómo cambia el índice en cada iteración?

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const numeros = [
  4,
  7,
  2,
  9,
  6
];

let suma = 0;
let mayores = 0;

for (let i = 0; i < numeros.length; i++) {

  suma += numeros[i];

  if (numeros[i] > 5) {
    mayores++;
  }

}

console.log(suma);
console.log(mayores);

Antes de ejecutarlo, responde:

  • ¿Qué valores irá tomando i?
  • ¿Qué elementos se recorrerán?
  • ¿Qué valor tendrá finalmente suma?
  • ¿Cuántos elementos son mayores que 5?
  • ¿Qué valor tendrá finalmente mayores?
Ver solución

La variable i tomará los valores 0, 1, 2, 3 y 4.

Por tanto, se recorrerán los valores 4, 7, 2, 9 y 6.

La suma será: 4 + 7 + 2 + 9 + 6 = 28.

Los valores mayores que 5 son 7, 9 y 6. Por tanto, mayores tendrá el valor 3.

Console mostrará:

Console 
28
3

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y prueba las siguientes instrucciones:

JavaScript 
const numeros = [
  3,
  8,
  12,
  5,
  20
];

for (let i = 0; i < numeros.length; i++) {
  console.log(i, numeros[i]);
}

for (let i = numeros.length - 1; i >= 0; i--) {
  console.log(numeros[i]);
}

Antes de ejecutarlo, intenta predecir qué mostrará cada uno de los dos bucles.

Después comprueba en Console cómo cambia el índice i y qué elemento representa numeros[i] en cada iteración.
