4.5 Buscar elementos en un array

Hasta ahora hemos aprendido a crear arrays, acceder a sus elementos, modificarlos y añadir o eliminar información.

Sin embargo, cuando un array contiene muchos elementos no siempre conoceremos de antemano la posición que ocupa el dato que estamos buscando.

JavaScript proporciona distintos métodos que permiten buscar elementos dentro de un array o comprobar si un determinado valor está presente.

📌 Importante

No todos los métodos de búsqueda devuelven lo mismo. Algunos devuelven un índice, otros un valor y otros simplemente true o false.

Buscar la posición con indexOf()

El método indexOf() permite buscar un valor dentro de un array y obtener el índice de su primera aparición.

Su sintaxis básica es:

JavaScript 
array.indexOf(valorBuscado);

Observa el siguiente ejemplo:

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

const posicion = lenguajes.indexOf("JavaScript");

console.log(posicion);

Console mostrará:

Console 
2

El resultado es 2 porque "JavaScript" se encuentra en el índice 2.

Índice Elemento
0 HTML
1 CSS
2 JavaScript
3 PHP

¿Qué ocurre si un elemento aparece varias veces?

indexOf() devuelve únicamente el índice de la primera aparición del valor.

JavaScript 
const tecnologias = [
  "HTML",
  "CSS",
  "JavaScript",
  "CSS"
];

console.log(tecnologias.indexOf("CSS"));

Console mostrará:

Console 
1

Interpretar el valor -1

Si indexOf() no encuentra el elemento buscado, devuelve el valor -1.

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript"
];

const posicion = lenguajes.indexOf("PHP");

console.log(posicion);

Console mostrará:

Console 
-1
⚠️ Atención

El valor -1 no representa una posición válida del array. Significa que el elemento no ha sido encontrado.

Este resultado permite utilizar indexOf() dentro de una estructura condicional:

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript"
];

if (lenguajes.indexOf("CSS") !== -1) {
  console.log("CSS está en el array");
} else {
  console.log("CSS no está en el array");
}

Como "CSS" sí está presente, Console mostrará:

Console 
CSS está en el array

Comprobar la existencia con includes()

Cuando únicamente necesitamos saber si un valor se encuentra dentro de un array, podemos utilizar el método includes().

Este método devuelve un valor booleano:

  • true si el elemento existe.
  • false si el elemento no existe.
JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript"
];

console.log(lenguajes.includes("CSS"));
console.log(lenguajes.includes("PHP"));

Console mostrará:

Console 
true
false

También podemos utilizar directamente el resultado de includes() como condición:

JavaScript 
const tecnologias = [
  "HTML",
  "CSS",
  "JavaScript"
];

if (tecnologias.includes("JavaScript")) {
  console.log("JavaScript está disponible");
}
📌 Importante

Utiliza includes() cuando únicamente necesites responder a la pregunta: «¿Está este valor dentro del array?».

indexOf() o includes()

Aunque ambos métodos permiten buscar valores, proporcionan información diferente.

Método Devuelve Uso principal
indexOf() Un índice o -1 Conocer la posición de un valor.
includes() true o false Comprobar si un valor existe.

Por ejemplo:

JavaScript 
const navegadores = [
  "Chrome",
  "Firefox",
  "Edge"
];

console.log(navegadores.indexOf("Firefox"));
console.log(navegadores.includes("Firefox"));

Console mostrará:

Console 
1
true

Buscar según una condición con find()

indexOf() e includes() son muy útiles cuando conocemos exactamente el valor que queremos buscar.

En otras ocasiones necesitaremos localizar el primer elemento que cumpla una determinada condición. Para ello podemos utilizar find().

JavaScript 
const notas = [4, 6, 8, 3, 9];

const notaAlta = notas.find(
  nota => nota >= 8
);

console.log(notaAlta);

Console mostrará:

Console 
8

El método examina los elementos del array y devuelve el primer valor que cumple la condición nota >= 8.

⚠️ Sobre la función flecha

La expresión nota => nota >= 8 es una función flecha. Por ahora solo necesitamos entender que expresa la condición que debe cumplir cada elemento. Las funciones se estudiarán con detalle en la UT5.

¿Qué ocurre si ningún elemento cumple la condición?

Si find() no encuentra ningún elemento que cumpla la condición, devuelve undefined.

JavaScript 
const notas = [4, 5, 6, 7];

const resultado = notas.find(
  nota => nota >= 9
);

console.log(resultado);

Console mostrará:

Console 
undefined
📌 Importante

find() devuelve el primer elemento que cumple la condición. No devuelve todos los elementos que la cumplen.

Buscar una posición con findIndex()

El método findIndex() funciona de forma parecida a find(), pero en lugar de devolver el elemento encontrado devuelve su índice.

JavaScript 
const notas = [4, 6, 8, 3, 9];

const posicion = notas.findIndex(
  nota => nota >= 8
);

console.log(posicion);

Console mostrará:

Console 
2

El primer elemento que cumple nota >= 8 es 8, que ocupa el índice 2.

Si no encuentra ningún elemento

Al igual que indexOf(), findIndex() devuelve -1 cuando ningún elemento cumple la condición.

JavaScript 
const notas = [4, 5, 6];

const posicion = notas.findIndex(
  nota => nota >= 9
);

console.log(posicion);
Console 
-1

Qué método utilizar

La elección del método depende de la información que necesitemos obtener.

Método ¿Qué busca? ¿Qué devuelve?
indexOf() Un valor concreto. Su índice o -1.
includes() Un valor concreto. true o false.
find() El primer elemento que cumple una condición. El elemento o undefined.
findIndex() El primer elemento que cumple una condición. Su índice o -1.
📌 Recuerda

Antes de elegir un método pregúntate qué necesitas obtener: ¿saber si existe?, ¿conocer su posición?, ¿obtener el elemento o encontrar la posición de un elemento que cumple una condición?

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación almacena los tiempos de carga, en milisegundos, registrados en varias peticiones. Queremos comprobar determinados valores y localizar la primera petición especialmente lenta.

JavaScript 
const tiempos = [
  320,
  450,
  1200,
  580,
  1500
];

console.log(tiempos.includes(450));
console.log(tiempos.indexOf(1200));

const tiempoLento = tiempos.find(
  tiempo => tiempo > 1000
);

const posicionLenta = tiempos.findIndex(
  tiempo => tiempo > 1000
);

console.log(tiempoLento);
console.log(posicionLenta);

Console mostrará:

Console 
true
2
1200
2

En este ejemplo:

  • includes(450) comprueba si existe exactamente el valor 450.
  • indexOf(1200) obtiene la posición exacta del valor 1200.
  • find() obtiene el primer tiempo superior a 1000.
  • findIndex() obtiene la posición de ese primer tiempo superior a 1000.

Errores frecuentes al buscar en arrays

1. Pensar que indexOf() devuelve true o false

indexOf() devuelve una posición o -1. Si únicamente necesitamos un valor booleano, normalmente será más claro utilizar includes().

2. Interpretar -1 como una posición del array

Tanto indexOf() como findIndex() utilizan -1 para indicar que no se ha encontrado ningún resultado.

3. Pensar que find() devuelve el índice

find() devuelve el elemento encontrado. Si necesitamos su posición, debemos utilizar findIndex().

4. Pensar que find() devuelve todos los resultados

find() se detiene cuando encuentra el primer elemento que cumple la condición.

5. Confundir undefined con -1

Si find() no encuentra ningún elemento devuelve undefined. En cambio, indexOf() y findIndex() devuelven -1.

⚠️ Atención

Recuerda especialmente esta diferencia: find() devuelve un elemento, mientras que findIndex() devuelve un índice.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const notas = [
  5,
  7,
  4,
  9,
  6
];

const posicion = notas.indexOf(9);
const existe = notas.includes(7);

const primeraAlta = notas.find(
  nota => nota >= 8
);

const indiceAlta = notas.findIndex(
  nota => nota >= 8
);

console.log(posicion);
console.log(existe);
console.log(primeraAlta);
console.log(indiceAlta);

Antes de ejecutarlo, responde:

  • ¿Qué valor tendrá posicion?
  • ¿Qué valor tendrá existe?
  • ¿Qué elemento devolverá find()?
  • ¿Qué posición devolverá findIndex()?
  • ¿Qué diferencia existe entre los resultados de find() y findIndex()?
Ver solución

El valor 9 ocupa el índice 3, por lo que posicion será 3.

El valor 7 está en el array, por lo que existe será true.

El primer valor mayor o igual que 8 es 9. Por tanto, find() devolverá 9.

Ese valor ocupa el índice 3, por lo que findIndex() devolverá 3.

Console mostrará:

Console 
3
true
9
3
