4.12 Resolución de problemas con arrays

En los apartados anteriores hemos aprendido a crear arrays, acceder y modificar sus elementos, añadir y eliminar datos, realizar búsquedas, recorrer sus valores, transformar y filtrar información, ordenar elementos y trabajar con arrays multidimensionales.

Hasta ahora hemos estudiado estas herramientas principalmente por separado. Sin embargo, cuando desarrollamos una aplicación, lo habitual es encontrarnos con un problema que debemos analizar y resolver combinando varias de ellas.

En este último apartado de la UT4 aprenderemos a elegir qué operación resulta más adecuada en cada situación y a combinar lo aprendido para resolver problemas completos.

📌 Importante

Resolver un problema con arrays no consiste en utilizar el mayor número posible de métodos. El objetivo es comprender qué necesitamos obtener y elegir una solución clara, correcta y adecuada.

Analizar el problema antes de programar

Antes de comenzar a escribir código conviene detenerse y responder algunas preguntas:

  • ¿Qué datos tenemos?
  • ¿Cómo están almacenados?
  • ¿Qué resultado queremos obtener?
  • ¿Necesitamos consultar un elemento concreto?
  • ¿Tenemos que recorrer todos los elementos?
  • ¿Queremos buscar, seleccionar, transformar u ordenar datos?
  • ¿Necesitamos modificar el array original?
  • ¿Necesitamos conocer los índices?

Por ejemplo:

JavaScript 
const notas = [
  7,
  4,
  9,
  3,
  6
];

A partir del mismo array podemos encontrarnos con problemas muy diferentes:

Problema Herramienta que puede resultar adecuada
Obtener una nota concreta Índice
Saber cuántas notas existen length
Recorrer todas las notas for o for...of
Saber si existe una nota determinada includes()
Localizar una nota indexOf(), find() o findIndex()
Obtener únicamente los aprobados filter()
Transformar todas las notas map()
Ordenar las notas sort()
Invertir el orden actual reverse()
⚠️ Atención

Esta tabla no representa reglas absolutas. Un mismo problema puede resolverse de distintas formas. Lo importante es que la solución sea correcta, comprensible y adecuada.

Elegir la herramienta adecuada

Una de las habilidades que debemos desarrollar al programar es identificar qué queremos hacer con los datos.

Si necesitamos recorrer todos los elementos

Podemos utilizar for o for...of.

JavaScript 
const precios = [
  20,
  50,
  80,
  120
];

for (const precio of precios) {
  console.log(precio);
}

Si solo necesitamos trabajar con los valores, for...of suele resultar especialmente sencillo.

Si necesitamos conocer también el índice, puede resultar más adecuado utilizar for.

Si necesitamos comprobar si existe un valor

Podemos utilizar includes():

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript",
  "PHP"
];

console.log(
  lenguajes.includes("JavaScript")
);

Console mostrará:

Console 
true

En este caso no necesitamos construir manualmente un recorrido porque disponemos de un método que expresa directamente lo que queremos comprobar.

Si necesitamos seleccionar determinados elementos

Podemos utilizar filter():

JavaScript 
const notas = [
  7,
  4,
  9,
  3,
  6
];

const aprobados = notas.filter((nota) => {
  return nota >= 5;
});

console.log(aprobados);

Console mostrará:

Console 
[7, 9, 6]

Si necesitamos transformar los elementos

Podemos utilizar map():

JavaScript 
const precios = [
  20,
  50,
  80
];

const preciosConIVA = precios.map((precio) => {
  return precio * 1.21;
});

console.log(preciosConIVA);

Console mostrará:

Console 
[24.2, 60.5, 96.8]
📌 Recuerda

forEach() realiza una acción con cada elemento, map() transforma los elementos y genera un nuevo array, mientras que filter() selecciona elementos y genera un nuevo array.

Dividir un problema en pasos

Cuando un problema contiene varias operaciones, intentar resolverlo todo de una vez puede dificultar su comprensión.

Una estrategia útil consiste en dividir el problema en pasos más pequeños.

Supongamos que tenemos:

JavaScript 
const tiempos = [
  320,
  1200,
  450,
  1500,
  700
];

Queremos:

  1. Obtener únicamente los tiempos superiores a 1000 milisegundos.
  2. Convertir esos tiempos a segundos.

Podemos resolver primero una operación y después la otra:

JavaScript 
const lentos = tiempos.filter((tiempo) => {
  return tiempo > 1000;
});

const segundos = lentos.map((tiempo) => {
  return tiempo / 1000;
});

console.log(lentos);
console.log(segundos);

Console mostrará:

Console 
[1200, 1500]
[1.2, 1.5]

Una vez comprendemos los pasos, también podemos encadenar las operaciones:

JavaScript 
const segundos = tiempos
  .filter((tiempo) => {
    return tiempo > 1000;
  })
  .map((tiempo) => {
    return tiempo / 1000;
  });

console.log(segundos);

Resultado:

Console 
[1.2, 1.5]
📌 Importante

Antes de combinar métodos debemos tener claro qué hace cada operación y en qué orden debe realizarse.

Problema 1 — Analizar un conjunto de calificaciones

Tenemos las siguientes notas:

JavaScript 
const notas = [
  7,
  4,
  9,
  5,
  3,
  8
];

Queremos obtener:

  • La suma de todas las notas.
  • La nota media.
  • El número de aprobados.
  • El número de suspensos.

Como necesitamos examinar todos los valores y acumular información, podemos recorrer el array:

JavaScript 
const notas = [
  7,
  4,
  9,
  5,
  3,
  8
];

let suma = 0;
let aprobados = 0;
let suspensos = 0;

for (const nota of notas) {

  suma += nota;

  if (nota >= 5) {
    aprobados++;
  } else {
    suspensos++;
  }

}

const media = suma / notas.length;

console.log("Suma:", suma);
console.log("Media:", media);
console.log("Aprobados:", aprobados);
console.log("Suspensos:", suspensos);

Console mostrará:

Console 
Suma: 36
Media: 6
Aprobados: 4
Suspensos: 2

En este problema hemos combinado conocimientos de diferentes apartados:

  • Arrays.
  • length.
  • for...of.
  • Acumuladores.
  • Contadores.
  • Estructuras condicionales.
💡 Idea clave

Los arrays no sustituyen a las estructuras de control estudiadas anteriormente. Las utilizamos conjuntamente para resolver problemas más completos.

Problema 2 — Filtrar y ordenar datos

Tenemos una serie de tiempos de respuesta:

JavaScript 
const tiempos = [
  450,
  1200,
  320,
  1500,
  580,
  2100
];

Queremos:

  1. Obtener únicamente los tiempos superiores a 1000 ms.
  2. Ordenarlos de mayor a menor.

Primero filtramos:

JavaScript 
const lentos = tiempos.filter((tiempo) => {
  return tiempo > 1000;
});

Después ordenamos el nuevo array:

JavaScript 
lentos.sort((a, b) => {
  return b - a;
});

console.log(lentos);

Resultado:

Console 
[2100, 1500, 1200]

También podemos escribir:

JavaScript 
const lentos = tiempos
  .filter((tiempo) => {
    return tiempo > 1000;
  })
  .sort((a, b) => {
    return b - a;
  });

console.log(lentos);

Resultado:

Console 
[2100, 1500, 1200]

Aquí hemos combinado:

Esquema 
filter() → seleccionar
sort()   → ordenar

El orden de las operaciones tiene sentido: primero nos quedamos con los datos que nos interesan y después los ordenamos.

Problema 3 — Buscar información

Una aplicación almacena los códigos de varios módulos:

JavaScript 
const modulos = [
  "DWEC",
  "DIW",
  "SASP",
  "DAW"
];

Queremos comprobar si existe el módulo "DWEC".

JavaScript 
const existe = modulos.includes("DWEC");

console.log(existe);

Resultado:

Console 
true

Si además necesitamos conocer su posición:

JavaScript 
const posicion = modulos.indexOf("DWEC");

console.log(posicion);

Resultado:

Console 
0

Este ejemplo muestra algo importante: la herramienta depende de la información que necesitamos obtener.

Necesitamos Herramienta
Saber si existe includes()
Conocer su posición indexOf()
📌 Importante

Antes de programar debemos concretar qué resultado necesitamos. Esa decisión nos ayudará a elegir la herramienta adecuada.

Problema 4 — Trabajar con arrays multidimensionales

Supongamos que almacenamos tiempos de respuesta registrados durante varios días:

JavaScript 
const tiempos = [
  [320, 450, 1200],
  [580, 1500, 430],
  [290, 1100, 700]
];

Queremos calcular:

  • Cuántas peticiones se han registrado.
  • Cuántas han tardado más de 1000 ms.
  • La suma de todos los tiempos.
  • El tiempo medio.

Necesitamos recorrer todas las filas y todos sus elementos:

JavaScript 
const tiempos = [
  [320, 450, 1200],
  [580, 1500, 430],
  [290, 1100, 700]
];

let totalPeticiones = 0;
let peticionesLentas = 0;
let suma = 0;

for (const fila of tiempos) {

  for (const tiempo of fila) {

    totalPeticiones++;
    suma += tiempo;

    if (tiempo > 1000) {
      peticionesLentas++;
    }

  }

}

const media = suma / totalPeticiones;

console.log(
  "Peticiones:",
  totalPeticiones
);

console.log(
  "Peticiones lentas:",
  peticionesLentas
);

console.log(
  "Tiempo medio:",
  media
);

Console mostrará:

Console 
Peticiones: 9
Peticiones lentas: 3
Tiempo medio: 730

Aquí integramos lo estudiado en el apartado 4.11 con conceptos anteriores como contadores, acumuladores y condiciones.

Ejemplo práctico

💻 Ejemplo DAW

Supongamos que durante una prueba de rendimiento de una aplicación web registramos los tiempos de respuesta de varias peticiones. Queremos analizar esos datos utilizando diferentes operaciones con arrays.

JavaScript 
const tiempos = [
  320,
  1500,
  450,
  1200,
  580,
  2100,
  700
];

Queremos:

  1. Saber cuántas peticiones se han registrado.
  2. Obtener únicamente las peticiones lentas, superiores a 1000 ms.
  3. Ordenarlas de mayor a menor.
  4. Convertir esos tiempos a segundos.
  5. Mostrar los resultados.

Podemos resolverlo paso a paso:

JavaScript 
const tiempos = [
  320,
  1500,
  450,
  1200,
  580,
  2100,
  700
];

console.log(
  "Total de peticiones:",
  tiempos.length
);

const lentos = tiempos.filter((tiempo) => {
  return tiempo > 1000;
});

lentos.sort((a, b) => {
  return b - a;
});

const segundos = lentos.map((tiempo) => {
  return tiempo / 1000;
});

console.log(
  "Peticiones lentas:",
  lentos
);

console.log(
  "Tiempos en segundos:",
  segundos
);

Console mostrará:

Console 
Total de peticiones: 7
Peticiones lentas: [2100, 1500, 1200]
Tiempos en segundos: [2.1, 1.5, 1.2]

El problema se ha dividido en operaciones sencillas:

Esquema 
length
   ↓
filter()
   ↓
sort()
   ↓
map()
📌 Importante

Esta forma de trabajar facilita la lectura, comprobación y corrección del programa. Si aparece un error, podemos comprobar cada paso por separado.

Comprobar la solución

Resolver un problema no termina cuando conseguimos escribir código que aparentemente funciona.

También debemos comprobar que el resultado es correcto.

Por ejemplo, podemos preguntarnos:

  • ¿Qué ocurre si el array está vacío?
  • ¿Hemos recorrido todos los elementos?
  • ¿Los índices utilizados son correctos?
  • ¿La condición incluye exactamente los valores que queremos?
  • ¿Estamos modificando el array original sin querer?
  • ¿El resultado tiene el tipo y la estructura esperados?
  • ¿Podemos probar el programa con datos diferentes?

Las herramientas de desarrollo del navegador y console.log() nos permiten observar valores intermedios y comprobar el comportamiento del programa.

JavaScript 
const numeros = [
  4,
  8,
  12,
  3
];

const mayores = numeros.filter((numero) => {
  return numero > 5;
});

console.log(numeros);
console.log(mayores);

Resultado:

Console 
[4, 8, 12, 3]
[8, 12]

Esto también nos permite comprobar que filter() no ha modificado el array original.

Errores frecuentes al resolver problemas con arrays

1. Empezar a programar sin analizar el problema

Es frecuente comenzar a escribir un bucle o utilizar un método sin haber determinado qué resultado necesitamos.

Antes de programar debemos identificar claramente:

Esquema 
datos → operación → resultado

2. Elegir un método porque lo conocemos, no porque sea adecuado

Por ejemplo, si queremos saber si existe "JavaScript":

JavaScript 
const lenguajes = [
  "HTML",
  "CSS",
  "JavaScript"
];

Podríamos recorrer manualmente todo el array, pero:

JavaScript 
lenguajes.includes("JavaScript");

expresa directamente nuestra intención.

3. Confundir transformar con filtrar

map() y filter() realizan operaciones diferentes:

Esquema 
map()     → transforma
filter()  → selecciona

4. Olvidar si un método modifica el array original

Debemos recordar:

Método ¿Modifica el array original?
map() No
filter() No
sort() Sí
reverse() Sí

5. Utilizar índices cuando no son necesarios

Si únicamente necesitamos trabajar con los valores:

JavaScript 
for (const nota of notas) {
  console.log(nota);
}

puede resultar más claro que un recorrido basado en índices.

6. No comprobar los resultados intermedios

Cuando combinamos varias operaciones es útil comprobar cada paso:

JavaScript 
console.log(datos);
console.log(filtrados);
console.log(ordenados);

Esto facilita localizar errores.

7. Intentar resolver todo en una única expresión

Encadenar métodos puede ser útil, pero no siempre produce el código más fácil de entender.

Durante el aprendizaje, si una solución resulta difícil de seguir, es preferible dividirla en varios pasos.

⚠️ Atención

Una solución más corta no es necesariamente una solución mejor. La claridad del código también es importante.

Estrategia general para resolver problemas con arrays

Podemos utilizar el siguiente proceso:

1. Comprender el problema

¿Qué debemos obtener?

2. Identificar los datos

¿Qué contiene el array?

3. Elegir las operaciones

¿Necesitamos buscar, recorrer, filtrar, transformar u ordenar?

4. Dividir el problema

Si existen varias operaciones, conviene resolverlas paso a paso.

5. Implementar la solución

Escribimos el código utilizando las herramientas adecuadas.

6. Comprobar los resultados

Podemos utilizar Console y diferentes datos de prueba.

7. Revisar el código

Comprobamos si la solución es clara y si estamos modificando algún dato innecesariamente.

Podemos resumirlo así:

Esquema 
PROBLEMA
   ↓
ANALIZAR
   ↓
DATOS
   ↓
OPERACIONES
   ↓
IMPLEMENTAR
   ↓
COMPROBAR
   ↓
REVISAR

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const precios = [
  120,
  40,
  200,
  80,
  150
];

const seleccionados = precios.filter((precio) => {
  return precio >= 100;
});

seleccionados.sort((a, b) => {
  return a - b;
});

const rebajados = seleccionados.map((precio) => {
  return precio * 0.9;
});

console.log(seleccionados);
console.log(rebajados);
console.log(precios);

Antes de ejecutarlo, responde:

  1. ¿Qué elementos contendrá seleccionados después de filter()?
  2. ¿Qué elementos contendrá después de sort()?
  3. ¿Qué contendrá rebajados?
  4. ¿Se habrá modificado el array precios?
  5. ¿Qué operación selecciona datos?
  6. ¿Qué operación ordena?
  7. ¿Qué operación transforma?
Ver solución

Después de filter(), seleccionados contiene:

Resultado 
[120, 200, 150]

Después de sort() contiene:

Resultado 
[120, 150, 200]

rebajados contiene:

Resultado 
[108, 135, 180]

El array original precios continúa siendo:

Resultado 
[120, 40, 200, 80, 150]

filter() selecciona, sort() ordena y map() transforma.

sort() modifica el array seleccionados, pero no modifica precios, porque seleccionados es el nuevo array creado previamente por filter().

JavaScript
