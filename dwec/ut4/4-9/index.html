4.9 Transformar y filtrar arrays

En el apartado anterior hemos aprendido a utilizar forEach() para recorrer todos los elementos de un array y realizar una acción con cada uno de ellos.

Sin embargo, en muchas aplicaciones no queremos únicamente recorrer los datos. También necesitamos transformarlos o seleccionar únicamente aquellos que cumplen una determinada condición.

JavaScript proporciona varios métodos de los arrays que facilitan estas operaciones. En este apartado estudiaremos dos de los más utilizados: map() y filter().

📌 Importante

map() permite transformar los elementos de un array, mientras que filter() permite seleccionar únicamente aquellos elementos que cumplen una condición. Ambos métodos generan un nuevo array.

Transformar arrays con map()

El método map() recorre todos los elementos de un array, aplica una transformación a cada uno de ellos y devuelve un nuevo array con los resultados.

Una forma habitual de utilizarlo es:

JavaScript 
const nuevoArray = array.map((elemento) => {
  return transformación;
});

En esta estructura:

  • array es el array original.
  • elemento representa cada elemento durante el recorrido.
  • return indica el valor que se incorporará al nuevo array.
  • nuevoArray almacenará los resultados obtenidos.
⚠️ Atención

Igual que en el apartado anterior, utilizaremos una función flecha para trabajar con estos métodos. En la UT5 estudiaremos las funciones y la instrucción return con mayor detalle. Por ahora nos interesa comprender qué operación realiza map().

Observa el siguiente ejemplo:

JavaScript 
const numeros = [
  2,
  4,
  6,
  8
];

const dobles = numeros.map((numero) => {
  return numero * 2;
});

console.log(dobles);

Console mostrará:

Console 
[4, 8, 12, 16]

Cada elemento del array original se multiplica por 2 y el resultado se almacena en el nuevo array dobles.

Cómo funciona map()

Para comprender mejor el proceso, podemos observar qué ocurre en cada iteración:

Elemento original Operación Resultado
2 2 * 2 4
4 4 * 2 8
6 6 * 2 12
8 8 * 2 16

El nuevo array tendrá el mismo número de elementos que el array original, porque map() genera un resultado por cada elemento recorrido.

📌 Recuerda

map() se utiliza cuando queremos transformar todos los elementos de un array y obtener otro array con los resultados.

Otro ejemplo con cadenas de texto

También podemos utilizar map() con arrays que contienen cadenas de texto.

JavaScript 
const lenguajes = [
  "html",
  "css",
  "javascript"
];

const mayusculas = lenguajes.map((lenguaje) => {
  return lenguaje.toUpperCase();
});

console.log(mayusculas);

Console mostrará:

Console 
["HTML", "CSS", "JAVASCRIPT"]

Filtrar arrays con filter()

En otras ocasiones no queremos transformar todos los elementos, sino seleccionar únicamente aquellos que cumplen una determinada condición.

Para ello podemos utilizar el método filter().

Su estructura habitual es:

JavaScript 
const nuevoArray = array.filter((elemento) => {
  return condición;
});

La condición debe producir un valor verdadero o falso:

  • Si la condición es true, el elemento se incluye en el nuevo array.
  • Si la condición es false, el elemento no se incluye.

Por ejemplo, podemos obtener únicamente las notas aprobadas:

JavaScript 
const notas = [
  7,
  4,
  9,
  3,
  6
];

const aprobadas = notas.filter((nota) => {
  return nota >= 5;
});

console.log(aprobadas);

Console mostrará:

Console 
[7, 9, 6]

Cómo funciona filter()

En el ejemplo anterior, filter() comprueba la condición nota >= 5 para cada elemento.

Nota ¿nota >= 5? ¿Se incluye?
7 true Sí
4 false No
9 true Sí
3 false No
6 true Sí
📌 Recuerda

filter() no transforma los valores. Selecciona únicamente los elementos del array original que cumplen la condición indicada.

Otro ejemplo de filtrado

Podemos seleccionar, por ejemplo, únicamente los tiempos de respuesta que superen los 1000 milisegundos:

JavaScript 
const tiempos = [
  320,
  1200,
  450,
  1500,
  700
];

const lentos = tiempos.filter((tiempo) => {
  return tiempo > 1000;
});

console.log(lentos);

Console mostrará:

Console 
[1200, 1500]

El array original y el nuevo array

Una característica muy importante de map() y filter() es que generan un nuevo array.

El array original no se modifica simplemente por utilizar estos métodos.

JavaScript 
const numeros = [
  2,
  4,
  6
];

const dobles = numeros.map((numero) => {
  return numero * 2;
});

console.log(numeros);
console.log(dobles);

Console mostrará:

Console 
[2, 4, 6]
[4, 8, 12]

Podemos observar que:

  • numeros continúa almacenando [2, 4, 6].
  • dobles almacena el nuevo array [4, 8, 12].
⚠️ Atención

No debemos olvidar guardar el resultado de map() o filter() si queremos utilizar posteriormente el nuevo array.

Comparación entre forEach(), map() y filter()

Los tres métodos recorren los elementos de un array, pero están pensados para resolver necesidades diferentes.

Método Objetivo principal ¿Genera un nuevo array?
forEach() Realizar una acción con cada elemento. No.
map() Transformar cada elemento. Sí.
filter() Seleccionar los elementos que cumplen una condición. Sí.
📌 Recuerda

Podemos pensar en tres preguntas: ¿quiero realizar una acción? forEach(). ¿Quiero transformar los valores? map(). ¿Quiero seleccionar algunos elementos? filter().

Combinar map() y filter()

Los métodos de los arrays pueden utilizarse de forma encadenada. Esto permite realizar varias operaciones sucesivas sobre los datos.

Por ejemplo, podemos seleccionar primero las notas aprobadas y después transformar esas notas multiplicándolas por 10:

JavaScript 
const notas = [
  7,
  4,
  9,
  3,
  6
];

const resultados = notas
  .filter((nota) => {
    return nota >= 5;
  })
  .map((nota) => {
    return nota * 10;
  });

console.log(resultados);

Console mostrará:

Console 
[70, 90, 60]

El proceso se realiza en dos pasos:

  • filter() obtiene primero [7, 9, 6].
  • map() transforma esos valores en [70, 90, 60].
⚠️ Atención

El encadenamiento de métodos es muy habitual en JavaScript, pero conviene utilizarlo cuando el código siga siendo fácil de comprender. Primero debemos entender correctamente qué hace cada método por separado.

Ejemplo práctico

💻 Ejemplo DAW

Imagina que una aplicación web registra los tiempos de respuesta de varias peticiones al servidor. Queremos obtener únicamente las peticiones lentas y, después, convertir sus tiempos de milisegundos a segundos.

JavaScript 
const tiempos = [
  320,
  450,
  1200,
  580,
  1500
];

const tiemposLentos = tiempos.filter((tiempo) => {
  return tiempo > 1000;
});

const segundos = tiemposLentos.map((tiempo) => {
  return tiempo / 1000;
});

console.log(tiemposLentos);
console.log(segundos);

Console mostrará:

Console 
[1200, 1500]
[1.2, 1.5]

En este ejemplo:

  • El array original contiene todos los tiempos de respuesta.
  • filter() selecciona únicamente los tiempos superiores a 1000 milisegundos.
  • map() transforma esos tiempos de milisegundos a segundos.
  • El array original tiempos permanece sin cambios.

Errores frecuentes al utilizar map() y filter()

1. Pensar que map() modifica el array original

map() genera un nuevo array con los valores transformados. El array original no se sustituye automáticamente.

2. Pensar que filter() transforma los valores

filter() selecciona elementos según una condición. Los elementos seleccionados mantienen sus valores.

3. Olvidar guardar el nuevo array

Si queremos utilizar el resultado posteriormente, debemos almacenarlo en una variable:

JavaScript 
const dobles = numeros.map((numero) => {
  return numero * 2;
});

4. Confundir map() con forEach()

Si únicamente queremos realizar una acción con cada elemento, forEach() puede ser suficiente.

Si queremos obtener un nuevo array con los valores transformados, utilizaremos map().

5. Confundir la condición de filter()

La condición determina qué elementos permanecen en el nuevo array. Los elementos para los que la condición sea verdadera se conservan.

📌 Recuerda

map() transforma y filter() selecciona. Ambos generan un nuevo array y son herramientas fundamentales para trabajar con colecciones de datos en JavaScript.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const numeros = [
  3,
  8,
  12,
  5,
  20
];

const mayores = numeros.filter((numero) => {
  return numero > 5;
});

const dobles = mayores.map((numero) => {
  return numero * 2;
});

console.log(mayores);
console.log(dobles);

Antes de ejecutarlo, responde:

  • ¿Qué elementos tendrá el array mayores?
  • ¿Qué elementos tendrá el array dobles?
  • ¿Qué método está realizando el filtrado?
  • ¿Qué método está realizando la transformación?
  • ¿Se modifica el array original numeros?
Ver solución

filter() selecciona los valores mayores que 5, por lo que mayores contendrá [8, 12, 20].

Después, map() multiplica cada uno de esos valores por 2, por lo que dobles contendrá [16, 24, 40].

El método que realiza el filtrado es filter() y el que realiza la transformación es map().

El array original numeros no se modifica.

Console mostrará:

Console 
[8, 12, 20]
[16, 24, 40]

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y prueba las siguientes instrucciones:

JavaScript 
const precios = [
  20,
  50,
  80,
  120,
  200
];

const preciosAltos = precios.filter((precio) => {
  return precio >= 100;
});

const preciosConDescuento = preciosAltos.map((precio) => {
  return precio * 0.9;
});

console.log(precios);
console.log(preciosAltos);
console.log(preciosConDescuento);

Antes de ejecutarlo, intenta predecir:

  • Qué valores tendrá preciosAltos.
  • Qué valores tendrá preciosConDescuento.
  • Si el array original precios cambiará.

Después ejecuta el código y comprueba el resultado. Observa cómo filter() selecciona determinados elementos y map() transforma posteriormente esos valores.
