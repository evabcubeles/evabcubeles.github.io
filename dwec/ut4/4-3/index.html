4.3 Añadir y eliminar elementos

En el apartado anterior hemos aprendido a acceder a los elementos de un array mediante sus índices, modificar su contenido e incluso añadir un nuevo elemento utilizando la siguiente posición disponible.

Sin embargo, JavaScript proporciona métodos específicos que permiten añadir y eliminar elementos de una forma más sencilla y expresiva. Estos métodos permiten trabajar tanto con el principio como con el final del array.

En este apartado estudiaremos cuatro métodos fundamentales: push(), pop(), unshift() y shift().

push() Añade elementos al final
pop() Elimina el último elemento
unshift() Añade elementos al principio
shift() Elimina el primer elemento
📌 Importante

Los métodos push(), pop(), unshift() y shift() modifican directamente el array original. Después de ejecutarlos, el contenido y normalmente también la propiedad length del array habrán cambiado.

Añadir elementos al final con push()

El método push() permite añadir uno o varios elementos al final de un array.

Su sintaxis básica es:

JavaScript 
nombreArray.push(elemento);

Observa el siguiente ejemplo:

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript"];

lenguajes.push("PHP");

console.log(lenguajes);

El método añade "PHP" después del último elemento existente. El array queda así:

Console 
["HTML", "CSS", "JavaScript", "PHP"]

También podemos añadir varios elementos en una sola operación:

JavaScript 
const lenguajes = ["HTML", "CSS"];

lenguajes.push("JavaScript", "PHP");

console.log(lenguajes);

El resultado será:

Console 
["HTML", "CSS", "JavaScript", "PHP"]
💻 Ejemplo DAW

Imagina que una aplicación mantiene un array con los productos añadidos al carrito. Cada vez que el usuario selecciona un nuevo producto podemos incorporarlo al final mediante, por ejemplo, carrito.push("Teclado");.

Eliminar el último elemento con pop()

El método pop() permite eliminar el último elemento de un array.

No es necesario indicar ningún índice ni pasar ningún argumento.

JavaScript 
const navegadores = ["Chrome", "Firefox", "Edge", "Safari"];

navegadores.pop();

console.log(navegadores);

pop() elimina "Safari", porque era el último elemento del array.

El resultado será:

Console 
["Chrome", "Firefox", "Edge"]

Como hemos eliminado un elemento, también cambia la propiedad length:

JavaScript 
const navegadores = ["Chrome", "Firefox", "Edge", "Safari"];

console.log(navegadores.length);

navegadores.pop();

console.log(navegadores.length);

Console mostrará:

Console 
4
3
📌 Importante

pop() siempre actúa sobre el último elemento. No permite indicar una posición concreta. Más adelante estudiaremos cómo eliminar elementos situados en otras posiciones del array.

Añadir elementos al principio con unshift()

El método unshift() permite añadir uno o varios elementos al principio de un array.

El nuevo elemento pasa a ocupar el índice 0 y los elementos que ya existían cambian de posición.

JavaScript 
const alumnos = ["Luis", "Marta", "Pablo"];

alumnos.unshift("Ana");

console.log(alumnos);

El resultado será:

Console 
["Ana", "Luis", "Marta", "Pablo"]

Antes de ejecutar unshift(), "Luis" estaba situado en el índice 0. Después de añadir "Ana", pasa al índice 1.

Elemento Índice antes Índice después
Luis 0 1
Marta 1 2
Pablo 2 3

También podemos añadir varios elementos:

JavaScript 
const alumnos = ["Marta", "Pablo"];

alumnos.unshift("Ana", "Luis");

console.log(alumnos);

El resultado será:

Console 
["Ana", "Luis", "Marta", "Pablo"]

Eliminar el primer elemento con shift()

El método shift() permite eliminar el primer elemento de un array.

Al eliminar el elemento situado en el índice 0, los demás elementos cambian de posición.

JavaScript 
const tareas = ["Estudiar", "Practicar JavaScript", "Hacer el reto"];

tareas.shift();

console.log(tareas);

El método elimina "Estudiar". El resultado será:

Console 
["Practicar JavaScript", "Hacer el reto"]

Después de eliminar el primer elemento, "Practicar JavaScript" pasa a ocupar el índice 0.

💻 Ejemplo DAW

Una aplicación puede mantener una cola de avisos pendientes. Si el primer aviso ya ha sido procesado, avisos.shift(); permite eliminarlo y hacer que el siguiente aviso pase a ocupar la primera posición.

Añadir y eliminar al principio o al final

Los cuatro métodos estudiados pueden organizarse según la zona del array sobre la que actúan.

Método Operación Zona del array
push() Añade uno o varios elementos Final
pop() Elimina un elemento Final
unshift() Añade uno o varios elementos Principio
shift() Elimina un elemento Principio
unshift() → añade al principio
shift() → elimina del principio
push() → añade al final
pop() → elimina del final

Observa cómo podemos combinar varios métodos:

JavaScript 
const tecnologias = ["CSS", "JavaScript"];

tecnologias.unshift("HTML");
tecnologias.push("PHP");

console.log(tecnologias);

El resultado será:

Console 
["HTML", "CSS", "JavaScript", "PHP"]
⚠️ Atención

Cuando utilizamos unshift() o shift(), cambian los índices de los elementos que ya estaban en el array. Esto es importante si posteriormente necesitamos acceder a ellos mediante su posición.

Valores devueltos por estos métodos

Además de modificar el array, estos métodos devuelven un valor. Es importante conocerlo porque podemos guardar ese resultado en una variable o utilizarlo posteriormente.

Valor devuelto por push()

push() devuelve la nueva longitud del array.

JavaScript 
const lenguajes = ["HTML", "CSS"];

const nuevaLongitud = lenguajes.push("JavaScript");

console.log(nuevaLongitud);
console.log(lenguajes);

Console mostrará:

Console 
3
["HTML", "CSS", "JavaScript"]

Valor devuelto por unshift()

unshift() también devuelve la nueva longitud del array.

JavaScript 
const lenguajes = ["CSS", "JavaScript"];

const nuevaLongitud = lenguajes.unshift("HTML");

console.log(nuevaLongitud);
console.log(lenguajes);

Console mostrará:

Console 
3
["HTML", "CSS", "JavaScript"]

Valor devuelto por pop()

pop() devuelve el elemento que ha eliminado.

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript"];

const eliminado = lenguajes.pop();

console.log(eliminado);
console.log(lenguajes);

Console mostrará:

Console 
JavaScript
["HTML", "CSS"]

Valor devuelto por shift()

shift() devuelve el elemento que ha eliminado.

JavaScript 
const lenguajes = ["HTML", "CSS", "JavaScript"];

const eliminado = lenguajes.shift();

console.log(eliminado);
console.log(lenguajes);

Console mostrará:

Console 
HTML
["CSS", "JavaScript"]
Método Modifica el array Valor devuelto
push() Sí Nueva longitud
pop() Sí Elemento eliminado
unshift() Sí Nueva longitud
shift() Sí Elemento eliminado
📌 Importante

No debemos confundir el efecto que produce un método sobre el array con el valor que devuelve. Por ejemplo, pop() modifica el array eliminando su último elemento y, además, devuelve precisamente el elemento eliminado.

Ejemplos prácticos

Podemos combinar los cuatro métodos para gestionar conjuntos de datos que cambian durante la ejecución de un programa.

Ejemplo 1: lista de tareas

JavaScript 
const tareas = ["Estudiar JavaScript", "Hacer ejercicios"];

tareas.push("Preparar el reto");
tareas.unshift("Revisar apuntes");

console.log(tareas);

const primeraTarea = tareas.shift();

console.log("Tarea realizada: " + primeraTarea);
console.log(tareas);

Primero se añade una tarea al final y otra al principio. Después se elimina la primera tarea y se guarda en la variable primeraTarea.

Ejemplo 2: historial de páginas

JavaScript 
const historial = ["inicio.html", "productos.html"];

historial.push("detalle.html");
historial.push("carrito.html");

console.log(historial);

const ultimaPagina = historial.pop();

console.log("Página eliminada: " + ultimaPagina);
console.log(historial);

En este caso utilizamos push() para incorporar nuevas páginas al final del historial y pop() para retirar la última.

💻 Ejemplo DAW

En una aplicación web es habitual trabajar con colecciones que cambian: productos de un carrito, mensajes pendientes, tareas, notificaciones o páginas visitadas. Elegir entre push(), pop(), unshift() y shift() dependerá de si necesitamos actuar sobre el principio o sobre el final del array.

🧠 Comprueba lo aprendido

Observa el siguiente código sin ejecutarlo:

JavaScript 
const tecnologias = ["HTML", "CSS", "JavaScript"];

tecnologias.push("PHP");
tecnologias.unshift("Git");

const ultima = tecnologias.pop();
const primera = tecnologias.shift();

Responde a las siguientes preguntas:

  • ¿Cuál es el contenido del array después de ejecutar push("PHP")?
  • ¿Cuál es el contenido después de ejecutar unshift("Git")?
  • ¿Qué valor se almacena en la variable ultima?
  • ¿Qué valor se almacena en la variable primera?
  • ¿Cuál es el contenido final del array tecnologias?
  • ¿Cuánto vale finalmente tecnologias.length?
Ver solución

Después de ejecutar push("PHP"), el array es ["HTML", "CSS", "JavaScript", "PHP"].

Después de ejecutar unshift("Git"), el array es ["Git", "HTML", "CSS", "JavaScript", "PHP"].

pop() elimina el último elemento, por lo que ultima contiene "PHP".

Después de esa operación el array es ["Git", "HTML", "CSS", "JavaScript"].

shift() elimina el primer elemento, por lo que primera contiene "Git".

El contenido final de tecnologias es ["HTML", "CSS", "JavaScript"].

Finalmente, tecnologias.length vale 3.

Presta especial atención a la diferencia entre los métodos que actúan sobre el principio del array y los que actúan sobre el final.
