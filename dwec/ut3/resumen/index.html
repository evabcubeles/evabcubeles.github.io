✏️ Resumen de la UT3

En esta unidad hemos aprendido a controlar el flujo de ejecución de un programa mediante estructuras condicionales y repetitivas.

Hemos estudiado cómo tomar decisiones con if, if...else, else if y switch, cómo repetir instrucciones mediante for, while y do...while, y cómo combinar estas estructuras para resolver problemas.

Este resumen reúne las ideas esenciales de los apartados 3.1 a 3.11 para utilizarlo como guía rápida de repaso.

3.1 El flujo de ejecución de un programa

El flujo de ejecución indica el orden en el que se ejecutan las instrucciones de un programa.

Ejecución secuencial Las instrucciones se ejecutan normalmente de arriba hacia abajo.
Control del flujo Permite alterar ese orden mediante decisiones y repeticiones.
Condición Expresión que se evalúa como true o false.
Comparaciones Podemos utilizar operadores como ===, !==, >, <, >= y <=.
Operadores lógicos &&, || y ! permiten combinar o modificar condiciones.
Bloques Las llaves { } agrupan instrucciones que pertenecen a una estructura de control.
📌 Idea esencial

Las estructuras de control permiten decidir qué instrucciones se ejecutan, cuándo se ejecutan y cuántas veces se repiten.

3.2 Estructuras condicionales: if

La estructura if permite ejecutar un bloque de instrucciones solo cuando una condición es verdadera.

💻 Estructura básica

if (condicion) { ... }

Condición verdadera El bloque asociado al if se ejecuta.
Condición falsa El bloque se omite y el programa continúa.
Booleanos La condición debe poder evaluarse como true o false.
Bloque de código Las instrucciones que dependen del if se agrupan entre llaves.

3.3 Alternativas con if...else

if...else permite establecer dos caminos alternativos de ejecución.

✅ if

Se ejecuta cuando la condición es verdadera.

❌ else

Se ejecuta cuando la condición es falsa.

🔀 Dos alternativas

En cada evaluación se ejecutará uno de los dos bloques.

📌 Recuerda

else no lleva condición propia: representa el camino que se ejecuta cuando la condición del if es falsa.

3.4 Decisiones múltiples con else if

Cuando necesitamos elegir entre más de dos alternativas podemos encadenar condiciones mediante else if.

Orden de evaluación Las condiciones se comprueban de arriba hacia abajo.
Primera coincidencia Cuando una condición resulta verdadera se ejecuta su bloque y no se evalúan las alternativas posteriores.
Rangos El orden es especialmente importante cuando las condiciones representan intervalos o rangos de valores.
else final Puede utilizarse para recoger cualquier caso que no haya cumplido las condiciones anteriores.
⚠️ Atención

En una cadena de if...else if, el orden de las condiciones puede cambiar el resultado.

3.5 La estructura switch

switch permite seleccionar una alternativa comparando una expresión con diferentes valores concretos.

Elemento Función
switch Indica el valor o expresión que queremos comparar.
case Define cada uno de los valores posibles.
break Finaliza el switch después de ejecutar un caso.
default Se ejecuta cuando ningún case coincide.
📌 switch o if...else if

switch resulta especialmente cómodo cuando comparamos un mismo valor con varias opciones concretas. Para condiciones complejas, rangos o combinaciones lógicas, normalmente resulta más flexible if...else if.

3.6 Introducción a los bucles

Los bucles permiten repetir un conjunto de instrucciones sin tener que escribirlas varias veces.

Inicialización Establece el valor inicial utilizado para controlar la repetición.
Condición Determina si el bucle debe continuar ejecutándose.
Actualización Modifica el valor de control para que el bucle pueda avanzar.
Iteración Cada ejecución completa del cuerpo del bucle.
⚠️ Bucle infinito

Si la condición nunca llega a ser falsa, el bucle puede continuar indefinidamente. Por eso debemos comprobar que existe una forma de alcanzar la condición de finalización.

3.7 El bucle for

El bucle for resulta especialmente útil cuando conocemos o podemos determinar el número de repeticiones.

1️⃣ Inicialización

Se ejecuta una vez antes de comenzar el bucle.

2️⃣ Condición

Se comprueba antes de cada iteración.

3️⃣ Actualización

Se ejecuta después de cada iteración.

💻 Estructura básica

for (let i = 1; i <= 10; i++) { ... }

📌 Recuerda

Un for puede realizar recorridos ascendentes o descendentes. Lo importante es que inicialización, condición y actualización sean coherentes entre sí.

3.8 Los bucles while y do...while

while y do...while son especialmente útiles cuando la repetición depende de que una condición continúe cumpliéndose.

Bucle Cuándo comprueba la condición Ejecución mínima
while Antes de ejecutar el bloque. Puede ejecutarse 0 veces.
do...while Después de ejecutar el bloque. Se ejecuta al menos 1 vez.
📌 Diferencia fundamental

while comprueba primero y ejecuta después; do...while ejecuta primero y comprueba después.

⚠️ Atención

En los bucles controlados por una variable debemos asegurarnos de que esa variable se actualice correctamente. De lo contrario, podemos provocar un bucle infinito.

3.9 Control de bucles con break y continue

break y continue permiten modificar el comportamiento normal de un bucle durante su ejecución.

🛑 break

Finaliza completamente el bucle y continúa con la primera instrucción situada después de él.

⏭️ continue

Interrumpe únicamente la iteración actual y permite continuar con las siguientes.

🧭 Uso responsable

Debemos utilizarlos cuando hagan el flujo del programa más claro y fácil de comprender.

⚠️ continue dentro de while

Debemos comprobar que la variable de control pueda actualizarse antes de comenzar la siguiente iteración. De lo contrario, podemos provocar un bucle infinito.

📌 Regla rápida

break = termina el bucle.
continue = salta esta iteración y continúa.

3.10 Estructuras de control anidadas

Una estructura de control está anidada cuando se encuentra dentro de otra estructura de control.

if dentro de if Permite realizar una segunda comprobación únicamente cuando se ha cumplido una condición anterior.
if dentro de un bucle Permite tomar una decisión diferente en cada iteración.
Bucles anidados El bucle interior se ejecuta completamente por cada iteración del bucle exterior.
Variables de control Cada bucle debe utilizar correctamente su propia variable de control.
📌 Bucles anidados

Si un bucle exterior realiza 3 iteraciones y el interior realiza 4 por cada una de ellas, el bloque interior se ejecutará 3 × 4 = 12 veces.

⚠️ Legibilidad

Un exceso de niveles de anidamiento puede dificultar la lectura. Utiliza una indentación clara y analiza el flujo paso a paso.

3.11 Resolución de problemas con estructuras de control

Programar no consiste únicamente en conocer la sintaxis. Antes de escribir código debemos comprender el problema y diseñar una solución.

RESOLVER UN PROBLEMA Comprender qué debe hacer el programa
↓
Datos ¿Con qué información trabajamos?
Decisiones ¿Qué condiciones debemos comprobar?
Repeticiones ¿Qué instrucciones debemos repetir?
↓
DISEÑAR EL ALGORITMO Secuencia ordenada, clara y finita de pasos
↓
PROGRAMAR → PROBAR → DEPURAR → CORREGIR

Prueba y depuración

Casos normales Comprueban el comportamiento habitual del programa.
Casos límite Comprueban valores situados antes, en y después de los límites importantes.
console.log() Permite observar valores y seguir el flujo de ejecución.
Breakpoints Permiten detener temporalmente el programa y analizar su ejecución paso a paso.
Console Permite consultar resultados, mensajes y errores.
Sources Permite examinar los archivos JavaScript y utilizar herramientas de depuración.
Tipo de error Qué ocurre
Error de sintaxis El código no respeta la sintaxis de JavaScript.
Error durante la ejecución El problema aparece mientras se está ejecutando el programa.
Error lógico El programa se ejecuta, pero produce un resultado diferente del esperado.
💻 Método de trabajo

Analizar → diseñar → programar → ejecutar → observar → probar → corregir → volver a probar.

Ideas clave de la UT3

📌 Si tuvieras que recordar solo estas ideas…
  • Las estructuras de control permiten modificar el flujo de ejecución de un programa.
  • Una condición se evalúa como true o false.
  • if ejecuta un bloque únicamente cuando se cumple una condición.
  • if...else permite elegir entre dos caminos de ejecución.
  • else if permite encadenar varias alternativas, y el orden de las condiciones importa.
  • switch resulta útil cuando comparamos un mismo valor con varias opciones concretas.
  • Los bucles permiten repetir instrucciones mientras se cumplan determinadas condiciones.
  • for es especialmente apropiado cuando conocemos o podemos determinar el número de repeticiones.
  • while comprueba la condición antes de ejecutar el bloque; do...while la comprueba después y, por tanto, se ejecuta al menos una vez.
  • break termina completamente un bucle, mientras que continue omite únicamente la iteración actual.
  • Las estructuras pueden anidarse, pero debemos mantener una indentación clara y comprender bien su orden de ejecución.
  • Antes de programar debemos identificar los datos, las decisiones y las repeticiones necesarias.
  • Un algoritmo es una secuencia ordenada, clara y finita de pasos para resolver un problema.
  • Que un programa se ejecute sin errores no garantiza que sea correcto: debemos probar también casos normales y casos límite.
  • console.log(), las DevTools, Console, Sources y los breakpoints nos ayudan a observar y depurar el programa.
  • Resolver problemas es un proceso iterativo: analizar, diseñar, programar, probar, corregir y volver a probar.
