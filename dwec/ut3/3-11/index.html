3.11 Resolución de problemas con estructuras de control

Conocer la sintaxis de las estructuras condicionales y de los bucles es importante, pero programar no consiste únicamente en saber escribir un if, un for o un while.

Cuando nos enfrentamos a un problema debemos aprender a analizarlo, identificar qué decisiones y repeticiones necesitamos y diseñar una solución antes de escribir el código.

📌 Importante

Antes de programar debemos comprender qué queremos resolver. Una buena solución comienza analizando el problema y diseñando los pasos que deberá seguir el programa.

Analizar el problema

El primer paso consiste en leer detenidamente el enunciado y determinar qué debe hacer exactamente el programa.

Por ejemplo, supongamos que queremos resolver el siguiente problema:

💻 Problema

Mostrar los números del 1 al 10 e indicar para cada uno si es par o impar.

Antes de escribir JavaScript podemos preguntarnos qué información tenemos, qué debemos repetir y qué decisión debemos tomar.

⚠️ Atención

Empezar a escribir código sin haber comprendido previamente el problema suele provocar soluciones innecesariamente complicadas y hace más difícil detectar los errores.

Identificar los datos

Una vez comprendido el problema debemos identificar los datos que necesita utilizar el programa.

En nuestro ejemplo necesitamos trabajar con los números comprendidos entre 1 y 10.

También necesitaremos una variable que represente el número que estamos comprobando en cada momento.

📌 Importante

Identificar correctamente los datos ayuda a decidir qué variables necesitaremos y qué valores deberán almacenar durante la ejecución del programa.

Identificar las decisiones

A continuación debemos preguntarnos si el programa necesita tomar alguna decisión.

En nuestro ejemplo necesitamos decidir si cada número es par o impar. Para ello podemos comprobar el resto de su división entre 2.

JavaScript 
if (numero % 2 === 0) {
  console.log(numero + " es par");
} else {
  console.log(numero + " es impar");
}

La estructura if...else representa precisamente la decisión que habíamos identificado durante el análisis.

Identificar las repeticiones

También debemos comprobar si existen instrucciones que tengan que ejecutarse varias veces.

En nuestro problema debemos realizar la misma comprobación para los números del 1 al 10.

Como conocemos de antemano cuántas iteraciones necesitamos, un bucle for resulta adecuado:

JavaScript 
for (let numero = 1; numero <= 10; numero++) {
  // Comprobar el número
}
💻 Recuerda

Si conocemos cuántas veces queremos repetir una operación, normalmente for es una buena opción. Si la repetición depende de que una condición siga cumpliéndose, puede ser más apropiado utilizar while o do...while.

Diseñar el algoritmo

Una vez identificados los datos, las decisiones y las repeticiones, podemos establecer los pasos que debe seguir el programa.

Esta secuencia de pasos constituye el algoritmo.

📌 Algoritmo

Un algoritmo es una secuencia ordenada de pasos que permite resolver un problema.

Para nuestro ejemplo podríamos diseñar el siguiente algoritmo:

  1. Comenzar con el número 1.
  2. Comprobar si el número es par.
  3. Si es par, mostrar que es par.
  4. En caso contrario, mostrar que es impar.
  5. Aumentar el número en una unidad.
  6. Repetir el proceso hasta llegar al número 10.

Todavía no estamos escribiendo el programa completo. Primero estamos organizando la solución de forma lógica.

Traducirlo a JavaScript

Una vez diseñado el algoritmo podemos traducir cada uno de sus pasos a las estructuras de JavaScript que ya conocemos.

JavaScript 
for (let numero = 1; numero <= 10; numero++) {

  if (numero % 2 === 0) {
    console.log(numero + " es par");
  } else {
    console.log(numero + " es impar");
  }

}

La consola mostrará:

Console 
1 es impar
2 es par
3 es impar
4 es par
5 es impar
6 es par
7 es impar
8 es par
9 es impar
10 es par
💻 Ejemplo DAW

En desarrollo web tendremos que resolver continuamente problemas de este tipo: comprobar datos, decidir qué acción realizar, repetir operaciones o combinar varias estructuras. Analizar el problema antes de programarlo ayuda a construir aplicaciones más claras y fáciles de mantener.

Probar casos

Que un programa se ejecute sin mostrar errores no significa necesariamente que funcione correctamente.

Debemos probar diferentes valores y comprobar que el resultado obtenido coincide con el esperado.

Valor Resultado esperado
1 Impar
2 Par
9 Impar
10 Par

Casos límite

Es especialmente importante comprobar los valores que se encuentran en los límites de una condición.

Observa este ejemplo:

JavaScript 
let edad = 18;

if (edad >= 18) {
  console.log("Puede acceder");
} else {
  console.log("No puede acceder");
}

En este caso conviene probar, como mínimo, valores como 17, 18 y 19.

📌 Importante

No pruebes únicamente valores que sabes que funcionarán. Prueba también valores situados justo antes, justo en el límite y justo después de las condiciones importantes del programa.

Depurar y corregir

Cuando un programa no produce el resultado esperado debemos localizar la causa del problema. Este proceso se denomina depuración.

Durante la depuración podemos comprobar el valor de las variables y observar qué instrucciones se están ejecutando.

Utilizar console.log()

Una de las técnicas más sencillas consiste en utilizar console.log() para observar los valores que toman las variables durante la ejecución.

JavaScript 
for (let numero = 1; numero <= 5; numero++) {

  console.log("Valor de numero:", numero);

  if (numero % 2 === 0) {
    console.log("La condición es true");
  } else {
    console.log("La condición es false");
  }

}

Estos mensajes permiten seguir el flujo del programa y comprobar qué está ocurriendo en cada iteración.

Utilizar las herramientas del navegador

Los navegadores incorporan herramientas de desarrollo que permiten analizar y depurar JavaScript.

Podemos abrir las DevTools del navegador y utilizar principalmente las pestañas Console y Sources.

Herramienta Utilidad
Console Permite ver mensajes, resultados y errores producidos por JavaScript.
Sources Permite examinar los archivos JavaScript y detener la ejecución del programa.
Breakpoints Permiten detener temporalmente la ejecución en una línea concreta para analizar el estado del programa.

Utilizar un breakpoint

Un breakpoint o punto de interrupción permite detener temporalmente la ejecución del programa en una línea determinada.

Mientras el programa está detenido podemos observar los valores de las variables y avanzar por el código paso a paso.

💻 Prueba en el navegador

Abre las herramientas de desarrollo, entra en Sources, localiza tu archivo JavaScript y pulsa sobre el número de una línea para crear un breakpoint. Después recarga la página y observa cómo la ejecución se detiene al llegar a esa línea.

Tipos de errores

Durante el desarrollo podemos encontrarnos con diferentes tipos de errores.

Tipo Qué ocurre
Error de sintaxis El código no respeta la sintaxis de JavaScript y no puede interpretarse correctamente.
Error durante la ejecución El problema aparece mientras se está ejecutando el programa.
Error lógico El programa se ejecuta, pero el resultado obtenido no es el que esperábamos.
⚠️ Atención

Los errores lógicos pueden ser especialmente difíciles de detectar porque el programa puede ejecutarse sin mostrar ningún mensaje de error. Por eso es fundamental probar diferentes casos y comprobar los resultados.

Ciclo de resolución de problemas

Durante la programación es habitual repetir varias veces el mismo proceso:

📌 Método de trabajo

Analizar → diseñar → programar → ejecutar → observar → probar → corregir → volver a probar.

Encontrar un error no significa que el proceso haya fallado. Detectar, comprender y corregir errores forma parte normal del desarrollo de software.

🧠 Comprueba lo aprendido

Observa el siguiente problema:

Problema

Mostrar los números del 1 al 20 que sean múltiplos de 3.

Antes de escribir el programa, responde:

  1. ¿Qué datos necesitamos?
  2. ¿Existe alguna repetición?
  3. ¿Qué estructura repetitiva utilizarías?
  4. ¿Qué decisión debe tomar el programa?
  5. ¿Qué condición utilizarías para saber si un número es múltiplo de 3?
Ver solución

Necesitamos recorrer los números del 1 al 20, por lo que podemos utilizar un for. En cada iteración comprobaremos si el resto de dividir el número entre 3 es igual a 0.

JavaScript 
for (let numero = 1; numero <= 20; numero++) {

  if (numero % 3 === 0) {
    console.log(numero);
  }

}

💻 Práctica de resolución de problemas

Ejercicio 1

Diseña un programa que recorra los números del 1 al 20 y muestre únicamente los números pares. Antes de programarlo, identifica la repetición y la condición necesarias.

Ejercicio 2

Diseña un programa que recorra los números del 1 al 15 y muestre para cada número si es divisible entre 3 o no.

Ejercicio 3

Crea un programa que muestre los números del 10 al 1 en orden descendente y, al terminar, muestre el mensaje "Fin".

Ejercicio 4

Analiza y programa una solución que recorra los números del 1 al 20, ignore el número 10 utilizando continue y detenga completamente el bucle cuando llegue al número 16.

Ejercicio 5

Diseña un programa con dos bucles anidados. El bucle exterior debe representar 3 filas y el interior 4 columnas. Muestra por consola cada combinación de fila y columna.

📌 Recuerda

Resolver un problema de programación no comienza escribiendo código. Primero debemos comprender el problema, identificar los datos, localizar las decisiones y repeticiones, diseñar el algoritmo, traducirlo a JavaScript y, finalmente, probar y depurar nuestra solución.
