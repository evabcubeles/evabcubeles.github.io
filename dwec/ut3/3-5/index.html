3.5 La estructura switch

En el apartado anterior aprendimos a utilizar if...else if...else para elegir entre varias alternativas. Sin embargo, existen situaciones en las que todas las decisiones consisten en comparar una misma expresión con distintos valores concretos.

Para estos casos JavaScript dispone de la estructura switch, que permite organizar varias alternativas de una forma clara y sencilla.

📌 Importante

La estructura switch permite comparar el resultado de una expresión con diferentes valores. Cuando encuentra una coincidencia, ejecuta las instrucciones asociadas a ese case.

Cuándo utilizar switch

Imagina que queremos mostrar un mensaje diferente dependiendo del día de la semana almacenado en una variable.

Podríamos resolverlo mediante una cadena if...else if:

JavaScript 
const dia = 2;

if (dia === 1) {
  console.log("Lunes");
} else if (dia === 2) {
  console.log("Martes");
} else if (dia === 3) {
  console.log("Miércoles");
} else {
  console.log("Otro día");
}

Esta solución es correcta. Sin embargo, todas las condiciones realizan el mismo tipo de comprobación:

  • dia === 1
  • dia === 2
  • dia === 3

Es decir, estamos comparando la misma variable con diferentes valores concretos.

📌 Importante

Esto no significa que siempre debamos utilizar switch cuando comparemos valores concretos. Ambas soluciones pueden ser correctas. switch resulta especialmente útil cuando queremos expresar de forma clara varias alternativas basadas en distintos valores de una misma expresión.

En este tipo de situaciones podemos expresar la decisión mediante switch:

JavaScript 
const dia = 2;

switch (dia) {
  case 1:
    console.log("Lunes");
    break;

  case 2:
    console.log("Martes");
    break;

  case 3:
    console.log("Miércoles");
    break;

  default:
    console.log("Otro día");
}

Como el valor de dia es 2, JavaScript encuentra el case 2 y muestra:

Console 
Martes
💻 Ejemplo DAW

En una aplicación web podemos utilizar switch para procesar estados concretos de un pedido, tipos de usuario, opciones seleccionadas en un menú, códigos de operación o cualquier situación en la que una misma expresión pueda tomar varios valores determinados.

Sintaxis de switch

La estructura general de switch es la siguiente:

JavaScript 
switch (expresión) {
  case valor1:
    // Instrucciones
    break;

  case valor2:
    // Instrucciones
    break;

  default:
    // Instrucciones
}

Su funcionamiento puede resumirse en los siguientes pasos:

  • JavaScript evalúa una sola vez la expresión situada entre los paréntesis de switch.
  • Compara el resultado con los valores indicados en cada case.
  • Cuando encuentra una coincidencia, comienza a ejecutar las instrucciones de ese punto.
  • Normalmente utilizamos break para salir de la estructura después de ejecutar el bloque correspondiente.
  • Si ningún case coincide, puede ejecutarse el bloque default.
📌 Importante

switch compara el resultado de la expresión con los valores de los distintos case. Estas comparaciones son estrictas, por lo que también debe coincidir el tipo de dato.

Observa este ejemplo:

JavaScript 
const opcion = "1";

switch (opcion) {
  case 1:
    console.log("Opción numérica");
    break;

  case "1":
    console.log("Opción de texto");
    break;
}

El resultado será:

Console 
Opción de texto

El texto "1" y el número 1 no son el mismo valor para esta comparación.

case

Cada palabra reservada case representa uno de los posibles valores que queremos comprobar.

Observa:

JavaScript 
const estado = "enviado";

switch (estado) {
  case "pendiente":
    console.log("El pedido está pendiente");
    break;

  case "preparando":
    console.log("El pedido se está preparando");
    break;

  case "enviado":
    console.log("El pedido ha sido enviado");
    break;

  case "entregado":
    console.log("El pedido ha sido entregado");
    break;
}

JavaScript evalúa el valor de estado y lo compara con cada uno de los valores indicados después de case.

Como:

JavaScript 
estado === "enviado"

es verdadero, el programa muestra:

Console 
El pedido ha sido enviado
⚠️ Atención

Después del valor de un case escribimos dos puntos (:), no punto y coma. Las instrucciones correspondientes se escriben a continuación.

break

En los ejemplos anteriores hemos escrito break al final de cada case. Su función es interrumpir la ejecución del switch cuando ya hemos realizado la acción correspondiente.

Observa:

JavaScript 
const opcion = 2;

switch (opcion) {
  case 1:
    console.log("Has elegido la opción 1");
    break;

  case 2:
    console.log("Has elegido la opción 2");
    break;

  case 3:
    console.log("Has elegido la opción 3");
    break;
}

El resultado será:

Console 
Has elegido la opción 2

Cuando JavaScript ejecuta break, abandona el switch y continúa ejecutando las instrucciones que aparezcan después de la estructura.

¿Qué ocurre si olvidamos break?

Si eliminamos break, JavaScript no se detiene automáticamente al terminar las instrucciones del case que ha coincidido.

Observa:

JavaScript - Sin break 
const opcion = 2;

switch (opcion) {
  case 1:
    console.log("Opción 1");

  case 2:
    console.log("Opción 2");

  case 3:
    console.log("Opción 3");

  default:
    console.log("Fin del switch");
}

Como el valor es 2, la ejecución comienza en case 2. Pero, al no encontrar ningún break, continúa ejecutando los bloques siguientes.

El resultado será:

Console 
Opción 2
Opción 3
Fin del switch
⚠️ Atención

Olvidar break es uno de los errores más frecuentes al comenzar a utilizar switch. Sin break, la ejecución continúa por los case siguientes hasta encontrar un break o llegar al final del switch.

Este comportamiento se denomina habitualmente fall-through. Aunque puede utilizarse de forma intencionada, al principio emplearemos normalmente break para que cada alternativa quede claramente separada.

default

El bloque default permite indicar qué debe ocurrir cuando ninguno de los case coincide con el valor evaluado.

Su función es similar a la alternativa final else de una estructura if...else if...else.

JavaScript 
const dia = 8;

switch (dia) {
  case 1:
    console.log("Lunes");
    break;

  case 2:
    console.log("Martes");
    break;

  case 3:
    console.log("Miércoles");
    break;

  default:
    console.log("Día no válido");
}

Como 8 no coincide con ninguno de los case, el resultado será:

Console 
Día no válido
📌 Importante

default no es obligatorio. Lo utilizaremos cuando queramos establecer una respuesta para todos los valores que no coincidan con ninguno de los case anteriores.

Varios case para una misma acción

En ocasiones queremos ejecutar exactamente las mismas instrucciones para varios valores diferentes.

Podemos conseguirlo colocando varios case seguidos antes del mismo bloque de instrucciones.

Por ejemplo, podemos distinguir entre días laborables y fin de semana:

JavaScript 
const dia = "sábado";

switch (dia) {
  case "lunes":
  case "martes":
  case "miércoles":
  case "jueves":
  case "viernes":
    console.log("Día laborable");
    break;

  case "sábado":
  case "domingo":
    console.log("Fin de semana");
    break;

  default:
    console.log("Día no válido");
}

Como dia contiene "sábado", JavaScript comienza a ejecutar las instrucciones asociadas a ese grupo de casos y muestra:

Console 
Fin de semana

Observa que los case agrupados no contienen instrucciones ni break entre ellos. Todos conducen al mismo bloque.

💻 Ejemplo DAW

Esta técnica puede ser útil cuando varios estados de una aplicación deben producir la misma respuesta. Por ejemplo, diferentes tipos de usuario podrían compartir permisos o varios códigos de operación podrían mostrar el mismo mensaje.

switch frente a if...else if

Tanto switch como if...else if permiten elegir entre varias alternativas, pero no se utilizan exactamente en las mismas situaciones.

Situación Estructura más adecuada
Comparar una misma expresión con varios valores concretos switch
Comprobar rangos de valores if...else if
Utilizar operadores como >, <, >= o <= if...else if
Combinar varias condiciones mediante &&, || o ! if...else if
Seleccionar una opción entre varios valores exactos switch puede resultar más claro

Ejemplo adecuado para switch

JavaScript 
const rol = "profesor";

switch (rol) {
  case "administrador":
    console.log("Acceso de administrador");
    break;

  case "profesor":
    console.log("Acceso de profesor");
    break;

  case "alumno":
    console.log("Acceso de alumno");
    break;

  default:
    console.log("Rol desconocido");
}

Estamos comparando la misma variable, rol, con varios valores concretos.

Ejemplo más adecuado para if...else if

JavaScript 
const nota = 8;

if (nota >= 9) {
  console.log("Sobresaliente");
} else if (nota >= 7) {
  console.log("Notable");
} else if (nota >= 5) {
  console.log("Aprobado");
} else {
  console.log("No aprobado");
}

En este caso estamos trabajando con rangos de valores. Por ello, if...else if expresa la decisión de forma más natural.

⚠️ Atención

switch no sustituye siempre a if...else if. La elección depende del tipo de condición que necesitemos expresar. Si trabajamos con rangos o condiciones complejas, normalmente utilizaremos if...else if.

JavaScript

console.log("Inicio");

  case "A":
    console.log("Opción A");
    break;

  case "B":
    console.log("Opción B");
    break;

  case "C":
    console.log("Opción C");
    break;

  default:
    console.log("Opción desconocida");
}

console.log("Fin");
Ver solución

El valor de opcion es "B".

El primer case no coincide. El segundo sí coincide, por lo que se ejecuta console.log("Opción B").

Después se encuentra break, por lo que JavaScript abandona el switch.

En Console aparecerá:

Console 
Inicio
Opción B
Fin

💻 Práctica con switch

Crea un archivo JavaScript y resuelve los siguientes ejercicios. Antes de ejecutar cada programa, intenta predecir qué case se ejecutará.

  • Declara una constante dia con valor 3. Utiliza switch para mostrar "Lunes", "Martes", "Miércoles", "Jueves" o "Viernes" para los valores del 1 al 5. Para cualquier otro valor muestra "Día no válido".
  • Declara una constante color con valor "verde". Muestra "Detenerse" para "rojo", "Precaución" para "amarillo" y "Avanzar" para "verde". Utiliza default para cualquier otro valor.
  • Declara una constante rol con valor "alumno". Muestra un mensaje diferente para los roles "administrador", "profesor" y "alumno".
  • Declara una constante diaSemana con valor "domingo". Agrupa de lunes a viernes para mostrar "Día laborable" y sábado y domingo para mostrar "Fin de semana".

📌 Recuerda

Utilizamos switch principalmente cuando queremos comparar una misma expresión con varios valores concretos. Cada case representa una posible coincidencia, break permite salir de la estructura y default establece una alternativa cuando ningún caso coincide. Para rangos de valores o condiciones más complejas suele ser más apropiado utilizar if...else if.
