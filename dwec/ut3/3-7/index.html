3.7 El bucle for

En el apartado anterior hemos aprendido que los bucles permiten repetir un bloque de instrucciones varias veces. También hemos visto que muchos bucles necesitan un valor inicial, una condición que determine hasta cuándo deben continuar y una actualización que modifique la variable de control.

Cuando conocemos de antemano cuántas veces queremos realizar una repetición, una de las estructuras más utilizadas en JavaScript es el bucle for.

Su principal ventaja es que permite reunir en una misma línea los tres elementos que normalmente controlan la repetición: inicialización, condición y actualización.

📌 Importante

El bucle for resulta especialmente útil cuando conocemos o podemos determinar el número de repeticiones que debe realizar el programa.

Sintaxis de for

La estructura general de un bucle for es la siguiente:

JavaScript 
for (inicialización; condición; actualización) {
  // Instrucciones que se repiten
}

Dentro de los paréntesis encontramos tres partes separadas por punto y coma:

Parte Función
Inicialización Establece el valor inicial de la variable que controlará el bucle.
Condición Determina si el bucle debe continuar ejecutándose.
Actualización Modifica la variable de control después de cada iteración.

Observa este primer ejemplo:

JavaScript 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

El resultado será:

Console 
1
2
3
4
5

En este ejemplo podemos identificar claramente las tres partes:

Estructura del for 
for (let i = 1; i <= 5; i++) {
     ↑          ↑       ↑
 inicialización condición actualización
}

El funcionamiento completo es:

  1. Se ejecuta la inicialización: let i = 1.
  2. Se comprueba la condición: i <= 5.
  3. Si la condición es true, se ejecuta el bloque.
  4. Se realiza la actualización: i++.
  5. Se vuelve a comprobar la condición.
  6. El proceso continúa hasta que la condición sea false.
📌 Importante

La inicialización se realiza una sola vez. La condición se comprueba antes de cada iteración y la actualización se ejecuta después de cada iteración.

Inicialización

La primera parte del for establece normalmente el valor inicial de la variable que utilizará el bucle para controlar las repeticiones.

Por ejemplo:

JavaScript 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

La inicialización es:

JavaScript 
let i = 1;

Esto significa que el contador comienza con el valor 1.

También podríamos comenzar desde otro valor:

JavaScript 
for (let i = 5; i <= 10; i++) {
  console.log(i);
}

En este caso, el primer valor mostrado será 5.

⚠️ Atención

El contador no tiene que comenzar siempre en 0 ni en 1. Su valor inicial dependerá del problema que queramos resolver.

En muchos ejemplos encontraremos la variable i. Esta letra suele utilizarse como abreviatura de índice o como variable de control de una iteración.

Sin embargo, podemos utilizar un nombre más descriptivo cuando ayude a comprender mejor el código:

JavaScript 
for (let intento = 1; intento <= 3; intento++) {
  console.log("Intento " + intento);
}

El resultado será:

Console 
Intento 1
Intento 2
Intento 3

Condición

La segunda parte del for contiene la condición que determina si el bucle debe continuar ejecutándose.

En el siguiente ejemplo:

JavaScript 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

la condición es:

JavaScript 
i <= 5

Antes de cada iteración JavaScript evalúa esta expresión.

Valor de i i <= 5 ¿Se ejecuta el bloque?
1 true Sí
2 true Sí
3 true Sí
4 true Sí
5 true Sí
6 false No

Cuando i llega a 6, la expresión 6 <= 5 es falsa y el bucle termina.

📌 Importante

La condición del for se comprueba antes de ejecutar cada iteración. Si desde el principio es falsa, el bloque no se ejecutará ninguna vez.

Por ejemplo:

JavaScript 
for (let i = 10; i <= 5; i++) {
  console.log(i);
}

console.log("Fin");

La condición 10 <= 5 es falsa desde el principio. Por tanto, el bloque del bucle no se ejecuta y únicamente veremos:

Console 
Fin

Actualización

La tercera parte del for indica cómo debe modificarse la variable de control después de cada iteración.

En nuestro ejemplo:

JavaScript 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

la actualización es:

JavaScript 
i++

Después de cada iteración, el valor de i aumenta en una unidad:

Evolución de i 
1 → 2 → 3 → 4 → 5 → 6

Como vimos en el apartado anterior:

JavaScript 
i++

equivale, en este contexto, a:

JavaScript 
i = i + 1;

Pero la actualización no tiene que realizarse siempre de uno en uno. Podemos avanzar, por ejemplo, de dos en dos:

JavaScript 
for (let i = 0; i <= 10; i += 2) {
  console.log(i);
}

El resultado será:

Console 
0
2
4
6
8
10
⚠️ Atención

La actualización debe hacer que el bucle se acerque a su condición de finalización. Una actualización incorrecta puede provocar que el bucle no termine.

Contadores

La variable utilizada para controlar las iteraciones suele actuar como contador.

Podemos utilizar su valor dentro del propio bloque del for.

Por ejemplo:

JavaScript 
for (let i = 1; i <= 4; i++) {
  console.log("Iteración número " + i);
}

El resultado será:

Console 
Iteración número 1
Iteración número 2
Iteración número 3
Iteración número 4

En cada iteración el valor de i es diferente. Esto nos permite utilizar el contador para realizar cálculos.

Por ejemplo, podemos mostrar la tabla de multiplicar del 5:

JavaScript 
for (let i = 1; i <= 10; i++) {
  console.log("5 x " + i + " = " + (5 * i));
}

El resultado comienza así:

Console 
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
...
5 x 10 = 50
💻 Ejemplo DAW

Más adelante utilizaremos contadores e índices para trabajar con colecciones de datos, generar elementos de una interfaz o procesar información repetitiva. Por ahora nos centraremos en comprender correctamente el funcionamiento del bucle.

Recorridos ascendentes

Un recorrido ascendente es aquel en el que la variable de control aumenta progresivamente.

El ejemplo más sencillo es contar del 1 al 5:

JavaScript 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

El contador evoluciona de esta forma:

Evolución 
1 → 2 → 3 → 4 → 5

También podemos comenzar desde 0:

JavaScript 
for (let i = 0; i < 5; i++) {
  console.log(i);
}

En este caso el resultado es:

Console 
0
1
2
3
4
⚠️ Atención

Observa la diferencia entre i < 5 e i <= 5. Con i < 5, el valor 5 no se incluye. Este tipo de detalle es una causa frecuente de errores en los bucles.

También podemos realizar saltos mayores:

JavaScript 
for (let i = 0; i <= 20; i += 5) {
  console.log(i);
}

El resultado será:

Console 
0
5
10
15
20

Recorridos descendentes

Un bucle for también puede realizar un recorrido descendente. En este caso la variable de control disminuye después de cada iteración.

Por ejemplo, podemos realizar una cuenta atrás:

JavaScript 
for (let i = 5; i >= 1; i--) {
  console.log(i);
}

console.log("¡Despegue!");

El resultado será:

Console 
5
4
3
2
1
¡Despegue!

En este caso:

  • el contador comienza en 5;
  • el bucle continúa mientras i >= 1;
  • después de cada iteración se ejecuta i--.

La evolución del contador es:

Evolución 
5 → 4 → 3 → 2 → 1 → 0

Cuando i vale 0, la condición 0 >= 1 es falsa y el bucle termina.

También podemos descender de dos en dos:

JavaScript 
for (let i = 10; i >= 0; i -= 2) {
  console.log(i);
}

El resultado será:

Console 
10
8
6
4
2
0

Errores frecuentes

Al comenzar a trabajar con for es habitual cometer algunos errores relacionados con la condición o con la actualización del contador.

1. Utilizar una condición incorrecta

Supongamos que queremos mostrar los números del 1 al 5:

JavaScript 
for (let i = 1; i < 5; i++) {
  console.log(i);
}

Este código mostrará:

Console 
1
2
3
4

Si queremos incluir también el 5, debemos utilizar:

JavaScript 
i <= 5

2. Actualizar el contador en la dirección equivocada

Observa este código:

JavaScript 
for (let i = 1; i <= 5; i--) {
  console.log(i);
}

El contador comienza en 1, pero en lugar de aumentar, disminuye:

Evolución 
1 → 0 → -1 → -2 → -3 → ...

La condición i <= 5 continúa siendo verdadera, por lo que el bucle no alcanza su finalización.

⚠️ Atención

No ejecutes intencionadamente un bucle infinito. Puede provocar que la pestaña del navegador deje de responder. Antes de ejecutar un bucle, comprueba siempre que la actualización acerca la variable de control al final de la repetición.

3. Añadir un punto y coma después del for

Observa:

JavaScript 
for (let i = 1; i <= 3; i++); {
  console.log("Hola");
}

El punto y coma situado justo después del paréntesis termina la instrucción for. Por tanto, el bloque que aparece después ya no forma parte del bucle.

La forma correcta es:

JavaScript 
for (let i = 1; i <= 3; i++) {
  console.log("Hola");
}

4. Confundir el último valor ejecutado con el valor que hace terminar el bucle

Observa este ejemplo:

JavaScript 
for (let i = 1; i <= 3; i++) {
  console.log(i);
}

El bloque se ejecuta con los valores 1, 2 y 3. Después de la tercera iteración se ejecuta i++, por lo que i pasa a valer 4. A continuación se comprueba de nuevo la condición. Como 4 <= 3 es false, el bucle termina. Por tanto, el último valor con el que se ejecuta el bloque es 3, aunque la condición deja de cumplirse cuando el contador alcanza el valor 4.

📌 Importante

Para analizar correctamente un for, sigue siempre este orden: inicialización → condición → bloque → actualización → condición → bloque → actualización...

JavaScript

}

console.log("Fin");

  • el valor inicial;
  • la condición;
  • la actualización;
  • los valores que tomará i.
Ver solución

Por tanto, la consola mostrará:

8
Fin

📌 Recuerda

El bucle for reúne tres elementos fundamentales: inicialización → condición → actualización. La inicialización se ejecuta una sola vez, la condición se comprueba antes de cada iteración y la actualización se realiza después de ejecutar el bloque. Antes de ejecutar un bucle, comprueba siempre que la variable de control avanza hacia una situación en la que la condición llegue a ser falsa.
