3.3 Alternativas con if...else

En el apartado anterior aprendimos a utilizar if para ejecutar un bloque de instrucciones cuando una condición es verdadera. Sin embargo, muchas decisiones necesitan contemplar también qué debe ocurrir cuando la condición no se cumple.

Para resolver estas situaciones utilizamos la estructura if...else, que permite establecer dos caminos alternativos de ejecución.

📌 Importante

Una estructura if...else permite elegir entre dos alternativas: si la condición es verdadera se ejecuta el bloque del if; si es falsa se ejecuta el bloque del else.

Dos caminos de ejecución

Con una sentencia if simple solo indicamos qué debe hacer el programa cuando se cumple una condición. Si la condición es falsa, ese bloque se omite y el programa continúa.

En muchas situaciones necesitamos definir también una acción para el caso contrario.

Imagina que queremos comprobar si una persona es mayor de edad:

JavaScript 
const edad = 16;

if (edad >= 18) {
  console.log("Es mayor de edad");
}

Como la condición es falsa, este programa no mostrará ningún mensaje. Pero quizá queremos informar también de que la persona es menor de edad.

Para ello necesitamos establecer una segunda alternativa:

JavaScript 
const edad = 16;

if (edad >= 18) {
  console.log("Es mayor de edad");
} else {
  console.log("Es menor de edad");
}

Ahora siempre se ejecutará uno de los dos bloques:

  • Si edad >= 18 es true, se ejecutará el bloque del if.
  • Si edad >= 18 es false, se ejecutará el bloque del else.
💻 Ejemplo DAW

En una aplicación web podemos utilizar if...else para decidir entre dos comportamientos: permitir o denegar un acceso, indicar si existe o no stock, comprobar si una sesión está iniciada o mostrar un mensaje diferente dependiendo de una condición.

Sintaxis de if...else

La estructura general de if...else es la siguiente:

JavaScript 
if (condición) {
  // Instrucciones si la condición es true
} else {
  // Instrucciones si la condición es false
}
Elemento Función
if Inicia la estructura y contiene la condición que se evaluará.
(condición) Expresión cuyo resultado determinará qué bloque se ejecuta.
Primer { } Contiene las instrucciones que se ejecutan cuando la condición es verdadera.
else Introduce la alternativa que se ejecutará cuando la condición sea falsa.
Segundo { } Contiene las instrucciones que se ejecutan cuando la condición es falsa.
📌 Importante

En una estructura if...else se ejecuta un bloque u otro, pero nunca los dos para una misma evaluación de la condición.

Funcionamiento paso a paso

Para comprender correctamente una estructura if...else conviene seguir siempre el mismo razonamiento.

Observa este programa:

JavaScript 
const nota = 7;

console.log("Comprobando resultado...");

if (nota >= 5) {
  console.log("Asignatura superada");
} else {
  console.log("Asignatura no superada");
}

console.log("Fin del programa");

JavaScript realiza el siguiente proceso:

  • Evalúa la condición nota >= 5.
  • Como 7 >= 5 produce true, entra en el bloque del if.
  • Ejecuta console.log("Asignatura superada").
  • Omite completamente el bloque del else.
  • Continúa ejecutando las instrucciones situadas después de la estructura condicional.

El resultado será:

Console 
Comprobando resultado...
Asignatura superada
Fin del programa

Si cambiamos el valor:

JavaScript 
const nota = 3;

if (nota >= 5) {
  console.log("Asignatura superada");
} else {
  console.log("Asignatura no superada");
}

La condición será false, por lo que JavaScript omitirá el bloque del if y ejecutará el bloque del else.

Console 
Asignatura no superada
⚠️ Atención

else no lleva una nueva condición entre paréntesis. Representa directamente el caso contrario: se ejecuta cuando la condición del if ha producido false.

Condiciones con operadores lógicos

La condición de una estructura if...else puede combinar varias comprobaciones mediante los operadores lógicos &&, || y !.

Utilizar &&

El operador && permite exigir que se cumplan varias condiciones al mismo tiempo.

JavaScript 
const edad = 20;
const tieneEntrada = true;

if (edad >= 18 && tieneEntrada) {
  console.log("Acceso permitido");
} else {
  console.log("Acceso denegado");
}

Para que aparezca "Acceso permitido" deben cumplirse las dos condiciones. Si al menos una es falsa, se ejecutará el else.

Utilizar ||

El operador || permite que sea suficiente con que se cumpla al menos una de las condiciones.

JavaScript 
const esAdministrador = false;
const esProfesor = true;

if (esAdministrador || esProfesor) {
  console.log("Puede acceder al panel");
} else {
  console.log("No tiene permisos");
}

Utilizar !

El operador ! permite negar un valor booleano.

JavaScript 
const sesionIniciada = false;

if (!sesionIniciada) {
  console.log("Debes iniciar sesión");
} else {
  console.log("Bienvenido");
}

Como sesionIniciada contiene false, la expresión !sesionIniciada produce true. Por tanto, se ejecuta el primer bloque.

📌 Importante

Antes de decidir qué bloque se ejecutará, evalúa primero la condición completa. Si el resultado final es true, se ejecutará el if; si es false, se ejecutará el else.

Casos prácticos

Las estructuras if...else aparecen constantemente en las aplicaciones. Veamos algunos ejemplos sencillos.

Comprobar si existe stock

JavaScript 
const stock = 8;

if (stock > 0) {
  console.log("Producto disponible");
} else {
  console.log("Producto agotado");
}

Comprobar una contraseña

JavaScript 
const passwordCorrecta = "dwec2026";
const passwordIntroducida = "dwec2026";

if (passwordIntroducida === passwordCorrecta) {
  console.log("Contraseña correcta");
} else {
  console.log("Contraseña incorrecta");
}

Comprobar un valor introducido por el usuario

También podemos combinar if...else con prompt(). Recuerda que prompt() devuelve inicialmente una cadena de texto.

JavaScript 
const edadTexto = prompt("Introduce tu edad:");
const edad = Number(edadTexto);

if (edad >= 18) {
  console.log("Puedes acceder");
} else {
  console.log("No puedes acceder");
}

Primero obtenemos el dato mediante prompt() y después lo convertimos explícitamente a número mediante Number(). Finalmente, utilizamos ese valor en la condición.

💻 Ejemplo DAW

Este patrón aparece con frecuencia en aplicaciones web: obtenemos un dato, comprobamos una condición y elegimos entre dos posibles respuestas. Más adelante utilizaremos estas decisiones junto con formularios, eventos y elementos de una página web.

Errores frecuentes

Al utilizar if...else debemos prestar atención a la estructura del código y a la relación entre ambos bloques.

Escribir una condición después de else

Un else simple no lleva condición.

JavaScript - Incorrecto 
if (edad >= 18) {
  console.log("Mayor de edad");
} else (edad < 18) {
  console.log("Menor de edad");
}

La forma correcta es:

JavaScript - Correcto 
if (edad >= 18) {
  console.log("Mayor de edad");
} else {
  console.log("Menor de edad");
}

Utilizar dos if cuando queremos dos alternativas

Observa este código:

JavaScript 
const edad = 20;

if (edad >= 18) {
  console.log("Mayor de edad");
}

if (edad < 18) {
  console.log("Menor de edad");
}

Este código puede funcionar, pero JavaScript evalúa dos condiciones independientes. Si estamos representando exactamente dos alternativas opuestas, resulta más claro utilizar una única estructura if...else.

JavaScript 
const edad = 20;

if (edad >= 18) {
  console.log("Mayor de edad");
} else {
  console.log("Menor de edad");
}

Colocar incorrectamente las llaves

El bloque del if debe cerrarse antes de escribir else. Después, el bloque del else tendrá sus propias llaves.

JavaScript 
if (condición) {
  // Primer bloque
} else {
  // Segundo bloque
}

Olvidar que solo se ejecuta una alternativa

Si la condición es verdadera, JavaScript ejecuta el bloque del if y omite el else. Si es falsa, ocurre exactamente lo contrario.

⚠️ Atención

No debemos interpretar if y else como dos comprobaciones independientes. Forman parte de una misma decisión y representan dos caminos alternativos.

🧠 Comprueba lo aprendido

Sin ejecutar el código, indica qué aparecerá en Console.

JavaScript 
const edad = 19;
const tieneEntrada = false;

console.log("Inicio");

if (edad >= 18 && tieneEntrada) {
  console.log("Acceso permitido");
} else {
  console.log("Acceso denegado");
}

console.log("Fin");
Ver solución

La expresión edad >= 18 es true, pero tieneEntrada contiene false.

Como utilizamos &&, las dos condiciones deben ser verdaderas. La condición completa produce false, por lo que se ejecuta el bloque del else.

En Console aparecerá:

Console 
Inicio
Acceso denegado
Fin

💻 Práctica con if...else

Crea un archivo JavaScript y resuelve los siguientes ejercicios. Antes de ejecutar cada programa, intenta predecir qué bloque se ejecutará.

  • Declara una constante numero con valor 8. Muestra "Número positivo" si es mayor que 0 y "Número no positivo" en caso contrario.
  • Declara una constante nota con valor 4. Muestra "Aprobado" si la nota es mayor o igual que 5 y "No aprobado" en caso contrario.
  • Declara una constante booleana usuarioRegistrado. Si es verdadera, muestra "Bienvenido"; en caso contrario, muestra "Debes registrarte".
  • Declara edad = 22 y tieneEntrada = false. Utiliza && para mostrar "Acceso permitido" únicamente cuando se cumplan ambas condiciones. En caso contrario, muestra "Acceso denegado".
Ver solución

if (numero > 0) {
  console.log("Número positivo");
} else {
  console.log("Número no positivo");

} else {

}

  console.log("Bienvenido");

📌 Recuerda

Utilizamos if cuando queremos ejecutar unas instrucciones únicamente si se cumple una condición. Utilizamos if...else cuando necesitamos elegir entre dos alternativas. En el siguiente apartado aprenderemos a resolver decisiones con más de dos posibilidades mediante else if.
