3.8 Los bucles while y do...while

En el apartado anterior hemos aprendido a utilizar el bucle for, especialmente útil cuando conocemos o podemos determinar de antemano el número de repeticiones que debe realizar el programa.

Sin embargo, no siempre sabemos cuántas veces será necesario repetir una acción. En muchas situaciones queremos que un bloque de instrucciones continúe ejecutándose mientras se cumpla una determinada condición.

Para resolver este tipo de problemas JavaScript dispone de las estructuras while y do...while. Ambas permiten repetir instrucciones en función de una condición, aunque existe una diferencia fundamental en el momento en el que dicha condición se comprueba.

📌 Importante

El bucle while comprueba la condición antes de ejecutar el bloque. El bucle do...while la comprueba después. Por este motivo, un do...while ejecutará su bloque al menos una vez.

El bucle while

El bucle while permite repetir un bloque de instrucciones mientras una condición sea verdadera.

Su estructura general es:

JavaScript 
while (condición) {
  // Instrucciones que se repiten
}

Antes de comenzar cada iteración, JavaScript evalúa la condición. Si su resultado es true, ejecuta el bloque. Cuando la condición pasa a ser false, el bucle termina.

Observa este ejemplo:

JavaScript 
let contador = 1;

while (contador <= 5) {
  console.log(contador);
  contador++;
}

El resultado será:

Console 
1
2
3
4
5

En este ejemplo encontramos los mismos elementos fundamentales que vimos al estudiar los bucles:

Elemento Código Función
Valor inicial let contador = 1 Establece el valor desde el que comienza el contador.
Condición contador <= 5 Determina si debe ejecutarse otra iteración.
Actualización contador++ Modifica el contador después de cada iteración.
⚠️ Atención

A diferencia del for, en un while la inicialización y la actualización no aparecen en la misma línea que la condición. Debemos asegurarnos de escribirlas en los lugares adecuados.

Funcionamiento paso a paso

Para comprender correctamente un while es importante seguir el orden exacto en el que se ejecutan sus instrucciones.

Partimos de este programa:

JavaScript 
let numero = 1;

while (numero <= 3) {
  console.log(numero);
  numero++;
}

console.log("Fin");

JavaScript realiza el siguiente proceso:

  1. Se crea numero con el valor 1.
  2. Se comprueba la condición numero <= 3.
  3. Como es true, se ejecuta el bloque.
  4. Se muestra el valor de numero.
  5. Se ejecuta numero++.
  6. Se vuelve a comprobar la condición.
  7. El proceso continúa mientras la condición sea verdadera.
  8. Cuando la condición es falsa, se continúa ejecutando el programa después del bucle.
Valor de numero numero <= 3 ¿Se ejecuta el bloque?
1 true Sí
2 true Sí
3 true Sí
4 false No

Por tanto, la consola mostrará:

Console 
1
2
3
Fin
📌 Importante

En un while, la condición se comprueba antes de cada iteración. Si es falsa desde el principio, el bloque no se ejecutará ninguna vez.

Por ejemplo:

JavaScript 
let numero = 10;

while (numero <= 5) {
  console.log(numero);
  numero++;
}

console.log("Fin");

La condición 10 <= 5 es false desde el principio. Por tanto, el bloque del bucle no se ejecuta y únicamente veremos:

Console 
Fin

El bucle do...while

El bucle do...while también permite repetir un bloque de instrucciones mientras se cumpla una condición.

La diferencia respecto a while es que el bloque se ejecuta antes de comprobar la condición.

Su sintaxis general es:

JavaScript 
do {
  // Instrucciones que se repiten
} while (condición);
📌 Importante

Como la condición se comprueba después de ejecutar el bloque, un do...while siempre ejecuta sus instrucciones al menos una vez.

Observa este ejemplo:

JavaScript 
let numero = 1;

do {
  console.log(numero);
  numero++;
} while (numero <= 3);

El resultado será:

Console 
1
2
3

En este caso el proceso es:

  1. Se ejecuta el bloque.
  2. Se muestra el valor de numero.
  3. Se actualiza la variable con numero++.
  4. Se comprueba la condición.
  5. Si es true, se vuelve a ejecutar el bloque.
  6. Si es false, el bucle termina.

La característica principal de do...while se observa con claridad cuando la condición es falsa desde el principio.

JavaScript 
let numero = 10;

do {
  console.log(numero);
  numero++;
} while (numero <= 5);

console.log("Fin");

Aunque numero <= 5 es falsa, el bloque se ejecuta una vez porque la condición todavía no se ha comprobado cuando se entra en él.

El resultado será:

Console 
10
Fin
⚠️ Atención

Observa el punto y coma situado después de while (condición);. Forma parte de la sintaxis de do...while y no debemos olvidarlo.

Diferencias entre while y do...while

Las dos estructuras repiten instrucciones dependiendo de una condición, pero no comprueban esa condición en el mismo momento.

Característica while do...while
Momento de comprobar la condición Antes de ejecutar el bloque. Después de ejecutar el bloque.
Mínimo de ejecuciones Puede ejecutarse 0 veces. Se ejecuta al menos 1 vez.
Uso habitual Cuando primero debemos comprobar si se cumple la condición para poder ejecutar el bloque. Cuando necesitamos realizar la acción antes de comprobar si debe repetirse.

Podemos verlo comparando dos programas prácticamente iguales.

Con while

JavaScript 
let numero = 5;

while (numero < 5) {
  console.log(numero);
  numero++;
}

No se muestra nada porque la condición 5 < 5 es falsa desde el principio.

Con do...while

JavaScript 
let numero = 5;

do {
  console.log(numero);
  numero++;
} while (numero < 5);

En este caso sí se muestra:

Console 
5

El bloque se ha ejecutado antes de comprobar la condición.

📌 Importante

La diferencia fundamental no está en la condición utilizada, sino en cuándo se evalúa: while comprueba primero y do...while ejecuta primero.

Cuándo utilizar cada uno

Elegir entre for, while y do...while depende principalmente de cómo se controla la repetición.

Situación Bucle habitual
Conocemos o podemos determinar el número de repeticiones. for
No sabemos exactamente cuántas repeticiones habrá y queremos comprobar primero una condición. while
Necesitamos ejecutar primero la acción y después decidir si debe repetirse. do...while
💻 Ejemplo DAW

Imagina una aplicación que intenta realizar una operación mientras todavía quedan intentos disponibles. El número real de iteraciones puede depender de lo que ocurra durante la ejecución. Este tipo de situación puede expresarse de forma natural mediante un while.

Por ejemplo:

JavaScript 
let intentos = 1;

while (intentos <= 3) {
  console.log("Intento " + intentos);
  intentos++;
}

console.log("Proceso finalizado");

La consola mostrará:

Console 
Intento 1
Intento 2
Intento 3
Proceso finalizado

En cambio, un do...while resulta especialmente apropiado cuando la acción debe realizarse al menos una vez antes de decidir si se repite.

📌 Importante

No existe un único tipo de bucle válido para todos los problemas. En muchos casos sería posible resolver la misma situación con estructuras diferentes. Debemos elegir la que exprese de forma más clara la lógica del programa.

Bucles controlados por condición

Los bucles while son especialmente útiles cuando la repetición depende de una condición cuyo momento de finalización no se expresa simplemente mediante un número fijo de iteraciones.

Por ejemplo, podemos repetir una operación mientras una cantidad sea inferior a un determinado límite:

JavaScript 
let saldo = 20;

while (saldo < 100) {
  saldo += 20;
  console.log("Saldo: " + saldo);
}

El resultado será:

Console 
Saldo: 40
Saldo: 60
Saldo: 80
Saldo: 100

En cada iteración cambia el valor de saldo. Cuando alcanza 100, la condición saldo < 100 pasa a ser falsa y el bucle termina.

También podemos utilizar condiciones compuestas:

JavaScript 
let intentos = 0;
let completado = false;

while (intentos < 3 && !completado) {
  console.log("Realizando intento...");
  intentos++;

  if (intentos === 2) {
    completado = true;
  }
}

console.log("Proceso terminado");

El bucle continúa mientras se cumplan simultáneamente dos condiciones: que queden intentos y que el proceso todavía no se haya completado.

En este ejemplo se realizarán dos iteraciones. Después de la segunda, completado pasa a valer true, por lo que la expresión !completado pasa a ser false y el bucle termina.

💻 Ejemplo DAW

En aplicaciones web encontraremos situaciones en las que una repetición depende del estado de un proceso: continuar mientras queden elementos por procesar, mientras una operación no haya terminado o mientras se mantenga una determinada condición. Más adelante aplicaremos estas ideas a problemas más completos.

Riesgo de bucle infinito

Al trabajar con while y do...while debemos prestar especial atención a que la condición pueda llegar a ser falsa.

Observa conceptualmente este código incorrecto:

JavaScript · Ejemplo incorrecto · No ejecutar 
let numero = 1;

while (numero <= 5) {
  console.log(numero);

  // Falta actualizar numero
}

numero comienza valiendo 1 y nunca cambia. Por tanto, la condición numero <= 5 seguirá siendo verdadera indefinidamente.

⚠️ Atención

No ejecutes este ejemplo incorrecto. Un bucle infinito puede hacer que la pestaña del navegador deje de responder. Antes de ejecutar un bucle, comprueba siempre qué elemento hará que la condición llegue a ser falsa.

La versión correcta sería:

JavaScript 
let numero = 1;

while (numero <= 5) {
  console.log(numero);
  numero++;
}

Ahora numero aumenta después de cada iteración:

Evolución 
1 → 2 → 3 → 4 → 5 → 6

Cuando alcanza el valor 6, la condición 6 <= 5 es falsa y el bucle termina.

También debemos comprobar que la actualización se realice en la dirección correcta. Por ejemplo, si queremos aumentar desde 1 hasta 5, utilizar numero-- alejaría cada vez más el contador del final de la repetición.

📌 Importante

Antes de ejecutar un while o un do...while, identifica siempre la condición de continuación y qué instrucción o cambio permitirá que esa condición llegue a ser falsa.

🧠 Comprueba lo aprendido

Sin ejecutar el programa, indica qué mostrará la consola:

JavaScript 
let numero = 2;

console.log("Inicio");

while (numero <= 8) {
  console.log(numero);
  numero += 2;
}

console.log("Fin");

Antes de comprobar la solución, identifica:

  • el valor inicial;
  • la condición;
  • la actualización;
  • los valores que tomará numero;
  • el momento en el que la condición será falsa.
Ver solución

El valor inicial es 2. La condición es numero <= 8 y la actualización aumenta numero de dos en dos.

La consola mostrará:

Console 
Inicio
2
4
6
8
Fin

Después de mostrar 8, se ejecuta numero += 2, por lo que numero pasa a valer 10. La condición 10 <= 8 es false y el bucle termina.

💻 Práctica con while y do...while

Realiza los siguientes ejercicios. Antes de ejecutar cada programa, intenta predecir el resultado.

Ejercicio 1

Utilizando while, muestra los números del 1 al 10.

Ejercicio 2

Utilizando while, muestra los números pares desde 2 hasta 20.

Ejercicio 3

Utilizando while, realiza una cuenta atrás desde 10 hasta 1 y después muestra "¡Fin de la cuenta atrás!".

Ejercicio 4

Utilizando do...while, muestra los números del 1 al 5.

Ejercicio 5

Analiza los siguientes programas sin ejecutarlos e indica cuántas veces se ejecutará el bloque de cada uno.

Programa A:

JavaScript 
let numero = 10;

while (numero < 5) {
  console.log(numero);
}

Programa B:

JavaScript 
let numero = 10;

do {
  console.log(numero);
} while (numero < 5);
Ver soluciones

Ejercicio 1

JavaScript 
let numero = 1;

while (numero <= 10) {
  console.log(numero);
  numero++;
}

Ejercicio 2

JavaScript 
let numero = 2;

while (numero <= 20) {
  console.log(numero);
  numero += 2;
}

Ejercicio 3

JavaScript 
let numero = 10;

while (numero >= 1) {
  console.log(numero);
  numero--;
}

console.log("¡Fin de la cuenta atrás!");

Ejercicio 4

JavaScript 
let numero = 1;

do {
  console.log(numero);
  numero++;
} while (numero <= 5);

Ejercicio 5

El Programa A no ejecuta el bloque ninguna vez. La condición 10 < 5 es falsa desde el principio y while comprueba la condición antes de entrar en el bloque.

El Programa B ejecuta el bloque una vez. do...while ejecuta primero el bloque y comprueba después la condición. Por eso se muestra el valor 10 una vez.

📌 Recuerda

while comprueba la condición antes de ejecutar el bloque, por lo que puede ejecutarse cero veces. do...while comprueba la condición después, por lo que el bloque se ejecuta al menos una vez. En ambos casos debemos asegurarnos de que durante la repetición se produzca algún cambio que permita que la condición llegue a ser falsa.
