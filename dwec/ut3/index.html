UT3 - Estructuras de control en JavaScript

En esta unidad aprenderemos a controlar el flujo de ejecución de un programa JavaScript. Hasta ahora nuestras instrucciones se ejecutaban principalmente de forma secuencial; a partir de este momento podremos hacer que el programa tome decisiones y repita determinadas instrucciones cuando sea necesario.

Estudiaremos las estructuras condicionales if, if...else, else if y switch, aprendiendo a construir condiciones y a elegir qué instrucciones deben ejecutarse en función de los datos del programa.

También trabajaremos con las principales estructuras repetitivas de JavaScript: for, while y do...while. Veremos cómo controlar sus iteraciones, cómo utilizar break y continue y cómo combinar varias estructuras mediante anidamiento.

Finalmente, aplicaremos estas herramientas a la resolución de problemas, aprendiendo a identificar decisiones y repeticiones, diseñar una solución, traducirla a JavaScript y comprobar su funcionamiento mediante pruebas y depuración.
