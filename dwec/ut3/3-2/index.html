3.2 Estructuras condicionales: if

En el apartado anterior vimos que una condición es una expresión cuyo resultado puede ser true o false. Ahora aprenderemos a utilizar ese resultado para decidir si determinadas instrucciones deben ejecutarse o no.

Para ello utilizaremos la estructura condicional más sencilla de JavaScript: la sentencia if.

📌 Importante

La estructura if permite ejecutar un bloque de instrucciones únicamente cuando una determinada condición se cumple.

Qué es una condición

Como vimos en el apartado 3.1, una condición es una expresión que JavaScript evalúa y cuyo resultado determina si algo se cumple o no.

El resultado de una condición será un valor booleano: true o false.

JavaScript 
const edad = 20;

console.log(edad >= 18);

La expresión edad >= 18 produce true, porque el valor de edad es 20.

Hasta ahora simplemente mostrábamos ese resultado en Console. Con if podremos utilizarlo para controlar qué instrucciones ejecuta el programa.

Sintaxis de if

La estructura básica de una sentencia if es la siguiente:

JavaScript 
if (condición) {
  // Instrucciones que se ejecutan si la condición es true
}

Podemos distinguir tres elementos fundamentales:

Elemento Función
if Palabra reservada que indica el comienzo de una estructura condicional.
(condición) Expresión que JavaScript evalúa como true o false.
{ } Delimitan el bloque de instrucciones que se ejecutará cuando la condición sea verdadera.

Veamos un ejemplo completo:

JavaScript 
const edad = 20;

if (edad >= 18) {
  console.log("La persona es mayor de edad");
}

JavaScript evalúa la condición edad >= 18. Como 20 >= 18 produce true, se ejecuta la instrucción situada dentro del bloque.

Por tanto, en Console aparecerá:

Console 
La persona es mayor de edad
💻 Ejemplo DAW

Una aplicación web puede utilizar if para comprobar si un usuario cumple una determinada condición antes de realizar una acción: por ejemplo, comprobar su edad, verificar si ha aceptado unas condiciones o determinar si un valor supera un límite establecido.

Evaluación de la condición

Cuando JavaScript encuentra una sentencia if, lo primero que hace es evaluar la condición situada entre paréntesis.

A partir de ese resultado pueden ocurrir dos situaciones:

  • Si la condición produce true, JavaScript ejecuta el bloque de instrucciones.
  • Si la condición produce false, JavaScript omite el bloque y continúa ejecutando el programa después del if.

Observa el siguiente ejemplo:

JavaScript 
const edad = 15;

console.log("Inicio");

if (edad >= 18) {
  console.log("La persona es mayor de edad");
}

console.log("Fin");

La condición edad >= 18 es falsa, porque 15 no es mayor o igual que 18. Por tanto, JavaScript no ejecutará la instrucción situada dentro del if.

El resultado será:

Console 
Inicio
Fin
📌 Importante

Cuando la condición de un if es false, el programa no se detiene. Simplemente omite el bloque asociado al if y continúa con la siguiente instrucción.

Bloque de instrucciones

Dentro de las llaves de un if podemos incluir una o varias instrucciones. Todas ellas pertenecen al mismo bloque y se ejecutarán únicamente si la condición es verdadera.

JavaScript 
const edad = 22;

if (edad >= 18) {
  console.log("Acceso permitido");
  console.log("El usuario es mayor de edad");
  console.log("Puede continuar con el proceso");
}

console.log("Programa finalizado");

Como la condición es verdadera, se ejecutan las tres instrucciones del bloque y, posteriormente, la instrucción situada después del if.

Console 
Acceso permitido
El usuario es mayor de edad
Puede continuar con el proceso
Programa finalizado
⚠️ Atención

Aunque JavaScript permite determinadas formas abreviadas cuando solo existe una instrucción, utilizaremos siempre las llaves { }. Esto hace que el código sea más claro y evita errores cuando posteriormente añadimos nuevas instrucciones.

También debemos indentar correctamente las instrucciones que se encuentran dentro del bloque:

JavaScript 
if (edad >= 18) {
  console.log("Acceso permitido");
}

La indentación permite identificar visualmente qué instrucciones pertenecen al if.

Condiciones simples

Las condiciones de un if pueden construirse utilizando los operadores de comparación estudiados en el apartado anterior.

Comprobar si un número supera un valor

JavaScript 
const temperatura = 32;

if (temperatura > 30) {
  console.log("La temperatura es alta");
}

Comprobar una igualdad

JavaScript 
const ciudad = "Teruel";

if (ciudad === "Teruel") {
  console.log("La ciudad seleccionada es Teruel");
}

Utilizar directamente una variable booleana

Como vimos en el apartado anterior, si una variable ya contiene un valor booleano podemos utilizarla directamente como condición.

JavaScript 
const sesionIniciada = true;

if (sesionIniciada) {
  console.log("Bienvenido a tu cuenta");
}

No necesitamos escribir:

JavaScript 
if (sesionIniciada === true) {
  console.log("Bienvenido a tu cuenta");
}

La primera forma es más directa y expresa claramente que queremos comprobar si sesionIniciada es verdadera.

Combinar varias condiciones

También podemos utilizar los operadores lógicos &&, || y ! para construir condiciones más completas.

JavaScript 
const edad = 20;
const tieneEntrada = true;

if (edad >= 18 && tieneEntrada) {
  console.log("Puede acceder al evento");
}

Para que se ejecute el bloque deben cumplirse las dos condiciones: que la persona tenga al menos 18 años y que tenga entrada.

📌 Importante

Todo lo aprendido en 3.1 sobre comparaciones y operadores lógicos puede utilizarse para construir las condiciones de una sentencia if.

Errores frecuentes

Al comenzar a utilizar estructuras condicionales aparecen algunos errores con mucha frecuencia. Conviene aprender a reconocerlos desde el principio.

Confundir = con ===

Recuerda que = se utiliza para asignar un valor y === para comprobar una igualdad estricta. Utilizar = por error dentro de la condición puede modificar el valor de la variable en lugar de realizar la comparación que pretendíamos.

Observa este código incorrecto:

JavaScript - Incorrecto 
let edad = 20;

if (edad = 18) {
  console.log("La edad es 18");
}

En este caso no estamos comparando edad con 18: estamos asignando el valor 18 a la variable. Por tanto, hemos modificado accidentalmente su valor.

La comparación correcta sería:

JavaScript - Correcto 
let edad = 20;

if (edad === 18) {
  console.log("La edad es 18");
}

Escribir un punto y coma después de la condición

Observa este código:

JavaScript - Incorrecto 
if (edad >= 18); {
  console.log("Acceso permitido");
}

Ese punto y coma termina la sentencia if. Como consecuencia, el bloque que aparece después ya no queda controlado por la condición como pretendíamos.

La forma correcta es:

JavaScript - Correcto 
if (edad >= 18) {
  console.log("Acceso permitido");
}

Olvidar las llaves o escribirlas incorrectamente

Las llaves permiten identificar claramente qué instrucciones pertenecen al bloque del if. Debemos comprobar que cada llave de apertura { tenga su correspondiente llave de cierre }.

Esperar que siempre se muestre un mensaje

Observa este ejemplo:

JavaScript 
const nota = 4;

if (nota >= 5) {
  console.log("Asignatura superada");
}

En este caso no aparecerá ningún mensaje porque la condición es falsa. Esto no significa que el programa tenga un error: es exactamente el comportamiento definido por nuestro if.

En el siguiente apartado aprenderemos a utilizar if...else para indicar qué debe ocurrir cuando la condición no se cumple.

⚠️ Atención

Si un if no produce el resultado esperado, comprueba primero la condición, los operadores utilizados, los paréntesis, las llaves y la indentación del bloque.

💻 Práctica con if

Crea un archivo JavaScript y realiza los siguientes ejercicios. Ejecuta cada ejemplo y comprueba el resultado en Console.

  • Declara una constante numero con valor 15. Muestra un mensaje si el número es mayor que 10.
  • Declara una constante temperatura con valor 35. Muestra "Temperatura elevada" si supera los 30 grados.
  • Declara una constante booleana usuarioRegistrado con valor true. Utilízala directamente como condición para mostrar "Usuario identificado".
  • Declara edad = 20 y tieneEntrada = true. Utiliza && para mostrar un mensaje únicamente si se cumplen las dos condiciones.
Ver solución
JavaScript 
const numero = 15;

if (numero > 10) {
  console.log("El número es mayor que 10");
}


const temperatura = 35;

if (temperatura > 30) {
  console.log("Temperatura elevada");
}


const usuarioRegistrado = true;

if (usuarioRegistrado) {
  console.log("Usuario identificado");
}


const edad = 20;
const tieneEntrada = true;

if (edad >= 18 && tieneEntrada) {
  console.log("Puede acceder");
}
