3.9 Control de bucles con break y continue

En los apartados anteriores hemos aprendido a utilizar los bucles for, while y do...while. En todos ellos, las repeticiones se producen siguiendo la condición que controla el bucle.

Sin embargo, durante la ejecución de un programa pueden aparecer situaciones en las que necesitemos interrumpir completamente un bucle o omitir una iteración concreta y continuar con la siguiente.

JavaScript proporciona dos instrucciones que permiten modificar el comportamiento normal de un bucle: break y continue.

📌 Importante

break termina inmediatamente el bucle. continue interrumpe únicamente la iteración actual y permite que el bucle continúe con la siguiente.

Interrumpir un bucle con break

La instrucción break permite salir inmediatamente de un bucle, aunque la condición que lo controla todavía permita realizar más iteraciones.

Cuando JavaScript encuentra un break, deja de ejecutar el bucle y continúa con la primera instrucción situada después de él.

Observa este ejemplo:

JavaScript 
for (let i = 1; i <= 10; i++) {

  if (i === 5) {
    break;
  }

  console.log(i);
}

Aunque el for está preparado para realizar diez iteraciones, cuando i alcanza el valor 5 se ejecuta break y el bucle termina.

El resultado será:

Console 
1
2
3
4

El valor 5 no se muestra porque la instrucción break se ejecuta antes de llegar a console.log(i).

Funcionamiento paso a paso

Podemos seguir la ejecución del programa mediante esta tabla:

Valor de i i === 5 Acción
1 false Se muestra 1.
2 false Se muestra 2.
3 false Se muestra 3.
4 false Se muestra 4.
5 true Se ejecuta break y termina el bucle.
💻 Ejemplo

break puede ser útil cuando estamos realizando una búsqueda y encontramos el dato que necesitábamos. A partir de ese momento puede no tener sentido continuar realizando más iteraciones.

break dentro de un while

break no se utiliza únicamente con for. También puede utilizarse en while y do...while.

Por ejemplo:

JavaScript 
let numero = 1;

while (numero <= 10) {

  console.log(numero);

  if (numero === 4) {
    break;
  }

  numero++;
}

console.log("Fin");

La consola mostrará:

Console 
1
2
3
4
Fin

Cuando numero vale 4, se ejecuta break. El while termina inmediatamente y el programa continúa con console.log("Fin").

Saltar una iteración con continue

La instrucción continue tiene un comportamiento diferente. No termina el bucle completo, sino que interrumpe únicamente la iteración actual.

Cuando JavaScript encuentra continue, deja de ejecutar las instrucciones que quedan en esa iteración y pasa a la siguiente.

Observa este ejemplo:

JavaScript 
for (let i = 1; i <= 5; i++) {

  if (i === 3) {
    continue;
  }

  console.log(i);
}

El resultado será:

Console 
1
2
4
5

Cuando i vale 3, se ejecuta continue. Por tanto, se omite console.log(i) durante esa iteración.

Sin embargo, el bucle no termina. Continúa con los valores 4 y 5.

Funcionamiento paso a paso

Valor de i i === 3 Acción
1 false Se muestra 1.
2 false Se muestra 2.
3 true Se ejecuta continue. No se muestra 3.
4 false Se muestra 4.
5 false Se muestra 5.

continue con una condición

También podemos utilizar continue para omitir todos los valores que cumplan una determinada condición.

Por ejemplo, podemos mostrar únicamente los números impares:

JavaScript 
for (let i = 1; i <= 10; i++) {

  if (i % 2 === 0) {
    continue;
  }

  console.log(i);
}

La expresión i % 2 === 0 permite comprobar si el número es par. Cuando lo es, se ejecuta continue y esa iteración se omite.

El resultado será:

Console 
1
3
5
7
9

Atención al utilizar continue dentro de while

Cuando utilizamos continue dentro de un bucle while, debemos prestar especial atención a la actualización de la variable de control.

Si continue se ejecuta antes de actualizar esa variable, el programa puede volver a comprobar siempre la misma condición y provocar un bucle infinito.

⚠️ Atención

Observa el siguiente ejemplo. Es incorrecto y no debes ejecutarlo, porque provoca un bucle infinito.

JavaScript · Ejemplo incorrecto · No ejecutar 
let numero = 1;

while (numero <= 5) {

  if (numero === 3) {
    continue;
  }

  console.log(numero);
  numero++;
}

Cuando numero alcanza el valor 3, se ejecuta continue antes de llegar a numero++.

Por tanto, numero sigue valiendo 3. En la siguiente iteración vuelve a cumplirse numero === 3, se ejecuta de nuevo continue y el contador nunca puede avanzar.

Una posible corrección sería actualizar la variable antes de ejecutar continue:

JavaScript 
let numero = 1;

while (numero <= 5) {

  if (numero === 3) {
    numero++;
    continue;
  }

  console.log(numero);
  numero++;
}

En este caso, cuando numero vale 3, primero se incrementa hasta 4 y después se ejecuta continue. De esta forma, el bucle puede seguir avanzando.

📌 Importante

Cuando utilices continue dentro de un while, comprueba siempre que la variable que controla el bucle puede actualizarse correctamente antes de comenzar la siguiente iteración.

Diferencias entre break y continue

Aunque ambas instrucciones modifican el flujo normal de un bucle, su comportamiento es muy diferente.

Característica break continue
¿Termina el bucle? Sí. No.
¿Qué interrumpe? Todo el bucle. Solo la iteración actual.
¿Se realizan más iteraciones? No. Sí, si el bucle todavía puede continuar.
Uso habitual Finalizar una repetición cuando ya hemos alcanzado el objetivo. Omitir determinados casos y continuar procesando los demás.
📌 Importante

Podemos recordar la diferencia de esta forma: break significa «termina el bucle» y continue significa «salta esta iteración y continúa con la siguiente».

Comparación directa

Observa la diferencia utilizando prácticamente el mismo programa.

Con break

JavaScript 
for (let i = 1; i <= 5; i++) {

  if (i === 3) {
    break;
  }

  console.log(i);
}

Resultado:

Console 
1
2

Con continue

JavaScript 
for (let i = 1; i <= 5; i++) {

  if (i === 3) {
    continue;
  }

  console.log(i);
}

Resultado:

Console 
1
2
4
5

Uso responsable

Las instrucciones break y continue son útiles, pero debemos utilizarlas de forma razonada.

Un uso excesivo puede hacer que el comportamiento de un bucle sea más difícil de seguir, ya que introduce puntos adicionales en los que el flujo normal de ejecución cambia.

⚠️ Atención

Antes de utilizar break o continue, debemos comprobar si realmente hacen el código más claro. No deben utilizarse simplemente para evitar pensar correctamente la condición que controla el bucle.

Por ejemplo, este programa funciona:

JavaScript 
for (let i = 1; i <= 100; i++) {

  console.log(i);

  if (i === 5) {
    break;
  }
}

Pero si realmente solo queremos mostrar los números del 1 al 5, resulta mucho más claro escribir:

JavaScript 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

En este segundo caso no necesitamos break, porque podemos expresar directamente el límite mediante la condición del for.

💻 Ejemplo DAW

En una aplicación web puede ser necesario repetir una serie de comprobaciones. Si durante esas comprobaciones encontramos el dato que buscábamos, podemos utilizar break para detener el proceso. Si queremos ignorar determinados casos y continuar comprobando los demás, continue puede resultar útil.

Más adelante, cuando trabajemos con arrays y con datos recibidos desde un servidor, veremos aplicaciones más reales de estas instrucciones.

Ejemplos prácticos

Ejemplo 1. Detener una búsqueda

Supongamos que queremos comprobar números consecutivos y detener el proceso cuando lleguemos al número 7.

JavaScript 
for (let numero = 1; numero <= 10; numero++) {

  console.log("Comprobando: " + numero);

  if (numero === 7) {
    console.log("Número encontrado");
    break;
  }
}

La consola mostrará:

Console 
Comprobando: 1
Comprobando: 2
Comprobando: 3
Comprobando: 4
Comprobando: 5
Comprobando: 6
Comprobando: 7
Número encontrado

Los valores 8, 9 y 10 ya no se procesan porque el bucle ha terminado.

Ejemplo 2. Omitir un valor

En este caso queremos mostrar los números del 1 al 6, excepto el número 4.

JavaScript 
for (let numero = 1; numero <= 6; numero++) {

  if (numero === 4) {
    continue;
  }

  console.log(numero);
}

Resultado:

Console 
1
2
3
5
6

Ejemplo 3. Mostrar números no divisibles entre 3

JavaScript 
for (let numero = 1; numero <= 10; numero++) {

  if (numero % 3 === 0) {
    continue;
  }

  console.log(numero);
}

Los números divisibles entre 3 provocan la ejecución de continue, por lo que no se muestran.

El resultado será:

Console 
1
2
4
5
7
8
10

Ejemplo 4. Finalizar un while con break

JavaScript 
let contador = 1;

while (contador <= 10) {

  console.log(contador);

  if (contador === 5) {
    break;
  }

  contador++;
}

console.log("Bucle terminado");

El resultado será:

Console 
1
2
3
4
5
Bucle terminado

🧠 Comprueba lo aprendido

Observa el siguiente programa sin ejecutarlo:

JavaScript 
for (let i = 1; i <= 8; i++) {

  if (i === 3) {
    continue;
  }

  if (i === 6) {
    break;
  }

  console.log(i);
}

console.log("Fin");

Responde:

  1. ¿Qué ocurre cuando i vale 3?
  2. ¿Se muestra el número 3?
  3. ¿Qué ocurre cuando i vale 6?
  4. ¿Se ejecutan las iteraciones correspondientes a 7 y 8?
  5. ¿Qué mostrará exactamente la consola?
Ver solución

Cuando i vale 3, se ejecuta continue. Por tanto, esa iteración se interrumpe y el número 3 no se muestra.

El bucle continúa con 4 y 5.

Cuando i vale 6, se ejecuta break. El bucle termina completamente, por lo que nunca se alcanzan los valores 7 y 8.

La consola mostrará:

Console 
1
2
4
5
Fin

📌 Recuerda

break termina completamente el bucle en el que se ejecuta. continue únicamente omite el resto de la iteración actual y permite continuar con la siguiente. Ambas instrucciones son útiles, pero debemos utilizarlas cuando realmente hagan que el comportamiento del programa sea más claro y sencillo de comprender.
