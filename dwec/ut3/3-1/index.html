3.1 El flujo de ejecución de un programa

Cuando escribimos un programa, sus instrucciones no se ejecutan de forma desordenada. JavaScript sigue un determinado flujo de ejecución, es decir, un orden que determina qué instrucciones se ejecutan y en qué momento.

Hasta ahora hemos trabajado principalmente con programas sencillos en los que las instrucciones se ejecutaban una detrás de otra. Sin embargo, los programas reales necesitan tomar decisiones y repetir determinadas acciones dependiendo de las circunstancias.

📌 Importante

El flujo de ejecución es el orden en el que se ejecutan las instrucciones de un programa. Las estructuras de control permiten modificar ese orden para tomar decisiones o repetir instrucciones.

Ejecución secuencial

La forma más sencilla de ejecutar un programa es la ejecución secuencial. En un programa sencillo como los que hemos utilizado hasta ahora, JavaScript ejecuta las instrucciones una detrás de otra, siguiendo el orden en el que aparecen escritas.

Observa el siguiente ejemplo:

JavaScript 
console.log("Inicio del programa");
console.log("Procesando datos...");
console.log("Fin del programa");

Las tres instrucciones se ejecutan siguiendo el orden en el que están escritas. Por tanto, en Console veremos:

Console 
Inicio del programa
Procesando datos...
Fin del programa
1 Primera instrucción
2 Segunda instrucción
3 Tercera instrucción

Este tipo de ejecución es suficiente para programas muy sencillos, pero resulta limitado cuando queremos que el comportamiento del programa dependa de los datos que está procesando.

💻 Ejemplo DAW

Imagina una aplicación web que solicita la edad de una persona. No tendría sentido mostrar siempre el mismo mensaje: el programa podría necesitar mostrar un resultado diferente dependiendo de si la persona es mayor o menor de edad. Para conseguirlo necesitamos controlar el flujo de ejecución.

Qué significa controlar el flujo

Controlar el flujo significa decidir qué instrucciones deben ejecutarse, cuáles deben omitirse y cuáles deben repetirse.

Para conseguirlo utilizamos las denominadas estructuras de control. Estas estructuras permiten modificar la ejecución estrictamente secuencial de un programa.

Durante esta unidad estudiaremos principalmente dos grandes grupos:

Tipo ¿Para qué sirve? Estructuras
Condicionales Permiten tomar decisiones y ejecutar unas instrucciones u otras dependiendo de una condición. if, if...else, else if y switch
Repetitivas Permiten repetir un conjunto de instrucciones varias veces. for, while y do...while
📌 Importante

Las estructuras condicionales permiten tomar decisiones, mientras que los bucles permiten repetir instrucciones. Ambas forman parte de las estructuras de control de un programa.

Condiciones y valores booleanos

Para que un programa pueda tomar una decisión necesita comprobar si se cumple o no una determinada situación. Esa comprobación se expresa mediante una condición.

Una condición es una expresión cuyo resultado puede ser uno de los dos valores booleanos que ya conocemos:

  • true → la condición se cumple.
  • false → la condición no se cumple.

Podemos comprobarlo directamente en Console:

Console 
10 > 5
3 > 8
7 === 7
4 === 9

JavaScript devolverá:

Resultado 
true
false
true
false

El programa puede utilizar posteriormente estos resultados para decidir qué camino debe seguir.

💻 Ejemplo DAW

Una aplicación puede comprobar condiciones como edad >= 18, precio > 100 o nombre === "Eva". El resultado siempre será un valor booleano: true o false.

⚠️ Atención

No confundas = con ===. El operador = se utiliza para asignar un valor, mientras que === comprueba si dos valores son estrictamente iguales. Esta diferencia es especialmente importante cuando comenzamos a construir condiciones.

Expresiones de comparación

Muchas condiciones se construyen utilizando operadores de comparación. Estos operadores comparan dos valores y producen como resultado true o false.

Operador Significado Ejemplo Resultado
=== Igualdad estricta 5 === 5 true
!== Desigualdad estricta 5 !== 3 true
> Mayor que 8 > 4 true
< Menor que 8 < 4 false
>= Mayor o igual que 18 >= 18 true
<= Menor o igual que 7 <= 10 true

También podemos utilizar variables dentro de las comparaciones:

JavaScript 
const edad = 20;
const precio = 75;

console.log(edad >= 18);
console.log(precio > 100);

En este caso, Console mostrará:

Console 
true
false

La primera comparación es verdadera porque 20 es mayor o igual que 18. La segunda es falsa porque 75 no es mayor que 100.

Operadores lógicos en condiciones

En muchas situaciones una única comparación no es suficiente. Podemos necesitar comprobar varias condiciones al mismo tiempo. Para ello utilizamos los operadores lógicos.

Los tres operadores lógicos fundamentales que utilizaremos son:

Operador Nombre Funcionamiento
&& AND El resultado es verdadero cuando se cumplen las dos condiciones.
|| OR El resultado es verdadero cuando se cumple al menos una de las condiciones.
! NOT Niega un valor lógico: convierte true en false y false en true.

Operador AND: &&

El operador && se utiliza cuando queremos que todas las condiciones se cumplan.

JavaScript 
const edad = 20;
const tieneEntrada = true;

console.log(edad >= 18 && tieneEntrada);

El resultado será true, porque ambas condiciones se cumplen.

Como tieneEntrada ya contiene un valor booleano, podemos utilizar la variable directamente como condición. No es necesario escribir tieneEntrada === true.

Operador OR: ||

El operador || se utiliza cuando es suficiente con que se cumpla al menos una de las condiciones.

JavaScript 
const esProfesor = false;
const esAlumno = true;

console.log(esProfesor || esAlumno);

El resultado será true, porque una de las dos condiciones es verdadera.

Operador NOT: !

El operador ! permite negar un valor booleano.

JavaScript 
const conectado = false;

console.log(!conectado);

Como conectado contiene false, !conectado produce true.

📌 Importante

Los operadores de comparación permiten construir condiciones y los operadores lógicos permiten combinar varias condiciones. Estas expresiones serán la base de las estructuras condicionales que comenzaremos a estudiar en el apartado 3.2.

Bloques de código

En la UT2 vimos que un bloque de código es un conjunto de instrucciones delimitado mediante llaves { }.

A partir de esta unidad los bloques adquieren especial importancia, porque las estructuras de control los utilizan para indicar qué instrucciones pertenecen a una decisión o a una repetición.

JavaScript 
{
  console.log("Primera instrucción del bloque");
  console.log("Segunda instrucción del bloque");
}

Las llaves indican dónde comienza y termina el bloque. Las instrucciones situadas en su interior aparecen indentadas para que la estructura del programa resulte más fácil de reconocer.

📌 Importante

Las llaves { } delimitan los bloques de código. La indentación no modifica por sí misma el funcionamiento de JavaScript, pero es fundamental para escribir programas claros y fáciles de mantener.

⚠️ Atención

A medida que combinemos condiciones y bucles aparecerán bloques dentro de otros bloques. Una indentación correcta será esencial para entender rápidamente qué instrucciones pertenecen a cada estructura.

🧠 Comprueba lo aprendido

Sin ejecutar el código, indica si cada una de las siguientes expresiones produce true o false:

JavaScript 
10 > 4
5 === 8
12 >= 12
7 !== 7
10 > 5 && 3 < 8
10 < 5 || 3 < 8
!(4 > 2)
Ver solución

10 > 4 → true.

5 === 8 → false.

12 >= 12 → true.

7 !== 7 → false.

10 > 5 && 3 < 8 → true, porque las dos condiciones son verdaderas.

10 < 5 || 3 < 8 → true, porque aunque la primera condición es falsa, la segunda es verdadera.

!(4 > 2) → false. La expresión 4 > 2 produce true y el operador ! invierte ese valor.

💻 Prueba en Console

Abre las herramientas de desarrollo del navegador y entra en Console. Escribe las siguientes instrucciones una a una:

Console 
15 > 10
15 < 10
15 === 15
15 !== 15
15 >= 10 && 20 > 5
15 < 10 || 20 > 5
!(15 > 10)

Antes de pulsar Enter en cada expresión, intenta predecir si JavaScript devolverá true o false. Después compara tu respuesta con el resultado obtenido.

El objetivo es acostumbrarnos a leer y evaluar condiciones, ya que en los próximos apartados serán las condiciones las que determinarán qué instrucciones ejecuta el programa.
