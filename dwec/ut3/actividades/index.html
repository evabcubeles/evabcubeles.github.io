📝 Actividades de la UT3

Para finalizar la UT3 vas a aplicar de forma conjunta los principales conceptos trabajados en los apartados 3.1 a 3.11.

Las actividades se organizan en tres bloques: actividades prácticas, un reto final y una autoevaluación. El objetivo es comprobar que sabes utilizar las estructuras de control para tomar decisiones, repetir instrucciones y resolver problemas mediante JavaScript.

📌 Importante

Antes de escribir código, analiza siempre el problema e identifica los datos, las decisiones y las repeticiones necesarias. Después programa, prueba distintos casos y depura el resultado.

💻 Actividades prácticas

Actividad 1 — Analiza el flujo de ejecución

Observa el siguiente programa sin ejecutarlo:

JavaScript 
const edad = 20;

console.log("Inicio");

if (edad >= 18) {
  console.log("Mayor de edad");
}

console.log("Fin");
  1. Escribe el orden exacto en el que crees que se mostrarán los mensajes.
  2. Indica qué condición se evalúa.
  3. Explica qué bloque depende del resultado de esa condición.
  4. Cambia edad por 16 y vuelve a predecir la salida.
  5. Ejecuta finalmente ambos casos y comprueba tus respuestas.

Actividad 2 — Decisiones con if e if...else

Crea un programa que solicite mediante prompt() una edad y la convierta a número.

  1. Si la edad es mayor o igual que 18, muestra "Eres mayor de edad".
  2. En caso contrario, muestra "Eres menor de edad".
  3. Prueba el programa con 17, 18 y 19.
  4. Explica por qué 18 es un caso especialmente importante para probar el programa.
💻 Recuerda

if permite ejecutar un bloque cuando se cumple una condición. if...else permite establecer dos caminos alternativos de ejecución.

Actividad 3 — Decisiones múltiples

Diseña un programa que reciba una nota numérica entre 0 y 10 y muestre:

  • Insuficiente: menos de 5.
  • Suficiente: desde 5 hasta menos de 6.
  • Bien: desde 6 hasta menos de 7.
  • Notable: desde 7 hasta menos de 9.
  • Sobresaliente: desde 9 hasta 10.
  1. Resuelve el problema utilizando if...else if...else.
  2. Comprueba especialmente las notas 4.9, 5, 6, 7, 9 y 10.
  3. Explica por qué el orden de las condiciones es importante.
⚠️ Atención

Cuando trabajamos con rangos, una condición demasiado general colocada antes que otra más específica puede impedir que esta última llegue a evaluarse.

Actividad 4 — Elige entre switch e if...else if

Crea una variable llamada dia con un número entre 1 y 7.

Utiliza switch para mostrar:

  • 1 → Lunes.
  • 2 → Martes.
  • 3 → Miércoles.
  • 4 → Jueves.
  • 5 → Viernes.
  • 6 → Sábado.
  • 7 → Domingo.

Para cualquier otro valor debe mostrarse "Día no válido".

  1. Incluye correctamente case, break y default.
  2. Prueba al menos los valores 1, 5, 7 y 9.
  3. Elimina temporalmente uno de los break y observa qué ocurre.
  4. Explica por qué switch resulta apropiado en este problema.

Actividad 5 — Recorridos con for

Resuelve los siguientes recorridos utilizando el bucle for.

  1. Muestra los números del 1 al 20.
  2. Muestra los números del 20 al 1.
  3. Muestra únicamente los números pares entre 1 y 20.
  4. Muestra los múltiplos de 3 comprendidos entre 1 y 30.
  5. Calcula la suma de los números comprendidos entre 1 y 10.
📌 Antes de programar

Para cada ejercicio identifica la inicialización, la condición y la actualización del bucle.

Actividad 6 — while y do...while

Analiza primero estos dos programas:

JavaScript A · while 
let numero = 1;

while (numero <= 5) {
  console.log(numero);
  numero++;
}
JavaScript B · do...while 
let numero = 1;

do {
  console.log(numero);
  numero++;
} while (numero <= 5);
  1. Predice la salida de ambos programas.
  2. Explica cuándo se comprueba la condición en cada caso.
  3. Cambia el valor inicial de numero a 10 en ambos programas.
  4. Predice nuevamente la salida antes de ejecutarlos.
  5. Explica por qué do...while puede ejecutar su bloque al menos una vez aunque la condición sea falsa desde el principio.

Actividad 7 — Control de bucles con break y continue

Escribe un programa que recorra los números del 1 al 20 y cumpla estas condiciones:

  1. Cuando el número sea 10, debe saltar esa iteración mediante continue.
  2. Cuando el número sea 16, debe finalizar completamente el bucle mediante break.
  3. El resto de los números debe mostrarse en Console.
  4. Antes de ejecutar, escribe qué números esperas ver.
  5. Explica con tus palabras la diferencia entre break y continue.

Actividad 8 — Decisiones dentro de un bucle

Crea un programa que recorra los números del 1 al 20.

Para cada número debe indicar:

  • "Par" si es divisible entre 2.
  • "Impar" en caso contrario.

La salida debe seguir un formato parecido a:

Console · Resultado esperado 
1 es impar
2 es par
3 es impar
4 es par
...
  1. Identifica qué estructura realiza la repetición.
  2. Identifica qué estructura toma la decisión.
  3. Explica qué operador permite comprobar si el número es par.
  4. Modifica después el programa para indicar también si cada número es múltiplo de 5.

Actividad 9 — Bucles anidados

Observa el siguiente código:

JavaScript 
for (let fila = 1; fila <= 3; fila++) {
  for (let columna = 1; columna <= 4; columna++) {
    console.log(`Fila ${fila} - Columna ${columna}`);
  }
}
  1. Sin ejecutar el programa, indica cuántos mensajes se mostrarán.
  2. Escribe los cuatro primeros mensajes que esperas obtener.
  3. Explica qué bucle se ejecuta completamente por cada iteración del otro.
  4. Explica qué ocurre con columna cada vez que comienza una nueva iteración de fila.
  5. Modifica el programa para trabajar con 5 filas y 3 columnas.
  6. Calcula cuántas veces se ejecutará ahora el console.log().

Actividad 10 — Analiza, prueba y depura

El siguiente programa pretende mostrar los números pares comprendidos entre 1 y 10, pero contiene un error lógico:

JavaScript · Código con error lógico 
for (let numero = 1; numero <= 10; numero++) {
  if (numero % 2 !== 0) {
    console.log(numero);
  }
}
  1. Ejecuta el programa y observa el resultado.
  2. Explica por qué el programa puede ejecutarse sin mostrar ningún mensaje de error y, sin embargo, ser incorrecto.
  3. Localiza la condición responsable del problema.
  4. Corrige el programa.
  5. Coloca un breakpoint en la línea del if.
  6. Observa el valor de numero y el resultado de la condición durante varias iteraciones.
  7. Comprueba finalmente que la salida obtenida coincide con la esperada.
📌 Método de trabajo

Analizar → diseñar → programar → ejecutar → observar → probar → corregir → volver a probar.

🧩 Reto final — Sistema de control de calificaciones

El centro necesita un pequeño programa que permita introducir sucesivamente las calificaciones de varios alumnos y obtener información básica sobre los resultados.

En este reto deberás analizar el problema y combinar diferentes estructuras de control de JavaScript.

Proyecto inicial

Estructura 
calificaciones/
├── index.html
└── js/
    └── app.js

El archivo index.html contiene:

HTML · index.html 
<!DOCTYPE html>
<html lang="es">

<head>
  <meta charset="UTF-8">
  <title>Control de calificaciones</title>
  <script src="js/app.js" defer></script>
</head>

<body>
  <h1>Control de calificaciones</h1>
</body>

</html>

El programa deberá trabajar con las calificaciones de 10 alumnos. En cada iteración solicitará una calificación mediante prompt().

Antes de programar

No empieces escribiendo directamente el código. Responde primero:

  1. Datos. ¿Qué información necesita manejar el programa?
  2. Repeticiones. ¿Qué operación debe realizarse varias veces?
  3. Decisiones. ¿Qué condiciones tendrá que comprobar el programa?
  4. Algoritmo. Escribe mediante una lista ordenada los pasos que seguirá el programa antes de traducirlos a JavaScript.

Tu misión

  1. Solicita 10 calificaciones. Utiliza un bucle adecuado para repetir la entrada exactamente diez veces.
  2. Convierte cada dato. Recuerda que prompt() devuelve texto, por lo que debes convertir la calificación a un valor numérico.
  3. Controla el rango. Si la calificación es menor que 0 o mayor que 10, muestra un mensaje indicando que no es válida.
  4. Ignora las calificaciones no válidas. Utiliza continue para evitar que una calificación fuera del intervalo 0–10 participe en los cálculos.
  5. Clasifica las calificaciones válidas. Muestra para cada una: Insuficiente, Suficiente, Bien, Notable o Sobresaliente.
  6. Cuenta aprobados y suspensos. Utiliza dos contadores que se actualicen únicamente cuando la calificación sea válida.
  7. Acumula las calificaciones. Mantén una variable con la suma de todas las notas válidas.
  8. Cuenta las notas válidas. Necesitarás este dato para calcular posteriormente la media.
  9. Calcula la media. Al finalizar el bucle, muestra la media de las calificaciones válidas con dos decimales.
  10. Evita una división incorrecta. Antes de calcular la media, comprueba que existe al menos una calificación válida.
  11. Muestra un resumen final. Debe indicar: número de calificaciones válidas, número de aprobados, número de suspensos y nota media.
  12. Prueba distintos casos. Utiliza calificaciones situadas antes, en y después de los límites importantes: 4.9, 5, 6, 7, 9 y 10. Prueba también valores no válidos como -1 y 12.
  13. Depura el programa. Coloca al menos un breakpoint dentro del bucle y observa cómo cambian los contadores y el acumulador durante la ejecución.
⚠️ Alcance del reto

No necesitas utilizar arrays, funciones ni manipulación del DOM. El reto debe resolverse únicamente con los conocimientos trabajados hasta la UT3: variables, operadores, entrada y salida básica, condicionales, bucles y herramientas de depuración.

📦 Entrega del reto

Entrega la carpeta calificaciones con index.html y js/app.js. El programa debe estar correctamente indentado, utilizar nombres descriptivos, ejecutarse sin errores y producir resultados correctos para los casos de prueba indicados.
