3.10 Estructuras de control anidadas

Hasta ahora hemos estudiado las estructuras condicionales y los bucles de forma independiente. Sin embargo, en un programa real es frecuente que necesitemos combinar varias estructuras de control para resolver problemas más complejos.

Podemos colocar una estructura de control dentro de otra. Por ejemplo, podemos introducir un if dentro de otro if, utilizar una condición dentro de un bucle o incluso colocar un bucle dentro de otro.

📌 Importante

Cuando una estructura de control aparece dentro de otra hablamos de estructuras anidadas. El anidamiento permite combinar decisiones y repeticiones para construir algoritmos más completos.

Qué significa anidar estructuras

Anidar significa colocar una estructura dentro del bloque de instrucciones de otra estructura.

Por ejemplo, podemos colocar un if dentro de otro if:

JavaScript 
if (condicion1) {

  if (condicion2) {
    // Instrucciones
  }

}

En este caso, la segunda condición solo se comprobará si previamente se ha cumplido condicion1.

También podemos colocar una estructura condicional dentro de un bucle:

JavaScript 
for (let i = 1; i <= 5; i++) {

  if (i % 2 === 0) {
    console.log(i);
  }

}

El bucle realiza varias iteraciones y, en cada una de ellas, el if decide si debe ejecutarse console.log(i).

💻 Ejemplo

Las estructuras anidadas permiten expresar situaciones como «repite varias veces y, en cada repetición, toma una decisión» o «si ocurre una situación, realiza una segunda comprobación».

if dentro de if

Una de las formas más sencillas de anidamiento consiste en colocar un if dentro de otro if.

Observa este ejemplo:

JavaScript 
let edad = 20;
let tieneEntrada = true;

if (edad >= 18) {

  console.log("Es mayor de edad");

  if (tieneEntrada) {
    console.log("Puede acceder");
  }

}

La primera condición comprueba si la persona tiene al menos 18 años. Solo cuando esta condición es true se entra en el primer bloque.

Una vez dentro, se comprueba la segunda condición: tieneEntrada.

Como ambas condiciones se cumplen, la consola mostrará:

Console 
Es mayor de edad
Puede acceder

Funcionamiento paso a paso

  1. JavaScript evalúa edad >= 18.
  2. Como 20 >= 18 es true, entra en el primer bloque.
  3. Se muestra "Es mayor de edad".
  4. Después se evalúa tieneEntrada.
  5. Como su valor es true, también se ejecuta el segundo bloque.
📌 Importante

Una condición interna solo se evalúa cuando la ejecución ha conseguido entrar en el bloque que la contiene.

Añadir alternativas

También podemos combinar estructuras if...else anidadas:

JavaScript 
let edad = 20;
let tieneEntrada = false;

if (edad >= 18) {

  if (tieneEntrada) {
    console.log("Puede acceder");
  } else {
    console.log("Necesita una entrada");
  }

} else {
  console.log("No cumple la edad mínima");
}

En este caso, primero se comprueba la edad. Como la persona es mayor de edad, se realiza una segunda comprobación para saber si tiene entrada.

Como tieneEntrada vale false, la consola mostrará:

Console 
Necesita una entrada

if dentro de un bucle

Otra combinación muy habitual consiste en colocar una estructura condicional dentro de un bucle.

De esta forma podemos repetir una serie de valores y tomar una decisión diferente en cada iteración.

Por ejemplo, podemos recorrer los números del 1 al 10 y comprobar cuáles son pares:

JavaScript 
for (let numero = 1; numero <= 10; numero++) {

  if (numero % 2 === 0) {
    console.log(numero + " es par");
  }

}

En cada iteración, el for proporciona un nuevo valor de numero. Después, el if comprueba si el resto de dividir ese valor entre 2 es igual a 0.

La consola mostrará:

Console 
2 es par
4 es par
6 es par
8 es par
10 es par

if...else dentro de un bucle

También podemos utilizar if...else para realizar una acción diferente en cada iteración.

JavaScript 
for (let numero = 1; numero <= 5; numero++) {

  if (numero % 2 === 0) {
    console.log(numero + " es par");
  } else {
    console.log(numero + " es impar");
  }

}

El resultado será:

Console 
1 es impar
2 es par
3 es impar
4 es par
5 es impar
💻 Ejemplo DAW

En una aplicación web es habitual repetir operaciones y realizar comprobaciones durante cada repetición. Por ejemplo, podemos procesar varios valores y decidir cuáles cumplen una determinada condición. Más adelante aplicaremos esta idea al trabajar con arrays y otros conjuntos de datos.

Bucles anidados

También podemos colocar un bucle dentro de otro. En ese caso hablamos de bucles anidados.

Observa el siguiente ejemplo:

JavaScript 
for (let fila = 1; fila <= 3; fila++) {

  for (let columna = 1; columna <= 2; columna++) {
    console.log("Fila " + fila + ", columna " + columna);
  }

}

Tenemos dos bucles:

  • El bucle exterior utiliza la variable fila.
  • El bucle interior utiliza la variable columna.

Por cada iteración del bucle exterior, el bucle interior se ejecuta completamente.

La consola mostrará:

Console 
Fila 1, columna 1
Fila 1, columna 2
Fila 2, columna 1
Fila 2, columna 2
Fila 3, columna 1
Fila 3, columna 2

Cómo se ejecutan los bucles anidados

Es importante comprender que el bucle interior se ejecuta completamente por cada iteración del bucle exterior.

Cuando el bucle exterior avanza a su siguiente iteración, se vuelve a ejecutar la declaración del bucle interior. Por tanto, su variable de control se inicializa de nuevo con el valor indicado en su for.

En nuestro ejemplo, cada vez que fila cambia de valor, el bucle interior comienza de nuevo con columna = 1 y realiza todas sus iteraciones:

fila columna Resultado
1 1 Fila 1, columna 1
1 2 Fila 1, columna 2
2 1 Fila 2, columna 1
2 2 Fila 2, columna 2
3 1 Fila 3, columna 1
3 2 Fila 3, columna 2
📌 Importante

Si el bucle exterior realiza 3 iteraciones y el interior realiza 2 por cada una de ellas, el bloque interior se ejecutará un total de 6 veces.

Este efecto es importante porque, al anidar bucles, el número de ejecuciones puede aumentar rápidamente.

Por ejemplo, si un bucle exterior realiza 100 iteraciones y, en cada una de ellas, el bucle interior realiza otras 100, el bloque situado dentro de ambos bucles puede ejecutarse:

💻 Ejemplo

100 × 100 = 10.000 veces.

⚠️ Atención

Los bucles anidados son muy útiles, pero debemos tener en cuenta que las repeticiones del bucle exterior y del interior se combinan. Por ello, un número elevado de iteraciones en ambos bucles puede hacer que se ejecuten muchas operaciones.

Construir patrones con bucles anidados

Los bucles anidados también pueden utilizarse para construir patrones. Por ejemplo:

JavaScript 
for (let fila = 1; fila <= 4; fila++) {

  let linea = "";

  for (let columna = 1; columna <= fila; columna++) {
    linea += "*";
  }

  console.log(linea);
}

El resultado será:

Console 
*
**
***
****

En cada iteración del bucle exterior se crea una nueva linea. El bucle interior añade tantos asteriscos como indica el valor actual de fila.

Variables de control

Cuando trabajamos con bucles anidados es especialmente importante utilizar correctamente las variables de control.

Cada bucle debe tener su propia variable para controlar sus iteraciones.

Por ejemplo:

JavaScript 
for (let i = 1; i <= 3; i++) {

  for (let j = 1; j <= 2; j++) {
    console.log("i = " + i + ", j = " + j);
  }

}

En este ejemplo:

  • i controla el bucle exterior.
  • j controla el bucle interior.
⚠️ Atención

No debemos confundir las variables que controlan cada bucle. Utilizar nombres diferentes permite comprender qué estructura controla cada variable y evita errores en el algoritmo.

Utilizar nombres descriptivos

Los nombres i y j son habituales en ejemplos pequeños, pero cuando el contexto lo permite es mejor utilizar nombres que indiquen qué representa cada variable.

Compara:

JavaScript 
for (let fila = 1; fila <= 3; fila++) {

  for (let columna = 1; columna <= 4; columna++) {
    console.log("Fila " + fila + " - Columna " + columna);
  }

}

Los nombres fila y columna hacen que la intención del código sea más fácil de entender.

Lectura paso a paso

Cuando aparecen varias estructuras anidadas, intentar comprender todo el programa de una sola vez puede resultar complicado.

La mejor estrategia consiste en seguir el flujo de ejecución paso a paso.

Observa este programa:

JavaScript 
for (let i = 1; i <= 3; i++) {

  console.log("Iteración " + i);

  if (i === 2) {
    console.log("Valor especial");
  }

}

Podemos analizarlo de esta forma:

Valor de i i === 2 Resultado
1 false Se muestra «Iteración 1».
2 true Se muestra «Iteración 2» y después «Valor especial».
3 false Se muestra «Iteración 3».

Por tanto, la consola mostrará:

Console 
Iteración 1
Iteración 2
Valor especial
Iteración 3

Estrategia para leer estructuras anidadas

Cuando tengas que analizar un programa con varias estructuras, puedes seguir este orden:

  1. Identifica la estructura exterior.
  2. Determina cuándo se ejecuta su bloque.
  3. Localiza las estructuras que aparecen dentro.
  4. Comprueba sus condiciones utilizando los valores de esa iteración.
  5. Anota qué instrucciones se ejecutan.
  6. Continúa con la siguiente iteración o condición.
💻 Consejo

Cuando un programa con estructuras anidadas resulte difícil de seguir, puedes crear una pequeña tabla con los valores de las variables en cada paso. Esta técnica ayuda a comprender el flujo de ejecución y a detectar errores.

Legibilidad

Las estructuras anidadas son necesarias en muchos programas, pero un exceso de niveles de anidamiento puede hacer que el código sea difícil de leer y mantener.

Por ello, debemos prestar especial atención a la indentación y a la organización del código.

Observa este ejemplo:

JavaScript 
if (edad >= 18) {

  if (tieneEntrada) {

    if (accesoPermitido) {
      console.log("Puede entrar");
    }

  }

}

El código es válido, pero cuantos más niveles añadamos, más difícil será seguir el flujo del programa.

⚠️ Atención

Anidar estructuras no significa que debamos añadir niveles innecesarios. Debemos buscar siempre una solución clara y fácil de seguir.

La indentación ayuda a comprender el código

La indentación permite identificar visualmente qué instrucciones pertenecen a cada bloque.

Por ejemplo:

JavaScript 
for (let i = 1; i <= 3; i++) {

  if (i % 2 === 0) {
    console.log(i + " es par");
  } else {
    console.log(i + " es impar");
  }

}

Gracias a la indentación podemos ver rápidamente que el if...else pertenece al bloque del for.

📌 Importante

Una buena indentación no cambia el funcionamiento de JavaScript, pero mejora enormemente la legibilidad del código y ayuda a detectar errores en estructuras anidadas.

🧠 Comprueba lo aprendido

Observa el siguiente programa sin ejecutarlo:

JavaScript 
for (let i = 1; i <= 3; i++) {

  console.log("Inicio " + i);

  if (i === 2) {

    for (let j = 1; j <= 2; j++) {
      console.log("j = " + j);
    }

  }

  console.log("Fin " + i);
}

Responde:

  1. ¿Cuántas iteraciones realiza el bucle exterior?
  2. ¿En qué valor de i se ejecuta el bucle interior?
  3. ¿Cuántas veces se ejecuta el bucle interior?
  4. ¿Qué valores toma j?
  5. ¿Qué mostrará exactamente la consola?
Ver solución

El bucle exterior realiza tres iteraciones, correspondientes a los valores 1, 2 y 3.

El bucle interior solo se ejecuta cuando i === 2. En ese momento realiza dos iteraciones, con j = 1 y j = 2.

La consola mostrará:

Console 
Inicio 1
Fin 1
Inicio 2
j = 1
j = 2
Fin 2
Inicio 3
Fin 3

📌 Recuerda

Las estructuras de control pueden combinarse entre sí. Podemos colocar condiciones dentro de condiciones, condiciones dentro de bucles y bucles dentro de otros bucles. Cuando trabajes con estructuras anidadas, sigue el flujo de ejecución paso a paso, utiliza correctamente las variables de control y mantén una indentación clara para facilitar la lectura del programa.
