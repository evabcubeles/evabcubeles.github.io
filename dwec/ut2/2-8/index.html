2.8 Entrada y salida básica de datos

Hasta ahora hemos utilizado valores escritos directamente en el código y hemos mostrado resultados principalmente mediante console.log(). Sin embargo, muchos programas necesitan recibir datos del usuario y mostrarle información como respuesta.

En este apartado utilizaremos herramientas sencillas del navegador para practicar la entrada y salida de datos: console.log(), alert() y prompt(). También veremos un aspecto especialmente importante: prompt() devuelve texto, por lo que en muchas ocasiones tendremos que convertir el dato antes de realizar cálculos.

📌 Importante

En este apartado utilizaremos alert() y prompt() como herramientas sencillas para practicar la entrada y salida de datos. Más adelante, en la UT7, estudiaremos con mayor detalle la interacción con el navegador y sus objetos predefinidos.

Salida con console.log()

El método console.log() permite mostrar información en la Console de las herramientas de desarrollo del navegador. Ya lo hemos utilizado en apartados anteriores para comprobar valores y resultados.

JavaScript 
const nombre = "Lucía";
const edad = 20;

console.log(nombre);
console.log(edad);
console.log(`Hola, ${nombre}. Tienes ${edad} años.`);

El resultado será:

Console 
Lucía
20
Hola, Lucía. Tienes 20 años.
💻 Ejemplo DAW

Durante el desarrollo de una aplicación web, console.log() resulta muy útil para comprobar el contenido de variables, seguir la ejecución del programa y localizar errores. El usuario final normalmente no ve estos mensajes.

Salida con alert()

La función alert() muestra un cuadro de diálogo en el navegador con un mensaje y un botón para cerrarlo.

JavaScript 
alert("Bienvenido a la aplicación");

También podemos construir el mensaje utilizando variables o template literals:

JavaScript 
const usuario = "Ana";

alert(`Hola, ${usuario}`);
⚠️ Atención

alert() interrumpe temporalmente la interacción con la página hasta que el usuario cierra el cuadro de diálogo. Por ello es útil para ejemplos sencillos, pero en aplicaciones web modernas no debemos abusar de este tipo de ventanas.

Entrada con prompt()

La función prompt() muestra un cuadro de diálogo que permite al usuario introducir un dato mediante el teclado. El valor introducido puede guardarse en una variable para utilizarlo después.

JavaScript 
const nombre = prompt("¿Cómo te llamas?");

console.log(nombre);

Podemos combinar la entrada y la salida de datos:

JavaScript 
const nombre = prompt("¿Cómo te llamas?");

alert(`Hola, ${nombre}`);
console.log(`El usuario se llama ${nombre}`);
📌 Importante

Si el usuario pulsa Cancelar en un prompt(), el resultado es el valor null. Más adelante aprenderemos a controlar este tipo de situaciones mediante estructuras condicionales.

prompt() devuelve texto

Aunque el usuario escriba un número, prompt() devuelve normalmente el dato como una cadena de texto. Este comportamiento es fundamental cuando queremos realizar operaciones matemáticas.

JavaScript 
const edad = prompt("Introduce tu edad:");

console.log(edad);
console.log(typeof edad);

Si el usuario introduce 20, en Console veremos:

Console 
20
string

Esto puede producir resultados inesperados si utilizamos directamente el dato en una operación:

JavaScript 
const edad = prompt("Introduce tu edad:");

console.log(edad + 1);

Si el usuario introduce 20, el resultado será:

Console 
201
⚠️ Atención

El resultado es 201 porque edad contiene la cadena "20". Al utilizar el operador + con una cadena, JavaScript realiza una concatenación en lugar de una suma numérica.

Conversión de datos introducidos

Cuando esperamos que el usuario introduzca un número, podemos convertir el resultado de prompt() utilizando las funciones estudiadas en el apartado 2.4. Una opción habitual es utilizar Number().

JavaScript 
const edad = Number(prompt("Introduce tu edad:"));

console.log(edad);
console.log(typeof edad);
console.log(edad + 1);

Si el usuario introduce 20, el resultado será:

Console 
20
number
21

También podemos guardar primero el texto introducido y realizar después la conversión. Esta forma permite observar con claridad cada paso:

JavaScript 
const datoIntroducido = prompt("Introduce un precio:");
const precio = Number(datoIntroducido);

console.log(datoIntroducido);
console.log(typeof datoIntroducido);

console.log(precio);
console.log(typeof precio);
⚠️ Atención

Si el texto introducido no puede convertirse correctamente en un número, Number() puede producir NaN. Ya hemos visto en el apartado 2.7 cómo reconocer este valor mediante Number.isNaN().

💻 Ejemplo DAW

Imagina una página que pide el precio y la cantidad de un producto. Antes de calcular el total necesitamos convertir los datos introducidos en números.

JavaScript 
const precio = Number(prompt("Introduce el precio del producto:"));
const cantidad = Number(prompt("Introduce la cantidad:"));

const total = precio * cantidad;

alert(`El importe total es ${total.toFixed(2)} €`);

🧠 Comprueba lo aprendido

Supón que el usuario introduce 10 en los dos cuadros de diálogo. Antes de ejecutar el código, intenta predecir el resultado de cada console.log():

JavaScript 
const dato1 = prompt("Introduce un número:");
const dato2 = Number(prompt("Introduce otro número:"));

console.log(typeof dato1);
console.log(typeof dato2);
console.log(dato1 + 5);
console.log(dato2 + 5);
Ver solución

Primera instrucción: muestra string.

Segunda instrucción: muestra number.

Tercera instrucción: muestra 105, porque dato1 contiene texto.

Cuarta instrucción: muestra 15, porque dato2 se ha convertido en número.

💻 Prueba en el navegador

Crea un archivo HTML enlazado con un archivo JavaScript y escribe el siguiente código. Introduce distintos valores y observa el resultado:

JavaScript 
const nombre = prompt("Introduce tu nombre:");
const edad = Number(prompt("Introduce tu edad:"));

console.log(`Nombre: ${nombre}`);
console.log(`Edad: ${edad}`);

alert(`Hola, ${nombre}. El año que viene tendrás ${edad + 1} años.`);
📌 Reto

Modifica el programa para pedir también una nota numérica y mostrar en Console el nombre, la edad y la nota introducida. Comprueba con typeof qué tipo tiene cada dato después de realizar las conversiones necesarias.
