2.7 Números y objeto Math

En JavaScript utilizamos números continuamente: precios, cantidades, edades, notas, coordenadas, porcentajes o resultados de cálculos. En este apartado profundizaremos en el tipo number y veremos algunas herramientas útiles para trabajar con valores numéricos.

También conoceremos NaN e Infinity, aprenderemos a mostrar números con una determinada precisión y utilizaremos el objeto Math para realizar operaciones matemáticas frecuentes.

📌 Importante

JavaScript utiliza el tipo number tanto para números enteros como para números decimales. No existen tipos separados como int y float para estos valores.

Números enteros y decimales

Podemos escribir directamente números enteros y decimales en nuestro código. Los decimales se escriben utilizando un punto como separador decimal.

JavaScript 
const edad = 20;
const precio = 19.95;
const temperatura = -3.5;

console.log(edad);
console.log(precio);
console.log(temperatura);
⚠️ Atención

En JavaScript los decimales se escriben con punto. Por ejemplo, 19.95 es correcto, mientras que 19,95 no representa un número decimal.

También podemos utilizar notación científica cuando trabajamos con números muy grandes o muy pequeños:

JavaScript 
const distancia = 3e8;
const cantidadPequena = 2.5e-4;

console.log(distancia);
console.log(cantidadPequena);

El resultado será:

Console 
300000000
0.00025

NaN e Infinity

JavaScript dispone de algunos valores numéricos especiales. Uno de ellos es NaN, abreviatura de Not a Number. Representa el resultado de una operación numérica que no produce un valor numérico válido. Puede aparecer, por ejemplo, cuando intentamos convertir en número una cadena que no contiene un valor numérico.

JavaScript 
const resultado = Number("hola");

console.log(resultado);
console.log(typeof resultado);

El resultado será:

Console 
NaN
number
📌 Importante

Aunque su nombre significa Not a Number, NaN pertenece al tipo number. Por eso typeof NaN devuelve "number".

Para comprobar si un valor es realmente NaN podemos utilizar Number.isNaN():

JavaScript 
const resultado = Number("hola");

console.log(Number.isNaN(resultado));

El resultado será:

Console 
true
⚠️ Atención

No debemos comprobar NaN utilizando resultado === NaN, ya que NaN tiene una característica especial: no es igual ni siquiera a sí mismo. Para realizar esta comprobación utilizaremos Number.isNaN().

Otro valor especial es Infinity, que representa un valor infinito. Puede aparecer, por ejemplo, al dividir un número distinto de cero entre 0.

JavaScript 
console.log(10 / 0);
console.log(-10 / 0);
Console 
Infinity
-Infinity
⚠️ Atención

Que una operación produzca NaN o Infinity normalmente indica que debemos revisar los datos o el cálculo realizado.

toFixed()

El método toFixed() permite representar un número utilizando un número determinado de cifras decimales. Indicamos entre paréntesis cuántos decimales queremos mostrar.

JavaScript 
const precio = 19.9567;

console.log(precio.toFixed(2));
console.log(precio.toFixed(3));
Console 
19.96
19.957
📌 Importante

toFixed() devuelve una cadena de texto, no un número. Es muy útil cuando queremos preparar un valor para mostrarlo al usuario, por ejemplo un precio con dos decimales.

💻 Ejemplo DAW

Si un producto cuesta 12.5 euros, podemos mostrar 12.50 € utilizando precio.toFixed(2).

toPrecision()

El método toPrecision() permite indicar el número total de cifras significativas que queremos utilizar para representar un número.

JavaScript 
const numero = 123.456;

console.log(numero.toPrecision(4));
console.log(numero.toPrecision(6));
Console 
123.5
123.456

La diferencia principal es que toFixed() controla el número de decimales, mientras que toPrecision() controla el número total de cifras significativas.

Método Controla Ejemplo con 123.456
toFixed(2) Número de decimales "123.46"
toPrecision(4) Número total de cifras significativas "123.5"
⚠️ Atención

Igual que toFixed(), toPrecision() devuelve una cadena de texto.

El objeto Math

JavaScript incorpora el objeto predefinido Math, que agrupa propiedades y métodos útiles para realizar operaciones matemáticas.

No necesitamos crear un objeto Math. Utilizamos directamente su nombre seguido de un punto y de la propiedad o método que queramos emplear.

JavaScript 
console.log(Math.PI);
console.log(Math.sqrt(25));
console.log(Math.abs(-8));
console.log(Math.max(4, 12, 7));
console.log(Math.min(4, 12, 7));
Console 
3.141592653589793
5
8
12
4
Elemento Utilidad
Math.PIValor aproximado de π.
Math.sqrt(x)Raíz cuadrada de un número.
Math.abs(x)Valor absoluto.
Math.max(...)Mayor de varios valores.
Math.min(...)Menor de varios valores.
📌 Importante

En este apartado utilizamos Math de forma práctica para trabajar con números. Más adelante, en la UT7, estudiaremos con más detalle los objetos predefinidos de JavaScript.

round(), floor() y ceil()

El objeto Math dispone de varios métodos para redondear números. Los tres más habituales son Math.round(), Math.floor() y Math.ceil().

Método Comportamiento Ejemplo
Math.round() Redondea al entero más cercano. Math.round(4.6) → 5
Math.floor() Redondea hacia abajo. Math.floor(4.9) → 4
Math.ceil() Redondea hacia arriba. Math.ceil(4.1) → 5
JavaScript 
const numero = 7.6;

console.log(Math.round(numero));
console.log(Math.floor(numero));
console.log(Math.ceil(numero));
Console 
8
7
8
⚠️ Atención

Con números negativos, “hacia abajo” y “hacia arriba” se refieren a su posición en la recta numérica. Por ejemplo, Math.floor(-4.2) devuelve -5 y Math.ceil(-4.2) devuelve -4.

Math.random()

El método Math.random() genera un número decimal pseudoaleatorio comprendido entre 0, incluido, y 1, excluido.

JavaScript 
console.log(Math.random());

Cada ejecución puede producir un valor diferente, por ejemplo 0.347281....

📌 Importante

Math.random() cumple 0 <= resultado < 1. Puede devolver 0, pero nunca 1.

Si queremos obtener un número entero aleatorio entre 1 y 10, podemos combinar Math.random() con Math.floor():

JavaScript 
const numeroAleatorio = Math.floor(Math.random() * 10) + 1;

console.log(numeroAleatorio);

Primero Math.random() * 10 produce un valor entre 0 y casi 10. Después Math.floor() obtiene un entero entre 0 y 9, y finalmente sumamos 1 para obtener un valor entre 1 y 10.

Si queremos generar un número entero entre un valor mínimo y un valor máximo, ambos incluidos, podemos utilizar la siguiente expresión:

JavaScript 
Math.floor(Math.random() * (maximo - minimo + 1)) + minimo;
📌 Importante

La expresión anterior genera un número entero comprendido entre minimo y maximo, incluyendo ambos extremos.

💻 Ejemplo DAW

Los números aleatorios pueden utilizarse para elegir preguntas al azar, seleccionar elementos de una lista o crear pequeños juegos. Para usos de seguridad, contraseñas o criptografía no debemos utilizar Math.random().

🧠 Comprueba lo aprendido

Antes de ejecutar el código, intenta predecir el resultado de cada expresión:

JavaScript 
const numero = 12.678;

console.log(numero.toFixed(2));
console.log(numero.toPrecision(3));
console.log(Math.round(4.7));
console.log(Math.floor(4.7));
console.log(Math.ceil(4.2));
console.log(Math.sqrt(81));
console.log(Math.abs(-15));
Ver solución

12.68 — resultado de numero.toFixed(2).

12.7 — resultado de numero.toPrecision(3).

5 — resultado de Math.round(4.7).

4 — resultado de Math.floor(4.7).

5 — resultado de Math.ceil(4.2).

9 — resultado de Math.sqrt(81).

15 — resultado de Math.abs(-15).

💻 Prueba en Console

Copia el siguiente código en Console. Ejecútalo varias veces y observa cómo cambia el número aleatorio. Después modifica el código para generar un número entero entre 1 y 20.

Console 
const minimo = 1;
const maximo = 10;

const numeroAleatorio =
  Math.floor(Math.random() * (maximo - minimo + 1)) + minimo;

console.log(numeroAleatorio);
📌 Reto

Cambia los valores de minimo y maximo y comprueba que el programa siempre genera un entero dentro del intervalo indicado.
