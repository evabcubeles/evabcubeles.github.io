2.11 Prueba y depuración del código

Cuando programamos es normal cometer errores. Una variable puede estar mal escrita, puede faltar un paréntesis o podemos intentar realizar una operación que JavaScript no sabe ejecutar.

La depuración o debugging es el proceso de localizar, comprender y corregir esos errores. Los navegadores actuales incorporan herramientas de desarrollo que nos permiten analizar qué está ocurriendo en nuestro código.

📌 Importante

Depurar no consiste simplemente en cambiar código hasta que funcione. Debemos observar el error, localizar su origen, comprender la causa y comprobar después que la solución funciona correctamente.

Uso de Console

La pestaña Console de las herramientas de desarrollo del navegador permite ejecutar instrucciones JavaScript, mostrar información y consultar los errores que se producen durante la ejecución.

Podemos abrir las herramientas de desarrollo con F12 o con la combinación Ctrl + Shift + I en muchos navegadores. Después seleccionamos la pestaña Console.

JavaScript 
const nombre = "Ana";
const edad = 20;

console.log(nombre);
console.log(edad);
console.log(`Usuario: ${nombre} - Edad: ${edad}`);

console.log() es especialmente útil para comprobar qué valor tiene una variable en un momento determinado del programa.

💻 Ejemplo DAW

Si una página calcula incorrectamente el importe de un pedido, podemos mostrar en Console el precio, la cantidad y el resultado intermedio para averiguar en qué punto comienza el problema.

Mensajes de error

Cuando JavaScript encuentra un problema que impide ejecutar correctamente una instrucción, el navegador suele mostrar un mensaje de error en Console.

Estos mensajes nos ofrecen pistas sobre el problema. Habitualmente incluyen:

  • El tipo de error.
  • Una breve descripción del problema.
  • El archivo en el que se ha producido.
  • La línea y, en muchos casos, la columna.
Console 
ReferenceError: precioFinal is not defined
    at app.js:8:13

En este ejemplo, JavaScript indica que no encuentra precioFinal y señala que el problema aparece en el archivo app.js, línea 8.

⚠️ Atención

No debemos ignorar el mensaje de error. Leerlo con atención suele ser el primer paso para encontrar la causa del problema.

SyntaxError

Un SyntaxError aparece cuando escribimos código que no respeta la sintaxis esperada por JavaScript. El navegador no puede interpretar correctamente esa parte del programa.

JavaScript 
const nombre = "Lucía;

console.log(nombre);

En este caso falta la comilla que cierra la cadena de texto. El navegador mostrará un error de sintaxis porque no puede interpretar correctamente la instrucción.

Otros errores de sintaxis frecuentes son:

  • Olvidar cerrar un paréntesis.
  • Olvidar cerrar una llave.
  • Escribir incorrectamente una instrucción.
  • Dejar una cadena de texto sin cerrar.
📌 Clave

Los errores de sintaxis suelen impedir que JavaScript pueda interpretar correctamente el código afectado. Revisaremos primero los signos de apertura y cierre, las palabras reservadas y la línea indicada por el navegador.

ReferenceError

Un ReferenceError se produce cuando intentamos utilizar un identificador que JavaScript no encuentra en el ámbito actual.

JavaScript 
const precio = 25;

console.log(precioFinal);

Hemos declarado precio, pero intentamos mostrar precioFinal, que no existe.

La Console mostrará un mensaje similar a:

Console 
ReferenceError: precioFinal is not defined
⚠️ Atención

Un ReferenceError puede deberse a un nombre mal escrito, a una variable que no ha sido declarada o a que intentamos acceder a ella desde un ámbito en el que no está disponible.

TypeError

Un TypeError aparece cuando intentamos realizar una operación o utilizar una propiedad o método que no es válido para el valor con el que estamos trabajando.

JavaScript 
const edad = 20;

edad.toUpperCase();

toUpperCase() es un método utilizado con cadenas de texto. Como edad contiene un número, JavaScript no puede aplicar ese método.

La Console mostrará un mensaje similar a:

Console 
TypeError: edad.toUpperCase is not a function
💻 Consejo

Cuando aparezca un TypeError, conviene comprobar qué valor contiene realmente la variable y cuál es su tipo. Podemos utilizar console.log() y typeof para investigarlo.

Archivo y línea del error

Además del tipo de error, la Console suele mostrar el archivo y la posición aproximada en la que se ha producido. Esta información nos permite ir directamente a la parte del código que debemos revisar.

Console 
Uncaught ReferenceError: total is not defined
    at app.js:12:13

En app.js:12:13, el primer número corresponde normalmente a la línea 12 y el segundo a la columna 13.

📌 Importante

La línea indicada señala dónde se ha detectado el error, pero la causa real puede encontrarse unas líneas antes. Por ejemplo, una variable puede haberse escrito incorrectamente al declararla.

Sources y breakpoints

La pestaña Sources de las herramientas de desarrollo permite consultar los archivos cargados por la página y detener temporalmente la ejecución de JavaScript para analizar qué está ocurriendo.

Un breakpoint o punto de interrupción es una marca que colocamos en una línea de código para detener temporalmente la ejecución del programa cuando se alcanza ese punto. De esta forma podemos observar los valores de las variables y continuar la ejecución paso a paso.

Para crear un breakpoint de forma básica:

  • Abre las herramientas de desarrollo con F12.
  • Entra en la pestaña Sources.
  • Abre el archivo JavaScript que quieras analizar.
  • Haz clic sobre el número de la línea en la que quieres detener la ejecución.
  • Recarga la página o vuelve a realizar la acción que ejecuta ese código.
JavaScript 
const precio = 12;
const cantidad = 3;

const subtotal = precio * cantidad;
const iva = subtotal * 0.21;
const total = subtotal + iva;

console.log(total);

Podemos colocar un breakpoint, por ejemplo, en la línea donde se calcula subtotal. Cuando la ejecución se detenga podremos consultar los valores de las variables y avanzar paso a paso.

⚠️ Atención

La apariencia exacta de DevTools puede variar ligeramente entre navegadores y versiones, pero las herramientas principales —Console, Sources, breakpoints e inspección de variables— funcionan de forma muy similar.

Ciclo de depuración

Cuando encontramos un error conviene seguir un proceso ordenado. Esto evita realizar cambios al azar y nos ayuda a comprender qué estaba ocurriendo realmente.

1. Reproducir Comprobar cuándo aparece el problema.
2. Observar Leer Console y revisar los valores.
3. Localizar Encontrar el archivo y la línea implicados.
4. Comprender Determinar cuál es la causa del error.
5. Corregir Modificar únicamente lo necesario.
6. Comprobar Ejecutar de nuevo y verificar la solución.
📌 Regla práctica

Reproduce → observa → localiza → comprende → corrige → comprueba. Convertir este proceso en un hábito permite resolver errores con mucha más eficacia.

🧠 Identifica el error

Observa los siguientes fragmentos. Antes de ejecutarlos, indica qué tipo de error esperas encontrar en cada uno.

JavaScript A 
const ciudad = "Teruel;

console.log(ciudad);
JavaScript B 
const nombre = "Lucía";

console.log(nomrbe);
JavaScript C 
const puntos = 10;

puntos.toUpperCase();
Ver solución

A: SyntaxError, porque falta cerrar la cadena de texto.

B: ReferenceError, porque se utiliza nomrbe en lugar de nombre.

C: TypeError, porque intentamos utilizar toUpperCase() sobre un número.

💻 Depura paso a paso

Crea un archivo JavaScript con el siguiente código y ejecútalo desde una página HTML. Utiliza Console y Sources para localizar el problema.

JavaScript 
const precioProducto = 15;
const cantidad = 4;

const subtotal = precioProducto * cantidad;
const descuento = subtotal * 0.10;
const total = subtotal - descuneto;

console.log(`Total: ${total} €`);
📌 Reto

Localiza el error utilizando el mensaje de Console, corrígelo y coloca después un breakpoint en la línea que calcula total. Comprueba los valores de subtotal y descuento antes de continuar la ejecución.

Ver solución

El problema está en el nombre descuneto. La variable declarada anteriormente se llama descuento.

La instrucción correcta es:

JavaScript 
const total = subtotal - descuento;

Antes de corregirlo, la Console mostrará un ReferenceError porque JavaScript intenta encontrar una variable llamada descuneto que no ha sido declarada.
