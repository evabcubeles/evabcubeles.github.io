UT2 - Fundamentos de JavaScript: variables, tipos y operadores

En esta unidad comenzaremos a trabajar con la sintaxis de JavaScript de forma sistemática, aprendiendo a escribir sentencias simples y a comprobar su ejecución directamente en el navegador.

Estudiaremos cómo declarar variables y constantes, qué tipos de datos utiliza JavaScript, cómo se producen las conversiones entre tipos y qué operadores podemos utilizar para construir expresiones.

También aprenderemos a trabajar con cadenas de texto, números y el objeto Math, utilizaremos mecanismos básicos de entrada y salida de datos y estudiaremos el ámbito de las variables, un concepto fundamental para comprender cómo se organiza el código JavaScript.

A lo largo de toda la unidad seguiremos utilizando Console y las herramientas de desarrollo del navegador para probar instrucciones, interpretar mensajes de error y adquirir un método de depuración basado en observar, localizar, corregir y volver a probar.
