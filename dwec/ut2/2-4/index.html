2.4 Conversión de tipos

En el apartado anterior vimos que JavaScript puede trabajar con distintos tipos de datos, como cadenas de texto, números o valores booleanos. En muchas situaciones necesitaremos transformar un valor de un tipo en otro.

Esta transformación se denomina conversión de tipos. Puede hacerse de forma explícita, cuando la indicamos nosotros en el código, o de forma implícita, cuando JavaScript intenta realizarla automáticamente.

📌 Importante

Comprender cómo convierte JavaScript los datos es fundamental para evitar resultados inesperados. Un mismo valor puede comportarse de forma diferente dependiendo de si es un número, una cadena o un valor booleano.

Conversión explícita

Hablamos de conversión explícita cuando indicamos de forma intencionada que queremos transformar un valor a otro tipo.

Para ello JavaScript proporciona funciones como Number(), String() y Boolean().

JavaScript 
const textoEdad = "25";
const edad = Number(textoEdad);

console.log(edad);
console.log(typeof edad);

El resultado será:

Console 
25
number

Aunque "25" y 25 puedan parecer iguales visualmente, representan valores de tipos distintos: el primero es una cadena y el segundo un número.

Number(), String() y Boolean()

Convertir a número con Number()

Number() intenta convertir un valor en un número.

JavaScript 
console.log(Number("42"));
console.log(Number("19.95"));
console.log(Number(true));
console.log(Number(false));

Obtendremos:

Console 
42
19.95
1
0

Una cadena que contiene un número válido puede convertirse correctamente. Los valores booleanos también tienen una conversión numérica: true se convierte en 1 y false en 0.

⚠️ Atención

Si intentamos convertir a número una cadena que no representa un valor numérico válido, obtendremos NaN (Not a Number).

JavaScript 
const resultado = Number("hola");

console.log(resultado);
Resultado 
NaN
⚠️ Atención

Aunque NaN significa Not a Number, en JavaScript pertenece al tipo number. Por eso typeof NaN devuelve "number". Estudiaremos este valor con más detalle en el apartado 2.7.

Convertir a texto con String()

String() convierte un valor en una cadena de texto.

JavaScript 
console.log(String(25));
console.log(String(true));
console.log(String(false));

El resultado será:

Console 
25
true
false

Los valores obtenidos son cadenas de texto, aunque Console los muestre de forma similar a los valores originales.

Convertir a booleano con Boolean()

Boolean() convierte un valor en true o false. Para entender su comportamiento debemos conocer los llamados valores falsy.

Algunos valores se convierten en false al evaluarlos como booleanos. Entre los más importantes están:

Valor Boolean(valor)
falsefalse
0false
""false
nullfalse
undefinedfalse
NaNfalse

La mayoría de los demás valores se convierten en true.

JavaScript 
console.log(Boolean(1));
console.log(Boolean("DWEC"));
console.log(Boolean(0));
console.log(Boolean(""));

El resultado será:

Console 
true
true
false
false
⚠️ Atención

La cadena "false" se convierte en true porque es una cadena no vacía. JavaScript no interpreta su contenido como el valor booleano false.

parseInt() y parseFloat()

JavaScript también proporciona parseInt() y parseFloat() para obtener valores numéricos a partir de cadenas de texto.

parseInt()

parseInt() intenta interpretar el comienzo de una cadena como un número entero.

JavaScript 
console.log(parseInt("25", 10));
console.log(parseInt("25.8", 10));
console.log(parseInt("25px", 10));

Obtendremos:

Console 
25
25
25

En los dos últimos casos parseInt() se detiene cuando encuentra un carácter que ya no puede formar parte del entero.

📌 Buena práctica

Cuando utilicemos parseInt(), indicaremos normalmente la base decimal de forma explícita mediante parseInt(valor, 10).

parseFloat()

parseFloat() funciona de forma similar, pero permite conservar la parte decimal.

JavaScript 
console.log(parseFloat("25.8"));
console.log(parseFloat("19.95€"));

Obtendremos:

Console 
25.8
19.95

Diferencia entre Number() y parseInt()/parseFloat()

Expresión Resultado
Number("25")25
Number("25px")NaN
parseInt("25px", 10)25
parseFloat("19.95€")19.95
📌 Importante

Number() intenta convertir el valor completo. En cambio, parseInt() y parseFloat() pueden interpretar una parte numérica inicial de una cadena y detenerse al encontrar otros caracteres.

Conversión implícita o coerción

En ocasiones JavaScript realiza conversiones automáticamente. Este proceso se denomina conversión implícita o coerción de tipos.

JavaScript 
console.log("5" + 2);
console.log("5" - 2);
console.log("5" * 2);

El resultado será:

Console 
52
3
10

El operador + tiene un comportamiento especial porque puede utilizarse tanto para sumar números como para concatenar cadenas. Si uno de los operandos es una cadena, JavaScript puede convertir el otro valor a texto y realizar una concatenación. Por eso "5" + 2 produce "52".

En cambio, operadores como - o * trabajan con valores numéricos, por lo que JavaScript intenta convertir la cadena "5" en el número 5.

⚠️ Atención

La coerción automática puede producir resultados que sorprendan si no tenemos claro el tipo de cada dato. Cuando necesitemos un tipo concreto, es preferible realizar una conversión explícita.

💻 Ejemplo DAW

Los datos introducidos por el usuario en un formulario suelen llegar como texto. Si esperamos una edad, una cantidad o un precio, tendremos que convertir ese texto a número antes de realizar operaciones aritméticas.

Casos prácticos de conversión

Convertir una edad escrita como texto

JavaScript 
const edadTexto = "18";
const edad = Number(edadTexto);

console.log(edad);
console.log(typeof edad);

Convertir un precio con decimales

JavaScript 
const precioTexto = "49.95";
const precio = parseFloat(precioTexto);

console.log(precio);

Convertir un número a texto

JavaScript 
const numeroPedido = 152;
const codigoPedido = String(numeroPedido);

console.log(codigoPedido);
console.log(typeof codigoPedido);

🧠 Comprueba lo aprendido

Antes de ejecutar el código, intenta predecir el resultado de cada expresión:

JavaScript 
Number("30")
Number("hola")
String(25)
Boolean(0)
Boolean("0")
parseInt("18.7", 10)
parseFloat("18.7px")
"10" + 5
"10" - 5
Ver solución

Number("30") → 30.

Number("hola") → NaN.

String(25) → "25".

Boolean(0) → false.

Boolean("0") → true, porque es una cadena no vacía.

parseInt("18.7", 10) → 18.

parseFloat("18.7px") → 18.7.

"10" + 5 → "105".

"10" - 5 → 5.

💻 Prueba en Console

Ejecuta las siguientes instrucciones una a una y comprueba el tipo del resultado con typeof:

Console 
const dato1 = Number("42");
const dato2 = String(42);
const dato3 = Boolean("");
const dato4 = parseInt("25px", 10);
const dato5 = parseFloat("19.95€");

console.log(typeof dato1);
console.log(typeof dato2);
console.log(typeof dato3);
console.log(typeof dato4);
console.log(typeof dato5);

Explica qué conversión se ha realizado en cada caso y por qué el resultado obtenido tiene ese tipo.
