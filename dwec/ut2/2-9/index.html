2.9 Comentarios y buenas prácticas

Escribir código que funcione es importante, pero también lo es escribir código claro, legible y fácil de mantener. Un programa puede funcionar correctamente y, sin embargo, resultar difícil de comprender si está desorganizado, utiliza nombres poco descriptivos o contiene comentarios innecesarios.

En este apartado aprenderemos a utilizar comentarios en JavaScript y veremos algunas buenas prácticas básicas relacionadas con los nombres, la indentación y la organización del código.

📌 Importante

El objetivo de las buenas prácticas no es que el código sea más largo, sino que sea más fácil de leer, comprender, modificar y depurar.

Comentarios de una línea

Los comentarios son textos que escribimos dentro del código para aportar información a las personas que lo leen. JavaScript ignora los comentarios durante la ejecución.

Para escribir un comentario de una sola línea utilizamos dos barras inclinadas: //.

JavaScript 
// Precio del producto
const precio = 25;

// Calculamos el precio con IVA
const precioFinal = precio * 1.21;

console.log(precioFinal);

Todo lo que aparece después de // hasta el final de esa línea se considera un comentario.

💻 Ejemplo DAW

Los comentarios pueden ser útiles para explicar una decisión concreta del programa, dejar una aclaración importante o indicar por qué se realiza una operación que no resulta evidente a primera vista.

Comentarios de bloque

Cuando necesitamos escribir un comentario que ocupa varias líneas podemos utilizar /* para iniciarlo y */ para finalizarlo.

JavaScript 
/*
  Calculamos el importe total del pedido
  a partir del precio y de la cantidad.
*/
const precio = 15;
const cantidad = 3;

const total = precio * cantidad;

console.log(total);
⚠️ Atención

No debemos utilizar comentarios de bloque para ocultar grandes cantidades de código que ya no necesitamos. Si un fragmento ha dejado de ser útil, normalmente es mejor eliminarlo.

Cuándo comentar

Un buen comentario debe aportar información que no sea evidente leyendo el propio código. No es necesario comentar cada instrucción.

Compara estos dos ejemplos:

JavaScript 
// Guardamos 20 en edad
const edad = 20;

// Sumamos 1 a edad
const edadProximoAnio = edad + 1;

Estos comentarios no aportan información nueva porque simplemente repiten lo que ya podemos leer en el código.

Sería más útil escribir algo como:

JavaScript 
const precio = 100;

// La promoción aplica un descuento fijo del 15 %
const precioConDescuento = precio * 0.85;
📌 Importante

Siempre que sea posible, intentaremos que el propio código se explique mediante nombres claros y una buena organización. Los comentarios deben complementar al código, no sustituir su legibilidad.

Legibilidad del código

La legibilidad indica lo fácil que resulta leer y comprender un programa. Un código legible ayuda a detectar errores, facilita las modificaciones y permite que otras personas puedan trabajar con él.

Algunas prácticas sencillas mejoran mucho la legibilidad:

  • Utilizar nombres descriptivos para variables y constantes.
  • Mantener una indentación coherente.
  • Separar visualmente bloques de código relacionados.
  • Evitar instrucciones innecesariamente complicadas.
  • Utilizar espacios de forma consistente alrededor de los operadores.
  • Escribir comentarios solo cuando aporten información útil.
JavaScript 
const precioProducto = 29.95;
const unidades = 3;

const importeTotal = precioProducto * unidades;

console.log(`Total: ${importeTotal.toFixed(2)} €`);
💻 Ejemplo DAW

En desarrollo web es habitual trabajar en equipo y volver a modificar código escrito semanas o meses antes. Un código claro reduce el tiempo necesario para entender qué hace una aplicación y cómo está organizada.

Nombres descriptivos

Los nombres de variables y constantes deben indicar con claridad qué información almacenan. Debemos evitar nombres excesivamente cortos o ambiguos cuando no expresan su propósito.

Poco descriptivo Más descriptivo
p precioProducto
n nombreUsuario
t importeTotal
x numeroIntentos

En JavaScript utilizaremos habitualmente la convención camelCase para nombrar variables:

JavaScript 
const nombreAlumno = "Laura";
const notaFinal = 8.5;
const numeroDeIntentos = 3;
⚠️ Atención

Un nombre más largo no siempre es mejor. Debe ser suficientemente descriptivo, pero también sencillo de leer y utilizar.

Indentación y organización

La indentación consiste en desplazar determinadas líneas hacia la derecha para mostrar visualmente la estructura del programa. En los ejemplos sencillos que hemos visto hasta ahora apenas es necesaria, pero será fundamental cuando trabajemos con estructuras condicionales, bucles y funciones.

Por ejemplo, en el siguiente código podemos distinguir fácilmente qué instrucciones pertenecen al bloque del if:

JavaScript 
const edad = 20;

if (edad >= 18) {
  console.log("Es mayor de edad");
  console.log("Puede continuar");
}

Todavía no necesitamos conocer en profundidad la estructura if; la estudiaremos en la UT3. Por ahora fíjate únicamente en la organización visual del bloque.

📌 Importante

La indentación no cambia el resultado del programa en JavaScript, pero es esencial para que el código sea comprensible. Debemos utilizar siempre un criterio coherente a lo largo de todo el proyecto.

También es conveniente separar con líneas en blanco las partes del programa que cumplen funciones diferentes:

JavaScript 
const nombre = "Ana";
const precio = 20;
const cantidad = 2;

const total = precio * cantidad;

console.log(`Cliente: ${nombre}`);
console.log(`Total: ${total} €`);

🧠 Comprueba lo aprendido

Observa el siguiente código y piensa qué aspectos podrían mejorarse:

JavaScript 
const p = 25;
const c = 4;
// Multiplicamos p por c
const t = p*c;
console.log(t);
Ver solución

Los nombres p, c y t son poco descriptivos. Podríamos utilizar precio, cantidad e importeTotal.

El comentario no aporta información útil porque simplemente repite la operación.

También podemos mejorar la legibilidad dejando espacios alrededor del operador *.

💻 Mejora el código

Reescribe el siguiente programa aplicando las buenas prácticas estudiadas:

JavaScript 
const n = "Carlos";
const p = 12.5;
const u = 3;
// calculo
const x=p*u;
console.log(n);
console.log(x);
📌 Reto

Utiliza nombres descriptivos, espacios alrededor de los operadores y elimina o sustituye el comentario por otro que realmente aporte información. Después muestra en Console un mensaje claro con el nombre del cliente y el importe total.
