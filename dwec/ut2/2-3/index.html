2.3 Tipos de datos en JavaScript

En el apartado anterior aprendimos a guardar datos mediante variables y constantes. Pero no todos los datos representan lo mismo: un nombre es texto, una edad puede ser un número y una respuesta como «sí» o «no» puede representarse mediante un valor lógico.

JavaScript distingue diferentes tipos de datos. Conocerlos nos permite comprender qué clase de información estamos manejando y qué operaciones podemos realizar con ella.

📌 Importante

JavaScript es un lenguaje de tipado dinámico. No indicamos explícitamente el tipo de una variable al declararla: el tipo está asociado al valor que contiene en cada momento.

JavaScript 
let dato = 25;
console.log(dato);

dato = "veinticinco";
console.log(dato);

La misma variable puede contener primero un número y después una cadena de texto. Esta flexibilidad es característica de JavaScript, aunque debemos utilizarla con cuidado para mantener el código comprensible.

Tipos primitivos

En JavaScript existen varios tipos primitivos. Son los tipos básicos que utiliza el lenguaje para representar valores simples.

Tipo Ejemplo Representa
string "Eva" Texto.
number 25 Números enteros y decimales.
boolean true Valores lógicos verdadero o falso.
undefined undefined Ausencia de un valor asignado.
null null Ausencia de valor establecida intencionadamente.
bigint 12345678901234567890n Enteros de gran tamaño.
symbol Symbol("id") Valores únicos, utilizados en casos más avanzados.

Además de estos tipos primitivos, JavaScript dispone del tipo Object, utilizado para representar estructuras de datos más complejas. Los arrays y muchos otros elementos de JavaScript son objetos.

⚠️ Atención

Un array no constituye un tipo primitivo independiente. En JavaScript los arrays son objetos. Los estudiaremos con profundidad en la UT4 y los objetos en la UT6.

String

El tipo string se utiliza para representar cadenas de texto. Una cadena está formada por una secuencia de caracteres y se escribe entre comillas.

JavaScript 
const nombre = "Lucía";
const modulo = 'DWEC';
const mensaje = "Hola, mundo";

console.log(nombre);
console.log(modulo);
console.log(mensaje);

JavaScript permite utilizar tanto comillas dobles como comillas simples para delimitar una cadena. En el apartado 2.6 estudiaremos las cadenas de texto con más detalle, incluyendo concatenación, caracteres de escape y template literals.

💻 Ejemplo DAW

En una aplicación web son cadenas de texto datos como el nombre de una persona, una dirección de correo, el título de un producto o un mensaje que se mostrará en la interfaz.

Number

El tipo number representa los números que utilizamos habitualmente en JavaScript. Sirve tanto para valores enteros como para valores con decimales.

JavaScript 
const edad = 20;
const precio = 49.95;
const temperatura = -3.5;

console.log(edad);
console.log(precio);
console.log(temperatura);

En JavaScript el separador decimal es el punto, no la coma.

⚠️ Atención

Para escribir un valor decimal debemos utilizar, por ejemplo, 19.95. No escribiremos 19,95 para representar un número decimal en el código JavaScript.

En 2.7 profundizaremos en el trabajo con números. Allí estudiaremos también valores especiales como NaN e Infinity.

Boolean

El tipo boolean únicamente puede tener dos valores: true o false.

JavaScript 
const sesionIniciada = true;
const usuarioBloqueado = false;

console.log(sesionIniciada);
console.log(usuarioBloqueado);

Los valores booleanos se utilizan para representar condiciones que solo pueden encontrarse en uno de dos estados: verdadero o falso, activado o desactivado, correcto o incorrecto, etc.

📌 Importante

true y false se escriben sin comillas. Si escribimos "true", tendremos una cadena de texto, no un valor booleano.

Undefined

Una variable declarada con let a la que todavía no hemos asignado un valor contiene automáticamente el valor undefined.

JavaScript 
let ciudad;

console.log(ciudad);
Resultado 
undefined

Podemos entender undefined como «todavía no hay un valor definido para este identificador».

⚠️ Atención

Normalmente no necesitamos asignar undefined manualmente. JavaScript lo utiliza de forma natural cuando un valor todavía no está definido.

Null

null también representa ausencia de valor, pero normalmente lo utilizamos para indicar que esa ausencia ha sido establecida de forma intencionada.

JavaScript 
let usuarioSeleccionado = null;

console.log(usuarioSeleccionado);

En este ejemplo hemos decidido explícitamente que todavía no existe un usuario seleccionado.

Valor Idea básica
undefined El valor todavía no está definido o no ha sido proporcionado.
null Indicamos intencionadamente que no hay ningún valor.
📌 Importante

null y undefined no significan exactamente lo mismo, aunque ambos se relacionen con la ausencia de un valor.

BigInt, Symbol y Object

Además de los tipos que utilizaremos con mayor frecuencia al comenzar el módulo, JavaScript dispone de otros tipos que conviene conocer.

BigInt

bigint permite trabajar con números enteros de tamaño muy grande. Un literal de tipo bigint se identifica normalmente porque termina en n.

JavaScript 
const numeroGrande = 12345678901234567890n;

console.log(numeroGrande);

No será uno de los tipos principales en nuestros primeros programas, pero debemos saber que forma parte del lenguaje.

Symbol

symbol permite crear valores únicos. Se utiliza principalmente en situaciones más avanzadas, especialmente al trabajar con objetos.

JavaScript 
const identificador = Symbol("id");

console.log(identificador);

En esta unidad basta con reconocer su existencia; no necesitamos utilizarlo todavía en nuestros programas.

Object

Los objetos permiten agrupar información más compleja mediante propiedades y valores. A diferencia de los anteriores, object representa valores no primitivos.

JavaScript 
const alumno = {
  nombre: "Lucía",
  curso: "2.º DAW"
};

console.log(alumno);

No estudiaremos todavía cómo crear o manipular objetos. El ejemplo solo sirve para reconocer que JavaScript puede trabajar con estructuras más complejas que un único número, texto o valor booleano.

⚠️ Atención

No confundas tipo primitivo con objeto. Los objetos se estudiarán con profundidad en la UT6.

El operador typeof

JavaScript proporciona el operador typeof, que permite consultar el tipo de un valor durante la ejecución del programa.

JavaScript 
const nombre = "Eva";
const edad = 25;
const activo = true;
let ciudad;

console.log(typeof nombre);
console.log(typeof edad);
console.log(typeof activo);
console.log(typeof ciudad);

El resultado será:

Console 
string
number
boolean
undefined

Observa que typeof devuelve el nombre del tipo en forma de cadena de texto.

El caso especial de null

Existe una particularidad histórica de JavaScript que debemos conocer:

JavaScript 
console.log(typeof null);

El resultado es:

Console 
object
⚠️ Atención

Aunque typeof null devuelve "object", null es un valor primitivo. Este resultado se debe a una particularidad histórica de JavaScript y se mantiene por compatibilidad.

Más ejemplos con typeof

JavaScript 
console.log(typeof "DWEC");
console.log(typeof 42);
console.log(typeof false);
console.log(typeof 123n);
console.log(typeof Symbol("id"));
console.log(typeof { nombre: "Ana" });

Obtendremos:

Console 
string
number
boolean
bigint
symbol
object
