2.6 Cadenas de texto y template literals

En los apartados anteriores hemos trabajado con distintos tipos de datos y hemos aprendido a operar con ellos. Uno de los tipos que utilizaremos con mayor frecuencia en una aplicación web es el texto: nombres de usuarios, mensajes, títulos, direcciones, descripciones o cualquier información que queramos mostrar en la interfaz.

En JavaScript, los textos se representan mediante cadenas de caracteres o strings. En este apartado aprenderemos a escribirlas correctamente, a incluir caracteres especiales, a unir varios textos y a construir cadenas de forma más cómoda mediante template literals.

📌 Importante

Una cadena de texto debe escribirse entre comillas. JavaScript permite utilizar comillas dobles, comillas simples y, en los template literals, acentos graves (`).

Cadenas de texto

Una cadena de texto es una secuencia de caracteres. Puede contener letras, números, espacios, signos de puntuación y otros símbolos.

JavaScript
const nombre = "Lucía";
const modulo = "Desarrollo web en entorno cliente";
const codigoPostal = "44001";

console.log(nombre);
console.log(modulo);
console.log(codigoPostal);

Aunque "44001" contiene únicamente cifras, sigue siendo una cadena porque está escrito entre comillas. Por tanto, no se comportará igual que el número 44001.

💻 Ejemplo DAW

En una aplicación web utilizaremos cadenas para representar datos como el nombre de un producto, un correo electrónico, un mensaje de bienvenida o el contenido textual que después mostraremos al usuario.

Comillas simples y dobles

Podemos delimitar una cadena utilizando comillas dobles (" ") o comillas simples (' '). Las dos formas son válidas.

JavaScript
const nombre = "Ana";
const ciudad = 'Teruel';

console.log(nombre);
console.log(ciudad);

Lo importante es que la cadena empiece y termine con el mismo tipo de comilla. Elegiremos un criterio y lo mantendremos de forma coherente en nuestro código.

Utilizar un tipo de comilla para delimitar la cadena también permite incluir el otro tipo en su interior sin necesidad de escaparlo:

JavaScript
const mensaje1 = "Hoy estudiamos 'strings' en JavaScript";
const mensaje2 = 'El alumno dijo: "Ya funciona"';

console.log(mensaje1);
console.log(mensaje2);
⚠️ Atención

Si abrimos una cadena con comillas dobles debemos cerrarla con comillas dobles; si la abrimos con comillas simples debemos cerrarla con comillas simples. Una cadena mal cerrada provocará un error de sintaxis.

Caracteres de escape

En algunas situaciones necesitamos incluir dentro de una cadena caracteres que tienen un significado especial. Para ello podemos utilizar el carácter de escape \.

console.log("Primera línea

📌 Importante

La barra invertida \ indica que el carácter siguiente debe interpretarse de una forma especial. No debemos confundirla con la barra normal /.

Concatenación con +

Concatenar significa unir varias cadenas para formar una sola. Podemos hacerlo mediante el operador +.

JavaScript
const nombre = "Ana";
const saludo = "Hola, " + nombre + "!";

console.log(saludo);
Console
Hola, Ana!

También podemos combinar texto con valores numéricos:

JavaScript
const producto = "Teclado";
const precio = 35;

console.log("Producto: " + producto + " - Precio: " + precio + " €");
⚠️ Atención

Recuerda lo estudiado en la conversión de tipos: cuando + interviene con una cadena, puede realizar una concatenación. Por ejemplo, "10" + 5 produce "105", no 15.

Template literals

Cuando tenemos que construir textos con varias variables, la concatenación con + puede resultar difícil de leer. JavaScript ofrece una alternativa más cómoda: los template literals o literales de plantilla.

Los template literals se escriben entre acentos graves (`), también llamados backticks, en lugar de utilizar comillas simples o dobles.

JavaScript
const nombre = "Ana";
const saludo = `Hola, ${nombre}!`;

console.log(saludo);

Además, permiten escribir cadenas en varias líneas de una forma muy natural:

JavaScript
const mensaje = `Bienvenido al módulo DWEC.
Hoy estamos aprendiendo JavaScript.`;

console.log(mensaje);
📌 Buena práctica

Cuando una cadena tenga que incorporar variables o expresiones, los template literals suelen producir un código más claro y legible que una concatenación larga con +.

Interpolación con ${}

Dentro de un template literal podemos insertar valores mediante la sintaxis ${...}. Esta técnica se denomina interpolación.

JavaScript
const nombre = "Marcos";
const curso = "2.º DAW";

console.log(`El alumno ${nombre} estudia ${curso}.`);

Entre ${...} no solo podemos escribir el nombre de una variable. También podemos incluir una expresión que JavaScript evaluará antes de incorporarla a la cadena.

JavaScript
const precio = 20;
const unidades = 3;

console.log(`Total: ${precio * unidades} €`);
Console
Total: 60 €
💻 Ejemplo DAW

Los template literals son especialmente útiles al generar mensajes dinámicos en una aplicación web, porque permiten combinar texto, variables y expresiones manteniendo el código legible.

🧠 Comprueba lo aprendido

Indica qué mostrará Console en cada caso antes de ejecutar el código:

JavaScript
const nombre = "Eva";
const edad = 25;

console.log("Hola " + nombre);
console.log(`Hola ${nombre}`);
console.log("Edad: " + edad);
console.log(`El año que viene tendrá ${edad + 1} años`);
Ver solución

"Hola " + nombre → Hola Eva.

`Hola ${nombre}` → Hola Eva.

"Edad: " + edad → Edad: 25.

`El año que viene tendrá ${edad + 1} años` → El año que viene tendrá 26 años.

💻 Prueba en Console

Copia el siguiente código en Console y comprueba el resultado. Después modifica los valores de las variables y crea tu propio mensaje utilizando un template literal.

Console
const producto = "Monitor";
const precio = 180;
const unidades = 2;

console.log(`Producto: ${producto}`);
console.log(`Precio por unidad: ${precio} €`);
