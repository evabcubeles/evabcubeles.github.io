📝 Actividades de la UT2

Para finalizar la UT2 vas a aplicar de forma conjunta los principales conceptos trabajados en los apartados 2.1 a 2.11.

Las actividades se organizan en tres bloques: actividades prácticas, un reto final y una autoevaluación para comprobar los fundamentos de JavaScript antes de comenzar con las estructuras de control.

📌 Importante

En esta unidad todavía no necesitamos utilizar if, bucles, arrays ni funciones. El objetivo es dominar primero variables, tipos, conversiones, operadores, cadenas, ámbito y depuración.

💻 Actividades prácticas

Actividad 1 — Sintaxis, identificadores y declaraciones

Observa el siguiente código:

JavaScript 
const nombre alumno = "Lucía";
let 2edad = 19;
const ciudad = "Teruel"
console.log(Ciudad);
  1. Localiza todos los problemas que encuentres.
  2. Indica cuáles afectan a las reglas de los identificadores.
  3. Indica cuál demuestra que JavaScript distingue entre mayúsculas y minúsculas.
  4. Reescribe el fragmento utilizando nombres válidos y descriptivos.
  5. Decide si mantendrías const o let en cada variable y justifica la respuesta.

Actividad 2 — Variables, tipos y typeof

Predice primero la salida y después compruébala en Console:

JavaScript 
const nombre = "Mario";
const edad = 21;
const matriculado = true;
let telefono;
const observaciones = null;

console.log(typeof nombre);
console.log(typeof edad);
console.log(typeof matriculado);
console.log(typeof telefono);
console.log(typeof observaciones);
  1. Anota qué mostrará cada console.log() antes de ejecutar el código.
  2. Comprueba tus respuestas en Console.
  3. Explica por qué telefono contiene undefined.
  4. Explica la particularidad de typeof null.

Actividad 3 — Conversión de datos

Ejecuta estas instrucciones una a una y anota el valor y el tipo obtenido:

JavaScript 
const dato1 = Number("25");
const dato2 = Number("25.5");
const dato3 = parseInt("25.8");
const dato4 = parseFloat("25.8");
const dato5 = String(150);
const dato6 = Boolean(0);
const dato7 = Boolean("0");

console.log(dato1, typeof dato1);
console.log(dato2, typeof dato2);
console.log(dato3, typeof dato3);
console.log(dato4, typeof dato4);
console.log(dato5, typeof dato5);
console.log(dato6, typeof dato6);
console.log(dato7, typeof dato7);
  1. ¿Qué diferencia observas entre Number(), parseInt() y parseFloat()?
  2. ¿Por qué Boolean(0) y Boolean("0") producen resultados distintos?
  3. Prueba también Number("hola"). ¿Qué valor obtienes?
  4. Comprueba ese último resultado mediante Number.isNaN().

Actividad 4 — Operadores y coerción

Sin ejecutar todavía el código, escribe qué resultado esperas en cada caso:

JavaScript 
console.log(10 + 5);
console.log("10" + 5);
console.log("10" - 5);
console.log(10 === "10");
console.log(10 == "10");
console.log(17 % 5);
console.log(true && false);
console.log(true || false);
console.log(!true);
  1. Comprueba tus predicciones en Console.
  2. Explica qué ocurre en "10" + 5 y en "10" - 5.
  3. Explica la diferencia entre == y ===.
  4. Indica qué representa el operador %.
⚠️ Atención

El operador % obtiene el resto de una división; no calcula directamente un porcentaje.

Actividad 5 — Cadenas y template literals

Partiendo de estas variables:

JavaScript 
const nombre = "Sara";
const ciclo = "DAW";
const curso = 2;

  1. Crea mediante concatenación una cadena con el texto: Sara estudia 2.º de DAW en IES Ejemplo.
  2. Genera el mismo resultado utilizando un template literal.
  3. Añade un salto de línea entre los datos del alumno y el centro.
  4. Muestra el resultado en Console.

Compara la legibilidad de la concatenación con + y la interpolación mediante ${...}.

Actividad 6 — Números y Math

Crea un archivo JavaScript y realiza las siguientes operaciones:

  1. Guarda el precio 19.95 y la cantidad 3.
  2. Calcula el importe total.
  3. Muestra el total con exactamente dos decimales utilizando toFixed().
  4. Redondea 7.6 con Math.round(), Math.floor() y Math.ceil().
  5. Genera un número pseudoaleatorio entre 0 incluido y 1 excluido con Math.random().
  6. Adapta después la expresión para obtener un entero pseudoaleatorio entre 1 y 10.
💻 Pista

Para un entero entre 1 y 10 puedes combinar Math.random(), una multiplicación, Math.floor() y una suma.

Actividad 7 — Entrada de datos y conversiones

Crea un pequeño programa que solicite mediante prompt():

  • el nombre de una persona;
  • el precio de un producto;
  • la cantidad de unidades.

Después:

  1. Convierte precio y cantidad a valores numéricos.
  2. Calcula el importe total.
  3. Muestra en Console una frase utilizando un template literal.
  4. Muestra también el tipo de los valores antes y después de convertirlos.
⚠️ Para esta actividad

Introduce datos válidos y pulsa Aceptar en los cuadros de diálogo. Más adelante aprenderemos a controlar mediante estructuras de decisión qué debe ocurrir cuando los datos no son válidos o el usuario cancela.

Actividad 8 — Scope: let, const y var

Predice qué ocurrirá y después compruébalo:

JavaScript 
{
  const mensaje = "Estoy dentro del bloque";
  let puntos = 10;
  var nivel = 1;

  console.log(mensaje);
  console.log(puntos);
  console.log(nivel);
}

console.log(nivel);
console.log(mensaje);
console.log(puntos);
  1. Indica qué instrucciones esperas que funcionen.
  2. Indica dónde esperas obtener un ReferenceError.
  3. Explica la diferencia entre el ámbito de let/const y var en este bloque.
  4. Comenta temporalmente la primera línea que produce el error para poder continuar observando el resto.

Actividad 10 — Depura con Sources y breakpoints

Crea y ejecuta este programa:

JavaScript 
const precio = 18;
const cantidad = 5;

const subtotal = precio * cantidad;
const descuento = subtotal * 0.10;
const total = subtotal - descuento;

console.log(`Total: ${total.toFixed(2)} €`);
  1. Abre DevTools y entra en Sources.
  2. Coloca un breakpoint en la línea que calcula subtotal.
  3. Recarga la página.
  4. Observa los valores de precio y cantidad.
  5. Avanza paso a paso y comprueba cómo aparecen subtotal, descuento y total.
  6. Explica con tus palabras qué utilidad tiene detener la ejecución.

🧩 Reto final — Calculadora básica de un pedido

Una pequeña tienda está preparando una primera versión de su aplicación web. Tu tarea consiste en completar y depurar un programa que solicite los datos básicos de un pedido y calcule su importe.

Proyecto inicial

Estructura 
pedido/
├── index.html
└── js/
    └── app.js

El archivo index.html contiene:

HTML · index.html 
<!DOCTYPE html>
<html lang="es">

<head>
  <meta charset="UTF-8">
  <title>Calculadora de pedido</title>
  <script src="js/app.js" defer></script>
</head>

<body>
  <h1>Calculadora de pedido</h1>
</body>

</html>

Y js/app.js contiene este código inicial con varios aspectos que debes revisar:

JavaScript · js/app.js 
const nombreCliente = prompt("Nombre del cliente:");
const precioProducto = prompt("Precio del producto:");
const cantidad = prompt("Cantidad:");

const subtotal = precioProducto * cantidad;
const iva = subtotal * 0.21;
const total = subtotal + IVA;

console.log("Cliente: " + nombreCliente);
console.log(`Subtotal: ${subtotal} €`);
console.log(`IVA: ${iva} €`);
console.log(`Total: ${total} €`);

Tu misión

  1. Ejecuta el proyecto sin corregirlo inicialmente. Abre Console, localiza el error y anota el tipo, el archivo y la línea señalada.
  2. Corrige el identificador erróneo. Recuerda que JavaScript distingue entre mayúsculas y minúsculas.
  3. Controla los tipos. Convierte explícitamente el precio y la cantidad obtenidos mediante prompt() antes de utilizarlos en los cálculos.
  4. Mejora la salida. Muestra subtotal, IVA y total con dos decimales.
  5. Utiliza template literals. Sustituye la concatenación del nombre del cliente por interpolación con ${...}.
  6. Documenta el código. Añade comentarios únicamente donde aporten información útil y mantén una indentación coherente.
  7. Comprueba los tipos. Utiliza temporalmente typeof y console.log() para comprobar que precio y cantidad son números después de la conversión.
  8. Depura paso a paso. Coloca un breakpoint antes del cálculo de total y observa los valores de subtotal e iva.
  9. Prueba el programa. Utiliza, por ejemplo, un precio de 15.50 y una cantidad de 4, y comprueba manualmente si el resultado mostrado es correcto.
⚠️ Alcance del reto

Para esta práctica suponemos que el usuario introduce valores válidos y pulsa Aceptar. La validación mediante decisiones se trabajará en la siguiente unidad.

📦 Entrega del reto

Entrega la carpeta pedido con index.html y js/app.js. El programa debe ejecutarse sin errores, realizar las conversiones necesarias, mostrar los importes con dos decimales y estar correctamente organizado y comentado.
