2.1 Sintaxis básica de JavaScript

En la unidad anterior aprendimos cómo se integra JavaScript en una página HTML y ejecutamos nuestros primeros programas utilizando console.log() y alert(). A partir de ahora comenzaremos a estudiar cómo se escribe realmente un programa en JavaScript.

Como cualquier lenguaje de programación, JavaScript posee una sintaxis: un conjunto de reglas que indican cómo debemos escribir las instrucciones para que el motor JavaScript pueda interpretarlas y ejecutarlas.

📌 Importante

La sintaxis establece las reglas que debemos seguir al escribir el código. Si una instrucción no respeta esas reglas, JavaScript no podrá interpretarla correctamente y se producirá un error de sintaxis.

En este apartado estudiaremos las reglas básicas necesarias para empezar a leer y escribir código. Las variables, los tipos de datos y los operadores se desarrollarán con detalle en los apartados siguientes.

Instrucciones y sentencias

Un programa JavaScript está formado por instrucciones que indican qué debe hacer el programa. También utilizamos habitualmente el término sentencia para referirnos a una instrucción completa del lenguaje.

Por ejemplo:

JavaScript 
console.log("Hola desde JavaScript");

Esta sentencia llama a console.log() y muestra el texto Hola desde JavaScript en la consola del navegador.

Un programa puede contener muchas sentencias. De forma general, JavaScript las ejecuta siguiendo el orden en el que aparecen:

JavaScript 
console.log("Primera instrucción");
console.log("Segunda instrucción");
console.log("Tercera instrucción");

En Console veremos:

Console 
Primera instrucción
Segunda instrucción
Tercera instrucción
💻 Ejemplo DAW

Durante esta unidad utilizaremos con frecuencia console.log() para comprobar resultados. Además de ser útil mientras aprendemos, la consola es una herramienta fundamental para localizar y analizar errores.

Uso del punto y coma

En nuestros ejemplos verás que las sentencias suelen terminar con un punto y coma (;).

JavaScript 
console.log("Hola");
console.log("Adiós");

El punto y coma marca el final de una sentencia. Sin embargo, JavaScript no exige escribirlo al final de todas las sentencias. El lenguaje dispone de un mecanismo denominado inserción automática de punto y coma (Automatic Semicolon Insertion, ASI).

JavaScript 
console.log("Hola")
console.log("Adiós")

Este código también funciona.

📌 Importante

En nuestros apuntes y ejercicios utilizaremos punto y coma al final de las sentencias. No porque siempre sea obligatorio, sino para mantener un criterio uniforme y evitar determinados casos ambiguos.

⚠️ Atención

La regla «todas las instrucciones JavaScript deben terminar obligatoriamente en punto y coma» no es exacta. JavaScript permite omitirlo en muchos casos gracias a ASI.

Bloques de código

Algunas construcciones de JavaScript agrupan varias sentencias dentro de un bloque de código. Los bloques se delimitan mediante llaves { y }.

JavaScript 
{
  console.log("Primera instrucción del bloque");
  console.log("Segunda instrucción del bloque");
}

Más adelante encontraremos bloques continuamente al estudiar estructuras de control, funciones y otros elementos del lenguaje.

Observa que las instrucciones del interior aparecen indentadas. La indentación no crea el bloque —lo hacen las llaves—, pero permite reconocer visualmente qué instrucciones pertenecen a él.

📌 Importante

Las llaves { } delimitan el bloque. La indentación hace que su estructura sea mucho más fácil de leer y será una norma de trabajo durante todo el módulo.

Mayúsculas y minúsculas

JavaScript es un lenguaje case-sensitive: distingue entre letras mayúsculas y minúsculas.

Por ejemplo, estos nombres son diferentes:

JavaScript 
nombre
Nombre
NOMBRE

Lo mismo sucede con los nombres que utilizamos al escribir instrucciones:

JavaScript 
console.log("Correcto");
Console.log("Incorrecto");

La primera instrucción utiliza correctamente console. La segunda intenta utilizar Console, que es un identificador diferente, y producirá un error en este contexto.

⚠️ Atención

Un simple cambio de mayúscula por minúscula puede provocar un error. Si JavaScript indica que un nombre no existe, comprueba también cómo están escritas sus mayúsculas y minúsculas.

Identificadores

Un identificador es el nombre que utilizamos para reconocer elementos de nuestro programa. Más adelante los utilizaremos para nombrar variables, constantes, funciones y otros elementos.

  • JavaScript distingue mayúsculas y minúsculas.

Palabras reservadas

JavaScript utiliza determinadas palabras con un significado especial. Se denominan palabras reservadas y forman parte de la sintaxis del lenguaje.

Algunos ejemplos que iremos encontrando durante el módulo son:

PalabraLa utilizaremos para...
letDeclarar variables.
constDeclarar constantes o valores que no vamos a reasignar.
varDeclarar variables con la sintaxis tradicional.
if / elseTomar decisiones.
for / whileRealizar repeticiones.
functionDefinir funciones.
returnDevolver un resultado desde una función.
classDefinir clases.
newCrear instancias de objetos.
try / catchGestionar errores mediante excepciones.

No es necesario memorizar ahora todas estas palabras. Las iremos estudiando cuando aparezcan en las unidades correspondientes.

⚠️ Atención

Una palabra reservada no puede utilizarse libremente como nombre de una variable, función u otro identificador. Por ejemplo, no podemos llamar const a una variable.

Expresiones básicas

En JavaScript utilizaremos constantemente expresiones. Una expresión es una combinación de valores, identificadores y operadores que JavaScript puede evaluar para obtener un resultado.

Una expresión puede ser tan sencilla como un número, una cadena de texto o una operación. JavaScript la evalúa y obtiene un valor como resultado.

Podemos probar expresiones sencillas directamente en Console:

Console 
2 + 3
10 - 4
5 * 2
20 / 4

JavaScript devuelve, respectivamente:

Resultado 
5
6
10
5

También podemos evaluar texto:

Console 
"Desarrollo Web en Entorno Cliente"
"Hola" + " " + "DAW"

La segunda expresión produce Hola DAW. Los operadores y las cadenas de texto se estudiarán con detalle en 2.5 y 2.6.

📌 Importante

Una sentencia indica una acción que debe realizar el programa. Una expresión produce un valor al ser evaluada. Las expresiones pueden formar parte de sentencias más amplias.
