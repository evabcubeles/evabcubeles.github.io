2.2 Variables, constantes e identificadores

En el apartado anterior vimos que los programas JavaScript están formados por instrucciones y expresiones. Para poder trabajar con datos necesitamos una forma de guardarlos y reconocerlos mediante un nombre. Para ello utilizamos las variables y las constantes.

En este apartado aprenderemos a declarar variables con let, a crear constantes con const y a comprender qué ocurre cuando declaramos, inicializamos o reasignamos un valor. También veremos var, la forma tradicional de declarar variables en JavaScript, para poder reconocerla cuando aparezca en código existente.

📌 Importante

En JavaScript moderno utilizaremos principalmente const y let. Como criterio general, usaremos const cuando no necesitemos reasignar el valor y let cuando sí vaya a cambiar.

Qué es una variable

Una variable es un identificador asociado a un valor que nuestro programa necesita utilizar. Podemos imaginarla como un nombre que nos permite acceder a un dato y, cuando corresponde, sustituirlo por otro durante la ejecución.

Por ejemplo:

JavaScript 
let edad = 18;
console.log(edad);

En este ejemplo, edad es el nombre de la variable y 18 es el valor que contiene en ese momento. Cuando escribimos edad, JavaScript puede recuperar ese valor.

💻 Ejemplo DAW

En una aplicación web podemos necesitar guardar datos como nombreUsuario, precioProducto, numeroArticulos o sesionIniciada. Utilizar nombres descriptivos hace que el código sea mucho más fácil de entender.

Declarar variables con let

Antes de utilizar una variable debemos declararla. Una de las formas modernas de hacerlo es mediante la palabra reservada let.

JavaScript 
let nombre;
let edad;
let precioProducto;

En este momento hemos creado los identificadores, pero todavía no les hemos asignado explícitamente ningún valor. Si consultamos una variable declarada con let antes de asignarle uno, su valor será undefined.

Console 
let ciudad;
console.log(ciudad);
Resultado 
undefined

Estudiaremos undefined con detalle en el apartado 2.3 al trabajar los tipos de datos.

Declaración, inicialización y reasignación

Conviene distinguir tres operaciones que realizaremos constantemente al trabajar con variables:

Operación Qué hacemos Ejemplo
Declaración Creamos la variable y le damos un nombre. let puntos;
Inicialización Asignamos un primer valor a la variable. puntos = 10;
Reasignación Sustituimos el valor anterior por otro. puntos = 15;
📌 Importante

En JavaScript, el símbolo = es el operador de asignación. Se utiliza para asignar un valor a un identificador.

Por ejemplo, en puntos = 10;, el valor 10 se asigna a puntos.

No debemos interpretar = como el signo matemático «igual a». Los operadores utilizados para comparar valores se estudiarán más adelante.

Podemos declarar e inicializar una variable en una única sentencia, que será la forma más habitual:

JavaScript 
let puntos = 10;
console.log(puntos);

puntos = 15;
console.log(puntos);

El resultado será:

Console 
10
15
📌 Importante

En una reasignación no volvemos a escribir let. La variable ya existe; únicamente estamos asignándole un nuevo valor.

Constantes con const

Cuando sabemos que un identificador no va a ser reasignado, utilizamos normalmente const.

JavaScript 
const nombreModulo = "DWEC";
const curso = "2.º DAW";

console.log(nombreModulo);
console.log(curso);

A diferencia de una variable declarada con let, una constante debe recibir un valor en el momento de declararla:

JavaScript 
const nombreCentro = "IES Ejemplo";

Si intentamos asignar después otro valor al mismo identificador, JavaScript producirá un error:

JavaScript 
const iva = 21;
iva = 10;
⚠️ Atención

const impide reasignar el identificador. Más adelante veremos que, cuando una constante contiene un objeto o un array, su contenido puede seguir siendo modificable. Por eso no debemos interpretar const como «todo es completamente inmutable».

¿Cuándo utilizar let y cuándo const?

SituaciónDeclaración recomendada
El identificador no necesita recibir otro valor. const
El valor deberá cambiar durante la ejecución. let
📌 Regla de trabajo del módulo

Utilizaremos const por defecto cuando no haya reasignación y recurriremos a let cuando sepamos que el valor tendrá que cambiar.

La declaración tradicional var

En libros, tutoriales y proyectos antiguos encontrarás con frecuencia var. Durante muchos años fue la forma habitual de declarar variables en JavaScript.

JavaScript 
var nombre = "Ana";
var edad = 20;

Este código sigue siendo válido, pero JavaScript moderno dispone de let y const, que permiten expresar mejor nuestra intención y tienen reglas de ámbito más claras.

⚠️ Atención

Debemos saber leer y reconocer var, pero en el código nuevo del módulo utilizaremos preferentemente let y const. En 2.10 estudiaremos con detalle sus diferencias de ámbito.

Cómo nombrar variables

En 2.1 vimos las reglas que determinan si un identificador es válido. Ahora añadiremos una cuestión igualmente importante: elegir nombres que hagan que el programa sea fácil de leer.

En JavaScript es habitual utilizar la convención camelCase para nombrar variables y constantes. La primera palabra comienza en minúscula y las siguientes empiezan con mayúscula, sin espacios.

JavaScript 
const nombreUsuario = "Lucía";
let numeroIntentos = 0;
const precioProducto = 49.95;
let sesionIniciada = false;
EvitaMejorMotivo
xprecioProductoExplica qué representa el dato.
nnumeroAlumnosFacilita la lectura del código.
dato1nombreUsuarioEvita nombres genéricos.
💻 Ejemplo DAW

Si meses después volvemos a un proyecto, una línea como let numeroIntentos = 0; se entiende inmediatamente. Un nombre como let x = 0; obliga a investigar el resto del programa para averiguar qué representa.

Errores frecuentes al trabajar con variables

Utilizar una variable que no ha sido declarada

JavaScript 
console.log(nombreAlumno);

Si nombreAlumno no existe, JavaScript mostrará un error. No debemos crear variables simplemente escribiendo un nombre y asignándole un valor sin declararlo previamente.

Reasignar una constante

JavaScript 
const curso = "2.º DAW";
curso = "1.º DAW";

La segunda sentencia provoca un error porque curso fue declarado mediante const.

Utilizar nombres poco descriptivos

JavaScript 
let a = 120;
let b = 21;

El código será mucho más comprensible si expresamos qué representa cada dato:

JavaScript 
let precioProducto = 120;
let porcentajeIva = 21;

🧠 Comprueba lo aprendido

Indica qué declaración utilizarías en cada caso: let o const.

  • El nombre de un módulo que no va a cambiar.
  • La puntuación de un jugador que irá aumentando.
  • El número máximo de intentos permitido.
  • El número de productos que hay actualmente en un carrito.
Ver solución

Nombre del módulo → const, porque no se reasignará.

Puntuación → let, porque irá cambiando.

Número máximo de intentos → const, si permanece fijo.

Productos del carrito → let, porque la cantidad puede cambiar.

💻 Prueba en Console

Escribe manualmente las siguientes instrucciones en Console, una a una, y observa cómo cambia el valor de la variable:

Console 
let contador = 1;
contador = 2;
contador = 3;
console.log(contador);

Después prueba a declarar contador con const e intenta reasignarlo. Lee el mensaje que muestra Console y trata de identificar qué ha provocado el error.
