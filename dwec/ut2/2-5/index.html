2.5 Operadores

En los apartados anteriores hemos aprendido a trabajar con variables, tipos de datos y conversiones. El siguiente paso consiste en aprender a operar con esos valores: realizar cálculos, asignar resultados, comparar datos o combinar condiciones.

Para ello JavaScript utiliza operadores. Un operador es un símbolo o conjunto de símbolos que indica qué operación debe realizarse sobre uno o varios valores.

📌 Importante

Los operadores trabajan sobre valores llamados operandos. Por ejemplo, en 8 + 2, los valores 8 y 2 son los operandos y + es el operador.

Operadores aritméticos

Los operadores aritméticos permiten realizar cálculos matemáticos con valores numéricos.

Operador Operación Ejemplo Resultado
+Suma8 + 210
-Resta8 - 26
*Multiplicación8 * 216
/División8 / 24
%Resto de la división8 % 32
**Potencia2 ** 38
JavaScript 
const a = 10;
const b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);

El operador % devuelve el resto de una división. Es especialmente útil, por ejemplo, para comprobar si un número es par: si numero % 2 produce 0, el número es divisible entre 2.

⚠️ Atención

Como vimos en el apartado anterior, + también puede utilizarse para concatenar cadenas. Por eso 5 + 2 produce 7, mientras que "5" + 2 produce "52".

Prioridad de las operaciones

Cuando una expresión contiene varios operadores, JavaScript aplica unas reglas de precedencia. La multiplicación y la división se realizan antes que la suma y la resta.

JavaScript 
console.log(2 + 3 * 4);
console.log((2 + 3) * 4);

El resultado será:

Console 
14
20
📌 Buena práctica

Utiliza paréntesis cuando quieras dejar claro el orden de las operaciones. Además de modificar la prioridad, hacen que las expresiones sean más fáciles de leer.

Operadores de asignación

El operador de asignación que ya conocemos es =. Se utiliza para guardar un valor en una variable.

JavaScript 
let puntos = 10;

puntos = 15;

console.log(puntos);

JavaScript también dispone de operadores de asignación compuesta, que permiten realizar una operación y guardar el resultado en la misma variable.

Operador Equivale a
x += 3x = x + 3
x -= 3x = x - 3
x *= 3x = x * 3
x /= 3x = x / 3
x %= 3x = x % 3
x **= 3x = x ** 3
JavaScript 
let saldo = 100;

saldo += 25;
console.log(saldo);

saldo -= 10;
console.log(saldo);
Console 
125
115
⚠️ Atención

No confundas = con un operador de comparación. = asigna un valor. Los operadores que permiten comparar valores los veremos más adelante en este mismo apartado.

Incremento y decremento

Los operadores ++ y -- permiten aumentar o disminuir en una unidad el valor de una variable numérica.

JavaScript 
let contador = 5;

contador++;
console.log(contador);

contador--;
console.log(contador);

El resultado será:

Console 
6
5

En estos ejemplos, contador++ equivale a aumentar el valor en uno y contador-- a disminuirlo en uno.

📌 Importante

++ y -- modifican el valor de la variable. Por ello deben utilizarse con variables declaradas con let, no con una constante cuyo valor no puede reasignarse.

Prefijo y sufijo

El operador puede escribirse antes o después de la variable: ++contador o contador++. En una instrucción aislada ambos terminan incrementando la variable, pero cuando forman parte de una expresión no producen exactamente el mismo resultado.

Forma Comportamiento dentro de una expresión
++contador Primero incrementa y después utiliza el nuevo valor.
contador++ Primero utiliza el valor actual y después incrementa.
JavaScript 
let a = 5;
let b = 5;

console.log(++a);
console.log(b++);

console.log(a);
console.log(b);
Console 
6
5
6
6
⚠️ Atención

Cuando el prefijo y el sufijo puedan dificultar la lectura, es preferible separar el incremento de otras operaciones. El código claro suele ser mejor que una expresión innecesariamente compacta.

Operadores de comparación

Los operadores de comparación permiten comparar dos valores. El resultado de una comparación siempre es un valor booleano: true o false.

Operador Significado Ejemplo
>Mayor que10 > 5 → true
<Menor que10 < 5 → false
>=Mayor o igual que10 >= 10 → true
<=Menor o igual que7 <= 10 → true
JavaScript 
const edad = 20;

console.log(edad > 18);
console.log(edad < 18);
console.log(edad >= 20);
console.log(edad <= 20);

Obtendremos:

Console 
true
false
true
true
💻 Ejemplo DAW

En una aplicación web podemos comparar la edad de un usuario, el precio de un producto, el número de elementos de un carrito o una puntuación. Estas comparaciones serán fundamentales cuando estudiemos las estructuras condicionales en la UT3.

Igualdad estricta: === y !==

Para comprobar si dos valores son iguales utilizaremos principalmente ===, denominado operador de igualdad estricta. Para comprobar si son distintos utilizaremos !==.

JavaScript 
console.log(5 === 5);
console.log(5 === "5");
console.log(5 !== "5");

El resultado será:

Console 
true
false
true

La igualdad estricta compara tanto el valor como el tipo de dato. Por eso 5 === "5" produce false: uno es un número y el otro una cadena.

== y !=

JavaScript también dispone de los operadores == y !=. Estos operadores permiten realizar conversiones implícitas antes de comparar.

JavaScript 
console.log(5 == "5");
console.log(5 === "5");
Console 
true
false
📌 Importante

Como criterio general en nuestros programas utilizaremos === y !==. Evitar conversiones implícitas durante la comparación hace que el código sea más predecible y reduce errores.

⚠️ Atención

No confundas =, == y ===: = asigna un valor, == compara permitiendo coerción y === compara sin convertir los tipos.

Operadores lógicos

Los operadores lógicos permiten combinar o negar condiciones. Los tres operadores que utilizaremos con mayor frecuencia son &&, || y !.

Operador Nombre Resultado básico
&& AND (Y) Es verdadero cuando se cumplen ambas condiciones.
|| OR (O) Es verdadero cuando se cumple al menos una condición.
! NOT (NO) Invierte el valor lógico.
JavaScript 
const edad = 20;
const tieneEntrada = true;

console.log(edad >= 18 && tieneEntrada);
console.log(edad < 18 || tieneEntrada);
console.log(!tieneEntrada);

El resultado será:

Console 
true
true
false
📌 Importante

En este apartado utilizamos los operadores lógicos con expresiones booleanas. En JavaScript también pueden trabajar con otros tipos de valores debido a las reglas de coerción, pero profundizaremos en su uso cuando estudiemos las estructuras de control.

Introducción al operador ternario

El operador ternario permite elegir entre dos valores según se cumpla o no una condición. Su estructura general es:

JavaScript 
condicion ? valorSiVerdadero : valorSiFalso

Por ejemplo, podemos utilizarlo para obtener un texto diferente dependiendo de si una persona es mayor de edad:

JavaScript 
const edad = 20;
const mensaje = edad >= 18 ? "Mayor de edad" : "Menor de edad";

console.log(mensaje);
Console 
Mayor de edad
⚠️ Atención

El operador ternario resulta útil para decisiones sencillas. Si la lógica es compleja, suele ser más claro utilizar estructuras condicionales como if y else, que estudiaremos en la UT3.

JavaScript

2 ** 4

8 >= 8
true && false

💻 Prueba en Console

Copia el siguiente código en Console. Antes de ejecutarlo, intenta predecir el valor final de cada variable y el resultado de las comparaciones.

Console 
let puntos = 10;

puntos += 5;
puntos *= 2;

const minimo = 25;
const alcanzaMinimo = puntos >= minimo;
const coincideExactamente = puntos === minimo;

console.log(puntos);
console.log(alcanzaMinimo);
console.log(coincideExactamente);

Después modifica los valores de puntos y minimo y comprueba cómo cambian los resultados.
