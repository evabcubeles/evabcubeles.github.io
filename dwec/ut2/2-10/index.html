2.10 Ámbito de las variables

Cuando declaramos una variable en JavaScript, no siempre podemos utilizarla desde cualquier parte del programa. El lugar en el que se declara determina dónde puede ser utilizada.

A esta zona del programa en la que una variable es accesible la llamamos ámbito o scope. Comprender el ámbito es fundamental para evitar errores y para organizar correctamente nuestros programas.

📌 Importante

El ámbito determina desde qué partes del código podemos acceder a una variable. Una variable puede existir y, sin embargo, no estar disponible desde el lugar en el que intentamos utilizarla.

Qué es el ámbito o scope

El scope de una variable es la región del código en la que esa variable puede ser utilizada. Dependiendo de dónde se declare, puede tener un ámbito más amplio o más limitado.

En esta unidad distinguiremos principalmente tres situaciones:

  • Ámbito global: la variable se declara fuera de bloques y funciones.
  • Ámbito de bloque: la variable solo existe dentro de un bloque delimitado por { }.
  • Ámbito de función: la variable solo puede utilizarse dentro de una función.
💻 Ejemplo DAW

En una aplicación web podemos necesitar datos que se utilicen en distintas partes del programa y otros que solo tengan sentido durante una operación concreta. Elegir correctamente su ámbito ayuda a evitar modificaciones accidentales y conflictos entre variables.

Ámbito global

En los ejemplos de esta unidad, una variable declarada en la parte principal del script, fuera de bloques y funciones, tendrá un ámbito más amplio y podrá utilizarse desde otras partes de ese código.

Habitualmente nos referiremos a este caso como ámbito global.

JavaScript 
const nombreCurso = "2.º DAW";

console.log(nombreCurso);

{
  console.log(nombreCurso);
}

En este ejemplo, nombreCurso se declara fuera del bloque y puede utilizarse tanto antes como dentro de él.

⚠️ Atención

Aunque las variables globales pueden resultar cómodas, debemos evitar utilizarlas innecesariamente. Cuantas más partes del programa puedan acceder a un dato, más difícil puede resultar controlar dónde se modifica y detectar errores.

Ámbito de bloque

Un bloque es un conjunto de instrucciones encerradas entre llaves { }. Las variables declaradas con let y const dentro de un bloque solo pueden utilizarse dentro de ese bloque.

JavaScript 
{
  const mensaje = "Estoy dentro del bloque";
  let puntos = 10;

  console.log(mensaje);
  console.log(puntos);
}

Mientras estamos dentro del bloque, ambas variables son accesibles. Sin embargo, si intentamos utilizarlas después de cerrar la llave, JavaScript producirá un error:

JavaScript 
{
  const mensaje = "Estoy dentro del bloque";
}

console.log(mensaje);

La Console mostrará un error similar a:

Console 
ReferenceError: mensaje is not defined
📌 Importante

Las llaves delimitan el bloque. Una variable declarada con let o const dentro de él deja de ser accesible desde fuera del bloque.

Variables con el mismo nombre en ámbitos diferentes

Podemos declarar una variable dentro de un bloque con el mismo nombre que otra variable situada fuera. Durante ese bloque se utilizará la variable más cercana.

JavaScript 
const mensaje = "Fuera del bloque";

{
  const mensaje = "Dentro del bloque";
  console.log(mensaje);
}

console.log(mensaje);

El resultado será:

Console 
Dentro del bloque
Fuera del bloque

La variable interior oculta temporalmente a la exterior dentro del bloque, pero no modifica su valor.

Introducción al ámbito de función

Las funciones permiten agrupar instrucciones para ejecutarlas cuando las necesitemos. Las estudiaremos en profundidad en la UT5, pero necesitamos anticipar una idea importante relacionada con el ámbito.

Una variable declarada dentro de una función pertenece a esa función y no puede utilizarse directamente desde fuera.

JavaScript 
function mostrarMensaje() {
  const mensaje = "Hola desde la función";

  console.log(mensaje);
}

mostrarMensaje();

La variable mensaje puede utilizarse dentro de mostrarMensaje(), pero no fuera de ella.

JavaScript 
function mostrarMensaje() {
  const mensaje = "Hola desde la función";
}

console.log(mensaje);

Este código provocará un ReferenceError porque mensaje no existe en el ámbito desde el que intentamos acceder a ella.

⚠️ Atención

Por ahora solo necesitamos comprender la idea de ámbito de función. La definición, los parámetros, el retorno y el funcionamiento completo de las funciones se estudiarán más adelante en la UT5.

Ámbito de let y const

Tanto let como const tienen ámbito de bloque. Si se declaran dentro de unas llaves, solo pueden utilizarse dentro de ese bloque.

JavaScript 
{
  let contador = 1;
  const limite = 5;

  contador = contador + 1;

  console.log(contador);
  console.log(limite);
}

Fuera del bloque no podremos acceder ni a contador ni a limite.

Declaración Ámbito de bloque Si se declara dentro de una función Uso recomendado
let Sí Solo es accesible dentro de su ámbito Cuando el valor necesita cambiar
const Sí Solo es accesible dentro de su ámbito Cuando no necesitamos reasignar el valor
var No Queda limitada a la función Principalmente para reconocer código antiguo
📌 Recuerda

Como criterio general de JavaScript moderno, utilizaremos const cuando no necesitemos reasignar el valor y let cuando sí vaya a cambiar. Ambos respetan el ámbito de bloque.

Diferencias básicas con var

Como vimos en el apartado 2.2, var es la forma tradicional de declarar variables en JavaScript. Una de sus diferencias más importantes es que no tiene ámbito de bloque.

JavaScript 
{
  var ciudad = "Teruel";
}

console.log(ciudad);

El resultado será:

Console 
Teruel

Aunque ciudad se ha declarado dentro de las llaves, sigue siendo accesible desde fuera porque var no crea ámbito de bloque.

Sin embargo, cuando var se declara dentro de una función, su ámbito queda limitado a esa función.

JavaScript 
function ejemplo() {
  var mensaje = "Variable local";
  console.log(mensaje);
}

ejemplo();
Declaración Ámbito de bloque Ámbito de función Uso recomendado
let Sí Sí Cuando el valor necesita cambiar
const Sí Sí Cuando no necesitamos reasignar el valor
var No Sí Principalmente para reconocer código antiguo
⚠️ Atención

En JavaScript moderno preferiremos let y const. El comportamiento de var puede resultar menos intuitivo y provocar errores relacionados con el ámbito.

🧠 Comprueba lo aprendido

Antes de ejecutar el siguiente código, intenta decidir qué instrucciones funcionan y cuál producirá un error:

JavaScript 
const curso = "DAW";

{
  const modulo = "DWEC";
  let horas = 126;

  console.log(curso);
  console.log(modulo);
  console.log(horas);
}

console.log(curso);
console.log(modulo);
Ver solución

Los tres console.log() situados dentro del bloque funcionan: pueden acceder a curso, modulo y horas.

El console.log(curso) situado fuera del bloque también funciona, porque curso se declaró fuera.

El último console.log(modulo) provoca un ReferenceError, porque modulo fue declarada con const dentro del bloque.
