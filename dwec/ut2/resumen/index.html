✏️ Resumen de la UT2

En esta unidad hemos aprendido los fundamentos del lenguaje JavaScript: su sintaxis básica, cómo almacenar y transformar datos, qué operadores podemos utilizar y cómo escribir código más claro, organizado y fácil de depurar.

Este resumen reúne las ideas esenciales de los apartados 2.1 a 2.11 para que puedas utilizarlo como guía rápida de repaso antes de comenzar a construir programas con estructuras de control.

2.1 Sintaxis básica de JavaScript

La sintaxis establece las reglas que debemos seguir para escribir instrucciones que JavaScript pueda interpretar correctamente.

SentenciasInstrucciones que indican al programa qué debe hacer.
Punto y comaJavaScript puede insertarlo automáticamente en muchos casos, pero conviene mantener un criterio consistente.
BloquesAgrupan instrucciones entre llaves { }.
Case-sensitivenombre y Nombre son identificadores diferentes.
IdentificadoresNombres utilizados para reconocer variables y otros elementos del programa.
ExpresionesFragmentos de código que JavaScript evalúa para obtener un valor.

2.2 Variables, constantes e identificadores

Las variables y constantes permiten guardar valores para utilizarlos posteriormente en el programa.

🔄let

Se utiliza cuando el valor almacenado necesita ser reasignado.

🔒const

Se utiliza cuando no necesitamos reasignar el valor.

🕰️var

Forma tradicional que debemos reconocer, aunque en código moderno preferiremos let y const.

📌 Recuerda

Como criterio general, utiliza const si no necesitas reasignar el valor y let cuando sí necesite cambiar.

2.3 Tipos de datos en JavaScript

JavaScript utiliza tipado dinámico: una variable puede almacenar valores de distintos tipos a lo largo de la ejecución.

StringTexto.
NumberNúmeros enteros y decimales.
BooleanValores true y false.
undefinedAusencia de un valor asignado.
nullAusencia de valor establecida intencionadamente.
typeofOperador que permite consultar el tipo de un valor.
⚠️ Atención

typeof null devuelve "object" por una particularidad histórica de JavaScript.

2.4 Conversión de tipos

En muchas aplicaciones necesitamos transformar un valor de un tipo a otro, especialmente cuando recibimos datos introducidos por el usuario.

RecursoUso principal
Number()Convertir un valor a número.
String()Convertir un valor a cadena de texto.
Boolean()Convertir un valor a booleano.
parseInt()Obtener un número entero a partir de texto.
parseFloat()Obtener un número decimal a partir de texto.
📌 Recuerda

La conversión explícita la indicamos nosotros; la coerción es una conversión implícita realizada por JavaScript.

2.5 Operadores

Los operadores permiten realizar cálculos, asignar valores, comparar datos y combinar condiciones.

Aritméticos+ - * / % **
Asignación= += -= *= /=
Comparación> < >= <= === !==
Lógicos&& || !
Incremento y decremento++ y --.
TernarioPermite elegir entre dos valores mediante una condición sencilla.
📌 Igualdad recomendada

En código moderno preferiremos normalmente === y !== para evitar conversiones implícitas inesperadas.

2.6 Cadenas de texto y template literals

Las cadenas permiten representar texto y pueden escribirse con comillas simples, dobles o, en los template literals, con backticks.

🔤Cadenas

Representan información textual.

➕Concatenación

El operador + permite unir cadenas.

🧩Template literals

Permiten insertar expresiones mediante ${...} y facilitan la construcción de textos.

💻 Ejemplo

`Usuario: ${nombre} - Edad: ${edad}`

2.7 Números y objeto Math

JavaScript proporciona recursos para trabajar con números, redondear resultados y generar valores aleatorios.

NaNValor especial que indica que el resultado no representa un número válido.
InfinityRepresenta un valor numérico infinito.
toFixed()Devuelve una representación con un número fijo de decimales.
toPrecision()Controla el número total de cifras significativas.
MathOfrece utilidades matemáticas como round(), floor() y ceil().
Math.random()Genera un número pseudoaleatorio entre 0 incluido y 1 excluido.
📌 Recuerda

Para comprobar específicamente NaN podemos utilizar Number.isNaN(); comparar con === NaN no funciona como podríamos esperar.

2.8 Entrada y salida básica de datos

Durante el aprendizaje podemos utilizar herramientas sencillas para mostrar información y solicitar datos al usuario.

🖥️console.log()

Muestra información en la consola y resulta muy útil durante el desarrollo.

💬alert()

Muestra un cuadro de diálogo sencillo en el navegador.

⌨️prompt()

Solicita un dato: al aceptar devuelve texto y al cancelar devuelve null.

⚠️ Atención

Si necesitamos realizar cálculos con un dato obtenido mediante prompt(), debemos tener en cuenta su tipo y realizar la conversión y validación necesarias.

2.9 Comentarios y buenas prácticas

Un programa no solo debe funcionar: también debe resultar comprensible para quien tenga que leerlo, modificarlo o depurarlo.

// comentarioComentario de una línea.
/* ... */Comentario de bloque.
Nombres descriptivosExplican la finalidad de variables y otros elementos.
camelCaseConvención habitual para nombres como precioFinal.
IndentaciónHace visible la estructura del código y facilita su lectura.
Comentarios útilesExplican decisiones o intenciones que no resultan evidentes en el propio código.

2.10 Ámbito de las variables

El ámbito o scope determina desde qué partes del programa puede utilizarse una variable.

DeclaraciónÁmbito de bloqueSi se declara dentro de una funciónUso recomendado
letSíSolo es accesible dentro de su ámbito.Cuando el valor necesita cambiar.
constSíSolo es accesible dentro de su ámbito.Cuando no necesitamos reasignar el valor.
varNoQueda limitada a la función.Principalmente para reconocer código antiguo.
📌 Idea esencial

Una variable solo puede utilizarse desde los lugares en los que su ámbito la hace accesible.

2.11 Prueba y depuración del código

Depurar consiste en localizar, comprender y corregir los errores de un programa siguiendo un proceso ordenado.

ConsolePermite observar resultados, valores y mensajes de error.
SyntaxErrorEl código no respeta la sintaxis esperada por JavaScript.
ReferenceErrorSe intenta utilizar un identificador que JavaScript no encuentra en el ámbito actual.
TypeErrorSe realiza una operación o se utiliza una propiedad o método no válido para el valor.
SourcesPermite consultar los archivos JavaScript cargados y depurarlos.
BreakpointDetiene temporalmente la ejecución para observar valores y avanzar paso a paso.
💻 Ciclo de depuración

Reproduce → observa → localiza → comprende → corrige → comprueba.

Ideas clave de la UT2

📌 Si tuvieras que recordar solo estas ideas…
  • JavaScript distingue entre mayúsculas y minúsculas y utiliza reglas concretas para formar identificadores.
  • En código moderno utilizaremos principalmente const y let; var se mantiene sobre todo para reconocer código existente.
  • JavaScript tiene tipado dinámico y podemos consultar el tipo de un valor con typeof.
  • Debemos distinguir entre conversión explícita y coerción implícita.
  • Para comparar valores preferiremos normalmente === y !==.
  • Los template literals facilitan la construcción de cadenas e incorporan expresiones mediante ${...}.
  • Math ofrece utilidades numéricas y Number.isNaN() permite comprobar específicamente el valor NaN.
  • prompt() devuelve texto al aceptar y null al cancelar, por lo que debemos controlar la conversión de los datos introducidos.
  • El ámbito determina dónde puede utilizarse una variable; let y const tienen ámbito de bloque.
  • Un código de calidad utiliza nombres descriptivos, comentarios útiles e indentación coherente.
  • La depuración debe ser un proceso ordenado: reproducir, observar, localizar, comprender, corregir y comprobar.
