6.6 Funciones constructoras e instancias

En los apartados anteriores hemos aprendido a crear objetos, definir sus propiedades, añadir métodos y utilizar la palabra clave this.

Hasta ahora hemos trabajado principalmente con objetos creados de forma individual, utilizando la sintaxis de objetos literales.

Sin embargo, en una aplicación web es habitual necesitar numerosos objetos que representan elementos del mismo tipo.

Por ejemplo, una tienda online puede gestionar cientos de productos. Todos tienen propiedades semejantes, como nombre, precio y stock, aunque cada producto almacena valores diferentes.

Para evitar repetir el código de creación de cada objeto, JavaScript permite utilizar funciones constructoras.

Estas funciones nos permiten crear múltiples objetos a partir de una misma definición. Cada objeto creado recibe el nombre de instancia.

📌 Importante

Una función constructora es una función preparada para inicializar nuevos objetos cuando se utiliza con el operador new.

Una instancia es cada objeto concreto creado mediante esa función constructora.

Necesidad de crear varios objetos

Imagina que estamos desarrollando una aplicación para gestionar los productos de una tienda.

Podemos crear cada producto mediante un objeto literal:

JavaScript 
const producto1 = {
  nombre: "Teclado",
  precio: 45,
  stock: 10
};

const producto2 = {
  nombre: "Ratón",
  precio: 25,
  stock: 20
};

const producto3 = {
  nombre: "Monitor",
  precio: 180,
  stock: 5
};

Los tres objetos tienen la misma estructura, pero contienen datos diferentes.

Este procedimiento funciona, aunque presenta varios inconvenientes cuando aumenta el número de objetos.

  • Tenemos que repetir los nombres de las propiedades en cada objeto.
  • Es más fácil cometer errores al escribir las propiedades.
  • Si necesitamos añadir una propiedad común, tendremos que modificar cada definición.
  • Resulta poco práctico cuando los objetos se crean dinámicamente a partir de formularios o datos recibidos del servidor.

Una primera solución: utilizar una función

Podemos crear una función ordinaria que reciba los datos y devuelva un objeto.

JavaScript 
function crearProducto(nombre, precio, stock) {
  return {
    nombre: nombre,
    precio: precio,
    stock: stock
  };
}

const producto1 = crearProducto("Teclado", 45, 10);
const producto2 = crearProducto("Ratón", 25, 20);

console.log(producto1.nombre);
console.log(producto2.nombre);

// Teclado
// Ratón

Esta técnica se conoce como función fábrica: una función que crea y devuelve objetos.

Es una opción válida en JavaScript. Sin embargo, también existe otro mecanismo para crear objetos a partir de una función: las funciones constructoras.

⚠️ Atención

Una función fábrica y una función constructora no son exactamente lo mismo.

La función fábrica suele crear y devolver explícitamente un objeto.

La función constructora se utiliza con new, que se encarga de crear y devolver la nueva instancia cuando la función no devuelve explícitamente otro objeto.

Funciones constructoras

Una función constructora se define utilizando la palabra clave function, igual que una función tradicional.

La diferencia fundamental está en cómo la utilizamos: la invocamos con el operador new para crear nuevos objetos.

Sintaxis de una función constructora

JavaScript 
function NombreConstructor(parametro1, parametro2) {
  this.propiedad1 = parametro1;
  this.propiedad2 = parametro2;
}

Observa los elementos principales:

  • function permite declarar la función.
  • NombreConstructor identifica la función constructora.
  • Los parámetros reciben los datos necesarios para inicializar el objeto.
  • this permite asignar propiedades a la nueva instancia.

Primera función constructora

Vamos a definir una función constructora para crear productos.

JavaScript 
function Producto(nombre, precio, stock) {
  this.nombre = nombre;
  this.precio = precio;
  this.stock = stock;
}

const producto1 = new Producto("Teclado", 45, 10);

console.log(producto1.nombre);
console.log(producto1.precio);
console.log(producto1.stock);

// Teclado
// 45
// 10

La función Producto define cómo se inicializan los objetos.

Al ejecutar new Producto("Teclado", 45, 10), JavaScript crea un nuevo objeto y asigna los valores recibidos a sus propiedades.

Convención de nombres

Por convención, las funciones constructoras se escriben utilizando PascalCase: la primera letra de cada palabra se escribe en mayúscula.

Función ordinaria Función constructora
calcularTotal() Producto()
mostrarUsuario() Usuario()
crearPedido() Pedido()
📌 Importante

Escribir el nombre con mayúscula inicial no convierte automáticamente una función en constructora.

Es una convención que ayuda a reconocer que esperamos utilizarla mediante el operador new.

El operador new

El operador new es fundamental para comprender el funcionamiento de las funciones constructoras.

Cuando utilizamos new con una función constructora, JavaScript realiza una serie de operaciones de forma automática.

Cómo funciona new paso a paso

Considera la siguiente instrucción:

JavaScript 
const alumno = new Alumno("Lucía", 20);

De forma simplificada, JavaScript realiza estos pasos:

  1. Crea un nuevo objeto vacío.
  2. Vincula su prototipo al objeto Alumno.prototype.
  3. Ejecuta la función constructora utilizando el nuevo objeto como valor de this.
  4. Devuelve la instancia si la función no devuelve explícitamente otro objeto.
1. new Alumno("Lucía", 20) Se solicita crear una nueva instancia.
2. Nuevo objeto JavaScript crea el objeto y establece su prototipo.
3. this La función inicializa las propiedades del nuevo objeto.
4. Instancia creada La variable alumno recibe una referencia al objeto.

Ejemplo completo

JavaScript 
function Alumno(nombre, edad) {
  this.nombre = nombre;
  this.edad = edad;
}

const alumno1 = new Alumno("Lucía", 20);
const alumno2 = new Alumno("Carlos", 22);

console.log(alumno1);
console.log(alumno2);

// Alumno { nombre: "Lucía", edad: 20 }
// Alumno { nombre: "Carlos", edad: 22 }

Los dos objetos han sido creados mediante la misma función constructora, pero contienen valores diferentes.

⚠️ Atención

El operador new no es una parte opcional de estos ejemplos.

Si llamamos a una función constructora como una función ordinaria, su comportamiento respecto a this será diferente.

Más adelante estudiaremos por qué esto puede provocar errores.

Creación de instancias

Cada objeto creado mediante una función constructora recibe el nombre de instancia.

Una misma función constructora puede utilizarse tantas veces como sea necesario.

Crear varios objetos independientes

JavaScript 
function Usuario(nombre, email) {
  this.nombre = nombre;
  this.email = email;
  this.activo = true;
}

const usuario1 = new Usuario(
  "Ana",
  "ana@ejemplo.com"
);

const usuario2 = new Usuario(
  "Carlos",
  "carlos@ejemplo.com"
);

console.log(usuario1.nombre);
console.log(usuario2.nombre);

// Ana
// Carlos

La función constructora establece la estructura inicial de los objetos.

Cada llamada a new Usuario() crea una instancia diferente.

Las instancias tienen propiedades independientes

Una característica fundamental es que las propiedades propias de cada instancia pueden modificarse sin afectar a las demás.

JavaScript 
function Usuario(nombre) {
  this.nombre = nombre;
  this.activo = true;
}

const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Carlos");

usuario1.activo = false;

console.log(usuario1.activo);
console.log(usuario2.activo);

// false
// true

Modificar la propiedad activo de usuario1 no cambia el valor de esa propiedad en usuario2.

Comparación entre instancias

JavaScript 
function Producto(nombre) {
  this.nombre = nombre;
}

const producto1 = new Producto("Teclado");
const producto2 = new Producto("Teclado");

console.log(producto1 === producto2);
console.log(producto1.nombre === producto2.nombre);

// false
// true

Aunque los dos productos contienen el mismo nombre, son objetos distintos.

La comparación === entre objetos comprueba su identidad, no si sus propiedades tienen los mismos valores.

📌 Importante

Crear dos instancias mediante la misma función constructora no significa que sean el mismo objeto.

Cada llamada a new crea un nuevo objeto, salvo comportamientos especiales de constructores que devuelven explícitamente otro objeto.

La palabra clave this en las funciones constructoras

En el apartado 6.5 estudiamos cómo funciona this dentro de los métodos.

En una función constructora llamada mediante new, this hace referencia a la nueva instancia que se está inicializando.

Asignar propiedades con this

JavaScript 
function Cliente(nombre, puntos) {
  this.nombre = nombre;
  this.puntos = puntos;
}

const cliente1 = new Cliente("Elena", 100);
const cliente2 = new Cliente("Marta", 50);

console.log(cliente1.puntos);
console.log(cliente2.puntos);

// 100
// 50

Durante la creación de cliente1, this hace referencia a esa nueva instancia.

Durante la creación de cliente2, this hace referencia a otra instancia distinta.

Propiedades con valores iniciales

No todas las propiedades tienen que recibir sus valores mediante parámetros.

También podemos establecer valores predeterminados dentro de la función.

JavaScript 
function Pedido(id, cliente, importe) {
  this.id = id;
  this.cliente = cliente;
  this.importe = importe;
  this.estado = "Pendiente";
  this.pagado = false;
}

const pedido1 = new Pedido(101, "Ana", 85);
const pedido2 = new Pedido(102, "Luis", 120);

console.log(pedido1.estado);
console.log(pedido2.pagado);

// Pendiente
// false

Cada pedido recibe sus propios datos, pero ambos comienzan con estado = "Pendiente" y pagado = false.

Validar datos durante la construcción

Una función constructora también puede comprobar los datos recibidos antes de asignarlos.

JavaScript 
function Producto(nombre, precio, stock) {
  this.nombre = nombre;

  this.precio =
    typeof precio === "number" &&
    Number.isFinite(precio) &&
    precio >= 0
      ? precio
      : 0;

  this.stock =
    Number.isInteger(stock) && stock >= 0
      ? stock
      : 0;
}

const producto = new Producto("Monitor", -50, 4);

console.log(producto.precio);
console.log(producto.stock);

// 0
// 4

En este ejemplo, si el precio no es válido, se utiliza el valor 0.

Lo mismo ocurre con el stock cuando no es un número entero mayor o igual que cero.

💻 Ejemplo DAW

En una aplicación web, las funciones constructoras pueden utilizarse para inicializar objetos a partir de datos introducidos en formularios.

También pueden asignar estados iniciales, como "Pendiente", false o 0.

Estas comprobaciones del lado del cliente no sustituyen las validaciones necesarias en el servidor.

Métodos en las instancias

Las funciones constructoras también permiten crear objetos que contienen métodos.

De esta forma, cada instancia puede almacenar datos y realizar operaciones relacionadas con ellos.

Definir métodos dentro de una constructora

JavaScript 
function Producto(nombre, precio) {
  this.nombre = nombre;
  this.precio = precio;

  this.mostrarInformacion = function() {
    console.log(
      `${this.nombre}: ${this.precio} €`
    );
  };
}

const producto1 = new Producto("Teclado", 45);
const producto2 = new Producto("Ratón", 25);

producto1.mostrarInformacion();
producto2.mostrarInformacion();

// Teclado: 45 €
// Ratón: 25 €

Cada producto dispone del método mostrarInformacion(), que consulta sus propias propiedades mediante this.

Métodos que modifican el estado

También podemos definir métodos que cambien los valores de las propiedades.

JavaScript 
function Contador(valorInicial) {
  this.valor = valorInicial;

  this.incrementar = function() {
    this.valor++;
  };

  this.consultar = function() {
    return this.valor;
  };
}

const contador1 = new Contador(0);
const contador2 = new Contador(10);

contador1.incrementar();
contador1.incrementar();

contador2.incrementar();

console.log(contador1.consultar());
console.log(contador2.consultar());

// 2
// 11

Cada contador mantiene su propio valor.

El método incrementar() modifica únicamente la instancia sobre la que se invoca.

Una consideración importante sobre los métodos

Cuando definimos un método dentro de una función constructora mediante una asignación como this.metodo = function() { ... }, se crea una nueva función para cada instancia.

JavaScript 
function Usuario(nombre) {
  this.nombre = nombre;

  this.saludar = function() {
    return `Hola, soy ${this.nombre}`;
  };
}

const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Carlos");

console.log(usuario1.saludar());
console.log(usuario2.saludar());

console.log(usuario1.saludar === usuario2.saludar);

// Hola, soy Ana
// Hola, soy Carlos
// false

Los dos objetos tienen un método llamado saludar, pero cada instancia contiene una función diferente.

📌 Importante

JavaScript dispone de un mecanismo llamado prototipos que permite compartir métodos entre varias instancias.

Por ejemplo, podemos definir Usuario.prototype.saludar para que las instancias utilicen una misma función.

En los siguientes apartados veremos cómo las clases proporcionan una sintaxis más cómoda para organizar este tipo de comportamiento.

Introducción a los métodos compartidos

Veamos brevemente la diferencia utilizando prototype.

JavaScript 
function Usuario(nombre) {
  this.nombre = nombre;
}

Usuario.prototype.saludar = function() {
  return `Hola, soy ${this.nombre}`;
};

const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Carlos");

console.log(usuario1.saludar());
console.log(usuario2.saludar());

console.log(usuario1.saludar === usuario2.saludar);

// Hola, soy Ana
// Hola, soy Carlos
// true

Ahora las dos instancias utilizan la misma función saludar(), que se encuentra en el prototipo compartido.

No es necesario dominar todavía el sistema de prototipos. Lo importante es comprender que existen distintas formas de organizar los métodos de los objetos.

El operador instanceof

Cuando trabajamos con varias funciones constructoras, puede resultar útil comprobar si un objeto pertenece a una determinada familia de instancias.

Para ello podemos utilizar el operador instanceof.

Sintaxis de instanceof

JavaScript 
objeto instanceof Constructor

El resultado es un valor booleano: true o false.

Ejemplo de comprobación

JavaScript 
function Alumno(nombre) {
  this.nombre = nombre;
}

function Profesor(nombre) {
  this.nombre = nombre;
}

const alumno = new Alumno("Lucía");
const profesor = new Profesor("Carlos");

console.log(alumno instanceof Alumno);
console.log(alumno instanceof Profesor);
console.log(profesor instanceof Profesor);

// true
// false
// true

El objeto alumno se creó mediante Alumno, mientras que profesor se creó mediante Profesor.

Por eso obtenemos resultados diferentes al utilizar instanceof.

Diferencia entre instanceof y typeof

JavaScript 
function Producto(nombre) {
  this.nombre = nombre;
}

const producto = new Producto("Monitor");

console.log(typeof producto);
console.log(producto instanceof Producto);

// object
// true

typeof indica que estamos trabajando con un objeto.

instanceof permite comprobar una relación más específica con una función constructora.

⚠️ Atención

Técnicamente, instanceof comprueba si el valor de Constructor.prototype aparece en la cadena de prototipos del objeto, salvo que se haya personalizado el comportamiento del operador.

No comprueba simplemente que el objeto tenga determinadas propiedades.

Por ejemplo, un objeto literal con las mismas propiedades que una instancia de Producto no tiene por qué cumplir objeto instanceof Producto.

Errores habituales con las funciones constructoras

Al comenzar a utilizar funciones constructoras, es frecuente cometer errores relacionados con new, this y la creación de instancias.

Error 1. Olvidar el operador new

Observa el siguiente ejemplo:

JavaScript 
"use strict";

function Usuario(nombre) {
  this.nombre = nombre;
}

const usuario = Usuario("Ana");

// TypeError: this es undefined
// en esta llamada ordinaria.

En este ejemplo no utilizamos new.

Como hemos activado el modo estricto, this es undefined durante la llamada ordinaria.

Por tanto, intentar asignar this.nombre provoca un error.

La forma correcta es:

JavaScript 
"use strict";

function Usuario(nombre) {
  this.nombre = nombre;
}

const usuario = new Usuario("Ana");

console.log(usuario.nombre);

// Ana

Error 2. Confundir el constructor con una instancia

La función constructora y los objetos creados a partir de ella son elementos diferentes.

JavaScript 
function Producto(nombre) {
  this.nombre = nombre;
}

const producto = new Producto("Teclado");

console.log(typeof Producto);
console.log(typeof producto);

console.log(producto.nombre);
console.log(Producto.nombre);

// function
// object
// Teclado
// Producto

Producto es una función constructora.

producto es una instancia creada mediante esa función.

Además, Producto.nombre no es la propiedad de la instancia: es la propiedad name de la función, que en JavaScript se escribe Producto.name.

⚠️ Atención

En JavaScript, Producto.nombre y Producto.name son propiedades distintas.

En el ejemplo anterior, Producto.nombre devuelve undefined, mientras que Producto.name devuelve "Producto".

La propiedad del producto creado se consulta mediante producto.nombre.

Error 3. Utilizar una función flecha como constructora

Las funciones flecha no pueden utilizarse como constructoras mediante new.

JavaScript 
const Usuario = (nombre) => {
  this.nombre = nombre;
};

const usuario = new Usuario("Ana");

// TypeError: Usuario is not a constructor

Para definir una función constructora tradicional utilizamos una función normal declarada mediante function.

Error 4. Compartir accidentalmente objetos internos

Aunque las instancias son objetos independientes, debemos prestar atención cuando una propiedad contiene otro objeto.

JavaScript 
const preferenciasIniciales = {
  tema: "claro"
};

function Usuario(nombre) {
  this.nombre = nombre;
  this.preferencias = preferenciasIniciales;
}

const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Carlos");

usuario1.preferencias.tema = "oscuro";

console.log(usuario2.preferencias.tema);

// oscuro

Ambos usuarios comparten una referencia al mismo objeto preferenciasIniciales.

Si queremos que cada instancia tenga sus propias preferencias, debemos crear un objeto nuevo durante la construcción.

JavaScript 
function Usuario(nombre) {
  this.nombre = nombre;

  this.preferencias = {
    tema: "claro"
  };
}

const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Carlos");

usuario1.preferencias.tema = "oscuro";

console.log(usuario1.preferencias.tema);
console.log(usuario2.preferencias.tema);

// oscuro
// claro
📌 Importante

Recuerda que los objetos se manejan mediante referencias.

Si varias instancias almacenan la referencia al mismo objeto interno, las modificaciones realizadas a través de una de ellas pueden afectar a las demás.

Ejemplos prácticos

Vamos a aplicar las funciones constructoras y la creación de instancias a situaciones habituales en el desarrollo de aplicaciones web.

⚠️ Atención

Los ejemplos siguientes son independientes.

Puedes ejecutarlos por separado en la consola del navegador o en archivos JavaScript diferentes.

Si ejecutas varios en el mismo ámbito, ten en cuenta que algunas funciones y variables utilizan nombres repetidos.

Ejemplo 1. Gestión de alumnos

Imagina una aplicación que necesita almacenar los datos de los alumnos de un ciclo formativo.

Todos los alumnos tienen un nombre, una edad y un curso.

JavaScript 
function Alumno(nombre, edad, curso) {
  this.nombre = nombre;
  this.edad = edad;
  this.curso = curso;

  this.mostrarDatos = function() {
    console.log(
      `${this.nombre} - ${this.curso}`
    );
  };
}

const alumno1 = new Alumno(
  "Lucía",
  20,
  "2º DAW"
);

const alumno2 = new Alumno(
  "Carlos",
  22,
  "2º DAW"
);

alumno1.mostrarDatos();
alumno2.mostrarDatos();

// Lucía - 2º DAW
// Carlos - 2º DAW

La función constructora permite crear alumnos sin repetir la definición de sus propiedades y métodos.

💻 Ejemplo DAW

En una aplicación de gestión académica, podríamos utilizar instancias para representar alumnos, profesores, módulos o matrículas.

Cada objeto contendría los datos correspondientes a un elemento concreto.

Ejemplo 2. Catálogo de productos

Una tienda online necesita crear numerosos productos con características semejantes.

Vamos a definir una función constructora que permita consultar la disponibilidad y calcular precios con descuento.

JavaScript 
function Producto(nombre, precio, stock) {
  this.nombre = nombre;
  this.precio = precio;
  this.stock = stock;

  this.estaDisponible = function() {
    return this.stock > 0;
  };

  this.calcularDescuento = function(porcentaje) {
    return this.precio * (1 - porcentaje / 100);
  };
}

const teclado = new Producto("Teclado", 50, 8);
const monitor = new Producto("Monitor", 200, 0);

console.log(teclado.estaDisponible());
console.log(monitor.estaDisponible());

console.log(teclado.calcularDescuento(10));
console.log(monitor.calcularDescuento(20));

// true
// false
// 45
// 160

Las dos instancias utilizan los mismos nombres de métodos, pero cada una trabaja con sus propios datos.

Ejemplo 3. Gestión de cuentas de clientes

Vamos a crear un constructor para representar cuentas con un saldo inicial.

Cada cuenta podrá recibir ingresos, realizar retiradas y consultar su saldo.

JavaScript 
function Cuenta(titular, saldoInicial) {
  this.titular = titular;
  this.saldo = saldoInicial;

  this.ingresar = function(cantidad) {
    if (
      typeof cantidad === "number" &&
      Number.isFinite(cantidad) &&
      cantidad > 0
    ) {
      this.saldo += cantidad;
      return true;
    }

    return false;
  };

  this.retirar = function(cantidad) {
    if (
      typeof cantidad === "number" &&
      Number.isFinite(cantidad) &&
      cantidad > 0 &&
      cantidad <= this.saldo
    ) {
      this.saldo -= cantidad;
      return true;
    }

    return false;
  };

  this.consultarSaldo = function() {
    return this.saldo;
  };
}

const cuenta1 = new Cuenta("Ana", 200);
const cuenta2 = new Cuenta("Carlos", 100);

cuenta1.ingresar(50);
cuenta2.retirar(30);

console.log(cuenta1.consultarSaldo());
console.log(cuenta2.consultarSaldo());

// 250
// 70

Cada cuenta mantiene su propio saldo.

Los métodos utilizan this.saldo para modificar o consultar el estado de la instancia.

Ejemplo 4. Sistema de reservas

Una aplicación de reservas puede necesitar gestionar varias habitaciones.

Cada habitación tendrá un número, un precio y un estado de disponibilidad.

JavaScript 
function Habitacion(numero, precioNoche) {
  this.numero = numero;
  this.precioNoche = precioNoche;
  this.disponible = true;

  this.reservar = function() {
    if (this.disponible) {
      this.disponible = false;
      return true;
    }

    return false;
  };

  this.calcularPrecio = function(noches) {
    if (!Number.isInteger(noches) || noches <= 0) {
      return null;
    }

    return this.precioNoche * noches;
  };
}

const habitacion1 = new Habitacion(101, 75);
const habitacion2 = new Habitacion(102, 95);

console.log(habitacion1.reservar());
console.log(habitacion1.reservar());

console.log(habitacion2.calcularPrecio(3));

// false

Reservar una habitación no modifica la disponibilidad de las demás.

Ejemplo 5. Gestión de pedidos de una tienda online

Vamos a desarrollar un ejemplo más completo que combine funciones constructoras, instancias, propiedades, métodos, condiciones y el operador instanceof.

Imagina una tienda online que necesita crear pedidos, calcular su importe total y actualizar su estado.

JavaScript 
function Pedido(id, cliente, importe, gastosEnvio) {
  this.id = id;
  this.cliente = cliente;
  this.importe = importe;
  this.gastosEnvio = gastosEnvio;
  this.estado = "Pendiente";

  this.calcularTotal = function() {
    return this.importe + this.gastosEnvio;
  };

  this.cambiarEstado = function(nuevoEstado) {
    const estadosValidos = [
      "Pendiente",
      "Preparando",
      "Enviado",
      "Entregado"
    ];

    if (estadosValidos.includes(nuevoEstado)) {
      this.estado = nuevoEstado;
      return true;
    }

    return false;
  };

  this.mostrarResumen = function() {
    console.log(`Pedido: ${this.id}`);
    console.log(`Cliente: ${this.cliente}`);
    console.log(`Estado: ${this.estado}`);
    console.log(`Total: ${this.calcularTotal()} €`);
  };
}

const pedido1 = new Pedido(101, "Ana", 120, 6);
const pedido2 = new Pedido(102, "Carlos", 85, 5);

pedido1.cambiarEstado("Enviado");

pedido1.mostrarResumen();
pedido2.mostrarResumen();

console.log(pedido1 instanceof Pedido);
console.log(pedido2 instanceof Pedido);

// Pedido: 101
// Cliente: Ana
// Estado: Enviado
// Total: 126 €
//
// Pedido: 102
// Cliente: Carlos
// Estado: Pendiente
// Total: 90 €
//
// true
// true

Analicemos su funcionamiento:

  1. Definimos la función constructora Pedido.
  2. Recibimos los datos iniciales mediante parámetros.
  3. Utilizamos this para inicializar las propiedades.
  4. Definimos métodos para calcular el total, modificar el estado y mostrar información.
  5. Creamos dos instancias utilizando new.
  6. Cambiamos el estado únicamente del primer pedido.
  7. Comprobamos que ambos objetos cumplen la relación instanceof Pedido.

Este ejemplo muestra cómo una función constructora permite organizar la creación de numerosos objetos con características semejantes.

Las funciones constructoras facilitan la reutilización de una estructura común.

Qué debemos recordar

Antes de continuar, conviene repasar las ideas fundamentales.

  • Una función constructora permite inicializar nuevos objetos mediante el operador new.
  • Cada objeto creado recibe el nombre de instancia.
  • Por convención, las funciones constructoras se escriben con mayúscula inicial.
  • El operador new crea un objeto, establece su prototipo y ejecuta la función con ese objeto como this.
  • this permite inicializar las propiedades de cada instancia.
  • Las instancias creadas mediante llamadas diferentes a new son objetos distintos.
  • Podemos definir métodos que consulten o modifiquen los datos de cada instancia.
  • Los métodos también pueden compartirse mediante prototipos.
  • El operador instanceof permite comprobar relaciones con las funciones constructoras a través de la cadena de prototipos.
  • Las funciones flecha no pueden utilizarse como constructoras con new.
📌 Importante

Las funciones constructoras permiten pasar de la creación individual de objetos a la creación sistemática de múltiples instancias.

Este concepto resulta esencial para comprender la Programación Orientada a Objetos en JavaScript.

En el siguiente apartado aprenderemos a utilizar la sintaxis moderna de class y constructor.

💭 Piensa

Imagina que estás desarrollando una aplicación web para gestionar los vehículos de una empresa de alquiler.

Cada vehículo debe almacenar un identificador, una marca, un precio por día y su disponibilidad.

Responde a las siguientes preguntas antes de consultar la solución:

  1. ¿Cómo definirías una función constructora llamada Vehiculo que reciba el identificador, la marca y el precio por día?
  2. ¿Cómo utilizarías this para asignar las propiedades de cada vehículo?
  3. ¿Cómo establecerías que todos los vehículos estén inicialmente disponibles?
  4. ¿Cómo crearías dos instancias diferentes mediante el operador new?
  5. ¿Cómo definirías un método calcularAlquiler(dias) que devuelva el precio total de un alquiler?
  6. ¿Cómo crearías un método alquilar() que cambie la disponibilidad a false solamente si el vehículo está disponible?
  7. ¿Qué ocurriría si alquiláramos un vehículo? ¿Cambiaría la disponibilidad del otro?
  8. ¿Qué resultado devolvería vehiculo1 instanceof Vehiculo?
Ver una posible solución

Una posible solución sería la siguiente:

JavaScript 
function Vehiculo(id, marca, precioDia) {
  // 1, 2 y 3. Inicializar propiedades
  this.id = id;
  this.marca = marca;
  this.precioDia = precioDia;
  this.disponible = true;

  // 5. Calcular el precio del alquiler
  this.calcularAlquiler = function(dias) {
    if (!Number.isInteger(dias) || dias <= 0) {
      return null;
    }

    return this.precioDia * dias;
  };

  // 6. Alquilar si está disponible
  this.alquilar = function() {
    if (this.disponible) {
      this.disponible = false;
      return true;
    }

    return false;
  };
}

// 4. Crear dos instancias
const vehiculo1 = new Vehiculo(1, "Toyota", 45);
const vehiculo2 = new Vehiculo(2, "Seat", 35);

// Calcular el precio de tres días
console.log(vehiculo1.calcularAlquiler(3));

// Alquilar el primer vehículo
console.log(vehiculo1.alquilar());

// Comprobar disponibilidad
console.log(vehiculo1.disponible);
console.log(vehiculo2.disponible);

// Intentar alquilar otra vez
console.log(vehiculo1.alquilar());

// 8. Comprobar la instancia
console.log(vehiculo1 instanceof Vehiculo);

// 135
// true
// false
// true
// false
// true

Preguntas 1 y 2. La función constructora Vehiculo recibe los datos mediante parámetros y utiliza this para asignarlos a la nueva instancia.

Pregunta 3. La instrucción this.disponible = true establece el estado inicial de cada vehículo.

Pregunta 4. Utilizamos new Vehiculo() dos veces para crear dos objetos diferentes.

Pregunta 5. El método calcularAlquiler(dias) multiplica el precio diario por el número de días. También comprueba que la duración sea válida.

Pregunta 6. El método alquilar() comprueba this.disponible. Si el vehículo está libre, modifica su estado y devuelve true.

Pregunta 7. Alquilar vehiculo1 no modifica vehiculo2, porque son instancias independientes. Además, intentar alquilar dos veces el primer vehículo devuelve false en la segunda llamada.

Pregunta 8. La expresión vehiculo1 instanceof Vehiculo devuelve true, porque la instancia conserva la relación de prototipos establecida al crearla con new Vehiculo().
