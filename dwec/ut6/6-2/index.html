6.2 Propiedades y métodos de los objetos

En el apartado anterior hemos aprendido que los objetos en JavaScript permiten agrupar información relacionada dentro de una misma estructura. También hemos visto que un objeto puede contener propiedades para almacenar datos y métodos para realizar operaciones.

Sin embargo, crear un objeto es solamente el primer paso. Para utilizarlo en una aplicación necesitamos saber cómo consultar sus propiedades, modificar sus valores y ejecutar sus métodos.

Por ejemplo, en una tienda online podríamos representar un producto mediante un objeto. Después, el programa tendría que consultar su precio, comprobar las unidades disponibles o actualizar su información cuando se produjera una venta.

En este apartado estudiaremos las operaciones fundamentales que permiten trabajar con las propiedades y los métodos de los objetos.

📌 Importante

Las propiedades permiten almacenar y consultar información de un objeto, mientras que los métodos permiten ejecutar operaciones asociadas a él.

En JavaScript podemos acceder a ambos utilizando la notación de punto o, en determinados casos, la notación de corchetes.

Qué son las propiedades

Una propiedad es un elemento de un objeto que permite almacenar un valor asociado a un nombre.

Cada propiedad está formada por dos componentes:

  • Nombre o clave: identifica la propiedad dentro del objeto.
  • Valor: contiene la información asociada a esa propiedad.

Vamos a utilizar como ejemplo un objeto que representa un producto de una tienda online:

JavaScript 
const producto = {
  nombre: "Monitor Samsung",
  precio: 189.99,
  stock: 10,
  disponible: true
};

En este objeto encontramos cuatro propiedades: nombre, precio, stock y disponible.

Propiedad Valor Tipo de dato
nombre "Monitor Samsung" String
precio 189.99 Number
stock 10 Number
disponible true Boolean

Como podemos observar, las propiedades de un mismo objeto pueden almacenar valores de diferentes tipos.

Esto permite representar de forma organizada entidades que contienen información variada, como productos, usuarios, alumnos, pedidos o reservas.

Las propiedades identifican la información

Una diferencia importante entre los objetos y los arrays es la forma habitual de identificar sus elementos.

En un array accedemos normalmente a un elemento mediante su posición:

JavaScript 
const datos = ["Monitor Samsung", 189.99, 10];

console.log(datos[0]); // Monitor Samsung
console.log(datos[1]); // 189.99

En cambio, en un objeto podemos identificar directamente cada dato por el nombre de su propiedad:

JavaScript 
const producto = {
  nombre: "Monitor Samsung",
  precio: 189.99,
  stock: 10
};

console.log(producto.nombre);
console.log(producto.precio);

En este segundo ejemplo, el código resulta más expresivo porque podemos comprender qué información estamos consultando simplemente leyendo el nombre de la propiedad.

💻 Ejemplo DAW

En una aplicación de gestión académica, resulta más comprensible escribir alumno.email que depender de una posición como datos[3] para consultar el correo electrónico.

Los nombres de las propiedades ayudan a documentar la estructura de los datos y facilitan el mantenimiento del código.

Acceso mediante el punto

La forma más habitual de acceder a una propiedad consiste en utilizar la notación de punto.

Para ello escribimos el nombre de la variable que contiene el objeto, seguido de un punto y del nombre de la propiedad.

Sintaxis 
objeto.propiedad

Por ejemplo:

JavaScript 
const alumno = {
  nombre: "Laura",
  edad: 20,
  ciclo: "DAW",
  matriculado: true
};

console.log(alumno.nombre);
console.log(alumno.edad);
console.log(alumno.ciclo);
console.log(alumno.matriculado);

El resultado será:

Consola 
Laura
20
DAW
true

Cuando escribimos alumno.nombre, JavaScript busca la propiedad nombre dentro del objeto referenciado por alumno y devuelve su valor.

Utilizar propiedades en operaciones

Las propiedades no solamente pueden mostrarse por consola. También pueden utilizarse en expresiones, cálculos, comparaciones y estructuras de control.

Imagina que necesitamos calcular el precio de tres unidades de un producto:

JavaScript 
const producto = {
  nombre: "Teclado mecánico",
  precio: 65,
  stock: 12
};

const cantidad = 3;

const total = producto.precio * cantidad;

console.log(total); // 195

En este ejemplo, producto.precio devuelve el número 65, que se utiliza directamente en la multiplicación.

También podemos utilizar las propiedades para tomar decisiones:

JavaScript 
const producto = {
  nombre: "Teclado mecánico",
  precio: 65,
  stock: 12
};

if (producto.stock > 0) {
  console.log("Producto disponible");
} else {
  console.log("Producto agotado");
}

La condición consulta el valor de producto.stock y comprueba si es mayor que cero.

Acceso a propiedades de objetos anidados

Como vimos en el apartado anterior, una propiedad puede contener otro objeto.

En ese caso, podemos encadenar varios puntos para acceder a una propiedad situada dentro de un objeto anidado.

JavaScript 
const alumno = {
  nombre: "Laura",
  contacto: {
    email: "laura@ejemplo.com",
    telefono: "600123456"
  }
};

console.log(alumno.contacto.email);
console.log(alumno.contacto.telefono);

La expresión alumno.contacto.email se interpreta de la siguiente manera:

  1. Accedemos al objeto alumno.
  2. Consultamos su propiedad contacto, que contiene otro objeto.
  3. Dentro de ese segundo objeto, consultamos la propiedad email.
alumno Objeto principal
nombre "Laura"
contacto Objeto anidado
alumno.contacto.email Acceso a la propiedad email dentro del objeto contacto
⚠️ Atención

Para utilizar la notación de punto, el nombre de la propiedad debe escribirse directamente después del punto, sin comillas.

Por ejemplo, alumno.nombre es correcto, mientras que alumno."nombre" no es una expresión válida.

Acceso mediante corchetes

JavaScript también permite acceder a las propiedades de un objeto utilizando corchetes.

En este caso, el nombre de la propiedad puede escribirse como una cadena de texto dentro de los corchetes.

Sintaxis 
objeto["propiedad"]

Vamos a utilizar el mismo objeto que en el ejemplo anterior:

JavaScript 
const alumno = {
  nombre: "Laura",
  edad: 20,
  ciclo: "DAW"
};

console.log(alumno["nombre"]);
console.log(alumno["edad"]);
console.log(alumno["ciclo"]);

El resultado será exactamente el mismo que utilizando la notación de punto:

Consola 
Laura
20
DAW

Diferencias entre punto y corchetes

Ambas notaciones permiten consultar propiedades, pero presentan algunas diferencias importantes.

Característica Notación de punto Notación de corchetes
Sintaxis alumno.nombre alumno["nombre"]
Nombre fijo de propiedad Sí Sí
Nombre almacenado en una variable No directamente Sí
Propiedades con espacios No Sí
Uso habitual Acceso directo y legible Acceso dinámico o nombres especiales

Acceder mediante una variable

Una de las ventajas más importantes de la notación de corchetes es que permite utilizar una variable para indicar qué propiedad queremos consultar.

JavaScript 
const producto = {
  nombre: "Impresora",
  precio: 120,
  stock: 8
};

const propiedad = "precio";

console.log(producto[propiedad]); // 120

Observa que dentro de los corchetes escribimos propiedad sin comillas.

JavaScript consulta el valor de esa variable, que es la cadena "precio", y utiliza ese texto para localizar la propiedad correspondiente.

Por tanto, estas dos expresiones no significan lo mismo:

JavaScript 
const propiedad = "precio";

console.log(producto["precio"]);  // 120
console.log(producto[propiedad]); // 120

En la primera expresión utilizamos directamente el texto "precio". En la segunda, utilizamos el contenido de una variable.

📌 Importante

Cuando conocemos de antemano el nombre de una propiedad, normalmente utilizamos la notación de punto por su sencillez.

Cuando el nombre de la propiedad se obtiene de una variable o de una expresión, utilizamos la notación de corchetes.

Propiedades con espacios o nombres especiales

La notación de corchetes también resulta necesaria cuando el nombre de una propiedad contiene espacios u otros caracteres que impiden utilizarlo directamente con la notación de punto.

JavaScript 
const alumno = {
  nombre: "Laura",
  "correo electrónico": "laura@ejemplo.com"
};

console.log(alumno["correo electrónico"]);

En este caso, la propiedad "correo electrónico" contiene un espacio, por lo que no podemos escribir alumno.correo electrónico.

Aunque JavaScript permite este tipo de nombres, en nuestros programas suele ser preferible utilizar identificadores claros como correoElectronico.

Acceso dinámico a diferentes propiedades

La notación de corchetes resulta especialmente útil cuando necesitamos seleccionar una propiedad en función de una condición o de una decisión del programa.

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 180,
  stock: 5
};

let datoSolicitado = "nombre";

console.log(producto[datoSolicitado]);

datoSolicitado = "stock";

console.log(producto[datoSolicitado]);

El resultado será:

Consola 
Monitor
5

Este mecanismo será especialmente importante en el apartado 6.4, cuando aprendamos a recorrer las propiedades de un objeto.

Modificación de propiedades

Además de consultar las propiedades, JavaScript permite modificar sus valores.

Esta operación es fundamental en aplicaciones web, ya que la información puede cambiar durante la ejecución del programa.

Por ejemplo, el stock de un producto disminuye cuando se realiza una venta, el precio puede actualizarse o el estado de una reserva puede pasar de disponible a ocupada.

Modificar mediante la notación de punto

Para cambiar el valor de una propiedad, podemos utilizar el operador de asignación =.

JavaScript 
const producto = {
  nombre: "Ratón inalámbrico",
  precio: 25,
  stock: 15
};

producto.precio = 29;

console.log(producto.precio); // 29

Inicialmente, el precio del producto era 25. Después de ejecutar producto.precio = 29, su valor pasa a ser 29.

El objeto sigue siendo el mismo; simplemente hemos modificado una de sus propiedades.

Modificar mediante corchetes

También podemos modificar propiedades utilizando la notación de corchetes.

JavaScript 
const producto = {
  nombre: "Ratón inalámbrico",
  precio: 25,
  stock: 15
};

producto["precio"] = 29;

console.log(producto["precio"]); // 29

El resultado es idéntico al obtenido con la notación de punto.

También podríamos indicar el nombre de la propiedad mediante una variable:

JavaScript 
const producto = {
  nombre: "Ratón inalámbrico",
  precio: 25,
  stock: 15
};

const campo = "stock";

producto[campo] = 20;

console.log(producto.stock); // 20

Actualizar propiedades mediante operaciones

En muchas situaciones no queremos sustituir un valor por otro fijo, sino calcular el nuevo valor a partir del anterior.

Imagina que vendemos tres unidades de un producto:

JavaScript 
const producto = {
  nombre: "Auriculares",
  precio: 50,
  stock: 12
};

producto.stock = producto.stock - 3;

console.log(producto.stock); // 9

Primero se consulta el valor actual de producto.stock, que es 12. Después se le resta 3 y el resultado se almacena nuevamente en la misma propiedad.

Como ya conocemos los operadores de asignación compuesta, también podemos escribir:

JavaScript 
producto.stock -= 3;

Esta instrucción equivale a:

JavaScript 
producto.stock = producto.stock - 3;

También podemos incrementar una propiedad:

JavaScript 
const producto = {
  nombre: "Auriculares",
  stock: 12
};

producto.stock++;

console.log(producto.stock); // 13
⚠️ Atención

Aunque un objeto esté declarado mediante const, sus propiedades pueden modificarse.

const impide reasignar la variable a otro objeto, pero no impide modificar el contenido del objeto al que hace referencia.

Esta diferencia ya se introdujo en el apartado 6.1 y es importante recordarla al actualizar propiedades.

Modificar propiedades de objetos anidados

Si una propiedad contiene otro objeto, también podemos modificar los datos de ese objeto anidado.

JavaScript 
const alumno = {
  nombre: "Laura",
  contacto: {
    email: "laura@ejemplo.com",
    telefono: "600123456"
  }
};

alumno.contacto.email = "laura.nuevo@ejemplo.com";

console.log(alumno.contacto.email);

En este ejemplo modificamos la propiedad email del objeto contacto, que se encuentra dentro del objeto alumno.

¿Qué ocurre si consultamos una propiedad inexistente?

Cuando intentamos consultar una propiedad que no existe en un objeto, JavaScript normalmente devuelve el valor undefined.

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 180
};

console.log(producto.stock); // undefined

En este caso, el objeto no tiene una propiedad llamada stock.

Por eso, la consulta devuelve undefined.

⚠️ Atención

Que una consulta devuelva undefined no demuestra por sí solo que la propiedad no exista.

Una propiedad también puede existir y tener asignado explícitamente ese valor.

En el apartado 6.3 aprenderemos a comprobar la existencia de propiedades de manera adecuada.

Qué son los métodos

Hasta ahora hemos trabajado principalmente con propiedades que almacenan datos, como nombres, precios, edades o cantidades disponibles.

Sin embargo, un objeto también puede incorporar operaciones relacionadas con esos datos.

Estas operaciones se realizan mediante métodos.

Un método es una función asociada a un objeto, que normalmente utilizamos para consultar información, realizar cálculos o modificar su estado.

📌 Importante

En JavaScript, un método es una función que se utiliza como operación de un objeto.

Las propiedades permiten representar información y los métodos permiten definir operaciones relacionadas con ella.

Propiedades y métodos de un mismo objeto

Imagina una aplicación que gestiona cuentas bancarias.

Cada cuenta necesita almacenar información, como el titular y el saldo, pero también puede realizar operaciones como consultar el saldo o ingresar dinero.

Objeto: cuenta Representa una cuenta bancaria dentro del programa.
Propiedades titular saldo
Métodos consultarSaldo() ingresar()

Podemos representar esa idea mediante el siguiente objeto:

JavaScript 
const cuenta = {
  titular: "Ana",
  saldo: 1200,

  consultarSaldo: function () {
    return this.saldo;
  },

  ingresar: function (cantidad) {
    this.saldo += cantidad;
  }
};

En este ejemplo, titular y saldo son propiedades que almacenan información.

Por otra parte, consultarSaldo e ingresar son propiedades cuyos valores son funciones utilizadas como métodos.

Observa que en el interior de esos métodos aparece la palabra clave this. En estas llamadas permite acceder a las propiedades del objeto sobre el que se ejecuta el método.

Estudiaremos detalladamente cómo definir métodos propios y cómo funciona this en el apartado 6.5.

Diferencia entre consultar una propiedad y ejecutar un método

Cuando consultamos una propiedad que almacena un dato, normalmente obtenemos directamente su valor.

Cuando invocamos un método, ejecutamos las instrucciones de la función asociada.

Elemento Ejemplo Resultado
Propiedad cuenta.saldo Consulta el valor del saldo
Método cuenta.consultarSaldo() Ejecuta el método y devuelve el saldo
Método con argumento cuenta.ingresar(100) Ejecuta el ingreso de 100 €
💻 Ejemplo DAW

En una aplicación de gestión de pedidos, un objeto podría almacenar propiedades como numeroPedido, cliente y total.

Además, podría incorporar métodos como calcularTotal() o mostrarResumen().

Así, el objeto reuniría la información del pedido y las operaciones relacionadas con ella.

Invocación de métodos

Para ejecutar un método, escribimos el nombre del objeto, seguido de un punto, el nombre del método y unos paréntesis.

Sintaxis 
objeto.metodo();

Si el método necesita recibir información, podemos pasarle argumentos dentro de los paréntesis:

Sintaxis 
objeto.metodo(argumento1, argumento2);

Este funcionamiento es semejante al de las funciones estudiadas en la UT5, con la diferencia de que ahora la operación está asociada a un objeto.

Invocar un método sin argumentos

Vamos a utilizar el objeto cuenta del ejemplo anterior:

JavaScript 
const cuenta = {
  titular: "Ana",
  saldo: 1200,

  consultarSaldo: function () {
    return this.saldo;
  }
};

const saldoActual = cuenta.consultarSaldo();

console.log(saldoActual); // 1200

Al escribir cuenta.consultarSaldo(), JavaScript ejecuta la función asociada a ese método.

Como el método devuelve this.saldo, obtenemos el valor 1200.

Invocar un método con argumentos

Los métodos también pueden recibir argumentos, igual que las funciones.

Por ejemplo, podemos utilizar un método para ingresar una cantidad de dinero:

JavaScript 
const cuenta = {
  titular: "Ana",
  saldo: 1200,

  ingresar: function (cantidad) {
    this.saldo += cantidad;
  }
};

cuenta.ingresar(200);

console.log(cuenta.saldo); // 1400

En este caso, el método ingresar() recibe el argumento 200.

El método suma esa cantidad al saldo actual de la cuenta, que pasa de 1200 a 1400.

La importancia de los paréntesis

Es importante distinguir entre acceder a una función y ejecutarla.

Observa estas dos expresiones:

JavaScript 
cuenta.consultarSaldo

cuenta.consultarSaldo()

La primera expresión accede al valor de la propiedad consultarSaldo, que es una función.

La segunda expresión invoca esa función como método del objeto.

⚠️ Atención

No debemos olvidar los paréntesis cuando queremos ejecutar un método.

Escribir cuenta.consultarSaldo no ejecuta el método. Para invocarlo debemos escribir cuenta.consultarSaldo().

Métodos que devuelven valores y métodos que modifican datos

No todos los métodos tienen el mismo propósito.

Algunos realizan cálculos y devuelven un resultado. Otros modifican propiedades del objeto.

También es posible que un método realice ambas operaciones.

Tipo de operación Ejemplo Finalidad
Consultar consultarSaldo() Obtener información
Calcular calcularTotal() Devolver un resultado
Modificar ingresar(100) Cambiar el estado del objeto

Esta clasificación nos ayuda a comprender para qué sirven los métodos, aunque más adelante estudiaremos con mayor detalle cómo diseñarlos correctamente.

Ejemplos prácticos

Vamos a reunir los conceptos estudiados en diferentes ejemplos relacionados con situaciones habituales del desarrollo web.

Ejemplo 1. Consultar y modificar los datos de un alumno

Imagina una aplicación que permite gestionar los datos de los alumnos matriculados en un ciclo formativo.

Cada alumno tiene un nombre, una edad, un ciclo y un estado de matrícula.

JavaScript 
const alumno = {
  nombre: "Marcos",
  edad: 19,
  ciclo: "DAW",
  matriculado: true
};

// Consultar propiedades
console.log(alumno.nombre);
console.log(alumno.ciclo);

// Modificar una propiedad
alumno.edad = 20;

// Consultar el nuevo valor
console.log(alumno.edad);

// Comprobar el estado de matrícula
if (alumno.matriculado) {
  console.log("El alumno está matriculado");
} else {
  console.log("El alumno no está matriculado");
}

El resultado será:

Consola 
Marcos
DAW
20
El alumno está matriculado

Este ejemplo muestra cómo podemos consultar y modificar propiedades sin necesidad de crear variables independientes para cada dato.

Ejemplo 2. Actualizar el stock de una tienda online

Vamos a representar un producto que tiene un precio y una cantidad determinada de unidades disponibles.

El programa deberá comprobar si existe suficiente stock antes de realizar una venta.

JavaScript 
const producto = {
  nombre: "Disco SSD",
  precio: 75,
  stock: 8
};

const cantidadSolicitada = 3;

if (cantidadSolicitada > 0 &&
    producto.stock >= cantidadSolicitada) {

  const importe =
    producto.precio * cantidadSolicitada;

  producto.stock -= cantidadSolicitada;

  console.log("Venta realizada");
  console.log("Importe: " + importe + " €");
  console.log("Stock restante: " + producto.stock);

} else {

  console.log("No se puede realizar la venta");

}

El resultado será:

Consola 
Venta realizada
Importe: 225 €
Stock restante: 5

A diferencia de los ejemplos anteriores, aquí no modificamos directamente el stock sin realizar ninguna comprobación. Primero verificamos que la cantidad solicitada sea válida y que existan suficientes unidades disponibles.

Solo cuando se cumplen ambas condiciones, calculamos el importe de la venta y actualizamos la propiedad stock. De esta manera, combinamos el trabajo con objetos con las estructuras de control estudiadas en unidades anteriores.

💻 Ejemplo DAW

En una tienda online real, esta lógica podría utilizarse para comprobar la disponibilidad de un artículo antes de añadirlo a un pedido.

En una aplicación completa, la confirmación definitiva del stock y de la venta tendría que realizarse también en el servidor.

Ejemplo 3. Consultar propiedades mediante una variable

Imagina que una aplicación necesita consultar diferentes datos de un usuario.

El nombre de la propiedad que queremos mostrar puede cambiar durante la ejecución.

JavaScript 
const usuario = {
  nombre: "Elena",
  email: "elena@ejemplo.com",
  rol: "administrador"
};

let campo = "nombre";

console.log(usuario[campo]);

campo = "email";

console.log(usuario[campo]);

campo = "rol";

console.log(usuario[campo]);

El resultado será:

Consola 
Elena
elena@ejemplo.com
administrador

Este ejemplo muestra por qué la notación de corchetes es especialmente útil cuando no conocemos de antemano qué propiedad necesitaremos.

Ejemplo 4. Utilizar métodos para gestionar una reserva

Vamos a representar una habitación de hotel mediante un objeto que contiene propiedades y métodos.

El objeto tendrá información sobre el número de habitación, su precio por noche y su disponibilidad.

Además, incorporará un método para calcular el precio de una estancia y otro para realizar una reserva.

JavaScript 
const habitacion = {
  numero: 204,
  precioNoche: 85,
  disponible: true,

  calcularPrecio: function (noches) {
    return this.precioNoche * noches;
  },

  reservar: function () {
    if (this.disponible) {
      this.disponible = false;
      return true;
    }

    return false;
  }
};

const precio = habitacion.calcularPrecio(3);

console.log("Precio: " + precio + " €");

const reservaRealizada = habitacion.reservar();

console.log("Reserva realizada:", reservaRealizada);
console.log("Disponible:", habitacion.disponible);

El resultado será:

Consola 
Precio: 255 €
Reserva realizada: true
Disponible: false

En este ejemplo podemos distinguir claramente las propiedades y los métodos del objeto.

  • numero, precioNoche y disponible almacenan información.
  • calcularPrecio(3) calcula el precio correspondiente a tres noches y devuelve el resultado.
  • reservar() comprueba la disponibilidad y, si es posible, modifica el estado de la habitación.

No es necesario memorizar todavía todos los detalles de la definición de estos métodos.

Lo importante en este momento es comprender cómo se invocan, qué argumentos reciben y qué efectos producen.

En el apartado 6.5 aprenderemos a definir nuestros propios métodos y a utilizar correctamente la palabra clave this.

Qué debemos recordar

Después de estudiar las propiedades y los métodos de los objetos, debemos tener claras las siguientes ideas:

  • Las propiedades permiten almacenar información asociada a un objeto.
  • Podemos consultar propiedades utilizando la notación de punto: objeto.propiedad.
  • También podemos utilizar la notación de corchetes: objeto["propiedad"].
  • Los corchetes permiten utilizar variables para indicar dinámicamente el nombre de una propiedad.
  • Podemos modificar propiedades mediante asignaciones y operaciones.
  • Los métodos son funciones asociadas a objetos.
  • Para ejecutar un método utilizamos paréntesis: objeto.metodo().
  • Los métodos pueden recibir argumentos, devolver valores y modificar el estado de un objeto.
📌 Importante

Saber consultar y modificar propiedades, así como invocar métodos, es fundamental para trabajar con objetos en JavaScript.

Estos conocimientos serán la base de los siguientes apartados, en los que aprenderemos a crear, manipular y organizar objetos de forma más avanzada.

💭 Piensa

Imagina que estás desarrollando una aplicación web para gestionar los pedidos de una tienda online.

Cada pedido tiene un número, un cliente, un importe total y un estado que indica si está pendiente o enviado.

Responde a las siguientes preguntas:

  1. ¿Qué propiedades incluirías en un objeto que represente un pedido?
  2. ¿Cómo consultarías el nombre del cliente utilizando la notación de punto?
  3. ¿Cómo consultarías el importe total utilizando la notación de corchetes?
  4. ¿Qué instrucción utilizarías para cambiar el estado de un pedido de "pendiente" a "enviado"?
  5. ¿Qué métodos podría tener el objeto para facilitar la gestión de los pedidos?
  6. ¿Qué diferencia existiría entre escribir pedido.mostrarResumen y pedido.mostrarResumen()?
Ver una posible solución

Podemos representar cada pedido mediante un objeto que agrupe las propiedades numero, cliente, total y estado.

JavaScript 
const pedido = {
  numero: 105,
  cliente: "María",
  total: 249.99,
  estado: "pendiente",

  mostrarResumen: function () {
    return `Pedido ${this.numero}: ${this.total} €`;
  }
};

Para consultar el nombre del cliente mediante la notación de punto:

JavaScript 
console.log(pedido.cliente); // María

Para consultar el importe total mediante corchetes:

JavaScript 
console.log(pedido["total"]); // 249.99

Para cambiar el estado del pedido podemos modificar directamente su propiedad:

JavaScript 
pedido.estado = "enviado";

console.log(pedido.estado); // enviado

El objeto podría incorporar métodos como mostrarResumen(), marcarComoEnviado() o calcularDescuento().

Por último, escribir pedido.mostrarResumen permite acceder a la función almacenada en esa propiedad, pero no la ejecuta.

En cambio, pedido.mostrarResumen() invoca el método y devuelve el resumen del pedido.

JavaScript 
console.log(pedido.mostrarResumen());

// Pedido 105: 249.99 €
