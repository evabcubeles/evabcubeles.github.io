6.4 Recorrido de las propiedades de un objeto

En los apartados anteriores hemos aprendido a crear objetos en JavaScript, consultar sus propiedades, modificar sus valores y añadir o eliminar información.

Hasta ahora, para acceder a una propiedad, normalmente conocíamos su nombre. Por ejemplo, podíamos consultar producto.nombre o producto.precio.

Sin embargo, en una aplicación web no siempre conocemos de antemano todas las propiedades que contiene un objeto.

Imagina que recibimos información sobre un producto, un usuario o un pedido. Puede que algunos objetos tengan más propiedades que otros, o que necesitemos mostrar automáticamente todos sus datos.

Para resolver estas situaciones, JavaScript ofrece distintas formas de recorrer las propiedades de un objeto.

📌 Importante

Recorrer un objeto significa examinar sus propiedades de manera sucesiva, normalmente mediante un bucle o una operación que permite obtener sus nombres y valores.

Esta técnica resulta especialmente útil cuando queremos trabajar con información cuya estructura puede variar durante la ejecución de una aplicación.

Recorrer un objeto

Observa el siguiente objeto, que representa un producto de una tienda online:

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 189.99,
  stock: 12,
  disponible: true
};

console.log(producto.nombre);
console.log(producto.precio);
console.log(producto.stock);
console.log(producto.disponible);

// Monitor
// 189.99
// 12
// true

En este ejemplo accedemos individualmente a cada propiedad mediante la notación de punto.

Esta forma de trabajar es adecuada cuando conocemos las propiedades y solamente necesitamos consultar algunas de ellas.

Pero ¿qué sucedería si el objeto tuviera veinte propiedades? ¿Y si no supiéramos cuáles contiene?

Escribir una instrucción para cada propiedad resultaría poco práctico.

En estas situaciones necesitamos un mecanismo que permita recorrer automáticamente la información del objeto.

Qué podemos obtener al recorrer un objeto

Cuando recorremos las propiedades de un objeto, normalmente nos interesa conocer:

  • El nombre de cada propiedad: por ejemplo, nombre, precio o stock.
  • El valor de cada propiedad: por ejemplo, "Monitor", 189.99 o 12.
  • La relación entre ambos: qué valor corresponde a cada nombre de propiedad.
Propiedad Valor
nombre "Monitor"
precio 189.99
stock 12
disponible true
💻 Ejemplo DAW

En una aplicación de administración de usuarios podríamos necesitar mostrar los datos disponibles de cada perfil.

Un usuario podría tener nombre, correo electrónico y teléfono, mientras que otro podría incluir también ciudad y empresa.

Recorrer las propiedades permite procesar los campos disponibles sin escribir una instrucción diferente para cada posible dato.

El bucle for...in

JavaScript dispone de una estructura especialmente diseñada para recorrer los nombres de las propiedades enumerables de un objeto: for...in.

Su sintaxis básica es la siguiente:

JavaScript 
for (const propiedad in objeto) {
  // Instrucciones que se repiten
}

En cada iteración, la variable propiedad contiene el nombre de una propiedad que el bucle está recorriendo.

Vamos a verlo con un ejemplo.

Primer ejemplo con for...in

JavaScript 
const alumno = {
  nombre: "Lucía",
  edad: 20,
  curso: "2º DAW"
};

for (const propiedad in alumno) {
  console.log(propiedad);
}

// nombre
// edad
// curso

El bucle recorre los nombres de las propiedades enumerables del objeto.

En este caso, como hemos creado un objeto literal sencillo con tres propiedades propias, obtenemos: nombre, edad y curso.

Cómo funciona paso a paso

Analicemos la ejecución:

  1. JavaScript comienza el recorrido de las propiedades enumerables del objeto alumno.
  2. En la primera iteración, propiedad contiene el texto "nombre".
  3. Se ejecuta la instrucción console.log(propiedad).
  4. En las siguientes iteraciones, la variable toma los valores "edad" y "curso".
  5. Cuando termina el recorrido, el bucle finaliza.
📌 Importante

En un bucle for...in, la variable del bucle contiene el nombre de la propiedad, no su valor.

Por ejemplo, si la propiedad se llama nombre y contiene "Lucía", la variable del bucle tendrá el texto "nombre".

Para obtener "Lucía", necesitaremos acceder al valor mediante corchetes.

Recorrer un objeto que cambia

Una ventaja de for...in es que no necesitamos conocer previamente todas las propiedades del objeto.

JavaScript 
const usuario = {
  nombre: "Ana",
  email: "ana@ejemplo.com"
};

usuario.ciudad = "Teruel";

for (const propiedad in usuario) {
  console.log(propiedad);
}

// nombre
// email
// ciudad

Hemos añadido ciudad antes de ejecutar el bucle.

Como la nueva propiedad forma parte del objeto cuando comienza el recorrido, también aparece en el resultado.

⚠️ Atención

for...in está pensado para recorrer nombres de propiedades enumerables. No debe confundirse con for...of, que utilizamos para recorrer los valores de estructuras iterables, como los arrays.

Además, for...in puede incluir propiedades heredadas. Más adelante veremos cómo evitarlo cuando solamente queremos recorrer las propiedades propias.

Acceso dinámico a propiedades

En el apartado 6.2 aprendimos que JavaScript permite acceder a una propiedad utilizando la notación de punto o la notación de corchetes.

Esta diferencia es fundamental cuando trabajamos con for...in.

Obtener los valores durante el recorrido

Observa el siguiente ejemplo:

JavaScript 
const producto = {
  nombre: "Teclado",
  precio: 45,
  stock: 8
};

for (const propiedad in producto) {
  console.log(producto[propiedad]);
}

// Teclado
// 45
// 8

La expresión producto[propiedad] utiliza el contenido de la variable propiedad para consultar el valor correspondiente.

Durante el recorrido sucede lo siguiente:

Valor de propiedad Acceso realizado Resultado
"nombre" producto["nombre"] Teclado
"precio" producto["precio"] 45
"stock" producto["stock"] 8

Mostrar nombres y valores juntos

Habitualmente nos interesará mostrar tanto el nombre de cada propiedad como su valor.

JavaScript 
const producto = {
  nombre: "Ratón",
  precio: 19.99,
  stock: 15
};

for (const propiedad in producto) {
  console.log(
    propiedad + ": " + producto[propiedad]
  );
}

// nombre: Ratón
// precio: 19.99
// stock: 15

Ahora obtenemos una representación más completa de la información.

En cada iteración, JavaScript concatena el nombre de la propiedad, el texto ": " y su valor.

Utilizar plantillas literales

También podemos construir el mensaje utilizando plantillas literales, que ya conocemos de unidades anteriores.

JavaScript 
const alumno = {
  nombre: "Carlos",
  edad: 21,
  curso: "2º DAW"
};

for (const propiedad in alumno) {
  console.log(
    `${propiedad}: ${alumno[propiedad]}`
  );
}

// nombre: Carlos
// edad: 21
// curso: 2º DAW

Esta forma suele resultar más legible cuando necesitamos combinar texto y valores.

Por qué no debemos utilizar el punto

Un error frecuente consiste en escribir objeto.propiedad dentro del bucle.

JavaScript 
const alumno = {
  nombre: "Elena",
  edad: 19
};

for (const propiedad in alumno) {
  console.log(alumno.propiedad);
}

// undefined
// undefined

El problema es que alumno.propiedad busca literalmente una propiedad llamada propiedad.

Como nuestro objeto no tiene una propiedad con ese nombre, el resultado es undefined.

La solución consiste en utilizar corchetes:

JavaScript 
const alumno = {
  nombre: "Elena",
  edad: 19
};

for (const propiedad in alumno) {
  console.log(alumno[propiedad]);
}

// Elena
// 19
⚠️ Atención

No debemos confundir:

  • objeto.propiedad: busca una propiedad cuyo nombre es literalmente propiedad.
  • objeto[propiedad]: utiliza el valor almacenado en la variable propiedad.

Cuando recorremos objetos con for...in, normalmente utilizaremos la segunda forma.

Propiedades propias y heredadas

Hasta ahora hemos recorrido objetos literales sencillos y hemos obtenido exactamente las propiedades que habíamos definido.

Sin embargo, hay una característica importante de for...in que debemos conocer.

Este bucle puede recorrer propiedades enumerables propias y propiedades enumerables heredadas.

Las propiedades heredadas proceden de otros objetos relacionados mediante la cadena de prototipos de JavaScript. Estudiaremos la herencia con más profundidad en apartados posteriores.

Un ejemplo con propiedades heredadas

Observa este ejemplo:

JavaScript 
const datosGenerales = {
  centro: "IES Ejemplo"
};

const alumno = Object.create(datosGenerales);

alumno.nombre = "Lucía";
alumno.curso = "2º DAW";

for (const propiedad in alumno) {
  console.log(propiedad);
}

// nombre
// curso
// centro

En este ejemplo hemos utilizado Object.create() para crear un objeto relacionado con otro mediante su prototipo.

No es necesario dominar todavía esta operación. Lo importante es observar que el recorrido también incluye centro, aunque esa propiedad no se ha definido directamente en alumno.

Utilizar Object.hasOwn() durante el recorrido

En el apartado 6.3 aprendimos que Object.hasOwn() permite comprobar si una propiedad pertenece directamente a un objeto.

Podemos combinar esta operación con for...in para recorrer únicamente las propiedades propias enumerables.

JavaScript 
const datosGenerales = {
  centro: "IES Ejemplo"
};

const alumno = Object.create(datosGenerales);

alumno.nombre = "Lucía";
alumno.curso = "2º DAW";

for (const propiedad in alumno) {
  if (Object.hasOwn(alumno, propiedad)) {
    console.log(propiedad);
  }
}

// nombre
// curso

Ahora el programa comprueba cada propiedad antes de mostrarla.

Como centro es una propiedad heredada, Object.hasOwn() devuelve false y no se muestra.

📌 Importante

Si utilizamos for...in y solamente queremos trabajar con propiedades propias, podemos filtrarlas mediante:

Object.hasOwn(objeto, propiedad)

También podemos utilizar Object.keys() o Object.entries(), que veremos a continuación y que obtienen únicamente propiedades propias enumerables.

Object.keys()

JavaScript proporciona una forma muy cómoda de obtener los nombres de las propiedades propias enumerables de un objeto: Object.keys().

Esta operación devuelve un array que contiene los nombres de las propiedades.

Obtener los nombres de las propiedades

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 189.99,
  stock: 10
};

const propiedades = Object.keys(producto);

console.log(propiedades);

// ["nombre", "precio", "stock"]

El resultado es un array de cadenas de texto.

Cada elemento del array contiene el nombre de una propiedad propia enumerable del objeto.

Recorrer las propiedades obtenidas

Como Object.keys() devuelve un array, podemos recorrerlo con for...of.

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 189.99,
  stock: 10
};

for (const propiedad of Object.keys(producto)) {
  console.log(propiedad);
}

// nombre
// precio
// stock

En este caso, el bucle for...of recorre el array devuelto por Object.keys().

También podemos utilizar los nombres obtenidos para consultar los valores.

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 189.99,
  stock: 10
};

for (const propiedad of Object.keys(producto)) {
  console.log(
    `${propiedad}: ${producto[propiedad]}`
  );
}

// nombre: Monitor
// precio: 189.99
// stock: 10

Contar las propiedades de un objeto

Otra utilidad de Object.keys() es conocer cuántas propiedades propias enumerables tiene un objeto.

JavaScript 
const usuario = {
  nombre: "Marta",
  email: "marta@ejemplo.com",
  ciudad: "Zaragoza"
};

const cantidad = Object.keys(usuario).length;

console.log(cantidad);

// 3

Primero obtenemos un array con los nombres de las propiedades y después consultamos su length.

💻 Ejemplo DAW

En un formulario web podríamos guardar los campos completados por un usuario en un objeto.

Utilizando Object.keys(datosFormulario).length podríamos conocer cuántos campos propios enumerables contiene ese objeto.

Eso no significa necesariamente que todos los campos tengan valores válidos: para comprobarlo necesitaríamos realizar las validaciones correspondientes.

Object.values()

Si en lugar de obtener los nombres de las propiedades necesitamos sus valores, podemos utilizar Object.values().

Esta operación devuelve un array con los valores de las propiedades propias enumerables del objeto.

Obtener los valores

JavaScript 
const producto = {
  nombre: "Teclado",
  precio: 45,
  stock: 8
};

const valores = Object.values(producto);

console.log(valores);

// ["Teclado", 45, 8]

Observa que el array contiene los valores originales.

Por tanto, puede incluir cadenas de texto, números, valores booleanos u otros tipos de datos.

Recorrer los valores con for...of

JavaScript 
const alumno = {
  nombre: "Sara",
  edad: 20,
  matriculado: true
};

for (const valor of Object.values(alumno)) {
  console.log(valor);
}

// Sara
// 20
// true

En este caso, cada iteración nos proporciona directamente uno de los valores del objeto.

Ejemplo: sumar importes

Una aplicación puede almacenar diferentes importes en un objeto.

Si todos sus valores son numéricos, podemos recorrerlos para calcular una suma.

JavaScript 
const ventas = {
  lunes: 120,
  martes: 85,
  miercoles: 150,
  jueves: 95
};

let total = 0;

for (const importe of Object.values(ventas)) {
  total += importe;
}

console.log(`Ventas totales: ${total} €`);

// Ventas totales: 450 €

El programa obtiene los importes, los recorre y acumula cada valor en la variable total.

⚠️ Atención

Object.values() no garantiza que todos los valores obtenidos sean números.

Antes de realizar operaciones matemáticas debemos asegurarnos de que los datos tienen el tipo adecuado.

En el ejemplo anterior sabemos que todas las propiedades representan importes numéricos.

Object.entries()

En muchas situaciones necesitamos conocer simultáneamente el nombre de una propiedad y su valor.

Para ello, JavaScript dispone de Object.entries().

Esta operación devuelve un array de parejas, donde cada pareja contiene dos elementos:

  1. El nombre de la propiedad.
  2. El valor correspondiente.

Obtener las parejas propiedad-valor

JavaScript 
const producto = {
  nombre: "Ratón",
  precio: 19.99,
  stock: 15
};

const entradas = Object.entries(producto);

console.log(entradas);

// [
//   ["nombre", "Ratón"],
//   ["precio", 19.99],
//   ["stock", 15]
// ]

El resultado es un array cuyos elementos son, a su vez, arrays de dos posiciones.

La primera posición contiene el nombre de la propiedad y la segunda contiene su valor.

Recorrer las parejas

Podemos recorrer el resultado utilizando for...of.

JavaScript 
const producto = {
  nombre: "Ratón",
  precio: 19.99,
  stock: 15
};

for (const entrada of Object.entries(producto)) {
  console.log(entrada[0], entrada[1]);
}

// nombre Ratón
// precio 19.99
// stock 15

Cada elemento de Object.entries(producto) es un array con dos valores.

Por eso podemos acceder a entrada[0] y entrada[1].

Utilizar desestructuración

JavaScript también permite extraer directamente los elementos de cada pareja mediante desestructuración de arrays.

JavaScript 
const producto = {
  nombre: "Ratón",
  precio: 19.99,
  stock: 15
};

for (const [propiedad, valor] of Object.entries(producto)) {
  console.log(`${propiedad}: ${valor}`);
}

// nombre: Ratón
// precio: 19.99
// stock: 15

En cada iteración:

  • propiedad recibe el primer elemento de la pareja.
  • valor recibe el segundo elemento.

De esta manera podemos trabajar directamente con ambos datos sin acceder a las posiciones 0 y 1.

📌 Importante

La expresión Object.entries(objeto) resulta especialmente útil cuando necesitamos recorrer nombres y valores al mismo tiempo.

Combinada con for...of y la desestructuración, permite escribir recorridos claros y fáciles de mantener.

Comparación de las distintas operaciones

Vamos a resumir las diferencias entre las herramientas que hemos estudiado.

Operación Qué obtiene Resultado
for...in Nombres de propiedades enumerables propias y heredadas. Los recorre directamente.
Object.keys() Nombres de propiedades propias enumerables. Array de nombres.
Object.values() Valores de propiedades propias enumerables. Array de valores.
Object.entries() Nombres y valores de propiedades propias enumerables. Array de parejas.

Las tres operaciones Object.keys(), Object.values() y Object.entries() trabajan con propiedades propias enumerables cuyos nombres son cadenas de texto.

Existen propiedades no enumerables y propiedades identificadas mediante símbolos que no aparecen en estos recorridos habituales. Por ahora trabajaremos con objetos literales sencillos y propiedades ordinarias.

Ejemplos prácticos

Vamos a aplicar las técnicas estudiadas a situaciones relacionadas con el desarrollo de aplicaciones web.

⚠️ Atención

Los ejemplos siguientes son independientes. Puedes ejecutarlos por separado en la consola del navegador o en archivos JavaScript diferentes.

Si ejecutas varios ejemplos en el mismo ámbito, recuerda que no puedes volver a declarar una variable const con el mismo nombre.

Ejemplo 1. Mostrar los datos de un usuario

Imagina que una aplicación necesita mostrar los datos de un usuario en un panel de administración.

Podemos recorrer las propiedades del objeto y construir un mensaje para cada campo.

JavaScript 
const usuario = {
  nombre: "Ana",
  email: "ana@ejemplo.com",
  ciudad: "Alcañiz",
  activo: true
};

for (const [campo, valor] of Object.entries(usuario)) {
  console.log(`${campo}: ${valor}`);
}

// nombre: Ana
// email: ana@ejemplo.com
// ciudad: Alcañiz
// activo: true

El programa no necesita consultar individualmente nombre, email, ciudad y activo.

Obtiene automáticamente las parejas de propiedades y valores.

Ejemplo 2. Calcular el total de ventas

Una tienda online almacena las ventas de varios días en un objeto.

Queremos calcular el importe total y mostrar el resultado.

JavaScript 
const ventas = {
  lunes: 120,
  martes: 85,
  miercoles: 150,
  jueves: 95,
  viernes: 200
};

let total = 0;

for (const importe of Object.values(ventas)) {
  total += importe;
}

console.log(`Total semanal: ${total} €`);

// Total semanal: 650 €

Como solamente necesitamos los importes, utilizamos Object.values().

No es necesario consultar los nombres de los días para realizar el cálculo.

Ejemplo 3. Buscar una propiedad con un valor determinado

Supongamos que un objeto contiene las calificaciones de un alumno.

Queremos identificar las asignaturas cuya nota es inferior a 5.

JavaScript 
const notas = {
  DWEC: 8,
  DIW: 7,
  DWES: 4,
  DAW: 6
};

for (const [modulo, nota] of Object.entries(notas)) {
  if (nota < 5) {
    console.log(`${modulo}: suspenso (${nota})`);
  }
}

// DWES: suspenso (4)

En cada iteración obtenemos el nombre del módulo y su calificación.

La condición comprueba si la nota es inferior a 5.

Cuando se cumple, mostramos el módulo correspondiente.

Ejemplo 4. Contar propiedades con información

En un formulario, algunos campos pueden estar vacíos.

Vamos a contar cuántas propiedades contienen cadenas de texto no vacías.

JavaScript 
const formulario = {
  nombre: "Laura",
  email: "laura@ejemplo.com",
  telefono: "",
  ciudad: "Teruel"
};

let camposCompletados = 0;

for (const valor of Object.values(formulario)) {
  if (typeof valor === "string" && valor.trim() !== "") {
    camposCompletados++;
  }
}

console.log(`Campos completados: ${camposCompletados}`);

// Campos completados: 3

El programa recorre los valores del formulario y comprueba dos condiciones:

  1. Que el valor sea una cadena de texto.
  2. Que, después de eliminar los espacios de los extremos, la cadena no esté vacía.

En este ejemplo, telefono no se considera completado.

💻 Ejemplo DAW

En una aplicación web, este tipo de recorrido puede servir para comprobar qué campos de texto ha rellenado un usuario antes de enviar los datos al servidor.

No sustituye a una validación completa, pero permite realizar comprobaciones generales sobre los valores almacenados en un objeto.

Ejemplo 5. Recorrer un objeto con información de un pedido

Vamos a desarrollar un ejemplo algo más completo que combine varias de las operaciones estudiadas.

Imagina que una aplicación gestiona pedidos de una tienda online.

Cada pedido contiene un identificador, un cliente, un importe, un estado y una dirección de envío.

JavaScript 
const pedido = {
  id: 105,
  cliente: "María",
  importe: 249.99,
  estado: "Pendiente",
  direccion: {
    ciudad: "Zaragoza",
    codigoPostal: "50001"
  }
};

console.log("Datos del pedido:");

for (const [propiedad, valor] of Object.entries(pedido)) {
  if (propiedad === "direccion") {
    console.log(`Ciudad: ${valor.ciudad}`);
    console.log(`Código postal: ${valor.codigoPostal}`);
  } else {
    console.log(`${propiedad}: ${valor}`);
  }
}

// Datos del pedido:
// id: 105
// cliente: María
// importe: 249.99
// estado: Pendiente
// Ciudad: Zaragoza
// Código postal: 50001

Analicemos el funcionamiento:

  1. Creamos un objeto pedido con distintas propiedades.
  2. La propiedad direccion contiene otro objeto.
  3. Utilizamos Object.entries() para obtener las propiedades propias enumerables y sus valores.
  4. Si la propiedad es direccion, consultamos por separado ciudad y codigoPostal.
  5. En los demás casos, mostramos directamente el nombre de la propiedad y su valor.

Este ejemplo introduce una idea importante: recorrer las propiedades de un objeto no significa recorrer automáticamente todos los niveles de objetos anidados.

Si una propiedad contiene otro objeto, debemos decidir cómo queremos procesar esa información.

⚠️ Atención

Object.values() y Object.entries() no recorren automáticamente el interior de los objetos anidados.

Si una propiedad contiene otro objeto, obtenemos ese objeto como valor. Para acceder a sus propiedades internas necesitamos realizar un acceso adicional o un nuevo recorrido.

Qué debemos recordar

Antes de continuar con el siguiente apartado, conviene tener claras las ideas fundamentales.

  • Recorrer un objeto permite examinar sus propiedades sin conocer necesariamente todos sus nombres.
  • for...in recorre nombres de propiedades enumerables, incluidas las heredadas.
  • Para acceder dinámicamente a un valor utilizamos objeto[propiedad].
  • Object.hasOwn() permite distinguir las propiedades propias de las heredadas.
  • Object.keys() devuelve los nombres de las propiedades propias enumerables.
  • Object.values() devuelve sus valores.
  • Object.entries() devuelve parejas formadas por el nombre y el valor.
  • Los objetos anidados requieren un tratamiento adicional si queremos recorrer su contenido.
📌 Importante

Cuando necesitamos recorrer las propiedades de un objeto ordinario, es importante elegir la operación más adecuada.

Si necesitamos solamente los nombres, podemos utilizar Object.keys(). Si necesitamos los valores, Object.values(). Y si necesitamos ambos, Object.entries() suele ofrecer una solución especialmente clara.

Estas técnicas serán útiles cuando trabajemos con objetos más complejos y organicemos aplicaciones mediante clases.

💭 Piensa

Imagina que estás desarrollando una aplicación web para gestionar los productos de una tienda de informática.

La aplicación recibe un objeto llamado producto con la siguiente información:

JavaScript 
const producto = {
  nombre: "Portátil",
  precio: 899,
  stock: 6,
  marca: "Lenovo",
  disponible: true
};

Responde a las siguientes preguntas antes de consultar la solución:

  1. ¿Cómo recorrerías los nombres de las propiedades del objeto utilizando for...in?
  2. ¿Cómo mostrarías el nombre y el valor de cada propiedad mediante el mismo bucle?
  3. ¿Qué diferencia existe entre producto.propiedad y producto[propiedad] dentro del recorrido?
  4. ¿Qué instrucción utilizarías para obtener un array con los nombres de las propiedades propias enumerables?
  5. ¿Cómo obtendrías un array con los valores del objeto?
  6. ¿Cómo recorrerías las parejas propiedad-valor utilizando Object.entries() y for...of?
  7. ¿Qué diferencia habría entre utilizar for...in y Object.keys() si el objeto tuviera propiedades heredadas enumerables?
Ver una posible solución

Una posible solución sería la siguiente:

JavaScript 
const producto = {
  nombre: "Portátil",
  precio: 899,
  stock: 6,
  marca: "Lenovo",
  disponible: true
};

// 1. Recorrer nombres con for...in
for (const propiedad in producto) {
  console.log(propiedad);
}

// 2. Mostrar nombres y valores
for (const propiedad in producto) {
  console.log(
    `${propiedad}: ${producto[propiedad]}`
  );
}

// 3. Acceso dinámico
// producto.propiedad busca literalmente
// una propiedad llamada "propiedad".
// producto[propiedad] utiliza el valor
// de la variable propiedad.

// 4. Obtener nombres de propiedades
const nombres = Object.keys(producto);

console.log(nombres);

// 5. Obtener valores
const valores = Object.values(producto);

console.log(valores);

// 6. Recorrer parejas propiedad-valor
for (const [nombre, valor] of Object.entries(producto)) {
  console.log(`${nombre}: ${valor}`);
}

// 7. Diferencia entre recorridos
// for...in puede incluir propiedades
// heredadas enumerables.
// Object.keys() devuelve solamente
// propiedades propias enumerables.

En la segunda operación utilizamos corchetes porque el nombre de la propiedad se obtiene dinámicamente durante el recorrido.

En las operaciones cuarta y quinta utilizamos Object.keys() y Object.values() para obtener dos arrays diferentes: uno de nombres y otro de valores.

En la sexta operación, Object.entries() proporciona las parejas de propiedades y valores. La desestructuración permite acceder directamente a ambos elementos.

Por último, debemos recordar que for...in puede incluir propiedades heredadas enumerables. En cambio, Object.keys() solamente obtiene las propiedades propias enumerables.
