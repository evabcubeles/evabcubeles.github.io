6.5 Definición de métodos y palabra clave this

En los apartados anteriores hemos aprendido a crear objetos en JavaScript, trabajar con sus propiedades y recorrer la información que contienen.

Hasta ahora hemos utilizado los objetos principalmente para almacenar y organizar datos. Sin embargo, en una aplicación web los objetos también pueden realizar acciones relacionadas con esos datos.

Imagina que estamos desarrollando una tienda online. Un producto puede tener un nombre, un precio y un stock, pero también puede necesitar calcular su precio con descuento o comprobar si hay unidades disponibles.

Para representar este comportamiento utilizamos métodos, que son funciones asociadas a los objetos.

Además, JavaScript dispone de una palabra clave especialmente importante cuando trabajamos con métodos: this. Gracias a ella, un método puede acceder a los datos del objeto sobre el que se está ejecutando.

📌 Importante

Un objeto puede reunir estado y comportamiento:

  • Estado: los datos almacenados en sus propiedades.
  • Comportamiento: las acciones definidas mediante sus métodos.

Esta combinación es una de las ideas fundamentales de la Programación Orientada a Objetos.

Métodos de los objetos

En JavaScript, un método es una función que se utiliza como propiedad de un objeto.

Mientras que una propiedad ordinaria suele almacenar un dato, un método contiene una función que podemos ejecutar para realizar una determinada operación.

Un objeto que solamente contiene datos

Observa el siguiente objeto:

JavaScript 
const producto = {
  nombre: "Portátil",
  precio: 850,
  stock: 5
};

console.log(producto.nombre);
console.log(producto.precio);

// Portátil
// 850

Este objeto contiene tres propiedades: nombre, precio y stock.

Podemos consultar sus valores, pero todavía no hemos definido ninguna acción que el propio objeto pueda realizar.

Un objeto que también tiene comportamiento

Vamos a añadir un método que muestre la información del producto.

JavaScript 
const producto = {
  nombre: "Portátil",
  precio: 850,
  stock: 5,

  mostrarInformacion: function() {
    console.log("Producto disponible");
  }
};

producto.mostrarInformacion();

// Producto disponible

Ahora el objeto contiene tanto datos como una función asociada a él.

La propiedad mostrarInformacion almacena una función. Cuando la invocamos mediante producto.mostrarInformacion(), JavaScript ejecuta las instrucciones que contiene.

Propiedades nombre, precio, stock Describen el estado del producto.
Métodos mostrarInformacion() Definen acciones del producto.
💻 Ejemplo DAW

En una aplicación de gestión de pedidos, un objeto puede almacenar el identificador, el cliente y el estado de un pedido.

También puede incluir métodos para calcular el importe, cambiar el estado o mostrar un resumen.

De esta forma, la información y las operaciones relacionadas quedan agrupadas en un mismo objeto.

Definición de métodos

JavaScript permite definir métodos de diferentes formas. Vamos a estudiar las más habituales.

Definir un método mediante function

La primera forma consiste en asignar una función a una propiedad del objeto.

JavaScript 
const usuario = {
  nombre: "Lucía",

  saludar: function() {
    console.log("Hola, bienvenido");
  }
};

usuario.saludar();

// Hola, bienvenido

La propiedad saludar contiene una función anónima, es decir, una función que no necesita un nombre propio porque ya está asociada a la propiedad del objeto.

Sintaxis abreviada de métodos

En los objetos literales modernos podemos utilizar una sintaxis más breve.

JavaScript 
const usuario = {
  nombre: "Lucía",

  saludar() {
    console.log("Hola, bienvenido");
  }
};

usuario.saludar();

// Hola, bienvenido

Observa que ya no necesitamos escribir : function.

Indicamos directamente el nombre del método, los paréntesis y el bloque de instrucciones.

Forma tradicional Forma abreviada
saludar: function() { ... } saludar() { ... }
Asigna una función a una propiedad. Define el método mediante sintaxis abreviada.

Ambas formas permiten definir métodos ordinarios y utilizar this cuando se invocan sobre un objeto.

📌 Importante

Para los ejemplos de esta unidad utilizaremos preferentemente la sintaxis abreviada:

nombreMetodo() { ... }

Es clara, evita escribir código innecesario y resulta habitual en JavaScript moderno.

Añadir un método después de crear el objeto

Igual que podemos añadir propiedades a un objeto existente, también podemos añadir métodos.

JavaScript 
const usuario = {
  nombre: "Carlos"
};

usuario.saludar = function() {
  console.log("Hola desde el método");
};

usuario.saludar();

// Hola desde el método

En este caso, el método se añade mediante una asignación después de crear el objeto.

Invocación de métodos

Definir un método no significa ejecutarlo. Para ejecutar sus instrucciones debemos invocarlo.

Normalmente utilizamos el nombre del objeto, un punto, el nombre del método y los paréntesis.

JavaScript 
objeto.nombreMetodo();

Diferencia entre consultar e invocar

Observa el siguiente ejemplo:

JavaScript 
const calculadora = {
  sumar() {
    return 4 + 6;
  }
};

console.log(typeof calculadora.sumar);
console.log(calculadora.sumar());

// function
// 10

En la primera instrucción, calculadora.sumar hace referencia a la función, pero no la ejecuta.

En la segunda, calculadora.sumar() invoca el método y obtiene el resultado.

⚠️ Atención

No debemos confundir:

  • objeto.metodo: accede a la función almacenada en la propiedad.
  • objeto.metodo(): ejecuta esa función.

Los paréntesis son fundamentales cuando queremos realizar la llamada.

Invocación mediante corchetes

Los métodos también son propiedades. Por tanto, podemos acceder a ellos mediante corchetes cuando conocemos su nombre dinámicamente.

JavaScript 
const sistema = {
  iniciar() {
    console.log("Sistema iniciado");
  }
};

const accion = "iniciar";

sistema[accion]();

// Sistema iniciado

JavaScript consulta la propiedad cuyo nombre contiene la variable accion y ejecuta la función correspondiente.

Parámetros y valores de retorno

Como los métodos son funciones, pueden recibir parámetros y devolver resultados mediante return.

Métodos que reciben parámetros

Vamos a crear un objeto que permita calcular el precio de un producto con diferentes descuentos.

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 200,

  calcularDescuento(porcentaje) {
    const descuento = 200 * porcentaje / 100;
    return 200 - descuento;
  }
};

console.log(producto.calcularDescuento(10));
console.log(producto.calcularDescuento(25));

// 180
// 150

El parámetro porcentaje permite indicar un descuento diferente en cada llamada.

El método realiza un cálculo y devuelve el precio resultante mediante return.

Por ahora hemos utilizado directamente el valor 200. En el siguiente apartado aprenderemos a consultar la propiedad precio del propio objeto mediante this.

Diferencia entre console.log() y return

Es importante recordar una diferencia que ya estudiamos en la unidad dedicada a las funciones.

JavaScript 
const operaciones = {
  mostrarSuma(a, b) {
    console.log(a + b);
  },

  devolverSuma(a, b) {
    return a + b;
  }
};

operaciones.mostrarSuma(3, 4);

const resultado = operaciones.devolverSuma(3, 4);

console.log(resultado);

// 7
// 7

El primer método muestra el resultado en la consola, pero no devuelve explícitamente ningún valor.

El segundo utiliza return, por lo que podemos guardar su resultado en una variable y utilizarlo en otras operaciones.

📌 Importante

Un método puede:

  • Recibir cero o varios parámetros.
  • Realizar cálculos y modificar datos.
  • Mostrar información.
  • Devolver un valor mediante return.

Si no ejecuta ninguna instrucción return que devuelva un valor, el resultado de su invocación será undefined.

La palabra clave this

Hasta ahora hemos definido métodos que realizan operaciones, pero todavía no hemos aprovechado completamente la relación entre los métodos y las propiedades del objeto.

Supongamos que tenemos un objeto usuario y queremos que su método saludar() muestre el nombre almacenado en la propiedad nombre.

Acceder a las propiedades desde un método

Podemos hacerlo utilizando el nombre de la variable que contiene el objeto.

JavaScript 
const usuario = {
  nombre: "Ana",

  saludar() {
    console.log(`Hola, soy ${usuario.nombre}`);
  }
};

usuario.saludar();

// Hola, soy Ana

Este ejemplo funciona, pero tiene una limitación: el método depende directamente del nombre de la variable usuario.

Si queremos utilizar el mismo método con otro objeto, esa dependencia puede provocar problemas.

Utilizar this

Para evitar esa dependencia, podemos utilizar la palabra clave this.

JavaScript 
const usuario = {
  nombre: "Ana",

  saludar() {
    console.log(`Hola, soy ${this.nombre}`);
  }
};

usuario.saludar();

// Hola, soy Ana

Cuando invocamos el método mediante usuario.saludar(), el valor de this dentro de ese método es el objeto usuario.

Por tanto, la expresión this.nombre consulta su propiedad nombre.

usuario.saludar() Se invoca el método sobre el objeto usuario.
this Hace referencia a usuario durante esta llamada.
this.nombre Obtiene el valor "Ana".
📌 Importante

En una llamada ordinaria como objeto.metodo(), si el método se ha definido mediante una función normal, this hace referencia al objeto utilizado para invocarlo.

No significa que this siempre represente el objeto en el que se escribió originalmente la función. Su valor depende de cómo se realiza la llamada.

Utilizar this para realizar cálculos

Vamos a mejorar el ejemplo del producto con descuento.

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 200,

  calcularDescuento(porcentaje) {
    const descuento = this.precio * porcentaje / 100;
    return this.precio - descuento;
  }
};

console.log(producto.calcularDescuento(10));
console.log(producto.calcularDescuento(25));

// 180
// 150

Ahora el método utiliza this.precio en lugar de escribir directamente el número 200.

Si modificamos la propiedad precio, el método utilizará automáticamente el nuevo valor.

JavaScript 
const producto = {
  precio: 200,

  calcularDescuento(porcentaje) {
    return this.precio * (1 - porcentaje / 100);
  }
};

console.log(producto.calcularDescuento(10));

producto.precio = 300;

console.log(producto.calcularDescuento(10));

// 180
// 270

El método no necesita modificarse cuando cambia el precio, porque consulta la propiedad del objeto en el momento de ejecutarse.

Funcionamiento de this

Una de las características más importantes de this es que su valor depende del contexto de invocación.

Vamos a estudiar varios ejemplos para comprender cómo funciona.

El mismo método en diferentes objetos

Podemos utilizar una misma función como método de diferentes objetos.

JavaScript 
function mostrarNombre() {
  console.log(`Nombre: ${this.nombre}`);
}

const usuario1 = {
  nombre: "Ana",
  mostrarNombre
};

const usuario2 = {
  nombre: "Carlos",
  mostrarNombre
};

usuario1.mostrarNombre();
usuario2.mostrarNombre();

// Nombre: Ana
// Nombre: Carlos

Ambos objetos utilizan la misma función. Sin embargo, el resultado es diferente porque cada llamada establece un valor distinto para this.

  • En usuario1.mostrarNombre(), this hace referencia a usuario1.
  • En usuario2.mostrarNombre(), this hace referencia a usuario2.

El objeto utilizado en la llamada

Observa este segundo ejemplo:

JavaScript 
const usuario = {
  nombre: "Lucía",

  mostrarNombre() {
    console.log(this.nombre);
  }
};

const otroUsuario = {
  nombre: "Marta",
  mostrarNombre: usuario.mostrarNombre
};

usuario.mostrarNombre();
otroUsuario.mostrarNombre();

// Lucía
// Marta

Aunque la función se definió inicialmente en usuario, también podemos utilizarla como método de otroUsuario.

Cuando ejecutamos otroUsuario.mostrarNombre(), el valor de this es otroUsuario.

📌 Importante

En las funciones normales, el valor de this no queda fijado simplemente por el lugar donde se define la función.

En una invocación ordinaria mediante objeto.metodo(), importa especialmente el objeto utilizado para realizar la llamada.

Utilizar this para modificar propiedades

this no solamente permite consultar propiedades. También podemos modificar sus valores.

JavaScript 
const contador = {
  valor: 0,

  incrementar() {
    this.valor++;
  },

  mostrar() {
    console.log(this.valor);
  }
};

contador.incrementar();
contador.incrementar();
contador.mostrar();

// 2

Cada vez que ejecutamos contador.incrementar(), el método aumenta en una unidad la propiedad valor.

El método mostrar() consulta el valor actualizado.

Un método puede llamar a otro método

También podemos utilizar this para invocar otro método del mismo objeto.

JavaScript 
const producto = {
  nombre: "Teclado",
  precio: 50,

  calcularIVA() {
    return this.precio * 0.21;
  },

  calcularTotal() {
    return this.precio + this.calcularIVA();
  }
};

console.log(producto.calcularTotal());

// 60.5

El método calcularTotal() utiliza this.precio y también invoca this.calcularIVA().

De esta forma evitamos repetir el cálculo del IVA en varios métodos.

Errores habituales con this

La palabra clave this resulta muy útil, pero también puede provocar errores cuando no comprendemos cómo se determina su valor.

Error 1. Olvidar this al consultar una propiedad

Observa este código:

JavaScript 
const usuario = {
  nombre: "Ana",

  saludar() {
    console.log(nombre);
  }
};

usuario.saludar();

// ReferenceError si no existe una variable
// accesible llamada nombre.

La instrucción console.log(nombre) busca una variable llamada nombre. No consulta automáticamente la propiedad del objeto.

La forma correcta es:

JavaScript 
const usuario = {
  nombre: "Ana",

  saludar() {
    console.log(this.nombre);
  }
};

usuario.saludar();

// Ana

Error 2. Utilizar una función flecha como método con this

En la unidad dedicada a las funciones aprendimos a utilizar funciones flecha.

Sin embargo, existe una diferencia importante: las funciones flecha no tienen su propio this.

Por ello, no debemos utilizarlas como sustitución directa de un método normal cuando necesitamos acceder al objeto mediante this.

JavaScript 
const usuario = {
  nombre: "Ana",

  saludar: () => {
    console.log(this.nombre);
  }
};

usuario.saludar();

// No obtiene automáticamente "Ana".

En este caso, la función flecha toma this de su entorno exterior. No establece como this el objeto usuario por haber sido invocada como usuario.saludar().

La solución más sencilla es utilizar la sintaxis abreviada de métodos.

JavaScript 
const usuario = {
  nombre: "Ana",

  saludar() {
    console.log(this.nombre);
  }
};

usuario.saludar();

// Ana
⚠️ Atención

No debemos pensar que una función flecha es siempre equivalente a una función normal.

Cuando un método necesita acceder a las propiedades del objeto mediante this, normalmente utilizaremos:

nombreMetodo() { ... }

Las funciones flecha siguen siendo útiles en muchas situaciones, pero su comportamiento respecto a this es diferente.

Error 3. Separar el método del objeto

Otro error habitual aparece cuando guardamos un método en una variable y después lo ejecutamos como una función independiente.

JavaScript 
"use strict";

const usuario = {
  nombre: "Carlos",

  saludar() {
    console.log(this.nombre);
  }
};

const funcion = usuario.saludar;

funcion();

// TypeError: no se puede leer nombre
// de this, porque aquí es undefined.

Al ejecutar funcion() ya no estamos realizando la llamada mediante usuario.saludar().

En este ejemplo, como hemos activado el modo estricto, this es undefined dentro de esa llamada independiente.

Por eso intentar acceder a this.nombre provoca un error.

Una solución: utilizar bind()

JavaScript permite fijar el valor de this mediante bind().

JavaScript 
"use strict";

const usuario = {
  nombre: "Carlos",

  saludar() {
    console.log(this.nombre);
  }
};

const funcion = usuario.saludar.bind(usuario);

funcion();

// Carlos

bind(usuario) crea una nueva función cuyo this queda asociado al objeto usuario.

No es necesario dominar todavía todas las posibilidades de bind(). Lo importante es comprender por qué podemos perder el contexto al separar un método de su objeto.

📌 Importante

Recuerda estas tres ideas:

  • this no equivale automáticamente al nombre de una variable.
  • En un método normal, su valor depende de cómo se realiza la llamada.
  • Las funciones flecha no establecen su propio this.

Ejemplos prácticos

Vamos a aplicar los métodos y la palabra clave this a situaciones relacionadas con el desarrollo de aplicaciones web.

⚠️ Atención

Los ejemplos siguientes son independientes. Puedes ejecutarlos por separado en la consola del navegador o en archivos JavaScript diferentes.

Si ejecutas varios en el mismo ámbito, recuerda que no puedes volver a declarar una variable const con el mismo nombre.

Ejemplo 1. Perfil de un usuario

Imagina una aplicación que gestiona perfiles de usuarios. Cada usuario tiene un nombre, un correo electrónico y un estado.

Queremos definir métodos para mostrar sus datos y cambiar su estado.

JavaScript 
const usuario = {
  nombre: "Lucía",
  email: "lucia@ejemplo.com",
  activo: true,

  mostrarPerfil() {
    console.log(`Nombre: ${this.nombre}`);
    console.log(`Email: ${this.email}`);
    console.log(`Activo: ${this.activo}`);
  },

  desactivar() {
    this.activo = false;
  }
};

usuario.mostrarPerfil();

usuario.desactivar();

console.log(usuario.activo);

// Nombre: Lucía
// Email: lucia@ejemplo.com
// Activo: true
// false

El método mostrarPerfil() consulta las propiedades mediante this.

El método desactivar() modifica la propiedad activo del mismo objeto.

💻 Ejemplo DAW

En un panel de administración, podríamos utilizar métodos semejantes para consultar o actualizar el estado de un usuario.

En una aplicación real, las operaciones que deban mantenerse en el servidor necesitarían además comunicarse con él.

Ejemplo 2. Gestión del stock de un producto

Una tienda online necesita controlar las unidades disponibles de sus productos.

Vamos a definir métodos para consultar la disponibilidad y vender unidades.

JavaScript 
const producto = {
  nombre: "Ratón inalámbrico",
  stock: 8,

  estaDisponible() {
    return this.stock > 0;
  },

  vender(cantidad) {
    if (
      Number.isInteger(cantidad) &&
      cantidad > 0 &&
      cantidad <= this.stock
    ) {
      this.stock -= cantidad;
      return true;
    }

    return false;
  }
};

console.log(producto.estaDisponible());
console.log(producto.vender(3));
console.log(producto.stock);

// true
// true
// 5

El método estaDisponible() devuelve un valor booleano.

El método vender(cantidad) comprueba que la cantidad sea un entero positivo y que existan suficientes unidades.

Si se cumplen las condiciones, reduce el stock y devuelve true. En caso contrario, devuelve false.

Ejemplo 3. Calcular el total de un pedido

Vamos a crear un objeto que represente un pedido con un importe y unos gastos de envío.

Definiremos un método para calcular el total y otro para mostrar un resumen.

JavaScript 
const pedido = {
  id: 105,
  cliente: "María",
  importe: 120,
  gastosEnvio: 6,

  calcularTotal() {
    return this.importe + this.gastosEnvio;
  },

  mostrarResumen() {
    console.log(`Pedido: ${this.id}`);
    console.log(`Cliente: ${this.cliente}`);
    console.log(`Total: ${this.calcularTotal()} €`);
  }
};

pedido.mostrarResumen();

// Pedido: 105
// Cliente: María
// Total: 126 €

Observa que mostrarResumen() invoca otro método del mismo objeto mediante this.calcularTotal().

Esta organización permite separar el cálculo del total de la presentación de la información.

Ejemplo 4. Cuenta de puntos de un cliente

Algunas aplicaciones utilizan sistemas de puntos para recompensar a sus clientes.

Vamos a crear un objeto que permita añadir y canjear puntos.

JavaScript 
const cliente = {
  nombre: "Elena",
  puntos: 100,

  anadirPuntos(cantidad) {
    if (Number.isInteger(cantidad) && cantidad > 0) {
      this.puntos += cantidad;
    }
  },

  canjearPuntos(cantidad) {
    if (
      Number.isInteger(cantidad) &&
      cantidad > 0 &&
      cantidad <= this.puntos
    ) {
      this.puntos -= cantidad;
      return true;
    }

    return false;
  },

  consultarPuntos() {
    return this.puntos;
  }
};

cliente.anadirPuntos(50);

console.log(cliente.canjearPuntos(80));
console.log(cliente.consultarPuntos());

// true
// 70

Los métodos modifican o consultan la propiedad puntos.

Además, incluyen comprobaciones básicas para evitar añadir cantidades negativas o canjear más puntos de los disponibles.

Ejemplo 5. Gestión del estado de un pedido

Vamos a desarrollar un ejemplo más completo que combine propiedades, métodos, parámetros, condiciones y this.

Imagina una aplicación de gestión de pedidos que permite cambiar su estado y mostrar la información actualizada.

JavaScript 
const pedido = {
  id: 208,
  cliente: "Carlos",
  estado: "Pendiente",
  importe: 249.99,

  cambiarEstado(nuevoEstado) {
    const estadosValidos = [
      "Pendiente",
      "Preparando",
      "Enviado",
      "Entregado"
    ];

    if (estadosValidos.includes(nuevoEstado)) {
      this.estado = nuevoEstado;
      return true;
    }

    return false;
  },

  estaEntregado() {
    return this.estado === "Entregado";
  },

  mostrarInformacion() {
    console.log(`Pedido: ${this.id}`);
    console.log(`Cliente: ${this.cliente}`);
    console.log(`Estado: ${this.estado}`);
    console.log(`Importe: ${this.importe} €`);
  }
};

pedido.mostrarInformacion();

console.log(pedido.cambiarEstado("Enviado"));

pedido.mostrarInformacion();

console.log(pedido.estaEntregado());

// Primera información:
// Pedido: 208
// Cliente: Carlos
// Estado: Pendiente
// Importe: 249.99 €
//
// true
//
// Segunda información:
// Pedido: 208
// Cliente: Carlos
// Estado: Enviado
// Importe: 249.99 €
//
// false

Analicemos su funcionamiento:

  1. Creamos un objeto pedido con sus propiedades iniciales.
  2. El método cambiarEstado() recibe el nuevo estado como parámetro.
  3. Comprueba si el estado recibido pertenece a la lista de estados permitidos.
  4. Si es válido, actualiza this.estado.
  5. El método estaEntregado() devuelve un booleano.
  6. mostrarInformacion() consulta los valores actuales del objeto.

Este ejemplo muestra cómo podemos agrupar en un mismo objeto los datos de un pedido y las operaciones que necesitamos realizar sobre ellos.

💻 Ejemplo DAW

Este tipo de organización resulta útil en aplicaciones de comercio electrónico, sistemas de reservas y paneles de gestión.

En proyectos más grandes, los objetos pueden crearse a partir de funciones constructoras o clases, que estudiaremos en los siguientes apartados.

Qué debemos recordar

Antes de continuar con el siguiente apartado, conviene tener claras las ideas fundamentales.

  • Un método es una función utilizada como propiedad de un objeto.
  • Los métodos permiten representar el comportamiento de los objetos.
  • Podemos definir métodos mediante function o utilizando la sintaxis abreviada.
  • Para ejecutar un método utilizamos los paréntesis: objeto.metodo().
  • Los métodos pueden recibir parámetros y devolver valores mediante return.
  • La palabra clave this permite acceder a propiedades y métodos del objeto utilizado en una llamada ordinaria como objeto.metodo().
  • El valor de this depende de cómo se invoca una función normal.
  • Las funciones flecha no tienen su propio this.
  • Separar un método de su objeto puede modificar el contexto con el que se ejecuta.
📌 Importante

Los métodos permiten que un objeto no sea solamente un conjunto de datos, sino también una estructura capaz de realizar operaciones relacionadas con esos datos.

La palabra clave this facilita esa relación entre propiedades y comportamiento.

Estos conocimientos serán fundamentales para comprender las funciones constructoras, las instancias y las clases de JavaScript.

💭 Piensa

Imagina que estás desarrollando una aplicación web para gestionar reservas de habitaciones de un hotel.

Dispones del siguiente objeto:

JavaScript 
const habitacion = {
  numero: 204,
  precioNoche: 85,
  disponible: true
};

Responde a las siguientes preguntas antes de consultar la solución:

  1. ¿Cómo añadirías un método mostrarInformacion() que muestre el número y el precio de la habitación?
  2. ¿Cómo utilizarías this para acceder a las propiedades numero y precioNoche?
  3. ¿Cómo definirías un método calcularPrecio(noches) que devuelva el precio total de una estancia?
  4. ¿Cómo crearías un método reservar() que cambie disponible a false solamente cuando la habitación esté libre?
  5. ¿Qué diferencia existe entre habitacion.reservar y habitacion.reservar()?
  6. ¿Por qué no sería adecuado definir reservar como una función flecha si queremos utilizar this.disponible?
  7. ¿Qué ocurriría si intentáramos reservar dos veces seguidas la misma habitación?
Ver una posible solución

Una posible solución sería la siguiente:

JavaScript 
const habitacion = {
  numero: 204,
  precioNoche: 85,
  disponible: true,

  // 1 y 2. Mostrar información con this
  mostrarInformacion() {
    console.log(`Habitación: ${this.numero}`);
    console.log(`Precio por noche: ${this.precioNoche} €`);
  },

  // 3. Calcular el precio de la estancia
  calcularPrecio(noches) {
    if (!Number.isInteger(noches) || noches <= 0) {
      return null;
    }

    return this.precioNoche * noches;
  },

  // 4. Reservar si está disponible
  reservar() {
    if (this.disponible) {
      this.disponible = false;
      return true;
    }

    return false;
  }
};

// Mostrar los datos
habitacion.mostrarInformacion();

// Calcular tres noches
console.log(habitacion.calcularPrecio(3));

// Primera reserva
console.log(habitacion.reservar());

// Segunda reserva
console.log(habitacion.reservar());

// Consultar disponibilidad final
console.log(habitacion.disponible);

// Habitación: 204
// Precio por noche: 85 €
// 255
// true
// false
// false

Preguntas 1 y 2. El método mostrarInformacion() utiliza this.numero y this.precioNoche para consultar las propiedades de la habitación.

Pregunta 3. El método calcularPrecio(noches) multiplica el precio por noche por el número de noches. Además, comprueba que el número de noches sea un entero positivo.

Pregunta 4. El método reservar() comprueba this.disponible. Si la habitación está libre, modifica su estado y devuelve true.

Pregunta 5. habitacion.reservar accede a la función, mientras que habitacion.reservar() la ejecuta.

Pregunta 6. Una función flecha no tiene su propio this, por lo que no recibiría automáticamente el objeto habitacion como contexto de la llamada.

Pregunta 7. La primera reserva devuelve true y cambia disponible a false. La segunda devuelve false, porque la habitación ya no está disponible.
