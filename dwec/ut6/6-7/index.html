6.7 Clases en JavaScript: class y constructor

En el apartado anterior hemos aprendido a utilizar funciones constructoras para crear varios objetos con una misma estructura.

También hemos comprobado que cada objeto creado mediante new recibe el nombre de instancia y que podemos definir propiedades y métodos para representar su información y comportamiento.

JavaScript dispone de otra sintaxis para organizar estas definiciones de forma más clara: las clases.

Las clases permiten agrupar la inicialización de los objetos y sus métodos en una estructura fácil de leer y mantener.

📌 Importante

Una clase es una definición que permite crear objetos con una estructura y un comportamiento comunes.

Cada objeto creado a partir de una clase es una instancia de esa clase.

Qué es una clase en JavaScript

Imagina que estamos desarrollando una aplicación para gestionar los productos de una tienda online.

Todos los productos tienen información similar: nombre, precio y unidades disponibles. Además, pueden realizar operaciones comunes, como mostrar su información o calcular su precio con descuento.

Podemos definir una clase que reúna estas características:

JavaScript 
class Producto {
  constructor(nombre, precio, stock) {
    this.nombre = nombre;
    this.precio = precio;
    this.stock = stock;
  }

  mostrarInformacion() {
    return `${this.nombre}: ${this.precio} €`;
  }
}

En este ejemplo, Producto es el nombre de la clase. En su interior hemos definido:

  • Un constructor, que inicializa los datos de cada producto.
  • Tres propiedades de instancia: nombre, precio y stock.
  • Un método llamado mostrarInformacion().

Esta definición todavía no crea ningún producto concreto. Para ello necesitamos utilizar el operador new.

Sintaxis de class

Para declarar una clase utilizamos la palabra reservada class, seguida del nombre de la clase y un bloque delimitado por llaves.

JavaScript 
class NombreClase {
  constructor(parametro1, parametro2) {
    this.propiedad1 = parametro1;
    this.propiedad2 = parametro2;
  }

  nombreMetodo() {
    // Comportamiento de los objetos.
  }
}

Aunque la sintaxis recuerda a la de otros lenguajes orientados a objetos, debemos recordar que JavaScript utiliza un modelo de objetos basado en prototipos.

La sintaxis class facilita la escritura de código orientado a objetos, pero no sustituye el mecanismo de prototipos del lenguaje.

Convenciones de escritura

Por convenio, los nombres de las clases se escriben utilizando PascalCase, es decir, comenzando cada palabra con mayúscula.

JavaScript 
// Nombres habituales de clases:
class Producto {}
class Cliente {}
class CarritoCompra {}
class ReservaHotel {}

// Las variables que almacenan instancias
// suelen escribirse en camelCase.
const productoDestacado = new Producto();
const clientePrincipal = new Cliente();
⚠️ Atención

Los nombres en PascalCase son una convención, no una obligación del lenguaje.

También debes recordar que JavaScript distingue entre mayúsculas y minúsculas: Producto y producto son identificadores diferentes.

El método constructor

Dentro de una clase podemos declarar un método especial denominado constructor.

Este método se ejecuta automáticamente cuando creamos una instancia mediante new. Su función habitual es inicializar las propiedades del objeto.

JavaScript 
class Alumno {
  constructor(nombre, edad, ciclo) {
    this.nombre = nombre;
    this.edad = edad;
    this.ciclo = ciclo;
  }
}

const alumno1 = new Alumno(
  "Lucía",
  20,
  "DAW"
);

console.log(alumno1.nombre); // Lucía
console.log(alumno1.edad);   // 20
console.log(alumno1.ciclo);  // DAW

Cuando ejecutamos new Alumno("Lucía", 20, "DAW"), JavaScript crea una nueva instancia y ejecuta el constructor con los argumentos indicados.

La palabra clave this hace referencia a esa nueva instancia, por lo que las asignaciones guardan los datos dentro del objeto.

El constructor puede recibir valores por defecto

Podemos asignar valores predeterminados a los parámetros para facilitar la creación de instancias.

JavaScript 
class Usuario {
  constructor(nombre, activo = true) {
    this.nombre = nombre;
    this.activo = activo;
  }
}

const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Pablo", false);

console.log(usuario1.activo); // true
console.log(usuario2.activo); // false

¿Es obligatorio declarar un constructor?

No. Si una clase no incluye un constructor, JavaScript utiliza un constructor predeterminado que permite crear instancias.

JavaScript 
class Mensaje {
  mostrar() {
    return "Hola desde una clase";
  }
}

const mensaje = new Mensaje();

console.log(mensaje.mostrar());
// Hola desde una clase
📌 Importante

Una clase puede tener como máximo un método constructor.

Si necesitamos diferentes formas de inicializar los objetos, podemos utilizar parámetros opcionales, valores por defecto u otras estrategias que estudiaremos progresivamente.

Creación de instancias con new

Una vez declarada la clase, podemos crear tantos objetos como necesitemos utilizando el operador new.

JavaScript 
class Producto {
  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }
}

const producto1 = new Producto("Teclado", 45);
const producto2 = new Producto("Ratón", 25);
const producto3 = new Producto("Monitor", 180);

console.log(producto1.nombre); // Teclado
console.log(producto2.nombre); // Ratón
console.log(producto3.nombre); // Monitor

Los tres productos se han creado a partir de la misma clase, pero cada instancia es un objeto independiente.

JavaScript 
producto1.precio = 40;

console.log(producto1.precio); // 40
console.log(producto2.precio); // 25
console.log(producto3.precio); // 180

console.log(producto1 === producto2);
// false

Modificar el precio del primer producto no afecta a los demás porque cada instancia almacena sus propias propiedades.

Comprobar la clase de una instancia

Podemos utilizar el operador instanceof, que ya conocemos del apartado anterior.

JavaScript 
console.log(producto1 instanceof Producto);
// true

console.log(producto2 instanceof Producto);
// true

console.log(producto1 instanceof Array);
// false

console.log(typeof producto1);
// object
⚠️ Atención

Para crear instancias de una clase declarada con class, debemos utilizar new.

No podemos invocar una clase como si fuera una función ordinaria.

La palabra clave this en las clases

La palabra clave this sigue siendo fundamental al trabajar con clases.

Dentro del constructor, this identifica la instancia que se está creando. Dentro de un método ordinario llamado mediante una instancia, normalmente identifica el objeto que realiza la llamada.

JavaScript 
class Cuenta {
  constructor(titular, saldo) {
    this.titular = titular;
    this.saldo = saldo;
  }

  consultarSaldo() {
    return `${this.titular}: ${this.saldo} €`;
  }

  ingresar(cantidad) {
    this.saldo += cantidad;
  }
}

const cuentaAna = new Cuenta("Ana", 100);
const cuentaLuis = new Cuenta("Luis", 250);

cuentaAna.ingresar(50);

console.log(cuentaAna.consultarSaldo());
// Ana: 150 €

console.log(cuentaLuis.consultarSaldo());
// Luis: 250 €

Cuando llamamos a cuentaAna.ingresar(50), this se refiere a cuentaAna.

Por tanto, el ingreso modifica únicamente el saldo de esa cuenta.

El contexto de this puede perderse

Aunque un método esté definido dentro de una clase, el valor de this depende de cómo se invoque.

JavaScript 
class Persona {
  constructor(nombre) {
    this.nombre = nombre;
  }

  saludar() {
    return `Hola, soy ${this.nombre}`;
  }
}

const persona = new Persona("Elena");

console.log(persona.saludar());
// Hola, soy Elena

const funcionSaludo = persona.saludar;

// Esta llamada pierde el objeto receptor:
// funcionSaludo(); // TypeError

// Podemos fijar explícitamente el contexto:
const saludoVinculado =
  persona.saludar.bind(persona);

console.log(saludoVinculado());
// Hola, soy Elena
📌 Importante

Los métodos de las clases se ejecutan en modo estricto. Si extraemos un método y lo invocamos sin un objeto receptor, su this será undefined.

Definición de métodos en una clase

Una clase no solo sirve para inicializar propiedades. También permite definir las operaciones que podrán realizar sus instancias.

Los métodos se escriben directamente dentro del cuerpo de la clase, sin utilizar la palabra function.

JavaScript 
class Rectangulo {
  constructor(ancho, alto) {
    this.ancho = ancho;
    this.alto = alto;
  }

  calcularArea() {
    return this.ancho * this.alto;
  }

  calcularPerimetro() {
    return 2 * (this.ancho + this.alto);
  }

  esCuadrado() {
    return this.ancho === this.alto;
  }
}

const figura = new Rectangulo(8, 5);

console.log(figura.calcularArea());
// 40

console.log(figura.calcularPerimetro());
// 26

console.log(figura.esCuadrado());
// false

Cada método representa una operación relacionada con los datos de la instancia. Algunos devuelven números, otros valores booleanos o cadenas de texto.

Los métodos se comparten mediante el prototipo

Una diferencia importante respecto a declarar funciones directamente dentro del constructor es que los métodos definidos con esta sintaxis se almacenan normalmente en el prototipo de la clase.

JavaScript 
class Saludo {
  constructor(nombre) {
    this.nombre = nombre;
  }

  saludar() {
    return `Hola, ${this.nombre}`;
  }
}

const saludo1 = new Saludo("Ana");
const saludo2 = new Saludo("Luis");

console.log(saludo1.saludar());
// Hola, Ana

console.log(saludo2.saludar());
// Hola, Luis

console.log(saludo1.saludar === saludo2.saludar);
// true

Aunque cada instancia contiene su propio nombre, ambas utilizan la misma función saludar() compartida mediante el prototipo.

Este comportamiento evita crear una copia independiente del método para cada objeto.

💻 Ejemplo DAW

En una aplicación que gestiona cientos de alumnos, cada alumno necesita sus propios datos, pero todos pueden compartir métodos como mostrarFicha() o estaAprobado().

Clases y funciones constructoras

En el apartado 6.6 aprendimos a crear objetos utilizando funciones constructoras. Ahora podemos conseguir un resultado equivalente mediante clases.

Con una función constructora

JavaScript 
function Libro(nombre, precio) {
  this.nombre = nombre;
  this.precio = precio;
}

Libro.prototype.mostrar = function () {
  return `${this.nombre}: ${this.precio} €`;
};

const libro1 = new Libro("JavaScript", 30);

console.log(libro1.mostrar());
// JavaScript: 30 €

Con una clase

JavaScript 
class Libro {
  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }

  mostrar() {
    return `${this.nombre}: ${this.precio} €`;
  }
}

const libro1 = new Libro("JavaScript", 30);

console.log(libro1.mostrar());
// JavaScript: 30 €

Los dos ejemplos son alternativas independientes y producen el mismo resultado visible.

Aspecto Función constructora Clase
Declaración function class
Inicialización Cuerpo de la función Método constructor
Creación de instancias new new
Métodos compartidos Mediante prototype Dentro de la clase
Modelo de objetos Basado en prototipos Basado en prototipos
Lectura del código Definición más dispersa Definición agrupada

La sintaxis de clases resulta especialmente útil cuando queremos reunir en un mismo lugar las propiedades iniciales y los comportamientos de un tipo de objeto.

⚠️ Atención

Aunque las clases facilitan el trabajo con objetos, no son simplemente idénticas a las funciones constructoras.

Por ejemplo, las clases no pueden invocarse sin new y presentan reglas específicas de inicialización y acceso.

Errores habituales al trabajar con clases

1. Olvidar el operador new

Una clase no puede utilizarse como una función ordinaria.

JavaScript 
class Cliente {
  constructor(nombre) {
    this.nombre = nombre;
  }
}

// Incorrecto:
// const cliente = Cliente("Ana");

// Correcto:
const cliente = new Cliente("Ana");

console.log(cliente.nombre); // Ana

2. Escribir function delante de un método

Dentro de una clase, los métodos se declaran directamente con su nombre.

JavaScript 
class Calculadora {

  // Incorrecto:
  // function sumar(a, b) { return a + b; }

  // Correcto:
  sumar(a, b) {
    return a + b;
  }
}

const calculadora = new Calculadora();

console.log(calculadora.sumar(4, 6)); // 10

3. Olvidar this al acceder a una propiedad

Los parámetros y las propiedades de instancia no son lo mismo. Para acceder a una propiedad del objeto utilizamos this.

JavaScript 
class Curso {
  constructor(titulo) {
    this.titulo = titulo;
  }

  mostrarTitulo() {
    // Incorrecto:
    // return titulo;

    // Correcto:
    return this.titulo;
  }
}

const curso = new Curso("DWEC");

console.log(curso.mostrarTitulo()); // DWEC

4. Confundir la clase con una instancia

La clase define cómo serán los objetos. La instancia es el objeto concreto.

JavaScript 
class Pelicula {
  constructor(titulo) {
    this.titulo = titulo;
  }
}

const pelicula = new Pelicula("Origen");

console.log(pelicula.titulo);
// Origen

console.log(Pelicula.name);
// Pelicula

console.log(Pelicula.titulo);
// undefined

5. Intentar utilizar una clase antes de declararla

Las declaraciones de clases no pueden utilizarse antes de que se haya ejecutado su declaración.

JavaScript 
// Incorrecto:
// const producto = new Producto("Teclado");

class Producto {
  constructor(nombre) {
    this.nombre = nombre;
  }
}

// Correcto:
const producto = new Producto("Teclado");

console.log(producto.nombre);
// Teclado

Ejemplos prácticos en aplicaciones web

Ejemplo 1. Gestión de alumnos

Vamos a representar alumnos de un ciclo formativo mediante una clase.

Cada alumno tendrá un nombre, un ciclo y una nota. Además, podrá consultar si ha aprobado.

JavaScript 
class Alumno {
  constructor(nombre, ciclo, nota) {
    this.nombre = nombre;
    this.ciclo = ciclo;
    this.nota = nota;
  }

  estaAprobado() {
    return this.nota >= 5;
  }

  mostrarResultado() {
    const estado = this.estaAprobado()
      ? "Aprobado"
      : "Suspenso";

    return `${this.nombre}: ${estado}`;
  }
}

const alumno1 = new Alumno("Ana", "DAW", 8);
const alumno2 = new Alumno("Luis", "DAW", 4);

console.log(alumno1.mostrarResultado());
// Ana: Aprobado

console.log(alumno2.mostrarResultado());
// Luis: Suspenso

Ejemplo 2. Productos de una tienda online

En una tienda online podemos representar cada producto mediante una instancia de una misma clase.

JavaScript 
class Producto {
  constructor(nombre, precio, stock) {
    this.nombre = nombre;
    this.precio = precio;
    this.stock = stock;
  }

  hayStock() {
    return this.stock > 0;
  }

  calcularDescuento(porcentaje) {
    return this.precio * (1 - porcentaje / 100);
  }

  vender(unidades) {
    if (
      !Number.isInteger(unidades) ||
      unidades <= 0 ||
      unidades > this.stock
    ) {
      return false;
    }

    this.stock -= unidades;
    return true;
  }
}

const teclado = new Producto("Teclado", 50, 10);

console.log(teclado.hayStock());
// true

console.log(teclado.calcularDescuento(20));
// 40

console.log(teclado.vender(3));
// true

console.log(teclado.stock);
// 7

Este ejemplo muestra cómo una clase puede reunir tanto los datos del producto como las operaciones relacionadas con él.

💻 Ejemplo DAW

En una aplicación real, las instancias de Producto podrían crearse a partir de los datos recibidos de una API. Después, sus métodos permitirían calcular descuentos o comprobar la disponibilidad de los productos.

Ejemplo 3. Reservas de habitaciones

Vamos a crear una clase para representar habitaciones de un hotel.

JavaScript 
class Habitacion {
  constructor(numero, precioNoche) {
    this.numero = numero;
    this.precioNoche = precioNoche;
    this.ocupada = false;
  }

  reservar() {
    if (this.ocupada) {
      return false;
    }

    this.ocupada = true;
    return true;
  }

  liberar() {
    this.ocupada = false;
  }

  calcularEstancia(noches) {
    if (!Number.isInteger(noches) || noches <= 0) {
      return null;
    }

    return noches * this.precioNoche;
  }
}

const habitacion101 = new Habitacion(101, 75);

console.log(habitacion101.reservar());
// true

console.log(habitacion101.reservar());
// false

console.log(habitacion101.calcularEstancia(3));
// 225

habitacion101.liberar();

console.log(habitacion101.ocupada);
// false

Observa que los métodos no se limitan a mostrar información: también pueden modificar el estado de la instancia.

Resumen del apartado

En este apartado hemos aprendido que las clases proporcionan una sintaxis clara para definir y crear objetos en JavaScript.

  • class permite declarar una clase.
  • constructor inicializa las propiedades de cada instancia.
  • new crea un nuevo objeto a partir de la clase.
  • this permite acceder a las propiedades y métodos de la instancia.
  • Los métodos se declaran dentro de la clase sin utilizar function.
  • Los métodos ordinarios declarados en el cuerpo de la clase se comparten mediante el prototipo.
  • Las clases facilitan la organización del código, aunque JavaScript sigue utilizando prototipos.
📌 Importante

La idea fundamental es distinguir entre clase e instancia.

La clase define las características comunes; cada instancia representa un objeto concreto con sus propios datos.

💭 Piensa

Queremos desarrollar una aplicación para gestionar vehículos de alquiler.

Cada vehículo debe almacenar su matrícula, su modelo y su precio diario. También debe poder calcular el coste de un alquiler de varios días.

¿Cómo definirías una clase Vehiculo que permita crear varios vehículos y calcular el coste de su alquiler?

Mostrar una posible solución
JavaScript 
class Vehiculo {
  constructor(matricula, modelo, precioDia) {
    this.matricula = matricula;
    this.modelo = modelo;
    this.precioDia = precioDia;
  }

  calcularAlquiler(dias) {
    if (!Number.isInteger(dias) || dias <= 0) {
      return null;
    }

    return this.precioDia * dias;
  }

  mostrarInformacion() {
    return `${this.modelo} (${this.matricula})`;
  }
}

const coche1 = new Vehiculo(
  "1234-ABC",
  "Seat León",
  45
);

const coche2 = new Vehiculo(
  "5678-DEF",
  "Toyota Corolla",
  55
);

console.log(coche1.mostrarInformacion());
// Seat León (1234-ABC)

console.log(coche1.calcularAlquiler(3));
// 135

console.log(coche2.calcularAlquiler(3));
// 165

console.log(coche1 instanceof Vehiculo);
// true

Hemos definido una única clase, pero podemos crear tantos vehículos como necesitemos.

Cada instancia almacena sus propios datos y utiliza los mismos métodos definidos en la clase.
