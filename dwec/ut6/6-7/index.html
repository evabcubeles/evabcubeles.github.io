6.7 Clases en JavaScript: class y constructor

En el apartado anterior hemos aprendido a utilizar funciones constructoras para crear varios objetos con las mismas propiedades y métodos. También hemos visto cómo intervienen el operador new y la palabra clave this en la creación de instancias.

Aunque las funciones constructoras permiten organizar la creación de objetos, JavaScript dispone de una sintaxis más clara y estructurada para trabajar con ellos: las clases.

Las clases facilitan la definición de objetos que comparten una estructura y un comportamiento. Son especialmente útiles cuando una aplicación necesita gestionar muchos elementos similares, como alumnos, productos, usuarios, pedidos o reservas.

📌 Importante

En JavaScript, una clase se declara mediante la palabra reservada class. Su constructor permite establecer los valores iniciales de los objetos, mientras que sus métodos definen las operaciones que pueden realizar.

Qué es una clase en JavaScript

Una clase es una estructura que permite definir cómo serán los objetos que se creen a partir de ella. Podemos entenderla como un modelo que establece qué información tendrá cada objeto y qué operaciones podrá realizar.

Por ejemplo, imaginemos una tienda en línea que necesita gestionar cientos de productos. Todos los productos pueden tener un nombre, un precio y una cantidad disponible.

En lugar de escribir un objeto diferente para cada producto, podemos crear una clase Producto y utilizarla para generar tantos objetos como necesitemos.

JavaScript 
class Producto {
  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }

  mostrarInformacion() {
    console.log(`${this.nombre}: ${this.precio} €`);
  }
}

const producto1 = new Producto("Teclado", 35);
const producto2 = new Producto("Ratón", 20);

producto1.mostrarInformacion();
producto2.mostrarInformacion();

En este ejemplo, Producto es la clase, mientras que producto1 y producto2 son objetos creados a partir de ella.

Cada objeto almacena sus propios valores, pero ambos pueden utilizar el método mostrarInformacion().

💻 Ejemplo DAW

En una aplicación de comercio electrónico, una clase Producto podría representar los artículos del catálogo. A partir de ella, la aplicación crearía objetos para cada producto recibido de una base de datos o de una API.

Sintaxis de class

Para declarar una clase en JavaScript se utiliza la palabra reservada class, seguida del nombre de la clase y un bloque de llaves.

Dentro de ese bloque podemos definir un constructor y los métodos que utilizarán los objetos.

JavaScript 
class NombreClase {
  constructor(parametro1, parametro2) {
    this.propiedad1 = parametro1;
    this.propiedad2 = parametro2;
  }

  nombreMetodo() {
    // Instrucciones del método
  }
}

Observa los elementos que intervienen:

  • class: indica que vamos a declarar una clase.
  • NombreClase: identifica la clase.
  • constructor(): es el método especial que inicializa las instancias.
  • this: permite acceder al objeto que se está creando o sobre el que se ejecuta un método.
  • Métodos: son funciones definidas dentro de la clase que describen su comportamiento.

Convenciones para nombrar clases

Aunque JavaScript permite diferentes nombres, es habitual utilizar la convención PascalCase: cada palabra comienza con mayúscula y no se emplean espacios.

JavaScript 
class Usuario {
}

class CarritoCompra {
}

class ReservaHotel {
}

⚠️ Atención

Dentro de una clase, los métodos se escriben directamente con su nombre. No se utiliza la palabra function delante de ellos. Tampoco es necesario separar las declaraciones de métodos con comas.

El método constructor

El método constructor() es un método especial que se ejecuta automáticamente cuando creamos una instancia de una clase mediante new.

Su función habitual es inicializar las propiedades del nuevo objeto utilizando los valores que recibe como argumentos.

Veamos una clase que representa a un alumno.

JavaScript 
class Alumno {
  constructor(nombre, edad, ciclo) {
    this.nombre = nombre;
    this.edad = edad;
    this.ciclo = ciclo;
  }
}

const alumno1 = new Alumno("Lucía", 20, "DAW");

console.log(alumno1.nombre); // Lucía
console.log(alumno1.edad);   // 20
console.log(alumno1.ciclo);  // DAW

Cuando se ejecuta la instrucción new Alumno("Lucía", 20, "DAW"), JavaScript crea un objeto y ejecuta su constructor. Los argumentos se asignan a los parámetros nombre, edad y ciclo.

Después, las instrucciones con this almacenan esos valores como propiedades del nuevo objeto.

Valores predeterminados en el constructor

Los parámetros del constructor pueden tener valores predeterminados, igual que los de cualquier otra función.

JavaScript 
class Usuario {
  constructor(nombre, activo = true) {
    this.nombre = nombre;
    this.activo = activo;
  }
}

const usuario1 = new Usuario("Ana");
const usuario2 = new Usuario("Pedro", false);

console.log(usuario1.activo); // true
console.log(usuario2.activo); // false

En este caso, si no se proporciona el segundo argumento, la propiedad activo tendrá inicialmente el valor true.

¿Es obligatorio declarar un constructor?

No. Una clase puede declararse sin escribir explícitamente el método constructor(). En ese caso, JavaScript proporciona un constructor predeterminado para una clase que no hereda de otra.

JavaScript 
class Saludo {
  mostrarMensaje() {
    console.log("Bienvenido a DWEC");
  }
}

const saludo1 = new Saludo();

saludo1.mostrarMensaje();

📌 Importante

Una clase solo puede declarar un método constructor(). Si necesitamos diferentes formas de inicializar un objeto, podemos utilizar parámetros opcionales, valores predeterminados o lógica condicional dentro del mismo constructor.

Creación de instancias con new

Una vez declarada una clase, podemos crear objetos utilizando el operador new, seguido del nombre de la clase y los argumentos correspondientes.

Cada objeto creado a partir de una clase recibe el nombre de instancia.

JavaScript 
class Libro {
  constructor(titulo, autor) {
    this.titulo = titulo;
    this.autor = autor;
  }
}

const libro1 = new Libro(
  "El principito",
  "Antoine de Saint-Exupéry"
);

const libro2 = new Libro(
  "Don Quijote de la Mancha",
  "Miguel de Cervantes"
);

console.log(libro1.titulo);
console.log(libro2.titulo);

Los dos objetos pertenecen a la misma clase, pero almacenan información diferente.

Independencia de las instancias

Cada instancia mantiene sus propias propiedades. Por ello, modificar una propiedad de un objeto no modifica automáticamente la propiedad equivalente de otro.

JavaScript 
class Contador {
  constructor(valorInicial) {
    this.valor = valorInicial;
  }
}

const contador1 = new Contador(0);
const contador2 = new Contador(10);

contador1.valor = 5;

console.log(contador1.valor); // 5
console.log(contador2.valor); // 10

La modificación de contador1 no afecta a contador2.

Comprobar si un objeto es una instancia

El operador instanceof, estudiado en el apartado anterior, también puede utilizarse con las clases.

JavaScript 
class Cliente {
  constructor(nombre) {
    this.nombre = nombre;
  }
}

const cliente1 = new Cliente("María");

console.log(cliente1 instanceof Cliente); // true
console.log(cliente1 instanceof Array);   // false
console.log(typeof cliente1);             // object

⚠️ Atención

Aunque utilizamos la palabra clase, las instancias siguen siendo objetos de JavaScript. Por eso, el operador typeof devuelve "object" cuando se aplica a una instancia.

La palabra clave this en las clases

La palabra clave this permite acceder al objeto sobre el que se está trabajando. Ya la hemos utilizado en los objetos literales y en las funciones constructoras.

Dentro del constructor de una clase, this hace referencia a la instancia que se está creando.

Cuando llamamos a un método mediante objeto.metodo(), this normalmente hace referencia a ese objeto.

JavaScript 
class CuentaBancaria {
  constructor(titular, saldoInicial) {
    this.titular = titular;
    this.saldo = saldoInicial;
  }

  mostrarSaldo() {
    console.log(
      `${this.titular} tiene ${this.saldo} €`
    );
  }
}

const cuenta1 = new CuentaBancaria("Laura", 500);
const cuenta2 = new CuentaBancaria("Carlos", 1200);

cuenta1.mostrarSaldo();
cuenta2.mostrarSaldo();

Cuando ejecutamos cuenta1.mostrarSaldo(), this hace referencia a cuenta1.

En cambio, cuando ejecutamos cuenta2.mostrarSaldo(), hace referencia a cuenta2.

La importancia de cómo se llama a un método

En JavaScript, el valor de this en un método depende de cómo se invoque. Si guardamos un método en una variable y lo ejecutamos por separado, podemos perder la referencia al objeto original.

JavaScript 
class Persona {
  constructor(nombre) {
    this.nombre = nombre;
  }

  saludar() {
    console.log(`Hola, soy ${this.nombre}`);
  }
}

const persona1 = new Persona("Elena");

persona1.saludar(); // Hola, soy Elena

const funcionSaludar = persona1.saludar;

// Esta llamada produciría un error:
// funcionSaludar();

const saludoVinculado = persona1.saludar.bind(persona1);

saludoVinculado(); // Hola, soy Elena

El método bind() permite crear una función cuyo this queda vinculado al objeto indicado.

📌 Importante

Para acceder a una propiedad de la instancia desde un método, normalmente debemos escribir this.nombrePropiedad. Escribir solamente el nombre de la propiedad no significa que JavaScript vaya a buscarla automáticamente dentro del objeto.

Definición de métodos en una clase

Además del constructor, una clase puede contener métodos que representen las operaciones que sus instancias pueden realizar.

Los métodos se declaran escribiendo su nombre, sus parámetros entre paréntesis y un bloque de instrucciones entre llaves.

Vamos a crear una clase que represente un rectángulo.

JavaScript 
class Rectangulo {
  constructor(ancho, alto) {
    this.ancho = ancho;
    this.alto = alto;
  }

  calcularArea() {
    return this.ancho * this.alto;
  }

  calcularPerimetro() {
    return 2 * (this.ancho + this.alto);
  }

  mostrarInformacion() {
    console.log(
      `Área: ${this.calcularArea()}`
    );

    console.log(
      `Perímetro: ${this.calcularPerimetro()}`
    );
  }
}

const rectangulo1 = new Rectangulo(5, 3);

console.log(rectangulo1.calcularArea());      // 15
console.log(rectangulo1.calcularPerimetro()); // 16

rectangulo1.mostrarInformacion();

La clase Rectangulo contiene tres métodos:

  • calcularArea() devuelve el área del rectángulo.
  • calcularPerimetro() devuelve su perímetro.
  • mostrarInformacion() utiliza los otros métodos para mostrar los resultados.

Observa que un método puede llamar a otro método del mismo objeto mediante this.nombreMetodo().

¿Dónde se almacenan los métodos?

Los métodos declarados de forma habitual dentro de una clase se encuentran en el prototipo de la clase. Esto permite que las instancias compartan esos métodos, en lugar de crear una copia independiente de cada función para cada objeto.

JavaScript 
class Saludo {
  saludar() {
    return "Hola";
  }
}

const saludo1 = new Saludo();
const saludo2 = new Saludo();

console.log(
  saludo1.saludar === saludo2.saludar
); // true

console.log(
  Saludo.prototype.saludar === saludo1.saludar
); // true

Aunque las dos instancias son objetos diferentes, utilizan la misma función definida en el prototipo.

💻 Ejemplo DAW

Si una aplicación gestiona mil productos, todos pueden utilizar el método calcularPrecioFinal() definido en la clase Producto. No es necesario escribir manualmente ese método en cada objeto.

Clases y funciones constructoras

En el apartado 6.6 aprendimos a crear objetos utilizando funciones constructoras. Las clases permiten expresar una idea semejante mediante una sintaxis más organizada.

Vamos a comparar las dos formas de crear una estructura para representar libros.

Utilizando una función constructora

JavaScript 
function Libro(titulo, autor) {
  this.titulo = titulo;
  this.autor = autor;
}

Libro.prototype.mostrarInformacion = function() {
  console.log(`${this.titulo} - ${this.autor}`);
};

const libro1 = new Libro(
  "1984",
  "George Orwell"
);

libro1.mostrarInformacion();

Utilizando una clase

JavaScript 
class Libro {
  constructor(titulo, autor) {
    this.titulo = titulo;
    this.autor = autor;
  }

  mostrarInformacion() {
    console.log(`${this.titulo} - ${this.autor}`);
  }
}

const libro1 = new Libro(
  "1984",
  "George Orwell"
);

libro1.mostrarInformacion();

Ambos ejemplos permiten crear un objeto Libro y llamar al método mostrarInformacion().

La diferencia principal está en la forma de organizar y declarar el código. En el segundo ejemplo, el constructor y los métodos aparecen agrupados dentro de una misma clase.

Aspecto Función constructora Clase
Declaración function class
Inicialización En el cuerpo de la función En constructor()
Creación de instancias new new
Acceso a propiedades this this
Métodos compartidos Se pueden añadir al prototipo Se declaran en el cuerpo de la clase
Uso sin new Depende de cómo esté definida la función Produce un error
Organización Constructor y métodos pueden declararse por separado Constructor y métodos aparecen agrupados

📌 Importante

Las clases de JavaScript están basadas en el sistema de prototipos del lenguaje. No sustituyen ese mecanismo por otro completamente diferente, sino que ofrecen una sintaxis más clara para trabajar con él.

Errores habituales al trabajar con clases

Cuando comenzamos a utilizar clases, es frecuente cometer errores relacionados con la sintaxis, el constructor, la creación de instancias y el uso de this.

1. Olvidar el operador new

Las clases deben instanciarse mediante el operador new.

JavaScript 
class Usuario {
  constructor(nombre) {
    this.nombre = nombre;
  }
}

// Incorrecto:
// const usuario1 = Usuario("Ana");

// Correcto:
const usuario1 = new Usuario("Ana");

console.log(usuario1.nombre);

Si intentamos ejecutar una clase como si fuera una función normal, JavaScript genera un error de tipo TypeError.

2. Escribir function delante de un método

Dentro de una clase no se utiliza function para declarar métodos ordinarios.

JavaScript 
class Producto {
  constructor(nombre) {
    this.nombre = nombre;
  }

  // Correcto:
  mostrarNombre() {
    console.log(this.nombre);
  }
}

3. Olvidar this al acceder a una propiedad

Si una propiedad pertenece a la instancia, debemos acceder a ella mediante this.

JavaScript 
class Alumno {
  constructor(nombre) {
    this.nombre = nombre;
  }

  saludar() {
    // Incorrecto:
    // console.log(nombre);

    // Correcto:
    console.log(this.nombre);
  }
}

const alumno1 = new Alumno("Mario");
alumno1.saludar();

4. Confundir la clase con una instancia

La clase define el modelo. Para acceder a las propiedades de una instancia, primero debemos crear el objeto.

JavaScript 
class Coche {
  constructor(marca) {
    this.marca = marca;
  }
}

const coche1 = new Coche("Toyota");

// Incorrecto:
// console.log(Coche.marca);

// Correcto:
console.log(coche1.marca);

5. Utilizar una clase antes de declararla

A diferencia de las declaraciones de funciones tradicionales, no podemos utilizar una clase antes de que se haya ejecutado su declaración.

JavaScript 
// Incorrecto:
// const alumno1 = new Alumno("Ana");

class Alumno {
  constructor(nombre) {
    this.nombre = nombre;
  }
}

// Correcto:
const alumno1 = new Alumno("Ana");

console.log(alumno1.nombre);

⚠️ Atención

Aunque una declaración de clase se registra al entrar en su ámbito, no puede utilizarse antes de su inicialización. Intentarlo produce un ReferenceError.

Ejemplos prácticos en aplicaciones web

Las clases resultan especialmente útiles cuando una aplicación necesita representar entidades con datos y comportamientos bien definidos.

Vamos a ver tres situaciones habituales en el desarrollo de aplicaciones web.

Ejemplo 1. Gestión de calificaciones

Imaginemos una aplicación que permite registrar alumnos y calcular sus notas medias. Podemos utilizar una clase Alumno para representar a cada estudiante.

JavaScript 
class Alumno {
  constructor(nombre, notas) {
    this.nombre = nombre;
    this.notas = notas;
  }

  calcularMedia() {
    if (this.notas.length === 0) {
      return 0;
    }

    const suma = this.notas.reduce(
      (total, nota) => total + nota,
      0
    );

    return suma / this.notas.length;
  }

  estaAprobado() {
    return this.calcularMedia() >= 5;
  }

  mostrarResultado() {
    console.log(`Alumno: ${this.nombre}`);

    console.log(
      `Media: ${this.calcularMedia().toFixed(2)}`
    );

    console.log(
      this.estaAprobado() ? "Aprobado" : "Suspenso"
    );
  }
}

const alumno1 = new Alumno(
  "Lucía",
  [7, 8, 6]
);

const alumno2 = new Alumno(
  "David",
  [3, 4, 5]
);

alumno1.mostrarResultado();
alumno2.mostrarResultado();

Cada objeto contiene el nombre y las notas de un alumno. Los métodos permiten calcular la media, comprobar si ha aprobado y mostrar su resultado.

Esta organización facilita que una aplicación pueda gestionar una colección de alumnos sin repetir las mismas operaciones.

Ejemplo 2. Productos de una tienda en línea

Una tienda puede utilizar una clase Producto para almacenar los datos de sus artículos y calcular su precio final.

JavaScript 
class Producto {
  constructor(nombre, precio, descuento = 0) {
    this.nombre = nombre;
    this.precio = precio;
    this.descuento = descuento;
  }

  calcularPrecioFinal() {
    return this.precio * (1 - this.descuento / 100);
  }

  mostrarFicha() {
    console.log(`Producto: ${this.nombre}`);

    console.log(
      `Precio final: ${this.calcularPrecioFinal().toFixed(2)} €`
    );
  }
}

const producto1 = new Producto(
  "Monitor",
  200,
  10
);

const producto2 = new Producto(
  "Teclado",
  40
);

producto1.mostrarFicha();
producto2.mostrarFicha();

En este ejemplo, el descuento es opcional. Si no se indica, se utiliza el valor predeterminado 0.

Así, una misma clase permite representar productos con descuento y productos que se venden a su precio original.

Ejemplo 3. Reservas de habitaciones

También podemos utilizar clases para representar las habitaciones de un hotel y controlar si están disponibles.

JavaScript 
class Habitacion {
  constructor(numero, precioNoche) {
    this.numero = numero;
    this.precioNoche = precioNoche;
    this.disponible = true;
  }

  reservar() {
    if (!this.disponible) {
      console.log("La habitación ya está reservada");
      return false;
    }

    this.disponible = false;
    console.log("Reserva realizada correctamente");
    return true;
  }

  liberar() {
    this.disponible = true;
    console.log("Habitación disponible");
  }

  calcularImporte(noches) {
    return this.precioNoche * noches;
  }
}

const habitacion1 = new Habitacion(204, 75);

habitacion1.reservar();
habitacion1.reservar();

console.log(
  `Importe por 3 noches: ${habitacion1.calcularImporte(3)} €`
);

habitacion1.liberar();

El objeto habitacion1 mantiene su propio estado mediante la propiedad disponible.

El método reservar() comprueba ese estado antes de realizar una nueva reserva. Si la habitación ya está ocupada, devuelve false.

💻 Ejemplo DAW

En una aplicación web real, estas clases podrían utilizarse para organizar los datos recibidos del servidor, validar operaciones y preparar la información que después se mostrará en la interfaz.

Más adelante aprenderemos a combinar estos objetos con el DOM, los eventos y las peticiones asíncronas.

Resumen del apartado

En este apartado hemos aprendido a declarar clases y crear objetos a partir de ellas. También hemos comprobado que las clases permiten agrupar las propiedades iniciales y los métodos de una manera organizada.

  • Una clase define un modelo para crear objetos.
  • La palabra reservada class permite declarar una clase.
  • El método constructor() inicializa las instancias.
  • El operador new crea una nueva instancia.
  • La palabra clave this permite acceder a las propiedades y métodos del objeto correspondiente.
  • Los métodos ordinarios declarados en una clase se comparten mediante su prototipo.
  • Las clases ofrecen una sintaxis más estructurada para trabajar con el sistema de objetos basado en prototipos de JavaScript.

📌 Importante

La idea fundamental es distinguir entre clase e instancia: la clase define la estructura y las operaciones; cada instancia representa un objeto concreto con sus propios datos.

💭 Piensa

Una empresa de alquiler de vehículos necesita gestionar su flota mediante una aplicación web.

Cada vehículo debe almacenar su matrícula, su marca, el precio de alquiler por día y si está disponible.

Reflexiona sobre las siguientes cuestiones:

  1. ¿Por qué sería conveniente utilizar una clase en lugar de crear manualmente cada objeto?
  2. ¿Qué parámetros debería recibir el constructor?
  3. ¿Qué propiedades tendría cada instancia?
  4. ¿Qué métodos permitirían alquilar, devolver y calcular el importe de un alquiler?
  5. ¿Cómo crearías dos vehículos con datos diferentes?

Intenta diseñar la clase Vehiculo antes de consultar la solución.

Ver una posible solución

Podemos crear una clase Vehiculo que inicialice los datos de cada vehículo y contenga métodos para gestionar su disponibilidad.

JavaScript 
class Vehiculo {
  constructor(matricula, marca, precioDia) {
    this.matricula = matricula;
    this.marca = marca;
    this.precioDia = precioDia;
    this.disponible = true;
  }

  alquilar() {
    if (!this.disponible) {
      console.log("El vehículo no está disponible");
      return false;
    }

    this.disponible = false;
    console.log("Vehículo alquilado");
    return true;
  }

  devolver() {
    this.disponible = true;
    console.log("Vehículo devuelto");
  }

  calcularImporte(dias) {
    return this.precioDia * dias;
  }
}

const vehiculo1 = new Vehiculo(
  "1234ABC",
  "Toyota",
  45
);

const vehiculo2 = new Vehiculo(
  "5678DEF",
  "Seat",
  38
);

vehiculo1.alquilar();

console.log(
  vehiculo1.calcularImporte(4)
); // 180

console.log(vehiculo1.disponible); // false
console.log(vehiculo2.disponible); // true

vehiculo1.devolver();

La clase evita repetir la misma estructura para cada vehículo. Cada instancia almacena sus propios datos y su disponibilidad.

El método alquilar() comprueba si el vehículo está disponible, devolver() modifica su estado y calcularImporte() calcula el coste según el número de días.
