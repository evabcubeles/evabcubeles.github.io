6.1 Introducción a los objetos en JavaScript

En las unidades anteriores hemos aprendido a utilizar variables, operadores, estructuras de control, arrays y funciones para desarrollar programas en JavaScript. Con estas herramientas podemos almacenar información, realizar cálculos, tomar decisiones y organizar nuestro código.

Sin embargo, cuando desarrollamos aplicaciones más completas, necesitamos trabajar con datos que están relacionados entre sí. Por ejemplo, una tienda online puede almacenar información sobre productos, clientes y pedidos. Cada producto tiene un nombre, un precio, una categoría y una cantidad disponible.

Podríamos guardar estos datos utilizando variables independientes, pero a medida que aumentase el número de productos, el programa resultaría más difícil de organizar y mantener.

Para resolver esta necesidad, JavaScript permite utilizar objetos, estructuras que agrupan información relacionada y que también pueden incorporar operaciones para trabajar con ella.

📌 Importante

Un objeto es una estructura que permite agrupar datos relacionados mediante propiedades y, cuando es necesario, definir métodos que realizan operaciones asociadas a ese objeto.

Qué es un objeto

Un objeto es una forma de representar una entidad dentro de un programa, reuniendo en una misma estructura los datos que la describen.

Pensemos en una aplicación de gestión de productos. Para almacenar la información de un ordenador portátil, podríamos utilizar varias variables:

JavaScript 
const nombre = "Portátil Lenovo";
const precio = 850;
const stock = 12;
const disponible = true;

console.log(nombre);
console.log(precio);
console.log(stock);
console.log(disponible);

Este código es correcto, pero presenta una limitación: aunque todas las variables describen el mismo producto, no existe ninguna estructura que las agrupe.

Si tuviéramos que gestionar decenas o cientos de productos, necesitaríamos una forma más adecuada de organizar esa información.

Podemos resolverlo creando un objeto:

JavaScript 
const producto = {
  nombre: "Portátil Lenovo",
  precio: 850,
  stock: 12,
  disponible: true
};

console.log(producto);

Ahora los cuatro datos se encuentran agrupados en una única estructura llamada producto.

Cada elemento del objeto está formado por un nombre de propiedad y un valor. Por ejemplo, precio es el nombre de una propiedad y 850 es su valor.

Objeto: producto Agrupa toda la información relacionada con un mismo producto.
nombre "Portátil Lenovo"
precio 850
stock 12
disponible true

Observa que el objeto puede almacenar valores de distintos tipos: cadenas de texto, números y booleanos.

Esta característica permite representar entidades de una aplicación de una forma más natural y comprensible.

⚠️ Atención

Un objeto no es simplemente una variable que almacena varios valores. Es una estructura que permite identificar cada dato mediante un nombre de propiedad.

Por eso, en un objeto podemos acceder directamente al dato que necesitamos, sin depender de su posición como ocurre habitualmente al trabajar con arrays.

Los objetos en la vida real

Para comprender mejor el concepto de objeto, podemos pensar en elementos de la vida cotidiana. Cada elemento tiene determinadas características y puede realizar ciertas acciones.

Por ejemplo, un coche tiene una marca, un modelo, un color y una velocidad. Además, puede acelerar, frenar o detenerse.

Objeto Características Acciones
Coche Marca, modelo, color, velocidad Acelerar, frenar, detenerse
Cuenta bancaria Titular, número de cuenta, saldo Ingresar, retirar, consultar saldo
Producto Nombre, precio, stock Aplicar descuento, actualizar stock
Usuario Nombre, correo, estado Iniciar sesión, cerrar sesión

Cuando trasladamos estas entidades a un programa, sus características pueden representarse mediante propiedades y sus acciones mediante métodos.

💻 Ejemplo DAW

Imagina una aplicación web de gestión de matrículas. Podemos representar cada alumno mediante un objeto que almacene su nombre, correo electrónico, ciclo formativo y estado de matrícula.

Más adelante, ese objeto podría incorporar operaciones como consultar sus datos o actualizar su estado.

Un mismo tipo de entidad puede tener diferentes objetos

En una tienda online no existe un único producto. Puede haber ordenadores, monitores, teclados y muchos otros artículos.

Cada producto puede representarse mediante un objeto independiente, aunque todos compartan propiedades semejantes.

JavaScript 
const producto1 = {
  nombre: "Monitor",
  precio: 180,
  stock: 8
};

const producto2 = {
  nombre: "Teclado",
  precio: 45,
  stock: 20
};

console.log(producto1.nombre);
console.log(producto2.nombre);

El programa mostrará:

Consola 
Monitor
Teclado

Aunque ambos objetos tienen las mismas propiedades, cada uno almacena sus propios valores.

Más adelante aprenderemos a crear múltiples objetos de manera más organizada utilizando funciones constructoras y clases.

Estado y comportamiento

Una de las ideas fundamentales al trabajar con objetos es distinguir entre estado y comportamiento.

El estado de un objeto está formado por los valores de sus propiedades en un momento determinado.

El comportamiento representa las operaciones que puede realizar el objeto mediante sus métodos.

Objeto: cuenta bancaria Reúne información y operaciones relacionadas con una cuenta.
Estado Titular: "Ana" Saldo: 1200 €
Comportamiento Ingresar dinero Consultar saldo

Ejemplo de un objeto con estado y comportamiento

Vamos a representar una cuenta bancaria sencilla mediante un objeto:

JavaScript 
const cuenta = {
  titular: "Ana",
  saldo: 1200,

  mostrarSaldo: function () {
    console.log("Saldo actual: " + this.saldo + " €");
  }
};

cuenta.mostrarSaldo();

El resultado será:

Consola 
Saldo actual: 1200 €

En este ejemplo, las propiedades titular y saldo representan el estado de la cuenta. Por otra parte, mostrarSaldo() es un método que permite consultar parte de esa información.

También aparece la palabra clave this, que en esta llamada permite acceder al propio objeto cuenta. Estudiaremos su funcionamiento con detalle en el apartado 6.5.

📌 Importante

Las propiedades describen el estado de un objeto y los métodos permiten definir su comportamiento.

Un objeto puede contener únicamente propiedades, como los primeros ejemplos, o combinar propiedades y métodos.

Objetos en JavaScript

En JavaScript, los objetos son una parte fundamental del lenguaje. Se utilizan constantemente para organizar información, representar entidades y trabajar con diferentes funcionalidades.

Una forma sencilla de crear un objeto consiste en utilizar llaves {}. Esta forma se conoce como notación literal de objetos.

JavaScript 
const alumno = {
  nombre: "Lucía",
  edad: 21,
  ciclo: "DAW",
  matriculado: true
};

Observa los principales elementos de esta declaración:

  • const alumno declara una variable que almacena una referencia al objeto.
  • Las llaves {} delimitan el contenido del objeto.
  • Cada propiedad tiene un nombre y un valor separados por dos puntos :.
  • Las propiedades se separan mediante comas.
  • Los valores pueden ser de diferentes tipos.

Acceder a la información de un objeto

Para consultar una propiedad podemos utilizar el nombre del objeto, seguido de un punto y del nombre de la propiedad.

JavaScript 
const alumno = {
  nombre: "Lucía",
  edad: 21,
  ciclo: "DAW",
  matriculado: true
};

console.log(alumno.nombre);
console.log(alumno.edad);
console.log(alumno.ciclo);

El resultado será:

Consola 
Lucía
21
DAW

En este caso, alumno.nombre permite consultar el valor de la propiedad nombre.

También podemos acceder mediante corchetes, como veremos en el siguiente apartado.

Los objetos pueden contener otros objetos

Una característica especialmente útil es que una propiedad puede almacenar otro objeto.

JavaScript 
const alumno = {
  nombre: "Lucía",
  contacto: {
    email: "lucia@ejemplo.com",
    telefono: "600123456"
  }
};

console.log(alumno.nombre);
console.log(alumno.contacto.email);

La propiedad contacto almacena otro objeto que agrupa la información de contacto.

Este tipo de organización es muy habitual en aplicaciones web que manejan datos estructurados.

💻 Ejemplo DAW

En una aplicación de comercio electrónico, un objeto pedido puede contener información del cliente, una lista de productos, la dirección de entrega y el importe total.

De esta forma, todos los datos necesarios para gestionar un pedido pueden organizarse en una estructura relacionada.

Valores primitivos y objetos

En JavaScript es importante distinguir entre los valores primitivos y los objetos.

Los valores primitivos representan datos individuales, como números, cadenas de texto o valores booleanos.

Los objetos, en cambio, permiten reunir diferentes valores bajo una misma estructura.

Aspecto Valor primitivo Objeto
Ejemplo 25 { edad: 25 }
Información Un valor individual Puede agrupar varias propiedades
Asignación Se copia el valor Se copia la referencia al objeto
Mutabilidad El valor primitivo es inmutable Sus propiedades pueden modificarse

Ejemplo con valores primitivos

JavaScript 
let numero1 = 10;
let numero2 = numero1;

numero2 = 20;

console.log(numero1);
console.log(numero2);

El resultado será:

Consola 
10
20

Al asignar numero1 a numero2, se copia el valor numérico. Por eso, modificar posteriormente numero2 no afecta a numero1.

Ejemplo con objetos

Ahora vamos a realizar una operación semejante utilizando un objeto:

JavaScript 
const producto1 = {
  nombre: "Ratón",
  precio: 25
};

const producto2 = producto1;

producto2.precio = 30;

console.log(producto1.precio);
console.log(producto2.precio);

El resultado será:

Consola 
30
30

En este caso, ambas variables hacen referencia al mismo objeto. Por tanto, cuando modificamos su propiedad precio a través de producto2, el cambio también se observa al consultar producto1.

⚠️ Atención

Cuando asignamos un objeto a otra variable, no se crea automáticamente una copia independiente del objeto. Se copia la referencia.

Por eso, dos variables pueden apuntar al mismo objeto y observar las mismas modificaciones.

¿Se pueden modificar las propiedades de un objeto declarado con const?

Sí. La palabra clave const impide reasignar la variable a otro valor, pero no impide modificar las propiedades del objeto al que hace referencia.

JavaScript 
const usuario = {
  nombre: "Carlos",
  edad: 22
};

// Permitido: modificar una propiedad
usuario.edad = 23;

console.log(usuario.edad); // 23

// No permitido: reasignar la variable
// usuario = { nombre: "Ana" };

Esta distinción será importante cuando aprendamos a manipular objetos y a trabajar con referencias.

📌 Importante

Cuando declaramos un objeto mediante const, no podemos reasignar la variable para que haga referencia a otro objeto.

Sin embargo, const no convierte automáticamente en inmutables las propiedades del objeto. Podemos modificar sus valores, añadir nuevas propiedades o eliminar las existentes.

Recuerda: modificar una propiedad no es lo mismo que reasignar una variable.

Primer ejemplo de objeto

Vamos a reunir los conceptos estudiados en un ejemplo relacionado con el desarrollo de aplicaciones web.

Imagina que estamos desarrollando una tienda online y necesitamos representar un producto.

El producto tendrá las siguientes características:

  • Un identificador.
  • Un nombre.
  • Un precio.
  • Una cantidad disponible.
  • Un estado que indique si está activo.

Paso 1. Crear el objeto

Utilizamos la notación literal para agrupar todos los datos:

JavaScript 
const producto = {
  id: 101,
  nombre: "Auriculares Bluetooth",
  precio: 59.99,
  stock: 15,
  activo: true
};

Paso 2. Consultar las propiedades

Podemos acceder a cada dato utilizando la notación de punto:

JavaScript 
console.log(producto.nombre);
console.log(producto.precio);
console.log(producto.stock);

El resultado será:

Consola 
Auriculares Bluetooth
59.99
15

Paso 3. Utilizar los datos del objeto

Las propiedades de un objeto pueden utilizarse en expresiones, condiciones y operaciones, igual que cualquier otra variable.

Por ejemplo, podemos comprobar si el producto está disponible para su venta:

JavaScript 
const producto = {
  id: 101,
  nombre: "Auriculares Bluetooth",
  precio: 59.99,
  stock: 15,
  activo: true
};

if (producto.activo && producto.stock > 0) {
  console.log("Producto disponible");
} else {
  console.log("Producto no disponible");
}

El resultado será:

Consola 
Producto disponible

Observa que estamos combinando los objetos con conocimientos adquiridos en unidades anteriores, como los operadores lógicos y las estructuras condicionales.

Paso 4. Modificar el estado del objeto

Si se vende una unidad del producto, podemos actualizar su stock:

JavaScript 
producto.stock = producto.stock - 1;

console.log(producto.stock); // 14

El objeto sigue siendo el mismo, pero ha cambiado el valor de una de sus propiedades.

Por tanto, podemos decir que ha cambiado su estado.

Paso 5. Mostrar un resumen del producto

También podemos utilizar sus propiedades para construir un mensaje informativo:

JavaScript 
const producto = {
  id: 101,
  nombre: "Auriculares Bluetooth",
  precio: 59.99,
  stock: 15,
  activo: true
};

console.log(
  `Producto: ${producto.nombre}`
);

console.log(
  `Precio: ${producto.precio} €`
);

console.log(
  `Unidades disponibles: ${producto.stock}`
);

El resultado será:

Consola 
Producto: Auriculares Bluetooth
Precio: 59.99 €
Unidades disponibles: 15
💻 Ejemplo DAW

En una aplicación web real, la información de los productos puede llegar desde un servidor y utilizarse para mostrar tarjetas de productos, comprobar existencias o calcular importes.

Los objetos permiten mantener relacionados los datos de cada producto y facilitan su tratamiento mediante JavaScript.

Qué debemos recordar

Después de este primer contacto con los objetos, debemos tener claras las siguientes ideas:

  • Un objeto permite agrupar información relacionada.
  • Las propiedades representan datos o características.
  • Los métodos permiten asociar operaciones al objeto.
  • El estado de un objeto está determinado por los valores de sus propiedades.
  • Podemos crear objetos mediante la notación literal {}.
  • Los objetos se manejan mediante referencias, por lo que dos variables pueden referirse al mismo objeto.
📌 Importante

Los objetos son una herramienta esencial para organizar la información de las aplicaciones JavaScript.

Comprender cómo representan datos y comportamientos es el primer paso para estudiar la Programación Orientada a Objetos.

💭 Piensa

Imagina que estás desarrollando una aplicación web para gestionar las reservas de habitaciones de un hotel.

Cada habitación tiene un número, un tipo, un precio por noche y un estado que indica si está disponible.

Responde a las siguientes preguntas:

  1. ¿Por qué sería conveniente representar cada habitación mediante un objeto?
  2. ¿Qué propiedades incluirías en ese objeto?
  3. ¿Qué posibles métodos podría tener?
  4. ¿Qué ocurriría si cambiamos el estado de disponibilidad de una habitación?
  5. ¿Qué diferencia existiría entre almacenar estos datos en variables independientes y hacerlo mediante un objeto?
Ver una posible solución

Sería conveniente utilizar un objeto porque permite agrupar toda la información relacionada con una habitación dentro de una misma estructura.

Podríamos definir las propiedades numero, tipo, precioNoche y disponible.

JavaScript 
const habitacion = {
  numero: 204,
  tipo: "Doble",
  precioNoche: 85,
  disponible: true
};

console.log(habitacion.tipo);
console.log(habitacion.precioNoche);

Más adelante, el objeto podría incorporar métodos como reservar(), liberar() o calcularPrecio().

Si una habitación pasa de estar disponible a estar reservada, cambiaría su estado. Por ejemplo:

JavaScript 
habitacion.disponible = false;

console.log(habitacion.disponible); // false

La ventaja principal es que todas las características de la habitación quedan agrupadas y podemos acceder a ellas de manera organizada.

Además, esta estructura facilitaría gestionar múltiples habitaciones y desarrollar nuevas funcionalidades sin perder la relación entre sus datos.
