6.8 Propiedades y métodos de las clases

En el apartado anterior hemos aprendido a definir clases en JavaScript mediante la palabra reservada class, a utilizar el método constructor y a crear instancias mediante el operador new.

También hemos visto que una clase puede contener propiedades y métodos. Ahora vamos a profundizar en estos dos elementos para comprender cómo organizan la información y el comportamiento de los objetos.

En una aplicación web, los objetos no solo almacenan datos: también realizan operaciones sobre ellos. Por ejemplo, un producto puede guardar su precio y calcular un descuento; una cuenta bancaria puede almacenar su saldo y registrar un ingreso.

📌 Importante

Las propiedades representan los datos o el estado de un objeto.

Los métodos representan las operaciones que ese objeto puede realizar.

Propiedades de instancia

Las propiedades de instancia son los datos que pertenecen a cada objeto creado a partir de una clase.

Aunque varias instancias se hayan creado utilizando la misma clase, cada una puede almacenar valores diferentes en sus propiedades.

JavaScript 
class Producto {
  constructor(nombre, precio, stock) {
    this.nombre = nombre;
    this.precio = precio;
    this.stock = stock;
  }
}

const producto1 = new Producto("Teclado", 45, 10);
const producto2 = new Producto("Ratón", 25, 20);

console.log(producto1.nombre);
// Teclado

console.log(producto2.nombre);
// Ratón

console.log(producto1.precio);
// 45

console.log(producto2.precio);
// 25

En este ejemplo, producto1 y producto2 son dos instancias independientes de la clase Producto.

Ambas tienen las mismas propiedades: nombre, precio y stock, pero sus valores son diferentes.

producto1 nombre: "Teclado" precio: 45 stock: 10
producto2 nombre: "Ratón" precio: 25 stock: 20

Este comportamiento es fundamental en la Programación Orientada a Objetos: cada instancia mantiene su propio estado.

Declaración de propiedades

Una forma habitual de inicializar las propiedades de una instancia consiste en asignarlas dentro del método constructor, utilizando la palabra clave this.

JavaScript 
class Alumno {
  constructor(nombre, ciclo, nota) {
    this.nombre = nombre;
    this.ciclo = ciclo;
    this.nota = nota;
  }
}

const alumno = new Alumno("Lucía", "DAW", 8);

console.log(alumno.nombre); // Lucía
console.log(alumno.ciclo);  // DAW
console.log(alumno.nota);   // 8

Las expresiones this.nombre, this.ciclo y this.nota crean o asignan propiedades en la instancia.

Propiedades con valores iniciales

No todas las propiedades tienen que recibir su valor mediante un parámetro. Algunas pueden comenzar con un valor fijo.

JavaScript 
class Pedido {
  constructor(numero, cliente) {
    this.numero = numero;
    this.cliente = cliente;
    this.estado = "pendiente";
    this.total = 0;
  }
}

const pedido1 = new Pedido(101, "Ana");

console.log(pedido1.estado);
// pendiente

console.log(pedido1.total);
// 0

En este caso, todas las instancias de Pedido comienzan con el estado "pendiente" y un total de 0.

Campos de instancia

JavaScript también permite declarar campos de instancia directamente dentro del cuerpo de una clase, fuera del constructor.

JavaScript 
class Usuario {
  activo = true;
  intentos = 0;

  constructor(nombre) {
    this.nombre = nombre;
  }
}

const usuario = new Usuario("Pablo");

console.log(usuario.nombre);   // Pablo
console.log(usuario.activo);   // true
console.log(usuario.intentos); // 0

Los campos activo e intentos se inicializan automáticamente en cada instancia.

⚠️ Atención

Cuando declaramos un campo de instancia directamente en una clase, no escribimos this delante de su nombre.

En cambio, dentro del constructor o de los métodos, utilizamos this para acceder a las propiedades del objeto.

Acceso y modificación de propiedades

Las propiedades públicas de una instancia pueden consultarse y modificarse utilizando la notación del punto o, cuando resulte necesario, la notación de corchetes.

JavaScript 
class Libro {
  constructor(titulo, precio) {
    this.titulo = titulo;
    this.precio = precio;
  }
}

const libro = new Libro("JavaScript", 30);

// Consultar propiedades.
console.log(libro.titulo);
// JavaScript

console.log(libro["precio"]);
// 30

// Modificar una propiedad.
libro.precio = 25;

console.log(libro.precio);
// 25

La modificación afecta a la instancia concreta sobre la que estamos trabajando.

Añadir nuevas propiedades

En JavaScript, los objetos ordinarios permiten añadir nuevas propiedades después de su creación, incluso si no estaban definidas en el constructor.

JavaScript 
class Cliente {
  constructor(nombre) {
    this.nombre = nombre;
  }
}

const cliente = new Cliente("Ana");

cliente.email = "ana@ejemplo.com";

console.log(cliente.nombre);
// Ana

console.log(cliente.email);
// ana@ejemplo.com

Aunque esta posibilidad existe, es recomendable que las propiedades principales de los objetos estén previstas en el diseño de la clase.

📌 Importante

Las propiedades públicas pueden modificarse desde fuera de la clase.

Por ello, cuando necesitemos controlar cómo se actualizan los datos, podemos definir métodos que realicen las comprobaciones correspondientes.

Métodos de instancia

Los métodos de instancia son funciones definidas en una clase que pueden invocarse mediante los objetos creados a partir de ella.

Permiten consultar información, realizar cálculos y modificar las propiedades de una instancia.

JavaScript 
class Rectangulo {
  constructor(ancho, alto) {
    this.ancho = ancho;
    this.alto = alto;
  }

  calcularArea() {
    return this.ancho * this.alto;
  }

  calcularPerimetro() {
    return 2 * (this.ancho + this.alto);
  }
}

const rectangulo = new Rectangulo(8, 5);

console.log(rectangulo.calcularArea());
// 40

console.log(rectangulo.calcularPerimetro());
// 26

Los métodos calcularArea() y calcularPerimetro() utilizan las propiedades de la instancia para obtener sus resultados.

Métodos con parámetros

Al igual que las funciones, los métodos pueden recibir parámetros.

JavaScript 
class Producto {
  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }

  calcularDescuento(porcentaje) {
    return this.precio * (1 - porcentaje / 100);
  }
}

const producto = new Producto("Monitor", 200);

console.log(producto.calcularDescuento(10));
// 180

console.log(producto.calcularDescuento(25));
// 150

El parámetro porcentaje permite realizar el mismo cálculo utilizando diferentes descuentos.

Métodos que devuelven valores

Los métodos pueden devolver distintos tipos de datos mediante return: números, cadenas de texto, valores booleanos, objetos o cualquier otro valor de JavaScript.

JavaScript 
class Alumno {
  constructor(nombre, nota) {
    this.nombre = nombre;
    this.nota = nota;
  }

  estaAprobado() {
    return this.nota >= 5;
  }

  mostrarResultado() {
    return this.estaAprobado()
      ? `${this.nombre}: Aprobado`
      : `${this.nombre}: Suspenso`;
  }
}

const alumno = new Alumno("Lucía", 8);

console.log(alumno.estaAprobado());
// true

console.log(alumno.mostrarResultado());
// Lucía: Aprobado

Observa que el método mostrarResultado() llama a otro método de la misma instancia: this.estaAprobado().

💻 Ejemplo DAW

En una aplicación de gestión académica, una clase Alumno puede contener propiedades como nombre y nota, junto con métodos como estaAprobado() o mostrarResultado().

De esta manera, los datos y las operaciones relacionadas con ellos permanecen organizados dentro de la misma clase.

Diferencia entre propiedades y métodos

Aunque ambos forman parte de los objetos, las propiedades y los métodos cumplen funciones diferentes.

Aspecto Propiedad Método
Finalidad Almacenar información Realizar una operación
Ejemplo producto.precio producto.calcularDescuento()
Acceso Se consulta su valor Se invoca utilizando paréntesis
Contenido Puede almacenar diferentes tipos de valores Contiene una función que ejecuta instrucciones
Relación con el objeto Representa su estado Representa su comportamiento

Vamos a observar ambas posibilidades en un mismo ejemplo.

JavaScript 
class Cuenta {
  constructor(titular, saldo) {
    this.titular = titular;
    this.saldo = saldo;
  }

  consultarSaldo() {
    return this.saldo;
  }
}

const cuenta = new Cuenta("Ana", 150);

// Acceso a una propiedad.
console.log(cuenta.saldo);
// 150

// Invocación de un método.
console.log(cuenta.consultarSaldo());
// 150

Las dos instrucciones muestran el mismo valor, pero no funcionan de la misma manera: la primera consulta directamente una propiedad y la segunda ejecuta un método.

⚠️ Atención

No debemos confundir cuenta.consultarSaldo con cuenta.consultarSaldo().

La primera expresión obtiene una referencia a la función; la segunda la ejecuta.

Métodos que modifican el estado del objeto

Los métodos no tienen por qué limitarse a devolver información. También pueden modificar las propiedades de una instancia.

Cuando un método modifica los datos del objeto, decimos que cambia su estado.

JavaScript 
class CuentaBancaria {
  constructor(titular, saldoInicial = 0) {
    this.titular = titular;
    this.saldo = saldoInicial;
  }

  ingresar(cantidad) {
    if (cantidad <= 0) {
      return false;
    }

    this.saldo += cantidad;
    return true;
  }

  retirar(cantidad) {
    if (cantidad <= 0 || cantidad > this.saldo) {
      return false;
    }

    this.saldo -= cantidad;
    return true;
  }

  consultarSaldo() {
    return this.saldo;
  }
}

const cuenta = new CuentaBancaria("Ana", 100);

console.log(cuenta.ingresar(50));
// true

console.log(cuenta.consultarSaldo());
// 150

console.log(cuenta.retirar(30));
// true

console.log(cuenta.consultarSaldo());
// 120

console.log(cuenta.retirar(200));
// false

El método ingresar() aumenta el saldo de la cuenta, mientras que retirar() lo disminuye cuando la operación es válida.

Ambos métodos comprueban determinadas condiciones antes de modificar la propiedad saldo.

Por qué es útil modificar los datos mediante métodos

Si modificamos las propiedades directamente desde cualquier parte del programa, podemos introducir valores incorrectos.

JavaScript 
// La propiedad es pública.
cuenta.saldo = -500;

console.log(cuenta.saldo);
// -500

Como saldo es una propiedad pública, el programa puede modificarla directamente sin pasar por las comprobaciones de los métodos.

Más adelante estudiaremos cómo los principios de la Programación Orientada a Objetos ayudan a controlar el acceso a los datos.

📌 Importante

Definir métodos para modificar propiedades permite centralizar las operaciones y comprobar que los nuevos valores cumplen las condiciones necesarias.

Sin embargo, un método de validación no impide por sí solo que una propiedad pública sea modificada directamente.

Propiedades y métodos estáticos

Hasta ahora hemos trabajado con propiedades y métodos de instancia, es decir, elementos que utilizamos mediante los objetos creados con new.

JavaScript también permite definir propiedades y métodos estáticos, que pertenecen a la propia clase.

Para declararlos utilizamos la palabra reservada static.

Propiedades estáticas

Una propiedad estática puede almacenar información común relacionada con la clase, en lugar de pertenecer a cada instancia.

JavaScript 
class Producto {
  static categoriaGeneral = "Informática";

  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }
}

const producto1 = new Producto("Teclado", 45);
const producto2 = new Producto("Ratón", 25);

console.log(Producto.categoriaGeneral);
// Informática

console.log(producto1.nombre);
// Teclado

console.log(producto2.nombre);
// Ratón

console.log(producto1.categoriaGeneral);
// undefined

La propiedad categoriaGeneral pertenece a la clase Producto. Por eso accedemos a ella mediante Producto.categoriaGeneral.

Métodos estáticos

Los métodos estáticos se invocan mediante el nombre de la clase, sin necesidad de crear una instancia.

JavaScript 
class Calculadora {
  static sumar(a, b) {
    return a + b;
  }

  static multiplicar(a, b) {
    return a * b;
  }
}

console.log(Calculadora.sumar(5, 3));
// 8

console.log(Calculadora.multiplicar(4, 6));
// 24

En este caso no necesitamos crear un objeto Calculadora, porque los métodos realizan operaciones que no dependen del estado de una instancia.

Comparación entre miembros de instancia y estáticos

Aspecto De instancia Estático
Pertenece a La instancia La clase
Declaración Sin static Con static
Acceso objeto.metodo() Clase.metodo()
Uso habitual Operaciones sobre un objeto concreto Operaciones generales relacionadas con la clase
⚠️ Atención

Un método estático no se invoca directamente mediante una instancia.

Por ejemplo, si sumar() es estático, utilizaremos Calculadora.sumar(2, 3), no calculadora.sumar(2, 3).

Errores habituales al trabajar con propiedades y métodos

1. Olvidar this al acceder a una propiedad

Dentro de un método de instancia debemos utilizar this para acceder a las propiedades del objeto.

JavaScript 
class Producto {
  constructor(precio) {
    this.precio = precio;
  }

  mostrarPrecio() {
    // Incorrecto:
    // return precio;

    // Correcto:
    return this.precio;
  }
}

const producto = new Producto(50);

console.log(producto.mostrarPrecio());
// 50

2. Olvidar los paréntesis al llamar a un método

Para ejecutar un método debemos escribir los paréntesis correspondientes.

JavaScript 
class Saludo {
  saludar() {
    return "Hola";
  }
}

const saludo = new Saludo();

// Referencia a la función:
console.log(typeof saludo.saludar);
// function

// Ejecución del método:
console.log(saludo.saludar());
// Hola

3. Confundir un método estático con uno de instancia

JavaScript 
class Conversor {
  static eurosADolares(euros, cambio) {
    return euros * cambio;
  }
}

// Incorrecto:
// const conversor = new Conversor();
// conversor.eurosADolares(100, 1.1);

// Correcto:
console.log(Conversor.eurosADolares(100, 1.1));
// 110.00000000000001

El resultado del último ejemplo también nos recuerda que JavaScript utiliza números de coma flotante, por lo que algunas operaciones decimales pueden presentar pequeñas imprecisiones.

4. Modificar directamente una propiedad sin validarla

Las propiedades públicas pueden recibir valores incorrectos si no controlamos las asignaciones.

JavaScript 
class Producto {
  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }

  cambiarPrecio(nuevoPrecio) {
    if (
      typeof nuevoPrecio !== "number" ||
      !Number.isFinite(nuevoPrecio) ||
      nuevoPrecio < 0
    ) {
      return false;
    }

    this.precio = nuevoPrecio;
    return true;
  }
}

const producto = new Producto("Ratón", 25);

console.log(producto.cambiarPrecio(-10));
// false

console.log(producto.cambiarPrecio(20));
// true

console.log(producto.precio);
// 20

El método cambiarPrecio() comprueba que el nuevo precio sea un número válido y no sea negativo.

Ejemplos prácticos en aplicaciones web

Ejemplo 1. Gestión de productos

Vamos a desarrollar una clase que permita representar productos de una tienda online.

Cada producto tendrá un nombre, un precio y un stock. Además, dispondrá de métodos para consultar la disponibilidad y vender determinadas unidades.

JavaScript 
class Producto {
  constructor(nombre, precio, stock) {
    this.nombre = nombre;
    this.precio = precio;
    this.stock = stock;
  }

  hayStock() {
    return this.stock > 0;
  }

  vender(unidades) {
    if (
      !Number.isInteger(unidades) ||
      unidades <= 0 ||
      unidades > this.stock
    ) {
      return false;
    }

    this.stock -= unidades;
    return true;
  }

  calcularValorStock() {
    return this.precio * this.stock;
  }

  mostrarInformacion() {
    return `${this.nombre}: ${this.stock} unidades`;
  }
}

const teclado = new Producto("Teclado", 50, 10);

console.log(teclado.hayStock());
// true

console.log(teclado.vender(3));
// true

console.log(teclado.mostrarInformacion());
// Teclado: 7 unidades

console.log(teclado.calcularValorStock());
// 350

Este ejemplo combina propiedades que almacenan información con métodos que consultan o modifican el estado del producto.

💻 Ejemplo DAW

En una tienda online real, estos métodos podrían utilizarse para actualizar las existencias después de una venta o para mostrar al usuario si un producto se encuentra disponible.

Ejemplo 2. Gestión de alumnos

En una aplicación educativa podemos utilizar una clase para almacenar las calificaciones de un alumno y calcular su nota media.

JavaScript 
class Alumno {
  constructor(nombre, ciclo) {
    this.nombre = nombre;
    this.ciclo = ciclo;
    this.notas = [];
  }

  agregarNota(nota) {
    if (
      typeof nota !== "number" ||
      !Number.isFinite(nota) ||
      nota < 0 ||
      nota > 10
    ) {
      return false;
    }

    this.notas.push(nota);
    return true;
  }

  calcularMedia() {
    if (this.notas.length === 0) {
      return null;
    }

    const suma = this.notas.reduce(
      (total, nota) => total + nota,
      0
    );

    return suma / this.notas.length;
  }

  estaAprobado() {
    const media = this.calcularMedia();

    return media !== null && media >= 5;
  }
}

const alumno = new Alumno("Lucía", "DAW");

alumno.agregarNota(8);
alumno.agregarNota(7);
alumno.agregarNota(9);

console.log(alumno.notas);
// [8, 7, 9]

console.log(alumno.calcularMedia());
// 8

console.log(alumno.estaAprobado());
// true

La propiedad notas contiene un array, mientras que los métodos agregarNota(), calcularMedia() y estaAprobado() permiten trabajar con sus datos.

Ejemplo 3. Gestión de reservas

Vamos a crear una clase para representar las reservas de una aplicación web.

JavaScript 
class Reserva {
  static totalReservas = 0;

  constructor(cliente, precioNoche) {
    this.cliente = cliente;
    this.precioNoche = precioNoche;
    this.noches = 0;
    this.confirmada = false;

    Reserva.totalReservas++;
  }

  establecerNoches(noches) {
    if (!Number.isInteger(noches) || noches <= 0) {
      return false;
    }

    this.noches = noches;
    return true;
  }

  calcularTotal() {
    return this.precioNoche * this.noches;
  }

  confirmar() {
    if (this.noches <= 0) {
      return false;
    }

    this.confirmada = true;
    return true;
  }

  static consultarTotalReservas() {
    return Reserva.totalReservas;
  }
}

const reserva1 = new Reserva("Ana", 75);
const reserva2 = new Reserva("Luis", 90);

reserva1.establecerNoches(3);
reserva1.confirmar();

console.log(reserva1.calcularTotal());
// 225

console.log(reserva1.confirmada);
// true

console.log(reserva2.confirmada);
// false

console.log(Reserva.consultarTotalReservas());
// 2

Este ejemplo permite observar tres elementos:

  • Propiedades de instancia: cliente, precioNoche, noches y confirmada.
  • Métodos de instancia: establecerNoches(), calcularTotal() y confirmar().
  • Miembros estáticos: totalReservas y consultarTotalReservas().

Cada reserva mantiene sus propios datos, pero la clase también dispone de un contador común que registra cuántas instancias se han creado.

⚠️ Atención

En este ejemplo, el contador aumenta cuando se crea una instancia de Reserva, aunque todavía no se haya confirmado.

Por tanto, representa el número de objetos creados, no necesariamente el número de reservas confirmadas.

Resumen del apartado

En este apartado hemos profundizado en las propiedades y métodos de las clases de JavaScript.

  • Las propiedades de instancia almacenan los datos particulares de cada objeto.
  • Las propiedades pueden inicializarse dentro del constructor o mediante campos de instancia.
  • Las propiedades públicas pueden consultarse y modificarse desde fuera de la clase.
  • Los métodos de instancia permiten realizar operaciones relacionadas con los objetos.
  • Los métodos pueden recibir parámetros, devolver valores y modificar el estado de una instancia.
  • La palabra clave this permite acceder a las propiedades y métodos de la instancia correspondiente.
  • Los miembros estáticos pertenecen a la clase y se declaran mediante static.
  • Organizar los datos y sus operaciones dentro de una clase facilita la comprensión y el mantenimiento de los programas.
📌 Importante

La distinción fundamental es la siguiente: las propiedades describen el estado de los objetos y los métodos permiten trabajar con ese estado.

Además, debemos distinguir entre los elementos de instancia, que utilizamos mediante un objeto concreto, y los elementos estáticos, que utilizamos mediante la propia clase.

💭 Piensa

Queremos desarrollar una aplicación web para gestionar los libros de una biblioteca.

Cada libro debe almacenar su título, su autor y si está disponible para ser prestado.

Además, debe disponer de métodos para prestar y devolver el libro, evitando que se preste cuando ya está ocupado.

¿Cómo definirías una clase Libro que incluya estas propiedades y métodos?

¿Qué propiedades deberían pertenecer a cada instancia y qué métodos modificarían su estado?

Ver una posible solución
JavaScript 
class Libro {
  constructor(titulo, autor) {
    this.titulo = titulo;
    this.autor = autor;
    this.disponible = true;
  }

  prestar() {
    if (!this.disponible) {
      return false;
    }

    this.disponible = false;
    return true;
  }

  devolver() {
    if (this.disponible) {
      return false;
    }

    this.disponible = true;
    return true;
  }

  mostrarInformacion() {
    const estado = this.disponible
      ? "Disponible"
      : "Prestado";

    return `${this.titulo} - ${estado}`;
  }
}

const libro1 = new Libro(
  "Aprende JavaScript",
  "María López"
);

const libro2 = new Libro(
  "Desarrollo Web",
  "Carlos Pérez"
);

console.log(libro1.mostrarInformacion());
// Aprende JavaScript - Disponible

console.log(libro1.prestar());
// true

console.log(libro1.prestar());
// false

console.log(libro1.mostrarInformacion());
// Aprende JavaScript - Prestado

console.log(libro1.devolver());
// true

console.log(libro1.mostrarInformacion());
// Aprende JavaScript - Disponible

console.log(libro2.disponible);
// true

Hemos definido tres propiedades de instancia: titulo, autor y disponible.

Los métodos prestar() y devolver() modifican el estado del libro, mientras que mostrarInformacion() consulta sus datos y devuelve una cadena de texto.

Cada libro mantiene su propio estado. Por tanto, prestar libro1 no modifica la disponibilidad de libro2.
