6.3 Creación y manipulación de objetos

En los apartados anteriores hemos aprendido qué son los objetos en JavaScript y cómo podemos acceder a sus propiedades y métodos.

Ahora vamos a avanzar un paso más: aprenderemos a crear objetos de distintas formas y modificar su estructura durante la ejecución de un programa.

En una aplicación web, la información no siempre permanece igual. Por ejemplo, un usuario puede completar su perfil, un producto puede incorporar una nueva característica o una aplicación puede eliminar un dato que ya no necesita.

JavaScript permite realizar estas operaciones directamente sobre los objetos, sin necesidad de volver a crearlos desde cero.

📌 Importante

Los objetos ordinarios de JavaScript son estructuras dinámicas: podemos crear un objeto con determinadas propiedades y, posteriormente, añadir otras, modificar sus valores o eliminar algunas de ellas.

En este apartado trabajaremos con objetos sencillos. Más adelante aprenderemos a crear múltiples objetos mediante funciones constructoras y clases.

Objetos literales

La forma más habitual y sencilla de crear un objeto en JavaScript es mediante un literal de objeto.

Un literal de objeto se escribe utilizando llaves {}. Dentro de ellas incluimos las propiedades y sus valores, separados por comas.

JavaScript 
const alumno = {
  nombre: "Lucía",
  edad: 20,
  curso: "2º DAW",
  matriculado: true
};

console.log(alumno.nombre);
console.log(alumno.curso);

// Lucía
// 2º DAW

En este ejemplo hemos creado un objeto llamado alumno que contiene cuatro propiedades:

  • nombre: almacena una cadena de texto.
  • edad: almacena un número.
  • curso: almacena otra cadena.
  • matriculado: almacena un valor booleano.

Observa que los valores de las propiedades pueden ser de diferentes tipos. No es necesario que todas almacenen la misma clase de información.

Crear un objeto vacío

También podemos crear un objeto sin propiedades iniciales.

JavaScript 
const usuario = {};

console.log(usuario);

// {}

Aunque inicialmente esté vacío, sigue siendo un objeto válido. Más adelante podremos incorporar las propiedades que necesitemos.

Objetos con otros objetos

Una propiedad también puede almacenar otro objeto. Esto permite organizar información que tiene una estructura más compleja.

JavaScript 
const cliente = {
  nombre: "Carlos",
  email: "carlos@ejemplo.com",
  direccion: {
    ciudad: "Zaragoza",
    codigoPostal: "50001"
  }
};

console.log(cliente.nombre);
console.log(cliente.direccion.ciudad);

// Carlos
// Zaragoza

La propiedad direccion contiene un segundo objeto. Para consultar la ciudad accedemos primero a direccion y después a ciudad.

💻 Ejemplo DAW

En una aplicación de comercio electrónico, podríamos almacenar los datos de un pedido en un objeto y los datos de envío en otro objeto incluido dentro del primero.

Así evitamos crear muchas variables independientes y mantenemos relacionada la información que pertenece a una misma entidad.

Creación con Object

Además de utilizar literales, JavaScript permite crear objetos mediante Object.

Una de las formas posibles es utilizar new Object().

JavaScript 
const producto = new Object();

producto.nombre = "Monitor";
producto.precio = 189.99;
producto.stock = 8;

console.log(producto.nombre);
console.log(producto.precio);

// Monitor
// 189.99

En este caso, primero creamos un objeto vacío y después incorporamos sus propiedades mediante asignaciones.

El resultado es equivalente, para este ejemplo, al de crear el objeto directamente con un literal:

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 189.99,
  stock: 8
};

¿Qué forma debemos utilizar?

Para crear objetos sencillos, normalmente se recomienda utilizar la notación literal, porque resulta más breve, clara y fácil de leer.

Forma Ejemplo Uso habitual
Literal const obj = {}; Opción habitual para crear objetos sencillos.
Object const obj = new Object(); Alternativa válida, aunque menos utilizada para este caso.
⚠️ Atención

new Object() permite crear un objeto, pero no debemos confundir esta operación con las funciones constructoras personalizadas que estudiaremos en el apartado 6.6.

En aquel apartado aprenderemos a definir nuestros propios modelos para crear múltiples objetos con una estructura común.

Añadir propiedades

Una de las características más útiles de los objetos de JavaScript es que podemos incorporar propiedades después de haberlos creado.

Para hacerlo, asignamos un valor a una propiedad que todavía no existe.

Añadir propiedades con el punto

JavaScript 
const usuario = {
  nombre: "Ana",
  edad: 22
};

usuario.email = "ana@ejemplo.com";

console.log(usuario);

// {
//   nombre: "Ana",
//   edad: 22,
//   email: "ana@ejemplo.com"
// }

Inicialmente, el objeto tenía dos propiedades: nombre y edad.

Al ejecutar la asignación usuario.email = "ana@ejemplo.com", JavaScript incorpora la propiedad email al objeto.

Añadir propiedades con corchetes

También podemos utilizar la notación de corchetes que estudiamos en el 6.2.

JavaScript 
const producto = {
  nombre: "Teclado"
};

producto["precio"] = 45;
producto["en oferta"] = true;

console.log(producto.precio);
console.log(producto["en oferta"]);

// 45
// true

La notación de corchetes resulta especialmente útil cuando el nombre de la propiedad contiene espacios o se obtiene a partir de una variable.

Añadir una propiedad con nombre dinámico

Imagina que una aplicación recibe el nombre de una característica y necesita guardarla en un objeto.

JavaScript 
const configuracion = {
  idioma: "es"
};

const nuevaPropiedad = "tema";

configuracion[nuevaPropiedad] = "oscuro";

console.log(configuracion.tema);

// oscuro

Como nuevaPropiedad contiene el texto "tema", JavaScript crea una propiedad con ese nombre.

Si hubiéramos escrito configuracion.nuevaPropiedad, estaríamos utilizando literalmente el nombre nuevaPropiedad, no el valor almacenado en la variable.

📌 Importante

Al asignar un valor mediante objeto.propiedad = valor, pueden suceder dos cosas:

  • Si la propiedad no existe, se añade al objeto.
  • Si la propiedad ya existe y permite escritura, se actualiza su valor.

En nuestros ejemplos trabajamos con propiedades ordinarias que permiten estas operaciones.

Añadir propiedades a un objeto declarado con const

Recordemos una diferencia importante: declarar un objeto con const no significa que sus propiedades sean inmutables.

JavaScript 
const empleado = {
  nombre: "Marta"
};

empleado.departamento = "Informática";
empleado.nombre = "Marta López";

console.log(empleado);

// {
//   nombre: "Marta López",
//   departamento: "Informática"
// }

Las operaciones anteriores son válidas porque no estamos asignando un nuevo objeto a la variable empleado. Estamos modificando el objeto existente.

Eliminar propiedades

En determinadas situaciones puede ser necesario quitar una propiedad de un objeto.

Para ello, JavaScript dispone del operador delete.

Uso básico de delete

JavaScript 
const usuario = {
  nombre: "Pablo",
  edad: 25,
  telefono: "600123456"
};

delete usuario.telefono;

console.log(usuario);

// {
//   nombre: "Pablo",
//   edad: 25
// }

El operador delete elimina la propiedad telefono del objeto.

Si intentamos consultar posteriormente esa propiedad, obtendremos undefined.

JavaScript 
const usuario = {
  nombre: "Pablo",
  telefono: "600123456"
};

delete usuario.telefono;

console.log(usuario.telefono);

// undefined

Eliminar mediante corchetes

El operador también funciona con la notación de corchetes.

JavaScript 
const producto = {
  nombre: "Ratón",
  precio: 19.99,
  descuento: 10
};

const propiedad = "descuento";

delete producto[propiedad];

console.log(producto);

// {
//   nombre: "Ratón",
//   precio: 19.99
// }

En este caso, el nombre de la propiedad que queremos eliminar se encuentra almacenado en una variable.

Eliminar no es lo mismo que asignar undefined

Esta diferencia es importante y puede producir confusiones.

JavaScript 
const alumno = {
  nombre: "Elena",
  telefono: "600111222"
};

alumno.telefono = undefined;

console.log("telefono" in alumno);

// true

Aunque ahora la propiedad contiene undefined, sigue existiendo dentro del objeto.

En cambio, si utilizamos delete, la propiedad deja de existir.

JavaScript 
const alumno = {
  nombre: "Elena",
  telefono: "600111222"
};

delete alumno.telefono;

console.log("telefono" in alumno);

// false
⚠️ Atención

delete elimina una propiedad del objeto, no una variable declarada con let o const.

Además, no todas las propiedades de JavaScript pueden eliminarse: algunas están definidas como no configurables. En nuestros ejemplos utilizamos propiedades ordinarias creadas por nosotros.

Comprobar propiedades

Antes de utilizar una propiedad, puede resultar conveniente comprobar si existe dentro de un objeto.

Esta operación es habitual cuando trabajamos con formularios, perfiles de usuario o datos que pueden contener campos opcionales.

El operador in

El operador in permite comprobar si una propiedad existe en un objeto o en su cadena de prototipos.

Su sintaxis es:

JavaScript 
"nombrePropiedad" in objeto

El resultado será true si la propiedad existe y false si no existe.

JavaScript 
const producto = {
  nombre: "Impresora",
  precio: 120
};

console.log("nombre" in producto);
console.log("stock" in producto);

// true
// false

La propiedad nombre existe, mientras que stock todavía no se ha definido.

Comprobar propiedades propias con Object.hasOwn()

Existe otra operación especialmente útil: Object.hasOwn().

Este método comprueba si una propiedad pertenece directamente al objeto, sin considerar las propiedades que pudiera heredar.

JavaScript 
const alumno = {
  nombre: "Raúl",
  nota: 8
};

console.log(Object.hasOwn(alumno, "nombre"));
console.log(Object.hasOwn(alumno, "email"));

// true
// false

En este ejemplo, nombre es una propiedad propia de alumno, pero email no existe.

Diferencia entre in y Object.hasOwn()

Ambos permiten comprobar propiedades, pero no responden exactamente a la misma pregunta.

Operación Qué comprueba
"x" in objeto Si la propiedad existe en el objeto o en su cadena de prototipos.
Object.hasOwn(objeto, "x") Si la propiedad pertenece directamente al objeto.

Por ahora nos interesa comprender esta distinción básica. Estudiaremos la herencia más adelante, cuando trabajemos con clases.

📌 Importante

No debemos utilizar siempre objeto.propiedad !== undefined para determinar si una propiedad existe.

Una propiedad puede existir y contener precisamente el valor undefined.

Cuando necesitamos comprobar su existencia, resulta más apropiado utilizar in o Object.hasOwn(), según lo que queramos averiguar.

Comprobación antes de añadir una propiedad

Podemos combinar una condición con la comprobación de propiedades para evitar sobrescribir información.

JavaScript 
const usuario = {
  nombre: "Sofía"
};

if (!Object.hasOwn(usuario, "email")) {
  usuario.email = "sin-email@ejemplo.com";
}

console.log(usuario.email);

// sin-email@ejemplo.com

El programa comprueba primero si existe la propiedad email. Como no existe, incorpora un valor inicial.

Referencias a objetos

Hasta ahora hemos trabajado con objetos mediante variables. Sin embargo, es importante comprender qué ocurre cuando asignamos un objeto a otra variable.

En JavaScript, los objetos se manejan mediante referencias. Esto significa que una variable que contiene un objeto permite acceder a ese objeto, pero no almacena una copia independiente de todas sus propiedades.

Dos variables que hacen referencia al mismo objeto

Observa el siguiente ejemplo:

JavaScript 
const producto1 = {
  nombre: "Portátil",
  precio: 850
};

const producto2 = producto1;

producto2.precio = 799;

console.log(producto1.precio);
console.log(producto2.precio);

// 799
// 799

Aunque utilizamos dos variables, ambas hacen referencia al mismo objeto.

Por eso, al modificar el precio mediante producto2, también observamos el cambio cuando accedemos a través de producto1.

⚠️ Atención

La asignación const producto2 = producto1 no crea un objeto nuevo.

Únicamente hace que ambas variables permitan acceder al mismo objeto. Este comportamiento puede provocar errores si pensamos que estamos trabajando con copias independientes.

Comparación entre objetos

Dos objetos diferentes pueden tener las mismas propiedades y valores sin ser el mismo objeto.

JavaScript 
const alumno1 = {
  nombre: "Laura"
};

const alumno2 = {
  nombre: "Laura"
};

console.log(alumno1 === alumno2);

// false

Aunque los dos objetos contienen exactamente el mismo nombre, se han creado por separado.

Por tanto, sus referencias son diferentes y la comparación mediante === devuelve false.

En cambio, si dos variables apuntan al mismo objeto, la comparación será verdadera.

JavaScript 
const alumno1 = {
  nombre: "Laura"
};

const alumno2 = alumno1;

console.log(alumno1 === alumno2);

// true

Crear una copia superficial con el operador spread

Si queremos obtener un nuevo objeto con las propiedades de otro, podemos utilizar el operador de propagación ..., también conocido como spread.

JavaScript 
const productoOriginal = {
  nombre: "Tablet",
  precio: 250
};

const productoCopia = {
  ...productoOriginal
};

productoCopia.precio = 220;

console.log(productoOriginal.precio);
console.log(productoCopia.precio);

// 250
// 220

Ahora sí hemos creado dos objetos diferentes. Por eso, modificar la propiedad precio de la copia no altera la del objeto original.

Sin embargo, debemos tener en cuenta una limitación importante.

Las copias superficiales y los objetos anidados

El operador spread realiza una copia superficial. Copia las propiedades del primer nivel, pero no duplica automáticamente los objetos que puedan existir dentro de ellas.

JavaScript 
const clienteOriginal = {
  nombre: "Ana",
  direccion: {
    ciudad: "Huesca"
  }
};

const clienteCopia = {
  ...clienteOriginal
};

clienteCopia.direccion.ciudad = "Teruel";

console.log(clienteOriginal.direccion.ciudad);
console.log(clienteCopia.direccion.ciudad);

// Teruel
// Teruel

La copia es un objeto nuevo, pero su propiedad direccion sigue haciendo referencia al mismo objeto anidado que utiliza clienteOriginal.

Por tanto, cambiar la ciudad afecta a ambos.

📌 Importante

Debemos distinguir entre:

  • Asignar un objeto a otra variable: ambas variables hacen referencia al mismo objeto.
  • Crear una copia superficial: obtenemos un objeto nuevo, pero sus propiedades que contienen otros objetos pueden seguir compartiendo referencias.

Esta diferencia es especialmente importante cuando trabajamos con datos anidados.

Ejemplos prácticos

Vamos a aplicar las operaciones estudiadas en situaciones relacionadas con el desarrollo de aplicaciones web.

⚠️ Atención

Los ejemplos siguientes son independientes. Puedes ejecutarlos por separado en la consola del navegador o en archivos JavaScript diferentes.

Si los reúnes en un mismo ámbito, recuerda que no puedes declarar varias veces una variable con el mismo nombre utilizando const.

Ejemplo 1. Completar un perfil de usuario

Imagina que estamos desarrollando una aplicación web en la que los usuarios pueden completar su perfil progresivamente.

Inicialmente solo conocemos su nombre y correo electrónico. Posteriormente, el usuario añade su ciudad y número de teléfono.

JavaScript 
const usuario = {
  nombre: "David",
  email: "david@ejemplo.com"
};

// Añadimos nuevos datos
usuario.ciudad = "Alcañiz";
usuario.telefono = "600123456";

// Actualizamos un dato existente
usuario.email = "david.nuevo@ejemplo.com";

console.log(usuario);

// {
//   nombre: "David",
//   email: "david.nuevo@ejemplo.com",
//   ciudad: "Alcañiz",
//   telefono: "600123456"
// }

En este ejemplo realizamos dos operaciones distintas:

  1. Añadimos propiedades que inicialmente no existían.
  2. Modificamos el valor de una propiedad existente.

El objeto evoluciona a medida que el usuario completa su información.

Ejemplo 2. Eliminar un dato opcional

Supongamos que una aplicación permite almacenar un teléfono de contacto, pero este dato es opcional.

Si el usuario decide retirarlo, podemos eliminar la propiedad.

JavaScript 
const perfil = {
  nombre: "Sara",
  email: "sara@ejemplo.com",
  telefono: "600222333"
};

if (Object.hasOwn(perfil, "telefono")) {
  delete perfil.telefono;
}

console.log(perfil);

// {
//   nombre: "Sara",
//   email: "sara@ejemplo.com"
// }

Primero comprobamos que la propiedad existe y después la eliminamos.

La comprobación previa no es imprescindible para eliminar una propiedad ordinaria, pero nos permite practicar ambas operaciones de manera conjunta.

Ejemplo 3. Incorporar características a un producto

En una tienda online, algunos productos pueden tener características adicionales que otros no necesitan.

Por ejemplo, un portátil puede incluir información sobre su memoria RAM y su almacenamiento.

JavaScript 
const producto = {
  nombre: "Portátil",
  precio: 899
};

const caracteristicas = {
  ram: "16 GB",
  almacenamiento: "512 GB SSD"
};

producto.ram = caracteristicas.ram;
producto.almacenamiento = caracteristicas.almacenamiento;

console.log(producto);

// {
//   nombre: "Portátil",
//   precio: 899,
//   ram: "16 GB",
//   almacenamiento: "512 GB SSD"
// }

Hemos ampliado la información de un objeto existente sin tener que crearlo nuevamente.

💻 Ejemplo DAW

Esta forma de trabajar resulta útil cuando una aplicación recibe datos desde un formulario. Podemos comenzar con un objeto que contenga los campos obligatorios e incorporar otros campos cuando el usuario los complete.

Ejemplo 4. Crear una versión modificada de un producto

En ocasiones necesitamos generar una versión modificada de un producto sin alterar sus datos originales.

Podemos crear una copia superficial y cambiar únicamente los valores necesarios.

JavaScript 
const producto = {
  id: 15,
  nombre: "Auriculares",
  precio: 60,
  stock: 12
};

const productoOferta = {
  ...producto,
  precio: 48,
  enOferta: true
};

console.log(producto.precio);
console.log(productoOferta.precio);
console.log(productoOferta.enOferta);

// 60
// 48
// true

El objeto productoOferta contiene las propiedades originales, pero con un precio diferente y una nueva propiedad que indica que está en oferta.

El producto original mantiene su precio de 60 euros.

Observa que también podemos utilizar el operador spread dentro de un literal que incorpora propiedades adicionales.

Ejemplo 5. Gestionar los datos de un pedido

Vamos a construir un ejemplo un poco más completo en el que combinaremos varias de las operaciones estudiadas.

Imagina que estamos desarrollando una aplicación de gestión de pedidos. Inicialmente, el pedido contiene un identificador, un cliente y un importe.

Posteriormente, añadiremos el estado del pedido, incorporaremos una dirección de envío y comprobaremos si existe un descuento.

JavaScript 
const pedido = {
  id: 105,
  cliente: "María",
  importe: 249.99
};

// Añadimos el estado inicial
pedido.estado = "Pendiente";

// Añadimos una dirección de envío
pedido.direccion = {
  ciudad: "Zaragoza",
  codigoPostal: "50001"
};

// Comprobamos si existe un descuento propio
if (!Object.hasOwn(pedido, "descuento")) {
  pedido.descuento = 0;
}

// Actualizamos el estado
pedido.estado = "Preparando envío";

// Mostramos información
console.log(pedido.cliente);
console.log(pedido.estado);
console.log(pedido.direccion.ciudad);
console.log(pedido.descuento);

// María
// Preparando envío
// Zaragoza
// 0

Analicemos lo que hace el programa:

  1. Crea un objeto literal con los datos iniciales del pedido.
  2. Añade una propiedad estado.
  3. Incorpora una propiedad direccion que contiene otro objeto.
  4. Comprueba si existe una propiedad propia llamada descuento.
  5. Como no existe, le asigna el valor inicial 0.
  6. Actualiza el estado del pedido.
  7. Consulta distintas propiedades para mostrar la información.

Este ejemplo muestra cómo un objeto puede modificarse durante el funcionamiento de una aplicación web.

📌 Importante

La creación y manipulación de objetos nos permite representar información que cambia a lo largo de la ejecución del programa.

En aplicaciones reales, estas operaciones suelen realizarse como respuesta a acciones del usuario o a datos recibidos desde otros componentes de la aplicación.

💭 Piensa

Imagina que estás desarrollando una aplicación web para gestionar las reservas de habitaciones de un hotel.

Cada habitación tiene un número, un tipo, un precio por noche y un estado que indica si está disponible.

Durante el funcionamiento de la aplicación pueden producirse diferentes cambios: se incorpora una descripción, se elimina un dato opcional y se crea una versión modificada de la habitación para mostrar una oferta.

Responde a las siguientes preguntas:

  1. ¿Cómo crearías un objeto literal llamado habitacion con las propiedades numero, tipo, precio y disponible?
  2. ¿Cómo añadirías una propiedad descripcion después de crear el objeto?
  3. ¿Cómo comprobarías si habitacion tiene una propiedad propia llamada descuento?
  4. ¿Qué instrucción utilizarías para eliminar la propiedad descripcion?
  5. ¿Cómo crearías un nuevo objeto habitacionOferta a partir de habitacion, con un precio diferente, sin modificar el objeto original?
  6. ¿Qué ocurriría si escribieras const otraHabitacion = habitacion; y después modificaras otraHabitacion.precio?
Ver una posible solución

Una posible solución sería la siguiente:

JavaScript 
// 1. Crear el objeto
const habitacion = {
  numero: 203,
  tipo: "Doble",
  precio: 90,
  disponible: true
};

// 2. Añadir una propiedad
habitacion.descripcion = "Vistas al jardín";

// 3. Comprobar una propiedad propia
console.log(
  Object.hasOwn(habitacion, "descuento")
);

// false

// 4. Eliminar una propiedad
delete habitacion.descripcion;

// 5. Crear una copia superficial
const habitacionOferta = {
  ...habitacion,
  precio: 75
};

console.log(habitacion.precio);
console.log(habitacionOferta.precio);

// 90
// 75

// 6. Compartir la misma referencia
const otraHabitacion = habitacion;

otraHabitacion.precio = 100;

console.log(habitacion.precio);

// 100

En la quinta operación utilizamos el operador spread para crear un nuevo objeto. Como precio es un número, modificar su valor en la copia no afecta al original.

En la sexta operación, otraHabitacion y habitacion hacen referencia al mismo objeto. Por eso, modificar el precio mediante una de las variables también afecta al valor consultado mediante la otra.
