✏️ Resumen de la UT6

En esta unidad hemos aprendido a trabajar con objetos en JavaScript para representar datos y comportamientos relacionados, así como a crear y utilizar clases para organizar nuestros programas.

Hemos estudiado las propiedades, los métodos, la palabra clave this, las funciones constructoras, la encapsulación, la abstracción, la herencia y las relaciones entre objetos.

Este resumen recoge las ideas fundamentales de los apartados 6.1 a 6.11, con ejemplos breves y recordatorios para repasar antes de las actividades y la evaluación.

📌 Idea principal

Un objeto agrupa datos y operaciones relacionadas. Las clases permiten definir una estructura común para crear múltiples objetos.

6.1 Introducción a los objetos en JavaScript

Un objeto es una estructura que agrupa información mediante propiedades y puede incorporar funciones llamadas métodos.

📦Objeto

Representa una entidad mediante pares propiedad–valor.

🏷️Propiedad

Almacena un dato asociado al objeto.

⚙️Método

Es una función asociada a un objeto.

JavaScript — Objeto literal
const alumno = {\n  nombre: "Lucía",\n  edad: 20\n};\n\nconsole.log(alumno.nombre); // Lucía
📌 Recuerda

Un objeto puede contener propiedades de diferentes tipos, incluidos otros objetos y funciones.

6.2 Propiedades y métodos de los objetos

Accedemos a las propiedades mediante la notación de punto o la notación de corchetes. Para ejecutar un método, debemos invocarlo con paréntesis.

Notación de puntoobjeto.propiedad: útil cuando conocemos el nombre.
Notación de corchetesobjeto[clave]: permite utilizar nombres dinámicos.
Métodoobjeto.metodo(): ejecuta una función asociada al objeto.
Propiedad y métodoConsultar un valor no es lo mismo que invocar una función.
JavaScript — Acceso a propiedades y métodos
const producto = {\n  nombre: "Teclado",\n  precio: 35,\n  mostrarPrecio() {\n    return this.precio + " €";\n  }\n};\n\nconsole.log(producto["nombre"]);\nconsole.log(producto.mostrarPrecio());
⚠️ Atención

producto.mostrarPrecio hace referencia a la función; producto.mostrarPrecio() la ejecuta.

6.3 Creación y manipulación de objetos

Podemos crear objetos con la sintaxis literal {} y añadir, modificar o eliminar propiedades según las necesidades del programa.

JavaScript — Modificar un objeto
const libro = { titulo: "JavaScript" };\nlibro.paginas = 250;\nlibro.paginas = 280;\ndelete libro.paginas;\n\nconsole.log(libro.titulo);
📌 Recuerda

Declarar un objeto con const impide reasignar la variable, pero no convierte automáticamente sus propiedades en inmutables.

6.4 Recorrido de propiedades de objetos

Para examinar el contenido de un objeto podemos utilizar for...in, Object.keys(), Object.values() y Object.entries().

Object.keys()Devuelve un array con los nombres de las propiedades propias enumerables.
Object.values()Devuelve sus valores.
Object.entries()Devuelve pares [clave, valor].
for...inRecorre propiedades enumerables, incluidas las heredadas.
JavaScript — Recorrer entradas
const notas = { dwec: 8 };\nnotas.diw = 9;\n\nfor (const [modulo, nota] of Object.entries(notas)) {\n  console.log(modulo, nota);\n}
⚠️ Atención

Con for...in conviene comprobar si una propiedad pertenece al propio objeto mediante Object.hasOwn() cuando no deseamos recorrer propiedades heredadas.

6.5 Métodos y palabra clave this

En una llamada como objeto.metodo(), this normalmente hace referencia al objeto que realiza la llamada. Su valor depende de cómo se invoca la función.

JavaScript — this dentro de un método
const cuenta = {\n  titular: "Ana",\n  saldo: 100,\n  mostrarSaldo() {\n    return `${this.titular}: ${this.saldo} €`;\n  }\n};\n\nconsole.log(cuenta.mostrarSaldo());
⚠️ Atención

Las funciones flecha no tienen un this propio; por ello, no suelen ser adecuadas como métodos cuando necesitamos que this señale al objeto receptor.

6.6 Funciones constructoras y creación de instancias

Una función constructora permite crear varios objetos con una estructura semejante utilizando el operador new.

JavaScript — Función constructora
function Alumno(nombre, curso) {\n  this.nombre = nombre;\n  this.curso = curso;\n}\n\nconst a1 = new Alumno("Eva", "DAW");\nconst a2 = new Alumno("Pablo", "DAW");\n\nconsole.log(a1.nombre);
📌 Recuerda

Cada llamada a new Alumno(...) crea una instancia distinta.

6.7 Introducción a las clases en JavaScript

La sintaxis class permite definir clases de forma clara. El método constructor inicializa los datos de cada instancia.

JavaScript — Definir una clase
class Alumno {\n  constructor(nombre) {\n    this.nombre = nombre;\n  }\n\n  saludar() {\n    return `Hola, soy ${this.nombre}`;\n  }\n}\n\nconst alumno = new Alumno("Lucía");\nconsole.log(alumno.saludar());
📌 Recuerda

Una clase actúa como definición común; los objetos creados con new son sus instancias.

6.8 Propiedades y métodos de las clases

Las clases pueden definir datos y comportamientos de instancia. También permiten distinguir entre miembros públicos, privados y estáticos.

Propiedades de instanciaCada objeto conserva sus propios datos.
Métodos de instanciaSe invocan sobre un objeto creado a partir de la clase.
Miembros privadosLa sintaxis #nombre limita el acceso desde fuera de la clase.
Miembros estáticosSe consultan mediante el nombre de la clase, no desde una instancia.
JavaScript — Propiedad privada
class Contador {\n  #valor = 0;\n\n  incrementar() {\n    this.#valor++;\n  }\n\n  consultar() {\n    return this.#valor;\n  }\n}\n\nconst contador = new Contador();\ncontador.incrementar();\nconsole.log(contador.consultar()); // 1
⚠️ Atención

Una propiedad privada declarada con # no puede consultarse directamente desde fuera de la clase.

6.9 Principios de la Programación Orientada a Objetos

La Programación Orientada a Objetos (POO) organiza el software alrededor de entidades con datos y comportamientos.

🧩Abstracción

Representa lo esencial de una entidad y evita detalles innecesarios.

🔒Encapsulación

Agrupa estado y comportamiento, controlando cómo se accede a los datos.

🌳Herencia

Permite especializar clases a partir de otras.

📌 Recuerda

La POO busca repartir responsabilidades entre objetos de forma comprensible y mantenible.

6.10 Herencia básica entre clases

Con extends podemos crear una clase derivada a partir de una clase base. super() permite invocar el constructor de la clase padre.

JavaScript — Herencia con extends
class Empleado {\n  constructor(nombre) {\n    this.nombre = nombre;\n  }\n\n  presentarse() {\n    return `Soy ${this.nombre}`;\n  }\n}\n\nclass Desarrollador extends Empleado {\n  constructor(nombre, lenguaje) {\n    super(nombre);\n    this.lenguaje = lenguaje;\n  }\n}\n\nconst dev = new Desarrollador("Ana", "JavaScript");\nconsole.log(dev.presentarse());
⚠️ Atención

En una clase derivada, cuando definimos un constructor debemos llamar a super() antes de utilizar this.

6.11 Organización de programas mediante objetos y clases

Antes de programar conviene identificar las entidades del problema, las responsabilidades de cada clase y las relaciones entre objetos. Una aplicación puede utilizar composición y colecciones de objetos para organizar su información.

ResponsabilidadCada clase debe tener un propósito definido.
ComposiciónUn objeto contiene o utiliza otros objetos para cumplir su función.
ColeccionesLos arrays permiten gestionar múltiples instancias.
SeparaciónDistinguir modelos, reglas de negocio y presentación facilita el mantenimiento.
JavaScript — Objetos que colaboran
class Producto {\n  constructor(nombre, precio) {\n    this.nombre = nombre;\n    this.precio = precio;\n  }\n}\n\nclass Pedido {\n  constructor() {\n    this.productos = [];\n  }\n\n  agregar(producto) {\n    this.productos.push(producto);\n  }\n\n  total() {\n    return this.productos.reduce((suma, p) => suma + p.precio, 0);\n  }\n}\n\nconst pedido = new Pedido();\npedido.agregar(new Producto("Ratón", 20));\nconsole.log(pedido.total()); // 20
💻 Aplicación al desarrollo web

En un sistema de matrículas podemos utilizar clases como Alumno, Modulo, Matricula y GestorMatriculas, asignando a cada una una responsabilidad concreta.

Ideas clave de la UT6

📌 Si tuvieras que recordar solo estas ideas…
  • Un objeto reúne propiedades y métodos relacionados.
  • La notación de punto y la de corchetes permiten acceder a propiedades.
  • Podemos crear, modificar, eliminar y recorrer propiedades de los objetos.
  • El valor de this depende de la forma en que se invoca una función.
  • Las funciones constructoras y las clases permiten crear instancias.
  • constructor inicializa cada instancia; los métodos definen comportamientos.
  • La encapsulación y la abstracción ayudan a controlar la complejidad.
  • extends establece herencia y super() permite acceder al constructor padre.
  • La composición y las colecciones facilitan la colaboración entre objetos.
  • Asignar responsabilidades claras a cada clase mejora la organización del programa.
