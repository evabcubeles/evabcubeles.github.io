UT7 - Objetos predefinidos y modelo del navegador (BOM)

En las unidades anteriores hemos aprendido a desarrollar programas en JavaScript utilizando variables, operadores, estructuras de control, arrays, funciones y objetos. En la UT6 hemos estudiado cómo crear nuestros propios objetos y clases para representar entidades de una aplicación y organizar sus responsabilidades. Sin embargo, JavaScript también proporciona objetos y funcionalidades ya definidos que podemos utilizar directamente para resolver numerosas tareas habituales de programación.

En esta unidad aprenderemos a utilizar los objetos predefinidos de JavaScript, que ofrecen propiedades y métodos para trabajar con cadenas de texto, números, operaciones matemáticas, fechas y patrones de búsqueda. Estudiaremos objetos como String, Number, Math, Date y RegExp, así como el objeto JSON, que permite convertir información entre objetos JavaScript y representaciones de texto estructurado.

Comenzaremos utilizando los métodos de String para buscar, extraer y transformar información textual. Después conoceremos las herramientas de Number y Math para realizar operaciones numéricas, redondear resultados y generar valores aleatorios. También aprenderemos a trabajar con fechas mediante Date, realizando consultas, comparaciones y operaciones habituales en aplicaciones como sistemas de reservas, calendarios o gestión de pedidos.

A continuación, estudiaremos las expresiones regulares, que permiten identificar patrones dentro de cadenas de texto, y conoceremos las posibilidades de JSON para representar e intercambiar información. Estos conocimientos resultarán especialmente útiles cuando necesitemos procesar datos, almacenarlos o comunicarlos entre diferentes partes de una aplicación web.

En la segunda parte de la unidad nos introduciremos en el Browser Object Model (BOM), o modelo de objetos del navegador. El BOM proporciona acceso a determinadas características del entorno en el que se ejecuta una página web, como la ventana, la dirección actual, el historial de navegación, la información del navegador y las características de la pantalla. Aprenderemos a utilizar objetos como window, location, history, navigator y screen.

También estudiaremos cómo gestionar ventanas y temporizadores mediante métodos como window.open(), setTimeout() y setInterval(), teniendo en cuenta las restricciones de seguridad de los navegadores actuales. Además, aprenderemos a guardar y recuperar información en el navegador utilizando localStorage, sessionStorage y los mecanismos básicos de las cookies.

Finalmente, integraremos los conocimientos adquiridos en pequeños programas relacionados con el desarrollo web, como la gestión de preferencias de usuario, el procesamiento de datos y la navegación entre páginas. Prestaremos especial atención a la organización del código, la documentación, las pruebas y la depuración, así como al uso adecuado de las funcionalidades del navegador.

Esta unidad servirá como preparación para la UT8, en la que aprenderemos a crear aplicaciones web interactivas mediante el DOM, los eventos y los formularios. De esta forma, distinguiremos las funcionalidades generales del navegador de las operaciones que permiten acceder y modificar directamente el contenido de una página HTML.
