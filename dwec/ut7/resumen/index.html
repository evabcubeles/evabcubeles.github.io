✏️ Resumen de la UT7

En esta unidad hemos estudiado los objetos predefinidos de JavaScript y el modelo de objetos del navegador (BOM), herramientas que permiten procesar información e interactuar con el entorno de una página web.

Hemos trabajado con cadenas, números, cálculos, fechas, expresiones regulares y JSON, además de explorar ventanas, diálogos, temporizadores, navegación, historial y almacenamiento.

Este resumen reúne las ideas fundamentales de los apartados 7.1 a 7.14, con ejemplos breves y recordatorios para repasar antes de las actividades y la evaluación.

📌 Idea principal

Los objetos predefinidos facilitan operaciones habituales. El BOM permite interactuar con el entorno del navegador, sus ventanas y servicios.

7.1 Introducción a los objetos predefinidos de JavaScript

JavaScript proporciona objetos y funcionalidades incorporadas para realizar tareas habituales sin programarlas desde cero. Algunos, como Math o JSON, se utilizan directamente; otros, como Date, permiten crear instancias.

Objetos nativosForman parte del lenguaje JavaScript y no dependen de una página web.
Objetos del navegadorOfrecen acceso a funciones y características del entorno donde se ejecuta la página.
PropiedadesPermiten consultar información.
MétodosPermiten realizar operaciones mediante llamadas con paréntesis.
⚠️ Atención

No todos los objetos predefinidos se crean con new: por ejemplo, Math.random() y JSON.parse() se invocan directamente.

7.2 Objetos String y Number

String ofrece métodos para consultar y transformar cadenas; Number facilita la comprobación y el formato de valores numéricos.

trim()Elimina espacios al principio y al final.
toUpperCase()Convierte el texto a mayúsculas.
includes()Comprueba si una cadena contiene otra.
Number.isFinite()Comprueba si un valor es un número finito.
JavaScript — Texto y conversión numérica
const nombre = "  Ana  ".trim();
const precio = Number("19.95");

console.log(nombre.toUpperCase()); // ANA
console.log(Number.isFinite(precio)); // true
⚠️ Atención

Number("hola") devuelve NaN. Comprueba el resultado antes de utilizarlo en cálculos.

7.3 Objeto Math

El objeto Math agrupa constantes y operaciones matemáticas, como redondeos, potencias, valores máximos y números pseudoaleatorios.

JavaScript — Redondeo y número aleatorio
const precio = 18.75;
console.log(Math.round(precio)); // 19
console.log(Math.floor(precio)); // 18

const dado = Math.floor(Math.random() * 6) + 1;
console.log(dado); // Entero entre 1 y 6
📌 Recuerda

Math.random() devuelve un número desde 0 (incluido) hasta 1 (excluido).

7.4 Objeto Date

Date permite crear fechas, consultar sus componentes, modificarlas y comparar instantes mediante sus valores temporales.

JavaScript — Fechas y diferencias
const hoy = new Date();
const entrega = new Date(hoy.getTime() + 5 * 24 * 60 * 60 * 1000);

const diferencia = entrega.getTime() - hoy.getTime();
const dias = Math.ceil(diferencia / (1000 * 60 * 60 * 24));

console.log(dias); // 5
⚠️ Atención

Al construir fechas con new Date(año, mes, día), los meses se numeran del 0 al 11.

7.5 Objeto RegExp y expresiones regulares

Las expresiones regulares describen patrones para buscar o validar textos. El método test() indica si una cadena coincide con un patrón.

JavaScript — Validar un código de pedido
const patron = /^PED-\d{4}$/;

console.log(patron.test("PED-0123")); // true
console.log(patron.test("PED-12"));   // false
^ y $Marcan el inicio y el final de la cadena.
\dRepresenta un dígito.
{4}Exige cuatro repeticiones del elemento anterior.
iEs una bandera que permite ignorar mayúsculas y minúsculas.

7.6 Objeto JSON y conversión de datos

JSON es un formato de texto para intercambiar y guardar datos estructurados. JSON.stringify() convierte un valor JavaScript a texto JSON y JSON.parse() realiza la operación inversa.

JavaScript — Convertir datos a JSON y recuperarlos
const pedido = { codigo: "PED-0123", total: 45 };
const texto = JSON.stringify(pedido);
const recuperado = JSON.parse(texto);

console.log(recuperado.codigo); // PED-0123
⚠️ Atención

JSON no es lo mismo que un objeto JavaScript. JSON.parse() puede lanzar un error si el texto no tiene un formato JSON válido.

7.7 Introducción al BOM: estructura y características

El Browser Object Model (BOM) reúne objetos proporcionados por el navegador para consultar su entorno y controlar aspectos de la ventana o la navegación. window es el objeto global de una página web en el contexto habitual del navegador.

windowVentana y funciones generales del navegador.
navigatorInformación y capacidades del navegador.
screenCaracterísticas de la pantalla.
location y historyDirección actual e historial de navegación.
📌 Recuerda

El BOM no es el DOM: el BOM se relaciona con el navegador; el DOM representa la estructura del documento HTML.

7.8 Objeto window

window permite consultar propiedades de la ventana y acceder a funciones globales. En una página web, window.innerWidth indica el ancho interior de la ventana gráfica.

JavaScript — Consultar la ventana
console.log(window.innerWidth);
console.log(window.innerHeight);
console.log(window.location.href);
📌 Recuerda

En el navegador, algunas funciones globales pueden utilizarse con o sin el prefijo window.

7.9 Ventanas de diálogo y temporizadores

Los diálogos básicos permiten informar, pedir datos y solicitar confirmación. Los temporizadores ejecutan funciones después de una espera o a intervalos.

alert()Muestra un mensaje.
prompt()Solicita texto; puede devolver null.
confirm()Devuelve true o false.
setTimeout() y setInterval()Programan ejecuciones diferidas o periódicas.
JavaScript — Temporizador sencillo
const identificador = setTimeout(() => {
  console.log("Han pasado dos segundos");
}, 2000);

// clearTimeout(identificador) lo cancelaría.
⚠️ Atención

Los temporizadores no detienen el resto del programa. setInterval() se cancela con clearInterval().

7.10 Objeto location y navegación

El objeto location describe la dirección de la página actual y permite navegar a otras direcciones. La propiedad search contiene la parte de consulta de la URL.

JavaScript — Leer parámetros de la URL
// URL de ejemplo: pagina.html?pedido=PED-0123
const parametros = new URLSearchParams(location.search);
const codigo = parametros.get("pedido");
console.log(codigo); // PED-0123
📌 Recuerda

location.assign(url) navega a otra dirección; location.reload() recarga la página.

7.11 Objeto history e historial de navegación

El objeto history permite desplazarse por las entradas del historial de la pestaña o ventana actual.

JavaScript — Navegar por el historial
// Volver a la entrada anterior, si existe:
// history.back();

// Avanzar a la siguiente, si existe:
// history.forward();

// Desplazarse una entrada hacia atrás:
// history.go(-1);
⚠️ Atención

El navegador puede no tener entradas anteriores o posteriores. Por privacidad, el historial no permite consultar libremente las direcciones visitadas.

7.12 Objetos navigator y screen

navigator permite consultar determinadas características del navegador, mientras que screen informa sobre la pantalla del dispositivo.

JavaScript — Idioma y dimensiones de pantalla
console.log(navigator.language);
console.log(screen.width);
console.log(screen.height);
⚠️ Atención

El tamaño de la pantalla (screen.width) no equivale al tamaño interior de la ventana (window.innerWidth).

7.13 Almacenamiento en el navegador

El navegador puede conservar información sencilla mediante localStorage y sessionStorage. Ambos almacenan pares clave–valor como cadenas de texto.

localStorageMantiene los datos entre sesiones hasta que se eliminan.
sessionStorageConserva datos durante la sesión de la pestaña.
setItem()Guarda un valor asociado a una clave.
getItem()Recupera el valor o devuelve null si no existe.
JavaScript — Guardar y recuperar un objeto
const preferencias = { idioma: "es", avisos: true };
localStorage.setItem("preferencias", JSON.stringify(preferencias));

const texto = localStorage.getItem("preferencias");
const datos = texto === null ? null : JSON.parse(texto);
console.log(datos);
⚠️ Atención

El almacenamiento web no debe utilizarse para guardar contraseñas ni otros datos sensibles. Su acceso puede fallar en determinados contextos.

7.14 Interacción con el usuario y aplicación práctica del BOM

Una aplicación real combina varios recursos: recoge datos, los valida, consulta el navegador, presenta resultados y conserva información cuando es necesario.

Entrada de datosprompt() o controles HTML.
ValidaciónString, Number y RegExp.
Entorno y navegaciónnavigator, location y URLSearchParams.
PersistencialocalStorage, sessionStorage y JSON.
JavaScript — Ejemplo integrado: consulta de pedidos
const entrada = window.prompt("Código de pedido (PED-0000):");

if (entrada !== null) {
  const codigo = entrada.trim().toUpperCase();
  const patron = /^PED-\d{4}$/;


if (patron.test(codigo)) {
  try {
    sessionStorage.setItem("ultimoPedido", codigo);
  } catch (error) {
    console.warn("No se ha podido guardar el último pedido.", error);
  }

  console.log(`Pedido ${codigo} consultado el ${new Date().toLocaleDateString()}`);
} else {
  console.log("El código no tiene el formato correcto.");
}

}
💻 Ejemplo DAW

Un panel de pedidos puede recordar el último código consultado, leer parámetros de la URL y validar la entrada antes de procesarla.

Ideas clave de la UT7

📌 Si tuvieras que recordar solo estas ideas…
  • Los objetos predefinidos simplifican operaciones habituales.
  • String y Number ayudan a tratar textos y números.
  • Math permite realizar cálculos y generar números pseudoaleatorios.
  • Date representa fechas e instantes temporales.
  • RegExp permite buscar y validar patrones.
  • JSON.stringify() y JSON.parse() convierten entre valores JavaScript y texto JSON.
  • El BOM permite interactuar con el entorno del navegador.
  • window ofrece propiedades y funciones relacionadas con la ventana.
  • Los diálogos y temporizadores permiten interacciones sencillas y ejecuciones programadas.
  • location gestiona la dirección y history permite desplazarse por el historial.
  • navigator y screen proporcionan información del navegador y la pantalla.
  • localStorage y sessionStorage guardan datos como texto con distinta duración.
  • Una aplicación útil combina entrada, validación, navegación y persistencia de forma organizada.
