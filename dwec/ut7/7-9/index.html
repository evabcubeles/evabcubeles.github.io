7.9 Gestión de ventanas y temporizadores

En el apartado anterior hemos estudiado las propiedades y métodos del objeto window. Ahora aprenderemos a abrir y cerrar ventanas y a programar tareas que se ejecuten después de un tiempo o de forma repetida.

Estas herramientas pueden utilizarse para mostrar información adicional, retrasar mensajes, actualizar un contador o controlar acciones periódicas en una aplicación web.

📌 Importante

Los temporizadores de JavaScript no detienen la ejecución del programa. Programan una función para que se ejecute más adelante. El tiempo indicado es un retraso mínimo aproximado, no una garantía de ejecución exacta.

Apertura de ventanas

El método window.open() solicita al navegador que abra una dirección web en un nuevo contexto de navegación. Según el navegador, sus preferencias y las características indicadas, puede abrirse una pestaña o una ventana independiente.

SintaxisSignificado
window.open(url, destino, caracteristicas)Solicita abrir una URL y devuelve una referencia a la ventana abierta, o null si no se ha podido abrir
urlDirección que queremos mostrar
destinoNombre o destino, por ejemplo _blank
caracteristicasOpciones como width o height; el navegador puede ignorarlas
JavaScript
const nuevaVentana = window.open("https://example.com", "_blank");

if (nuevaVentana === null) {
  console.log("El navegador no ha permitido abrir la ventana");
} else {
  console.log("Se ha solicitado abrir la ventana");
}

Salida por consola: depende de si el navegador permite la apertura. Puede mostrarse cualquiera de los dos mensajes del ejemplo.

Para probarlo, ejecuta el código desde un clic en un botón. Los navegadores suelen bloquear las aperturas automáticas que no están asociadas a una acción del usuario.

JavaScript
const boton = document.querySelector("#abrirAyuda");

boton.addEventListener("click", () => {
  window.open("ayuda.html", "_blank");
});

Este segundo ejemplo presupone que la página contiene un botón con id="abrirAyuda" y que existe el archivo ayuda.html.

⚠️ Atención

window.open() puede devolver null si el navegador bloquea la apertura. Cuando devuelve una referencia, esta corresponde a un contexto de navegación, pero no garantiza que se haya abierto una ventana flotante independiente.

El navegador puede abrir una pestaña en lugar de una ventana, modificar las dimensiones solicitadas o aplicar otras restricciones. Por ello, no debemos diseñar una aplicación suponiendo que siempre se abrirá una ventana independiente.

Opciones de tamaño

JavaScript
const ayuda = window.open(
  "ayuda.html",
  "ventanaAyuda",
  "width=600,height=400"
);

Las opciones width y height solicitan unas dimensiones, pero el navegador puede modificarlas o ignorarlas. Es preferible que una aplicación funcione correctamente aunque la página se abra en una pestaña.

Cierre de ventanas

El método close() permite solicitar el cierre de una ventana. Por motivos de seguridad y experiencia de usuario, los navegadores normalmente solo permiten cerrar mediante JavaScript las ventanas que han sido abiertas por un script.

JavaScript
const ventana = window.open("ayuda.html", "_blank");

if (ventana !== null) {
  console.log("Ventana solicitada");
  // Más adelante, tras una acción del usuario:
  // ventana.close();
}

Salida por consola si se permite la apertura:

Consola
Ventana solicitada

La instrucción ventana.close() se ha dejado comentada para evitar que el ejemplo cierre inmediatamente la ventana. En una aplicación real podríamos ejecutarla desde otro botón.

JavaScript
const cerrar = document.querySelector("#cerrarAyuda");

cerrar.addEventListener("click", () => {
  if (ventana !== null && !ventana.closed) {
    ventana.close();
  }
});

La propiedad closed permite comprobar si una ventana referenciada ya está cerrada. Este código presupone que existe el botón cerrarAyuda y que la variable ventana contiene una referencia obtenida previamente.

📌 Importante

Una página abierta manualmente por el usuario no suele poder cerrarse mediante window.close(). La decisión final depende de las políticas del navegador; no debemos diseñar una funcionalidad esencial suponiendo que el cierre siempre funcionará.

Comunicación básica entre ventanas

Cuando window.open() devuelve una referencia, podemos consultar algunas propiedades de la ventana abierta. Sin embargo, el acceso a su contenido está restringido por la política del mismo origen (*same-origin policy*).

JavaScript
const ventana = window.open("ayuda.html", "_blank");

if (ventana !== null) {
  console.log("¿Está cerrada?", ventana.closed);
}

Salida por consola habitual si la ventana se ha abierto y sigue activa:

Consola
¿Está cerrada? false

Si ambas páginas tienen el mismo origen, es posible realizar determinadas operaciones entre ellas. Cuando pertenecen a orígenes diferentes, no podemos acceder libremente a su DOM o a sus variables.

Para enviar mensajes entre ventanas de forma controlada existe postMessage(), cuyo uso requiere validar el origen de los mensajes. Su estudio detallado queda fuera de este apartado introductorio.

⚠️ Atención

No intentes acceder directamente a ventana.document si la ventana muestra una página de otro origen: el navegador puede lanzar un error de seguridad. Tampoco debes confiar en mensajes recibidos sin comprobar su procedencia.

setTimeout() y clearTimeout()

setTimeout() programa la ejecución de una función una sola vez, después de que haya transcurrido al menos el tiempo indicado en milisegundos. Devuelve un identificador que permite cancelar la tarea pendiente.

JavaScript
console.log("Inicio");

setTimeout(() => {
  console.log("Han pasado aproximadamente 2 segundos");
}, 2000);

console.log("Fin del código principal");

Orden esperado de los mensajes:

Consola
Inicio
Fin del código principal
Han pasado aproximadamente 2 segundos

Observa que el programa no espera a que termine el temporizador: primero ejecuta las instrucciones siguientes y después, cuando corresponde, ejecuta la función programada.

Cancelar una tarea con clearTimeout()

JavaScript
const aviso = setTimeout(() => {
  console.log("Pedido enviado");
}, 3000);

clearTimeout(aviso);
console.log("Envío cancelado");

Salida por consola:

Consola
Envío cancelado

El mensaje «Pedido enviado» no aparece porque cancelamos el temporizador antes de que se ejecute su función.

⚠️ Atención

clearTimeout() impide la ejecución de una tarea que todavía está pendiente. No puede deshacer una función que ya se ha ejecutado. Los tiempos pueden variar por la carga del navegador y la gestión de pestañas en segundo plano.

setInterval() y clearInterval()

setInterval() programa una función para que se ejecute repetidamente, dejando un intervalo aproximado entre ejecuciones. Para detenerla utilizamos clearInterval() con el identificador devuelto.

JavaScript
let contador = 0;

const intervalo = setInterval(() => {
  contador++;
  console.log("Repetición:", contador);

  if (contador === 3) {
    clearInterval(intervalo);
  }
}, 1000);

Salida por consola, aproximadamente cada segundo:

Consola
Repetición: 1
Repetición: 2
Repetición: 3

El contador aumenta en cada ejecución. Cuando llega a tres, se cancela el intervalo para evitar que siga ejecutándose indefinidamente.

MétodoCuándo se ejecutaCómo se cancela
setTimeout()Una vez, tras un retrasoclearTimeout()
setInterval()Repetidamente, con un intervalo aproximadoclearInterval()
📌 Importante

Los milisegundos no garantizan precisión absoluta. Si una tarea tarda mucho o la pestaña está en segundo plano, el navegador puede retrasar ejecuciones. Para animaciones visuales suele ser más adecuado requestAnimationFrame().

Ejemplos prácticos

Ejemplo 1. Mostrar un aviso después de unos segundos

Una aplicación puede informar de que se ha guardado un borrador después de un breve retraso. En este ejemplo, el aviso aparece en la consola para evitar cuadros de diálogo molestos.

JavaScript
console.log("Guardando borrador...");

setTimeout(() => {
  console.log("Borrador guardado correctamente");
}, 1500);

Salida por consola (el segundo mensaje aparece más tarde):

Consola
Guardando borrador...
Borrador guardado correctamente

Ejemplo 2. Cuenta atrás para una reserva

Simularemos una cuenta atrás de tres segundos. El intervalo se detendrá automáticamente cuando llegue a cero.

JavaScript
let segundos = 3;

console.log("Tiempo restante:", segundos);

const reloj = setInterval(() => {
  segundos--;
  console.log("Tiempo restante:", segundos);

  if (segundos === 0) {
    clearInterval(reloj);
    console.log("Tiempo agotado");
  }
}, 1000);

Salida por consola (aproximadamente cada segundo):

Consola
Tiempo restante: 3
Tiempo restante: 2
Tiempo restante: 1
Tiempo restante: 0
Tiempo agotado

Ejemplo 3. Evitar que un aviso se muestre si se cancela

En una tienda online podemos programar un recordatorio y cancelarlo cuando el usuario completa una acción.

JavaScript
const recordatorio = setTimeout(() => {
  console.log("Recuerda finalizar tu pedido");
}, 5000);

const pedidoFinalizado = true;

if (pedidoFinalizado) {
  clearTimeout(recordatorio);
  console.log("Pedido finalizado: recordatorio cancelado");
}

Salida por consola:

Consola
Pedido finalizado: recordatorio cancelado
💻 Ejemplo DAW

En un panel de administración, los temporizadores pueden servir para actualizar un indicador, retrasar una notificación o cancelar un aviso cuando el usuario realiza una acción. Debemos detener los intervalos que ya no sean necesarios.

💭 Piensa

Sin ejecutar el código, indica el orden de los mensajes que aparecerán en la consola. ¿Cuántas veces se ejecutará la función del intervalo? ¿Por qué no aparece el mensaje «Aviso pendiente»?

JavaScript
console.log("A");

const aviso = setTimeout(() => {
  console.log("Aviso pendiente");
}, 2000);

let veces = 0;
const intervalo = setInterval(() => {
  veces++;
  console.log("B", veces);
  if (veces === 2) {
    clearInterval(intervalo);
  }
}, 500);

clearTimeout(aviso);
console.log("C");
Ver una posible solución

Primero aparecen A y C, porque son instrucciones síncronas. El temporizador de dos segundos se cancela antes de ejecutarse. El intervalo muestra dos mensajes, aproximadamente a los 500 y 1000 milisegundos, y después se detiene.

Salida esperada por consola:

Consola
A
C
B 1
B 2

La función del intervalo se ejecuta dos veces. El mensaje «Aviso pendiente» no aparece porque clearTimeout(aviso) cancela esa tarea pendiente.
