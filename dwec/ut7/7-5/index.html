7.5 Objeto RegExp y expresiones regulares

En los apartados anteriores hemos aprendido a utilizar objetos predefinidos de JavaScript para trabajar con cadenas de texto, números, operaciones matemáticas y fechas.

Sin embargo, en muchas aplicaciones web necesitamos realizar operaciones más complejas con el texto. Por ejemplo, comprobar si un usuario ha introducido un código postal válido, localizar una palabra dentro de una descripción o sustituir determinados caracteres de una cadena.

Para resolver estas situaciones, JavaScript proporciona las expresiones regulares, que permiten definir patrones de búsqueda y comprobar si un texto cumple unas determinadas condiciones.

📌 Importante

Una expresión regular es un patrón que permite buscar, identificar, validar o sustituir fragmentos de texto.

En JavaScript, las expresiones regulares se representan mediante objetos RegExp.

Qué es una expresión regular

Una expresión regular, también conocida como regular expression o regex, es una secuencia de caracteres que describe un patrón de texto.

Ese patrón puede ser tan sencillo como una palabra concreta o tan elaborado como una combinación de letras, números y símbolos que debe cumplir determinadas reglas.

Imaginemos que estamos desarrollando una aplicación para gestionar pedidos. El formulario solicita al cliente un código postal y necesitamos comprobar que contiene exactamente cinco cifras.

Podríamos recorrer la cadena carácter por carácter, comprobar su longitud y verificar que todos sus caracteres son números.

Sin embargo, una expresión regular permite describir esas condiciones mediante un único patrón.

JavaScript 
const patron = /^\d{5}$/;

console.log(patron.test("44001"));
console.log(patron.test("4400"));
console.log(patron.test("44A01"));
Consola 
true
false
false

El primer valor cumple el patrón porque contiene exactamente cinco dígitos.

El segundo tiene únicamente cuatro caracteres, mientras que el tercero contiene una letra. Por eso ambos producen false.

💻 Ejemplo DAW

Las expresiones regulares se utilizan con frecuencia para comprobar el formato de datos introducidos en formularios, buscar información en textos, limpiar cadenas y procesar registros.

Más adelante, cuando trabajemos con formularios y eventos, podremos aplicar estos patrones a los valores introducidos por el usuario.

El objeto RegExp

En JavaScript, una expresión regular es un objeto que dispone de propiedades y métodos específicos para trabajar con patrones.

Podemos comprobar su tipo utilizando typeof.

JavaScript 
const patron = /javascript/;

console.log(typeof patron);
console.log(patron instanceof RegExp);
Consola 
object
true

La primera instrucción devuelve object, mientras que la segunda confirma que el valor es una instancia de RegExp.

Principales aplicaciones

Validación Comprobar que un dato cumple un formato determinado.
Búsqueda Localizar palabras o fragmentos dentro de una cadena.
Extracción Obtener partes de un texto que coinciden con un patrón.
Sustitución Reemplazar fragmentos de texto por otros valores.

Sintaxis de los patrones

Para utilizar expresiones regulares necesitamos conocer cómo se escriben sus patrones.

En JavaScript podemos crear una expresión regular de dos formas principales: mediante una expresión literal o mediante el constructor RegExp.

Creación mediante una expresión literal

La forma más habitual consiste en escribir el patrón entre dos barras inclinadas /.

JavaScript 
const patron = /hola/;

console.log(patron.test("hola mundo"));
console.log(patron.test("adiós mundo"));
Consola 
true
false

El patrón /hola/ busca la secuencia de caracteres hola dentro del texto.

No exige que la cadena completa sea exactamente "hola". Por eso encuentra una coincidencia dentro de "hola mundo".

Creación mediante el constructor RegExp

También podemos crear expresiones regulares mediante el constructor RegExp, al que proporcionamos una cadena con el patrón.

JavaScript 
const patron = new RegExp("hola");

console.log(patron.test("hola mundo"));
Consola 
true

Ambas formas permiten crear objetos RegExp.

La expresión literal resulta especialmente cómoda cuando conocemos el patrón al escribir el programa. El constructor puede resultar útil cuando necesitamos construirlo dinámicamente.

⚠️ Atención

Cuando utilizamos el constructor RegExp con una cadena, debemos tener cuidado con las barras invertidas.

Por ejemplo, para representar el patrón \d dentro de una cadena de JavaScript debemos escribir "\\d".

JavaScript 
const patron1 = /\d{5}/;

const patron2 = new RegExp("\\d{5}");

console.log(patron1.test("44001"));
console.log(patron2.test("44001"));
Consola 
true
true

Diferencia entre buscar y validar una cadena completa

Una expresión regular puede buscar una coincidencia en cualquier parte de un texto o exigir que la cadena completa cumpla el patrón.

Para distinguir estos comportamientos utilizamos los símbolos ^ y $.

Símbolo Significado habitual
^ Inicio del texto.
$ Final del texto, con algunas particularidades.
^...$ Permite comprobar el contenido completo del texto, con precauciones respecto a los saltos de línea.
JavaScript 
const buscar = /DAW/;
const validar = /^DAW$/;

console.log(buscar.test("Estudio DAW"));
console.log(validar.test("Estudio DAW"));
console.log(validar.test("DAW"));
Consola 
true
false
true

El primer patrón localiza la palabra DAW en cualquier parte del texto.

El segundo exige que el texto se ajuste al patrón desde el principio hasta el final.

📌 Importante

Cuando queremos validar un dato completo, normalmente utilizamos patrones delimitados por ^ y $.

Debemos recordar que $ también puede coincidir antes de un salto de línea final. Si necesitamos una validación estricta, conviene tratar previamente los saltos de línea o utilizar comprobaciones adicionales.

Caracteres especiales

Hasta ahora hemos utilizado patrones formados por palabras concretas. Sin embargo, las expresiones regulares permiten describir grupos de caracteres sin necesidad de enumerarlos uno por uno.

Para ello utilizamos caracteres especiales que tienen un significado dentro del patrón.

Clases de caracteres

Algunas de las clases de caracteres más utilizadas son las siguientes:

Patrón Significado Ejemplo
\d Un dígito ASCII, del 0 al 9. /\d/
\D Un carácter que no sea un dígito ASCII. /\D/
\w Carácter de palabra básico: letras ASCII, números o guion bajo. /\w/
\W Carácter que no pertenece a esa clase de palabra. /\W/
\s Espacio en blanco, tabulación o salto de línea, entre otros. /\s/
\S Carácter que no es un espacio en blanco. /\S/
. Cualquier carácter salvo determinados saltos de línea, si no se utiliza el modificador s. /a.c/

Buscar dígitos

El patrón \d permite encontrar un dígito dentro de una cadena.

JavaScript 
const patron = /\d/;

console.log(patron.test("Aula 3"));
console.log(patron.test("Aula tres"));
Consola 
true
false

El primer texto contiene el carácter 3, por lo que cumple el patrón.

El segundo no contiene ningún dígito, aunque incluya la palabra tres.

Conjuntos de caracteres

Los corchetes [] permiten indicar un conjunto de caracteres admitidos.

Por ejemplo, podemos buscar una vocal o una letra comprendida dentro de un intervalo.

JavaScript 
const vocal = /[aeiou]/;

const letraMayuscula = /[A-Z]/;

console.log(vocal.test("mesa"));
console.log(vocal.test("xyz"));

console.log(letraMayuscula.test("DAW"));
console.log(letraMayuscula.test("daw"));
Consola 
true
false
true
false

El patrón [aeiou] busca cualquiera de las vocales indicadas.

El patrón [A-Z] busca una letra mayúscula comprendida entre A y Z.

Negación de conjuntos

Cuando el símbolo ^ aparece al principio de un conjunto, indica que buscamos un carácter que no pertenezca a ese conjunto.

JavaScript 
const patron = /[^0-9]/;

console.log(patron.test("12345"));
console.log(patron.test("123A5"));
Consola 
false
true

El patrón busca algún carácter que no sea un número del 0 al 9.

La primera cadena contiene únicamente dígitos. La segunda incluye la letra A, por lo que sí encuentra una coincidencia.

Caracteres literales y caracteres especiales

Algunos símbolos tienen un significado especial dentro de una expresión regular.

Si queremos buscar literalmente uno de esos símbolos, en muchos casos debemos precederlo de una barra invertida \.

JavaScript 
const patron = /\./;

console.log(patron.test("archivo.txt"));
console.log(patron.test("archivo txt"));
Consola 
true
false

En este caso, \. representa un punto literal.

Si hubiéramos utilizado únicamente ., el patrón podría coincidir con muchos otros caracteres.

⚠️ Atención

La clase \w no incluye, en su uso básico, todas las letras del español, como ñ o las vocales acentuadas.

Para trabajar con alfabetos internacionales existen las propiedades Unicode, como \p{L}, que requieren el modificador u o v.

Cuantificadores

En muchas ocasiones no basta con indicar qué caracteres queremos encontrar. También necesitamos especificar cuántas veces pueden aparecer.

Para ello utilizamos los cuantificadores, que permiten establecer repeticiones dentro de un patrón.

Cuantificador Significado Ejemplo
* Cero o más repeticiones. /a*/
+ Una o más repeticiones. /a+/
? Cero o una repetición. /a?/
{n} Exactamente n repeticiones. /\d{5}/
{n,} Como mínimo n repeticiones. /\d{3,}/
{n,m} Entre n y m repeticiones. /\d{2,4}/

Exactamente un número de repeticiones

El cuantificador {n} exige que el elemento anterior aparezca exactamente el número de veces indicado.

Por ejemplo, podemos comprobar si una cadena contiene exactamente cinco dígitos.

JavaScript 
const codigoPostal = /^\d{5}$/;

console.log(codigoPostal.test("44001"));
console.log(codigoPostal.test("4401"));
console.log(codigoPostal.test("440011"));
Consola 
true
false
false

El patrón exige cinco dígitos desde el principio hasta el final de la cadena.

Un mínimo y un máximo de caracteres

El cuantificador {n,m} permite establecer un intervalo de repeticiones.

Vamos a comprobar que un nombre de usuario contiene entre cuatro y ocho caracteres, utilizando letras ASCII, números o guiones bajos.

JavaScript 
const usuario = /^\w{4,8}$/;

console.log(usuario.test("Ana"));
console.log(usuario.test("Ana25"));
console.log(usuario.test("Usuario123"));
Consola 
false
true
false

"Ana" tiene únicamente tres caracteres.

"Ana25" tiene cinco, mientras que "Usuario123" supera el máximo permitido.

Uno o más caracteres

El símbolo + exige que el elemento anterior aparezca al menos una vez.

JavaScript 
const numeros = /^\d+$/;

console.log(numeros.test("12345"));
console.log(numeros.test("12A45"));
console.log(numeros.test(""));
Consola 
true
false
false

El patrón permite una secuencia de uno o más dígitos, pero no admite letras ni una cadena vacía.

Caracteres opcionales

El cuantificador ? indica que el elemento anterior puede aparecer cero o una vez.

Por ejemplo, podemos admitir dos formas de escribir una palabra.

JavaScript 
const patron = /^colou?r$/;

console.log(patron.test("color"));
console.log(patron.test("colour"));
console.log(patron.test("colouur"));
Consola 
true
true
false

La letra u es opcional: puede aparecer una vez o no aparecer.

📌 Importante

Los cuantificadores se aplican al elemento que tienen inmediatamente a su izquierda.

Si queremos repetir un grupo completo, podemos utilizar paréntesis. Por ejemplo, /(ab){3}/ busca tres repeticiones consecutivas de la secuencia ab.

Agrupación y alternativas

Los paréntesis () permiten agrupar partes de un patrón. El símbolo | permite indicar alternativas.

JavaScript 
const patron = /^(rojo|verde|azul)$/;

console.log(patron.test("rojo"));
console.log(patron.test("verde"));
console.log(patron.test("amarillo"));
Consola 
true
true
false

El patrón admite exactamente una de las tres palabras indicadas.

Modificadores

Las expresiones regulares también permiten modificar su comportamiento mediante determinadas opciones llamadas modificadores o flags.

Los modificadores se escriben después de la barra de cierre de una expresión regular literal.

JavaScript 
const patron = /javascript/i;

En este caso, el modificador i permite realizar una búsqueda sin distinguir entre mayúsculas y minúsculas.

Modificador Función
i Ignora diferencias entre mayúsculas y minúsculas.
g Permite buscar todas las coincidencias.
m Hace que ^ y $ también funcionen respecto a los límites de las líneas.
s Permite que . también coincida con saltos de línea.
u Activa el tratamiento Unicode del patrón.
y Realiza búsquedas consecutivas desde la posición indicada por lastIndex.

Modificador i: ignorar mayúsculas y minúsculas

Sin el modificador i, las expresiones regulares distinguen entre letras mayúsculas y minúsculas.

JavaScript 
const normal = /javascript/;
const flexible = /javascript/i;

console.log(normal.test("JavaScript"));
console.log(flexible.test("JavaScript"));
console.log(flexible.test("JAVASCRIPT"));
Consola 
false
true
true

Modificador g: buscar todas las coincidencias

El modificador g permite realizar búsquedas globales, en lugar de limitarse a la primera coincidencia.

Resulta especialmente útil cuando utilizamos métodos como match() o replace().

JavaScript 
const texto = "JavaScript y javascript";

console.log(texto.match(/javascript/gi));
Consola 
["JavaScript", "javascript"]

El modificador g permite encontrar ambas coincidencias, mientras que i evita distinguir entre mayúsculas y minúsculas.

Combinar modificadores

Podemos utilizar varios modificadores dentro de una misma expresión regular.

JavaScript 
const texto = "DAW, daw y DaW";

const coincidencias = texto.match(/daw/gi);

console.log(coincidencias);
Consola 
["DAW", "daw", "DaW"]
⚠️ Atención

Los modificadores g y y hacen que métodos como test() utilicen y actualicen la propiedad lastIndex.

Por eso, al reutilizar una expresión regular global en varias llamadas a test(), los resultados pueden cambiar.

JavaScript 
const patron = /a/g;

console.log(patron.test("a"));
console.log(patron.test("a"));
console.log(patron.test("a"));
Consola 
true
false
true

Esto ocurre porque la expresión regular conserva su posición de búsqueda entre llamadas.

Si únicamente necesitamos comprobar si una cadena cumple un patrón, normalmente no debemos utilizar el modificador g.

Métodos test(), exec() y match()

Una vez definido un patrón, necesitamos métodos que permitan aplicarlo sobre una cadena de texto.

JavaScript ofrece diferentes posibilidades. Algunas pertenecen al objeto RegExp y otras son métodos de las cadenas String.

Método Pertenece a Función principal
test() RegExp Comprueba si existe alguna coincidencia.
exec() RegExp Devuelve información sobre una coincidencia.
match() String Obtiene coincidencias de un texto.
matchAll() String Permite recorrer todas las coincidencias y sus grupos.
replace() String Sustituye fragmentos que cumplen un patrón.
search() String Devuelve la posición de la primera coincidencia.

Método test()

El método test() comprueba si un texto contiene alguna coincidencia con el patrón.

Devuelve un valor booleano: true si encuentra una coincidencia y false en caso contrario.

JavaScript 
const patron = /^\d{4}$/;

console.log(patron.test("2026"));
console.log(patron.test("26"));
console.log(patron.test("20A6"));
Consola 
true
false
false

Este método resulta especialmente útil para realizar validaciones sencillas.

Método exec()

El método exec() busca una coincidencia y devuelve información sobre ella.

Si encuentra un resultado, devuelve un array con la coincidencia y propiedades adicionales, como la posición en la que aparece.

Si no encuentra ninguna coincidencia, devuelve null.

JavaScript 
const patron = /\d+/;

const resultado = patron.exec("Pedido 125");

console.log(resultado[0]);
console.log(resultado.index);
Consola 
125
7

El patrón \d+ busca una secuencia de uno o más dígitos.

El método encuentra "125" a partir de la posición 7. Recordemos que los índices de las cadenas comienzan en cero.

⚠️ Atención

Antes de acceder a resultado[0], debemos comprobar que exec() no ha devuelto null.

De lo contrario, el programa puede producir un error al intentar acceder a una propiedad de null.

Método match()

El método match() pertenece a las cadenas de texto. Recibe una expresión regular y permite obtener coincidencias.

JavaScript 
const texto = "Pedidos 12, 25 y 48";

const numeros = texto.match(/\d+/g);

console.log(numeros);
Consola 
["12", "25", "48"]

El modificador g permite recuperar todas las secuencias de dígitos encontradas.

El resultado es un array de cadenas de texto. Si necesitamos trabajar con esos valores como números, podemos convertirlos.

JavaScript 
const texto = "Pedidos 12, 25 y 48";

const numeros = (texto.match(/\d+/g) ?? [])
  .map(Number);

console.log(numeros);
Consola 
[12, 25, 48]

Hemos utilizado map(), estudiado en la UT4, para convertir cada coincidencia en un número.

La expresión ?? [] evita errores si no se encuentra ninguna coincidencia, porque match() puede devolver null.

Método replace()

El método replace() permite sustituir fragmentos de una cadena que coinciden con un patrón.

JavaScript 
const texto = "Curso 2026 - Grupo 2026";

const resultado = texto.replace(
  /2026/g,
  "2027"
);

console.log(resultado);
Consola 
Curso 2027 - Grupo 2027

El modificador g hace que se sustituyan todas las coincidencias.

Como las cadenas son inmutables, replace() devuelve una nueva cadena y no modifica la original.

Método search()

El método search() permite localizar la posición de la primera coincidencia.

Si no encuentra ninguna, devuelve -1.

JavaScript 
const texto = "Curso de JavaScript";

console.log(texto.search(/JavaScript/));
console.log(texto.search(/Python/));
Consola 
9
-1

La palabra JavaScript comienza en la posición 9.

Como Python no aparece en el texto, el resultado es -1.

📌 Importante

Utilizaremos test() cuando necesitemos comprobar si existe una coincidencia.

Utilizaremos exec() o match() cuando necesitemos recuperar información del texto encontrado.

Para sustituir contenido, podemos utilizar replace().

Ejemplos prácticos

Vamos a combinar expresiones regulares con funciones, estructuras de control, arrays y objetos, utilizando situaciones habituales en desarrollo web.

Ejemplo 1. Validar un código postal

Una aplicación de pedidos necesita comprobar que el código postal introducido contiene exactamente cinco cifras.

Podemos crear una función reutilizable que devuelva true o false.

JavaScript 
function validarCodigoPostal(codigo) {

  const patron = /^\d{5}$/;

  return patron.test(codigo);

}

console.log(validarCodigoPostal("44001"));
console.log(validarCodigoPostal("4400"));
console.log(validarCodigoPostal("44A01"));
Consola 
true
false
false

La función comprueba si el código tiene exactamente cinco dígitos.

Debemos recibirlo como cadena, ya que un código postal puede comenzar por cero.

⚠️ Atención

Este patrón comprueba únicamente el formato de cinco cifras.

No garantiza que el código postal exista realmente ni que corresponda a una localidad determinada.

Ejemplo 2. Validar un nombre de usuario

Supongamos que una plataforma educativa permite crear nombres de usuario que deben cumplir estas condiciones:

  • Contener entre 5 y 12 caracteres.
  • Empezar por una letra ASCII.
  • Utilizar únicamente letras ASCII, números y guiones bajos.

Podemos expresar estas condiciones mediante un patrón.

JavaScript 
function validarUsuario(usuario) {

  const patron = /^[A-Za-z][A-Za-z0-9_]{4,11}$/;

  return patron.test(usuario);

}

console.log(validarUsuario("alumno25"));
console.log(validarUsuario("25alumno"));
console.log(validarUsuario("ana"));
console.log(validarUsuario("alumno_2026"));
Consola 
true
false
false
true

El patrón exige una primera letra y después permite entre cuatro y once caracteres adicionales.

Por tanto, la longitud total del nombre de usuario debe estar entre 5 y 12 caracteres.

Ejemplo 3. Extraer códigos de pedido

Imaginemos que recibimos un texto con varios códigos de pedido.

Todos siguen el formato PED- seguido de tres cifras.

Podemos utilizar match() para extraerlos.

JavaScript 
const texto = `
  Pedidos recibidos:
  PED-125, PED-208 y PED-341.
`;

const patron = /PED-\d{3}/g;

const pedidos = texto.match(patron) ?? [];

console.log(pedidos);
console.log(pedidos.length);
Consola 
["PED-125", "PED-208", "PED-341"]
3

El patrón localiza las secuencias que contienen PED- seguido de tres dígitos.

El modificador g permite obtener todas las coincidencias del texto.

💻 Ejemplo DAW

Esta técnica puede utilizarse para analizar registros, extraer identificadores, localizar referencias de productos o procesar mensajes que contienen datos estructurados.

Ejemplo 4. Limpiar espacios repetidos

En ocasiones, un usuario introduce espacios innecesarios entre las palabras de un texto.

Podemos utilizar una expresión regular para sustituir varias secuencias de espacios en blanco por un único espacio.

JavaScript 
const texto = "  Teclado    mecánico   RGB  ";

const limpio = texto
  .trim()
  .replace(/\s+/g, " ");

console.log(limpio);
Consola 
Teclado mecánico RGB

Primero utilizamos trim() para eliminar los espacios de los extremos.

Después, el patrón \s+ identifica secuencias de uno o más espacios en blanco, que se sustituyen por un único espacio.

Ejemplo 5. Comprobar el formato de un correo electrónico

Las expresiones regulares también pueden utilizarse para realizar comprobaciones básicas sobre direcciones de correo electrónico.

Por ejemplo, podemos exigir que una cadena contenga texto antes y después del símbolo @, y un punto en la parte correspondiente al dominio.

JavaScript 
function validarEmailBasico(email) {

  const patron = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

  return patron.test(email);

}

console.log(
  validarEmailBasico("alumno@centro.es")
);

console.log(
  validarEmailBasico("alumno@centro")
);

console.log(
  validarEmailBasico("alumno centro.es")
);
Consola 
true
false
false

El patrón realiza una comprobación básica: exige caracteres antes del símbolo @, una parte de dominio y un punto seguido de más caracteres.

⚠️ Atención

Validar correctamente todas las direcciones de correo electrónico es mucho más complejo que comprobar este patrón.

Esta expresión sirve como ejemplo didáctico y como comprobación básica, pero no garantiza que la dirección exista ni que pueda recibir mensajes.

En una aplicación real, la validación del cliente debe complementarse con comprobaciones del servidor y, cuando sea necesario, con una verificación de la dirección.

Ejemplo 6. Procesar una lista de productos

Vamos a combinar expresiones regulares con arrays y objetos, conocimientos que ya hemos trabajado en las unidades anteriores.

Disponemos de una lista de productos cuyos códigos deben seguir el formato PROD- seguido de cuatro cifras.

Queremos obtener únicamente los productos cuyos códigos cumplen ese formato.

JavaScript 
const productos = [
  { codigo: "PROD-1001", nombre: "Teclado" },
  { codigo: "PROD-205", nombre: "Ratón" },
  { codigo: "PROD-3402", nombre: "Monitor" },
  { codigo: "ART-4001", nombre: "Webcam" }
];

const patron = /^PROD-\d{4}$/;

const productosValidos = productos.filter(
  producto => patron.test(producto.codigo)
);

productosValidos.forEach(producto => {
  console.log(
    producto.codigo + " - " + producto.nombre
  );
});
Consola 
PROD-1001 - Teclado
PROD-3402 - Monitor

Hemos utilizado filter() para seleccionar únicamente los productos cuyo código cumple el patrón.

Después recorremos el array resultante mediante forEach() y mostramos los productos válidos.

💻 Ejemplo DAW

Este procedimiento puede aplicarse en aplicaciones de inventario, gestión de pedidos o administración de productos, donde los identificadores deben seguir un formato común.

También muestra cómo las expresiones regulares pueden combinarse con funciones y métodos de arrays para resolver problemas reales.

💭 Piensa

Observa el siguiente código sin ejecutarlo:

JavaScript 
const texto = "PED-125, PED-28 y PED-341";

const patron = /PED-\d{3}/g;

const resultados = texto.match(patron);

console.log(resultados);

console.log(
  /^PED-\d{3}$/.test("PED-125")
);

console.log(
  /^PED-\d{3}$/.test("PED-28")
);

const nuevoTexto = texto.replace(
  /PED-/g,
  "ORD-"
);

console.log(nuevoTexto);

console.log(
  /javascript/i.test("JavaScript")
);

Responde a las siguientes preguntas:

  1. ¿Qué elementos contendrá el array resultados?
  2. ¿Por qué el código PED-28 no aparece en ese array?
  3. ¿Qué devuelve /^PED-\d{3}$/.test("PED-125")?
  4. ¿Qué devuelve la misma expresión cuando recibe "PED-28"?
  5. ¿Cuál será el contenido de nuevoTexto?
  6. ¿Qué función desempeñan los modificadores g e i?

["PED-125", "PED-341"]

false

true

1. Contenido del array: el array contiene las coincidencias "PED-125" y "PED-341".

2. Código excluido: PED-28 no aparece porque el patrón exige exactamente tres dígitos después de PED-.

3. Primera validación: devuelve true, porque PED-125 cumple el formato exigido.

4. Segunda validación: devuelve false, porque PED-28 contiene únicamente dos dígitos.

5. Sustitución: el método replace() sustituye todas las apariciones de PED- por ORD-.

La sustitución afecta también a PED-28, porque el patrón utilizado en replace() únicamente busca el prefijo PED- y no comprueba la cantidad de dígitos.

6. Modificadores: g permite buscar todas las coincidencias, mientras que i permite ignorar diferencias entre mayúsculas y minúsculas.

Por eso la última instrucción devuelve true, aunque el patrón esté escrito en minúsculas y el texto contenga letras mayúsculas.
