7.2 Objetos String y Number

En el apartado anterior hemos conocido qué son los objetos predefinidos de JavaScript y cómo podemos utilizar sus propiedades y métodos para resolver tareas habituales.

Dos de las operaciones más frecuentes en una aplicación web son trabajar con textos y procesar valores numéricos. Por ejemplo, podemos necesitar normalizar el nombre de un producto, buscar información dentro de una cadena, convertir el precio introducido por un usuario o comprobar que una cantidad es válida.

JavaScript proporciona funcionalidades específicas para estas tareas mediante String y Number. Aunque ya hemos utilizado cadenas y números en unidades anteriores, ahora estudiaremos con mayor profundidad sus propiedades, métodos y posibilidades.

📌 Importante

String proporciona herramientas para consultar, buscar y transformar cadenas de texto.

Number permite representar números y ofrece métodos y propiedades para trabajar con valores numéricos.

Ambos forman parte del propio lenguaje JavaScript y no dependen del navegador.

El objeto String

Una cadena de texto es una secuencia de caracteres. Puede contener letras, números, espacios, signos de puntuación y otros símbolos.

En JavaScript, las cadenas suelen crearse utilizando comillas simples, comillas dobles o acentos graves cuando necesitamos una plantilla de texto.

JavaScript 
const nombre = "Ana";
const modulo = 'DWEC';
const mensaje = `Bienvenida, ${nombre}`;

console.log(nombre);
console.log(modulo);
console.log(mensaje);

La salida será:

Consola 
Ana
DWEC
Bienvenida, Ana

Aunque normalmente trabajamos con valores primitivos de tipo string, JavaScript permite utilizar sobre ellos las propiedades y métodos asociados a String.

Esto es posible porque JavaScript facilita temporalmente el acceso a esas funcionalidades cuando utilizamos una cadena primitiva.

Cadenas primitivas y objetos String

Es importante distinguir entre una cadena primitiva y un objeto creado explícitamente mediante new String().

JavaScript 
const texto1 = "Hola";
const texto2 = new String("Hola");

console.log(typeof texto1);
console.log(typeof texto2);
Consola 
string
object

En el primer caso tenemos un valor primitivo de tipo string. En el segundo hemos creado un objeto de tipo String.

⚠️ Atención

En la programación habitual se recomienda utilizar cadenas primitivas en lugar de crear objetos con new String().

Los objetos envoltorio pueden producir comportamientos inesperados, especialmente al comparar valores.

La propiedad length

La propiedad length permite consultar la longitud de una cadena.

JavaScript 
const lenguaje = "JavaScript";

console.log(lenguaje.length); // 10

En este ejemplo, la cadena contiene diez caracteres.

Los espacios también cuentan como caracteres:

JavaScript 
const texto = "Hola mundo";

console.log(texto.length); // 10

Para acceder a un carácter mediante su posición podemos utilizar corchetes. La primera posición es la 0.

JavaScript 
const palabra = "DWEC";

console.log(palabra[0]); // D
console.log(palabra[1]); // W
console.log(palabra[3]); // C
📌 Importante

Las cadenas son inmutables. Esto significa que no podemos modificar directamente un carácter de una cadena existente mediante su posición.

Los métodos que transforman textos devuelven nuevas cadenas. Si queremos conservar el resultado, debemos guardarlo en una variable.

Métodos de String

El tipo String dispone de numerosos métodos que permiten consultar y manipular cadenas.

A continuación estudiaremos algunos de los más utilizados en el desarrollo de aplicaciones web.

Método Finalidad Ejemplo
toUpperCase() Convierte a mayúsculas. "hola".toUpperCase()
toLowerCase() Convierte a minúsculas. "HOLA".toLowerCase()
trim() Elimina espacios y otros blancos de los extremos. " hola ".trim()
charAt() Obtiene el carácter de una posición. "DWEC".charAt(0)
slice() Extrae una parte de la cadena. "JavaScript".slice(0, 4)
includes() Comprueba si contiene un texto. "JavaScript".includes("Script")
indexOf() Busca la primera posición de un texto. "banana".indexOf("na")
replace() Sustituye una coincidencia. "Hola Ana".replace("Ana", "Luis")
split() Divide una cadena y devuelve un array. "a,b,c".split(",")

Conversión a mayúsculas y minúsculas

Los métodos toUpperCase() y toLowerCase() permiten transformar el uso de mayúsculas y minúsculas.

JavaScript 
const producto = "Teclado Gaming";

console.log(producto.toUpperCase());
console.log(producto.toLowerCase());
console.log(producto);
Consola 
TECLADO GAMING
teclado gaming
Teclado Gaming

Observa que la variable original no se modifica. Los métodos devuelven nuevas cadenas.

Eliminación de espacios

El método trim() elimina los espacios y otros caracteres en blanco situados al principio y al final de una cadena.

JavaScript 
const usuario = "   ana23   ";

const usuarioLimpio = usuario.trim();

console.log(`[${usuario}]`);
console.log(`[${usuarioLimpio}]`);
Consola 
[   ana23   ]
[ana23]

Este método resulta especialmente útil cuando procesamos datos introducidos por los usuarios.

⚠️ Atención

trim() no elimina los espacios que aparecen entre las palabras. Solo actúa sobre los extremos de la cadena.

Extracción de caracteres y fragmentos

El método charAt() devuelve el carácter situado en una posición determinada.

El método slice() permite extraer una parte de la cadena indicando una posición inicial y, opcionalmente, una final.

JavaScript 
const lenguaje = "JavaScript";

console.log(lenguaje.charAt(0));
console.log(lenguaje.slice(0, 4));
console.log(lenguaje.slice(4));
console.log(lenguaje.slice(-6));
Consola 
J
Java
Script
Script

En slice(0, 4), la posición inicial está incluida, pero la posición final no.

Los índices negativos permiten contar desde el final de la cadena.

Búsqueda y transformación de cadenas

Además de consultar caracteres, con frecuencia necesitamos localizar información, comprobar si un texto contiene determinadas palabras o sustituir fragmentos.

JavaScript proporciona métodos específicos para estas operaciones.

Buscar texto con includes() e indexOf()

El método includes() comprueba si una cadena contiene otra cadena y devuelve un valor booleano.

JavaScript 
const descripcion = "Portátil con 16 GB de RAM";

console.log(descripcion.includes("RAM"));
console.log(descripcion.includes("SSD"));
Consola 
true
false

El método indexOf() devuelve la posición de la primera coincidencia. Si no encuentra el texto, devuelve -1.

JavaScript 
const palabra = "programacion";

console.log(palabra.indexOf("grama"));
console.log(palabra.indexOf("python"));
Consola 
3
-1
📌 Importante

Las búsquedas con estos métodos distinguen entre mayúsculas y minúsculas.

Por ejemplo, "JavaScript".includes("java") devuelve false.

Para realizar una búsqueda sencilla sin distinguir mayúsculas, podemos convertir previamente ambos textos a minúsculas.

Sustituir fragmentos con replace()

El método replace() permite sustituir un fragmento de texto por otro.

JavaScript 
const mensaje = "Pedido pendiente";

const nuevoMensaje =
  mensaje.replace("pendiente", "enviado");

console.log(nuevoMensaje);
Consola 
Pedido enviado

Cuando utilizamos una cadena como primer argumento, replace() sustituye únicamente la primera coincidencia.

Para sustituir todas las coincidencias de una cadena literal, podemos utilizar replaceAll().

JavaScript 
const texto = "rojo, azul, rojo";

console.log(texto.replace("rojo", "verde"));
console.log(texto.replaceAll("rojo", "verde"));
Consola 
verde, azul, rojo
verde, azul, verde

Dividir cadenas con split()

El método split() divide una cadena utilizando un separador y devuelve un array.

JavaScript 
const categorias = "portatiles,teclados,ratones";

const lista = categorias.split(",");

console.log(lista);
console.log(lista[1]);
Consola 
["portatiles", "teclados", "ratones"]
teclados

Este método conecta directamente con lo estudiado en la UT4, ya que nos permite transformar información textual en estructuras de datos.

💻 Ejemplo DAW

Imagina que recibimos una lista de categorías de una tienda separadas por comas. Podemos utilizar split() para obtener un array y después recorrerlo con un bucle o un método de arrays.

El objeto Number

El tipo number se utiliza en JavaScript para representar valores numéricos, tanto enteros como decimales.

Por ejemplo, en una aplicación de gestión de pedidos podemos necesitar almacenar precios, cantidades, descuentos o importes totales.

JavaScript 
const cantidad = 5;
const precio = 19.95;
const descuento = 0.10;

console.log(typeof cantidad);
console.log(typeof precio);
console.log(typeof descuento);
Consola 
number
number
number

Aunque unos valores sean enteros y otros decimales, todos pertenecen al tipo number.

Valores primitivos y objetos Number

Al igual que ocurre con String, podemos distinguir entre un número primitivo y un objeto creado mediante new Number().

JavaScript 
const numero1 = 25;
const numero2 = new Number(25);

console.log(typeof numero1);
console.log(typeof numero2);
Consola 
number
object

En la práctica utilizaremos normalmente números primitivos, ya que son más sencillos y evitan confusiones al comparar valores.

Valores numéricos especiales

JavaScript también puede representar determinados resultados especiales, como Infinity, -Infinity y NaN.

NaN significa Not a Number y suele aparecer cuando una operación numérica no produce un valor numérico válido.

JavaScript 
console.log(10 / 0);
console.log(-10 / 0);
console.log(Number("hola"));
Consola 
Infinity
-Infinity
NaN
⚠️ Atención

Aunque su nombre pueda resultar confuso, NaN pertenece al tipo number.

Por ello, typeof NaN devuelve "number". Para comprobar específicamente este valor utilizaremos Number.isNaN().

Métodos de Number

Number proporciona métodos para presentar valores numéricos y comprobar determinadas características.

Algunos se utilizan sobre un número concreto, mientras que otros se invocan directamente desde Number.

Método Finalidad Ejemplo
toFixed() Devuelve un texto con un número fijo de decimales. (12.345).toFixed(2)
toPrecision() Devuelve un texto con un número de cifras significativas. (123.456).toPrecision(4)
toString() Convierte el número en texto. (25).toString()
Number.isInteger() Comprueba si es un entero. Number.isInteger(10)
Number.isFinite() Comprueba si es un número finito. Number.isFinite(25)
Number.isNaN() Comprueba si el valor es NaN. Number.isNaN(NaN)

Formatear decimales con toFixed()

El método toFixed() permite obtener una representación de un número con una cantidad determinada de cifras decimales.

Es especialmente útil cuando queremos mostrar precios o importes con dos decimales.

JavaScript 
const precio = 19.5;

console.log(precio.toFixed(2));
console.log(precio.toFixed(3));
Consola 
19.50
19.500

Aunque los resultados parecen números, toFixed() devuelve una cadena de texto.

JavaScript 
const precio = 19.5;

const precioFormateado = precio.toFixed(2);

console.log(typeof precioFormateado);
Consola 
string
📌 Importante

toFixed() es un método de formato. No debemos utilizar directamente su resultado como si siguiera siendo un número.

Además, los números decimales se representan internamente mediante aritmética de coma flotante, por lo que algunos cálculos y redondeos pueden presentar pequeñas imprecisiones.

Convertir números en cadenas

El método toString() permite obtener la representación textual de un número.

JavaScript 
const codigo = 2026;

const codigoTexto = codigo.toString();

console.log(codigoTexto);
console.log(typeof codigoTexto);
Consola 
2026
string

La conversión puede resultar útil cuando necesitamos construir mensajes o identificadores a partir de valores numéricos.

Comprobación de enteros y valores finitos

El método Number.isInteger() permite comprobar si un valor es un número entero.

Por su parte, Number.isFinite() permite comprobar si un valor es un número finito.

JavaScript 
console.log(Number.isInteger(8));
console.log(Number.isInteger(8.5));

console.log(Number.isFinite(100));
console.log(Number.isFinite(Infinity));
console.log(Number.isFinite("100"));
Consola 
true
false
true
false
false

Observa que estos métodos no convierten automáticamente una cadena en un número.

Conversión y comprobación de valores

En muchas aplicaciones web, los datos introducidos por los usuarios llegan inicialmente como cadenas de texto.

Por ejemplo, cuando utilizamos prompt(), el resultado es una cadena o null si el usuario cancela.

Antes de realizar operaciones matemáticas, necesitamos comprobar y convertir correctamente esos valores.

Conversión mediante Number()

La función Number() permite convertir determinados valores a tipo numérico.

JavaScript 
console.log(Number("25"));
console.log(Number("12.5"));
console.log(Number("hola"));
console.log(Number(""));
Consola 
25
12.5
NaN
0

Cuando la cadena contiene un valor numérico válido, obtenemos un número.

Si el texto no puede convertirse, el resultado será NaN.

⚠️ Atención

Number("") devuelve 0. Lo mismo sucede con una cadena formada únicamente por espacios.

Por ello, cuando validamos una entrada obligatoria, debemos comprobar primero que el texto no esté vacío, en lugar de confiar únicamente en la conversión.

Diferencias entre Number(), parseInt() y parseFloat()

JavaScript también dispone de parseInt() y parseFloat(), que permiten interpretar la parte inicial de una cadena como un número.

Función Comportamiento Ejemplo
Number() Convierte el valor completo si es válido. Number("12.5") → 12.5
parseInt() Interpreta un entero desde el inicio del texto. parseInt("12.5", 10) → 12
parseFloat() Interpreta un decimal desde el inicio del texto. parseFloat("12.5") → 12.5
JavaScript 
const dato = "25 euros";

console.log(Number(dato));
console.log(parseInt(dato, 10));
console.log(parseFloat(dato));
Consola 
NaN
25
25

En este caso, Number() no puede convertir el texto completo.

Sin embargo, parseInt() y parseFloat() interpretan la parte numérica inicial y dejan de leer al encontrar un carácter que no pertenece al número.

📌 Importante

Para validar que una entrada contiene exclusivamente un número válido, normalmente conviene comprobar la entrada completa y utilizar Number().

parseInt() y parseFloat() son útiles cuando queremos interpretar expresamente un número situado al principio de un texto, pero pueden aceptar entradas incompletas.

Comprobación de NaN

El método Number.isNaN() permite comprobar si un valor es exactamente NaN.

JavaScript 
const valor1 = Number("30");
const valor2 = Number("treinta");

console.log(Number.isNaN(valor1));
console.log(Number.isNaN(valor2));
Consola 
false
true

En una aplicación real, podemos combinar Number() con Number.isFinite() para comprobar que hemos obtenido un valor numérico finito.

JavaScript 
const entrada = "49.90";

const precio = Number(entrada);

if (Number.isFinite(precio) && precio >= 0) {
  console.log("Precio válido:", precio);
} else {
  console.log("Precio no válido");
}
Consola 
Precio válido: 49.9

Esta comprobación es adecuada para un valor ya convertido, siempre que también hayamos verificado previamente las condiciones de la entrada, como que no esté vacía.

Ejemplos prácticos

Vamos a combinar las funcionalidades de String y Number en situaciones relacionadas con el desarrollo de aplicaciones web.

Ejemplo 1. Normalización de nombres de productos

Una tienda online recibe nombres de productos escritos con diferentes combinaciones de mayúsculas, minúsculas y espacios innecesarios.

Queremos eliminar los espacios de los extremos y mostrar los nombres en mayúsculas.

JavaScript 
const productos = [
  "   teclado mecánico   ",
  "Ratón Inalámbrico",
  "  MONITOR LED "
];

const productosNormalizados =
  productos.map(producto =>
    producto.trim().toUpperCase()
  );

console.log(productosNormalizados);
Consola 
[
  "TECLADO MECÁNICO",
  "RATÓN INALÁMBRICO",
  "MONITOR LED"
]

En este ejemplo combinamos métodos de cadenas con el método map() de arrays, estudiado en unidades anteriores.

💻 Ejemplo DAW

Normalizar textos puede facilitar las búsquedas y comparaciones dentro de un catálogo.

Sin embargo, transformar todos los nombres a mayúsculas es solo una decisión de presentación o normalización básica: no siempre conviene sustituir el nombre original almacenado.

Ejemplo 2. Cálculo del importe de un pedido

Supongamos que una aplicación recibe el precio y la cantidad de un producto como cadenas.

Antes de calcular el importe, debemos convertir los datos y comprobar que son válidos.

JavaScript 
const precioTexto = "29.95";
const cantidadTexto = "3";

const precio = Number(precioTexto);
const cantidad = Number(cantidadTexto);

const precioValido =
  precioTexto.trim() !== "" &&
  Number.isFinite(precio) &&
  precio >= 0;

const cantidadValida =
  cantidadTexto.trim() !== "" &&
  Number.isInteger(cantidad) &&
  cantidad > 0;

if (precioValido && cantidadValida) {

  const total = precio * cantidad;

  console.log("Precio:", precio.toFixed(2));
  console.log("Cantidad:", cantidad);
  console.log("Total:", total.toFixed(2));

} else {

  console.log("Datos del pedido no válidos");

}
Consola 
Precio: 29.95
Cantidad: 3
Total: 89.85

El programa realiza las siguientes operaciones:

  1. Convierte las cadenas a valores numéricos.
  2. Comprueba que las entradas no estén vacías.
  3. Verifica que el precio sea un número finito no negativo.
  4. Comprueba que la cantidad sea un entero positivo.
  5. Calcula el importe y lo presenta con dos decimales.
⚠️ Atención

Este ejemplo utiliza números decimales para facilitar el aprendizaje.

En aplicaciones económicas reales debemos prestar especial atención a la precisión de los cálculos. Una solución habitual consiste en trabajar con unidades enteras de la moneda, como céntimos, o utilizar herramientas de aritmética decimal adecuadas.
