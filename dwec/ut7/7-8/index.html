7.8 Objeto window: propiedades y métodos

En el apartado anterior hemos presentado el BOM y sus principales objetos. Ahora estudiaremos con más detalle window, el objeto que representa el contexto de una ventana o pestaña del navegador y que ofrece propiedades y métodos para interactuar con ella.

Aprenderemos a consultar el tamaño de la zona visible, detectar el desplazamiento de la página y mostrar cuadros de diálogo sencillos. Son operaciones frecuentes cuando desarrollamos aplicaciones web con JavaScript.

📌 Importante

En una página web, window es el objeto global del contexto de navegación. Muchas de sus propiedades y métodos pueden utilizarse con o sin el prefijo window..

El objeto window

El objeto window representa la ventana o pestaña del navegador en la que se ejecuta un documento. Proporciona acceso a funciones del entorno y a otros objetos, como location, history y document.

No debemos confundir la ventana del navegador con el documento HTML: window ofrece información sobre el entorno; document representa el contenido de la página y pertenece al DOM.

JavaScript
console.log(window === globalThis);
console.log(window.document === document);
console.log(window.location === location);

Salida por consola:

Consola
true
true
true

Estas comparaciones son verdaderas cuando ejecutamos el código en el contexto principal de una página web. En otros entornos, como Node.js o Web Workers, window puede no existir.

💻 Ejemplo DAW

Una aplicación de reservas puede utilizar window.innerWidth para conocer el ancho disponible, mientras que utiliza document para actualizar la lista de reservas que aparece en la página.

window y el ámbito global

En un script clásico ejecutado en una página web, el objeto global es window. Por ello, métodos como alert() o setTimeout() pueden invocarse sin escribir window..

JavaScript
console.log(window.parseInt === parseInt);
console.log(window.setTimeout === setTimeout);
console.log(window.JSON === JSON);

Salida por consola:

Consola
true
true
true

Sin embargo, no todas las variables declaradas en el nivel superior pasan a ser propiedades de window. Esto depende de la forma de declaración y del tipo de script.

JavaScript
var centro = "IES";
let modulo = "DWEC";
const curso = 2;

console.log(window.centro);
console.log(window.modulo);
console.log(window.curso);

Salida por consola (script clásico, en el ámbito global):

Consola
IES
undefined
undefined
⚠️ Atención

Este ejemplo presupone que se ejecuta como script clásico en el ámbito global. Si se ejecuta dentro de una función, un módulo JavaScript o determinados entornos de consola, el resultado puede ser distinto. Es preferible declarar variables con let o const y evitar depender de propiedades globales implícitas.

Otra característica importante es que window contiene referencias a sí mismo y al documento:

JavaScript
console.log(window.window === window);
console.log(window.document === document);

Salida por consola:

Consola
true
true

Dimensiones de la ventana

JavaScript permite consultar el tamaño de la zona interior de la ventana y otras medidas relacionadas con la pantalla. Estas propiedades son útiles para adaptar comportamientos, aunque para el diseño responsive suele ser preferible utilizar CSS y media queries.

PropiedadSignificadoUnidad
window.innerWidthAncho interior del área visible, incluida la barra de desplazamiento vertical si la hayPíxeles CSS
window.innerHeightAlto interior del área visiblePíxeles CSS
window.outerWidthAncho exterior de la ventana (según navegador y plataforma)Píxeles CSS
window.outerHeightAlto exterior de la ventana (según navegador y plataforma)Píxeles CSS
JavaScript
console.log("Ancho interior:", window.innerWidth);
console.log("Alto interior:", window.innerHeight);
console.log("Ancho exterior:", window.outerWidth);

Salida por consola (valores ilustrativos):

Consola
Ancho interior: 1280
Alto interior: 720
Ancho exterior: 1296

Los valores dependen del navegador, el tamaño de la ventana, el zoom y el dispositivo. No son constantes ni tienen por qué coincidir con los de tu ordenador.

Detectar cambios de tamaño

El evento resize se dispara cuando cambia el tamaño de la ventana. Podemos registrar una función para consultar sus dimensiones cada vez que ocurra.

JavaScript
window.addEventListener("resize", () => {
  console.log("Nuevo ancho:", window.innerWidth);
  console.log("Nuevo alto:", window.innerHeight);
});

Después de ejecutar el código, cambia el tamaño de la ventana del navegador y observa los mensajes. No existe una salida fija: los números dependen de cada cambio.

⚠️ Atención

El evento resize puede ejecutarse muchas veces mientras se cambia el tamaño de la ventana. Evita realizar cálculos pesados en cada ejecución. Para adaptar estilos visuales, utiliza CSS siempre que sea posible.

Desplazamiento y posición

Cuando una página tiene más contenido del que cabe en pantalla, el usuario puede desplazarse vertical u horizontalmente. window proporciona propiedades para consultar cuánto se ha desplazado el documento y métodos para mover la vista.

Propiedad o métodoFunción
window.scrollXNúmero de píxeles desplazados horizontalmente
window.scrollYNúmero de píxeles desplazados verticalmente
window.scrollTo(x, y)Desplaza la ventana hasta unas coordenadas del documento
window.scrollBy(x, y)Desplaza la ventana una distancia relativa a la posición actual
JavaScript
console.log("Desplazamiento horizontal:", window.scrollX);
console.log("Desplazamiento vertical:", window.scrollY);

Salida por consola (ejemplo con la página desplazada 350 píxeles):

Consola
Desplazamiento horizontal: 0
Desplazamiento vertical: 350

Desplazamiento absoluto con scrollTo()

JavaScript
window.scrollTo({
  top: 0,
  left: 0,
  behavior: "smooth"
});

Este código solicita volver suavemente al principio del documento. La animación puede variar según el navegador y las preferencias de accesibilidad.

Desplazamiento relativo con scrollBy()

JavaScript
window.scrollBy({
  top: 300,
  left: 0,
  behavior: "smooth"
});

Este segundo ejemplo solicita desplazarse 300 píxeles hacia abajo desde la posición actual. Si la página ya está cerca del final, el desplazamiento real puede ser menor.

⚠️ Atención

Los métodos window.scrollTo() y window.scrollBy() controlan el desplazamiento de la ventana.

Si una página contiene elementos con barras de desplazamiento independientes, como un menú lateral, estos métodos no desplazan necesariamente dichos elementos.

Para desplazar un elemento concreto que dispone de su propia barra de desplazamiento, podemos utilizar los métodos scrollTo() o scrollBy() directamente sobre ese elemento.

Escuchar el evento scroll

JavaScript
window.addEventListener("scroll", () => {
  console.log("Posición vertical:", Math.round(window.scrollY));
});

Al desplazarte, la consola mostrará sucesivos valores. Este tipo de evento puede utilizarse para activar un botón de «Volver arriba» cuando el usuario ha recorrido parte de la página.

📌 Importante

scrollY indica el desplazamiento vertical del documento, no la altura total de la página. Los métodos scrollTo() y scrollBy() mueven la vista, pero no modifican el contenido HTML.

Métodos alert(), confirm() y prompt()

El navegador ofrece tres métodos clásicos para mostrar mensajes y solicitar respuestas sencillas. Son útiles para practicar la interacción con el usuario, aunque en aplicaciones reales suelen sustituirse por interfaces HTML más flexibles y accesibles.

MétodoQué haceValor devuelto
alert(mensaje)Muestra un mensaje informativoundefined
confirm(mensaje)Solicita aceptar o cancelartrue o false
prompt(mensaje, valor)Solicita una entrada de textoCadena de texto o null

alert(): mostrar un aviso

JavaScript
window.alert("Bienvenido al módulo DWEC");
console.log("El programa continúa");

Salida por consola después de cerrar el aviso:

Consola
El programa continúa

Primero aparece el cuadro de diálogo. Cuando el usuario lo cierra, se ejecuta la siguiente instrucción. El mensaje del aviso se muestra en pantalla, no en la consola.

confirm(): aceptar o cancelar

JavaScript
const continuar = window.confirm("¿Deseas guardar los cambios?");

if (continuar) {
  console.log("El usuario ha aceptado");
} else {
  console.log("El usuario ha cancelado");
}

Salida por consola si pulsa «Aceptar»:

Consola
El usuario ha aceptado

Salida por consola si pulsa «Cancelar»:

Consola
El usuario ha cancelado

El resultado de confirm() es un booleano. Por ello, puede utilizarse directamente como condición de un if.

prompt(): solicitar texto

JavaScript
const nombre = window.prompt("Introduce tu nombre:", "");

if (nombre === null) {
  console.log("Entrada cancelada");
} else if (nombre.trim() === "") {
  console.log("No se ha escrito ningún nombre");
} else {
  console.log("Hola, " + nombre.trim());
}

Salida por consola si escribe «Ana» y acepta:

Consola
Hola, Ana

Si el usuario cancela, prompt() devuelve null. Si acepta sin escribir nada, normalmente devuelve una cadena vacía. Son situaciones distintas y conviene tratarlas por separado.

⚠️ Atención

prompt() siempre devuelve texto o null, incluso cuando se escribe un número. Antes de operar matemáticamente, convierte el valor y comprueba que sea válido. Los navegadores también pueden restringir o suprimir cuadros de diálogo en determinadas circunstancias.

Ejemplos prácticos

Ejemplo 1. Detectar el espacio disponible

Una aplicación puede mostrar un mensaje diferente en función del ancho interior de la ventana. Este ejemplo solo consulta el tamaño una vez, en el momento de ejecutarse.

JavaScript
const ancho = window.innerWidth;

if (ancho < 768) {
  console.log("Vista de ancho reducido");
} else {
  console.log("Vista de ancho amplio");
}

Salida por consola si el ancho es de 1200 píxeles:

Consola
Vista de ancho amplio

Para que el comportamiento se actualice al cambiar el tamaño, habría que volver a ejecutar la comprobación, por ejemplo mediante el evento resize.

Ejemplo 2. Calcular un precio con prompt()

Solicitaremos una cantidad de unidades y calcularemos el coste total, comprobando antes que la entrada sea un número entero positivo.

JavaScript
const entrada = window.prompt("¿Cuántas unidades deseas comprar?");
const cantidad = entrada === null ? NaN : Number(entrada);
const precioUnidad = 12.5;

if (entrada === null) {
  console.log("Operación cancelada");
} else if (entrada.trim() === "" || !Number.isInteger(cantidad) || cantidad <= 0) {
  console.log("Introduce una cantidad entera positiva");
} else {
  const total = cantidad * precioUnidad;
  console.log("Total:", total.toFixed(2) + " €");
}

Salida por consola si introduce 3:

Consola
Total: 37.50 €

Utilizamos Number() para convertir la cadena, Number.isInteger() para validar el resultado y toFixed(2) para mostrar dos decimales. El ejemplo evita realizar cálculos con entradas canceladas o no válidas.

Ejemplo 3. Confirmar una acción

Antes de realizar una operación importante, podemos solicitar confirmación. En este ejemplo no se elimina ningún dato real: únicamente se muestra un mensaje.

JavaScript
const borrar = window.confirm("¿Confirmas que deseas borrar el borrador?");

if (borrar) {
  console.log("Borrador marcado para eliminar");
} else {
  console.log("El borrador se conserva");
}

Salida por consola si pulsa «Cancelar»:

Consola
El borrador se conserva
💻 Ejemplo DAW

En una aplicación de gestión de pedidos, confirm() puede servir para practicar la confirmación de acciones. En una interfaz profesional, suele ser preferible un cuadro de diálogo HTML accesible, con botones claramente identificados.

💭 Piensa

Observa el siguiente código sin ejecutarlo. Supón que el usuario escribe "5" en el cuadro de diálogo y pulsa «Aceptar». ¿Qué se mostrará en la consola? ¿Qué sucedería si pulsa «Cancelar»?

JavaScript
const dato = window.prompt("Introduce una cantidad:");

console.log(typeof dato);
console.log(dato === null);

if (dato !== null) {
  console.log(Number(dato) + 2);
}
Ver una posible solución

Si escribe 5 y acepta, prompt() devuelve la cadena "5". Por eso typeof indica string. La comparación con null es falsa y, tras convertir el texto a número, la suma da 7.

Salida por consola si introduce 5:

Consola
string
false
7

Si pulsa «Cancelar», dato será null. La consola mostrará object (comportamiento histórico de typeof null) y true. La suma no se ejecutará.

Salida por consola si cancela:

Consola
object
true
