7.1 Introducción a los objetos predefinidos de JavaScript

En la unidad anterior hemos aprendido a crear y utilizar nuestros propios objetos en JavaScript. Hemos trabajado con propiedades, métodos, clases y diferentes formas de organizar la información y el comportamiento de una aplicación.

Sin embargo, cuando desarrollamos programas, no siempre necesitamos construir todas las funcionalidades desde cero. El propio lenguaje JavaScript incorpora numerosas herramientas que ya están preparadas para realizar operaciones habituales.

Por ejemplo, podemos necesitar transformar un texto, realizar un cálculo, consultar una fecha o comprobar si una cadena cumple un determinado patrón. Para resolver estas tareas, JavaScript proporciona objetos y funcionalidades que podemos utilizar directamente.

En este apartado conoceremos qué son los objetos predefinidos, para qué sirven, cómo se clasifican y cómo podemos acceder a sus propiedades y métodos.

📌 Importante

Los objetos predefinidos son objetos y funcionalidades que JavaScript proporciona para realizar operaciones habituales sin tener que programarlas completamente desde cero.

Algunos pertenecen al propio lenguaje, mientras que otros son proporcionados por el entorno donde se ejecuta el programa, como el navegador.

Qué son los objetos predefinidos

Un objeto predefinido es un objeto que ya está disponible en el lenguaje o en su entorno de ejecución y que ofrece funcionalidades para trabajar con determinados tipos de información o realizar tareas específicas.

A diferencia de los objetos que creamos nosotros mismos para representar productos, clientes o pedidos, estos objetos proporcionan herramientas de uso general.

Por ejemplo, JavaScript dispone del objeto Math, que agrupa constantes y métodos matemáticos. Podemos utilizarlo directamente para calcular una raíz cuadrada:

JavaScript 
const resultado = Math.sqrt(81);

console.log(resultado); // 9

En este ejemplo, Math ya existe y el método sqrt() está preparado para calcular raíces cuadradas. No hemos tenido que crear una clase ni programar el algoritmo matemático.

Es importante comprender que no todos los objetos predefinidos se utilizan de la misma manera. Algunos, como Math, se usan directamente; otros, como Date, permiten crear instancias que representan valores concretos.

⚠️ Atención

Que un objeto sea predefinido no significa que tengamos que escribir siempre new para utilizarlo.

Por ejemplo, Math se utiliza directamente y no admite new Math(). En cambio, podemos crear una fecha utilizando new Date().

Para qué sirven

Los objetos predefinidos permiten resolver problemas frecuentes de programación de una forma más sencilla, clara y reutilizable.

En una aplicación web pueden intervenir diferentes operaciones: procesar información, realizar cálculos, consultar fechas, comprobar datos o gestionar determinadas características del navegador.

JavaScript proporciona herramientas especializadas para muchas de estas tareas.

Necesidad Herramienta Ejemplo de uso
Trabajar con textos String Convertir un nombre a mayúsculas.
Trabajar con números Number Comprobar si un valor numérico es válido.
Realizar cálculos Math Calcular una raíz cuadrada.
Gestionar fechas Date Consultar la fecha actual.
Buscar patrones RegExp Comprobar si un texto sigue un formato.
Convertir información JSON Transformar un objeto en texto JSON.
Acceder al navegador window Consultar el tamaño de la ventana.

Utilizar estas herramientas presenta varias ventajas:

  • Reduce el código necesario: evitamos implementar operaciones que ya proporciona JavaScript.
  • Facilita la lectura: los métodos predefinidos expresan claramente qué operación realizamos.
  • Favorece la reutilización: podemos emplear las mismas herramientas en diferentes aplicaciones.
  • Permite concentrarse en el problema: dedicamos más tiempo a desarrollar la funcionalidad de la aplicación.
💻 Ejemplo DAW

Imagina una aplicación web de gestión de pedidos. Cuando se registra un pedido, el sistema puede necesitar obtener la fecha actual, calcular cantidades y preparar los datos para almacenarlos.

En lugar de crear desde cero todos esos mecanismos, podemos utilizar las funcionalidades predefinidas que ofrece JavaScript.

Clasificación de los objetos predefinidos

JavaScript incorpora diferentes objetos y funcionalidades que podemos agrupar según el tipo de tarea que realizan.

En esta unidad nos centraremos especialmente en las siguientes categorías:

Textos y números String y Number
Operaciones matemáticas Math
Fechas y horas Date
Patrones de texto RegExp
Conversión de datos JSON
Entorno del navegador window, location, history...

Esta clasificación nos ayuda a identificar qué herramienta puede resultar más adecuada según el problema que necesitemos resolver.

Por ejemplo, si necesitamos trabajar con fechas utilizaremos Date; si necesitamos realizar operaciones matemáticas recurriremos a Math; y si queremos consultar información del navegador utilizaremos los objetos que proporciona ese entorno.

📌 Importante

La clasificación anterior es una agrupación didáctica de las herramientas que estudiaremos en la UT7. No representa una clasificación completa de todos los objetos incorporados en JavaScript.

También existen otros objetos y estructuras predefinidas, como Array, Object, Map y Set, algunos de los cuales ya hemos utilizado en unidades anteriores.

Objetos nativos y objetos del navegador

Una distinción fundamental consiste en diferenciar las herramientas que forman parte del propio lenguaje JavaScript de aquellas que proporciona el entorno donde se ejecuta el programa.

Objetos incorporados en JavaScript

Son objetos y funcionalidades definidos por el lenguaje. Están disponibles en los entornos JavaScript compatibles con las características correspondientes.

Algunos ejemplos son: Math, Date, String, Number, RegExp y JSON.

Por ejemplo:

JavaScript 
console.log(Math.PI);

const fecha = new Date();

console.log(fecha instanceof Date);

La primera instrucción muestra el valor de la constante matemática PI. Después creamos un objeto de tipo Date y comprobamos su tipo mediante instanceof.

La segunda salida será true, porque fecha es una instancia de Date.

Objetos proporcionados por el navegador

Cuando ejecutamos JavaScript dentro de una página web, el navegador proporciona objetos adicionales que permiten acceder a características del entorno.

Entre ellos encontramos window, location, history, navigator y screen.

Estos objetos permiten consultar o gestionar determinadas características de la ventana, la navegación y el navegador.

Característica Objetos incorporados Objetos del navegador
Origen Lenguaje JavaScript Entorno del navegador
Finalidad Operaciones generales de programación Interacción con el entorno web
Ejemplos Math, Date, JSON window, location, history
Disponibilidad En entornos JavaScript compatibles En entornos que proporcionan esas API
⚠️ Atención

JavaScript no se ejecuta únicamente en navegadores. También puede ejecutarse en otros entornos, como Node.js.

Por ello, no debemos suponer que todos los objetos disponibles en una página web existen en cualquier programa JavaScript. Por ejemplo, el objeto window no está disponible como objeto global en Node.js.

Acceso a propiedades y métodos

En la UT6 ya hemos aprendido a acceder a las propiedades y a invocar los métodos de un objeto. Con los objetos predefinidos utilizaremos esa misma sintaxis.

Cuando queremos consultar una propiedad, escribimos el nombre del objeto, un punto y el nombre de la propiedad.

JavaScript 
console.log(Math.PI);

En este caso, PI es una propiedad del objeto Math. Su valor es aproximadamente 3.141592653589793.

Para invocar un método, añadimos los paréntesis y, cuando corresponda, los argumentos necesarios.

JavaScript 
const numero = Math.abs(-15);

console.log(numero); // 15

El método abs() devuelve el valor absoluto del número recibido.

También podemos utilizar métodos asociados a valores concretos, como una cadena de texto:

JavaScript 
const modulo = "dwec";

console.log(modulo.toUpperCase()); // DWEC

JavaScript permite utilizar métodos de String sobre cadenas primitivas, como sucede en este ejemplo. No necesitamos crear explícitamente un objeto mediante new String().

📌 Importante

No todos los miembros de un objeto se utilizan igual:

  • Propiedad: se consulta sin paréntesis, como Math.PI.
  • Método: se invoca con paréntesis, como Math.abs(-15).

Además, algunos métodos pertenecen directamente a un objeto o constructor, mientras que otros se utilizan sobre instancias o valores concretos.

Primer ejemplo práctico

Vamos a utilizar varias funcionalidades predefinidas en un pequeño programa relacionado con la gestión de un pedido.

El programa debe mostrar el nombre del producto en mayúsculas, calcular el valor absoluto de una diferencia de unidades y comprobar que podemos crear un objeto de fecha.

JavaScript 
const producto = "teclado";
const diferenciaUnidades = -3;
const fechaPedido = new Date();

const nombreFormateado = producto.toUpperCase();
const diferenciaAbsoluta = Math.abs(diferenciaUnidades);

console.log("Producto:", nombreFormateado);
console.log("Diferencia:", diferenciaAbsoluta);
console.log("Fecha válida:", !Number.isNaN(fechaPedido.getTime()));

La salida esperada será:

Consola 
Producto: TECLADO
Diferencia: 3
Fecha válida: true

Observa que el programa utiliza varias funcionalidades ya disponibles en JavaScript:

  • toUpperCase() transforma el texto del producto.
  • Math.abs() calcula el valor absoluto de la diferencia de unidades.
  • new Date() crea un objeto que representa el momento actual.
  • getTime() y Number.isNaN() permiten comprobar en este ejemplo que la fecha creada es válida.

No es necesario memorizar todavía todos estos métodos. Los estudiaremos con mayor profundidad en los siguientes apartados.

💻 Ejemplo DAW

En una aplicación de comercio electrónico podríamos utilizar objetos predefinidos para preparar nombres de productos, calcular importes, registrar fechas y convertir información para almacenarla.

La ventaja es que podemos combinar estas herramientas con nuestros propios objetos y funciones, construyendo aplicaciones más completas sin tener que desarrollar cada operación desde cero.
