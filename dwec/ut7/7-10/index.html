7.10 Objeto location: información y navegación

En los apartados anteriores hemos trabajado con el objeto window, la apertura de ventanas y los temporizadores. Ahora estudiaremos cómo consultar la dirección de una página y cómo navegar a otras direcciones desde JavaScript utilizando el objeto location.

Este objeto resulta útil cuando una aplicación necesita redirigir al usuario, consultar parámetros de una URL, cambiar de página o recargar el contenido actual.

📌 Importante

window.location representa la dirección del documento actual y permite consultar o modificar la URL. Cambiar su dirección puede provocar una navegación y abandonar la página actual.

El objeto location

El objeto location forma parte de la interfaz del navegador y está disponible a través de window.location. Como ocurre con otras propiedades de window, normalmente podemos omitir el prefijo window..

JavaScript
console.log(window.location === location); // true
console.log(location.protocol); // Protocolo de la página actual

La primera expresión compara dos referencias al mismo objeto. La segunda consulta el protocolo de la página, que normalmente será https: cuando accedemos a una web segura.

⚠️ Atención

Los resultados dependen de la dirección desde la que se ejecute el código. Si abres un archivo directamente desde tu ordenador, puede aparecer el protocolo file:. Para realizar las pruebas es preferible utilizar un servidor local, como Live Server de Visual Studio Code.

La propiedad href

La propiedad location.href contiene la URL completa del documento actual. Podemos leerla para conocer dónde está el usuario o asignarle otra dirección para iniciar una navegación.

JavaScript
console.log(location.href);
console.log(typeof location.href);

Salida orientativa si la página se encuentra en https://www.ejemplo.com/tienda/producto.html?id=25:

Consola
https://www.ejemplo.com/tienda/producto.html?id=25
string

La primera línea es solo un ejemplo: en la práctica aparecerá la dirección de la página que tengas abierta.

Navegar mediante href

JavaScript
// Esta instrucción abandona la página actual:
location.href = "https://example.com";

Al asignar una nueva dirección a href, el navegador solicita cargarla en el contexto actual. Por ello, no conviene ejecutar este ejemplo en la consola de tus apuntes si no quieres salir de la página.

💻 Ejemplo DAW

En una tienda online, tras completar correctamente un pedido, podríamos redirigir al usuario a una página de confirmación mediante location.href = "confirmacion.html";. La ruta es relativa a la URL actual y debe existir en el proyecto.

Partes de una URL

Además de la dirección completa, location ofrece propiedades para consultar sus componentes. Observa esta dirección ficticia:

URL de ejemplo
https://www.ejemplo.com:8080/catalogo/producto.html?id=25&color=azul#detalles

Para practicar sin depender de la dirección de la página actual, podemos crear un objeto URL a partir de una cadena. Este objeto permite estudiar las mismas partes de una dirección sin provocar ninguna navegación.

JavaScript
const direccion = new URL(
  "https://www.ejemplo.com:8080/catalogo/producto.html?id=25&color=azul#detalles"
);

console.log(direccion.protocol);
console.log(direccion.hostname);
console.log(direccion.pathname);
console.log(direccion.search);
console.log(direccion.hash);

Consultar parámetros de búsqueda

Los parámetros que aparecen después del signo ? suelen utilizarse para indicar filtros, identificadores o búsquedas. Podemos acceder a ellos mediante URLSearchParams.

JavaScript
const direccion = new URL(
  "https://www.ejemplo.com/catalogo?id=25&color=azul"
);

const parametros = direccion.searchParams;
console.log(parametros.get("id"));
console.log(parametros.get("color"));
console.log(parametros.has("oferta"));

Salida por consola:

Consola
25
azul
false

get() devuelve el valor como cadena de texto, o null si el parámetro no existe. has() indica si está presente. En una página real podríamos utilizar new URLSearchParams(location.search) para leer sus parámetros.

⚠️ Atención

Los parámetros de una URL pueden ser modificados por cualquier usuario. No deben considerarse datos fiables: es necesario validarlos antes de utilizarlos. Tampoco conviene colocar contraseñas ni información sensible en una URL.

Navegación con assign() y replace()

El objeto location dispone de métodos para navegar a otra dirección. Los dos principales son assign() y replace(). Ambos cargan otra página, pero se diferencian en su relación con el historial.

MétodoQué haceHistorial de navegación
location.assign(url)Navega a la URL indicadaNormalmente conserva la página anterior, permitiendo volver con Atrás
location.replace(url)Sustituye la entrada actual por la nueva URLNo conserva la entrada sustituida para volver a ella con Atrás

Utilizar assign()

JavaScript
// Ejemplo: abrir una página del propio proyecto
location.assign("productos.html");

El navegador intentará cargar productos.html. Si el usuario utiliza el botón «Atrás», normalmente podrá regresar a la página anterior.

Utilizar replace()

JavaScript
// Ejemplo: sustituir una pantalla temporal
location.replace("inicio.html");

Este método puede ser útil para sustituir una pantalla de redirección que no necesitamos mantener como entrada del historial. No elimina todo el historial: solo reemplaza la entrada actual.

📌 Importante

href, assign() y replace() pueden provocar que se abandone la página actual. La diferencia más importante es que replace() reemplaza la entrada actual del historial, mientras que assign() realiza una navegación ordinaria.

Rutas absolutas y relativas

TipoEjemploInterpretación
Absolutahttps://example.com/ayuda.htmlIndica una dirección completa
Relativaayuda.htmlSe resuelve a partir de la URL actual
Desde la raíz del sitio/contacto.htmlSe resuelve desde la raíz del origen actual

Una ruta relativa no depende de la ubicación del archivo JavaScript, sino de la URL base del documento (que también puede verse afectada por una etiqueta <base>).

Recarga de páginas

El método location.reload() solicita al navegador que vuelva a cargar la página actual. Puede utilizarse, por ejemplo, cuando el usuario desea actualizar una pantalla después de realizar cambios en el servidor.

JavaScript
// Recarga la página actual
location.reload();

Este ejemplo provoca una recarga real; por tanto, no debe ejecutarse sin querer mientras estés trabajando en los apuntes. La forma en que se reutilizan los recursos almacenados en caché depende del navegador y de sus políticas.

⚠️ Atención

Una recarga puede reiniciar el estado de las variables JavaScript y hacer que se pierdan los datos que solo estaban guardados en memoria. Antes de recargar una aplicación, comprueba si existen cambios sin guardar.

Ejemplos prácticos

Ejemplo 1. Identificar la sección actual

En una aplicación web podemos consultar la ruta para saber qué recurso se está mostrando. Usaremos una URL de ejemplo para obtener siempre la misma salida.

JavaScript
const direccion = new URL(
  "https://www.ejemplo.com/tienda/productos.html"
);

console.log("Ruta:", direccion.pathname);
console.log("Es la página de productos:",
  direccion.pathname.endsWith("productos.html"));

Salida por consola:

Consola
Ruta: /tienda/productos.html
Es la página de productos: true

Ejemplo 2. Obtener el identificador de un producto

Imagina que una tienda muestra un producto a partir de una dirección que contiene el parámetro id. Antes de utilizarlo debemos comprobar que sea válido.

JavaScript
const direccion = new URL(
  "https://www.ejemplo.com/producto.html?id=25"
);

const idTexto = direccion.searchParams.get("id");
const idProducto = Number(idTexto);

if (idTexto !== null && Number.isInteger(idProducto) && idProducto > 0) {
  console.log("Producto solicitado:", idProducto);
} else {
  console.log("Identificador no válido");
}

Salida por consola:

Consola
Producto solicitado: 25

El valor del parámetro llega como texto y se convierte a número. Comprobamos que sea un entero positivo antes de utilizarlo.

Ejemplo 3. Redirigir después de una acción

Cuando una aplicación termina una operación correctamente, puede ofrecer un botón para navegar a una página de confirmación.

JavaScript
// Se presupone que existe un botón con id="verConfirmacion"
const boton = document.querySelector("#verConfirmacion");

boton.addEventListener("click", () => {
  location.assign("confirmacion.html");
});

Este ejemplo requiere un botón HTML con id="verConfirmacion" y un archivo confirmacion.html accesible desde la ruta actual. La navegación se produce únicamente cuando el usuario pulsa el botón.

💻 Ejemplo DAW

En una aplicación de gestión de pedidos, location.search puede indicar qué pedido consultar, location.assign() permite ir a su ficha y location.reload() puede volver a solicitar la página. Es importante validar los parámetros y evitar recargas innecesarias.

💭 Piensa

Sin ejecutar el código, indica qué mensajes aparecerán en la consola. ¿Qué devuelve get("categoria") cuando el parámetro no existe? ¿Se produce alguna navegación?

JavaScript
const direccion = new URL(
  "https://www.ejemplo.com/catalogo.html?pagina=3#ofertas"
);

console.log(direccion.pathname);
console.log(direccion.searchParams.get("pagina"));
console.log(direccion.searchParams.get("categoria"));
console.log(direccion.hash);
Ver una posible solución

La URL se analiza con new URL(), pero no se modifica la dirección del navegador. El parámetro pagina existe y su valor es la cadena "3"; el parámetro categoria no existe y get() devuelve null.

Salida esperada por consola:

3
null

No se produce ninguna navegación porque el código únicamente consulta propiedades del objeto URL.
