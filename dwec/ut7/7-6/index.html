7.6 Objeto JSON y conversión de datos

Hasta ahora hemos trabajado con distintos tipos de datos de JavaScript: cadenas de texto, números, valores booleanos, arrays y objetos. Todos ellos permiten representar información dentro de nuestros programas.

Sin embargo, en una aplicación web no siempre trabajamos con datos que se encuentran únicamente en nuestro propio código. En muchas ocasiones necesitamos guardar información, recuperarla o intercambiarla con otros sistemas.

Por ejemplo, una tienda online puede enviar los datos de un pedido a un servidor, recibir un catálogo de productos o almacenar temporalmente la información de un carrito de compra.

Para facilitar estas operaciones se utiliza habitualmente JSON, un formato de texto que permite representar datos estructurados de una manera sencilla.

📌 Importante

JSON es uno de los formatos más utilizados para intercambiar información entre aplicaciones web y servidores.

JavaScript proporciona el objeto predefinido JSON, que incluye métodos para convertir objetos y otros valores en texto JSON y para realizar la operación inversa.

Qué es JSON

JSON son las siglas de JavaScript Object Notation, que podemos traducir como notación de objetos de JavaScript.

Se trata de un formato de texto utilizado para representar información estructurada. Aunque su sintaxis está inspirada en los objetos de JavaScript, JSON es independiente del lenguaje y puede utilizarse también en Python, Java, PHP y muchos otros.

Imaginemos que una aplicación necesita representar la información de un alumno:

JSON 
{
  "nombre": "Lucía",
  "edad": 21,
  "matriculado": true,
  "modulos": ["DWEC", "DIW", "DAW"]
}

Este texto contiene cuatro propiedades: el nombre del alumno, su edad, si está matriculado y los módulos que está cursando.

Cada propiedad está formada por una clave y un valor. Las claves aparecen entre comillas dobles, mientras que los valores pueden ser de diferentes tipos.

💻 Ejemplo DAW

Una aplicación de gestión académica podría recibir del servidor un documento JSON con los datos de un alumno.

Una vez convertido a un objeto de JavaScript, el programa podría consultar su nombre, mostrar los módulos matriculados o actualizar la información de la interfaz.

¿Por qué se utiliza JSON?

JSON se utiliza ampliamente porque presenta varias ventajas:

  • Su estructura es relativamente sencilla de leer y escribir.
  • Permite representar objetos, arrays y datos anidados.
  • Es compatible con numerosos lenguajes de programación.
  • Es adecuado para intercambiar datos entre el navegador y un servidor.
  • JavaScript incorpora herramientas para convertirlo fácilmente.
⚠️ Atención

Aunque JSON incluye la palabra JavaScript en su nombre, no es código JavaScript ejecutable.

JSON es un formato de datos. Su finalidad es representar información, no ejecutar instrucciones.

Sintaxis y estructura de JSON

Para escribir correctamente un documento JSON debemos respetar unas reglas de sintaxis.

La estructura de un objeto JSON se representa mediante llaves { }. En su interior aparecen pares clave-valor separados por comas.

JSON 
{
  "producto": "Teclado",
  "precio": 29.95,
  "disponible": true
}

En este ejemplo:

  • "producto", "precio" y "disponible" son las claves.
  • "Teclado", 29.95 y true son los valores.
  • Los dos puntos : separan cada clave de su valor.
  • Las comas separan las propiedades.

Tipos de valores admitidos

JSON admite los siguientes tipos de valores:

Tipo Ejemplo JSON Descripción
Cadena "Hola" Texto entre comillas dobles.
Número 25.5 Valor numérico.
Booleano true Verdadero o falso.
Nulo null Ausencia de valor.
Objeto {"id": 1} Conjunto de pares clave-valor.
Array [10, 20, 30] Lista ordenada de valores.

Objetos anidados

Un valor JSON puede contener otro objeto. Esto permite representar información más compleja.

JSON 
{
  "id": 101,
  "cliente": {
    "nombre": "Ana",
    "ciudad": "Zaragoza"
  },
  "total": 85.5
}

En este caso, la propiedad "cliente" contiene otro objeto con dos propiedades: "nombre" y "ciudad".

Arrays de objetos

También es frecuente utilizar arrays para representar colecciones de datos.

JSON 
[
  {
    "id": 1,
    "nombre": "Ratón",
    "precio": 15
  },
  {
    "id": 2,
    "nombre": "Teclado",
    "precio": 30
  }
]

El valor JSON completo de este ejemplo es un array que contiene dos objetos.

📌 Importante

Un texto JSON válido no tiene por qué comenzar siempre con llaves.

También puede representar un array, una cadena, un número, un booleano o null.

Por ejemplo, [1, 2, 3], "Hola" y 25 son valores JSON válidos.

Diferencias entre JSON y objetos JavaScript

A primera vista, un objeto JavaScript y un texto JSON pueden parecer prácticamente iguales.

Sin embargo, existe una diferencia fundamental: un objeto JavaScript es una estructura de datos que podemos manipular directamente, mientras que JSON es una representación textual de datos.

Objeto JavaScript

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 149.99,
  disponible: true
};

console.log(producto.nombre);
console.log(typeof producto);
Salida por consola: 
Monitor
object

La variable producto contiene un objeto real de JavaScript. Podemos acceder directamente a sus propiedades utilizando la notación de punto.

Texto JSON

JavaScript 
const textoJSON =
  '{"nombre":"Monitor","precio":149.99,"disponible":true}';

console.log(typeof textoJSON);
console.log(textoJSON.nombre);
Salida por consola: 
string
undefined

En este segundo ejemplo, textoJSON es una cadena. Aunque su contenido representa un objeto, JavaScript todavía no lo ha convertido en uno.

Por eso, intentar consultar textoJSON.nombre devuelve undefined.

Diferencias de sintaxis

Característica Objeto JavaScript JSON
Claves Pueden escribirse sin comillas en muchos casos. Siempre deben ir entre comillas dobles.
Cadenas Admite comillas simples, dobles y plantillas literales. Utiliza comillas dobles.
Funciones Puede contener métodos. No admite funciones.
undefined Es un valor válido. No está permitido.
Comentarios Se admiten en el código. No se admiten.
Coma final Puede admitirse. No está permitida.
⚠️ Atención

El siguiente fragmento es válido como objeto JavaScript, pero no es JSON válido:

JavaScript — No es JSON válido 
{
  nombre: 'Ana',
  edad: 20,
}

Para convertirlo en JSON válido debemos utilizar comillas dobles en las claves y las cadenas, y eliminar la coma final.

JSON válido 
{
  "nombre": "Ana",
  "edad": 20
}

JSON.stringify()

JavaScript incorpora el objeto predefinido JSON, que proporciona dos métodos especialmente importantes: JSON.stringify() y JSON.parse().

El método JSON.stringify() permite convertir un valor de JavaScript en una cadena que contiene su representación JSON.

Convertir un objeto en texto JSON

JavaScript 
const alumno = {
  nombre: "Carlos",
  edad: 22,
  matriculado: true
};

const textoJSON = JSON.stringify(alumno);

console.log(textoJSON);
console.log(typeof textoJSON);
Salida por consola: 
{"nombre":"Carlos","edad":22,"matriculado":true}
string

El objeto original contiene propiedades a las que podemos acceder directamente. Después de aplicar JSON.stringify(), obtenemos una cadena de texto.

📌 Importante

JSON.stringify() no modifica el objeto original.

Devuelve una nueva representación textual de sus datos.

Convertir un array en JSON

Este método también puede utilizarse con arrays.

JavaScript 
const notas = [7, 8.5, 9, 6];

const texto = JSON.stringify(notas);

console.log(texto);
console.log(typeof texto);
Salida por consola: 
[7,8.5,9,6]
string

Formatear JSON para facilitar su lectura

De manera predeterminada, JSON.stringify() genera un texto compacto.

Si queremos obtener un resultado más legible, podemos utilizar su tercer argumento para indicar el número de espacios de indentación.

JavaScript 
const producto = {
  id: 5,
  nombre: "Portátil",
  precio: 799
};

const texto = JSON.stringify(producto, null, 2);

console.log(texto);
Salida por consola: 
{
  "id": 5,
  "nombre": "Portátil",
  "precio": 799
}

En esta llamada:

  • producto es el valor que queremos convertir.
  • null indica que no estamos utilizando un filtro de propiedades.
  • 2 indica que queremos utilizar dos espacios para la indentación.

Seleccionar propiedades

El segundo argumento puede ser un array que indique qué propiedades queremos incluir en la conversión.

JavaScript 
const usuario = {
  id: 10,
  nombre: "Laura",
  correo: "laura@ejemplo.com",
  activo: true
};

const texto = JSON.stringify(
  usuario,
  ["id", "nombre"]
);

console.log(texto);
Salida por consola: 
{"id":10,"nombre":"Laura"}

En el resultado solamente aparecen las propiedades id y nombre.

⚠️ Atención

No todos los valores de JavaScript pueden representarse directamente en JSON.

Por ejemplo, las funciones y los valores undefined se omiten cuando aparecen como propiedades de un objeto.

Además, una estructura con referencias circulares produce un error al intentar convertirla mediante JSON.stringify().

JSON.parse()

El método JSON.parse() realiza la operación contraria a JSON.stringify().

Recibe una cadena que contiene un texto JSON válido y devuelve el valor de JavaScript correspondiente.

Convertir texto JSON en un objeto

JavaScript 
const textoJSON =
  '{"nombre":"Ana","edad":20,"activo":true}';

const usuario = JSON.parse(textoJSON);

console.log(usuario.nombre);
console.log(usuario.edad);
console.log(typeof usuario);
Salida por consola: 
Ana
20
object

Ahora usuario contiene un objeto de JavaScript. Podemos acceder a sus propiedades mediante la notación habitual.

Convertir un array JSON

JavaScript 
const texto = '["HTML","CSS","JavaScript"]';

const tecnologias = JSON.parse(texto);

console.log(tecnologias[0]);
console.log(tecnologias.length);
console.log(Array.isArray(tecnologias));
Salida por consola: 
HTML
3
true

El resultado es un array real. Por tanto, podemos consultar sus posiciones, su longitud y utilizar sus métodos.

Recorrer datos obtenidos de JSON

En las aplicaciones web es habitual recibir una colección de objetos representada mediante JSON.

JavaScript 
const textoJSON = `[
  {"id":1,"nombre":"Ratón","precio":15},
  {"id":2,"nombre":"Teclado","precio":30},
  {"id":3,"nombre":"Monitor","precio":150}
]`;

const productos = JSON.parse(textoJSON);

productos.forEach(producto => {
  console.log(
    `${producto.nombre}: ${producto.precio} €`
  );
});
Salida por consola: 
Ratón: 15 €
Teclado: 30 €
Monitor: 150 €

Primero convertimos el texto JSON en un array de objetos. Después utilizamos forEach() para recorrer sus elementos.

💻 Ejemplo DAW

Cuando una aplicación realiza una petición a un servidor, puede recibir una respuesta con información en formato JSON.

Una vez interpretados esos datos, la aplicación puede mostrar productos, usuarios, pedidos o cualquier otra información en la página web.

Más adelante estudiaremos cómo obtener estos datos mediante peticiones HTTP.

Conversión de ida y vuelta

Podemos combinar ambos métodos: primero convertir un objeto en texto JSON y después recuperar sus datos.

JavaScript 
const pedido = {
  numero: 105,
  cliente: "Marta",
  total: 59.9
};

const texto = JSON.stringify(pedido);

const recuperado = JSON.parse(texto);

console.log(recuperado.cliente);
console.log(recuperado.total);
console.log(recuperado === pedido);
Salida por consola: 
Marta
59.9
false

El último resultado es false porque JSON.parse() ha creado un objeto nuevo.

Aunque ambos objetos contienen los mismos datos, no son la misma referencia en memoria.

Errores y precauciones

Al trabajar con JSON debemos prestar especial atención a su sintaxis y a los tipos de datos que estamos convirtiendo.

Error por JSON no válido

Si intentamos interpretar un texto que no cumple las reglas de JSON, JSON.parse() produce un error de tipo SyntaxError.

JavaScript — Ejemplo con error 
const texto = "{nombre: 'Ana'}";

const usuario = JSON.parse(texto);

console.log(usuario.nombre);
Resultado esperado: 
SyntaxError: ...

El mensaje exacto puede variar según el navegador.

El problema es que el texto no cumple la sintaxis JSON: la clave no aparece entre comillas dobles y la cadena utiliza comillas simples.

Controlar errores con try...catch

Cuando recibimos datos externos, no debemos asumir que siempre tendrán un formato correcto.

Podemos utilizar try...catch para controlar los errores de conversión.

JavaScript 
const texto = '{"nombre":"Ana","edad":20}';

try {

  const usuario = JSON.parse(texto);

  console.log("Datos correctos");
  console.log(usuario.nombre);

} catch (error) {

  console.log("El JSON no es válido");

}
Salida por consola: 
Datos correctos
Ana

Si sustituimos el contenido de texto por un JSON incorrecto, se ejecutará el bloque catch.

📌 Importante

try...catch permite controlar un error de sintaxis durante la conversión.

Sin embargo, que un JSON sea válido no garantiza que contenga los datos que nuestra aplicación espera.

También debemos comprobar que las propiedades necesarias existen y tienen los tipos adecuados.

Pérdida o transformación de información

La conversión a JSON no conserva necesariamente todos los tipos y características de un objeto de JavaScript.

Observa el siguiente ejemplo:

JavaScript 
const datos = {
  nombre: "Ana",
  telefono: undefined,
  fecha: new Date("2026-10-28T10:00:00Z"),
  saludar: function() {
    return "Hola";
  }
};

const texto = JSON.stringify(datos);

console.log(texto);
Salida por consola: 
{"nombre":"Ana","fecha":"2026-10-28T10:00:00.000Z"}

Podemos observar que:

  • La propiedad telefono se ha omitido porque contiene undefined.
  • El método saludar también se ha omitido.
  • La fecha se ha convertido en una cadena con formato ISO.

Si posteriormente utilizamos JSON.parse(), la fecha se recuperará como una cadena, no como un objeto Date.

⚠️ Atención

JSON no debe utilizarse como un mecanismo para ejecutar código recibido de otros sistemas.

Para interpretar datos JSON debemos utilizar JSON.parse(), nunca eval().

Además, los datos recibidos deben validarse antes de utilizarlos en operaciones sensibles o incorporarlos a una página web.

Ejemplos prácticos

Vamos a aplicar los métodos del objeto JSON a situaciones habituales en el desarrollo de aplicaciones web.

Ejemplo 1. Preparar los datos de un pedido

Una tienda online necesita preparar la información de un pedido para enviarla a un servidor.

JavaScript 
const pedido = {
  id: 250,
  cliente: "Lucía",
  productos: [
    {
      nombre: "Ratón",
      cantidad: 2,
      precio: 15
    },
    {
      nombre: "Teclado",
      cantidad: 1,
      precio: 30
    }
  ]
};

const textoJSON = JSON.stringify(pedido);

console.log(textoJSON);
Salida por consola: 
{"id":250,"cliente":"Lucía","productos":[{"nombre":"Ratón","cantidad":2,"precio":15},{"nombre":"Teclado","cantidad":1,"precio":30}]}

La variable textoJSON contiene una cadena que representa toda la estructura del pedido.

Este formato puede utilizarse como cuerpo de una petición HTTP, siempre que se configure correctamente la petición.

Ejemplo 2. Recuperar y calcular el total de un pedido

Supongamos que recibimos un texto JSON con los productos de un pedido. Queremos convertirlo en un array y calcular su importe total.

JavaScript 
const textoJSON = `[
  {"nombre":"Ratón","cantidad":2,"precio":15},
  {"nombre":"Teclado","cantidad":1,"precio":30},
  {"nombre":"Alfombrilla","cantidad":3,"precio":5}
]`;

const productos = JSON.parse(textoJSON);

const total = productos.reduce(
  (acumulado, producto) => {
    return acumulado +
      producto.cantidad * producto.precio;
  },
  0
);

console.log(`Total del pedido: ${total} €`);
Salida por consola: 
Total del pedido: 75 €

El programa convierte el texto JSON en un array de objetos y utiliza reduce() para sumar el importe de cada producto.

Ejemplo 3. Guardar y recuperar preferencias

Una aplicación web puede necesitar conservar algunas preferencias del usuario, como el tema visual o el idioma seleccionado.

El almacenamiento del navegador trabaja con cadenas de texto. Por eso, JSON resulta especialmente útil para guardar objetos.

JavaScript — Ejecutar en el navegador 
const preferencias = {
  tema: "oscuro",
  idioma: "es",
  notificaciones: true
};

// Guardar preferencias como texto
localStorage.setItem(
  "preferencias",
  JSON.stringify(preferencias)
);

// Recuperar el texto almacenado
const textoGuardado =
  localStorage.getItem("preferencias");

// Convertirlo de nuevo en un objeto
const preferenciasRecuperadas =
  JSON.parse(textoGuardado);

console.log(preferenciasRecuperadas.tema);
console.log(preferenciasRecuperadas.idioma);
Salida por consola: 
oscuro
es

En este ejemplo hemos utilizado localStorage, una herramienta del navegador que estudiaremos con más detalle en el apartado 7.13.

Por ahora, lo importante es comprender el proceso:

  1. Creamos un objeto JavaScript.
  2. Lo convertimos en texto mediante JSON.stringify().
  3. Guardamos la cadena.
  4. Recuperamos el texto almacenado.
  5. Lo convertimos en un objeto mediante JSON.parse().
⚠️ Atención

localStorage debe utilizarse desde un entorno de navegador que permita acceder a este almacenamiento.

Además, no es adecuado para guardar contraseñas, claves privadas ni otros datos sensibles.

Ejemplo 4. Validar datos después de convertir JSON

Aunque un texto JSON sea correcto, sus datos podrían no tener el formato esperado.

Por ejemplo, imaginemos que esperamos recibir un producto con un nombre y un precio numérico.

JavaScript 
const textoJSON =
  '{"nombre":"Monitor","precio":"ciento cincuenta"}';

try {

  const producto = JSON.parse(textoJSON);

  if (
    typeof producto.nombre === "string" &&
    typeof producto.precio === "number" &&
    Number.isFinite(producto.precio)
  ) {

    console.log("Producto válido");

  } else {

    console.log("Datos del producto incorrectos");

  }

} catch (error) {

  console.log("JSON incorrecto");

}
Salida por consola: 
Datos del producto incorrectos

El texto JSON es válido, por lo que JSON.parse() no produce ningún error.

Sin embargo, la propiedad precio contiene una cadena en lugar de un número. Por eso, la validación detecta que los datos no son adecuados para nuestra aplicación.

💭 Piensa

Observa el siguiente programa sin ejecutarlo e intenta responder a las preguntas.

JavaScript 
const producto = {
  nombre: "Monitor",
  precio: 150,
  disponible: true
};

const texto = JSON.stringify(producto);

const copia = JSON.parse(texto);

copia.precio = 120;

console.log(typeof texto);
console.log(producto.precio);
console.log(copia.precio);
console.log(producto === copia);
  1. ¿Qué tipo de dato contiene la variable texto?
  2. ¿Qué valor mostrará producto.precio?
  3. ¿Qué valor mostrará copia.precio?
  4. ¿Por qué la comparación producto === copia devuelve el resultado que devuelve?
  5. ¿Qué diferencia habría si, en lugar de utilizar JSON, hubiéramos escrito const copia = producto;?
Ver una posible solución

1. La variable texto contiene una cadena, porque JSON.stringify() devuelve texto JSON.

2. producto.precio sigue valiendo 150.

3. copia.precio vale 120, porque hemos modificado la propiedad de ese objeto.

4. La comparación devuelve false. JSON.parse() crea un nuevo objeto que tiene una referencia distinta de la original.

5. Si escribiéramos const copia = producto;, ambas variables apuntarían al mismo objeto.

En ese caso, cambiar copia.precio también afectaría al valor observado mediante producto.precio.

Salida del programa original: 

string
150
120
false

Este ejemplo permite comprobar que convertir un objeto a JSON y recuperarlo genera una nueva estructura de datos.

Con el objeto JSON hemos aprendido a representar datos estructurados en formato de texto y a convertirlos entre JSON y los valores de JavaScript.

Estas operaciones son fundamentales en el desarrollo web, especialmente cuando necesitamos intercambiar información con un servidor o guardar datos de una aplicación.
