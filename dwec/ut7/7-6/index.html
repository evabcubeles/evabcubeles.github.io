7.6 Objeto JSON y conversión de datos

En una aplicación web no solo trabajamos con los datos que creamos en nuestro código. También necesitamos intercambiar información con servidores, guardar preferencias o recuperar pedidos y productos.

Para ello utilizamos con frecuencia JSON, un formato de texto que permite representar datos estructurados y convertirlos a valores de JavaScript.

📌 Importante

JSON es un formato de texto, no un objeto JavaScript. El objeto predefinido JSON proporciona los métodos stringify() y parse() para realizar conversiones.

Qué es JSON

JSON significa JavaScript Object Notation. Es un formato independiente del lenguaje que permite representar objetos, arrays y valores sencillos. Se utiliza habitualmente en las respuestas de servicios web y en el intercambio de información entre cliente y servidor.

JSON
{
  "nombre": "Lucía",
  "edad": 21,
  "matriculado": true,
  "modulos": ["DWEC", "DIW"]
}

En este ejemplo, cada propiedad contiene una clave y un valor. Las claves se escriben entre comillas dobles y los valores pueden tener diferentes tipos.

💻 Ejemplo DAW

Una tienda online puede recibir un catálogo de productos en formato JSON y transformarlo en un array de objetos para mostrar los artículos en pantalla.

Sintaxis y estructura de JSON

En JSON las propiedades de un objeto se escriben entre llaves { }, separando cada clave y valor con dos puntos. Los elementos de un array se escriben entre corchetes [ ].

TipoEjemplo JSON
Cadena"Hola"
Número29.95
Booleanotrue o false
Nulonull
Objeto{"id":1}
Array[1,2,3]

Podemos anidar objetos y arrays para representar estructuras más complejas, como un pedido que contiene los datos del cliente y una lista de productos.

JSON
{
  "pedido": 105,
  "cliente": {"nombre": "Ana", "ciudad": "Teruel"},
  "productos": [
    {"nombre": "Ratón", "precio": 15},
    {"nombre": "Teclado", "precio": 30}
  ]
}
⚠️ Atención

Las claves y las cadenas deben llevar comillas dobles. JSON no admite comentarios, funciones, undefined ni comas finales.

Diferencias entre JSON y objetos JavaScript

Un objeto de JavaScript es una estructura que podemos consultar y modificar. Un texto JSON es una cadena que representa datos, pero no permite acceder directamente a sus propiedades.

JavaScript
const producto = { nombre: "Monitor", precio: 150 };
const textoJSON = '{"nombre":"Monitor","precio":150}';

console.log(typeof producto);
console.log(typeof textoJSON);
console.log(producto.nombre);
console.log(textoJSON.nombre);

Salida por consola:

Consola
object
string
Monitor
undefined

En JavaScript podemos escribir claves sin comillas y utilizar métodos; JSON exige comillas dobles en las claves y no representa funciones.

JSON.stringify()

JSON.stringify() convierte un valor de JavaScript en su representación JSON como cadena. No modifica el objeto original.

JavaScript
const alumno = { nombre: "Carlos", edad: 22, activo: true };
const texto = JSON.stringify(alumno);

console.log(texto);
console.log(typeof texto);

Salida por consola:

Consola
{"nombre":"Carlos","edad":22,"activo":true}
string

Podemos utilizar el tercer argumento para presentar el texto con indentación. El segundo argumento permite indicar qué propiedades incluir.

JavaScript
const producto = { id: 5, nombre: "Portátil", precio: 799 };
console.log(JSON.stringify(producto, null, 2));
console.log(JSON.stringify(producto, ["id", "nombre"]));

Salida por consola:

Consola
{
  "id": 5,
  "nombre": "Portátil",
  "precio": 799
}
{"id":5,"nombre":"Portátil"}
⚠️ Atención

Al convertir un objeto, las propiedades cuyo valor es undefined o una función se omiten. Los objetos Date se convierten habitualmente en cadenas ISO. Las referencias circulares provocan un error.

JSON.parse()

JSON.parse() interpreta una cadena con JSON válido y devuelve el valor de JavaScript correspondiente.

JavaScript
const texto = '{"nombre":"Ana","edad":20,"activo":true}';
const usuario = JSON.parse(texto);

console.log(usuario.nombre);
console.log(usuario.edad);
console.log(typeof usuario);

Salida por consola:

Consola
Ana
20
object

Si el JSON representa un array, el resultado será un array que podemos recorrer mediante forEach(), map() o reduce().

JavaScript
const texto = '[{"nombre":"Ratón","precio":15},{"nombre":"Teclado","precio":30}]';
const productos = JSON.parse(texto);

productos.forEach(producto => {
  console.log(`${producto.nombre}: ${producto.precio} €`);
});

Salida por consola:

Consola
Ratón: 15 €
Teclado: 30 €

Al convertir un objeto mediante JSON.stringify() y recuperarlo con JSON.parse(), obtenemos una estructura nueva, no la misma referencia original.

JavaScript
const original = { total: 50 };
const copia = JSON.parse(JSON.stringify(original));
console.log(original === copia);

Salida por consola:

Consola
false

Errores y precauciones

Cuando el texto no cumple la sintaxis JSON, JSON.parse() lanza un SyntaxError. Conviene controlar esta posibilidad con try...catch.

JavaScript
const texto = "{nombre: 'Ana'}";

try {
  const usuario = JSON.parse(texto);
  console.log(usuario.nombre);
} catch (error) {
  console.log("El texto no contiene JSON válido");
}

Salida por consola:

Consola
El texto no contiene JSON válido

Que el texto sea JSON válido no significa que sus datos sean correctos para la aplicación. Después de convertirlo debemos comprobar las propiedades y sus tipos.

JavaScript
const texto = '{"nombre":"Monitor","precio":"caro"}';
const producto = JSON.parse(texto);

if (typeof producto.precio === "number" && Number.isFinite(producto.precio)) {
  console.log("Precio válido");
} else {
  console.log("Precio incorrecto");
}

Salida por consola:

Consola
Precio incorrecto
📌 Importante

Para interpretar JSON utiliza JSON.parse(), nunca eval(). Valida siempre los datos recibidos antes de incorporarlos a una página o realizar operaciones con ellos.

Ejemplos prácticos

Ejemplo 1. Preparar un pedido para enviarlo al servidor

Una tienda puede convertir los datos de un pedido en texto JSON antes de enviarlos en una petición HTTP.

JavaScript
const pedido = {
  id: 250,
  cliente: "Lucía",
  productos: [
    { nombre: "Ratón", cantidad: 2, precio: 15 },
    { nombre: "Teclado", cantidad: 1, precio: 30 }
  ]
};

const textoJSON = JSON.stringify(pedido);
console.log(textoJSON);

Salida por consola:

Consola
{"id":250,"cliente":"Lucía","productos":[{"nombre":"Ratón","cantidad":2,"precio":15},{"nombre":"Teclado","cantidad":1,"precio":30}]}

Ejemplo 2. Calcular el total de un pedido recibido

JavaScript
const texto = '[{"cantidad":2,"precio":15},{"cantidad":1,"precio":30},{"cantidad":3,"precio":5}]';
const productos = JSON.parse(texto);

const total = productos.reduce(
  (suma, producto) => suma + producto.cantidad * producto.precio,
  0
);

console.log(`Total del pedido: ${total} €`);

Salida por consola:

Consola
Total del pedido: 75 €

Ejemplo 3. Guardar preferencias en el navegador

El almacenamiento del navegador guarda cadenas. Por eso podemos utilizar JSON para conservar un objeto con las preferencias del usuario.

JavaScript
const preferencias = { tema: "oscuro", idioma: "es" };

localStorage.setItem("preferencias", JSON.stringify(preferencias));

const texto = localStorage.getItem("preferencias");
const recuperadas = JSON.parse(texto);

console.log(recuperadas.tema);
console.log(recuperadas.idioma);

Salida por consola:

Consola
oscuro
es
💻 Ejemplo DAW

En el apartado 7.13 estudiaremos localStorage con más detalle. No debe utilizarse para almacenar contraseñas o datos sensibles.

💭 Piensa

Observa el programa sin ejecutarlo. ¿Qué valores se mostrarán? ¿Se modifica el objeto original? ¿Qué ocurriría si escribiéramos const copia = producto;?

JavaScript
const producto = { nombre: "Monitor", precio: 150 };
const texto = JSON.stringify(producto);
const copia = JSON.parse(texto);
copia.precio = 120;

console.log(typeof texto);
console.log(producto.precio);
console.log(copia.precio);
console.log(producto === copia);
Ver una posible solución

texto es una cadena. copia es un objeto nuevo, por lo que cambiar su precio no modifica el objeto original. Si utilizáramos const copia = producto;, ambas variables compartirían la misma referencia.
