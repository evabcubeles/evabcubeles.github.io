7.7 Introducción al BOM: estructura y características

Hasta ahora hemos utilizado objetos predefinidos de JavaScript como Math, Date, RegExp y JSON. Sin embargo, cuando un programa se ejecuta en un navegador, también puede acceder a información y funciones propias de ese entorno.

El modelo de objetos del navegador (BOM) reúne diferentes objetos que permiten interactuar con la ventana, consultar la dirección de la página, acceder al historial o conocer determinadas características del navegador.

📌 Importante

El BOM permite interactuar con el entorno del navegador. Su objeto principal es window. No debe confundirse con el DOM, que representa la estructura del documento HTML.

Qué es el BOM

BOM son las siglas de Browser Object Model (modelo de objetos del navegador). Es el conjunto de objetos y funcionalidades que el navegador pone a disposición de JavaScript para interactuar con su entorno.

Gracias a estos objetos podemos, por ejemplo, consultar la URL actual, navegar a otra página, gestionar temporizadores o averiguar las dimensiones de la ventana.

💻 Ejemplo DAW

En una tienda online podemos utilizar location para conocer la dirección de la página, history para facilitar la navegación y localStorage para conservar ciertas preferencias del usuario.

⚠️ Atención

El término BOM es una denominación didáctica habitual, pero no corresponde a una única especificación formal que defina todos sus objetos. Muchas de estas API se describen en distintos estándares web y su disponibilidad depende del entorno.

Estructura del BOM

En una página web tradicional, window representa la ventana o pestaña en la que se ejecuta el código. Desde ella podemos acceder a otros objetos relacionados con el navegador.

windowObjeto principal de la ventana o pestaña
locationDirección y navegación
historyHistorial de navegación
navigatorInformación y capacidades del navegador
screenInformación de la pantalla

También encontramos métodos y propiedades de window como setTimeout(), innerWidth o alert(). Además, window.document da acceso al documento HTML, que estudiaremos mediante el DOM.

JavaScript
console.log(window.location === location);
console.log(window.history === history);
console.log(window.navigator === navigator);

Salida por consola:

Consola
true
true
true

Las tres comparaciones son verdaderas porque location, history y navigator pueden consultarse directamente o como propiedades de window en una página web.

El objeto window como objeto global

En el contexto de una página web, window es el objeto global de JavaScript. Por ello, muchas propiedades y métodos pueden utilizarse escribiendo window. o sin ese prefijo.

JavaScript
console.log(window === globalThis);
console.log(window.location === location);
console.log(window.setTimeout === setTimeout);

Salida por consola:

Consola
true
true
true

En este contexto, globalThis hace referencia al objeto global, que es window. Las otras dos comparaciones muestran que podemos acceder a propiedades y métodos de window sin escribir siempre su nombre.

⚠️ Atención

No todos los entornos de JavaScript tienen un objeto window. Por ejemplo, en Node.js y en los Web Workers el objeto global es diferente. Los ejemplos de este apartado deben ejecutarse en la consola del navegador de una página web.

También conviene distinguir entre las variables globales declaradas con var en un script clásico y las declaradas con let o const: estas últimas no se convierten automáticamente en propiedades de window.

JavaScript
var curso = "DAW";
let modulo = "DWEC";

console.log(window.curso);
console.log(window.modulo);

Salida por consola:

Consola
DAW
undefined
⚠️ Atención

Este último ejemplo supone que se ejecuta como script clásico en el ámbito global. En módulos JavaScript o dentro de funciones, el comportamiento de var respecto a window es diferente.

Principales objetos del navegador

Los objetos más utilizados del BOM permiten consultar información del entorno o realizar acciones de navegación. En los próximos apartados de la unidad estudiaremos sus propiedades y métodos con detalle.

ObjetoPara qué sirveEjemplo
windowAcceder a la ventana y a funciones globaleswindow.innerWidth
locationConsultar la URL y navegarlocation.href
historyInteractuar con el historial de navegaciónhistory.back()
navigatorConsultar información y capacidades del navegadornavigator.language
screenConsultar información de la pantallascreen.width

Podemos acceder a sus propiedades mediante la notación de punto, igual que hemos hecho con otros objetos de JavaScript.

JavaScript
console.log(typeof window.innerWidth);
console.log(typeof location.href);
console.log(typeof navigator.language);
console.log(typeof screen.width);

Salida por consola:

Consola
number
string
string
number

Los valores concretos pueden cambiar según el navegador, la pantalla y la página abierta, pero los tipos indicados son los esperados en estos ejemplos.

📌 Importante

El BOM no permite acceder sin restricciones a toda la información del usuario. Los navegadores aplican medidas de seguridad, permisos y restricciones de privacidad a determinadas funciones.

Diferencias entre BOM y DOM

Aunque ambos modelos se utilizan desde JavaScript en el navegador, representan aspectos distintos de una aplicación web.

AspectoBOMDOM
Qué representaEl entorno del navegadorLa estructura del documento HTML
Objeto de referenciawindowdocument
Para qué se utilizaConsultar la URL, navegar, gestionar temporizadores...Leer y modificar elementos, atributos y contenido HTML
Ejemplolocation.hrefdocument.title

El objeto document está disponible a través de window.document, pero pertenece conceptualmente al DOM, ya que representa el documento de la página.

JavaScript
console.log(window.document === document);
console.log(typeof document.title);
console.log(typeof location.href);

Salida por consola:

Consola
true
string
string
💻 Ejemplo DAW

En una aplicación de gestión de pedidos, el BOM puede indicar en qué página estamos y el DOM permite mostrar o actualizar la información de los pedidos dentro del HTML.

Primer ejemplo con el BOM

Ejemplo 1. Consultar información de la página

Este programa obtiene la dirección actual, el idioma preferido del navegador y el ancho interior de la ventana. No cambia la página ni solicita permisos especiales.

JavaScript
console.log("URL:", location.href);
console.log("Idioma:", navigator.language);
console.log("Ancho de la ventana:", window.innerWidth);

Salida por consola (ejemplo ilustrativo):

Consola
URL: http://localhost:5500/index.html
Idioma: es-ES
Ancho de la ventana: 1280

Los resultados dependen de la URL abierta, la configuración del navegador y el tamaño de la ventana. Por tanto, no tienen por qué coincidir con los de tu equipo.

Ejemplo 2. Comprobar si estamos en una página segura

Podemos consultar el protocolo de la dirección actual para saber si comienza por https:.

JavaScript
if (location.protocol === "https:") {
  console.log("La página utiliza HTTPS");
} else {
  console.log("La página no utiliza HTTPS");
}

Salida por consola si la página utiliza HTTPS:

Consola
La página utiliza HTTPS
⚠️ Atención

Si pruebas este código en una página local con http: o file:, verás el segundo mensaje. El protocolo por sí solo no garantiza que una aplicación sea completamente segura.

Ejemplo 3. Mostrar un resumen del entorno

JavaScript
const entorno = {
  pagina: location.pathname,
  idioma: navigator.language,
  anchoVentana: window.innerWidth
};

console.log(entorno.pagina);
console.log(typeof entorno.idioma);
console.log(typeof entorno.anchoVentana);

Salida por consola (ejemplo ilustrativo):

Consola
/index.html
string
number

Este ejemplo combina objetos del BOM con un objeto JavaScript propio. Es una forma sencilla de reunir información del navegador para utilizarla posteriormente en una aplicación.

💭 Piensa

Observa el siguiente código sin ejecutarlo. ¿Qué valores se mostrarán? ¿Qué diferencia hay entre consultar location.href y document.title?

JavaScript
console.log(window.location === location);
console.log(window.document === document);
console.log(typeof location.href);
console.log(typeof document.title);
Ver una posible solución

Las dos primeras comparaciones devuelven true porque las referencias apuntan a los mismos objetos. location.href es la dirección completa de la página (BOM), mientras que document.title es el título del documento HTML (DOM). Ambas propiedades contienen cadenas.
