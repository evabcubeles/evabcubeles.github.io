7.3 Objeto Math

En el apartado anterior hemos aprendido a trabajar con cadenas de texto y valores numéricos mediante String y Number. También hemos visto cómo convertir datos, comprobar su validez y presentar números con una cantidad determinada de decimales.

Sin embargo, en una aplicación web no siempre basta con sumar, restar, multiplicar o dividir. En ocasiones necesitamos redondear resultados, calcular potencias y raíces cuadradas, obtener valores máximos o mínimos y generar números aleatorios.

JavaScript proporciona estas funcionalidades mediante el objeto predefinido Math, que reúne constantes matemáticas y métodos para realizar cálculos habituales.

📌 Importante

Math es un objeto predefinido de JavaScript que proporciona constantes y métodos matemáticos.

Podemos utilizarlo directamente, sin crear una instancia mediante new.

Introducción a Math

El objeto Math forma parte del propio lenguaje JavaScript. Esto significa que podemos utilizarlo tanto en programas que se ejecutan en un navegador como en otros entornos compatibles con JavaScript.

A diferencia de los objetos que creamos a partir de nuestras propias clases, Math ya está disponible cuando comienza la ejecución del programa.

Para acceder a sus funcionalidades utilizamos el nombre Math, seguido de un punto y del nombre de la propiedad o del método.

JavaScript 
console.log(Math.PI);
console.log(Math.round(4.7));
console.log(Math.sqrt(81));

En este ejemplo:

  • Math.PI permite consultar una constante matemática.
  • Math.round(4.7) redondea un número al entero más próximo.
  • Math.sqrt(81) calcula una raíz cuadrada.
Consola 
3.141592653589793
5
9

Diferencia entre propiedades y métodos

Como hemos estudiado en la UT6, una propiedad contiene un valor asociado a un objeto, mientras que un método representa una funcionalidad que podemos ejecutar.

Esta diferencia también se aplica a Math.

Propiedad Math.PI Consultamos una constante. No utilizamos paréntesis.
Método Math.round(4.7) Ejecutamos una operación. Utilizamos paréntesis.
⚠️ Atención

No debemos escribir new Math(). Math no es un constructor y no puede utilizarse para crear instancias.

Si intentamos ejecutar new Math(), JavaScript producirá un TypeError.

Math y los operadores aritméticos

El objeto Math no sustituye a los operadores aritméticos habituales. Seguiremos utilizando +, -, *, / y % para realizar operaciones básicas.

Math complementa esos operadores cuando necesitamos funcionalidades matemáticas específicas.

JavaScript 
const precio = 19.95;
const cantidad = 3;

const total = precio * cantidad;

console.log(total);
console.log(Math.ceil(total));
Consola 
59.849999999999994
60

Primero multiplicamos el precio por la cantidad y después utilizamos Math.ceil() para obtener el entero superior.

El resultado decimal de la multiplicación también permite observar las pequeñas imprecisiones que pueden aparecer cuando JavaScript representa números decimales en coma flotante.

Constantes matemáticas

Una constante matemática es un valor que permanece fijo y que aparece frecuentemente en determinados cálculos.

JavaScript incluye varias constantes dentro de Math. De esta forma no necesitamos escribir manualmente sus valores aproximados cada vez que los utilizamos.

Propiedad Significado Valor aproximado
Math.PI Número pi. 3.14159
Math.E Número de Euler. 2.71828
Math.SQRT2 Raíz cuadrada de 2. 1.41421
Math.SQRT1_2 Raíz cuadrada de 1/2. 0.70711
Math.LN2 Logaritmo natural de 2. 0.69315
Math.LN10 Logaritmo natural de 10. 2.30259

Utilización de Math.PI

Una de las constantes más utilizadas es Math.PI, que representa el número pi.

Por ejemplo, podemos calcular el área de un círculo mediante la expresión:

Área = π × radio × radio

JavaScript 
const radio = 5;

const area = Math.PI * radio * radio;

console.log(area);
console.log(area.toFixed(2));
Consola 
78.53981633974483
78.54

En este ejemplo combinamos Math.PI con el método toFixed(), estudiado en el apartado 7.2.

El primer resultado conserva la precisión numérica disponible. El segundo se presenta con dos cifras decimales.

📌 Importante

Las constantes de Math son propiedades, no métodos.

Por eso escribimos Math.PI y no Math.PI().

Métodos de redondeo

Redondear consiste en transformar un valor numérico siguiendo una determinada regla.

En desarrollo web necesitamos realizar redondeos en situaciones como calcular cantidades, distribuir elementos, presentar estadísticas o determinar cuántas páginas de resultados debe mostrar una aplicación.

JavaScript ofrece varios métodos de redondeo mediante Math. Aunque pueden parecer similares, no producen siempre el mismo resultado.

Método Comportamiento Ejemplo
Math.round() Redondea al entero más próximo. Math.round(4.7) → 5
Math.floor() Redondea hacia el entero inferior. Math.floor(4.7) → 4
Math.ceil() Redondea hacia el entero superior. Math.ceil(4.2) → 5
Math.trunc() Elimina la parte decimal. Math.trunc(4.9) → 4

Math.round(): redondeo al entero más próximo

El método Math.round() devuelve el entero más próximo al número recibido.

Para los números positivos, cuando la parte decimal es inferior a 0.5, se redondea al entero inferior. Cuando es igual o superior a 0.5, se redondea al entero superior.

JavaScript 
console.log(Math.round(4.2));
console.log(Math.round(4.5));
console.log(Math.round(4.8));
console.log(Math.round(7));
Consola 
4
5
5
7

Math.floor(): redondeo hacia abajo

El método Math.floor() devuelve el mayor entero que sea menor o igual que el número indicado.

Podemos interpretarlo como un redondeo hacia abajo, es decir, hacia el valor entero inferior.

JavaScript 
console.log(Math.floor(8.9));
console.log(Math.floor(8.1));
console.log(Math.floor(8));
console.log(Math.floor(-3.2));
Consola 
8
8
8
-4
⚠️ Atención

Con números negativos, Math.floor() puede resultar menos intuitivo.

Por ejemplo, Math.floor(-3.2) devuelve -4, porque -4 es el entero inferior a -3.2.

Math.ceil(): redondeo hacia arriba

El método Math.ceil() devuelve el menor entero que sea mayor o igual que el número indicado.

Resulta especialmente útil cuando necesitamos una cantidad entera suficiente para cubrir una necesidad.

JavaScript 
console.log(Math.ceil(8.1));
console.log(Math.ceil(8.9));
console.log(Math.ceil(8));
console.log(Math.ceil(-3.2));
Consola 
9
9
8
-3
💻 Ejemplo DAW

Imagina que una tienda online muestra diez productos por página y dispone de veintitrés productos.

Aunque la división 23 / 10 produce 2.3, necesitaremos tres páginas para mostrar todos los productos.

JavaScript 
const totalProductos = 23;
const productosPorPagina = 10;

const numeroPaginas = Math.ceil(
  totalProductos / productosPorPagina
);

console.log(numeroPaginas);
Consola 
3

Math.trunc(): eliminación de decimales

El método Math.trunc() elimina la parte decimal de un número y conserva únicamente su parte entera.

A diferencia de Math.floor(), no redondea hacia abajo: simplemente descarta los decimales.

JavaScript 
console.log(Math.trunc(7.9));
console.log(Math.trunc(7.2));
console.log(Math.trunc(-7.9));
console.log(Math.trunc(-7.2));
Consola 
7
7
-7
-7

Comparación de los métodos de redondeo

Para comprender mejor las diferencias, vamos a aplicar los cuatro métodos a un mismo número positivo y a otro negativo.

Método Con 4.6 Con -4.6
Math.round() 5 -5
Math.floor() 4 -5
Math.ceil() 5 -4
Math.trunc() 4 -4
📌 Importante

Debemos elegir el método de redondeo según el resultado que necesitemos.

Math.round() busca el entero más próximo; Math.floor() redondea hacia abajo; Math.ceil() redondea hacia arriba; y Math.trunc() elimina los decimales.

Operaciones matemáticas

Además de los métodos de redondeo, Math proporciona funcionalidades para calcular valores absolutos, potencias, raíces cuadradas y comparar números.

Estas operaciones pueden utilizarse en aplicaciones de gestión, estadísticas, videojuegos, simulaciones y herramientas de cálculo.

Método Finalidad Ejemplo
Math.abs() Obtiene el valor absoluto. Math.abs(-8) → 8
Math.pow() Calcula una potencia. Math.pow(2, 3) → 8
Math.sqrt() Calcula una raíz cuadrada. Math.sqrt(49) → 7
Math.cbrt() Calcula una raíz cúbica. Math.cbrt(27) → 3
Math.max() Obtiene el valor máximo. Math.max(4, 9, 2) → 9
Math.min() Obtiene el valor mínimo. Math.min(4, 9, 2) → 2
Math.sign() Indica el signo de un número. Math.sign(-5) → -1

Valor absoluto con Math.abs()

El valor absoluto de un número representa su distancia respecto al cero, sin tener en cuenta su signo.

Por ello, el resultado de Math.abs() es siempre positivo o cero cuando recibe un número real finito.

JavaScript 
console.log(Math.abs(-15));
console.log(Math.abs(15));
console.log(Math.abs(0));
Consola 
15
15
0

Este método resulta útil cuando queremos calcular una diferencia sin importar cuál de los dos valores es mayor.

JavaScript 
const temperatura1 = 18;
const temperatura2 = 25;

const diferencia = Math.abs(
  temperatura1 - temperatura2
);

console.log(diferencia);
Consola 
7

Potencias con Math.pow()

El método Math.pow() permite elevar un número a una potencia.

Recibe dos argumentos: la base y el exponente.

JavaScript 
console.log(Math.pow(2, 3));
console.log(Math.pow(5, 2));
console.log(Math.pow(10, 0));
Consola 
8
25
1

JavaScript también dispone del operador de exponenciación **, que permite realizar la misma operación con una sintaxis más breve.

JavaScript 
console.log(Math.pow(2, 4));
console.log(2 ** 4);
Consola 
16
16

Raíces cuadradas con Math.sqrt()

El método Math.sqrt() devuelve la raíz cuadrada de un número.

Por ejemplo, la raíz cuadrada de 64 es 8, porque 8 × 8 = 64.

JavaScript 
console.log(Math.sqrt(64));
console.log(Math.sqrt(100));
console.log(Math.sqrt(2));
Consola 
8
10
1.4142135623730951
⚠️ Atención

Si intentamos calcular la raíz cuadrada de un número negativo mediante Math.sqrt(), el resultado será NaN.

Por ejemplo, Math.sqrt(-9) devuelve NaN, porque no existe una raíz cuadrada real de ese número.

Valores máximos y mínimos

Los métodos Math.max() y Math.min() permiten obtener, respectivamente, el mayor y el menor de varios valores numéricos.

JavaScript 
console.log(Math.max(12, 7, 25, 18));
console.log(Math.min(12, 7, 25, 18));
Consola 
25
7

Cuando tenemos los valores almacenados en un array, podemos utilizar el operador de expansión ... para pasarlos como argumentos individuales.

JavaScript 
const notas = [6, 8, 5, 9, 7];

const notaMaxima = Math.max(...notas);
const notaMinima = Math.min(...notas);

console.log(notaMaxima);
console.log(notaMinima);
Consola 
9
5
📌 Importante

Math.max() y Math.min() esperan valores individuales.

Si tenemos un array, podemos utilizar Math.max(...array) y Math.min(...array).

Para arrays muy grandes, conviene utilizar otras técnicas, como un recorrido o reduce(), porque existe un límite en el número de argumentos que puede recibir una función.

Generación de números aleatorios

En numerosas aplicaciones necesitamos obtener valores que cambien entre ejecuciones.

Por ejemplo, podemos utilizar números aleatorios para simular el lanzamiento de un dado, seleccionar preguntas de un cuestionario, elegir un elemento de una lista o realizar pruebas con datos generados automáticamente.

JavaScript proporciona el método Math.random() para generar números pseudoaleatorios.

Funcionamiento de Math.random()

Math.random() devuelve un número decimal mayor o igual que 0 y menor que 1.

Es decir, el valor puede ser 0, pero nunca será exactamente 1.

JavaScript 
const numero = Math.random();

console.log(numero);

Una posible salida sería:

Consola (ejemplo) 
0.472839125

Si ejecutamos nuevamente el programa, normalmente obtendremos otro valor.

📌 Importante

Math.random() genera valores dentro del intervalo [0, 1).

Esto significa que incluye el 0 y excluye el 1.

Generar números enteros entre 0 y un límite

Si queremos obtener un número entero entre 0 y 9, podemos multiplicar el resultado de Math.random() por 10 y aplicar Math.floor().

JavaScript 
const numero = Math.floor(
  Math.random() * 10
);

console.log(numero);

El resultado será uno de los enteros comprendidos entre 0 y 9, ambos incluidos.

Veamos el proceso:

  1. Math.random() genera un decimal entre 0 y 1, sin llegar a 1.
  2. Al multiplicarlo por 10, obtenemos un valor entre 0 y 10, sin llegar a 10.
  3. Math.floor() elimina la parte decimal redondeando hacia abajo.
  4. El resultado final es un entero entre 0 y 9.

Generar números enteros entre dos límites

En muchas ocasiones necesitamos generar un número aleatorio dentro de un intervalo concreto.

Por ejemplo, para simular un dado tradicional, queremos obtener un entero entre 1 y 6, ambos incluidos.

JavaScript 
const dado = Math.floor(
  Math.random() * 6
) + 1;

console.log(dado);

En este caso, Math.floor(Math.random() * 6) produce un entero entre 0 y 5.

Al sumar 1, desplazamos el intervalo y obtenemos valores entre 1 y 6.

Fórmula general

Para generar un entero aleatorio entre un valor mínimo y un valor máximo, ambos incluidos, podemos utilizar:

JavaScript 
const numero = Math.floor(
  Math.random() * (maximo - minimo + 1)
) + minimo;

Esta fórmula supone que minimo y maximo son números enteros válidos y que el mínimo no supera al máximo.

Vamos a utilizarla para generar un número entre 10 y 20.

JavaScript 
const minimo = 10;
const maximo = 20;

const numero = Math.floor(
  Math.random() * (maximo - minimo + 1)
) + minimo;

console.log(numero);

El resultado será un entero entre 10 y 20, incluidos ambos extremos.

⚠️ Atención

Math.random() no es adecuado para generar contraseñas, tokens de autenticación ni otros valores que requieran seguridad criptográfica.

Para esos casos, los navegadores ofrecen funcionalidades específicas, como crypto.getRandomValues().

Ejemplos prácticos

Vamos a combinar las funcionalidades de Math con los conocimientos de JavaScript que hemos adquirido en las unidades anteriores.

Ejemplo 1. Calcular las páginas de un catálogo

Una tienda online dispone de 47 productos y quiere mostrar 12 productos por página.

Necesitamos calcular cuántas páginas serán necesarias para mostrar todo el catálogo.

JavaScript 
const totalProductos = 47;
const productosPorPagina = 12;

const paginas = Math.ceil(
  totalProductos / productosPorPagina
);

console.log("Total de productos:", totalProductos);
console.log("Productos por página:", productosPorPagina);
console.log("Páginas necesarias:", paginas);
Consola 
Total de productos: 47
Productos por página: 12
Páginas necesarias: 4

La división produce aproximadamente 3.92, pero no podemos mostrar una fracción de página.

Por eso utilizamos Math.ceil(), que garantiza que disponemos de páginas suficientes.

💻 Ejemplo DAW

Este cálculo aparece habitualmente en sistemas de paginación de catálogos, listados de usuarios, resultados de búsquedas y paneles de administración.

Ejemplo 2. Seleccionar un producto aleatorio

Imagina que una tienda online quiere mostrar un producto destacado elegido al azar entre los productos disponibles.

Podemos utilizar Math.random() y Math.floor() para generar una posición válida dentro de un array.

JavaScript 
const productos = [
  "Teclado mecánico",
  "Ratón inalámbrico",
  "Monitor LED",
  "Auriculares USB"
];

const posicion = Math.floor(
  Math.random() * productos.length
);

const productoDestacado = productos[posicion];

console.log("Producto destacado:", productoDestacado);

Una posible salida sería:

Consola (ejemplo) 
Producto destacado: Monitor LED

El array contiene cuatro elementos, con posiciones entre 0 y 3.

La expresión Math.floor(Math.random() * productos.length) genera una de esas posiciones y permite acceder a un producto existente.

📌 Importante

Para seleccionar un elemento aleatorio de un array, debemos generar una posición comprendida entre 0 y array.length - 1.

También debemos comprobar que el array no esté vacío antes de intentar seleccionar un elemento.

Ejemplo 3. Calcular la distancia entre dos puntos

Supongamos que una aplicación necesita calcular la distancia entre dos puntos representados mediante coordenadas x e y.

Podemos utilizar el teorema de Pitágoras y los métodos Math.pow() y Math.sqrt().

JavaScript 
const puntoA = { x: 1, y: 2 };
const puntoB = { x: 4, y: 6 };

const diferenciaX = puntoB.x - puntoA.x;
const diferenciaY = puntoB.y - puntoA.y;

const distancia = Math.sqrt(
  Math.pow(diferenciaX, 2) +
  Math.pow(diferenciaY, 2)
);

console.log(distancia);
Consola 
5

En este ejemplo, la diferencia horizontal es 3 y la diferencia vertical es 4.

Por tanto, calculamos la raíz cuadrada de 3² + 4², que es igual a 5.

Este tipo de cálculo puede resultar útil en aplicaciones gráficas, mapas, simulaciones y videojuegos.

Ejemplo 4. Función reutilizable para números aleatorios

Como ya conocemos las funciones de la UT5, podemos encapsular la generación de números aleatorios en una función reutilizable.

De esta manera, no tendremos que repetir la fórmula cada vez que necesitemos un número dentro de un intervalo.

JavaScript 
function generarEnteroAleatorio(minimo, maximo) {

  if (
    !Number.isSafeInteger(minimo) ||
    !Number.isSafeInteger(maximo) ||
    minimo > maximo
  ) {
    throw new Error("Intervalo no válido");
  }

  return Math.floor(
    Math.random() * (maximo - minimo + 1)
  ) + minimo;

}

const dado = generarEnteroAleatorio(1, 6);
const numeroSorteo = generarEnteroAleatorio(1, 100);

console.log("Dado:", dado);
console.log("Sorteo:", numeroSorteo);

Una posible salida sería:

Consola (ejemplo) 
Dado: 4
Sorteo: 73

La función recibe dos parámetros: el valor mínimo y el máximo. Comprueba que ambos sean enteros seguros y que el intervalo tenga sentido.

Después aplica la fórmula de generación de números pseudoaleatorios.

Para los intervalos pequeños utilizados en estos ejemplos, esta técnica resulta adecuada como recurso didáctico. No debe emplearse para sorteos que requieran garantías de seguridad o imparcialidad verificable.

  4. ¿Por qué utilizamos Math.abs() al calcular la diferencia entre los precios?
  5. ¿Por qué Math.floor(-4.7) devuelve -5 y no -4?
Ver una posible solución

2. Número de páginas: utilizamos Math.ceil() porque necesitamos mostrar los 26 productos. Como cada página contiene 8 productos, la división produce 3.25. Necesitamos 4 páginas completas o parciales para mostrarlos todos.

3. Valores máximo y mínimo: Math.max(...precios) devuelve el precio más alto, 48.9, mientras que Math.min(...precios) devuelve el precio más bajo, 12.75.

Estas funcionalidades pueden combinarse con funciones, arrays y objetos propios para desarrollar programas más completos y reutilizables.
