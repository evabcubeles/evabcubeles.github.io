7.4 Objeto Date

En los apartados anteriores hemos aprendido a utilizar algunos de los objetos predefinidos de JavaScript para trabajar con cadenas de texto, números y operaciones matemáticas.

Sin embargo, muchas aplicaciones web necesitan trabajar también con fechas y horas. Por ejemplo, una tienda online debe registrar cuándo se realiza un pedido, una plataforma educativa puede mostrar la fecha límite de entrega de una actividad y una aplicación de reservas necesita comprobar si una fecha es anterior o posterior a otra.

JavaScript proporciona el objeto Date, que permite crear, consultar, modificar, comparar y representar fechas y horas.

📌 Importante

Date es un objeto predefinido de JavaScript que representa un instante temporal.

Podemos utilizarlo para trabajar con fechas y horas, pero debemos tener en cuenta que su representación puede depender de la zona horaria utilizada.

Introducción a Date

El objeto Date forma parte del propio lenguaje JavaScript y está disponible sin necesidad de instalar bibliotecas adicionales.

A diferencia del objeto Math, que utilizamos directamente, normalmente creamos objetos Date mediante el operador new.

JavaScript 
const fechaActual = new Date();

console.log(fechaActual);

En este ejemplo, new Date() crea un objeto que representa el instante en el que se ejecuta la instrucción.

Si ejecutamos el programa en momentos distintos, obtendremos fechas u horas diferentes. Además, la forma en que la consola muestra el objeto puede variar según el navegador y la zona horaria.

Cómo representa JavaScript las fechas

Internamente, un objeto Date almacena un valor temporal expresado en milisegundos transcurridos desde el 1 de enero de 1970 a las 00:00:00 UTC.

Este instante de referencia se conoce como época Unix o Unix epoch.

Representación interna Milisegundos desde el 1 de enero de 1970 UTC.
Representación visible Año, mes, día, hora, minutos y segundos.

Para obtener ese valor numérico podemos utilizar el método getTime().

JavaScript 
const fecha = new Date(0);

console.log(fecha.getTime());
console.log(fecha.toISOString());
Consola 
0
1970-01-01T00:00:00.000Z

La letra Z al final de la representación indica que la fecha y la hora están expresadas en UTC.

⚠️ Atención

Date representa un instante temporal, pero no almacena una zona horaria específica como propiedad independiente.

Los métodos locales, como getHours(), interpretan ese instante utilizando la zona horaria del entorno de ejecución.

Creación de fechas

JavaScript permite crear objetos Date de distintas maneras. La elección depende de si necesitamos la fecha actual, una fecha concreta o un instante representado mediante milisegundos.

Crear la fecha y hora actuales

La forma más sencilla consiste en utilizar new Date() sin argumentos.

JavaScript 
const ahora = new Date();

console.log(ahora.toLocaleString("es-ES"));

El resultado mostrará la fecha y la hora del instante actual, con un formato habitual en España.

Crear una fecha indicando sus componentes

También podemos indicar el año, el mes y el día, y opcionalmente la hora, los minutos, los segundos y los milisegundos.

JavaScript 
const fecha = new Date(
  2026, 9, 28, 10, 30, 0
);

console.log(fecha.getFullYear());
console.log(fecha.getMonth());
console.log(fecha.getDate());
console.log(fecha.getHours());
Consola 
2026
9
28
10

Aunque hemos creado una fecha correspondiente al 28 de octubre de 2026, el método getMonth() devuelve el valor 9.

Esto sucede porque JavaScript numera los meses desde cero.

Abril3
Mayo4

Julio6
Agosto7
Septiembre8

Noviembre10
Diciembre11
📌 Importante

Cuando creamos una fecha mediante componentes numéricos, los meses van de 0 a 11.

Por ejemplo, new Date(2026, 0, 15) representa el 15 de enero de 2026, mientras que new Date(2026, 11, 15) representa el 15 de diciembre.

Crear fechas a partir de cadenas

Otra posibilidad consiste en proporcionar una cadena de texto que represente una fecha.

Es recomendable utilizar formatos normalizados, como el formato ISO 8601, para evitar interpretaciones ambiguas.

JavaScript 
const fecha = new Date("2026-10-28");

console.log(fecha.toISOString());
Consola 
2026-10-28T00:00:00.000Z

En este caso, una cadena ISO que contiene únicamente la fecha se interpreta como medianoche UTC.

⚠️ Atención

No debemos asumir que cadenas como "28/10/2026" se interpretarán correctamente en todos los navegadores.

Además, existe una diferencia importante: "2026-10-28" se interpreta como fecha UTC, mientras que "2026-10-28T10:30:00", sin indicador de zona horaria, se interpreta como hora local.

Para indicar explícitamente UTC, podemos escribir "2026-10-28T10:30:00Z".

Crear una fecha a partir de milisegundos

También podemos construir una fecha utilizando un número que represente milisegundos desde la época Unix.

JavaScript 
const fecha = new Date(86400000);

console.log(fecha.toISOString());
Consola 
1970-01-02T00:00:00.000Z

El número 86400000 representa los milisegundos correspondientes a 24 horas.

Por tanto, hemos avanzado un día desde el instante de referencia del 1 de enero de 1970 UTC.

Fechas no válidas

No todos los valores permiten construir una fecha válida. Cuando JavaScript no puede representar el instante solicitado, podemos obtener un objeto Date no válido.

JavaScript 
const fecha = new Date("fecha incorrecta");

console.log(Number.isNaN(fecha.getTime()));
Consola 
true

La comprobación devuelve true porque getTime() produce NaN cuando el objeto no contiene una fecha válida.

Conviene distinguir este caso de la normalización automática que JavaScript realiza con algunos componentes numéricos. Por ejemplo, new Date(2026, 1, 30) no representa un 30 de febrero: JavaScript desplaza los días sobrantes al mes siguiente.

Consulta de fechas y horas

Una vez creado un objeto Date, podemos consultar sus componentes mediante diferentes métodos.

Por ejemplo, podemos obtener el año, el mes, el día, la hora o los minutos de una fecha determinada.

Método Información que devuelve
getFullYear() Año con cuatro cifras.
getMonth() Mes entre 0 y 11.
getDate() Día del mes, entre 1 y 31.
getDay() Día de la semana, entre 0 y 6.
getHours() Hora, entre 0 y 23.
getMinutes() Minutos, entre 0 y 59.
getSeconds() Segundos, entre 0 y 59.
getMilliseconds() Milisegundos, entre 0 y 999.
getTime() Milisegundos desde la época Unix.

Consultar los componentes de una fecha

Vamos a crear una fecha concreta y consultar algunos de sus componentes.

JavaScript 
const fecha = new Date(
  2026, 9, 28, 10, 45, 30
);

console.log("Año:", fecha.getFullYear());
console.log("Mes:", fecha.getMonth());
console.log("Día:", fecha.getDate());
console.log("Hora:", fecha.getHours());
console.log("Minutos:", fecha.getMinutes());
console.log("Segundos:", fecha.getSeconds());
Consola 
Año: 2026
Mes: 9
Día: 28
Hora: 10
Minutos: 45
Segundos: 30

Los métodos utilizados consultan los componentes de la fecha según la zona horaria local.

Diferencia entre getDate() y getDay()

Dos métodos que suelen confundirse son getDate() y getDay().

Aunque sus nombres son similares, devuelven información diferente.

getDate() Día del mes. Por ejemplo: 28.
getDay() Día de la semana. Domingo = 0, lunes = 1, ..., sábado = 6.
JavaScript 
const fecha = new Date(2026, 9, 28);

console.log(fecha.getDate());
console.log(fecha.getDay());
Consola 
28
3

El resultado 28 indica que estamos en el día 28 del mes. El valor 3 indica que es miércoles.

⚠️ Atención

En getDay(), la semana comienza con domingo = 0.

Por tanto, lunes es 1, martes es 2, miércoles es 3, y así sucesivamente hasta sábado, que es 6.

Consultar componentes en UTC

Los métodos que hemos utilizado trabajan con la zona horaria local. JavaScript también proporciona métodos equivalentes para consultar los componentes en UTC.

Algunos ejemplos son getUTCFullYear(), getUTCMonth(), getUTCDate() y getUTCHours().

JavaScript 
const fecha = new Date(
  "2026-10-28T10:30:00Z"
);

console.log(fecha.getUTCHours());
console.log(fecha.getUTCDate());
Consola 
10
28

Los resultados son independientes de la zona horaria local, porque estamos consultando directamente los componentes UTC.

Modificación de fechas

Los objetos Date también permiten modificar los componentes de una fecha.

Para ello utilizamos métodos que comienzan por set, como setFullYear(), setMonth() o setDate().

Método Función
setFullYear() Modifica el año.
setMonth() Modifica el mes.
setDate() Modifica el día del mes.
setHours() Modifica la hora.
setMinutes() Modifica los minutos.
setSeconds() Modifica los segundos.
setTime() Establece un instante mediante milisegundos.

Modificar el año, mes y día

Veamos cómo modificar una fecha creada previamente.

JavaScript 
const fecha = new Date(2026, 0, 15);

fecha.setFullYear(2027);
fecha.setMonth(5);
fecha.setDate(20);

console.log(fecha.getFullYear());
console.log(fecha.getMonth() + 1);
console.log(fecha.getDate());
Consola 
2027
6
20

El objeto original se ha modificado. Ahora representa el 20 de junio de 2027.

📌 Importante

Los objetos Date son mutables.

Esto significa que métodos como setDate() modifican el propio objeto, en lugar de devolver una fecha nueva e independiente.

Sumar o restar días

Una característica útil es que JavaScript normaliza automáticamente los componentes cuando sobrepasan los límites habituales de una fecha.

Podemos aprovechar este comportamiento para sumar o restar días.

JavaScript 
const fecha = new Date(2026, 9, 28);

fecha.setDate(fecha.getDate() + 5);

console.log(fecha.getFullYear());
console.log(fecha.getMonth() + 1);
console.log(fecha.getDate());
Consola 
2026
11
2

Hemos partido del 28 de octubre y hemos sumado cinco días.

Como octubre tiene 31 días, JavaScript avanza automáticamente hasta el 2 de noviembre.

Crear una copia antes de modificar

En ocasiones queremos calcular una nueva fecha sin alterar la fecha original.

Para ello podemos crear una copia utilizando el valor temporal de la primera fecha.

JavaScript 
const fechaOriginal = new Date(2026, 9, 28);

const fechaNueva = new Date(
  fechaOriginal.getTime()
);

fechaNueva.setDate(fechaNueva.getDate() + 7);

console.log(fechaOriginal.getDate());
console.log(fechaNueva.getDate());
Consola 
28
4

La fecha original continúa representando el 28 de octubre. La nueva fecha representa el 4 de noviembre.

⚠️ Atención

Si escribimos const copia = fechaOriginal, no estamos creando una copia independiente: ambas variables hacen referencia al mismo objeto.

Para evitar modificar accidentalmente la fecha original, podemos utilizar new Date(fechaOriginal.getTime()).

Precauciones al modificar meses

Al cambiar el mes de una fecha, debemos tener en cuenta que no todos los meses tienen el mismo número de días.

Por ejemplo, cambiar directamente el mes de una fecha situada en el día 31 puede producir un desplazamiento inesperado si el nuevo mes tiene menos días.

Cuando necesitemos operaciones de calendario complejas, como añadir meses conservando determinadas reglas de negocio, tendremos que definir cuidadosamente el comportamiento deseado.

Comparación y cálculo de diferencias

En desarrollo web es habitual comparar fechas para comprobar si un plazo ha terminado, si una reserva es futura o cuánto tiempo falta para un acontecimiento.

Como los objetos Date representan instantes temporales, podemos utilizar sus valores numéricos para realizar comparaciones y cálculos.

Comparar dos fechas

Podemos comprobar si una fecha es anterior o posterior a otra utilizando los operadores <, >, <= y >=.

JavaScript 
const fecha1 = new Date(2026, 9, 20);
const fecha2 = new Date(2026, 9, 28);

console.log(fecha1 < fecha2);
console.log(fecha1 > fecha2);
Consola 
true
false

El 20 de octubre es anterior al 28 de octubre. Por eso la primera comparación devuelve true.

Comprobar si dos fechas representan el mismo instante

Cuando queremos comprobar si dos objetos Date representan exactamente el mismo instante, es conveniente comparar sus valores numéricos.

JavaScript 
const fecha1 = new Date(2026, 9, 28);
const fecha2 = new Date(2026, 9, 28);

console.log(fecha1 === fecha2);

console.log(
  fecha1.getTime() === fecha2.getTime()
);
Consola 
false
true

La primera comparación devuelve false porque estamos comparando dos objetos distintos.

La segunda devuelve true porque ambos representan exactamente el mismo instante.

📌 Importante

Para comprobar si dos objetos Date representan el mismo instante, podemos comparar fecha1.getTime() y fecha2.getTime().

Esta comprobación presupone que ambas fechas son válidas.

Calcular la diferencia entre dos fechas

Podemos restar dos fechas para obtener la diferencia entre sus instantes temporales expresada en milisegundos.

JavaScript 
const inicio = new Date(
  "2026-10-20T00:00:00Z"
);

const fin = new Date(
  "2026-10-25T00:00:00Z"
);

const diferencia = fin - inicio;

console.log(diferencia);
Consola 
432000000

La diferencia equivale a cinco días de 24 horas.

Para convertir milisegundos a otras unidades temporales, podemos utilizar las siguientes equivalencias:

Unidad Milisegundos
1 segundo 1.000
1 minuto 60.000
1 hora 3.600.000
24 horas 86.400.000

Convertir la diferencia a días

Si dividimos la diferencia entre 86400000, obtenemos su duración expresada en periodos de 24 horas.

JavaScript 
const inicio = new Date(
  "2026-10-20T00:00:00Z"
);

const fin = new Date(
  "2026-10-25T00:00:00Z"
);

const milisegundos = fin - inicio;

const dias = milisegundos / 86400000;

console.log(dias);
Consola 
5
⚠️ Atención

Un periodo de 24 horas siempre contiene 86400000 milisegundos, pero un día del calendario local no siempre tiene 24 horas.

Cuando se produce un cambio de horario de verano o invierno, pueden existir días locales de 23 o 25 horas.

Por tanto, calcular una duración en periodos de 24 horas no es siempre equivalente a contar días de calendario.

Obtener el instante actual con Date.now()

JavaScript proporciona también el método estático Date.now().

Este método devuelve directamente los milisegundos transcurridos desde la época Unix, sin necesidad de crear un objeto Date.

JavaScript 
const instanteActual = Date.now();

console.log(instanteActual);

El resultado será un número que dependerá del momento en que ejecutemos el programa.

Date.now() resulta útil para registrar marcas temporales y calcular tiempos transcurridos de manera sencilla.

Formato de fechas

Una fecha puede representarse de diferentes maneras según el país, el idioma o las necesidades de una aplicación.

Por ejemplo, una misma fecha puede mostrarse como 28/10/2026, 28 de octubre de 2026 o 2026-10-28.

JavaScript dispone de métodos que permiten convertir objetos Date en cadenas de texto.

Método Finalidad
toISOString() Representa el instante en formato ISO 8601 y UTC.
toLocaleDateString() Representa la fecha según una configuración regional.
toLocaleTimeString() Representa la hora según una configuración regional.
toLocaleString() Representa fecha y hora según una configuración regional.
toString() Devuelve una representación textual del objeto.

Representar fechas en formato ISO

El método toISOString() devuelve una cadena con una representación normalizada del instante en UTC.

JavaScript 
const fecha = new Date(
  "2026-10-28T10:30:00Z"
);

console.log(fecha.toISOString());
Consola 
2026-10-28T10:30:00.000Z

Este formato resulta especialmente útil para intercambiar información temporal entre diferentes partes de una aplicación.

Mostrar una fecha en formato español

El método toLocaleDateString() permite mostrar una fecha según una configuración regional.

Podemos indicar "es-ES" para solicitar una representación habitual en España.

JavaScript 
const fecha = new Date(2026, 9, 28);

console.log(
  fecha.toLocaleDateString("es-ES")
);

Una representación habitual es:

Consola (formato habitual) 
28/10/2026

Personalizar el formato

Podemos proporcionar un objeto de opciones para controlar cómo se muestran los diferentes componentes de una fecha.

JavaScript 
const fecha = new Date(2026, 9, 28);

const opciones = {
  day: "numeric",
  month: "long",
  year: "numeric"
};

console.log(
  fecha.toLocaleDateString("es-ES", opciones)
);
Consola (formato habitual) 
28 de octubre de 2026

En este ejemplo:

  • day: "numeric" muestra el día como número.
  • month: "long" muestra el nombre completo del mes.
  • year: "numeric" muestra el año.

Formatear la fecha y la hora

Cuando necesitamos mostrar tanto la fecha como la hora, podemos utilizar toLocaleString().

JavaScript 
const fecha = new Date(
  "2026-10-28T10:30:00Z"
);

const opciones = {
  day: "2-digit",
  month: "2-digit",
  year: "numeric",
  hour: "2-digit",
  minute: "2-digit",
  hour12: false,
  timeZone: "Europe/Madrid"
};

console.log(
  fecha.toLocaleString("es-ES", opciones)
);
Consola (formato habitual) 
28/10/2026, 11:30

En este caso hemos indicado expresamente la zona horaria "Europe/Madrid".

El 28 de octubre de 2026, Madrid utiliza el horario UTC+1. Por eso las 10:30 UTC corresponden a las 11:30 en esa zona horaria.

📌 Importante

toLocaleDateString() y toLocaleString() son especialmente útiles para presentar fechas al usuario.

Si necesitamos un formato estable para intercambiar instantes entre sistemas, podemos utilizar toISOString().

Para mostrar fechas en una zona horaria determinada, podemos indicar la opción timeZone.

Ejemplos prácticos

Vamos a combinar los métodos del objeto Date con los conocimientos de JavaScript adquiridos en las unidades anteriores.

Ejemplo 1. Registrar la fecha de un pedido

Una tienda online necesita registrar el momento en el que se realiza un pedido y mostrarlo de forma comprensible al usuario.

Podemos almacenar una fecha y utilizar métodos de formato para mostrarla.

JavaScript 
const pedido = {
  numero: "PED-001",
  cliente: "Ana",
  fecha: new Date(2026, 9, 28, 10, 30)
};

console.log("Pedido:", pedido.numero);
console.log("Cliente:", pedido.cliente);

console.log(
  "Fecha:",
  pedido.fecha.toLocaleDateString("es-ES")
);
Consola (formato habitual) 
Pedido: PED-001
Cliente: Ana
Fecha: 28/10/2026

Hemos creado un objeto que contiene los datos de un pedido.

La propiedad fecha almacena un objeto Date, lo que nos permite consultar o modificar posteriormente la información temporal.

💻 Ejemplo DAW

En una aplicación real, registrar correctamente la fecha de un pedido permite organizar el historial de compras, mostrar información al cliente y calcular plazos de preparación o entrega.

Ejemplo 2. Calcular una fecha de entrega

Supongamos que una tienda online estima que un pedido se entregará cinco días naturales después de la fecha de compra.

Podemos crear una copia de la fecha del pedido y añadirle cinco días.

JavaScript 
const fechaPedido = new Date(2026, 9, 28);

const fechaEntrega = new Date(
  fechaPedido.getTime()
);

fechaEntrega.setDate(
  fechaEntrega.getDate() + 5
);

console.log(
  "Pedido:",
  fechaPedido.toLocaleDateString("es-ES")
);

console.log(
  "Entrega:",
  fechaEntrega.toLocaleDateString("es-ES")
);
Consola (formato habitual) 
Pedido: 28/10/2026
Entrega: 2/11/2026

La fecha de entrega se calcula sumando cinco días a la fecha del pedido.

Como la operación se realiza sobre una copia, la fecha original permanece sin cambios.

⚠️ Atención

En este ejemplo estamos sumando días naturales, no días laborables.

Si una aplicación necesita excluir sábados, domingos o festivos, tendremos que incorporar reglas adicionales.

Ejemplo 3. Comprobar si una actividad está fuera de plazo

Una plataforma educativa puede utilizar fechas para determinar si una actividad todavía admite entregas.

Vamos a comparar una fecha de entrega con una fecha límite.

JavaScript 
const fechaLimite = new Date(
  2026, 10, 5, 23, 59, 59
);

const fechaEntrega = new Date(
  2026, 10, 6, 9, 15
);

if (fechaEntrega > fechaLimite) {
  console.log("Entrega fuera de plazo");
} else {
  console.log("Entrega dentro del plazo");
}
Consola 
Entrega fuera de plazo

La fecha límite es el 5 de noviembre de 2026 a las 23:59:59.

Como la entrega se realiza el 6 de noviembre, la condición fechaEntrega > fechaLimite se cumple.

💻 Ejemplo DAW

Este tipo de comprobación puede utilizarse en plataformas de formación, aplicaciones de reservas, sistemas de citas y herramientas de gestión.

En aplicaciones reales, las comprobaciones importantes de plazos también deben realizarse en el servidor, porque la hora del dispositivo del usuario puede modificarse.

Ejemplo 4. Función reutilizable para formatear fechas

Como ya conocemos las funciones de la UT5, podemos encapsular el formato de fechas en una función reutilizable.

Así evitaremos repetir las mismas instrucciones en diferentes partes de una aplicación.

JavaScript 
function formatearFecha(fecha) {

  if (
    !(fecha instanceof Date) ||
    Number.isNaN(fecha.getTime())
  ) {
    return "Fecha no válida";
  }

  return fecha.toLocaleDateString("es-ES", {
    day: "2-digit",
    month: "long",
    year: "numeric"
  });

}

const fecha1 = new Date(2026, 9, 28);
const fecha2 = new Date(2027, 0, 15);

console.log(formatearFecha(fecha1));
console.log(formatearFecha(fecha2));
Consola (formato habitual) 
28 de octubre de 2026
15 de enero de 2027

La función recibe un objeto Date, comprueba que sea válido y devuelve una cadena con la fecha formateada.

Podemos reutilizarla para mostrar fechas de pedidos, entregas, reservas o cualquier otro acontecimiento.

2. Valor del mes: getMonth() devuelve 9 porque JavaScript numera los meses desde cero. Enero corresponde a 0 y octubre a 9.

3. Nueva fecha: al sumar siete días al 28 de octubre de 2026, obtenemos el 4 de noviembre de 2026.

4. Comparación temporal: fecha < fechaNueva devuelve true porque el 28 de octubre es anterior al 4 de noviembre.

5. Comparación de objetos: fecha === fechaNueva devuelve false porque son dos objetos diferentes, aunque estén relacionados mediante una operación de copia.
