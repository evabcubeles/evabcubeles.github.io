1.4 JavaScript y los lenguajes de programación en entorno cliente

En los apartados anteriores hemos visto cómo funciona una aplicación web y hemos distinguido entre el código que se ejecuta en el cliente y el que se ejecuta en el servidor.

Cuando trabajamos en el entorno cliente, el navegador debe interpretar distintas tecnologías que colaboran para construir la página, darle apariencia y permitir que el usuario interactúe con ella.

Entre estas tecnologías destacan tres fundamentales: HTML, CSS y JavaScript.

📌 Importante

HTML, CSS y JavaScript cumplen funciones diferentes. Una aplicación web moderna suele utilizar las tres tecnologías conjuntamente: HTML estructura el contenido, CSS controla su presentación y JavaScript aporta comportamiento e interactividad.

Lenguajes utilizados en el desarrollo web

El desarrollo de una aplicación web requiere utilizar diferentes lenguajes y tecnologías.

No existe un único lenguaje encargado de realizar todo el trabajo. Dependiendo de la parte de la aplicación que estemos desarrollando, utilizaremos unas tecnologías u otras.

En el entorno cliente, las tres tecnologías fundamentales son:

Tecnología Función principal
HTML Define la estructura y el contenido de la página.
CSS Controla la presentación y el aspecto visual.
JavaScript Añade comportamiento, lógica e interactividad.

En el entorno servidor podemos encontrar lenguajes y tecnologías como Java, PHP, Python, C# o JavaScript mediante Node.js, entre muchas otras.

Por tanto, una aplicación web puede combinar diferentes lenguajes.

Los lenguajes colaboran entre sí

Imaginemos una tienda online que muestra un producto.

HTML podría definir: Producto → Nombre → Precio → Botón «Añadir al carrito».

CSS podría determinar: colores → tamaños → posiciones → tipografía → diseño.

Y JavaScript podría encargarse de: clic en el botón → actualizar carrito → mostrar nuevo total.

Cada tecnología tiene, por tanto, una responsabilidad diferente.

💻 Ejemplo DAW

En una página de matrícula, HTML puede definir los campos del formulario, CSS puede establecer su diseño y JavaScript puede comprobar inicialmente si el usuario ha rellenado correctamente determinados datos antes de enviarlos.

HTML, CSS y JavaScript: funciones diferentes

Una de las primeras ideas que debemos comprender en desarrollo web es la separación entre estructura, presentación y comportamiento.

HTML Estructura y contenido
CSS Presentación
JavaScript Comportamiento

HTML: estructura y contenido

HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para definir la estructura de los documentos web.

Permite indicar que determinado contenido representa, por ejemplo:

  • un título;
  • un párrafo;
  • una imagen;
  • un enlace;
  • una tabla;
  • una lista;
  • un formulario;
  • un botón.

HTML describe principalmente qué elementos contiene el documento y qué significado estructural tienen.

CSS: presentación

CSS (Cascading Style Sheets) permite controlar la presentación visual de los elementos definidos mediante HTML.

Con CSS podemos determinar, entre otras cosas:

  • colores;
  • tamaños;
  • márgenes;
  • fuentes;
  • bordes;
  • posiciones;
  • distribuciones;
  • diseños adaptados a diferentes tamaños de pantalla;
  • animaciones y transiciones visuales.

JavaScript: comportamiento

JavaScript permite incorporar lógica y comportamiento a la aplicación.

Por ejemplo, puede:

  • responder a las acciones del usuario;
  • realizar cálculos;
  • comprobar datos;
  • mostrar u ocultar elementos;
  • modificar contenidos;
  • actualizar partes de una página;
  • almacenar información en el navegador;
  • solicitar datos a un servidor.
📌 Importante

HTML y CSS no son lenguajes de programación. HTML es un lenguaje de marcado y CSS es un lenguaje de hojas de estilo. JavaScript sí es un lenguaje de programación.

Una forma sencilla de recordarlo

Podemos imaginar una página web como una casa:

  • HTML → estructura de la casa: paredes, habitaciones, puertas...
  • CSS → decoración: colores, tamaños, distribución visual...
  • JavaScript → comportamiento: encender una luz al pulsar un interruptor, abrir automáticamente una puerta...

La comparación es simplificada, pero ayuda a distinguir las responsabilidades de cada tecnología.

Qué es JavaScript

JavaScript es un lenguaje de programación utilizado principalmente para desarrollar aplicaciones web interactivas.

Fue creado originalmente para permitir que las páginas web pudieran ejecutar programas directamente en el navegador.

Actualmente JavaScript es una de las tecnologías fundamentales del desarrollo web y sus posibilidades van mucho más allá de las primeras páginas interactivas.

Todos los navegadores modernos incorporan mecanismos capaces de ejecutar JavaScript.

Cuando una página contiene código JavaScript, el navegador puede ejecutarlo y utilizarlo para controlar parte del comportamiento de la aplicación.

JavaScript no es Java

Aunque sus nombres son parecidos, JavaScript y Java son lenguajes diferentes.

Tienen características, entornos de ejecución, ecosistemas y usos diferentes.

⚠️ Atención

JavaScript no es una versión de Java. Son dos lenguajes de programación distintos. La similitud entre sus nombres es una causa frecuente de confusión cuando se empieza a estudiar programación web.

JavaScript ya no se utiliza únicamente en el navegador

Aunque en DWEC estudiaremos principalmente JavaScript ejecutándose en el cliente, actualmente también puede utilizarse en otros entornos.

Por ejemplo, Node.js permite ejecutar JavaScript fuera del navegador y utilizarlo para desarrollar aplicaciones de servidor, herramientas de desarrollo y otros tipos de programas.

Por eso debemos distinguir: JavaScript → lenguaje de programación de Navegador → uno de los entornos donde puede ejecutarse JavaScript.

Características principales de JavaScript

JavaScript posee una serie de características que explican su importancia en el desarrollo web.

Es un lenguaje de programación

JavaScript permite trabajar con:

  • datos;
  • variables;
  • operadores;
  • decisiones;
  • repeticiones;
  • funciones;
  • arrays;
  • objetos;
  • eventos;
  • operaciones asíncronas.

Iremos estudiando estos elementos progresivamente durante el módulo.

Es multiplataforma

Un mismo programa JavaScript puede ejecutarse en navegadores disponibles en diferentes sistemas operativos. Esto permite desarrollar aplicaciones que pueden utilizarse desde ordenadores, tablets o teléfonos móviles.

Está integrado en el ecosistema web

JavaScript trabaja directamente con muchas funcionalidades proporcionadas por los navegadores. Esto permite crear aplicaciones capaces de responder a las acciones del usuario y modificar dinámicamente la interfaz.

Es un lenguaje dinámico

JavaScript es un lenguaje dinámico. Algunas decisiones relacionadas con los datos y su comportamiento se determinan durante la ejecución del programa.

Más adelante veremos las consecuencias prácticas de esta característica cuando estudiemos variables y tipos de datos.

Está basado en objetos

JavaScript permite trabajar ampliamente con objetos y también crear nuestros propios objetos.

Estudiaremos esta característica con profundidad cuando lleguemos a la programación orientada a objetos.

Soporta diferentes estilos de programación

JavaScript permite utilizar diferentes formas de organizar los programas, entre ellas:

  • programación imperativa;
  • programación funcional;
  • programación orientada a objetos;
  • programación basada en eventos.

No necesitamos dominar todavía estos conceptos. Los iremos descubriendo conforme avancemos.

📌 Importante

JavaScript ha evolucionado enormemente desde sus primeras versiones. Actualmente es un lenguaje de programación completo y de propósito general, aunque su relación con la Web continúa siendo especialmente importante.

JavaScript como lenguaje interpretado

Tradicionalmente JavaScript se clasifica como un lenguaje interpretado porque su código puede ser ejecutado por un motor JavaScript sin que el programador tenga que generar previamente un ejecutable independiente como ocurre en otros modelos de programación.

De forma simplificada podemos pensar: Código JavaScript → Motor JavaScript → Ejecución.

Los navegadores incorporan motores especializados para ejecutar este código.

Navegador / entorno Motor JavaScript
Chrome V8
Edge V8
Firefox SpiderMonkey
Safari JavaScriptCore
Node.js V8

¿Significa esto que JavaScript simplemente interpreta cada línea?

No exactamente.

Los motores JavaScript modernos utilizan técnicas mucho más sofisticadas para conseguir un alto rendimiento. Entre ellas pueden utilizar compilación JIT (Just-In-Time) y diferentes mecanismos de optimización durante la ejecución.

Por eso, la separación clásica entre lenguaje interpretado y lenguaje compilado no siempre describe perfectamente cómo funcionan los lenguajes modernos.

📌 Importante

A nivel introductorio podemos considerar JavaScript un lenguaje interpretado, pero debemos saber que los motores modernos pueden compilar y optimizar código internamente durante la ejecución.

Estudiaremos con más detalle las características de los lenguajes de script en el apartado 1.5.

JavaScript y ECMAScript

Cuando estudiamos JavaScript aparece frecuentemente otro término: ECMAScript.

Aunque están estrechamente relacionados, no significan exactamente lo mismo.

ECMAScript es la especificación que define las características fundamentales que debe tener el lenguaje JavaScript.

ECMAScript Especificación del lenguaje
JavaScript Implementación basada en la especificación
Navegador Ejecuta JavaScript mediante su motor

La especificación establece cuestiones como:

  • sintaxis;
  • tipos de datos;
  • operadores;
  • estructuras del lenguaje;
  • funciones;
  • objetos estándar;
  • comportamiento de determinadas operaciones.

¿Por qué existe una especificación?

Porque JavaScript debe poder funcionar de manera coherente en diferentes navegadores y entornos.

Si cada navegador implementara un lenguaje completamente diferente, desarrollar aplicaciones web compatibles sería extremadamente complicado.

La existencia de un estándar permite que los fabricantes de navegadores implementen un comportamiento común.

Versiones de ECMAScript

ECMAScript ha ido evolucionando mediante sucesivas versiones.

Una especialmente importante fue ECMAScript 2015, también conocida como ES6, porque incorporó numerosas características que forman parte del JavaScript moderno.

A partir de ahí, el estándar ha seguido evolucionando regularmente.

Durante el módulo utilizaremos JavaScript moderno, evitando basarnos innecesariamente en formas antiguas de escribir código.

⚠️ Atención

ECMAScript no es otro lenguaje que vayamos a estudiar además de JavaScript. Cuando programemos en JavaScript estaremos utilizando características definidas por la especificación ECMAScript.

ECMAScript no define todas las posibilidades del navegador

Hay otra diferencia importante.

ECMAScript define fundamentalmente el lenguaje JavaScript, pero muchas funcionalidades que utilizamos al desarrollar aplicaciones web son proporcionadas por el navegador mediante sus propias APIs.

Podemos distinguir:

  • ECMAScript: variables, operadores, funciones, arrays, objetos...
  • APIs del navegador: documento HTML, eventos, almacenamiento, temporizadores, comunicaciones...

Esta diferencia será cada vez más importante conforme avancemos en el módulo.

Otros lenguajes y tecnologías de entorno cliente

JavaScript es el lenguaje de programación fundamental del navegador, pero en el desarrollo frontend actual también podemos encontrar otras tecnologías relacionadas.

TypeScript

TypeScript es un lenguaje desarrollado como una extensión de JavaScript.

Añade, entre otras características, un sistema de tipos estático que permite detectar determinados errores durante el desarrollo.

El código TypeScript normalmente se transforma posteriormente en JavaScript para que pueda ser ejecutado en los entornos de destino.

Podemos representarlo así: TypeScript → transformación → JavaScript → navegador.

TypeScript se utiliza ampliamente en proyectos profesionales, especialmente en aplicaciones grandes.

📌 Importante

Los navegadores ejecutan JavaScript de forma nativa. Tecnologías como TypeScript necesitan normalmente un proceso de transformación antes de que el resultado pueda ejecutarse como JavaScript en el navegador.

WebAssembly

Otra tecnología que puede aparecer en aplicaciones web modernas es WebAssembly (Wasm).

Permite ejecutar en el navegador código en un formato diseñado para ofrecer un rendimiento elevado y puede utilizarse junto con JavaScript.

Se emplea especialmente en determinados escenarios exigentes, como aplicaciones gráficas, herramientas complejas, juegos o software que necesita ejecutar cálculos intensivos.

No lo estudiaremos en profundidad en este módulo.

Herramientas que transforman código

El desarrollo frontend moderno también utiliza herramientas capaces de:

  • transformar código;
  • agrupar archivos;
  • optimizar recursos;
  • gestionar dependencias;
  • preparar una aplicación para su publicación.

Las iremos encontrando cuando avancemos hacia proyectos más complejos.

⚠️ Atención

Que utilicemos TypeScript, React u otras herramientas no significa que JavaScript desaparezca. En una aplicación web convencional, el navegador acaba ejecutando JavaScript y las APIs web disponibles en ese entorno.

Frameworks y librerías JavaScript

Cuando las aplicaciones web crecen, desarrollar toda su funcionalidad desde cero puede resultar complejo.

Por este motivo existen librerías y frameworks que proporcionan herramientas, componentes y estructuras reutilizables.

Qué es una librería

Una librería proporciona código ya desarrollado que podemos utilizar desde nuestros programas para resolver determinadas tareas.

Nuestro código decide cuándo utilizar las funcionalidades de la librería.

Qué es un framework

Un framework proporciona una estructura más amplia para desarrollar una aplicación.

Normalmente establece una determinada forma de organizar el proyecto y ofrece mecanismos para construir sus diferentes partes.

La frontera entre ambos conceptos no siempre es completamente rígida, pero esta distinción nos sirve como primera aproximación.

React

React es una biblioteca para construir interfaces de usuario mediante componentes.

Permite dividir una interfaz en piezas reutilizables y actualizarla cuando cambian los datos de la aplicación.

En este módulo dedicaremos la UT10 a realizar una introducción específica a React.

Angular

Angular es una plataforma y framework para desarrollar aplicaciones web.

Proporciona una estructura amplia e integra numerosas herramientas para organizar proyectos complejos.

Vue

Vue es un framework progresivo para construir interfaces de usuario.

Puede utilizarse de forma gradual, desde pequeñas partes de una página hasta aplicaciones completas.

¿Debemos aprender primero un framework?

Antes de trabajar con estas herramientas es fundamental comprender correctamente JavaScript.

React, Angular y Vue utilizan conceptos que se apoyan en conocimientos del propio lenguaje.

Por eso nuestro recorrido será: JavaScript → DOM y eventos → asincronía → aplicaciones web → React.

📌 Importante

Aprender un framework sin comprender JavaScript suele provocar que el programador sepa repetir determinadas estructuras, pero tenga dificultades para entender qué está ocurriendo realmente.

💻 Ejemplo DAW

Una tienda online podría desarrollar su interfaz utilizando React, Angular o Vue. Sin embargo, detrás de componentes, eventos, funciones y peticiones al servidor continúan existiendo conceptos fundamentales de JavaScript que debemos dominar.

💭 Piensa

Una empresa desarrolla una aplicación web y utiliza HTML para definir los productos de una página, CSS para organizar las tarjetas y sus colores, JavaScript para calcular el total del carrito, React para construir la interfaz mediante componentes y una API para obtener del servidor la información de los productos.

¿Qué papel desempeña cada una de estas tecnologías? ¿React sustituye a JavaScript?

Ver una posible solución

HTML proporciona la estructura y el contenido de la página.

CSS controla su presentación visual.

JavaScript aporta la lógica y el comportamiento de la aplicación, por ejemplo, el cálculo del carrito.

React facilita la construcción de la interfaz mediante componentes, pero no sustituye a JavaScript. React se utiliza dentro del ecosistema JavaScript y para trabajar correctamente con él necesitamos conocer el lenguaje.

La API permite que el cliente se comunique con el servidor para obtener los datos de los productos.
