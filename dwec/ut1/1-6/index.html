1.6 Integración de JavaScript con HTML

Hasta ahora hemos estudiado qué papel desempeña JavaScript en una aplicación web, dónde se ejecuta y cuáles son algunas de sus principales características.

El siguiente paso consiste en aprender cómo incorporamos JavaScript a un documento HTML para que el navegador pueda cargarlo y ejecutarlo.

Existen dos formas principales de hacerlo: escribir el código JavaScript dentro del propio documento HTML o guardar el código en un archivo independiente y enlazarlo desde la página.

📌 Importante

El navegador no adivina qué archivos JavaScript queremos utilizar. Debemos indicarlo mediante el elemento <script>.

JavaScript dentro de una página HTML

Un documento HTML puede contener referencias a código JavaScript para que el navegador lo ejecute al cargar la página.

Podemos utilizar JavaScript de dos maneras principales:

  • JavaScript interno: el código se escribe dentro del propio archivo HTML.
  • JavaScript externo: el código se guarda en un archivo independiente con extensión .js.
HTML Contiene la estructura
<script> Indica qué JavaScript debe cargarse
JavaScript Se ejecuta en el navegador
💻 Ejemplo DAW

Una página puede contener el título y el texto en HTML, mientras que un pequeño script JavaScript muestra información en la consola del navegador.

El elemento <script>

El elemento <script> se utiliza para incorporar o enlazar código JavaScript desde un documento HTML.

Su forma más básica es:

HTML 
<script>
  console.log("Hola desde JavaScript");
</script>

Cuando utilizamos JavaScript interno, el código se escribe entre las etiquetas <script> y </script>, y el navegador lo procesa como JavaScript.

⚠️ Atención

No debemos utilizar atributos antiguos como language="JavaScript". En HTML moderno basta con utilizar el elemento <script>.

JavaScript interno

Hablamos de JavaScript interno cuando el código se escribe directamente dentro del documento HTML.

Por ejemplo:

index.html 
<!DOCTYPE html>
<html lang="es">

<head>
  <meta charset="UTF-8">
  <title>JavaScript interno</title>
</head>

<body>

  <h1>Mi primera página con JavaScript</h1>

  <script>
    console.log("JavaScript se está ejecutando");
  </script>

</body>

</html>

Cuando el navegador llega al elemento <script>, ejecuta el código que contiene.

¿Cuándo puede ser útil?

El JavaScript interno puede ser cómodo para ejemplos pequeños, pruebas rápidas o demostraciones muy sencillas.

📌 Importante

Para proyectos reales suele ser preferible separar el JavaScript en archivos externos. Así conseguimos un código más organizado, mantenible y reutilizable.

JavaScript externo

Hablamos de JavaScript externo cuando el código se guarda en un archivo independiente, normalmente con extensión .js.

Por ejemplo, podemos crear dos archivos:

index.html 
<!DOCTYPE html>
<html lang="es">

<head>
  <meta charset="UTF-8">
  <title>JavaScript externo</title>
</head>

<body>

  <h1>Mi página web</h1>

  <script src="app.js"></script>

</body>

</html>
app.js 
console.log("Código cargado desde app.js");

El documento HTML indica que debe cargar el archivo app.js, y el navegador ejecuta el código que contiene.

Ventajas del JavaScript externo

  • separa la estructura HTML de la lógica JavaScript;
  • facilita la lectura del código;
  • permite reutilizar un mismo archivo en varias páginas;
  • simplifica el mantenimiento;
  • facilita el trabajo en proyectos grandes.
💻 Ejemplo DAW

Si varias páginas de una aplicación utilizan las mismas funciones JavaScript, podemos enlazar todas ellas con el mismo archivo externo en lugar de repetir el código dentro de cada HTML.

El atributo src

El atributo src indica la ruta del archivo JavaScript externo que debe cargar el navegador.

Por ejemplo:

HTML 
<script src="js/app.js"></script>

Esta ruta indica que el navegador debe buscar el archivo app.js dentro de una carpeta llamada js.

Rutas relativas

Podemos utilizar rutas relativas de la misma forma que hacemos con imágenes, hojas de estilo o enlaces.

Ruta Significado
app.js El archivo está en la misma carpeta que el HTML.
js/app.js El archivo está dentro de una subcarpeta llamada js.
../js/app.js Primero subimos una carpeta y después accedemos a js/app.js.
⚠️ Atención

Si la ruta indicada en src es incorrecta, el navegador no podrá cargar el archivo JavaScript. Este será uno de los primeros errores que aprenderemos a localizar con las herramientas de desarrollo.

Dónde colocar el código JavaScript

El elemento <script> puede aparecer en diferentes lugares del documento HTML, pero su posición puede afectar al momento en que se descarga y ejecuta el código.

Al final del body

Una opción clásica consiste en colocar el script justo antes del cierre de </body>.

HTML 
<body>

  <h1>Mi aplicación</h1>

  <script src="js/app.js"></script>

</body>

De esta manera, el navegador ha procesado ya el contenido HTML anterior cuando llega al script.

En el head

También podemos incluir scripts dentro del <head>. Sin embargo, si utilizamos un script externo normal sin atributos adicionales, su descarga y ejecución puede interrumpir temporalmente el procesamiento del HTML.

📌 Importante

En proyectos modernos es muy habitual colocar el script externo en el <head> utilizando el atributo defer.

Carga de scripts y atributo defer

El atributo defer indica al navegador que puede descargar el archivo JavaScript mientras continúa procesando el documento HTML, pero que debe ejecutar el script cuando el HTML haya terminado de analizarse.

Su uso habitual es:

HTML 
<head>

  <meta charset="UTF-8">
  <title>Mi aplicación</title>

  <script src="js/app.js" defer></script>

</head>
HTML Continúa procesándose
JavaScript Se descarga en paralelo
Ejecución Se realiza después de analizar el HTML

¿Qué ventaja tiene?

Evita que la carga de un script externo bloquee innecesariamente el análisis del documento y garantiza que el HTML esté disponible cuando el script se ejecute.

📌 Importante

Para los proyectos que realizaremos en este módulo utilizaremos habitualmente: <script src="js/app.js" defer></script>.

⚠️ Atención

El atributo defer se utiliza con scripts externos. No es necesario utilizarlo en los ejemplos de JavaScript interno.

Separación entre HTML, CSS y JavaScript

Una buena práctica fundamental consiste en mantener separadas las distintas responsabilidades de una aplicación web.

Tecnología Responsabilidad principal Archivo habitual
HTML Estructura y contenido. index.html
CSS Presentación y diseño. estilos.css
JavaScript Lógica y comportamiento. app.js

Esta separación facilita entender qué parte del proyecto debemos modificar cuando queremos cambiar la estructura, el aspecto o el comportamiento de la aplicación.

💻 Ejemplo DAW

Si queremos cambiar el color de un botón, deberíamos modificar CSS. Si queremos cambiar el texto del documento, probablemente modificaremos HTML. Si queremos cambiar qué ocurre al realizar una acción, trabajaremos con JavaScript.

⚠️ Atención

En proyectos pequeños es posible mezclar tecnologías en un mismo archivo, pero conforme el proyecto crece esa mezcla dificulta la lectura, el mantenimiento y la reutilización del código.

Buenas prácticas para organizar los archivos

Desde el principio conviene acostumbrarse a organizar los proyectos de forma clara y predecible.

Una estructura sencilla podría ser:

Estructura del proyecto 
mi-proyecto/
├── index.html
├── css/
│   └── estilos.css
├── js/
│   └── app.js
└── img/
    └── logo.png

De esta forma cada tipo de recurso tiene una ubicación clara.

Ejemplo completo

El documento HTML podría enlazar tanto la hoja de estilos como el archivo JavaScript:

index.html 
<!DOCTYPE html>
<html lang="es">

<head>

  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <title>Mi proyecto web</title>

  <link rel="stylesheet" href="css/estilos.css">

  <script src="js/app.js" defer></script>

</head>

<body>

  <h1>Mi proyecto web</h1>
  <p>HTML, CSS y JavaScript en archivos separados.</p>

</body>

</html>
js/app.js 
console.log("El archivo app.js se ha cargado correctamente");
📌 Importante

Este tipo de estructura será la base de muchos de los ejercicios del módulo: HTML para la estructura, CSS para la presentación y JavaScript para el comportamiento.

💭 Piensa

Un alumno crea los archivos index.html y js/app.js. En el HTML escribe:

HTML 
<script src="app.js" defer></script>

El navegador no ejecuta el JavaScript. ¿Cuál es el problema?

Ver solución

El archivo JavaScript está dentro de la carpeta js, pero la ruta indicada en src busca app.js en la misma carpeta que index.html.

La referencia correcta sería:

<script src="js/app.js" defer></script>
