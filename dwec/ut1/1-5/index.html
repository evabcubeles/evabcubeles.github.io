1.5 Características de los lenguajes de script

En el apartado anterior hemos presentado JavaScript como el lenguaje de programación fundamental del entorno cliente y hemos visto algunas de sus características generales.

Ahora vamos a detenernos en un concepto que aparece con frecuencia cuando hablamos de JavaScript: el de lenguaje de script.

Comprender qué es un script nos ayudará a entender por qué JavaScript encaja especialmente bien en el desarrollo web y qué diferencias existen respecto a otros modelos de programación.

📌 Importante

La expresión lenguaje de script describe una forma habitual de utilizar determinados lenguajes, pero no significa que sean lenguajes «menos completos». JavaScript es actualmente un lenguaje de programación de propósito general.

Qué es un script

Un script es un programa, normalmente formado por un conjunto de instrucciones, que se ejecuta dentro de un determinado entorno de ejecución para realizar una tarea.

Ese entorno puede ser un navegador, un servidor, un sistema operativo, una herramienta de automatización u otro programa capaz de ejecutar el lenguaje.

En DWEC nos interesa especialmente el caso del navegador: el navegador carga el código JavaScript y dispone de un motor capaz de ejecutarlo.

Script Contiene las instrucciones
Entorno Proporciona los medios para ejecutarlo
Resultado Realiza una tarea o produce un comportamiento

Un script puede ser pequeño... o formar parte de una gran aplicación

Históricamente se asociaba la palabra script con programas breves utilizados para automatizar tareas sencillas. Esa idea sigue siendo útil en algunos contextos, pero hoy resulta demasiado limitada.

Una aplicación web moderna puede contener miles de líneas de JavaScript, numerosos módulos y diferentes herramientas de desarrollo. Por tanto, el tamaño del programa no determina por sí solo si estamos utilizando un lenguaje de script.

💻 Ejemplo DAW

Un pequeño script puede comprobar inicialmente los datos de un formulario. Pero JavaScript también puede utilizarse para desarrollar la interfaz completa de una aplicación web compleja.

Características de los lenguajes de script

Los lenguajes que tradicionalmente denominamos de script suelen compartir una serie de características. No todas se cumplen exactamente igual en todos los lenguajes, pero nos permiten comprender el concepto.

Se ejecutan dentro de un entorno

El código necesita un entorno capaz de interpretarlo o ejecutarlo. En JavaScript, ese entorno puede ser el navegador o, por ejemplo, Node.js.

Favorecen un ciclo de desarrollo rápido

Normalmente podemos escribir o modificar el código y probar el resultado sin tener que generar manualmente un ejecutable independiente antes de cada prueba.

Esto facilita un ciclo muy habitual durante el desarrollo: escribir → ejecutar → comprobar → corregir → volver a ejecutar.

Suelen tener una sintaxis relativamente flexible

Muchos lenguajes de script intentan facilitar la escritura de programas y reducir parte del trabajo necesario para realizar tareas habituales.

En JavaScript, además, trabajaremos con un sistema de tipos dinámico, que estudiaremos con detalle en la UT2.

Se integran con el entorno que los ejecuta

Una de sus grandes ventajas es que pueden utilizar funcionalidades proporcionadas por el propio entorno.

En el navegador, JavaScript puede trabajar con APIs web para interactuar con la página, responder a eventos, utilizar almacenamiento o comunicarse con servidores.

Son adecuados para automatizar y coordinar tareas

Los scripts se utilizan con frecuencia para conectar acciones, automatizar procesos o añadir comportamiento a un sistema existente.

📌 Importante

Estas características son una descripción general, no una frontera rígida. Los lenguajes modernos han evolucionado y las diferencias tradicionales entre categorías son cada vez menos absolutas.

Lenguajes interpretados y lenguajes compilados

Para comprender el origen del término script conviene diferenciar, de forma introductoria, dos modelos clásicos de ejecución: compilación e interpretación.

Modelo compilado

En un modelo tradicional de compilación, el código fuente se transforma antes de su ejecución mediante un compilador.

De forma simplificada: Código fuente → Compilador → Código preparado para ejecutarse → Ejecución.

Modelo interpretado

En un modelo interpretado, un programa encargado de ejecutar el lenguaje procesa el código durante la ejecución sin que el programador tenga que crear previamente un ejecutable independiente.

De forma simplificada: Código fuente → Intérprete o motor → Ejecución.

Aspecto Modelo compilado tradicional Modelo interpretado tradicional
Preparación Existe una fase previa de compilación. El código puede ser procesado por el entorno durante la ejecución.
Resultado previo Puede generarse código preparado para la plataforma de destino. No es necesario que el programador genere un ejecutable independiente.
Pruebas y cambios Tradicionalmente requieren volver a compilar tras determinados cambios. Suelen permitir probar los cambios de forma muy directa.
Ejemplos orientativos C, C++. JavaScript, Python.

La realidad actual es más compleja

Esta clasificación es útil para empezar, pero no debemos interpretarla como una división absoluta.

Muchos lenguajes y entornos modernos combinan distintas técnicas. Como vimos en el apartado 1.4, los motores JavaScript actuales pueden utilizar compilación JIT (Just-In-Time) y realizar optimizaciones mientras el programa se ejecuta.

⚠️ Atención

No debemos memorizar que «interpretado = lento» y «compilado = rápido». El rendimiento real depende del lenguaje, del motor, de las optimizaciones, del programa y del entorno donde se ejecuta.

Ventajas de los lenguajes de script

Las características anteriores hacen que los lenguajes de script resulten muy útiles en numerosos contextos, especialmente cuando necesitamos desarrollar, probar y modificar comportamiento con rapidez.

Desarrollo ágil

El ciclo entre escribir código y comprobar su resultado suele ser rápido, lo que facilita realizar pruebas y corregir errores durante el desarrollo.

Facilidad para realizar modificaciones

Podemos cambiar el código fuente y volver a ejecutarlo sin tener que construir manualmente un ejecutable independiente para cada modificación.

Integración con otros sistemas

Los scripts suelen estar diseñados para trabajar dentro de otros entornos y aprovechar sus funcionalidades. En el navegador, JavaScript se integra con las APIs web.

Automatización de tareas

Son especialmente útiles para automatizar operaciones repetitivas, coordinar procesos o responder a determinadas acciones.

Portabilidad

Cuando existe un entorno de ejecución compatible, el mismo código puede utilizarse en diferentes sistemas. En desarrollo web, los navegadores modernos proporcionan un entorno ampliamente disponible para JavaScript.

💻 Ejemplo DAW

Durante el desarrollo de una página podemos modificar un archivo JavaScript, recargar el navegador y comprobar rápidamente el nuevo comportamiento. Este ciclo de prueba resulta especialmente cómodo para aprender y desarrollar interfaces web.

Inconvenientes y limitaciones

Utilizar lenguajes de script también presenta algunos aspectos que debemos tener en cuenta. En el caso de JavaScript ejecutado en el navegador, varios de ellos están relacionados con el propio entorno cliente.

Dependencia del entorno de ejecución

El programa necesita disponer de un motor o entorno compatible. Además, no todos los entornos proporcionan exactamente las mismas APIs.

Compatibilidad

Algunas características pueden no estar disponibles en navegadores antiguos o comportarse de forma diferente según el entorno. Por eso es importante conocer los estándares y probar las aplicaciones.

El código cliente puede inspeccionarse

El código JavaScript enviado al navegador llega al dispositivo del usuario y puede ser consultado, analizado e incluso modificado localmente.

⚠️ Atención

Nunca debemos guardar en el JavaScript del cliente contraseñas, claves privadas, secretos o información que deba permanecer protegida.

Restricciones de seguridad

El navegador limita determinadas operaciones para proteger al usuario. Un script no puede acceder libremente a cualquier archivo, programa o recurso del sistema.

Recursos del dispositivo

Cuando JavaScript se ejecuta en el cliente utiliza recursos del dispositivo del usuario. Un código mal diseñado puede consumir demasiada memoria o tiempo de procesamiento y perjudicar la experiencia de uso.

📌 Importante

Algunas de estas limitaciones no pertenecen a los lenguajes de script en general, sino al entorno concreto donde se ejecuta JavaScript. Es importante distinguir el lenguaje de las restricciones impuestas por el navegador.

JavaScript como lenguaje de script

JavaScript nació estrechamente ligado al navegador y a la necesidad de añadir comportamiento a las páginas web. Por eso tradicionalmente se ha descrito como un lenguaje de scripting del lado del cliente.

Esta descripción continúa siendo útil para explicar uno de sus usos fundamentales, pero actualmente JavaScript ha crecido mucho más allá de ese origen.

Hoy podemos utilizar JavaScript para desarrollar interfaces web, aplicaciones de servidor con Node.js, herramientas de línea de comandos, aplicaciones multiplataforma y muchos otros tipos de software.

¿Sigue siendo correcto llamarlo lenguaje de script?

Sí, siempre que comprendamos qué queremos expresar con esa denominación. JavaScript puede utilizarse para escribir scripts, pero no está limitado a pequeños programas ni a tareas sencillas.

Idea antigua demasiado simplificada Visión actual
Un script siempre es un programa pequeño. JavaScript puede formar parte de aplicaciones de gran tamaño.
JavaScript solo se utiliza en páginas web. También puede ejecutarse fuera del navegador.
JavaScript simplemente interpreta cada línea. Los motores modernos utilizan JIT y diferentes optimizaciones.
Un lenguaje de script es un lenguaje poco potente. JavaScript es un lenguaje completo y de propósito general.
📌 Importante

En DWEC utilizaremos JavaScript principalmente como lenguaje de programación del entorno cliente, porque nuestro objetivo es aprender a desarrollar la lógica que se ejecuta en el navegador.

Programación tradicional y programación mediante scripts

En algunos materiales se contrapone la programación tradicional a la programación mediante scripts.

Esta comparación puede ayudarnos a comprender el origen de los lenguajes de scripting, pero debemos utilizarla con cuidado porque actualmente existen muchos modelos intermedios.

Aspecto Modelo tradicional compilado Programación mediante scripts
Ejecución Suele existir una fase previa de compilación. El entorno puede ejecutar el código directamente.
Entorno El programa puede ejecutarse como aplicación independiente. Es frecuente que el script se ejecute dentro de otro entorno.
Ciclo de desarrollo Tradicionalmente incluye compilar antes de volver a ejecutar. Suele favorecer pruebas y modificaciones rápidas.
Integración Depende del tipo de aplicación. Suele aprovechar funciones proporcionadas por el entorno anfitrión.

En una aplicación web estas ideas se combinan. El navegador es una aplicación compleja desarrollada con distintas tecnologías y, al mismo tiempo, proporciona el entorno en el que se ejecuta nuestro código JavaScript.

Por eso, más que pensar en dos categorías completamente separadas, debemos comprender cómo se prepara, dónde se ejecuta y qué entorno proporciona servicios a cada programa.

💭 Piensa

Una alumna afirma: «JavaScript es un lenguaje de script, así que solo sirve para hacer programas pequeños que el navegador interpreta línea por línea».

¿Qué partes de esta afirmación son demasiado simplificadas? ¿Cómo la corregirías?

Ver solución

Es correcto decir que JavaScript se ha utilizado tradicionalmente como lenguaje de script y que el navegador es uno de sus principales entornos de ejecución.

Sin embargo, JavaScript no está limitado a programas pequeños: puede utilizarse en aplicaciones muy grandes y también fuera del navegador, por ejemplo mediante Node.js.

Tampoco es preciso afirmar que los motores modernos se limitan a interpretar cada línea. Pueden utilizar compilación JIT y técnicas de optimización durante la ejecución.

Una formulación más adecuada sería: «JavaScript es un lenguaje de programación de propósito general que nació ligado al scripting web y que actualmente puede ejecutarse en distintos entornos mediante motores especializados».
