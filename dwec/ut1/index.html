UT1 - Introducción al desarrollo web en entorno cliente

En esta unidad comenzaremos estudiando cómo funcionan las aplicaciones web y qué papel desempeña el navegador dentro de una arquitectura cliente-servidor.

Analizaremos las diferencias entre la ejecución de código en el cliente y en el servidor, conoceremos las principales tecnologías utilizadas en el desarrollo web y situaremos JavaScript como el lenguaje fundamental para programar el comportamiento de las páginas web en el navegador.

También aprenderemos cómo se integra JavaScript con HTML, qué herramientas utilizaremos durante el curso y cómo ejecutar nuestros primeros programas, utilizando la consola del navegador para comprobar su funcionamiento y detectar posibles errores.

Esta unidad servirá como base para las siguientes, en las que comenzaremos a estudiar progresivamente la sintaxis de JavaScript y a desarrollar aplicaciones web cada vez más interactivas.
