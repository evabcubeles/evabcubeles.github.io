📝 Actividades de la UT1

Para finalizar la UT1 vas a aplicar de forma conjunta los principales conceptos trabajados en los apartados 1.1 a 1.8.

Las actividades se organizan en tres bloques: actividades prácticas, un reto final y una autoevaluación para comprobar los conceptos fundamentales de la unidad.

💻 Actividades prácticas

Actividad 1 — Cliente, servidor, frontend y backend

Una tienda online permite consultar productos, añadirlos al carrito, iniciar sesión y realizar una compra.

Indica dónde situarías principalmente cada una de estas tareas y justifica la respuesta:

  1. Mostrar en pantalla el catálogo recibido.
  2. Comprobar las credenciales de acceso de un usuario.
  3. Mostrar u ocultar visualmente un menú.
  4. Consultar el stock real de un producto.
  5. Registrar definitivamente una compra.
  6. Mostrar de forma inmediata un mensaje informativo al usuario.
📌 Recuerda

No basta con escribir «cliente» o «servidor». Debes explicar por qué esa responsabilidad debe realizarse principalmente en ese lado.

Actividad 2 — Interpreta una comunicación cliente-servidor

Un usuario escribe en el navegador la dirección de una plataforma educativa y pulsa Enter. Explica con tus propias palabras qué ocurre desde que el navegador realiza la petición hasta que la página puede mostrarse.

En tu explicación deben aparecer correctamente los conceptos:

  • cliente;
  • servidor;
  • petición;
  • respuesta;
  • HTML, CSS y JavaScript.

Actividad 3 — Corrige la integración de JavaScript

El proyecto tiene esta estructura:

Proyecto 
mi-proyecto/
├── index.html
└── js/
    └── app.js

Sin embargo, en index.html aparece:

HTML 
<script src="app.js" defer></script>
  1. Explica por qué el navegador no encuentra el archivo.
  2. Escribe la etiqueta <script> correcta.
  3. Indica qué herramienta del navegador utilizarías para comprobar que el archivo se ha cargado.

Actividad 4 — JavaScript interno o externo

Decide si utilizarías JavaScript interno o externo en cada situación y justifica brevemente la respuesta:

  1. Una demostración de cinco líneas que solo se utilizará una vez en clase.
  2. Una aplicación con varias páginas que comparten el mismo código JavaScript.
  3. Un proyecto que debe mantenerse durante todo el curso.
  4. Una prueba rápida para observar el comportamiento de una única instrucción.

Actividad 5 — Investiga con DevTools

Abre con Live Server el proyecto prueba-javascript utilizado durante la UT1 y realiza las siguientes comprobaciones:

  1. Abre Console y ejecuta 10 + 5.
  2. Localiza en Elements el elemento <h1> de la página.
  3. Abre Sources y localiza el archivo JavaScript cargado.
  4. Explica qué información aporta cada una de esas pestañas.

Actividad 6 — Lee y corrige un error

Crea un archivo js/app.js con este código:

JavaScript · js/app.js 
console.log("Inicio del programa");

console.log("Todo funciona";

console.log("Fin del programa");
  1. Ejecuta el proyecto con Live Server.
  2. Abre la consola del navegador.
  3. Localiza el mensaje de error y la línea señalada.
  4. Corrige el problema.
  5. Comprueba que aparecen los tres mensajes.
⚠️ Atención

No corrijas el código antes de mirar la consola. El objetivo de esta actividad es practicar el proceso de leer el error → localizarlo → corregirlo → volver a probar.

🧩 Reto final — Puesta en marcha de una mini aplicación web

Te incorporas a un equipo de desarrollo que está preparando la primera versión de InfoCurso, una pequeña página informativa. Tu responsable te entrega una estructura inicial con varios errores y te pide que dejes el proyecto correctamente organizado y preparado para comenzar a programar.

Proyecto recibido

Estructura inicial 
infocurso/
├── index.html
└── js/
    └── app.js

El archivo index.html contiene:

index.html 
<!DOCTYPE html>
<html lang="es">

<head>
  <meta charset="UTF-8">
  <title>InfoCurso</title>

  <script src="app.js"></script>
</head>

<body>

  <h1>InfoCurso</h1>
  <p>Información para el alumnado de DAW.</p>

</body>

</html>

Y js/app.js contiene:

JavaScript · js/app.js 
console.log("InfoCurso está funcionando");
alert("Bienvenido a InfoCurso");

Tu misión

  1. Corrige la integración de JavaScript. El archivo está dentro de js/, así que debes corregir la ruta utilizada desde index.html.
  2. Aplica la forma de carga utilizada en el módulo. Coloca el script externo en el <head> utilizando defer.
  3. Ejecuta el proyecto con Live Server y comprueba que aparece el alert() y que el mensaje de console.log() llega a Console.
  4. Utiliza DevTools. Localiza el <h1> en Elements y el archivo app.js en Sources.
  5. Provoca un error de sintaxis de forma controlada. Elimina temporalmente un paréntesis o una comilla del console.log(), observa el mensaje en Console, anota qué archivo y línea señala el navegador y después corrígelo.
  6. Explica la arquitectura. Indica qué elementos de este proyecto se ejecutan en el cliente y menciona dos tareas de una aplicación real que deberían resolverse en el servidor.
  7. Entrega una breve conclusión. Explica qué herramientas has utilizado y qué procedimiento seguirías en el futuro cuando una página no funcione como esperas.
📦 Entrega del reto

Entrega la carpeta infocurso con los archivos corregidos y un documento breve con las respuestas de los puntos 5, 6 y 7. El proyecto debe ejecutarse correctamente mediante Live Server.

Cada pregunta tiene una única respuesta correcta.

2. ¿Cuál de estas tareas debería controlarse necesariamente en el servidor de una tienda online?

3. ¿Qué función principal cumple JavaScript en una aplicación web?

4. ¿Qué relación existe entre JavaScript y ECMAScript?

7. ¿Qué pestaña de DevTools utilizarías principalmente para consultar mensajes generados con console.log()?

10. Cuando un programa no funciona como esperas, ¿qué estrategia es la más adecuada?
